# WAO CLI 能力同步

开发新的服务、API 或业务操作时，先确认实际用户操作与认证边界，再判断它是否应通过 `wao` 命令提供。当前 CLI 位于 `wao-cli/`，首版调用工作区 MCP；服务端工具目录位于 `WorkspaceMcpTools.java`，现有覆盖记录在 `docs/specs/wao-cli.md`。

1. 检查新能力是否已由工作区 MCP 以当前令牌可见；对新增工具明确读取或写入权限、成员可见性、输入 schema 和错误语义。不要把新增 HTTP API 自动暴露给旧令牌。
2. 对适合终端和脚本的操作，同步添加或更新易发现的 CLI 子命令与帮助示例；复杂字段可沿用通用 JSON 输入。新工具即使能经 `tools call` 使用，常用业务操作仍应有子命令。
3. 同步更新 `docs/specs/wao-cli.md` 的能力台账、相关 API/MCP 规格，以及覆盖参数、权限拒绝、错误退出和实际请求的测试。若此次不提供 CLI，简短记录具体原因和以后需要重审的条件。
4. 按 `AGENTS.md` 的现有交付流程验证。只记录实际已实现的能力；不要将 Token、密码或真实用户数据写入文档、测试和提交。

这个 skill 是开发时的维护提醒，不授予发布、扩权或操作生产数据的额外权限。
