# 证据与能力边界

## 证据等级

按优先级使用：

1. 当前系统的真实数据、可复现实验和运行记录。
2. 仓库中已接受的规格、ADR、契约和测试。
3. 官方接口或官方文档。
4. 可追溯的第三方资料。
5. 经验判断或传闻。

低等级材料可以生成待验证假设，不能直接成为产品承诺。时效性强、风险高或用户要求核验的事实必须查询最新权威来源。

## AI、Skill 与 MCP

- Skill 提供可复用指令和资源；加载后的正文会占上下文，不能视为零成本。
- MCP 在服务端执行工具逻辑，但工具定义、参数、返回和模型判断仍会产生上下文与用量；外部服务还可能独立计费。
- 工具调用数减少不代表结果更好。先固定质量验收，再比较 Token、时延、费用、调用和重试。
- 不同宿主、版本和账号的能力可能不同。没有实际探测或官方依据时标记不兼容/未知，不伪造按钮或状态。

## 最小实验

提出效率或质量改进时，固定任务样本、模型、推理强度、代码基线和验收器。记录至少包括：一次成功率、人工续跑率、完整验收率、非缓存/缓存/输出 Token、墙钟时间、工具失败和重试。

只有实验组保持或提高质量时，资源下降才算优化。未回传用量是“未知”，不是零。
