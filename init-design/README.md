# Handoff: WAO（Wayuwa All in One）Life OS

## Overview

WAO 是一个面向少数成员（初始 2 人，可扩展）长期共同使用的个人/家庭人生管理系统（Life OS）。核心理念：**All in One 不是把功能挤进一个页面，而是让目标、项目、任务、日程、知识与资料处于同一个清晰、可查询、可关联的上下文网络中**。

本包包含完整的高保真交互原型（`WAO Life OS v4.dc.html` 为最终版）与业务架构图 / ER 图（`WAO 架构图与ER图.dc.html`），供 Claude Code 在真实代码库中实现 1.0 版本。

## About the Design Files

**本包中的 `.dc.html` 文件是 HTML 设计参考稿（可运行的交互原型），不是可以直接搬运的生产代码。**

你的任务是：**在目标代码库的技术栈中重新实现这些设计**。如果代码库尚不存在，推荐 **React + TypeScript + Vite**，配合成熟组件库（如 Ant Design / Radix + Tailwind）与图标库（原型使用 Remix Icon）。原型文件中的模板（`<x-dc>` 内）与逻辑类（`class Component`）可作为布局、样式值、交互逻辑与模拟数据的精确参照，但其运行框架（DC runtime / support.js）不要迁移。

原型打开方式：直接用浏览器打开 `WAO Life OS v4.dc.html` 即可交互体验（需与 `support.js` 同目录）。

## Fidelity

**高保真（hifi）**。颜色、字号、间距、圆角、阴影、交互状态均为最终意图，应按像素级重建，但使用目标代码库的组件体系实现。模拟数据（成员"娃哥/娃弟"、项目"WAO 1.0 原型"等）为演示内容，实现时替换为真实数据模型。

## 全局框架

### 布局骨架
- 左侧导航：展开 236px / 折叠 62px（0.18s ease 过渡），背景 #F3F4F7，右边框 1px #E8E9ED
- 顶栏 header：高 52px，白底，含折叠按钮、面包屑、「+ 新建」（任务/项目下拉）、通知铃铛
- **多页签栏（Tab bar）**：高 39px，背景 #EFF0F4。点击左侧菜单/打开项目/打开知识库均生成页签；激活页签白底 + 底部 2px #4358D6；「首页」固定不可关闭；页签可点 × 关闭、**右键菜单：关闭当前 / 关闭左边 / 关闭右边 / 关闭全部**；关闭激活页签时切到相邻页签；页签列表持久化
- 页签 key 规则：模块页 = 模块名；项目 = `proj:<id>`；知识库 = `kb:<id>`（每个项目、每个知识库都是独立页签，可多开）
- 内容区最大宽度 1340px 统一（宽视图），页面内边距约 16px 24px 40px
- 适配：1440×900 为主，~1024px 嵌入窗口可用（首页多列 grid 按窗口宽度降列）

### 全局交互
- ⌘K / Ctrl+K：全局搜索弹层（项目/任务/文档分组结果，实时过滤；知识库入口触发时为"AI 语义搜索"模式）
- Esc：逐层关闭（右键菜单/下拉 → 弹层 → 抽屉）
- Toast：顶部居中深色胶囊（#23262F），2.6s 自动消失
- 新建任务/项目成功后：**1.5–1.8s 全屏纸屑庆祝动画**（canvas，两侧喷射约 90 片，克制配色 #4358D6/#8A9BE8/#E3BE62/#5CB88A/#C9CFE8，Esc 可跳过，不阻塞操作，底部提示"按 Esc 跳过"）

## State Management（原型现状 → 实现建议）

原型为单组件 state + localStorage（键：`wao-demo-v1` 会话状态、`wao-docs-v1` 文档编辑）。实现时建议：
- 路由化：每个页签 = 路由（`/projects/:id`、`/kb/:id` 等），页签栏为路由栈的可视化
- 全局 store：当前用户、组织、页签列表、导航折叠态
- 数据模型见 ER 图（`WAO 架构图与ER图.dc.html`）：org / member / project / milestone / task / task_item / comment / kb_group / kb / folder / doc / job / job_run / calendar_account / event / file / image / vault_group / vault_item + 关联表 project_member、task_assignee、doc_link（多态双向）、task_link（自关联阻塞）
- 文档协同：Markdown 存储 + CRDT（如 Yjs）；密码库字段 E2E 加密，密钥不落服务端；文件/图床走对象存储 + CDN 直链
