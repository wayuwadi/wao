## 体验核对

- [ ] 首次进入能说清用途、主要信息和主要动作。
- [ ] 字段、按钮、Tab、状态与相邻页面叫法一致；原名/别名仍能找到功能。
- [ ] 默认值来自当前上下文或明确规则，没有要求用户填写系统已经知道的信息。
- [ ] 点击之前知道是预览、保存、创建还是立即执行；没有伪造审批边界。
- [ ] 初始、空数据、读取中、执行中、成功、失败、部分成功、无权限和异常数据逐项验收或写明不适用。
- [ ] 失败后输入、已成功数据与草稿保留；重试指向明确失败范围。
- [ ] 保存中新增输入、后台刷新、切换成员、刷新页面和并发冲突按本流程真实适用范围检查。
- [ ] 图标控件有名称；键盘能到达主操作，弹层进出与关闭页签后的焦点有去向。
- [ ] 长标题、长错误、窄屏、缩放及主题切换不遮挡关键操作；没有用微型字体凑单屏。
- [ ] 数据源、时间范围、指标含义、演示边界准确；无凭据或私有输入进入日志/提交。
- [ ] 结果可找到，并有自然的下一步；系统没有未经用户动作默默重复执行。
