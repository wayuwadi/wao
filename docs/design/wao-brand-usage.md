# WAO 品牌使用规范 · v4

当前基线：2026-10-07。沿用已确认的柔环 W 与圆角字标。历史 v3 保留作档案，新增页面和材料使用 v4。

## 识别要素

WAO 始终使用大写名称。柔环 W 表示连接、持续与轻松，固定字标使用矢量轮廓，不用设备字体重新排写。`Life OS` 是可选辅助签名，“一呼一吸”是呼吸空间名称，二者都不替代 WAO。

| 素材 | 用法 |
| --- | --- |
| `wao-soft-loop-v4.svg` | 32px 及以上标准图形，透明背景 |
| `wao-soft-loop-small-v4.svg` | 16–24px 图标，保留光学放大及中央留白 |
| `wao-wordmark-v4.svg` | 独立圆角字标，蓝紫 |
| `wao-lockup-v4.svg` / `.png` | 横向图形与字标组合，蓝紫，透明背景 |
| `wao-lockup-ink-v4.svg` / `.png` | 浅色背景单色组合 |
| `wao-lockup-white-v4.svg` / `.png` | 深色背景反白组合 |
| `wao-soft-loop-mono-v4.svg` | 应用 CSS mask，随页面文字色；独立展示改用深色或反白文件 |
| `wao-soft-loop-ink-v4.svg` / `wao-soft-loop-white-v4.svg` | 独立单色图形 |
| `wao-soft-loop-{16,24,32,64,192,512}-v4.png` | 透明背景栅格，按使用尺寸选择 |
| `wao-soft-loop-180-v4.png` | Apple 主屏幕图标，白底 |
| `wao-soft-loop-maskable-512-v4.png` | 浏览器 maskable 图标，白底且图形在安全区 |

SVG 可无损缩放；PNG 不放大超过原始像素尺寸。完整资源包为 `wao-brand-kit-v4.zip`，`brand-manifest-v4.json` 包含逐文件 SHA-256，可核对内容。

## 尺寸与留白

- 独立图形最小 16×16 CSS px，小于 16px 不展示；图形加字标的横向组合最小 88px 宽，约 30px 图形画布。独立字标最小 44px 宽。
- 标准图形的画布高度记为 H；图形与字标间距约 0.25H，组合外侧至少留 0.25H。网页页脚可按现有紧凑样式缩放，保持各部分比例和阅读清楚。
- 图形与字标垂直居中，保持固定几何比例和线宽。不要拉伸、旋转、填死中央穿插、增加渐变/立体描边，或把成员头像和伙伴替换为主标识。
- 新应用页面复用 `WaoLogo`；单色场景用 `tone="current"`，由文字色提供对比。公共素材用运行时 `/brand/` 地址，不在 CSS 中写会被发布 base 改写的文件 URL。

## 色彩与背景

| 颜色 | 数值 | 角色 |
| --- | --- | --- |
| 蓝紫 | `#5665E9` | 主标识与轻量品牌强调 |
| 深墨绿 | `#273C3B` | 浅色呼吸背景单色标识 |
| 暖纸白 | `#F6F6ED` | 呼吸空间浅色背景 |
| 夜色 | `#202B2A` | 呼吸空间深色背景，使用反白标识 |

浅色空白背景使用蓝紫或深色组合；深色背景优先反白。照片和复杂背景先加简洁纯色容器及留白。主色不铺满内容页面，按钮与信息状态继续使用现有主题规则。背景柔环仅作静态装饰，日间透明度约 3.5%、窄屏约 2.5%，不能承载文字或操作提示。

## 页面表达

- 桌面侧栏展开：品牌放侧栏左上角；折叠：品牌放顶部菜单前面。导航品牌入口只保留一个。右下角的轻量 WAO Life OS 签名持续保留。
- 手机内容优先，完整菜单显示品牌；呼吸、登录与公开分享页使用同一图形/字标，业务标题与品牌分开。
- 页面有错误或加载状态时仍可保留品牌，但不以品牌占位掩盖状态。成员头像表达真实身份，不当作 WAO LOGO。
- 伙伴共用名字、颜色和特征：小绘 `#00B5F7`/贝雷帽，小知 `#FFCA0D`/眼镜，小悦 `#F42CDB`/墨镜，小悠 `#B3EC22`/凸眼和蝴蝶结。呼吸场景可柔化材质与明度，保持角色可识别。

## 品牌理念与伙伴

WAO Life OS 的表达是「让事务有序，让生活留白。」通过小记、待办、项目与 AI 协作，把日常事务放在顺手的位置。产品理念为随手记录、清楚安排、留一点空白，不用效率口号催促用户。

| 伙伴 | 含义 | 语气示例 | 稳定标识 |
| --- | --- | --- | --- |
| 小绘 · 表达 | 留下灵感，表达自己。想法不必完整，也值得被记录。 | 先记下来，慢慢再说。 | `painter` |
| 小知 · 理解 | 保持好奇，让杂乱的事情慢慢变清楚。 | 我们一起理一理。 | `bookworm` |
| 小悦 · 喜悦 | 看见每一点进展，小小的完成也值得开心。 | 这一步，也值得开心。 | `happy` |
| 小悠 · 松弛 | 按自己的节奏生活，休息也有它的价值。 | 歇一会儿，没关系。 | `frog` |

四位伙伴一起表达「记录一点，明白一点，开心一点，放松一点。」这是角色性格与品牌语气，不是四个新增 AI 服务。当前名称、含义、语气和肖像由 `companionIdentity.ts` 统一提供；稳定标识、已有形象、交互与身份缓存不随名称变化。

设置 → 关于 WAO 展示品牌名片、理念、伙伴与轻量了解更多入口。产品故事只链接真实公开记录，使用其当前标题；关于页不请求成员的私人小记。保留页面阅读与留白，不把品牌介绍堆到首页。

## 维护与验收

`wao-web/src/config/brandIdentity.json` 是字标几何和基础配色来源，`wao-soft-loop-v4.svg` 是图形母版。运行 `npm run brand:generate -- <Sharp 包路径>` 生成所有导出及资源包；参考页在 `/brand/guide.html`。导出依赖用于离线制图，不进入业务运行时。

解压资源包后可直接打开 `guide.html` 查看素材，主操作转为打开包内规范；保留文件夹内的相对路径。

核对小图标、字标、明暗背景、320/390px、侧栏展开折叠及公开分享；生产构建下核对资源实际可访问。已安装浏览器应用的图标更新由浏览器管理，网页文件更新不等于系统图标已刷新。实体设备验收记录与浏览器视口模拟分开。
