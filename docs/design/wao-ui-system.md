# WAO 界面设计系统

版本：1.2 · 2026-10-31 布局密度与轻量编辑整理。适用于浏览器中的 WAO，新开发和修改均以本文件为总入口。

## 已确认的共同语言

轻盈、有秩序、阅读优先。**留白线框为主，浅底分区为辅，阴影集中在浮层。** 蓝紫色用于品牌识别、选中和关键操作；普通页面不使用大面积高饱和底色。四位伙伴用于适当的陪伴场景，不为每个表单新增插画或品牌口号。

保留清楚的文字和空白，避免卡片套卡片、多层背景和同时高亮多个操作。主操作由当前业务决定，不把“新建任务”等全局快捷入口默认做成有底色主按钮。次要编辑操作可以在桌面 hover / focus 时出现，键盘和触屏始终可达。

## 基础样式

2026-10-31 全站文字一致性：操作界面统一为页面标题 22px（手机 20px）、分区与卡片标题 16px、正文及操作 14px、说明与字段标签 13px、编号与时间 12px。同级标题复用 600 字重与 1.4 行高，不以零散的 11.5 / 12.5 / 13.5px 区分重要性。任务详情的描述、子任务、评论、属性值统一为正文 14px / 1.7；页签 14px，分区 16px，标题沿页面标题，不再额外使用 24px。本条替代下方 2026-10-29 任务详情的 24 / 16px 特例。小记和知识库长篇正文继续使用 16px 阅读字号；内容自身的标题、代码、图表数字、头像与图标保留各自语义。

需要读懂的说明、状态、日期、编号和空提示用 `--wao-text-3`；弱色保留给禁用或装饰。增量 UI 检查新增 `typography` 规则，禁止在 `font-size` 和 `font` 简写中新加绝对字号（包括变量回退值）；图标、图表等必要例外逐文件逐声明登记。相对内容标题允许 em 缩放，禁止用全局 `!important` 覆盖富文本或第三方画布。

旧日期记录并入日历，管理界面沿用自适应日期卡片和人生领域 token，不默认创建示例数据。习惯页采用清单与月历详情两栏，1000px 以下纵向叠放；打卡同时使用文字/勾选表达状态，不能只靠颜色。表单复用 SettingsDialogShell/WaoField，明确草稿、并发冲突、可恢复删除与个人提醒。设计参考复用 DateCounterCard 的静态示例，业务行为见 [倒数日与习惯打卡](../specs/countdowns-habits.md)。

番茄专注已退役，历史示例保留供追溯。此前番茄专注使用两栏：左侧计时和任务关联，右侧专注笔记与统计，下方为私有历史；页面实际内容区不超过 720px 时顺序叠放，随导航侧栏和悬浮窗口空间自动重排。准备、运行、暂停和结束阶段保持同一表盘尺寸和操作区位置；任务关联使用搜索浮层，右侧集中笔记、统计与最近五条记录，桌面不随历史增加撑高页面。`FocusDial` 复用主题 token，数字使用等宽计数，不以颜色区分暂停和错误。设计参考仅展示静态计时，真实行为见 [番茄专注规范](../specs/pomodoro-focus.md)。

待办工作台的「所有」、日期、标签和已完成入口只汇总当前用户负责的任务；未指派的内嵌子项沿父链归属，显式指派给他人的子项不混入，无负责人主任务按创建者归属。移除「指派给我」，旧已保存入口回到个人所有。显式项目清单仍展示后端授权的共享任务；清单与四象限保持同一范围，不改变项目权限。标签编辑使用紧凑浮层和可切换选中项，不挤动正文。

- 品牌色由 `brandIdentity.json` 提供。操作色用 `--wao-primary`，强调文字用 `--wao-primary-text`，选中浅底用 `--wao-primary-soft`。不要把品牌色、操作色混为一个硬编码值。
- 页面、卡片、辅助分区分别用 `--wao-bg-page`、`--wao-bg-card`、`--wao-bg-sub`。内容线用 `--wao-line`，控件线用 `--wao-line-control`；默认 1px 细线。
- 正文用 `--wao-text`，说明用 `--wao-text-3`。弱色仅用于非关键元信息，不用于正文、错误或必须阅读的说明。成功、待处理、失败使用各自语义色对，同时保留文字和图标，不只靠颜色。
- 默认内容卡片圆角 `--wao-radius-card`（12px），控件 `--wao-radius-control`（8px），弹窗 `--wao-radius-modal`（16px）。胶囊只用于标签等已有用途。
- 常用间距 `--wao-space-1/2/3/4`（8/16/24/32px）。页面标题 `--wao-font-title` 22px（手机 20px）、小节 `--wao-font-section` 16px、卡片标题 `--wao-font-card-title` 16px、正文 `--wao-font-body` 14px、说明 `--wao-font-help` 13px、元信息 `--wao-font-caption` 12px。标题字重 600、行高 1.4，正文行高 1.7；窄屏重排而不缩小正文和说明。
- 阅读正文使用 `--wao-font-reading` 16px；富文本 h1/h2/h3/h4 分别按正文的 1.5/1.25/1.125/1 倍缩放，编辑和预览复用同一规则，正文变大时小节不能变得比正文小。代码继续使用等宽字体，计时与统计数字使用等宽数字，统计单位使用说明字号。
- 内容卡片默认无阴影。浅底分区不同时叠加强阴影；菜单和弹窗使用 `--wao-shadow-pop`、`--wao-shadow-modal`。
- 传送到 body 的右键菜单显式使用正文基线：`--wao-font`、14px（`--wao-font-body`）、1.5 行高和 400 字重，不能继承浏览器默认 16px；辅助标题使用说明字号。
- 图标沿用 Remix Icon 的线性图标，通常 16–20px；图标按钮有明确可访问名称，图标不能替代保存失败等状态文字。
- 页面宽度按内容选择，设置普通内容上限 1000px，管理表格可保留 1420px；小记、编辑器与沉浸场景保留已批准的布局。不要强制所有页面相同宽度。
- 常规页面的外侧留白随工作区或悬浮页签的实际内容宽度连续缩放，水平留白为 12–44px。分栏工作台由各自的导航和工具栏管理留白。

## 组件与布局规则

2026-11-12：固定菜单与功能目录移除倒数日、番茄钟和算一卦，旧手机配置与页签同样过滤。日期记录集中在“日历 → 日历设置 → 日期记录”，弹层使用统一标题和添加日期操作，内部不重复展示倒数日页面标题。

2026-11-03 待办清单采用导航、列表、详情三栏。列表标题、搜索与快速添加留在列表栏，右侧日期栏和标题从顶部开始；两栏独立滚动，默认分栏比例为 55% / 45%，保留成员已保存的宽度。窄容器按上下两区排列，不让清单名称和日期挤没任务标题。「今天」将已过期任务独立分组，组头提供「顺延」并先确认范围。日期和优先级使用右键菜单顶部图标行，所有图标有文字名称及键盘访问，普通操作按功能分段；菜单以浮层显示，不推移正文。

2026-10-31 用户反馈“空间占用很大”“加一个标签阵仗太大”：任务详情标题独占一行，工作项类型和标签放到页签工具行；手机允许工具行换行，不能把按钮缩到不可触达。概览空描述使用约 40px 轻量输入与并排图片入口，字数只在独立描述页签展示；有内容继续自然增高，不卸载编辑器、上传队列和草稿。分区间距统一以 16px 为主，空评论约 42px，聚焦或有草稿时展开，发送和失败提示仍可达。

标签在任务详情和清单中复用 `CellMenu` 的 body 浮层，宽约 300px，并限制在视口内；禁止使用 `position: static; width: 100%` 把小属性编辑变成整行大表单。候选标签列表独立滚动。Escape、点外部和滚动收起但保留本机草稿，再打开恢复原修订号；明确取消才清理草稿。保存中不收起，失败原位显示并可重试；独立快捷窗口沿用内嵌表单，避免浮层套浮层。

文件页去除已过时的功能上线横幅，上传区保持紧凑横行；上传进度、失败重试和文件限制仍直接显示。知识库卡片将图标、名称和收藏并排，空描述不保留固定高度，空分组使用轻量文字而非大虚线框。小记堆叠布局不能在更窄断点反向增加空编辑器高度；全屏写作、已输入内容和草稿保护继续沿原规格。

- `WaoCard` 的默认线框用于独立内容，`soft` 用于弱说明。不要为了“有设计感”给所有区域增加卡片。可点击整卡只能使用语义链接或按钮，不让普通 div 冒充操作。
- `WaoButton` 使用 primary / secondary / ghost / danger。一个当前操作区域通常只有一个主操作；危险操作有明确动词。加载时阻止重复提交，禁用说明由业务页面提供。
- `WaoField` 提供标签、说明、错误与关联关系，业务仍负责校验和草稿。输入不能只靠 placeholder 命名；错误在原字段位置显示，输入仍保留。
- 弹窗复用 `SettingsDialogShell`，复杂设置复用 `AiSettingsLayout` 等已确认组件。短确认约 420–480px，普通表单约 640–760px，复杂设置约 1000px / 最高 760px。按内容决定高度，不为短表单制造大片空白。
- 确认弹窗保持两个明确选择；普通表单保持焦点、Esc、关闭后焦点恢复、固定保存栏。关闭是否保存由原业务决定。320 / 390px 下弹窗全屏，分项导航换行或可浏览，正文独立滚动，底栏始终可达。
- 浮层首次渲染到位，不先出现在错误位置再跳动。长标题、长选项、大量标签都要有明确浏览方式。

### 知识库导航与阅读（2026-11-06）

语雀参考用于知识库的阅读秩序和导航清晰度，不替换 WAO 品牌色、主题或其他页面布局。知识库首页以目录和内容为主，库名、文件夹、文档标题与更新时间分层排列；层级来自真实目录关系，搜索保留必要上下文，不用多个同权重卡片制造层次。长目录先检索完整元数据再分批呈现，未渲染内容不能被解释为没有结果。

文档的路径、标题、作者与时间和正文形成连续阅读顺序；正文继续使用 `--wao-font-reading`，标题按相对字号缩放。阅读模式收起编辑工具，专注模式收起两侧导航；均保持同一个编辑器、草稿和保存反馈，不因显示切换重建内容或覆盖用户侧栏偏好。大纲按真实渲染标题导航，窄内容区按需显示为浮层，避免挤压正文。辅助日期可在窄区隐藏，必要保存状态仍须可读。

知识库清单和目录在手机作为互斥侧栏打开，保持正文可用宽度；打开后焦点进入侧栏，关闭后回到相应入口。目录键盘导航、单一 Tab 入口、层级读屏语义和触屏至少 44px 点击区属于组件行为。加载失败、真实空库和搜索无结果分别表达；既有内容刷新期间保留。设置与确认复用 `SettingsDialogShell` / `ConfirmActionDialog`，异步反馈归属于发起操作的库和账号。实现及验收边界见[知识库阅读、导航与编辑升级](../specs/knowledge-yuque-upgrade-2026-11-06.md)。

## 必须覆盖的状态与体验

2026-11-09：启动与模块列表读取遇到超时、断网或临时服务故障时，按 1/3/10/30 秒间隔自动重试失败模块。隐藏页面、离线或登录过期时暂停，恢复网络或返回页面时继续；账号切换与工作区释放取消旧队列。读取失败保留现有内容并显示自动恢复状态，知识库列表确认成功前不显示“知识库不存在”。沿用 DataLoadStatus 与现有空状态组件。

2026-10-29 全站反馈优化：自动保存回执复用 `SaveHint`，说明字号、可换行和读屏播报保持一致；明确区分本机草稿、保存中、服务器已确认和失败。列表初次为空与筛选无结果复用 `WaoEmptyState`，直接提供创建或清除筛选入口，读取失败不显示空状态。`DataLoadStatus` 优先展示当前页面所需模块，其他模块错误折叠，重试只读取所选模块；同账号刷新保留上次数据，成功后同时更新内容与加载状态。

文件、图片、项目资产与密码库的删除使用 `ConfirmActionDialog`，复用 `SettingsDialogShell`；确认前不写入、处理中不能重复提交或关闭、失败保留对象与原位重试。只有服务器确认成功后才移除条目。设置搜索仅检索设置目录并沿用原有离开保护。`/design` 的“状态与反馈”提供合成演示，不调用真实删除或保存接口。

可编辑功能逐项覆盖：读取中、读取失败、空数据、草稿、保存中、已保存、失败重试、跨设备冲突。读取失败不能假装空数据；服务端和定时同步不得覆盖未落库输入。成员切换隔离草稿，冲突不静默覆盖。设计参考只演示这些状态，不把演示保存称为账号保存。

同时检查浅色 / 深色、320 / 390px 与桌面、长文本、键盘顺序与焦点、触屏操作、减少动画偏好。触屏控件尽量至少 44px 点击区域；输入字号避免手机自动放大。动画不得阻碍阅读和主要操作。

## Agent 与开发者执行约束

1. 修改界面前读取本文件和对应专门规范，定位已有 tokens / 组件；提交说明写明复用了什么。设计已确认时直接实现，不重新发明组件风格。
2. 新增和修改的通用界面不得增加硬编码颜色、圆角或阴影；优先复用变量和公共组件。新增语义值放到 tokens，并维护两种主题与设计参考。
3. 特殊图表、第三方画布、品牌插画等确需字面值时，先记录 `wao-web/scripts/ui-style-exceptions.json` 中的具体文件、规则、声明及理由；例外不是通用界面免检。旧页面问题不自动批准为新标准。
4. 执行 `npm run ui:check -- --base origin/main`、相称测试、类型检查及构建，并浏览器对比已批准的方向。样式检查只能发现字面值漂移，不代替视觉和用户链路验收。
5. 同一需求修改组件或规则时，同步规范、参考和必要测试；新规范修改须有确认依据。产品界面不展示内部开发清单或工程术语。
