# 设置页面视觉与交互规范

2026-10-04 用户已确认统一 AI 设置 Demo，并授权后续设置页面直接沿用。此文件是该风格的唯一项目规范入口。

## 布局

- 保持明亮、轻盈的 WAO 风格，使用现有主题变量、蓝紫强调色、圆角和少量图标。颜色必须兼容浅色与深色主题。
- 多项 AI 设置弹窗桌面约 1000px 宽、最高 760px；左侧分项导航约 180px，右侧显示当前项。模型与思考深度固定放在右侧顶部，一次只编辑一段提示词。
- 使用 `SettingsDialogShell` 统一标题、说明、关闭按钮与固定底栏；`AiSettingsLayout` 提供分项导航、能力区域和独立内容滚动。普通短表单可用约 760px 宽、自适应高度，不制造大片空白。
- 底栏始终可见，明确当前保存状态和主按钮；错误在原位置展示并可重试。保留每个功能已有保存语义，不能仅因统一外观而改变关闭是否保存。
- 全局设置普通内容以 1000px 为上限，表格等确需宽度的管理页面保留 1420px；保持原导航分组与深链接。
- 手机使用全屏弹窗、顶部横向可浏览的分项导航；标题和底栏可换行，输入区独立滚动。不得横向溢出或让保存按钮被长文本挤出。

## 编辑与能力选择

AI 设置切换项目、关闭重开和刷新时保留成员隔离的本机草稿。服务器读取失败不能当作空配置；跨设备冲突必须保留草稿、展示账号当前设置，再由用户明确选择保留草稿基于最新版本或使用账号配置。读取不得自动更新草稿版本来绕过 CAS。

模型和深度来自真实模型目录；无法读取、已下架或不兼容时保留原选值并明确提示，禁止静默替换。小记与天人一卦共享界面组件，各自独立保存设置。恢复默认只改变当前编辑内容，保存后才生效。

## 已应用入口

- 小记页面设置、文档编辑器配图设置、全局设置的小记 AI 配置。
- 天人一卦页面的「解读与配图设置」。
- 项目设置弹窗、文件与图床设置弹窗。
- 全局设置普通页面的内容宽度。

未来设置页面可直接参考本规范；出现不同业务结构时保持视觉和状态表达一致，不强行增加导航或 AI 区域。
