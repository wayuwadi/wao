# 生日祝福页（龚慧 · 8 月 1 日）

一次性的祝福页，不进 SPA 路由，作为静态文件随前端一起发到云节点。

- 源文件：`wao-web/public/birthday/gonghui.html`
- 线上地址：`https://wao.wayuwa.cn/birthday/gonghui.html`
- 免登录，直接分享给收礼物的人；不引用任何外部脚本、字体和图片，断网也能开。

## 为什么是静态 HTML 而不是 Vue 页面

需求要的是「一个能发链接的 HTML」，收礼物的人不是 WAO 用户。放进 `wao-web/public/`：

- CD 里 `npm run build` 会把 `public/` 原样拷进 `dist/`，再整体同步到云节点 `/var/www/wao/dist/`，Nginx 的 `try_files $uri $uri/ /index.html` 命中真实文件，不会被 SPA 兜底接管；
- 不进 `router/index.ts`，因此不受登录态、布局和菜单影响，也不会被业务改动带崩。

## 交互状态

- **初始态**：夜色背景 + 暖光光斑，居中显示「龚慧 / 8 · 1 生日快乐」和提示「轻触屏幕，种一束夏天」。
- **点击后（开花中）**：30 朵玫瑰按由后到前的顺序，从屏幕下方抽出花茎、长叶、开花，约 3 秒开满；每朵开到一半时溅出一小簇光点。
- **开花后**：标题「生日快乐」和四行祝福逐行淡入，底部显示「30 朵永不凋零的夏天玫瑰」和「再开一次」。之后玫瑰持续轻微摇曳并偶尔飘落花瓣，画面不静止。
- **再次点击画面**：在手指位置炸开一小把花瓣和光点。
- **再开一次**：清空计时器与粒子，回到初始态，重新随机花束布局。

## 悬空效果

「点了之后页面悬空」是指整束花浮在屏幕前方随手机姿态移动：

- 手机：点击时申请陀螺仪权限（iOS 13+ 必须由用户手势触发），按 `beta` / `gamma` 做视差；用户拒绝授权也不影响祝福，退回自动漂浮。
- 桌面：跟随鼠标做同样的视差。
- 无论有没有输入源，花束都有一条低频自漂浮曲线，保证「悬空」不依赖传感器。
- 每朵花按所在圈层有不同的视差深度（后排 0.3 / 中排 0.62 / 前排 1.0），前后拉开距离感。

## 性能与降级

- 30 朵花不实时画花瓣：启动时按 6 套配色 × 3 个明暗层级预渲染 18 张玫瑰贴图，每帧只做 `drawImage`。
- `devicePixelRatio` 上限取 2，避免高分屏上画布过大掉帧。
- 尊重 `prefers-reduced-motion`：缩短开花时长，关闭摇曳、花瓣飘落和陀螺仪视差，只保留最终画面。
- 窗口尺寸变化和横竖屏切换会重新布局，并保留已开花的进度。
