# 四个日常，一种节奏：交互 Demo

打开同目录的 [独立 HTML](core-experience-2026-10-03.html)，无需安装依赖。也可从仓库根目录运行 `python -m http.server 5258 --bind 127.0.0.1 --directory docs/demos`，浏览器访问 `http://127.0.0.1:5258/core-experience-2026-10-03.html`。

本文件是视觉方案，不是业务页面改版。全部人物、任务、日期、天气与考勤均为明确标注的演示数据；保存只写本页内存，刷新恢复。CSP 禁止网络连接，不接 WAO API。不要将其保存反馈当作业务验收。

## 体验顺序

1. 待办：切「等待他人」再返回全部，查看五种截止分组、独立执行提示和仍有未收尾子项的已完成主任务；打开更多菜单、键盘 Enter 打开详情、Escape 关闭。
2. 小记：左侧写新草稿，右侧继续行内编辑；查找「桂花」并定位，展开全文。切页面后草稿仍在。设计说明中的「演示保存失败」可验证失败保留，关闭后重试。
3. 项目：切待验证，看到主任务及子项两种命中；组合负责人、关键词，区分项目计数与当前筛选。先排序或折叠子项，切筛选再清除，观察状态保留。
4. 日历：将紫色执行卡从周三拖至周四，截止仍为周五，14:00–15:30 时长不变；撤销。点击卡片也可输入日期。同日执行和截止合为一张卡，次级区域可展开天气、考勤和节日示例。
5. 切「手机 390」，核对底部导航、长标题、行内编辑、横滚表格和日历。切「当前结构对照」查看简化示意；它不是线上截图。

## 推荐与取舍

推荐保留小记写读结构和项目表格，只统一日期表达、操作位置、焦点及反馈。

| 页面 | 调整 | 代价与待确认取舍 |
| --- | --- | --- |
| 待办 | 标题与执行提示分层 | 行高略增，换取长标题可读性 |
| 小记 | 保留左写右读和行内编辑，保存反馈贴近输入 | 手机操作稍高，编辑入口更明确 |
| 项目 | 工具栏与快捷条件分层、父子缩进 | 手机仍需横向滚动读取全部字段 |
| 日历 | 紫色执行、浅橙截止，辅助信息折叠 | 天气/考勤/节日不再占首屏主要位置 |

正式实施须另行确认。本轮不恢复项目总览、独立状态、阶段按钮、批量选择或项目 AI Run，不新增任何模型调用。
