# 首页伙伴与灵感纸条

2026-10-03。延续首页伙伴规格，浏览器端轻互动，不新增服务接口。

- 首页空白处右键打开轻动作菜单；链接、输入区、选中文本保留浏览器菜单。可见按钮和伙伴 Shift+F10 提供键盘、触屏等价入口。
- 四个伙伴可分别邀请跳舞；集体舞持续八秒，安静陪伴、编辑、页面隐藏或减少动态效果时停止或降级。不播放声音。
- 灵感纸条可切换预置问题与当前成员自己的真实小记。旧小记只读引用，明确来源；加载失败可以重试，无数据时说明并提供问题。
- 浮层内写新想法，复用小记编辑器。独立账号草稿、保存中禁止关闭、失败重试、隐藏时保留编辑器和草稿；切换灵感不替换输入。
- 不扫描他人小记，不自动生成或保存内容，不将演示数据进入业务。
