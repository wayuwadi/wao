# 工作项类型与知识库混合目录

来源：https://wao.wayuwa.cn/api/share/tasks/t2c23fe1f9c7d473fa8a00e3aa8f819e.md

## 小记分享

- 小记列表卡片直接提供“复制分享链接”，复用已有 `/s/d/<id>` 免登录只读分享页；复制成功与失败沿用通用剪贴板提示。原有“分享到聊天”和完整文档入口保留。

## 工作项类型

- 新建任务和任务详情提供需求、任务、缺陷三种类型，表格使用绿灯泡、蓝任务、红缺陷图标区分。
- `Task.workItemType` / `CreateTaskRequest.workItemType` 取值为 `requirement`、`task`、`bug`；旧数据读取默认任务。类型存于既有 `detail_json`，全文保存纳入编辑版本；旧客户端省略类型时保留已存类型。
- 主子任务关系与工作项类型分开，修改类型不调整任务层级。旧式内嵌检查项继续使用子任务图标。

## 知识库

- 重命名使用独立输入草稿；服务端刷新不覆盖输入。回车或失焦保存，输入法组合期间回车不提交；失败保留输入，回车重试；Esc 取消。
- 自动保存提示移到顶部操作按钮之前，保留固定宽度，状态变化不挤动按钮。
- 分组和文档构成混合目录，支持分组下创建文档/分组、文档下创建分组/文档；拖到节点内改变父级并保留子树。根目录容纳分组，文档始终有分组祖先；分组可拖回根目录。
- 搜索展开命中节点的祖先路径，文档正文、草稿和链接仍用原 ID。归档和删除有子节点的文档前须先移出子节点；删除含子分组的分组前须先移出子分组，避免无意删除嵌套内容。失败不从本地移除内容。
- 新建节点后若关系保存失败，节点保留在创建时的原分组/根目录，并显示目录失败与重试；不把新建失败处理成自动删除业务数据。

## 接口与存储

- V160 新增 `kb.directory_json`。旧数据为 NULL，按既有分组与 `doc.folder_id` 构造目录，不重写已有正文。
- `KbDto.directory` 为父级映射，节点键为 `f:<folderId>` 或 `d:<docId>`；空字符串表示根目录。
- `PUT /api/kbs/{id}/directory-parent` 接受 `{node,parent,expectedParent}`，返回更新的 `KbDto`。锁定知识库后校验父级前置条件、节点所属库、环和分组祖先；并发移动冲突返回 409。
- 文档移动到其他祖先分组时只更新 `folder_id` 并递增 `rev`，保留正文和归档字段；旧编辑快照按既有冲突恢复机制处理。
- 已启用混合目录的知识库拒绝旧的完整平面目录排序接口，提示刷新后使用节点移动，避免旧客户端破坏层级。
