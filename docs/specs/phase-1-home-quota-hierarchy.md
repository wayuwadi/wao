# 首页额度与权益的摘要层级

对应体验审计 B06，补充首页权益记录及紧凑布局规格：原额度、权益数据与编辑能力不变，仅调整展示层级。

- 常态显示 Codex 周剩余比例与“展开额度与权益”，默认折叠详细数值、会员日期与重置卡记录。
- 保留现有低于 20% 的强调阈值，提示长任务可能受限，不判定所有账号或所有模型不可用，不阻止执行。
- 额度请求失败明确提示，保留旧快照仅供参考并提供重试。无有效快照不伪造零额度或正常状态。
- 权益读取/保存问题、草稿问题、未完成编辑及七日内到期在折叠时仍提示；到期提醒明确来自手工记录。
- 折叠仅隐藏组件，不能销毁未保存输入、原错误恢复与成员隔离逻辑。
- 首页起步引导横跨宽屏两列；原目标输入与 AI 控制区继续并列。

验收覆盖默认折叠、展开、错误重试、权益关注状态、草稿收起恢复和宽窄屏布局。
