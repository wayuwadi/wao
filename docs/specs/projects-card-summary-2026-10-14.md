# 项目卡片信息精简

2026-10-14 用户要求删除项目卡片红框中的重复统计文字。本规格调整项目列表卡片的展示，取代项目任务收尾计数规格中相应卡片条款，其他计数口径继续有效。

- 项目卡片移除“未收尾 X 项／共 Y 项任务”和“内嵌子项未收尾 X／共 Y 项”，不展示任务计数加载或错误文案。
- 未设置截止日期时不再占位显示“未排期”；已设置的真实截止日期保留，仍使用既有日期与逾期提示。
- 保留项目名称、所属领域、负责人、描述／目标和成员头像；项目页签计数、查找和按任务收尾率排序继续沿用既有口径。
- 不改变项目或任务数据、状态、权限、排序偏好、保存及草稿行为。复用现有组件与主题 token，不新增样式规则。
- 仅调整浏览器展示，不新增 API、MCP、CLI 操作或数据库变更。
