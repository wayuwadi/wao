# 小记 AI 挖掘与首页内容卡片

> 当前自动发现遵循 [小记顺手发现](notes-passive-discoveries.md) 与 ADR-314；本文件保留历史手动产物设计，不作为新生成、三类齐全、来源回退或配图规则。

## 用户结果

成员在“小记”页点击工具栏的“AI 挖掘”按钮，在弹层中即可从近期原文得到三种带证据的内容：可直接阅读的洞察、尚未启用的提醒草稿、可继续写作的文章种子。挖掘区默认收起，不占用小记撰写和浏览空间；首页只展示最新洞察或处理状态，成为总览地图的一部分。

## 状态与交互

- 初始：没有运行时说明至少需要两篇有正文的小记，并承诺不改写原文。
- 入口：与“阅读模式”并列放在小记清单工具栏；点击后打开弹层，点击遮罩、关闭按钮或按 `Esc` 均可退出并回到原按钮。
- 排队 / 运行：展示后台继续说明；离开页面不取消任务，重新进入后恢复轮询。
- 成功：三类页签展示内容、理由与来源小记标题/版本；点击来源进入阅读模式。
- 反馈：`留下它`、`不准确`、`作为提醒草稿` 均有保存中和失败重试状态。提醒草稿明确说明未启用、未推送。
- 失败：保留旧结果（若有），展示真实错误并允许使用同一请求标识确认或重试。
- 首页：加载、空、运行、成功、失败均有诚实状态；不提供重挖掘或直接启用提醒按钮。

## 数据与安全

- 数据表与状态见 ADR-288；API 见 `docs/api/note-mining.yaml`。
- 只读取当前成员本人创建、未删除、未归档、非自动生成的小记。提示材料按不可信输入处理，禁止其中的指令改变输出或触发工具。
- AI 返回必须完整包含三种唯一类型、非空内容、非空理由。非法来源索引回落到第一篇真实快照；无完整结果不写入任何产物。
- 内容候选最长 2000 字，理由最长 1000 字，来源摘录最长 240 字；数据库不复制完整原文。
- 首页和小记页均以浏览器登录会话鉴权，不使用公开链接或旧 MCP 令牌。

## 非目标

- 本期不自动创建提醒规则、不定时推送、不做医学或行为合规判断。
- 本期不覆盖原文、不自动发布文章、不把“收藏”解释为用户认可事实。
- 本期不提供 CLI/MCP 命令或后台定时挖掘。
