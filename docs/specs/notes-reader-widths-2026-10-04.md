# 小记阅读器两侧宽度

本规格扩展 `notes-reading-columns-2026-10-04.md`，保留正文宽屏 / 窄屏的最大宽度与三栏阅读行为。

- 桌面（大于 850px）在目录与正文、正文与图片清单的两条边界提供可拖拽分隔条。目录默认 180px，图片清单默认 238px；只改变两侧空间，不修改正文内容宽度设置。
- 拖拽结束自动保存到当前浏览器、当前成员的独立偏好，刷新或重新进入阅读器恢复。侧栏速览与全屏阅读共用；外面记录区比例偏好独立。
- 目录最小 140px、最大 600px，图片清单最小 180px、最大 700px，同时保留正文可用空间。窗口缩小时限制实际两侧宽度，850px 及以下使用既有响应式布局，隐藏拖拽条，保留桌面偏好。
- 支持键盘左右键微调（Shift 加速），Home 和双击恢复该侧默认宽度，End 到当前允许的最大值。分隔条提供标签、方向和宽度数值，键盘操作不触发翻篇。
- 退出阅读、窗口缩放、失焦、取消指针或卸载会结束拖拽并保存；切换成员不把旧成员的宽度写入新成员偏好。无效偏好使用默认值；存储失败提示并允许再次调整重试。
- 不重建编辑器，不更改图片、正文、草稿、版本、原文或阅读顺序，不新增 HTTP / MCP / CLI 或数据库字段。
