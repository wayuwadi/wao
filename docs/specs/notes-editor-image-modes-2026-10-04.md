# 小记编辑图片显示模式

本规格扩展 `notes-card-image-references-2026-10-04.md` 与 `notes-image-layout-2026-10-04.md`，修订旧规格中编辑时固定嵌入图片的约定。保留 ADR-198 的富文本 JSON 事实源与草稿保存契约。

- 新建、卡片原地编辑和全屏编辑右上角提供「预览引入 / 图片嵌入」。首次默认预览引入；成员偏好在当前浏览器自动保存，刷新恢复；阅读视图继续固定使用图号与图片栏。
- 预览引入模式在图片原位置显示图号引用，右侧图片栏来自当前编辑草稿，上传、粘贴、删除、撤销及 AI 插入后立即同步顺序和数量。同 URL 的不同节点分别编号，嵌套图片保留位置。
- 点击图号定位并突出右侧图片，返回正文定位原引用；点击图片全屏查看，关闭或 Esc 返回触发控件。引用可右键继续现有尺寸与复制操作，图片节点可选中、删除和撤销。
- 图片嵌入模式沿用原位图片排版、拖动与右键操作。切换只更新 NodeView 和布局，不重建编辑器、不装载另一份文档、不写正文、不清除光标、撤销历史或草稿。
- 右侧图片栏有加载失败查看原图入口；图片为空时隐藏空栏，两个模式入口仍可选。窄容器与窄屏将图片栏放在正文下方，保留保存按钮与全部模式入口。
- 保存中与保存失败、版本冲突、退出确认继续使用原有保护。偏好写入失败保留当前显示并提示再次切换重试。
- 仅浏览器视图与偏好变化，无 HTTP / MCP / CLI、数据库或部署契约变化。
