# Phase 1：可配置的每日通知提醒

对应任务：`t1788149102954`。决策见 [ADR-175](../adr/175-daily-reminders-reuse-automation.md)。

## 用户链路

1. 「设置 → 通知设置」增加“系统 · 每日提醒”，集中展示提醒时间、标题、正文、启停状态和最近一次真实运行结果。
2. 管理员可新增、编辑、暂停、删除和试发提醒；普通成员可查看真实配置但不能修改。
3. 系统预置上海时间每天 08:50 打卡、12:00 午餐、12:30 午休和 18:00 休息与打卡四条提醒。
4. 保存时间后立即重算下一次计划点；“试发”明确调用真实飞书执行器，配置或发送失败时保留失败原因，不显示伪成功。

## 数据与发送边界

- 每日提醒复用 `automation_job`、真实 Cron 调度和 `feishu-notification` 执行器，不再创建第二套定时表或轮询器。
- 提醒发送到“飞书群聊同步”中已选择的真实群；缺少应用凭据或目标群时运行明确失败，不回落到演示消息或普通 Webhook。
- 自动触发和试发都继续叠加群通知总开关、`reminders` 事件开关与每日沉默时段；命中门禁时记录为“已跳过”。
- 本页只维护每日固定时刻的提醒；复杂周期和有独立业务数据源的通知继续由各自自动化配置负责。

## 状态与验收

- 页面覆盖加载、空数据、未保存草稿、保存中、已保存、失败重试和离开防丢；窄屏下每条提醒改为纵向布局。
- 后端测试覆盖四条 migration 种子、每日 Cron 转换、管理员权限、字段校验、启停和误操作非提醒任务保护。
- 前端测试覆盖真实列表、编辑保存、新增失败保留草稿、暂停和试发前必须先保存。
- 生产部署后从通知设置核对四条提醒及其启用状态；不为验收主动试发，避免向真实群发送额外消息。
