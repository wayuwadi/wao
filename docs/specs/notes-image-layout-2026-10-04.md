# 小记图片排版与右键操作

按用户确认的交互 Demo 扩展 ADR-198、`editor-legacy-block-images.md` 和图片尺寸规格。

- 小记相邻图片按容器宽度并排，空间不足自然换行；Enter 在选中图片后插入空段落，明确分行。原有块图片结构不迁移；尺寸和换行仍保存到版本 1 JSON，既有 Markdown 尺寸元数据保持兼容。
- 编辑器内部拖动图片使用 ProseMirror 的移动语义，不将内部拖动当作外部图片上传或复制。外部文件拖入仍正常上传。
- 左键只选中图片；悬停、键盘聚焦和触摸入口可全屏查看。右键打开统一菜单，包含全屏、宽度百分比、宽/高 1–4000px 自定义、统一高度、应用到本篇全部图片、分行/接续、复制图片及复制图片链接。
- 百分比宽度配自动高度；固定高度配自动或像素宽度。统一高度将本篇图片设为自动宽度和相同像素高度。固定宽高完整显示原图，不裁切、不改变源文件；窄屏图片区域最多占可用宽度。
- 批量尺寸更改在一次编辑器事务中完成，可一次撤销；仅更新 width/height，不改变 URL、顺序、说明、缩进或已有正文。仍走小记草稿、显式保存和版本冲突保护。
- 小记菜单不提供旋转，不重新上传或生成图片。其他文档编辑器沿用现有菜单，本次不扩大操作范围。
- 不新增接口、服务、MCP、CLI、数据表或权限；使用现有安全尺寸属性及保存链路。

验收：两张图片并排/Enter 分行、拖动后的数量和顺序、右键与悬停全屏、单张及全篇百分比/像素/统一高度、一次撤销、保存刷新、窄屏、上传失败与草稿保护。
