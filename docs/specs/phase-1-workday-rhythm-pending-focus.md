# 今日重点接续未完成事项

今日节奏在「今日重点」卡内先展示「往日未完成」，再保留今日计划编辑区。按上海自然日从本人持久化日存档读取今日之前非空且未完成的重点，标明昨日或原日期。已完成项不带入；几天没打开、跨月、跨年仍能找到原未完成事项。空结果不占空间，损坏存档明确提示数量，不伪造空成功。

本规格补充既有今日重点执行闭环：历史重点引用原日期和原数组位置，不自动复制、覆盖或占用今日最多 20 项计划；同名但来源不同的真实事项保持独立。今日草稿、提前填写的计划及精力补给记录不会被历史列表的加载或刷新覆盖。

用户可以在列表中直接完成历史重点，更新原存档的 `focusCompleted`，刷新或第二天不再重复出现；当前会话保留已完成行供撤销误点。提交保存前显示保存中；失败保留原状态、错误与重试入口。撤销失败重试仍执行撤销。原文本变化或并发改写原存档时拒绝覆盖，提示刷新。

沿用原始日存档，无数据库迁移；旧存档缺失 `focusCompleted` 按未完成处理。接口只使用登录成员，不接受前端成员 id，不触发通知、不改变原日期归属。

验收覆盖：昨天部分完成、全部完成、旧版存档、跨年及间隔数日、同名事项、空数据、损坏记录、完成后回读及撤销、并发冲突、失败重试、账号与跨日迟到响应、今日草稿不受影响。滚动在重点卡内进行，窄屏完整显示长标题。
