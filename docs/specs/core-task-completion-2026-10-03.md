# 项目、待办与日历一致的收尾判定

沿用 [项目收尾规格](project-task-completion-2026-10-03.md)：任务主状态已完成且全部层级的内嵌 `subs.done=true` 才收尾；`parentTaskId` 关联的独立任务按自己的状态/清单判断，不级联改写父子状态。待验证未收尾。

待办列表和四象限隐藏已完成时仍保留有未收尾子项的主任务；看板保持真实已完成列，只收起已收尾卡片。标题旁明确标示剩余子项，并沿用打开和重新打开入口。列表和四象限保留原完成缓冲、失败保存和个人排序。

日历沿用既有完成开关默认值、日期/成员范围和事件入口；隐藏已完成只隐藏已收尾实体，主完成但子项未完的任务保持可见，事件文本包含未收尾子项数。安排与截止字段不在本需求修改。

仅调整浏览器展示，不新增 API、MCP/CLI、迁移或状态写入。回归覆盖未完成、待验证、全部收尾、已完成但有多层未收尾项、重新打开、按成员/项目筛选和完成缓冲。
