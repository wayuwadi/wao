# 小记润色直接生效（2026-10-11）

用户要求取消小记的建议确认流程，所有小记润色完成后直接使用润色结果。本规格取代 `notes-ai-companion-2026-10-05.md` 中的 AUTO / REVIEW 选择、人工采用 / 恢复 / 拒绝入口及复杂富文本转为建议的规则；其私有来源、取消、版本和草稿保护仍适用。

## 正文与交互

- 小记列表不显示「待确认 N 项建议」，也不为该提示读取私人成果列表与回执。
- 伴读设置不再提供采用方式选择，成果历史只供阅读对照、复制和重新整理，不提供人工采用、恢复、拒绝或把结果送入编辑草稿的入口。
- 已启用的自动润色和明确发起的手动润色均在后台成功后直接写回当前正文，无需再点击确认。润色执行状态、停止和失败重试继续保留。
- 原稿快照保持不可变；正在编辑但尚未保存的浏览器草稿不得被后台结果覆盖。

## 完整采用与保护

单纯段落替换仍保留原富文本节点属性。输出改变段落数量、标题、列表、加粗等结构时，完整持久化润色后的 Markdown，由既有编辑器解析，不再因为无法一一映射原节点而创建建议。数字表达不因字面格式变化而进入人工审核；模型提示继续要求保留事实、数字与原意。

原有图片、链接和附件引用必须保留，当前仍存在的总览图继续保留；模型丢失引用时记录真实失败并提供重试，不部分写回，也不创建待确认建议。书摘保护继续生效。

写回仍检查当前来源正文指纹、文档版本、阶段取消标记、自动开关与启用轮次。过期结果不覆盖用户后来保存的正文，手写标题继续受到保护；自动结果不触发新一轮自动润色。

## 既有结果接续

调度器接续当前保存轮次、各阶段最新一次、状态 DONE 且原因为 READY / REVIEW_REQUIRED 的已完成结果。复用原持久任务的输出，不重新提交模型。不接续历史轮次、旧尝试、删除或归档的小记。

接续同样执行来源、资源、取消和设置检查：有效结果直接写回；过期、关闭、取消或失败按现有终态记录，不覆盖新正文。接续异常必须进入失败 / 状态不可用路径，不能无限留在待确认状态。

历史原稿关联缺失时，沿用 `freezeAttempt` 从该持久尝试的原始 `source_json` 与精确 `input_text` 幂等补齐；已有原稿绝不覆盖。来源数据无效则保留失败，不用完成时的最新正文冒充原稿。

## 兼容与授权

成果采用偏好读取统一返回 AUTO；旧 REVIEW 行和旧排队快照不再阻止直接写回。偏好写入只接受 AUTO，保留既有版本条件；REVIEW 返回明确错误。旧成果 action API 保留私有会话鉴权与 CAS 兼容，不作为浏览器产品入口，不扩大旧工作区令牌权限。

此次没有数据库结构变化，不新增 migration。Workspace MCP / CLI 没有私人 AI 成果和模型执行权限，既有小记创建 / 更新工具不变；以后若开放独立终端 AI 能力须重新设计授权。

## 验收

覆盖富文本结构变化完整写回、资源缺失失败、旧 REVIEW 快照直接生效、历史结果复用且模型不重复提交、来源更新不覆盖、当前轮次和最新尝试筛选，以及列表无待确认入口、历史无人工操作、草稿保护。
