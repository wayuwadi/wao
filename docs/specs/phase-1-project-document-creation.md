# 规格：项目内创建文档

对应任务：`t1786938519344`（项目里面现在不能创建文档）。

## 目标

- 项目详情的「文档」页签提供真实的新建入口，不再显示演示提示。
- 新建文档必须写入知识库与文档后端，成功后直接进入可编辑文档；服务端失败时不得生成仅存在于浏览器内存的假文档。

## 项目知识库

- 延续“新建项目不自动生成知识库”的既有规则；只有用户在项目中首次点击「新建文档」时，才显式创建并关联一个项目知识库。
- 项目已有知识库时直接复用其第一个文件夹；知识库没有文件夹时补建「文档」文件夹。
- 项目知识库中新建的文档自动带项目出链，项目页同时汇总项目详情已有文档、关联知识库中的文档和显式带项目出链的文档。

## 状态与失败处理

- 请求进行中禁用入口并显示「创建中…」，避免重复点击创建多个知识库或文档。
- 任一步骤失败都停留在项目页，显示明确错误与「重试创建」入口；已经成功创建的项目知识库在重试时复用。
- 没有文档时展示真实空状态，说明首次创建会建立项目知识库，不使用演示数据填充。

## 验收

- 无关联知识库的项目首次创建：产生一个关联项目的知识库和一篇空文档，并进入标题可编辑的文档页。
- 已有关联知识库的项目创建：复用既有知识库，不重复建库。
- 后端创建失败：不进入文档页、不留下本地假文档，可从原处重试。
