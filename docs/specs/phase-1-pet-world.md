# 张三丰小世界：松风庭院

本次交付为单人可玩原型。入口在网页宠物快捷菜单，地址 `/pet-world`，沿用 WAO 登录和页签。

## 用户行为

- 初次进入显示庭院和操作提示；点击场景后 WASD / 方向键按镜头方向行走，Shift 加速，空格跳跃，E 招手。
- 鼠标拖动旋转镜头，滚轮缩放。触屏提供四向移动、跳跃、招手；松手、失焦或离开页面立即停止。
- 场景包括山门、太极台、听雨亭和荷池。角色不能穿过建筑、荷池或场地边界，斜向移动速度与直向一致。
- 张三丰行走时连续播放步行动作，停止后按镜头显示对应方向，招手和跳跃使用原宠物动作。
- 小地图展示真实角色位置和地标；回到太极台按钮可恢复出生点。位置在停止移动、重置、页面隐藏和退出时保存；刷新可恢复。存储损坏回到出生点，存储不可用明确提示并可重试。
- 加载中、图片加载失败、WebGL 不可用或上下文丢失均有可见提示和重新进入按钮，页面导航仍可用。

## 验收

验证移动、斜向归一化、碰撞滑动、边界、跳跃落地、朝向、恢复非法存档；实际浏览器操作进入、移动、跳跃、旋转、刷新恢复和退出。窄屏控制不遮挡角色和关键操作，场景失焦不吞键盘输入。
