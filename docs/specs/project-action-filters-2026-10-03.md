# 项目需要处理事项快捷筛选

沿用已确认的任务优先工具栏，在查找与人员筛选之下增加一行紧凑快捷条件：全部、待验证、等待反馈、逾期。单选条件与负责人、创建人、关键词以交集组合；再次点击已选条件或“全部”仅清除快捷条件。搜索结果的“清除筛选”清除快捷及人员条件，保留关键词。

计数单位为任务实体，不加总内嵌清单：待验证指主任务待验证或任一未完成清单子项待验证；等待反馈指未收尾任务的既有 waiting 文本非空；逾期指未收尾且主任务截止早于今天。主完成而子项待验证仍可命中；不推断验收负责人，因此不用“待我验证”。独立 parentTaskId 任务仍各计一次。

快捷按钮数字始终为项目总计，不随人员和关键词变化；旁边明确“项目计数”。筛选提示统计实际交集，搜索结果另外显示命中数量与被筛选排除数量。未加载/失败不显示伪零计数，沿用原读取状态与重试。空结果不表示项目没有任务。

不写任务、不改变状态、共享顺序或个人排序。清除条件沿用已有表格排序及展开偏好，不改表格默认视图或显示设置；不恢复项目总览、人工项目状态、表格批量选择或项目AI Run。无新API、MCP、CLI及迁移。
