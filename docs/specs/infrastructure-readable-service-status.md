# 基础设施服务状态可理解性与窄屏浏览

补充基础设施关注摘要的只读展示，不改变采集、服务状态筛选、权限或任何运维动作。

- 已知容器和系统服务状态增加中文解释，例如 created 显示“已创建，尚未启动”，exited 显示“已退出”。原始 state/status 保留在旁边，便于核对。
- running 只表示“运行中”，active 表示“已激活”，不得由此声称应用健康或可用；已有 unhealthy 证据单独提示健康检查异常。
- 未识别的状态如实标明未知并保留原文，不推断成功或失败。颜色沿用待核对服务的现有判断。
- 表格列不完整时提供横向浏览说明。滚动区域可以键盘聚焦、有明确名称和可见焦点，可用左右方向键查看其余列。
- 手机页面本身无横向溢出；仅表格内部横向滚动，不隐藏状态或资源信息。

验收：已创建、退出、运行且健康异常、未知状态的解释；原始状态可追溯；390px 下从核对入口到筛选结果、键盘与横向滚动查看状态和资源列。
