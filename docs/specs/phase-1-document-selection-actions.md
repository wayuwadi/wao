# 规格：文档划词图标工具栏与待办收集

## 用户结果

- 编辑文档选中文字时，只显示一条横向图标工具栏：添加到待办、润色、添加或维护链接、文字格式。按钮不显示常驻文字，悬停显示功能说明，并提供辅助技术可读的名称；表格和代码块操作也在同一行按上下文显示。
- 图片尺寸工具与文字工具栏互斥；划词工具栏位于吸附工具栏上方，窄屏时保持在视口内且可横向滚动，不折行、不再展开竖向格式列表。点击外部或取消选区后关闭。
- 图片尺寸工具仅在用户直接点击图片或用方向键选中图片后显示；编辑器挂载、自动聚焦或恢复选区本身不弹出图片工具。
- “添加到待办”打开现有新建任务表单：选中文字预填标题，完整文字与来源文档地址写入描述，原文不删除、不改写。长文本标题取前 200 字，完整文字保留在描述。
- 来源文档同时保存到任务已有的关联文档字段，可从任务附件区直接返回原文，避免紧凑描述编辑器中的链接编辑行为影响回查。
- 文档所在知识库的真实 `project` 为默认项目；可手动改选。未绑定项目或绑定项目不可用时，明确提示选择项目，不自动投到无关项目。
- 待办确认后通过现有任务持久化接口创建；只有服务器确认后提示成功，失败保留表单和重试入口。
- 文档待办草稿按成员、文档和选中文字隔离；同一选区重开恢复草稿，不覆盖普通新建任务或其他选区的未提交草稿。

## 验收

- 普通文字、已有链接、表格内文字、代码块文字均最多显示一条工具栏；单击链接仍能维护，图片操作不与文字操作叠加。
- 格式、链接和润色原有回归通过；只读页面与空白选区不能添加待办。
- 项目文档带入正确项目与选中文字；无项目时要求选择；改变项目后按用户选择提交。
- 创建失败后正文及待办输入不丢，重试不会在当前表单重复创建；刷新后能在目标项目找到待办，描述可回到来源文档。
- 窄屏、靠近顶部的选区、表格与代码场景均无工具栏遮挡；保存文档、切换文档及关闭弹窗无残留浮层。
