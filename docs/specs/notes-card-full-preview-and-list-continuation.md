# 小记全文预览与有序列表续号

本规格调整 `notes-fixed-height-reading-and-ai-settings.md` 中小记卡片固定高度的行为，并扩展 `notes-inline-card-edit.md` 的卡片交互。保留单击不进入编辑、双击原地编辑、Enter 打开沉浸阅读及现有保存和草稿语义；不改接口或数据结构。

## 卡片预览

- 单击卡片空白区域切换全文预览：展开时显示标题和按原位置穿插图片的完整正文，收起后回到固定高度卡片。
- 固定高度卡片始终显示“展开全文”入口；展开后显示“收起全文”，让被收起的正文有明确、可见的继续阅读方式，不依赖悬停或发现卡片空白区域的单击手势。
- 双击卡片空白区域仍进入原地编辑；编辑卡片随内容自然增高，不裁切正文或编辑器。
- 收起预览在正文底部淡出，避免固定高度裁切出半行文字；“展开全文”继续显示完整正文。
- 卡片上的链接、按钮、输入控件和图片操作保持原有行为，不触发预览切换或编辑；选中文本后不因点击而改变阅读状态。
- Enter 继续打开沉浸阅读；完整文档入口使用可辨认为文档的图标。

## 有序列表

- 相邻且编号样式一致的默认有序列表自动合并，后续条目继续前一列表的编号。
- 在默认有序列表前插入新列表项时，新条目从 1 开始，原有条目顺延为 2、3、4；不同编号样式或自定义起始编号不自动合并。

## 验收

- 使用卡片空白区域及常驻的“展开全文 / 收起全文”按钮展开和收起小记，确认控件操作、文本选择、双击编辑和 Enter 阅读仍能区分。
- 展开及编辑中的卡片均完整显示长标题和正文，不受桌面或窄屏固定高度裁切。
- 在编号样式一致的有序列表前插入新列表项，确认原有顺序自动顺延；不同编号样式和自定义起始编号保持独立。
- “完整文档”图标清楚表达文档入口。
