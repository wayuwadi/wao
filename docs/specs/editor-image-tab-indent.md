# 选中图片的 Tab 缩进

2026-10-02 用户反馈：选中图片按 Tab 后图片消失；预期是图片缩进。

- 图片节点选中时 Tab 增加一级缩进，Shift+Tab 减少一级，范围 0–8，每级 24px（实际留白不超过容器宽度的一半）。只更新该图属性，保留 URL、尺寸、标题、前后正文与节点选区；支持撤销、重做。
- 缩进后的图片按剩余可用宽度等比缩小，不造成窄屏横向溢出。恢复至 0 级时沿用原来的对齐设置。
- 文本、列表、表格及代码块原有 Tab 行为保持；其他原子节点不会被制表符替换。
- 按 ADR-198 沿用版本 1 JSON 事实源，image.attrs.indent 仅接受 0–8 整数。Markdown 投影在既有尺寸元数据中扩展可选的 ;indent=N；无尺寸时为 wao-image-size:autoxauto;indent=N。普通 Markdown 阅读与重新编辑均保留该缩进，拒绝非法元数据和任意 style。
- 不新增 API、MCP、CLI 操作或权限；既有文档保存支持该安全排版属性。部署须包含服务端白名单和浏览器改动。

验证命令与人工真实链路见 [图片缩进回归](../runbooks/editor-image-tab-regression.md)。
