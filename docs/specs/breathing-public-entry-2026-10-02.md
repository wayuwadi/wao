# WAO 一呼一吸：公共入口

增补 2026-09-29 登录与首页呼吸规格：统一公共休息空间取代 WOW 登录舞台及工作区内嵌练习；不修改账号权限、后端契约与无注册入口决定。

## 页面与路由

- `/breathe` 是独立公共入口，`/login` 为同组件兼容入口，登录前后均可停留。`/` 继续是受保护工作区，任务、AI Run 查询参数和目标草稿不迁移。未登录受保护访问携带完整内部目标至登录入口；普通首页访问进入静默，不强制弹窗。
- 顶部品牌、全站主题、结束声音与单一认证/工作区操作；中央微光、简短文案；下方呼吸/静坐、1/5/15/30 分钟及自定义。高级场景与节奏收进设置，真实备案位于页尾。角色只在静默时轻量出现，练习时卸载。
- 工作区保留天气、卦象、额度与工作能力，首页和全局工具栏提供“休息一下”。公开页不挂载工作区，不读取目录、任务、AI Run 或额度；仅会话识别与公开备案允许自动请求，认证接口按需调用。

## 练习与偏好

- 首次进入静默、无计时、无自动声音。呼吸与静坐共用绝对截止时刻计时，暂停冻结剩余时间；静坐保持固定光圈、不出现吸呼指令。有效整数时长 1–180 分钟，呼吸吸 2–6 秒、呼 2–8 秒。
- 运行中切换模式先暂停，明确确认结束并切换，取消保留暂停进度；主动结束与自然结束均提供“再待一会儿”“进入工作空间”。离开/刷新结束练习，不持久化普通练习状态，不保证关闭/休眠后的提醒。
- 访客偏好使用 `wao-breathing-guest:v1`；成员沿用 `wao-home-breathing:<memberId>`。登录读取成员偏好，绝不迁移访客设置。当前练习模式、节奏、总量与剩余量独立于偏好；只有主动认证允许保留练习，普通换号终止练习。存储失败提示并保留内存体验。

## 认证衔接

- 复用飞书扫码/授权/容器免登与邮箱登录，统一原生 dialog。打开暂停练习，关闭/失败/成功均不自动继续。邮箱及密码仅本页内存保留，成功清空密码；关闭重开与失败保留草稿。
- 公共空间主动登录留在原空间；结束后选择工作区则成功进入 `/`；受保护深链接成功返回完整原目标。内部跳转拒绝外站、认证循环及无效路径形式。
- 仅在实际飞书页面跳转前，把必要暂停快照与返回目标存入本标签页 sessionStorage，绑定本次 OAuth state，10 分钟有效；回调按 state 校验并一次性取走，后续恢复仅存在内存，恢复为暂停。账号认领沿用同一返回意图。无存储时告知跨页练习无法恢复，邮箱认证仍可保留练习。
- 弹窗按 visualViewport 首帧定位、独立滚动、焦点返回触发点；保持主题、键盘访问、减少动态效果及资源卸载。

## 验收边界

单测覆盖计时、一次性恢复、失效/伪造 state、偏好隔离、认证与深链接路由。浏览器实查访客完整练习、真实认证成功/失败、工作区往返、桌面/窄屏/矮屏/可视视口变化、无私有请求。类型检查、相关 lint、构建和真实服务链路结果另记验证记录；缺项不得宣称通过。单个 PR 本地验收后合并，不跟进 Jenkins。

本次不改变业务 HTTP API、MCP/CLI、数据库或部署拓扑，不扩大令牌能力。

## 视觉修订：黑色基调（2026-10-02）

依据用户对米黄配色和视觉眩晕的反馈，公共入口恢复原登录页的近黑底色 `#090a0c`，搭配灰白文字、低饱和描边及同色系认证弹窗。全站明确选择浅色时使用中性浅灰；全站为“跟随系统”时，此独立休息场景默认呈现夜间，按钮明确标记“默认夜间”。不改写全站或成员已有偏好，工作区仍按全站设置呈现。

减弱大面积背景光晕，取消光圈亮度随呼吸的起伏，光圈伸缩幅度由 26% 降为 10%；静默与静坐保持静止，减少动态效果时关闭伸缩。色温及亮度设置继续生效，计时、认证及偏好隔离规则保持不变。
