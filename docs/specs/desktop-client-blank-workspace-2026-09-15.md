# Windows 客户端工作区白屏闪烁修复

## 用户结果

- Windows 客户端首页加载、未读角标、菜单或轮询状态变化时，工作区保持连续可见，不再周期性白屏后重绘。
- 顶栏的当前功能、菜单、主题和未读数继续实时同步；系统级快捷键配置继续生效。
- 1.1.5 等旧客户端启动后，顶部固定按钮恢复可用；网页内入口继续保留。
- 刷新、隐藏、恢复和异常重试仍保留原 WebView、登录会话及未保存草稿。

## 实现边界

旧版客户端使用被原生层取消的同源顶层导航传递状态，WebView2 在频繁状态变化时仍会短暂清空页面。新版客户端改用受限的文档标题消息，不再触发页面导航。消息只接受两个固定同源路径，顶栏显示值、菜单数量、快捷键动作和组合格式继续沿用既有白名单与长度限制；远程页面仍没有 Tauri 插件或任意原生命令权限。

网页按客户端声明的桥接版本选择消息方式。旧客户端恢复网页内完整入口，并只在页面挂载后发送一次 `ready=1` 导航信号激活顶部固定按钮；它不再监听角标、主题或菜单变化，也不发送快捷键配置导航，因此不会重新引入周期性白屏。升级新版客户端后重新使用单层原生顶栏和完整实时同步。普通浏览器页面不受影响。

## 验收

- Windows 客户端使用真实账号打开首页，等待首页加载完成并持续观察至少两个轮询周期，页面不白屏，顶栏状态可更新。
- 1.1.5 客户端顶部后退、前进、刷新、新建任务和新建小记按钮均可点击，且页面加载后不再反复触发导航。
- 打开小记保留未提交正文，依次隐藏、恢复、切换页面；正文仍在，且没有自动刷新。
- 修改系统级快捷键并触发，窗口恢复到对应功能；非法路径、跨域标题和超长消息不会到达本地外壳。
