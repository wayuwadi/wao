# 规格：文档链接、三级目录、图片尺寸与模板正文维护

对应任务：`t17871887864620` 的「文档功能优化」。本规格在
[知识库文档模板、拖拽整理与写作导航](phase-1-knowledge-document-productivity.md) 基础上扩展编辑能力；
既有文档块与模板快照仍是唯一真实数据源。

## 用户链路

- 知识库文档里的链接带明确链接样式；点击后在新窗口打开，不替换当前正在编辑的文档页面。
- 选中普通文字可以添加链接；点击已有链接返回文档后，可以同时修改显示名称与 URL，也可以移除链接。
  保存后的正文仍是标准 Markdown 链接，不另存一份浏览器映射。
- 右侧目录展示一级、二级、三级标题，逐级缩进；点击与滚动高亮使用同一组标题，四级及以下不进入目录。
- 选中正文图片后，可以选择 `25% / 50% / 75% / 100%`，也可以填写 1–4000 像素的宽、高（至少一项）。
  应用尺寸后可再次点击同一张图重新打开调整框；窄屏按容器宽度等比收住，不把文档撑出横向滚动。
- 模板管理直接展示模板正文。进入编辑后，名称、说明和正文一起提交；保存中禁用重复提交，失败保留输入并可重试，
  删除模板仍不影响已经从模板创建的文档。编辑内容按“当前成员 + 模板”保存在本机草稿；关闭管理器或切换模板只会
  收起编辑，重新进入会恢复草稿。界面始终区分尚未同步、保存中、已保存和保存失败，只有服务端确认成功才清理草稿。

## 数据与安全边界

- 链接只接受 `http(s)`、邮件、电话和站内相对地址；裸域名补全 `https://`。编辑器生成的链接固定带
  `target="_blank"` 与 `rel="noopener noreferrer"`。
- 图片仍由真实图床提供正文。尺寸写入图片 Markdown 的 title 元数据 `wao-image-size:<宽>x<高>`；不新增数据表，
  旧图片没有元数据时按原始大小兼容，普通 Markdown 阅读器仍能显示同一张图片。WAO 公开分享页只把严格符合
  `25/50/75/100%` 或 `1–4000px` 的该元数据转换为固定图片样式；原始任意 `style` 和越界元数据均被净化。
  文档与模板粘贴图片必须先取得真实图床地址；上传失败保留原编辑内容和重试机会，不回退写入 `data:` Base64。
- 模板创建与 PATCH 复用同一组边界；PATCH 的 `null` 字段保持服务端原值。服务端仍按当前登录成员校验模板归属并原子更新现有
  `blocks_json`，不复制成普通文档。名称上限 128 字符、说明上限 512 字符、正文上限 5000 个块且序列化 JSON
  不超过 1000000 字符；从现有文档另存模板时同样检查来源正文快照。控制器校验与服务层写入前校验共同阻止
  无界内容落库。
- 模板 PATCH 必须携带本次编辑基于的 `expectedUpdatedAt`。服务端以 `updated_at` 做条件更新；读取后若已有其他窗口
  先保存，返回 409 且不覆盖。前端继续保留按成员和模板隔离的本机草稿，明确提供“载入服务器版”或确认保留本机
  草稿两种处理；确认保留后重新读取最新版本号，下一次保存仍受同一 CAS 保护。
- 图片尺寸、链接和模板正文都经过现有文档块 JSON 与自动保存链路持久化，不使用 fixtures 或仅内存占位数据。

## 验收

- 点击文档链接会打开新窗口；修改其名称和地址后刷新，显示与跳转地址都保持新值，危险协议不能保存。
- 含一至四级标题的文档，目录只出现前三层；三个目录项均能定位并随正文滚动高亮。
- 一张图分别设置 50% 与 640×480 像素，每次应用后都能点击图片继续调整；刷新和打开公开分享页后样式保持，清除尺寸后恢复原始自适应大小。
- 图床请求失败时正文和模板都不出现 `data:` URL，编辑器保留原内容并允许再次粘贴上传。
- 模板管理能查看真实正文，修改标题、段落、链接或图片后保存；关闭并重新打开仍显示服务端返回的新内容，
  新建文档选择该模板时复制更新后的正文。保存失败时编辑内容和本机草稿都保留并显示重试入口；关闭后重进可恢复，
  且不同成员、不同模板之间不会串用草稿。两个窗口基于同一版本编辑时，后保存者收到冲突而不是静默覆盖；处理冲突
  期间本机草稿不丢失。
