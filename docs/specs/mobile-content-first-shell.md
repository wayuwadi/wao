- 菜单支持关闭按钮、遮罩和 Esc，打开时聚焦关闭按钮，Tab 在面板内循环。关闭后焦点回“更多”；导航、打开搜索或编辑入口时自动收起菜单。
- 正文、底栏与悬浮新建在菜单打开时不可误触；底部导航、内容余量和悬浮新建继续避让安全区。
