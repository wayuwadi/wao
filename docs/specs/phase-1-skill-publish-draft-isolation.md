# Skill 发布草稿隔离与目标提示

- “发布新 Skill”只能创建新的 Skill；历史本机草稿不能决定服务器上传目标。仅 URL 中明确选择的 `skillId` 可用于上传新版本，并校验它属于当前发布者。
- 草稿按公开发布者和新建/具体 Skill 分开保存。旧缓存只有目标一致才恢复，原缓存保留；新文件仍经预检后填入标题、描述与建议 slug。
- 更新页明确展示原 Skill 名称、slug 和已有版本，提供“发布新 Skill”入口；当前页切换目标会清除旧文件及预检状态，迟到响应不能覆盖新目标。
- 同一个 Skill 的已有版本保持不可变；提交前提示具体冲突及处理入口，不把新 Skill 默认为旧 Skill 的升级。
- 写入失败保留文件与表单供重试；本机存储失败有明确提示，服务端保存成功不因本机清理异常被误报失败。
