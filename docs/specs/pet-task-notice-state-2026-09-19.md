# 宠物任务提示与当前状态一致

保留按成员、任务状态去重和八秒收起策略，聊天未读提示仍持续到查看。

- 网页宠物等待当前成员偏好成功读取后才展示任务气泡；读取中或失败不先按默认值打扰用户。
- 关闭任务提示立即清除当前气泡；任务完成、被删除、任务读取失败或成员切换时，不保留过时任务入口。
- 聊天打开或存在聊天未读时优先展示聊天；尚未展示的任务变化不提前记为已提示。
- 页面退出清理提示计时器，重新进入不重播已提示状态。

验收覆盖偏好读取顺序、开关即时生效、任务完成/删除、读取失败、聊天优先和定时器清理；不为测试发送消息或修改真实任务状态。

桌面远程宠物页同样在会话失效、请求失败、成员切换时清除旧任务提示；点击后收起气泡。聊天占用气泡期间不消费任务状态。只复用既有固定原生动作，不修改原生壳、版本号或发布安装包；浏览器/组件验收与 macOS、Windows 原生窗口验收分别记录。
