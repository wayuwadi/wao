# 小记与天人一卦统一设置面板

依据用户确认的 UI 与 ADR-321；视觉规范见 [设置页面规范](../design/settings-ui-pattern.md)。本规格补充既有小记设置与天人配图规格。

小记主页面、文档编辑器和全局设置使用同一 `NoteAiSettingsForm`；卦象使用同一布局和模型组件。左侧选择设置项，顶部显示模型和思考深度，正文只展示当前项；底栏固定保存状态、重新读取与保存操作。客户端草稿按成员隔离并保留原 CAS 版本，关闭、切项和刷新不会丢失；冲突重新读取不会隐式重基，需要明确选择后才能保存。保存失败保留输入。

天人 GET/PUT `/api/tianren/settings` 增加 `model` 与 `reasoningEffort`，使用本机 Codex 动态目录验证组合。历史配置缺少字段时为 `gpt-6-astra` / `medium`；旧 PUT 未传字段时保留当前已保存值。模型目录失效不改变账号选值，保存及执行时不兼容组合返回明确错误。天人设置与小记完全独立，继续使用现有成员偏好 TEXT 和运行档位字段，不新增 migration。

文字解读入队只读取一次完整天人设置，用于提示词、自动配图开关、模型和思考深度快照；文字与自动配图沿用同一快照，设置变化不会影响排队任务。手动配图或重画使用当前天人模型、深度和配图提示词。执行器显式接收天人深度，不读取小记设置。天人状态按当前成员配置返回模型与思考深度。

项目和文件与图床设置复用共享弹窗的标题、内容及固定底栏，短表单使用自适应高度；保留原关闭保存、失败保留及权限规则。已退役 AI Run 不恢复。全局设置普通内容宽度统一为 1000px，成员表格等宽页面保持原有容量。

继续属于成员浏览器私有链路，不向旧工作区 MCP/CLI 令牌增加成员偏好、私有解读或模型目录权限。
