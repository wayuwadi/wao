# 首页记得重要日子

用户确认「伙伴捎话为常态，节气轻旁白，生日有仪式」预览并要求实施。保留原留白、四伙伴、天气衣库、休息和写作入口，不添加常驻通知面板、菜单或声音。

## 日期与来源

- 事实来自当前会话成员的 `family_important_date` 和既有 `HolidayService`，日期以上海时区为准；公历、农历、闰月和年度发生日沿用原匹配规则。往日生日不补播。
- 日历编辑增加 IMPORTANT/BIRTHDAY/ANNIVERSARY 与生日对象 SELF/FAMILY/OTHER；旧行保留通用重要日，不从名称猜测生日身份。不展示年龄、出生年份或私有备注。
- 首页渠道独立于飞书和内部定时通知，不要求绑定飞书。单项首页开关默认开启；提前天数复用原字段，首页在指定提前日和当天各一次，不改变其他渠道投递语义。
- 设置「常用设置 / 外观与陪伴」增加全局开关与节气开关，默认开启。账号配置采用版本条件保存；本机成员隔离草稿在失败和冲突时保留，明确选择账号设置或保留草稿后继续保存。

## 留白与打扰预算

- 数据就绪且没有输入、伙伴活动或浮层时，进入首页约 4–8 秒后出现。每次访问最多一轮，提前准备和当天重要事项优先于生日纪念日、节气；返回重新读取，已展示事项不重复。
- 重要事项在伙伴上方短气泡，节气无边框旁白；生日纪念日局部小蛋糕及随机星点、彩带或烛光。随机不决定事件、日期或优先级，无全屏遮罩和音频。
- 同日多项合成一轮，表达主要两项，其他提示留在日历；每轮最多取得八项，更多仍保留在日历。
- 默认十秒退场；悬停、键盘聚焦、保存中和错误时保持操作。确认、收起、Esc 和其他操作回到留白。安静和减少动态效果保留文字、暂停仪式；后台、编辑、离开视区以及休息/写作过场让位。日期提醒出现时暂停闲聊。
- 「看看日历」定位实际发生日及真实事项/节气详情，已删除明确提示；已有本机草稿不被替换，导航失败可重试。

## 展示与确认

- GET 不写展示或已读。即将显示时按成员、当天、来源、发生日及提前阶段原子取得二十秒租约；未显示离开释放，崩溃后到期可再取。
- DOM 可见后才提交 SHOWN，明确点击确认才写 CONFIRMED；自然退场和 Esc 不冒充确认。刷新、多窗口和设备共享持久化展示记录；幂等回执、过期 token、跨成员和跨日校验。
- 源和开关在租约期间改变时重查，不确认已关闭或删除的事项。回执不完成/删除日历事项，不推进通知中心全局已读水位。记录复用 `member_preference` 的 `home-date:` 键，通用偏好 PUT 禁止覆盖专用状态。
- API 失败保持原首页并延后读取；确认失败留原位重试，不伪称保存。

新增成员浏览器私有 API 与 V187 三项兼容日历字段。显示回执依赖实际浏览器生命周期，当前工作区令牌没有私有生日/渠道设置权限，不新增 MCP/CLI 或扩权。终端管理日历需另行设计授权、版本与私密字段边界。
