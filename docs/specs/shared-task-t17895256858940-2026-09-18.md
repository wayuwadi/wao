# 项目使用体验大调：2026-09-18

来源：分享任务 t17895256858940（项目功能使用优化）当前 6 项未完成清单。一个 PR。

- AI Run 下线：任务 / 项目里的入口全部隐藏（任务弹框 AI run、停止 AI、执行档案，子任务派工，项目批量「给 AI」，状态选项与看板列里的「AI 进行中」），不再轮询运行档案。代码与接口保留，开关为 `wao-web/src/config/features.ts` 的 `AI_RUN_ENABLED`。已处于「AI 进行中」的历史任务仍显示当前状态。首页 AI 控制中心按用户确认不在本次范围。
- 任务详情从右侧抽屉改为居中弹框（参照 ONES）。子任务与主任务同一版式：主区展示标题、大尺寸描述编辑器和下级子任务，右侧为属性；顶栏面包屑按 parentId 展示「项目 › 任务 #n › 子任务 #m › …」的层级，可逐级返回。
- 类型图标：主任务、子任务各一个蓝底白标图标（`WorkItemIcon`），表格、子任务列表、面包屑共用。
- 项目表格参照 ONES：ID、类型图标 + 标题、子任务进度、分组、实心优先级、描边状态胶囊（待办显示为「未开始」）、负责人 / 创建者头像、计划开始、截止日期；子任务行与主任务同列。
- 「显示已完成」改为开关样式：表格工具条统一控制已完成子任务，不再在每个任务下各放一个按钮；详情里的子任务列表头部同样是开关。
- 子任务列表统一样式：小号灰色编号、子任务图标、状态胶囊、负责人与截止日。
- 分组可在表格里查看和修改：工具条「不分组 / 按分组」，按分组时分组头可折叠、改名、快速新建任务、删除分组；每行「分组」列可直接改；拖任务到分组头即移动。偏好按项目记在本机。

未改动后端接口、数据库与 migration。
