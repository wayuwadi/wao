# 工作区 MCP / CLI 日常能力首批补全

2026-10-04 用户确认把小记、标签、任务、子任务、执行安排、文档整理、检索及 CLI 文件输入导出一并纳入首批。此规格扩展 `wao-workspace-mcp.md`，不恢复退役模块。

## 业务范围

- 小记直接创建到当前成员文件夹；标题可选，正文支持文本、blocks 或高级 Markdown / JSON。支持创建时标签和独立标签增删、替换、清空。字典支持读取和幂等新建，不开放全局合并或删除。
- 小记查询默认本人，可按关键字、全部指定标签及真实创建日期筛选。任务查询含历史已完成，支持项目、负责人、状态、截止日期、关键词及分页。未完成包含主任务已完成但子任务尚未收尾。
- 任务支持负责人、参与成员、分组、步骤；子任务支持新增、内容修改、重排、同任务层级及跨任务子树移动。完整任务支持父级调整。关联文档、追加及编辑本人评论复用原业务规则。
- 文档支持高级正文、出链、文件夹与模板，支持归档查询、归档与取消归档。模板限定本人，创建须有真实来源文档，更新须携带模板版本。
- 全文检索覆盖可见任务、当前小记、当前知识文档，返回命中片段及业务链接；不含回收站、归档、私人原稿或 AI 输入。返回有界分页及总数，不能将前 100 条冒充全部。
- CLI 常用命令必须可发现，支持 UTF-8 Markdown 文件 / 标准输入、Markdown 与 JSON 导出、动态工具参数帮助、版本和身份权限诊断。以实时 `tools/list` 判断可用性，兼容旧服务器，不自动重试写入。

## 授权及并发

所有调用重新校验令牌成员、逐项操作快照及项目/知识库范围。新增工具在能力中心明确选择后签发的连接才可使用；旧令牌及既有逐项授权不自动增加新工具。原 `update_document` 的标签、高级正文属于已有文档编辑字段，仍受原操作和知识库范围约束。此处没有新增 AI 执行、私人历史、文件、公开分享、通知发送、管理员或永久删除授权。

每日进展读取及保存属于新个人范围，复用 ADR-322 的逐项授权，不另建整体授权开关。能力中心 → 我的连接 → CLI/MCP，可从旧连接复制授权草稿并选本次新工具，选择「日常完整」后，一次签发完整日常连接。所有新连接的工具清单固定，后续版本不自动扩权；CLI 的诊断列出实际可用工具，未出现时提示服务未提供或连接未授权，不猜测原因。每日读取同样按项目与小记知识库范围过滤事件、内容和统计，不能只过滤列表却泄漏未授权项目数量。

每日工具复用日视图 / 月度摘要、执行安排与日进展原子回执。账号从令牌成员的有效账号记录推导，不接受客户端指定账号。`start`、`start_at`、`end_at`、`schedule_period` 必须全部显式给出（可为 null）；截止保持独立。排程需 `expected_edit_version` 和 UUID 操作号。每日小记需 UUID 操作号、稳定文档 id、真实业务日期，修改既有小记和任务关联分别校验文档及任务版本。MCP 写入阻止自动 AI，不影响私人原稿保存和旧 AI 来源失效。

正文、标签、关联和任务集合编辑必须带读取时的版本，冲突返回明确错误，客户端保留文件或输入，不盲目刷新后覆盖。子任务跨任务移动同时校验两边快照并在原服务事务中完成。标签修改只传元数据，不重写正文。小记稳定 id 为 32 位无横线小写 UUID，创建记录请求摘要，同一成员、id、内容重试返回现有文档；不同内容拒绝且不会覆盖后续编辑。回执不包含私人来源正文；工作区回执仅允许 NOTE/SCHEDULE，不读取同表中的私人每日规则回执。

分页字段为 `offset` / `limit`（1–100），响应为 `items,total,offset,limit,hasMore`。日期 `from/to` 为有效 yyyy-MM-dd，小记按创建日期、任务按截止日期，排程查询使用每日工具。未知字段、错误类型和非法数组拒绝，不静默丢弃。

## 验收

覆盖只读与每日范围拒绝、项目隔离、本人默认筛选、标签保持正文与版本冲突、创建重试不覆盖、文本原样保留、多页结果、完整收尾判定、任务集合 CAS、跨任务移动、截止与安排独立、操作回执、安全 Markdown 导入导出、旧服务器兼容和动态帮助。真实持久化及浏览器回读单独记录，不以替身测试替代。
