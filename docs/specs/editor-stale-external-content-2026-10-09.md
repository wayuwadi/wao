# 编辑器失焦不得回填过期正文

## 已复现问题

共用 MarkdownEditor 在聚焦期间暂存外部 Markdown 和 JSON 正文，失焦后回填。当父页面后来回传与编辑器相同的最新内容时，旧实现直接返回，没有清除原先暂存的旧正文；用户继续输入也没有作废它。随后点击其他控件或切走页面，旧快照覆盖新一行。再次编辑会把被回退的内容作为新输入提交，造成持久化丢失风险。

2026-10-09 对线上静态版本 889f9b29 的相同源码增加回归测试：Markdown 与 JSON 两条路径都失败，实际编辑器正文变成旧快照，新一行消失。这证明代码缺陷；具体用户内容的历史丢失原因仍需文档身份、时间和保存记录确认，不能据此断言数据库损坏或已恢复缺失内容。

## 行为要求

- 每次用户正文更新先作废两种待回填快照，再发出最新内容。
- 外部值与当前正文相等时也取消此前暂存的旧值；JSON 值清空时取消旧 JSON 回填。
- 失焦仅回填仍对应当前 props 的外部值。
- 聚焦期间收到真实外部更新且没有后续本地修改时，仍在失焦后应用更新。
- 不改变保存 API、服务器版本冲突处理、草稿存储和用户原文；不自动恢复或覆盖真实业务记录。

## 验证边界

回归覆盖旧 Markdown、旧 JSON、最新值确认、无父页面回传的继续输入，以及既有正常外部同步。草稿恢复与保存期间继续输入测试另行执行。服务器健康接口不替代已登录保存、刷新和切回验收；记录阻塞而不把单测称为生产数据恢复。
