# Phase 1：本机摄像头与麦克风接入

对应任务：`t1788149448670`（终端设备接入）。

## 用户结果

- WAO 登录成员可从「工具 → 终端设备」进入设备页，查看当前浏览器实际枚举到的摄像头和麦克风。
- 选择摄像头后可在页面实时预览；选择麦克风后可观察实时输入电平，从而判断设备、浏览器权限与链路是否可用。
- 页面明确说明设备只在当前浏览器会话中使用，音视频不上传、不保存，也不把未接入服务端的本机硬件伪装成跨设备资产。

## 数据与权限边界

- 设备清单、媒体流和轨道参数只来自浏览器标准 `MediaDevices` / `MediaStream` API，不增加演示设备或静态状态。
- 首次进入只枚举浏览器可见设备；只有成员点击「开启预览」或「开始测试」时才申请对应权限。
- 浏览器拒绝权限、不支持媒体设备、安全上下文不满足、设备被占用或设备中途拔出时，页面展示可执行的错误提示并允许重新检测或重试。
- 页面卸载、停止调试或切换设备时立即停止对应媒体轨道并关闭音频分析上下文；本期不上传、不录制、不持久化音视频。
- 本期不包含网络摄像头、远程麦克风、设备账号、服务端设备绑定或远程控制；这些能力缺少统一协议、身份认证和可靠数据源，后续接入具体硬件时另立规格。

## 导航与兼容

- 新增稳定模块 id `devices`、受保护路由 `/devices`、WAO 页签、工作台目录项和内置菜单注册项。
- 内置菜单注册表升级到 V32。读取旧注册表时补入默认可见的「终端设备」，保留成员对其它菜单的改名、分组、排序、显隐、停靠与打开方式定制。

## 验收

- 有摄像头和麦克风的 HTTPS 浏览器进入 `/devices`，能看到真实设备数量；授权后可看到摄像头实时画面和麦克风输入电平。
- 拒绝摄像头或麦克风权限后，对应卡片显示权限恢复说明，另一种设备仍可独立调试；再次授权后可重试。
- 点击停止、切换设备或离开页面后，浏览器的摄像头/麦克风占用标识消失。
- 无设备、不支持媒体 API 或设备枚举失败时显示真实空状态/错误状态，不展示虚构设备。
