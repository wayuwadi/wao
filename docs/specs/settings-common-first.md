# 设置页：常用优先与左右分类

2026-10-04，按用户确认的第一版交互 Demo 实施：桌面保留左侧紧凑分类，右侧只展示当前配置；首次进入默认「常用设置」。本规格补充 settings-adaptive-space，并更新内嵌通知设置的内容分组，已有权限与接口保持原行为。

## 用户路径

- 左侧依次为常用设置、外观与陪伴、小记与 AI、通知与提醒、个人与账号；更多区为管理与连接。按最新 ADR-319 已下线版本与更新，不新增关于页面。
- 常用设置直接提供主题、安静陪伴与庆祝动画，另有小记和通知快捷入口。主题沿用本浏览器偏好，安静陪伴仅本次会话生效，庆祝动画仍按当前成员保存。
- 外观与陪伴保留伙伴入口，将控件风格、每周起始日及快捷键收进「更多外观设置」。
- 小记与 AI 保留最新版本的自动整理、模型、思考深度、提示词、并发设置和顺手发现。模型及执行细节默认收起；编辑中的未保存提醒独立展开、独立保存，不与 AI 或发现设置互相代存。
- 通知与提醒先选择站内与共享通知、项目通知或天人提醒，再进入原有真实面板。个人与账号收纳资料、登录和我的导航；管理与连接收纳组织、AI 账号、Webhook 和网站信息。编辑权限仍由原面板和后端确定，已退役设置不恢复。
- 详情页提供返回所属分类，左侧分类始终保持选中。窄屏分类换行，正文单列，不要求横向滚动寻找分类。

## 兼容与保存

旧 `tab=members/site/navigation/ai-accounts/webhook/profile/account/pet` 继续打开原面板，`quick-links` 映射我的导航，`prefs` 映射外观与陪伴。旧 `tab=notifications` 直接打开通知策略；带 `#tianren-notifications` 时打开天人提醒。新版通知分类入口为 `tab=reminders`，已有天人入口使用 `tab=tianren-notifications`。已退役的 `network-outage/version/wao-ai-capabilities` 沿用 ADR-319 回到组织与成员；未知页签回到常用设置。

继续由当前面板检查离开确认，进入恢复草稿的面板不提前确认。通知策略、天人、伙伴、导航、Webhook 的原有保护保留。小记 AI 沿用已有内存草稿；顺手发现切换分类时缓存面板并检查离开确认。小记提醒按成员在当前浏览器保留草稿，刷新时恢复；读取干净表单同步新值，读取脏表单保留输入，失败显示原草稿和重试。浏览器存储受限时明确提示，刷新前有防丢确认；保存中阻止离开。退出登录复用同一检查。

不新增后端、HTTP、CLI 或 MCP 能力，不改变配置字段或自动化触发语义。

2026-10-04：管理与连接补回「WAO CLI 与 MCP」入口，`tab=workspace-mcp` 打开既有工作区令牌组件。首页隐藏该组件后曾没有可访问的授权入口；本次只修复页面挂载，不恢复首页模块，不改变令牌权限。

## 本地验收

使用隔离前端 5248 连接既有 18080 服务和真实本机开发会话，未启动新数据库或执行 migration。1912px 常用页与分类详情显示正确；390px 下常用、通知分类和展开小记高级设置均无横向溢出。庆祝动画关闭后刷新保留，随后恢复细腻纸屑；提醒草稿三分钟可重新进入恢复，真实保存、刷新后仍为三分钟，最后恢复原一分钟。旧偏好和天人通知锚点打开对应分类/面板。未修改账号、成员、组织通知或 AI 消费策略。

相关前端测试覆盖分类和旧链接、干净/脏刷新、独立保存、失败重试、提醒恢复、存储受限、保存中离开、原 Webhook/通知/伙伴草稿保护；类型检查及生产构建通过。浏览器原生确认框可触发，但 Edge 自动化在确认框打开时无法执行取消命令，该分支以单元测试验证；不把工具超时声称为浏览器取消成功。
