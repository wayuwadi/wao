# 草图工作区

草图继续使用 Excalidraw、现有 `/api/drawings` 与乐观版本锁。普通入口读取文件摘要，草图与分组按成员保存的手动顺序展示；无保存顺序时按创建先后稳定展示，编辑不会改变位置。每个成员在本机记录上次成功打开的个人草图，再次进入时恢复该文件。显式 `drawing` 链接优先；记录不在当前可访问列表时回到首页，读取失败保留记录及错误。内嵌画板不改写个人入口。首次使用或没有记录时显示首页。列表支持名称搜索、清除搜索和收起。文件名可在标题中直接编辑，128 字上限；知识库关联画板可在此直接改名和编辑，名称与知识库文档在同一事务同步，沿用知识库权限；删除仍在知识库管理。

## 保存与恢复

- 停笔 1.1 秒自动保存，立即保存与 Ctrl/Cmd+S 走同一保存链路。保存期间新增的修改在本次响应后携带新版本继续保存。
- 含内嵌图片的场景读写允许等待 120 秒。连接中断或超时后保留原提交快照，重试先确认该快照，再携带确认的版本保存后续编辑；本机草稿同时记录待确认快照。返回页签或重开草稿时核对已提交内容，避免把自己的保存误判为并发修改；真实冲突继续阻止覆盖。
- 切换文件、新建、离开路由和版本更新刷新先完成当前保存。失败或冲突保留画布并阻止直接离开；可重试、下载 `.excalidraw` 备份或明确放弃草稿后读取云端。
- 本机草稿在 IndexedDB 事务完成后才显示“已记录”。按成员和文件隔离；只有读取获授权的个人文件后才迁移无成员信息的旧草稿，知识库关联画板不猜测旧草稿归属。
- 已保存快照清理与草稿写入串行处理，取消旧定时器；新编辑不会被清理中的旧快照覆盖。草稿内容与云端完全相同时沿用云端最新版本号。
- 并发冲突状态独立于绘制事件，继续绘制不会恢复自动覆盖。重新读取云端失败时保留本机内容，成功后才清理草稿。
- 删除成功后才清除当前编辑状态，失败保留内容。恢复版本和删除过程中阻止继续绘制及切换，避免旧响应覆盖另一个文件。
- 列表、文件、历史版本及画布模块的读取失败各自提供恢复入口；读取失败不显示为空列表。保留现有最近三个版本策略。

## 界面与验证

复用 WaoButton 和主题 token；标题、正文、说明采用界面字号规范。草图工作区与知识库一样紧贴全局导航，不套用通用页面外边距；左侧紧凑单行仅显示文件名，编辑时间、重命名和个人草图删除位于右侧顶部版本入口左边，支持键盘。手机文件列表采用遮罩，选择成功后收起，保存状态仍显示文字；触屏操作至少 44px。

正文的斜线画板选择器默认以紧凑行展示最近编辑的五个画板，搜索可找到更早的画板；新建并插入按钮固定在弹窗底部，列表较长或读取失败时仍可见。使用共享弹窗和按钮，保留列表加载、失败重试与新建失败重试。

回归覆盖保存期间编辑和切换、保存失败、刷新拒绝、冲突继续绘制、删除失败、草稿清理定时器、读取失败、账号隔离与旧草稿迁移。浏览器验收应验证真实新建、绘制、自动保存、刷新恢复、文件搜索和折叠，以及明暗主题和 320/390px 布局。

草图列表的右键菜单和键盘可达的更多按钮提供新建分组、重命名、导出 `.excalidraw` 和复制。分组与归属保存在成员账号下，文件可移动到任一分组或未分组；读取失败显示重试，不把失败当作空分组。导出当前画布包含当前本机内容；复制先完成当前编辑保存，冲突或保存失败阻止复制，成功创建独立个人草图并保留成员的分组。

草图可拖入分组、拖动分组或草图排序；右键菜单提供上下移动作为键盘替代，跨设备排序冲突提示重新读取，不覆盖其他设备的顺序。分组上的加号可在该分组原子创建草图。目录宽度可拖拽或用键盘调整，按成员保存在本机。切换页签保留画布实例，切换成员时释放旧实例，返回时后台校验文件和目录，云端无变化不重建画布；发生并发变更时保留未保存内容并提示冲突。

草图目录参照知识库的层级展示：文件相对所属分组缩进一级，并使用画板图标标识；未分组的文件同样缩进在「未分组」下。选中、菜单和拖放区域随文件行缩进。
