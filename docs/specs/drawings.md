# 草图工作区

草图继续使用 Excalidraw、现有 `/api/drawings` 与乐观版本锁。普通入口读取文件摘要，草图与分组按成员保存的手动顺序展示；无保存顺序时按创建先后稳定展示，编辑不会改变位置。每个成员在本机记录上次成功打开的个人草图，再次进入时恢复该文件。显式 `drawing` 链接优先；记录不在当前可访问列表时回到首页，读取失败保留记录及错误。内嵌画板不改写个人入口。首次使用或没有记录时显示首页。列表支持名称搜索、清除搜索和收起。文件名可在标题中直接编辑，128 字上限；知识库关联画板可在此直接改名和编辑，名称与知识库文档在同一事务同步，沿用知识库权限；删除沿用知识库回收站和权限。

## 保存与恢复

- 停笔 1.1 秒自动保存，立即保存与 Ctrl/Cmd+S 走同一保存链路。保存期间新增的修改在本次响应后携带新版本继续保存。
- 含内嵌图片的场景读写允许等待 120 秒。连接中断或超时后保留原提交快照，重试先确认该快照，再携带确认的版本保存后续编辑；本机草稿同时记录待确认快照。返回页签或重开草稿时核对已提交内容，避免把自己的保存误判为并发修改；真实冲突继续阻止覆盖。
- 切换文件、新建、离开路由和版本更新刷新先完成当前保存。失败或冲突保留画布并阻止直接离开；可重试、下载 `.excalidraw` 备份或明确放弃草稿后读取云端。
- 本机草稿在 IndexedDB 事务完成后才显示“已记录”。按成员和文件隔离；只有读取获授权的个人文件后才迁移无成员信息的旧草稿，知识库关联画板不猜测旧草稿归属。
- 已保存快照清理与草稿写入串行处理，取消旧定时器；新编辑不会被清理中的旧快照覆盖。草稿内容与云端完全相同时沿用云端最新版本号。
- 并发冲突状态独立于绘制事件，继续绘制不会恢复自动覆盖。重新读取云端失败时保留本机内容，成功后才清理草稿。
- 删除成功后才清除当前编辑状态，失败保留内容。恢复版本和删除过程中阻止继续绘制及切换，避免旧响应覆盖另一个文件。
- 列表、文件、历史版本及画布模块的读取失败各自提供恢复入口；读取失败不显示为空列表。保留现有最近三个版本策略。

## 界面与验证

已知要打开的文件时，并行加载场景、画布模块与成员本机草稿；目录独立加载，上次打开的个人草图仍须出现在当前目录。切换时先保留原画布并暂时停止编辑，保存与目标读取同时进行，当前修改完成保存后才切换到新画布。读取失败时保留原画布，可重试目标文件。展开版本菜单时才读取历史，菜单展开期间保存后更新列表。

在草图工作区点开目录文件时，上方为每张已打开的草图保留一个页签；再次打开同一文件切回原页签。页签支持横向滚动、方向键浏览、回车激活及 Delete 或关闭按钮；关闭当前页签先完成保存，然后切到相邻页签。浏览器刷新时仍按原规则恢复上次打开的草图。知识库中的内嵌画板使用原有单画布入口。

已打开的场景缓存在当前成员的浏览器页面内。切回时检查云端权限、修订及本机草稿；修订相同且本机有场景时只传输元数据，尚在内存中的编辑器保留缩放和浏览位置。云端修订或本机草稿发生变化时采用最新适用的场景。后台画布停止响应交互；最多驻留 5 个编辑器且按最近使用优先，编辑器对应的场景文本总预算为 24 Mi 个字符。释放后台编辑器后继续缓存场景文本，后台文本总预算为 64 Mi 个字符，超出预算时部分页签再次打开需下载。关闭页签、删除、权限失效、切换账号或关闭草图页时清理相应缓存。

在选择工具中，按住 Command（Windows / Linux 上为 Ctrl）并左键点击元素可逐个加入或移出选区。Shift＋左键和拖拽框选也可多选。

选中单个文字或带文字的形状后，选择「文字高亮」。整块背景会自动使用对比度更高的黑字或白字；在弹窗中选中文字可单独设色或清除选区颜色。预览确认后一次应用，可撤销。样式随原文字元素保存，WAO 画板、分享页和 PNG、JPG、SVG 导出均可显示。`.excalidraw` 源文件保留可编辑文字和 WAO 样式数据，普通 Excalidraw 按原生文字样式渲染。

选中两个以上的独立图形或组合时，画布工具栏显示「列居中」和「行居中」。列居中将选区中心对到同一竖线，行居中对到同一横线。使用画布原生对齐，组合和绑定连线随图形更新，可一次撤销。

草图工具栏可选择「对象吸附」「网格吸附」或「关闭吸附」，默认对象吸附。拖动元素靠近对齐位置或等距位置时，画布显示临时参考线。拖拽途中按住 Command / Ctrl 可临时绕过正在启用的吸附。模式按成员在当前浏览器记忆，切换模式不生成草图版本。

「智能排版」有选区时预览选区，否则预览整张画板。推荐布局以箭头方向组织主流程，有明确成功和失败标注时优先突出正常路径。分支独立排放，回路优先绕行，连线交叉增加或存在新增遮挡时停止应用不安全的结果。可以手动切换「突出主流程」和「按角色或分区排版」，原有的方向布局、树形及下拉菜单中的「轻量整理」「只整理连线」仍可使用。

- 普通矩形可以作为视觉容器。整体排版时，将框与明确属于它的未组合文字和标题一起移动，延续框内出线的原有位置。能明确归属的箭头旁说明随连线移动，遇到多条连线或多个框都可能是归属时保留相关对象。
- 对未套用画框的相连节点，在节点绑定文字首行填「角色：名称」或「泳道：名称」。识别到至少两个角色时，预览生成可编辑的横向泳道，节点在同一流程列中按角色对齐。未标注的节点集中显示，保留跨泳道连线。
- 对用矩形或画框分区的截图链路图，按步骤或阅读顺序重新排图片和说明。编号步骤共用对齐列，密集截图换行成网格，图片在分区内等比例缩放，越出边框但中心仍在分区内的图片纳入排版。文字过宽时按列换行，保留原文；跨区箭头随端点移动，固定连线、锁定内容或无法安全避让的对象保留。选中分区外框可单独整理该区。
- 预览支持整理前后切换、并排对照和放大。图形、文字和原有箭头关系保持，锁定对象、手绘和独立批注保持原位。使用现有画框时先尝试紧凑布局，空间不足时可以预览向右或向下扩展画框。扩展不得新增对邻近对象的遮挡，锁定画框不可扩展。计算在浏览器后台运行，应用前校验场景版本，结果以一次可撤销编辑走现有草稿和自动保存链路。取消预览不生成草图版本。

复用 WaoButton 和主题 token；标题、正文、说明采用界面字号规范。草图工作区与知识库一样紧贴全局导航，不套用通用页面外边距；左侧紧凑单行仅显示文件名，编辑时间、重命名和个人草图删除位于右侧顶部版本入口左边，支持键盘。手机文件列表采用遮罩，选择成功后收起，保存状态仍显示文字；触屏操作至少 44px。

正文的斜线画板选择器默认以紧凑行展示最近编辑的五个画板，搜索可找到更早的画板；新建并插入按钮固定在弹窗底部，列表较长或读取失败时仍可见。使用共享弹窗和按钮，保留列表加载、失败重试与新建失败重试。

回归覆盖保存期间编辑和切换、保存失败、刷新拒绝、冲突继续绘制、删除失败、草稿清理定时器、读取失败、账号隔离与旧草稿迁移。浏览器验收应验证真实新建、绘制、自动保存、刷新恢复、文件搜索和折叠，以及明暗主题和 320/390px 布局。

草图列表的右键菜单和键盘可达的更多按钮提供新建分组、重命名、导出和复制。草图可通过这两个入口删除，确认弹窗显示目标草图名称。独立草图和知识库关联草图确认后均进入回收站，7 天内可恢复。独立草图从列表标题栏「草图回收站」恢复，保留画布、最近三个历史版本和原分组。关联画板从「知识库回收站」恢复。独立草图移入回收站会撤销原公开链接，恢复后可重新分享。分组与归属保存在成员账号下，文件可移动到任一分组或未分组；读取失败显示重试，不把失败当作空分组。草图顶部和目录菜单均可导出 PNG、JPG、SVG 或可编辑的 `.excalidraw` 源文件，默认沿用草图名称。图片包含完整画布内容及画布背景；空画布仍可下载源文件。当前文件使用本机内容，目录中的其他文件使用云端版本。复制先完成当前编辑保存，冲突或保存失败阻止复制，成功创建独立个人草图并保留成员的分组。

草图可拖入分组、拖动分组或草图排序；右键菜单提供上下移动作为键盘替代，跨设备排序冲突提示重新读取，不覆盖其他设备的顺序。分组上的加号可在该分组原子创建草图。目录宽度可拖拽或用键盘调整，按成员保存在本机。切换页签保留画布实例，切换成员时释放旧实例，返回时后台校验文件和目录，云端无变化不重建画布；发生并发变更时保留未保存内容并提示冲突。

草图目录参照知识库的层级展示：文件相对所属分组缩进一级，并使用画板图标标识；未分组的文件同样缩进在「未分组」下。选中、菜单和拖放区域随文件行缩进。

## 拍照转草图

个人草图目录中的「新建草图」和「拍照转草图」在同一行。「拍照转草图」接受一张 10 MB 以内的 JPG、PNG 或 WebP，上传后保存在当前账号的参考图。现有本机 Codex 识别框、文字和连线，并建议语义分区与阅读顺序。前端校验结构和坐标，合并同一区域重叠的同文标签和连线旁重复说明，保留不同节点上的同名业务步骤。按分区排列原生元素，重算连线路径。明确两端的关系绑定原生图形；方向不明时使用无箭头虚线，端点不明时列入待核对。旧识别任务仍可按原始结构打开。

- 并排查看原照片和预览，支持放大、改名或下载可编辑源文件。预览只生成识别任务，确认「保存为新草图」后才写入个人目录和首个版本，现有草图仍走原保存流程。
- `POST /api/drawings/photo-jobs` 接收 `referenceId` 和 `requestId`，`GET /api/drawings/photo-jobs/{id}` 查询当前成员的排队、执行或终态。关闭弹窗后任务继续，同一浏览器页签重开可接续。换照片重新提交，识别失败可重新识别；网络失败可以同请求号继续。
- `POST /api/drawings` 可同时传入可选的 `sceneJson` 和 `requestId`。场景必须为有效的 Excalidraw JSON，同一成员重复提交相同请求号只创建一次。

## AI 整理已有画板

「智能排版」菜单提供「AI 整理」，默认使用当前选区，没有选区时分析全图。发送给本机 Codex 的是可移动布局单元的文字、类型、尺寸、分组和现有连线；图片随所属单元移动，不发送原始图片。AI 建议阅读方向、主线及分区，浏览器校验所有标识，计算位置与绕线。AI 不改写节点文字，也不增删或反转业务连线。

整理前后默认并排对照。受锁定、现有画框或模糊连线约束的对象留在原处；布局会尝试整理独立分区。确认应用时再次核对画布版本，一次撤销可恢复该次排版，取消预览不生成版本。

## 账号素材库

画布「素材库」支持从本机导入 `.excalidrawlib`、收藏选中的图形，也能通过「浏览素材库」从 Excalidraw 官方目录添加。官方目录返回草图后先确认添加，已收藏的相同素材自动去重。素材库和草图文件各自保存，当前登录成员在个人草图和知识库画板中共用自己的素材，切换设备登录同一账号即可取用。删除素材会同步到账号，已放进画布的元素仍是草图内容。素材读取与草图打开并行，连接恢复或回到可见草图时重新同步。同步失败可重试，存在待同步修改时刷新或离开浏览器会提示。

## 分享最新版本

- 独立草图和知识库画板的所有者可在画布工具栏或目录行的更多菜单生成、复制和撤销免登录只读链接。知识库画板也可从知识库目录分享，所有者须仍有该知识库的访问权限。有效期可选 1 小时、1 天、7 天（默认）或长期有效；每张草图最多 20 个有效链接。新的有效链接可从「有效链接」列表再次复制。仅存有摘要的历史链接可继续访问和撤销，原地址无法从服务端找回。
- 同一链接读取原草图最新已保存版本，改名和恢复版本也会同步。查看页支持缩放、平移及浏览器支持时全屏；页面可见时约每 5 秒检查，切回页面立即检查。画布修订变化才传输场景，更新时保留查看位置和缩放。
- 仅分享当前可见图形和被引用的内嵌图片。历史版本、本机草稿、外部嵌入、元素外链和其他文件不在分享范围。每次检查校验链接有效期、撤销状态、当前归属及所有者对关联知识库的访问权限；已打开的页面在检查发现失效时清除画布。独立草图或知识库画板移入回收站时撤销已有链接，恢复后可重新分享。到期清理草图时级联清除链接记录。
- 链接令牌在 URL 片段中，读取接口通过请求头接收。匿名访问使用令牌摘要校验；新链接的原始令牌加密保存，只有草图所有者可以取回，撤销时清除加密副本。响应禁止缓存、收录和来源地址传递。
