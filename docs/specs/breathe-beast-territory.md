# 幻兽领地首发规格

2026-10-03。第四款，前置星野已按PR #1121正式上线并公网核验。沿用A2绿色草甸、俯视区域路线与近景胖绒兽方向；用户已豁免后续Demo确认。仍执行完整本地验收、单独PR、正式发布和公网核验后再进入第五款。

## 玩法与有限内容

选择区域和三兽队伍→在连续分叉节点选择路线/风险/补给→资源、巢穴或短阵容遭遇→捕获/即时孵化→回营培养与进化→利用协同和技能优先级挑战守卫→解锁新区与图鉴目标。玩家主要决定路线、资源分配和阵容，不复制第三款逐人选择回合技能。

四区域：风铃草甸、镜水湿地、暖灰山脊、月苔秘境。每区三段可选探索路线，再进入守卫节点；可主动回营保留已结算收获，重新探索产生可复现的新路线。路线给出风险、消耗、可遇幻兽和地形影响，保守补给与追踪稀有目标有取舍。不会消耗现实等待时间，不付费抽取。稀有遭遇通过追踪进度保证可获得，不依赖无限碰运气。

十二只原创幻兽，攻击/守护/支援/控制各三只，具有独特技能与行为；每只两条可重配培养方向，六种明确进化形态改变技能/特性和轮廓。三只出战，四类双兽协同分别提供恢复、净化、灼烧连锁、控制节奏，实际改变遭遇结果。食物、晶露和进化材料用于可比较的培养选择，最高等级与成长有上限，不用无限数值代替策略。

捕获需要野兽受伤、安抚与合适时机，界面明确显示条件和把握；可以命令队伍留手，避免自动击倒目标。捕获消耗有限诱饵，可通过探索获取；重复幻兽转成明确资源，图鉴首次记录。巢穴获得蛋，完成可见的探索条件或投入资源立即孵化；未满足时可以正常继续探索，没有现实倒计时。

短遭遇采用实时自动阵容战斗，具备可暂停指令：攻击/守护/留手姿态、集火目标、各兽技能优先级、有限队伍主动指令与捕获。技能有冷却和触发条件，玩家能在战斗前及暂停时调整；没有逐人回合按钮。战斗可见攻击连线、命中/护盾/状态、技能与守卫前摇。四位守卫分别考验防御预判、破盾/持续伤害、处理治疗支援、打断蓄力；不能只增加血量。

## 界面和工程

绿色入口替换旧「今天怎么躺」，旧档保持。营地页内含队伍、兽舍、培养/进化、孵化、图鉴、区域路线；当前队伍三兽固定可访问，窄屏用底栏与完整面板替换。原创SVG角色与地形，Vue3/TypeScript/Vite，不新增大依赖。鼠标/触屏点选；战场焦点内Space暂停、1/2/3切姿态、Escape暂停/关闭选择。输入框和页面快捷键不拦截。

独立 `wao-game/games/beasts`，纯规则、内容、存档、渲染、音频、宿主协议分离；只挂载当前游戏。暂停/失焦/后台清理动画计时与音频，明确继续。合成音效默认关闭，交互后解锁。

稳定gameId=beasts、规则v1；保存所有收集/培养/进化/队伍/优先级/蛋/图鉴/区域/任务/纪录及探索节点。**遭遇从本节点开战前状态恢复**，已投入的节点补给和路线固定，未结算战斗不会重复发奖励；捕获/胜负结算立即保存。导出摘要明确恢复位置。沿用本机/本次、单款/全部导入导出、校验/预览/备份/事务冲突，全部记忆扩展四款，不依赖账号。
