# Phase 1：自媒体图文成稿与知识库回流

对应任务：`t1788138321680` 的「自媒体第一篇内容产出《我的WAO》」。本文在
[自媒体自动化 Agent](phase-1-media-automation-agent.md) 与
[知识库文档生产力](phase-1-knowledge-document-productivity.md) 的真实数据边界上补齐首篇图文通路。

## 用户结果

- 内容管理中直接出现首篇《我的 WAO》公众号审核稿；正文只陈述仓库已有的任务、知识、AI Run、热点、成稿、素材与真实平台能力。
- 成稿可预览为带封面和移动端排版的单文件 HTML，可复制 HTML 源码、复制富文本或下载文件；复制与下载始终取当前已保存版本。
- 用户可选择真实知识库和文件夹，把标题与正文块一次写入；成功后可打开知识库文档，失败时保留当前成稿并重试。
- 新建内容入口继续接受用户自己的短描述，并由已配置的真实模型结合账号定位生成初稿；模型未配置时明确降级为手写稿。

## 数据与安全边界

- 首篇内容通过一次 Agent Flyway migration 写入部署时已存在的真实工作区，不伪造热点来源、发布结果或阅读数据；没有工作区时不创建无主数据。
- 封面是概念插画，不冒充产品截图；HTML 使用 WAO 同域公开静态地址，正文与知识库文档不保存 Base64 图片。
- `POST /api/docs` 新增可选 `blocks`，与 `templateId` 互斥；知识库、文件夹、作者校验和正文写入处于同一事务，避免“先建空文档、再补正文”失败后留下半成品。
- 平台没有官方接口或真实授权时仍只提供 HTML 导出与人工发布，不显示虚假发布成功。

## 验收

- 进入「自媒体 Agent → 内容管理」，选择《我的 WAO》后可阅读、编辑并保存；刷新后正文不丢失。
- 点击“预览 / 导出 HTML”，封面、标题、分段与标签在桌面和窄屏均可读；复制 HTML、复制富文本和下载均使用当前服务端已保存内容，存在未保存修改时禁止导出。
- 点击“存入知识库”，选择真实知识库与文件夹后一次创建完整文档；刷新知识库仍能看到标题、段落、列表与提示块。
- 模型未配置、知识库为空、加载失败、保存中、保存失败和成功跳转均有明确反馈与恢复入口。
