# 顶部导航的轻盈单行分区

## 用户结果

顶部页签与右侧任务、小记、动态操作有明确的视觉边界，桌面仍保持原有的一行高度。用户在三个设计演示中确认采用「轻盈单行」；不采用增加顶部高度或将打开的页签移到左侧的方案。

## 行为

- 桌面顶栏维持 52px 高度；正文区不足 900px 时不再自动新增一行页签。手机沿用现有按需打开的导航和工具浮层。
- 页签使用中性浅灰底槽与完整圆角；激活项以品牌色浅底和文字标识，右侧快捷操作以留白和竖向分隔线形成独立区域。
- 任务、小记、动态保留可见名称；侧栏及自定义顶部菜单维持原入口，不把既有功能转移到折叠列表。
- 长标题限制单个页签宽度，以省略号展示，切换按钮的标题提示和无障碍名称保留完整标题。首页继续固定在滚动区外；其余页签可通过滚轮、左右箭头横向浏览。
- 保留页签顺序、拖拽、悬浮、置顶、重命名和关闭行为；容器宽度改变后重新测量左右滚动状态。
- 使用现有主题变量，深色模式保持可辨识的背景和选中层级。

本规格补充 [全局导航单行布局](compact-global-navigation-line.md)，替代正文区不足 900px 时将桌面页签另起一行的布局；不改变 API、数据库或权限。

## 验收

- 本地连接既有业务服务与真实数据，检查知识库、页面切换、任务/小记入口和动态面板。
- 覆盖大量页签、长标题、左右浏览、侧栏折叠、关闭当前页签、拖拽与键盘操作。
- 检查 1920px、1280px、1024px、820px 桌面视口仍为单行，390px/320px 手机无整页横向溢出，深色主题可辨识。
- 运行相关前端回归测试、类型检查和生产构建。
