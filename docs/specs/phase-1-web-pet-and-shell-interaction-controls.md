本规格补充[网页端 WAO AI 宠物](phase-1-web-ai-pet.md)、
[网页宠物今日节奏快捷动作](phase-1-web-ai-pet-rhythm-actions.md)、

## 宠物配置与静默

- “宠物设置”进入 `设置 → 宠物设置` 专用页面，不再跳到“今日节奏”。设置通过成员级偏好
  `web-pet-settings-v1` 持久化，覆盖悬停、左键、右键三种触发方式、任务气泡开关、轮播时间、空闲动作及默认静默时长。
- 三种触发方式可独立选择“快捷操作气泡 / 宠物功能气泡 / 不响应”；默认悬停和左键打开快捷操作，右键打开宠物功能气泡。
- 任务气泡提供关闭入口，可选择 5 分钟、10 分钟或成员配置的自选时长。宠物功能气泡同时提供气泡静音与宠物静默。
- 临时静默是当前浏览器的时效状态，不伪装成跨设备设置。宠物静默后收进屏幕右边缘的小图标，点击立即恢复；到期也自动恢复。
- 快捷操作继续读写真实“今日节奏”配置和当天记录；关闭任务气泡只降噪，不停止任务轮询或改写任务状态。

## 应用壳桌面交互

- 右上角共享聊天在桌面端可从聊天标题栏拖动，位置保存在当前浏览器；按钮、输入框和手机全屏聊天不触发拖动。
- 页签置顶后立即移动到首页与已有置顶页签之后；右键可重命名，并提供“关闭非置顶”。页签栏溢出时鼠标滚轮直接横向浏览。
- 侧栏菜单右键展示“重命名 / 置顶 / 隐藏”完整操作清单，所有变更继续写入统一菜单注册表；保存失败保留菜单与错误重试入口。
- 菜单设置不再要求输入 Remix Icon 字符串。点击当前图标打开可搜索的图标选择器，选择后立即保存统一注册表并同步侧栏与已打开页签。

## AI Run 入口一致性

- 任务详情和项目批量“单独给 AI / 合并给 AI”共同复用 `AiRunLauncher`，统一选择 AI 工具、模型、推理强度、Plan 模式、账号与执行电脑。
- 批量模式只改变任务是否共享运行；用户确认的单次参数原样进入现有 `/api/ai/runs`，服务端允许列表、账号与 Runner 能力校验保持不变。
- 首页一句目标使用独立的自主目标契约，不伪造该接口尚不支持的账号或模型字段；其执行电脑、思考深度和 Plan 选择继续使用真实后台选项。

## 验收

- 从宠物打开专用设置页，修改三种触发与静默时长并保存；刷新后恢复，保存失败时草稿不丢失。
- 关闭气泡、隐藏宠物后分别验证倒计时和手动恢复；任务快捷记录、失败重试与草稿冲突保护不回退。
- 置顶页签自动前移，页签可右键改名和关闭非置顶；大量页签可用滚轮横向浏览。
- 侧栏右键可改名、置顶和隐藏；设置页点击图标完成可视化选择并写透真实菜单注册表。
- 批量派工先出现与任务详情一致的完整配置弹层，选定参数后创建真实独立或合并 AI Run。
