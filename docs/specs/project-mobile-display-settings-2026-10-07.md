# 项目表格窄屏显示设置

关联规格：`project-table-visible-columns-2026-10-06.md`、`member-task-preferences-2026-10-06.md`、`mobile-content-first-shell.md`。

## 问题

390 × 430px 浏览器下，显示设置从工具栏向下展开，面板下半部分超出视口并被底部主导航遮挡。

## 调整

- 760px 及以下采用固定在底部导航上方的设置面板，距两侧 12px；计算底部安全区，限制最大高度，内容在面板内滚动。
- 字段选项、快捷配置和分组控件触控高度至少 44px。保留桌面的锚点面板、点击外部/再次点击关闭及 Esc 关闭行为。
- 不改变字段内容、成员偏好同步、失败重试、表格列宽或横向滚动。

## 验收

检查 320px、390px、短视口和桌面。面板两侧可见，底部位于主导航上方，末尾设置可滚动到达；常用/全部字段刷新恢复，保存失败保留选项并能重试。表格滚动限制在内部，长标题与查看、修改操作可达。
