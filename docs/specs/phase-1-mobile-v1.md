# Android / iOS 日常事务客户端 1.0

- 今日：日期、本人待办数、当天/逾期待办、近期小记；无数据时使用真实空状态。
- TODO：本人/全部可见切换，待办/完成筛选，搜索；新建、编辑标题/正文/优先级/截止日，完成与重新打开。选择真实项目，空项目时引导在 Web 建立项目。
- 日历：月份切换、今天、选择日期、任务数量标记、当日任务与新建；遵守本地日期，不用 UTC 转换导致跨日。
- 小记：本人小记列表、搜索、纯文本新建/编辑，稳定 id 重试，版本冲突保留草稿并可另存副本。既有富文本只读保护，显示完整 Markdown 原文并支持 Web 打开。
- 登录：已有 WAO 邮箱账号，密码不落盘；会话恢复、过期重登、退出。1.0 无注册入口。
- 交互：底部四栏与固定新建入口，44px 触控区、系统安全区、键盘滚动、Android 返回先关编辑器。
- 草稿：按账号＋编辑对象分区，输入即时保存，失败重试、刷新恢复，保存中禁止重复提交；网络不明结果不能自动重放新建任务。
- 发布：main 自动 CI；独立 mobile-v 版本标签触发签名 release，APK/AAB 与校验和、待个人签名的 IPA；签名保密、版本防回退、本地 doctor 和发布脚本。

验收：登录 → 创建任务 → Web 同步 → 编辑/完成 → 日历定位 → 创建小记 → 刷新/断网草稿恢复 → 双端安装/覆盖升级。测试夹具只进入测试，不打入生产数据。
