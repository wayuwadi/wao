# 天人一卦通知顶部收口

- 通知状态与配置通知群入口集中在页面标题右侧，与保存状态同处顶部操作区；未起卦时也保留配置入口。
- 移除正文上方常驻整行通知卡片。默认仅显示飞书发送状态，点击后展开浮层查看目标群、完整说明、刷新及重试操作。
- 失败、待配置或接收结果不确定时在顶部保留醒目状态。折叠不影响现有轮询，UNKNOWN 重试仍须确认群里未收到，已发送不能重复发送。
- 点击外部、关闭按钮或 Escape 可收起详情，切换卦象后自动收起。窄屏顶部换行，详情不挤占正文且不超出屏幕。

验收：桌面与窄屏查看已发送状态、打开和关闭详情、配置入口导航；回归通知读取失败、原群重试确认、切换日期与卸载停止轮询。
