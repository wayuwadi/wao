# Phase 1：工作台直接控制菜单显隐

对应任务：`t1788312586630`。

## 用户结果

1. 登录成员进入「工作台」后，可在每张内置功能卡和接入应用卡上直接显示或隐藏对应菜单，不再必须跳到系统设置。
2. 修改复用全局内置菜单注册表或外部应用注册表，保存成功后侧栏立即更新，刷新及其他设备读取同一真实配置。
3. 隐藏只影响侧栏和停靠区入口，不删除路由、业务数据或工作台卡片；隐藏项仍可从工作台打开并恢复显示。

## 交互与边界

- 卡片主体继续负责打开功能；独立的「显示菜单 / 隐藏菜单」按钮只修改显隐，不得误触发页面跳转。
- 保存期间显示明确进度并避免并发覆盖；成功给出结果提示，失败恢复服务端状态、保留错误原因并允许原地重试。
- 工作台的「小记」「设置」和成员快捷链接不是统一菜单注册表条目，不增加伪显隐开关。
- 桌面和窄屏沿用同一真实注册表和操作，不创建仅在当前浏览器生效的临时配置。

## 验收

- 在工作台搜索一个当前显示的内置功能，点击「隐藏菜单」后仍留在当前工作台，侧栏入口立即消失；刷新后仍为隐藏。
- 对工作台中标记「侧栏已隐藏」的内置功能或接入应用点击「显示菜单」，对应入口立即恢复且可正常打开。
- 模拟保存失败时，界面恢复保存前显隐状态，显示真实错误和「重试」；重试成功后错误消失并更新侧栏。
- 点击卡片主体仍按既有 `TAB / NEW_PAGE` 打开方式导航，显隐按钮不会误打开功能。
