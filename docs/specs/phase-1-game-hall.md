# Phase 1：游戏厅与数字熔炉

架构决策见 [ADR-040](../adr/040-game-hall-server-authoritative-saves.md)。

## 用户故事

1. 登录成员从左侧“工具 → 游戏厅”打开数字熔炉，第一次进入自动得到带两个数字的 4×4 棋盘。
2. 电脑使用方向键或 WASD，手机在棋盘滑动，也可以点击方向按钮；只有实际改变棋盘的方向才算一步。
3. 每一步由服务端合并、计分、生成新数字并立即保存。刷新、换设备或重新登录后恢复同一棋盘。
4. 玩家可以撤销最近一次有效移动；主动新开一局前要确认，已有步数的棋盘进入历史战绩。
5. 页面长期展示最高分、最高数字、累计步数、挑战局数、达成 2048 次数及最近八局。
6. 达成 2048 时触发已有庆祝动画，但允许继续挑战更高数字；棋盘无合法移动时给出本局成绩和重开入口。
7. 从同一个游戏厅切换到“记忆翻牌”，完成八对 WAO 模块图标配对；牌序、翻牌校验、计步、当前牌局和最佳步数都由服务端维护，并可跨设备恢复。

## 验收标准

- 游戏厅默认出现在“工具”分组，且能在“系统设置 → 菜单配置”改名、换组、排序或隐藏。
- 当前存档和战绩按服务端 Session 解析的成员 id 隔离，请求体不能指定玩家。
- 同一存档两个页面并发操作时，过期 `revision` 返回 409；前端重新载入最新存档，不静默覆盖。
- 棋盘必须始终为 16 个空格或 2 的幂；一次移动中一枚数字最多合并一次，合并值累加到分数。
- 加载中、保存中、已保存、读取失败、同步冲突、空历史、达成目标和终局状态都有明确反馈。
- 键盘、触摸滑动、方向按钮、撤销、重开、刷新恢复和历史归档都有自动化测试或真实链路验收证据。
- 记忆翻牌覆盖账号记录加载、空记录、保存中、保存失败重试、并发冲突和完成反馈，不再依赖独立 `/game/` 前端的本机 `localStorage`。
