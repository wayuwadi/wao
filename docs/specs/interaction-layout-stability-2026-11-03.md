# 交互布局稳定性

切换页签、展开菜单和搜索时，触发按钮及弹窗标题应保持原位。内容增减在受视口限制的区域内部滚动，不按每一页内容重新居中。保留原有关闭、草稿、保存失败、账号隔离语义。

## 排查及处理

本次检索全站分项导航、居中弹窗、设置外壳和菜单的条件渲染，重点处理以下同类根因：

| 入口 | 原因 | 处理 |
| --- | --- | --- |
| 任务与子任务属性菜单 | 遮罩插入使 `:first-child` 规则失效，重复属性标题出现并推移字段 | 移除重复标题，沿用公共详情外壳标题；主任务的状态、优先级、负责人和分组复用 `CellMenu`，浮层不参与属性区滚动范围 |
| 清单设置三分项 | 内容高度不同，弹窗重新居中 | 640px 高度并受视口约束；页签和底栏固定，面板独立滚动 |
| 关联知识、任务、文件或 HTML | 切换类型或搜索结果数量改变高度 | 固定选择器高度，列表独立滚动；手机底部面板同样保留高度 |
| 全局功能与内容搜索 | 空结果缩短面板，底部提示跟随移动 | 固定面板，空结果和列表共用剩余高度，输入框及底部提示固定 |
| 文件设置、小记与文档分享设置 | 加载、错误、新增分享地址改变外壳高度 | 固定外壳，动态内容在正文区滚动 |
| 图文复制 | 用途、图文步骤、反馈改变内容高度 | 固定外壳，预览占据剩余高度，低矮视口允许内部滚动 |
| 巡检历史 | 列表、空态与详情高度差异 | 固定外壳，标题与关闭按钮固定，内容独立滚动 |
| 登录方式 | 邮箱、授权和二维码内容长度不同 | 外壳随可视视口限高，方式内容独立滚动，切换入口保留位置 |

已检查的 AI 设置、聊天回顾、通知中心、任务详情、关联文档本身已有固定外壳；项目文件、全局设置、能力与 Skill 详情的分项在页面顶部，不由内容高度驱动弹窗居中。普通确认框和单步骤短表单仍保留紧凑布局。

## 验收

- 桌面及 320/390px 下，反复切换基本信息、成员、更多，标题、页签和底栏坐标不变；方向键切换及草稿保留。
- 任务属性反复开关状态、优先级、负责人、分组菜单，字段不向下偏移。
- 选择器与搜索覆盖多结果、空结果，输入框与完成按钮保持原位，超长列表内部滚动。
- 运行相关组件回归、类型检查、构建、UI 规范检查和 Windows 发布输入测试。几何位置通过真实浏览器测量，不能用 jsdom 的零尺寸当作视觉通过证据。
