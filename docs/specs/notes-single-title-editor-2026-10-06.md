# 小记单标题编辑与更多操作

承接 `notes-inline-card-edit.md`、`notes-quiet-inline-editor.md` 和 `notes-refine-layout-2026-10-06.md`，采用用户确认的交互预览。不修改正文、接口、成员权限或草稿存储结构。

- 卡片进入编辑时，隐藏外层只读标题与阅读操作行；编辑器的可输入标题成为卡片第一行的唯一标题。长标题在输入框内横向浏览，不挤占操作按钮。
- 标题后依次是新增标签与全屏编辑，右侧保留更多入口。全屏切换仍复用当前编辑器实例，标题、正文与标签草稿不丢失。
- 卡片编辑与阅读内编辑的快捷标签移到正文之后、保存栏之前；取消顶部重复选中标签。新增标签输入及失败提示同样位于底部标签区。新建记录的快捷标签仍在顶部。
- 卡片上的分享和置顶统一收进更多菜单。阅读卡片的更多菜单保留既有操作；编辑中的更多菜单只提供复制已保存小记的公开分享链接、置顶或取消置顶，不通过这些操作卸载编辑器或保存当前草稿。
- 更多菜单锚定按钮，首次定位完成后才显示；继续支持键盘、点击外侧及 Escape 收起。置顶保存失败保留原排序和输入。
- 保留显式保存、收起后恢复草稿、失败重试、版本冲突保护、原预览位置恢复和手机触控入口。

验收包含：唯一标题、操作同排、标签位于正文后、分享和置顶收口、置顶失败与未保存草稿、全屏切换与真实富文本保存、窄屏布局。
