# WeKnora 入口与 Linux2 部署

- 新增「WeKnora」菜单，默认位于公共分组、页签模式，支持原有菜单设置。
- 页签展示官方知识库、对话、模型配置界面，带重新加载和新窗口打开操作。
- 加载、服务不可用和首次账号/模型设置提示均明确；WeKnora 账号与 WAO Session 是两层独立认证。
- 登录校验子请求固定接受 JSON，不能继承流式聊天的 `Accept: text/event-stream`，避免认证端点内容协商返回 406 并被 Nginx 转为 500；实际聊天仍保持 SSE 流式传输。
- WeKnora 独立运行于 Linux2，固定 v0.8.0，模型走 API，持久化根目录 `/opt/wao-weknora`。
- 所有外部访问经过 WAO 登录校验。数据库、Redis、解析 gRPC 不发布公网端口。
- 备份保留原始数据和密钥，记录恢复流程；模型 API 缺失不冒充问答验收通过。
