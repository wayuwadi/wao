# 休息旅程视觉打磨

2026-10-05，用户决定逐项落地休息入口与旅程的视觉优化建议。视觉采用柔和的暖阳绘本感，保持现有黑洞过场、呼吸练习和走走行为。

- 休息伙伴统一为有圆润体积、柔光和轻纹理的形态，蓝、黄、绿角色的身形与脸部特征保持可辨。
- 抵达场景以日光、远近缓坡、落脚水色和微风线条构成浅景深；夜间主题仍沿用深色背景与可读文字。
- 黑洞与到达的对白使用柔和浮层，并避开黑洞的视觉中心和伙伴行进路径；抵达的阳光、空气、微风对白与休息页环境保持一致。
- 标题、副文案、伙伴、引导与选项收拢为单一阅读顺序；精简重复提示，让用户在场景中先看见伙伴与当前引导。
- 呼吸与散步选项保留同等选择权，通过不同图标底色、清晰文字层次和轻触反馈帮助识别；首页「休息一下」入口适度突出。
- 中低高度屏幕收紧竖向间距；窄屏、暗色主题、键盘焦点和减少动态效果继续可用。
- CSS 细节包含伙伴体积高光、行走姿态、草地层次和微风轻动；减少动态效果时停用装饰运动。

本次仅调整浏览器 UI 和样式，不修改休息时长、路由、数据、服务端 API、MCP、CLI 或部署拓扑。
