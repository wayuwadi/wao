# 天人一卦设置聚合与解读分层

2026-10-04，用户确认已发布的统一设置风格，并要求天人一卦所有现有配置聚合到同一入口。本规格补充 `unified-ai-settings.md`、`phase-1-tianren-notification-header.md` 与 `tianren-adaptive-space.md`，取代其分散页面入口与正文双栏的布局描述。

## 单一设置入口

页面标题区域只保留「设置」配置按钮与同步状态。沿用约 1000px 面板、分项导航及固定保存栏，设置项为 AI 能力、解读提示词、配图提示词、飞书通知。飞书通知聚合此前系统设置中的通知总开关、卦象开关、目标群、每天 9:00 自动起卦及今日投递状态、刷新与原群重试。

通知页不重复显示模型区；切换设置项保留 AI 与通知的独立草稿。各项沿用真实后端配置和原保存语义：当前通知操作不提交 AI 设置，当前 AI 操作不提交通知设置；关闭与刷新仍可恢复成员隔离的本机草稿，保存错误可重试。原全局设置深链接继续兼容，聚合不增加 API 或权限，也不恢复已退役页面。

行动通知总开关原本同时控制精力补给、今日重点与卦象通知，界面明确说明作用范围；不因聚合静默改变其语义。配置保存不会立即发消息。UNKNOWN 投递状态的重试仍要求用户确认群里没有收到，已发送状态不能重复发送；仅在用户主动点击时发起重试。本地验收不得给真实群发测试消息，也不得修改真实系统连接或通知策略。

## AI 按功能独立

用户明确选择按功能独立：小记使用自己保存的模型和思考深度，标题、正文与配图共用；天人一卦使用自己保存的模型和深度，解读与配图共用。同一功能切换提示词分项后显示同一能力选择属于预期，跨功能不能覆盖。真实目录仅改变当前模型可选的深度列表，不会静默改掉所选深度；不支持原深度时保留选值并要求明确处理。继续沿用 ADR-321 的独立配置、CAS 和任务快照。

## 阅读层次

今日解读上方为三个同级区域：左侧卦象概览、中间配图、右侧关注点，桌面顶部对齐。图片与占位使用 16:9 展示框，保留完整图片，不裁掉图中文字；图片状态、重画与放大查看能力保持。下方单独展示「详细解读」，包含完整文字、内容标注、加载、空状态、读取错误和失败恢复。

历史日期保留概览与已生成配图两栏，不显示当天关注点操作，也不补做历史结果。窄屏改为单列；关注点草稿、起卦幂等、页签切换、流式解读失败恢复和私有图片权限保持原有行为。
