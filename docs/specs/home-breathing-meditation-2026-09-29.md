# 首页呼吸与静默空间

用户于 2026-09-29 确认第二版交互稿并授权开发部署。原型固定链接：https://wao.wayuwa.cn/api/pages/wao-breathing-stardust 。本规格增补并替代首页智能看板的主视觉，不覆盖历史规格。

## 已确认交互

- 首页主区域铺满呼吸画面，默认夜间、余晖光晕、静默状态。全屏按钮将本区域进入浏览器原生全屏；不支持时给出提示。
- 中央光圈只做吸气舒展、呼气回落，不旋转、不追随鼠标。星河默认关闭，可手动显示静态星河；背景文字可隐藏。
- 日间/夜间、余晖光晕/静水地平线/纯净留白三方案、暖金/雾绿/月蓝、亮度均可调整。遵循系统减少动态效果设置。
- 提供 5/15/30 分钟与 1–180 整数分钟自定义。开始后显示剩余时间；暂停同时冻结时间与呼吸相位，继续后接续。默认吸 4 秒、呼 6 秒，无屏息阶段，节奏仅可在静默时调整。
- 到时显示一次结束弹窗，并按用户开关播放轻柔合成提示音。声音在开始的用户手势中解锁；不可用时仍保留文字提示。提供试听和明确标注的 10 秒提醒体验。
- 计时基于绝对时刻，后台回调延迟后按实际剩余时间恢复；页面关闭/离开首页会结束计时。设备休眠、页面关闭和浏览器静音不保证声音提醒，不宣称系统级闹钟能力。
- 默认不自动开始；刷新、重新进入或切换成员均回到静默。设置以 `wao-home-breathing:<memberId>` 存于本机，两个用户不共享偏好，不跨设备同步。存储失败明确提示，本次调整仍可用。

## 原有能力与边界

天气、今日卦象、Codex 额度收于首页信息浮层，沿用真实接口和错误恢复；AI Run 深链和已有目标草稿保留。进入 AI Run 控制台时卸载呼吸区并结束练习。全局导航不变。新增组件与既有首页同属 `home` 功能。

不修改后端、HTTP API、数据库、MCP/CLI、模型或推理设置。没有新增跨成员数据读取。所有动画帧、定时器、观察器、音频和事件监听在卸载时释放。
