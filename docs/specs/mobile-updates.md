# 移动端版本提醒与我的

新增“我的”底部 Tab，展示真实账号、安装版本、手动检查更新入口与退出登录。保留今日、待办、日历、小记、聊天入口。

安装版启动和回到前台读取下载站的 `/downloads/mobile/latest.json`；前台检查间隔至少 6 小时，手动检查不受间隔限制；失败后允许一分钟后的前台切换重试。通过原生 App.getInfo 读取安装版本，仅语义版本更高且对应平台文件有效时弹窗，已是最新、服务异常分别反馈。稍后提醒只抑制相同版本 24 小时；新版本及手动检查不受影响。

弹窗展示当前与最新版本、发布日期和对应平台下载操作。Android 在外部浏览器下载签名 APK；iOS 下载 unsigned IPA 后由用户个人签名安装，不宣称自动安装。严格校验版本、文件名、大小和 SHA-256，下载地址由固定 WAO 域名与有效版本拼接，不接受任意远程跳转地址。检查失败不阻断登录或草稿编辑。

原有 1.0.0 / 1.1.0 安装包没有此功能，需要先手动安装包含本次改动的版本；之后的 CI 发布会自动更新清单，客户端无需修改代码即可提醒。

验收覆盖版本排序、相同或更低版本、损坏清单、重复请求、稍后提醒与手动覆盖、离线失败恢复、窄屏我的及更新弹窗。发布签名 APK 和 unsigned IPA，验证公开文件 SHA-256。实体设备覆盖安装和 iOS 个人签名需实际设备验证。
