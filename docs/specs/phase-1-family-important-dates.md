# 规格：家庭重要日与个人提醒

对应任务：`t1787017505893`（家里人的重要节日需要日历与飞书提醒）。

## 用户结果

- 当前成员可在日历顶部进入“重要日”，新增、修改和删除家人的生日、纪念日等日期。
- 重要日从保存日期的原始年份起，按公历月、日每年出现在 WAO 年、月、周、日视图中；2 月 29 日只在闰年显示。
- 每个重要日可只在日历显示，也可选择当天或提前 0–30 天、指定时刻飞书私聊提醒。
- 飞书未绑定或自建应用未配置时，仍可保存日历事件，但界面和接口明确说明不能开启飞书提醒，不伪装成功。

## 数据与权限边界

- 重要日归当前成员所有，读取、修改和删除均按服务端会话成员隔离；前端传入其他成员 id 不能越权。
- 名称、原始日期、备注、提醒开关、提前天数与时间持久化到 MySQL，不使用原型数据或浏览器存储代替后端事实。
- 浏览器存储只用于尚未保存的表单草稿；保存成功后清理对应草稿。
- 日历日期采用公历确定性展开。当前版本不猜测农历生日；未来需要时应新增明确的历法类型与闰月规则。

## 提醒投递

- 调度按上海时区每分钟扫描到点提醒，并私聊当前账号绑定的飞书身份。
- 每次提醒以“重要日 id + 实际发生日期”唯一；即使提前发送，也用实际发生日期做年度幂等键。
- 多节点争抢由数据库唯一键拦截；失败五分钟后可重试，最多六次，成功后不再重复发送。
- 删除重要日时级联删除其投递记录；修改日期或提前天数后，未来年度按新配置投递。

## 交互状态

- 维护浮层覆盖加载中、空数据、加载失败重试、新增/编辑、保存中、保存失败重试和删除中状态。
- 输入草稿在浮层关闭或网络失败后保留；保存成功才清理。
- 日历翻页请求带序号，后返回的旧日期窗不能覆盖当前视图。
- 点击日历里的家庭重要日可直接打开对应编辑表单。

## 验收

- 新增“妈妈生日”后，无需刷新即可在维护列表与当年日历日期格看到它；切换到下一年仍在相同月日显示。
- 设置提前 3 天 08:30 后，刷新仍保留；到点只向当前成员飞书私聊一次，卡片可回到 WAO 日历。
- 未绑定飞书时可保存关闭提醒的重要日；尝试开启提醒会得到明确错误。
- 修改名称、日期、备注或提醒配置后日历同步更新；删除后列表、日历和后续提醒同时消失。
