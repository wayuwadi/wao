# Phase 1：页签置顶与批量关闭保护

## 用户结果

1. 成员可以从桌面页签的右键菜单置顶或取消置顶任意可关闭页签。
2. 置顶页签显示明确图钉，并在“关闭全部”“关闭其它”“关闭左边”和“关闭右边”时保留。
3. 成员仍可通过页签关闭按钮或“关闭当前”明确关闭置顶页签，不产生无法清理的永久入口。

## 状态与兼容

- 置顶状态和现有页签顺序、激活项一起保存在当前浏览器的 `localStorage`，刷新后恢复；不伪装成跨设备偏好。
- 旧浏览器缓存没有置顶字段时按未置顶读取；首页继续由不可关闭属性固定在最左，不重复提供置顶操作。
- 重新打开已存在的页签只能更新地址和展示信息，不得覆盖成员已经选择的置顶状态。

## 交互与验收

- 右键菜单按当前状态展示“置顶页签”或“取消置顶”，操作后菜单关闭并立即更新图钉。
- 批量关闭移除范围内所有未置顶的可关闭页签；若当前页签被移除，导航到最后一个保留页签。
- 自动测试覆盖置顶切换与刷新恢复、全部关闭保留、其它/左边/右边关闭保留，以及置顶页签单独关闭。
