# 小记视觉细化

用户在四页 Demo 交付后要求开始，先落地小记的操作层次。沿用最新单份正文、左写右读、卡片行内编辑和现有草稿保护。

- 卡片常显“继续编辑”，直接调用既有编辑入口；双击及阅读入口保留。
- 取消卡片悬停位移，操作位置稳定；保留主题色、轻边框和键盘焦点。
- 保存反馈在编辑器底部分隔显示，窄屏先显示状态，再显示操作，保存按钮至少44像素高。
- 窄屏快捷操作保持可见并扩大触控面积，长标题与元信息换行。

API、保存语义、自动整理、权限、存储结构均不变。复用 NotesView 的双草稿/收起恢复测试改走新入口，运行既有回归；真实授权环境核对新入口、输入保存、刷新和390像素。视觉不能代替业务验证。
