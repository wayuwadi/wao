## 人工精选维护（自动记录规则见下）

- `wao-web/src/data/releaseHistory.json` 是经过内容确认的更新档案，包含当前批次；`currentRelease.json` 继续服务现有通知及制品清单。当前对象必须完整出现在档案中，数据回归测试检查一致、唯一 id、倒序及真实功能路由。
- 每次修改当前说明，同时把新批次放到档案最前，保留旧批次，不以新说明覆盖历史条目。文字修正可修正对应记录，但不得把未发布能力写入旧批次。
- 制品构建检查当前说明是否完整归档、批次是否重复；缺失时构建失败，避免发布后才发现更新记录没有保留。
- 历史未完整记录时只显示「已收录」，不声称是所有 Git 提交或完整部署流水。此功能无新 HTTP API、数据库、CLI 或 MCP 能力。

## 自动 Git 记录（ADR-311）

- 顶栏当前说明按实际构建 SHA 自动变化，展示该版本最近五条提交；不再以手工清单 id 作为唯一版本介绍身份。
- 最近更新增加“版本提交记录”，初始 20 条，每次增加 20 条，可查看当前制品可达的全部提交；包含文档与测试，不只展示产品精选。提交标题作为纯文本渲染。
- 读取中、版本不匹配、格式错误与网络失败均明确提示，支持重试；错误不能当空档案或成功。日期为北京时间提交时间，明确不代表部署时间。
- 自动记录由版本清单、页面常量和 `git-history.json` 使用同一构建输入；静态归档进入现有摘要校验与原子发布。失败与回退不会把另一版本记录混入当前页面。
- 原精选档案继续保留，当前介绍自动生成，无需每个 PR 手工改 JSON。交付技能保留可选精选和实际制品校验步骤。
