## 用户结果

- 功能探索保留「全部功能」「本次更新」，增加「回顾最近更新」。原来只展示当前精选的大卡区域改为紧凑时间线。
- 按日期倒序展示批次标题、日期和摘要；同日按清单中的实际先后顺序排列。当前批次标「本次更新」并默认展开，历史批次按需展开具体改动与站内体验入口。
- 首屏 5 批，每次再显示 5 批，直到所有已收录更新均可见。已展开内容不因加载更多被收起；不使用滚动到底自动加载。
- 顶栏更新浮层提供「最近更新」，进入 `/features#recent-updates` 并定位时间线。当前精选弹层、目标版本校验、草稿保存屏障和已读状态保持原逻辑；浏览历史不标记当前批次已读。
- 已经在同一历史锚点、向下滚动后再次点击顶栏入口，也必须重新定位开头并收起浮层，不能仅依赖路由变化触发滚动。

## 数据维护

- `wao-web/src/data/releaseHistory.json` 是经过内容确认的更新档案，包含当前批次；`currentRelease.json` 继续服务现有通知及制品清单。当前对象必须完整出现在档案中，数据回归测试检查一致、唯一 id、倒序及真实功能路由。
- 每次修改当前说明，同时把新批次放到档案最前，保留旧批次，不以新说明覆盖历史条目。文字修正可修正对应记录，但不得把未发布能力写入旧批次。
- 制品构建检查当前说明是否完整归档、批次是否重复；缺失时构建失败，避免发布后才发现更新记录没有保留。
- 历史未完整记录时只显示「已收录」，不声称是所有 Git 提交或完整部署流水。此功能无新 HTTP API、数据库、CLI 或 MCP 能力。
