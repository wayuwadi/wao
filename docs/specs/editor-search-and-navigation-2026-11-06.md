# 文档查找、内容插入与上传定位

知识库、小记和任务详情继续复用 `MarkdownEditor`，不改变 Markdown / JSON 保存协议、草稿隔离或并发检查。

- 文内查找同时标记全部命中，当前命中使用主题强调色；支持前后循环、区分大小写、Enter / Shift+Enter、Esc 返回正文。搜索期间输入焦点保留在查询框，不弹出划词工具条。只读文档可查找，不提供替换。
- 查找按可读文字匹配，跨加粗等内联格式生效；图片、公式等原子节点中断匹配，避免替换误删内容。查询为字面文本，空格和特殊符号不会被解释成正则表达式。UTF-16 位置保持与编辑器一致。
- 单个替换与全部替换都使用纯文本，不解析输入的 HTML；允许空替换。全部替换按同一份正文快照单次遍历受影响文本块，保留节点属性与格式，以一个事务步骤应用并可一次撤销；不对每处命中逐个产生编辑器步骤，也不重复扫描大量内联格式节点。替换前重查最新正文，防止使用过时结果。
- 文档不变时前后导航复用命中缓存；正文修改后合并刷新，未开启查找时不扫描全文。超过 500 处匹配时仅渲染当前位置附近的高亮，全部结果仍参与计数、导航与替换，避免万级装饰节点拖慢输入。查找词上限 1000 字。高亮只属于编辑器装饰，不写入正文或保存历史。
- 斜线菜单与工具栏插入菜单提供同一组内容块；工具栏入口带搜索框。上下方向键、Enter、Esc 可完成选择，中文输入法合成期间不执行命令。菜单标注当前选项，控件有可访问名称、选中状态与触屏点击区域；色彩、字号、浮层使用现有主题变量。
- 图片和附件上传锁定发起时的编辑器，并随编辑事务映射原插入位置。排队中的每个附件在入队时锁定位置，失败重试沿用原锚点；图片和附件混合插入不互相使锚点失效。完成时不抢焦点、不替换用户后来选择的文字；编辑器已卸载、正文已切换、原位置已删除或已变为只读时不插入回执。正文切换清理旧队列，已上传资源仍保留在资源库。失败附件不持续占用“正在上传”状态。
- 图片或附件仍在处理期间暂时禁用“全部替换”，并给出可访问的原因提示，避免整篇批量事务使上传位置失效；查找、命中导航和单个替换仍可使用，上传完成后自动恢复全部替换。
- 宿主可通过 `openSearch()` 打开查找，通过 `hasPendingUploads()` 判断是否有进行中的上传；知识库在上传完成前保留编辑状态，避免阅读切换中断已发起的操作。

设计参考 `/design` 使用共享组件与合成正文演示这些行为。自动化验证覆盖 Unicode、内联原子、纯文本替换、批量撤销、只读切换、输入法、焦点、菜单键盘操作及上传回执隔离。
