# Phase 1：内容创作工作台菜单与真实能力归位

对应任务：`t1787820477577`（新增一个菜单组：内容创作）。

## 用户结果

成员进入 WAO 的「自媒体 Agent」后，从「内容创作」菜单组按创作者日常流程进入账号管理、内容管理、
素材管理、内容创作和内容发布，不再需要猜测“选题中心 / 发布中心”分别包含哪些能力。已有热点、账号画像、
平台授权、文案、素材、视频合成和发布任务继续读取 Agent 后端的真实持久化数据。

## 菜单与能力边界

- 账号管理：维护当前工作区的账号定位，查看平台真实能力并连接或解绑官方授权账号。
- 内容管理：创建平台内容草稿，默认使用 WAO 已启用的推荐模型生成标题、正文、标签和结构，人工修改后保存版本。
- 素材管理：上传图片或视频并查看当前工作区最近的真实素材记录；内容编辑和发布可直接复用已落库素材，
  不插入示例素材，不伪造预览地址。
- 内容创作：从真实热点生成选题建议，采用后带入内容草稿；浏览器视频工作流作为同页的可控创作方式保留。
- 内容发布：选择已有内容、官方授权账号和素材，人工确认后提交平台；任务状态和失败原因来自后端。

小红书、视频号等没有可靠官方内容发布接口的平台继续只支持成稿和人工发布说明，不显示可提交按钮，
不返回伪造的发布成功或效果数据。

## 数据与接口

- 复用 `agent_workspace_profile`、`agent_topic_suggestion`、`agent_publish_task`、`agent_platform_account`、
  `agent_media_asset` 和 `agent_video_project`。Agent Flyway V10 为 `agent_publish_task` 增加生成执行器、固化提示词、
  claim token 和租约字段，不保存模型凭据。
- 新增 `GET /api/agent/publish/media`，按当前 WAO Session 推导工作区，只返回该工作区最近 100 条素材元数据。
- 素材列表与上传响应都包含创建时间，不返回节点名、存储路径或凭据。
- 新增 `POST /api/agent/publish/tasks/{taskId}/retry-generation`，仅允许保留了固化生成请求的失败任务重新入队。
- 既有上传、内容保存、授权和发布接口保持不变，响应继续使用 `ApiResponse<T>`。

## 状态与恢复

- 五个入口分别提供加载、空数据、保存或上传中、成功结果和失败重试；切换内容任务前继续保护未保存编辑。
- 登录会话确认后立即显示完整导航；账号定位或热点等工作台数据加载失败时，只在当前页面显示原因与重试，不隐藏菜单或阻断其他能力。
- 内容管理的编辑器只负责草稿，内容发布页才展示平台账号选择和提交发布入口，降低误发布风险。
- 采用选题时先在服务端标记已采用，再把真实选题带入内容管理的新建草稿；失败时不切换页面。
- 素材列表刷新只替换已落库结果，不影响正在上传的文件选择。
- 勾选 AI 生成后，接口必须创建 `GENERATING` 任务或明确失败，不得静默改成 0% 空白手稿；页面每三秒自动读取
  进行中的任务，完成后在未修改本地草稿的前提下回填标题和正文。
- 推荐模型任务由 `wao-server` 持有 claim token 和十分钟租约执行；失败原因展示在任务内并提供重新生成，
  服务中断后允许租约到期恢复。

## 验收标准

- Agent 左侧出现「内容创作」分组和五个菜单，桌面与窄屏都能访问。
- 账号定位保存后刷新不丢失；平台无 OAuth 或发布能力时如实展示能力说明。
- 新建内容、保存修改、选择素材和提交发布仍经过现有后端状态机，发布前保留人工确认。
- 素材上传后立即出现在素材管理列表；其他工作区的素材不能被列出。
- 热点采用后自动进入内容管理并带入选题；视频工作流原有草稿防丢和真实 WebM 导出行为不变。
- 输入“什么是 AI、什么是 Skill、什么是 MCP”并开始创作后，页面先展示生成中状态，随后自动出现模型生成的
  标题与正文；刷新后内容仍存在。
- Agent 只能看到推荐模型非敏感元数据，模型 API Key 和 `WAO_VAULT_KEY` 始终留在 `wao-server`。
- Agent 前后端测试与生产构建通过，线上 `/agent/` 和 `/api/agent/health` 可用。
