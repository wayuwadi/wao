# Phase 1：模型网关可编辑模型与固定首页页签

对应任务：`t1788401573213`。本规格调整
`phase-1-trusted-model-gateway.md` 的固定模型约束，并补充 `phase-1-tab-pinning.md` 的首页可见性要求。

## 用户结果

1. 成员从「设置 → AI 账号」新增或编辑醒市模型网关时，可以填写网关真实暴露的模型标识；新建默认值为
   `xingshi`，已有配置完整回填，保存时不覆盖成员输入。
2. 网关地址仍锁定为受信 HTTPS 路径，Token 仍只在服务端加密保存；「测试连接」继续用真实 `/models`
   返回值核对当前 Token 是否有权使用所填模型，未知模型不显示伪成功。
3. 顶部页签栏的「首页」固定在横向滚动区域左侧；滚轮、左右按钮或激活远端页签只滚动其余页签，首页始终可见。

## 兼容与边界

- DeepSeek 官方 API 仍只允许规格列出的模型；仅受信模型网关放开为非空模型标识，且模型网关仍不参与 AI Run。
- 已保存的模型值不做 migration 或静默替换，成员可从现有编辑入口按真实网关权限调整。
- 首页继续不可关闭、不可拖动；业务页签的排序、置顶、重命名、单独关闭和批量关闭行为保持不变。

## 验收

- 新建模型网关时默认展示 `xingshi`；编辑旧配置为 `xingshi` 后，请求正文保留该值且留空 Token 沿用原密文。
- 网关真实 `/models` 不含所填值时连接状态为失败；含所填值后文档润色按同一模型发起 Chat Completions。
- 打开多个页签并横向滚动到最右侧，首页仍固定可见；点击首页可以正常返回，其他页签仍可滚动与关闭。
