# 首页可跳过的起步引导

对应体验审计 B22，补充现有首页规格，不改变原 AI 控制台业务。

- 首页主要内容前提供安排今天、整理资料、交给 AI 三个真实起点。
- 每个起点说明第一步、保存/执行后去哪查看，以及后续操作；分别使用既有待办、文件库、AI 新会话路由。
- 点击只打开对应功能，不自动创建任务、上传文件或执行 AI。已有目标页负责校验、权限和提交。
- 引导可随时收起和展开；本机按成员记住选择，不跨账号继承，存储不可用也能继续导航并提示记忆失败。
- 不伪造首日身份、完成进度或教学数据，不修改项目管理、知识库、小记、密码本和草图内部。
- 窄屏卡片纵向排列，按钮有明确文字与焦点样式。

验收：三个入口到现有可操作页面、收起及刷新恢复、成员隔离、存储失败回退；首页回归、类型检查和构建。
