# 小记服务端自动选择已有标签

补充 notes-ai-tags-and-editor-efficiency.md 与 notes-save-ai-settings.md。小记常用提示词及其他记录在人工保存且正文实质变化后，标签阶段随服务端持久整理运行；无需浏览器续跑，关闭页面仍能执行。只从小记共享标签字典选最多三个合适标签，不强行凑数，不创建或改名标签。已有手选标签保留，最多二十个。

复用 note_ai_stage_attempt 的 tags 阶段与持久 NOTE_TAGS 任务，不增加迁移。三个个人开关仍只管理标题、正文与图片；标签有已有字典即自动整理。正文超过 12000 字符、无已有标签或无相关标签时明确跳过。来源更新、成员权限、CAS、并发名额及稳定请求号与其他阶段一致；MCP 未授权自动执行边界保留。

模型结果由 NOTE_TAGS 原允许清单过滤；写回时再次锁定当前字典，仅合并仍存在的标签，避免删掉的标签被重新创建。标签仅作为元数据，不替换正文、标题或原稿对照。失败显示真实原因并可单独重试；刷新读取后台阶段状态并更新标签。

工作流响应新增 tags 状态与 stages.tags 详情；POST /api/docs/notes/{id}/ai-stages/tags 使用原 expectedRev/requestId 契约。旧三阶段响应兼容，历史浏览器任务仍可读回。不新增 CLI 或工作区 MCP 工具：这是人工保存的文档上下文增强，现有文档标签读写能力不变，不扩大旧令牌的模型消费权限。
