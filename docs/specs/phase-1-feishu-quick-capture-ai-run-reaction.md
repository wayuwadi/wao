# Phase 1：飞书快速收集任务的 AI Run 表情反馈

本规格扩展 `phase-1-feishu-personal-quick-capture-reactions.md`：快速收集消息除了反馈任务是否创建成功，
还要让群聊成员能直接看见这条记录后来是否已交给 AI。

## 用户结果

- 通过飞书群聊 `@` 机器人创建的任务成功进入 AI Run 队列后，机器人在对应原消息上添加飞机表情。
- 网页创建、首页自主目标等没有飞书原消息的任务不添加表情；合并派工时，每条来自快速收集的任务都反馈到
  各自的原消息。
- 重复点击未创建新运行、入队事务回滚时不添加表情，避免把未成功派工伪装成已经执行。
- 飞书凭据未配置或表情接口失败时只记录服务端日志，不回滚已经成功创建的 AI Run。

## 数据与实现边界

- 原消息只从 `feishu_quick_collect_event` 已持久化的 `target_id → message_id` 关系解析，不按标题、描述或
  发言人猜测来源。
- 飞机表情使用飞书官方消息表情枚举 `StatusInFlight`，继续复用群聊同步自建应用的真实凭据和消息表情接口。
- 表情在 AI Run 入队事务提交后发送；它表示这条群聊记录已经进入过 AI 执行链路，不替代任务详情中的实时状态。

## 验收

- 单元测试覆盖快速收集任务、普通任务和飞书接口失败三条路径，并验证 AI Run 只把真正创建运行的任务交给
  表情反馈服务。
- 线上用已绑定成员在目标群 `@` 机器人新建任务，再从 WAO 发起 AI Run；确认同一条原消息在既有完成表情旁
  新增飞机表情，任务运行与部署链路不受表情反馈成败影响。
