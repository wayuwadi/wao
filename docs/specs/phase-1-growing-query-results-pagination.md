# Phase 1：增长型查询结果分页

## 用户结果

- 项目详情「动态」每页显示最多 10 条，保留时间倒序、总数、页码、上一页/下一页与跳页；切换项目回到第一页。
- 项目、决策、记忆中心、项目工程记忆、知识库、词条、链接空间及常用收藏、功能导航、账号资源、AI 账号、爬虫能力、更新日志、密码条目、衣库等增长型查询结果复用同一分页组件。验证码最近记录和知识库回收站也按页浏览。
- 搜索、分类、范围或排序改变时回到第一页；删除或刷新使总页数缩小时，自动收口到最后一页。记忆深链仍定位到目标所在页。
- 列表为空时保留原有空状态；单页结果不显示无意义的分页条。窄屏沿用现有分页组件的双行布局。

## 边界

- 本次只对已经读取到浏览器的结果分页，不改变 API 契约或查询范围；项目动态仍按现有服务端上限返回最近 50 条，验证码仍只展示最近 100 条。
- 文档目录树、日历日期窗、固定服务拓扑、弹出式选择器和已经服务端分页或加载更多的页面保持原有浏览方式。目录树的层级和展开状态比独立页码更重要。
- 结果列表按现有顺序先筛选、排序，再分成每页 10 条；分组仅用于展示当前页的结果。
