# 小记思考图可配置提示词

用户反馈第二张图的固定样式和洞察不合预期，希望直接查看、修改默认提示词，后续自行调试。第一张总览图保持既有配置和生成流程。

## 设置与调试

- 小记设置增加「思考洞察」「思考图样式」两个分项，分别编辑 `thinkingPrompt` 和 `thinkingImagePrompt`，每段最多 4000 字。实际服务默认内容直接返回并只读展示；点击「基于默认修改」才编辑，恢复默认先比较，保存后生效。
- 空串沿用默认；旧客户端省略新字段时保留账号现值。聚合 CAS 保存、成员隔离草稿、失败重试、读取失败与跨设备冲突沿用现有 `NoteAiSettingsForm` 和 `AiPromptEditor`。
- 新保存和手动重做冻结两段提示词快照。修改设置不批量重画历史图片；保存后在原小记重做思考图，或下次正文保存时自动使用新配置。
- 默认洞察优先发现关系、取舍和可迁移方法，避免常识复述或为了质疑而质疑；用户可调整方向，事实保真与结构校验独立保护。

## 生成与隐私

- 思考阶段先按洞察提示词生成经过原文引文校验的结构化提纲，先持久保存可复制内容。随后复用既有 ImageGen 队列，按第二段提示词生成真正的思考信息图，不再使用固定五卡片排版。
- 默认视觉建议关系图、对照或决策树、横版 4:3、紧凑信息、清晰中文，用户可调整构图、颜色与风格。绘图只接收本篇经过校验的提纲，不读取历史或外部信息，不调用人物形象素材，不混用总览图提示词。
- 提纲和绘图为同一 `thinking` 阶段的持久子过程。绘图使用从阶段 ID 派生的独立稳定请求号，重复推进不会重复入队；阶段在绘图队列期间保持运行状态，来源、取消、关闭代次及作者权限覆盖两个过程。
- 绘图失败保留提纲，重做仅操作第二张图。新 PNG 以「小记思考图」来源入库并即时标记私有，匿名原图与预览均不可读；旧图片继续可读，不自动替换。
- 两张图仍各自保存。第二张图不写入正文、不覆盖总览图，也不成为下一轮的用户事实。

## 接口与能力范围

既有 `GET/PUT /api/docs/notes/ai-settings` 的 `settings` 与 `defaultPrompts` 增加两个提示词字段；成员偏好键为 `note-thinking-prompt-v1` 和 `note-thinking-image-prompt-v1`。工作流状态和手动重做 API 沿用现有契约；无 migration。

CLI/MCP 不开放私人模型配置和 AI 消费权限，本次不新增命令或旧令牌可见工具。后续有独立 AI scope 时再评估。

本规格补充并替代 `notes-thinking-image-2026-10-13.md` 中的固定字体排版约定，不改变总览图、正文和私有分享边界。
