# 全局定时任务关闭时的本机额度后台采样

恢复通知的部署核对发现 Windows 公网实例沿用 `local-cloud`，关闭了 `wao.scheduling.enabled`，因此原注解任务没有后台运行，只有会员接口查询才补采。额度通知需要连续采样，不能要求用户持续打开首页。

当 `wao.codex-quota.enabled=true` 且全局调度关闭时，新增独立单线程调度，仅注册额度采集器的十秒后首次刷新和一分钟间隔。沿用已有只读协议、来源配置、采集节流及通知观察器。采集关闭时不启动；全局调度启用时沿用原注解任务，不重复注册。

该独立调度不恢复其他后台任务、旧 Runner 或自主建设，不新增配置凭据、网络服务、数据库结构、HTTP API、CLI 或 MCP 权限。进程退出时由 Spring 关闭调度器。

验收覆盖默认关闭、显式启用且全局关闭时真实定时回调、全局启用不重复、显式关闭；本地连接既有线上数据库，在没有页面查询的情况下确认后台采样完成及基线持久化。运行说明接续 [通知恢复](codex-quota-feishu-restore-2026-10-11.md)。
