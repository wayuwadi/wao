# 人生回顾：周期一致性与失败恢复

补充证据化周期人生回顾规格与 ADR-072，不改变资料选择、生成规则或存档结构。

- 切换周期立即进入加载状态并清空上一周期展示，旧请求迟到不能覆盖新周期。读取失败只提供读取重试，不误调用生成。
- 报告生成绑定点击时的周期，显示该周期正在生成。期间仍能浏览其他周期，结果仅在原视图仍有效时更新当前报告，否则通过历史档案查看。
- 生成失败说明所属周期，重试仍针对该周期；避免在切换后生成另一周期。
- 历史档案加载、错误和重试独立于报告生成；生成成功但档案读取失败时保留成功报告，不引导重复生成。
- 无历史时明确说明尚无档案。

验收：周期切换失败恢复、并发读取顺序反转、生成期间切换、成功后历史失败重试；真实后端读取失败注入后恢复。
