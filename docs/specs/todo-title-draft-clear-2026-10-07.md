# 待办标题草稿清空与恢复

关联：`todo-daily-fusion.md`、`task-project-selection-2026-10-06.md`、`todo-narrow-screen-input-2026-10-07.md`。

## 问题与范围

按天待办中写入标题后全部清空，刷新仍恢复清空前的旧文字。原草稿监听跳过空标题，未同步删除存储副本。此次只修复当天任务快捷录入草稿，不改变小记编辑器、任务 API 或排时语义。

## 行为

- 用户输入标题和选择项目时同步保护当前账号、成员、日期的草稿。用户将标题清空或改为纯空白时，删除该范围的旧草稿，并重置未提交任务的稳定 ID。
- 加载日期或成员草稿属于恢复过程，程序清空表单或填回内容时不写入或删除目标草稿；其他日期、成员草稿保持独立。无法解析的旧草稿不因项目异步加载而被覆盖。
- 本机草稿更新或删除失败时，保留屏幕上的输入，明确说明保护失败，并提供“重试保护草稿”。清空失败时说明旧草稿尚未清除；成功重试后撤下提示。
- 网络写入失败仍保留输入、项目与稳定任务 ID；恢复连接后原地重试，使用同一个 ID，成功持久化后才清理草稿。

## 验收

覆盖清空后刷新、非空草稿切换页面/日期恢复、成员隔离、存储删除失败与重试、网络写入失败后的稳定 ID 重试。使用既有本机账号和原数据库，在 390px 浏览器走通上述链路；真实手机键盘、应用切换与系统回收需要实体设备最终确认。

项目请求完成但聚合快照尚未装入时，保留草稿项目；真实项目快照到达后才校验失效归属。
