# 呼吸圆与文字控件边界

2026-10-03 用户报告呼吸入口的「留一点空白，再开始。」超出圆圈。桌面实际文字宽 260px，圆圈直径 240px；文字层此前按整页宽度排列，与圆圈独立缩放。

- 呼吸圆与中心文字共用尺寸变量，中心文字限制在圆径的 72% 内。起始提示按短句完整换行，不裁切、不省略、不改变文案含义。
- 保持原有字号、圆圈颜色与呼吸动画；运行、暂停、静坐和手机/横屏沿用同一边界约束。
- 设置面板关闭按钮提供 34×34px 的稳定区域，完整容纳关闭符号，避免字体行框高于控件。
- 不修改业务接口、数据库、计时逻辑、偏好保存或旧 Runner 状态。

## 重复验收

启动现有本地真实服务验收入口：在 `wao-web` 下执行 `npm run dev:acceptance`，沿用已有 `WAO_ACCEPTANCE_API` 配置；浏览器进入 `/breathe`。

1. 分别设置 1440×900、390×844、320×700、844×390 视口，检查初始提示完整换行。
2. 打开画面与节奏，体验 10 秒结束提醒，检查吸气、呼气、暂停、继续、自然结束与主动结束；更多菜单进入静坐检查提示。
3. 在浏览器开发者工具控制台执行 `wao-web/scripts/acceptance/text-boundaries.js` 全文。也可由浏览器自动化工具只读执行同一脚本。
4. 检查 `circles[].passed`、`minimumInset` 与 `horizontalOverflow`。文字矩形四角均须处于实际圆圈内部；不能仅检查整页是否有横向滚动。
5. `controlCandidates` 是按钮/链接文字行框越界候选，须结合截图判断；裁切导航、可滚动内容或图标字体可能需要单独解释，不可直接计为 BUG。脚本只返回类名和几何数据，不记录正文、账号或网络数据。

此流程包含人工操作，不声称是无人值守端到端测试。现有计时与账号隔离测试命令：`npm run test:unit -- --run src/__tests__/HomeBreathingStage.spec.ts src/__tests__/PublicBreathing.spec.ts --maxWorkers=2`。
