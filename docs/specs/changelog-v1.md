# 更新日志 V1：前端示例预览

## 范围与兼容

按 2026-09-10 本次需求，先交付前端页面、路由、mock 数据及基础交互。沿用 Vue 3 / TypeScript / Ant Design Vue、AppLayout、全局主题变量、Remix Icon 与现有导航和页签体系，无新增依赖。

工程已有 `/updates` 更新日记，展示真实 Runner 交付事件。本期新增 `/changelog`，不替换已有页面、接口或真实数据。页面长期显示“示例预览”，所有日期、版本与更新文案仅为示例，不表示实际发布结果。

## 页面和交互

- 左侧新增“更新日志”。已有个人菜单没有此项时追加入口；用户自行隐藏、重命名或移动后保留其设置。
- 顶部蓝紫渐变概览，展示示例更新数与版本数。
- 全部 / 新功能 / 优化 / 修复 / AI能力 / 工作流 / 系统筛选；一条更新可属于多个分类。
- 关键词匹配标题、摘要、重点、标签和版本，与分类和最近版本组合筛选，提供清除筛选及空状态。
- 月份及更新日期倒序时间线，卡片展示类别、版本、摘要、重点、标签和来源标识；原生 details 展开完整说明，支持键盘操作。
- 右侧包含订阅演示、最近版本、发布方式。订阅仅在当前页面切换状态，不持久化、不发送通知、不收集邮箱。
- 支持加载、错误重试、真实空结果与筛选空结果；数据源失败时不自动填充 mock。
- 窄屏切换单列，使用现有深浅主题变量。

## 数据接入预留

`types/changelog.ts` 定义 `ChangelogEntry` 和 `ChangelogSource.list()`；`api/changelog.ts` 是唯一数据入口，V1 显式读取 `mocks/changelog.ts`。视图不直接调用 HTTP，也不抓取 Git。

`source.kind` 预留 manual / commit / pr，`aiGenerated` 表示内容整理来源，`references` 预留真实来源链接。示例不编造 SHA 或 PR 编号。后续以 HTTP adapter 替换数据源即可保持页面结构；实际请求统一放入 api 目录。

## 启动与验收

在 `wao-web` 执行 `npm install`（首次）和 `npm run dev`，登录原有 WAO 账号后打开 `/changelog` 或点击左侧“更新日志”。默认 Vite 端口为 5173；现有登录继续使用工程网关代理 `localhost:9000`。

验证类型检查、生产构建、分类与组合搜索、详情展开、订阅开关、最近版本、无结果恢复、错误重试、旧更新日记及个人导航兼容。Mock 只供本页预览；不引入模拟登录或生产失败回退。
