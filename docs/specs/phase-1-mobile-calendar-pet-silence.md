# 移动端日历设置与宠物静默

对应任务 `t1788477158861`。

- 日历“显示”和“日历设置”的浮层在窄屏中以工具栏整体为定位容器，首次展开即位于容器内，不再从左边移出屏幕。内容较高时可独立滚动。
- 宠物快捷操作气泡增加“宠物静默”，按成员已有静默时长收起，可点击侧边图标随时恢复。
- 手机宽度首次进入默认静默；成员主动恢复后，本次浏览器会话内保留展开选择。再次使用静默按既有时长生效，桌面行为保持不变。
- 默认静默不改写成员跨设备配置，不覆盖桌面选择；已恢复的宠物继续支持短按、长按和拖动。
- 验收包含默认收起、恢复、快捷静默、静默恢复，以及 390px 日历设置所有入口可见并可打开真实数据。
