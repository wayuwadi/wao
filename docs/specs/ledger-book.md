# 账务本：兄弟明账与财务规划

## 目标与边界

在 WAO 浏览器版增加独立的「账务本」模块，入口与密码本同级。记录需要双方明算的旧账、烂账及未来账；双方心知肚明且不打算公开核算的私下事项不录入。账务本不是银行流水同步，也不自动推断真实收入、资产或负债。

## 账本与访问

- 成员可创建多个账本；创建时默认只有创建者可见。创建者可把指定 WAO 成员加入为可编辑或只读成员。共享范围以账本为单位，不能通过请求体冒充创建者。
- 只有账本成员能读取账本、账目与结算记录；只有创建者与可编辑成员能增改账目和补录结算；只有创建者能邀请、改权限或撤销共享成员。陌生账本或账目统一返回不存在。
- 不自动分享给组织所有成员，也不向工作区 MCP 或 CLI 开放财务数据。若将来需要自动化处理，先单独设计明确授权与审计范围。

## 明账字段与核算

- 一笔一条：标题、对方、归类（旧账、烂账、未来账）、方向（应收、应付）、原始金额、发生日期、到期或复核日期、核实状态、凭据线索、争议说明、下一步约定。
- 金额以人民币元、两位小数存储。每次已结算金额单独追加日期、金额和说明；未结金额为原始金额减结算记录总额。结算记录保留原始痕迹，不提供删除。
- 状态为待核实、已确认、有争议、已作废。只有已确认且未作废的未结金额进入应收、应付和净额汇总；争议和待核实条目仍可查看和继续核对。
- 编辑使用版本号防止另一人修改后被静默覆盖；每次修改记录前后完整快照、修改人和时间。保存失败时保留浏览器中的草稿。已结金额不得超过原始金额，原始金额也不能改到低于已结金额。
- 账本中的未来到期金额按月份呈现。未填到期日的账目单独提示，避免误以为现金流已完整。月度现金收支计划需要真实期初余额和收入支出资料，未录入前不生成虚假的结余结论。

## 浏览器交互

- 借鉴密码本三栏：账本、按归类筛选的账目列表、详情。窄屏使用列表到详情的顺序导航。
- 空数据、读取失败、保存中、保存失败可重试、未保存离开提醒均有明确反馈。删除动作改为「作废」并保留历史。
- 资料不全的条目可以先存为待核实；已确认条目要求填写确认依据，争议条目要求填写争议说明。页面不提供“私下账”分类。

## 验收

- 两个成员共享一个账本后，双方可看到同一条目及结算记录；未加入的成员无法读取或修改。
- 部分结算、金额校验、争议排除、作废留痕和并发编辑冲突均按上述口径运行。
- WAO 导航中心、路由、页签与手机浏览器都能打开账务本；页面只显示真实持久化数据。
