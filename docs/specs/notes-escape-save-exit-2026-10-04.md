# 小记 Esc 保存退出

2026-10-04，按已确认交互补充小记编辑退出行为。

- 已保存小记编辑和新建全屏编辑中按 Esc，居中显示“保存修改并退出？”。默认聚焦“保存并退出”，Enter 直接保存并退出，返回原来的预览状态。
- “不保存，退出”清除本次浏览器草稿、恢复已保存正文并退出；不删除文章。普通新建输入框 Esc 不触发退出。
- 保存失败保留输入、草稿和确认层，展示失败提示并支持原地重试；保存时阻止重复操作。保存期间若出现较新输入，不关闭编辑。
- 确认层中的 Esc 取消确认并返回编辑，Tab 在两个选择之间循环。菜单、查找、帮助、标签输入等局部浮层优先消耗 Esc。
- 点击“退出全屏”仅调整视图，继续保留当前草稿。原“收起编辑”的保护草稿行为不变。

验证：小记和编辑器 182 项回归通过；覆盖默认焦点与 Enter、保存失败重试、取消确认、不保存清除草稿及新建全屏退出。真实数据库链路中确认弹层默认焦点和 Enter 保存退出。
