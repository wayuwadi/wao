# 首页到休息空间的伙伴旅程

2026-10-04 用户确认融合 Demo 并授权实现。本规格增补公共呼吸与首页休息入口规格，休息首页采用确认的暖白、鼠尾草绿、浅水色布局；明确深色主题提供对应夜间配色。2026-10-05 视觉打磨增补见 [休息旅程视觉打磨](rest-journey-visual-polish-2026-10-05.md)。

- 首页移除「功能探索」按钮。「休息一下」触发覆盖浏览器可视区的黑洞回收：界面的临时副本逐块缩入黑洞，原页面、页签及草稿不被改写。约 4 秒后蓝、黄、绿三个伙伴邀请一起休息，再翻面进入 `/breathe`，入场约 7 秒。
- 首页伙伴的既有四人互动保留；休息旅程由三位伙伴领航。新增动作采用原生 CSS / Canvas，不新增引擎依赖。
- 到达后，伙伴舒展身体和手臂，先引导约 8 秒的一轮呼吸，再提供「留下来，呼吸一会儿」「站起来，出去走走」。引导不是正式练习，不计入练习时长，不播放声音。
- 直接访问 `/breathe` 或兼容 `/login` 进入选择界面，不自动播放入场或呼吸引导；刷新不重播。减少动态效果时省略黑洞、翻转、伸缩，保留简短文字引导。提供跳过与 Esc；跳过直接进入选择界面。
- 留下后可选择呼吸 / 静坐及既有时长，主动开始才计时。复用原计时、暂停、提醒、认证快照、账户隔离和偏好失败提示。伙伴按实际练习相位呼吸，静坐与暂停保持静止。后台页面暂停休息页练习和入场引导，回到前台需要主动继续。
- 走走页面提供起身、喝水、远眺的简短提示和「我回来啦」，不强迫倒计时，不伪造已完成运动或健康效果。返回后可再选休息方式。
- 工作区 / 登录入口、全站主题、画面与节奏设置、备案继续可达。现有游戏移到休息首页「更多」中的次级入口，进入游戏暂停练习；游戏页保留原选择器和风格配置。
- 跳转失败时保留覆盖层并显示重试 / 返回首页；不把失败当成已到达。重复点击只启动一次，离开路由和卸载取消动画、计时器、焦点屏障和滚动锁。

不修改服务端、数据库、HTTP API、MCP / CLI 或部署拓扑。本地验收记录单独保存，交付以 PR 合并为准。
