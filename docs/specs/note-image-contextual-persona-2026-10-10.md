# 小记配图按内容选用本人形象

依据用户 2026-10-10 要求，补充 [数字成员图库规格](digital-member-library.md)。默认本人是可选配图素材，绑定形象不意味着每篇文章都出现人物。

## 行为

- `identitySelection.mode=default`（包括省略字段）：同一本机 Codex、同一模型和思考深度先读取全文及画面偏好，判断核心画面是否需要作者本人。第一人称、拥有形象或提到工作不构成出镜理由。
- 任务进展、下周计划、工作复盘、待办、技术说明和观点整理优先使用信息图、时间线、流程、场景或物件；引用和他人的经历不能替换成本人。生活场景确实需要作者本人作为主体时才使用冻结的本人资料及参考图。
- 只有严格返回 `USE_SELF` 才读取并传入本人的参考图片；`NO_PERSON` 或不明确的返回使用无人物构图，移除生图提示词里的身份资料，不传人物参考。判断阶段不接收人物图片或姓名资料，不启用图片工具。
- `explicit` 继续沿用用户本次明确指定的已确认成员和版本；`none` 继续不出现人物或宠物。两者均不做自动出镜判断。

## 完整性和失败

选择与形象仍在入队时冻结，判断不能读取后来变化的账号默认。默认任务不因尚未启用参考图能力在入队前失败；判定需要参考图时，仍必须通过原有主机能力、归属和哈希检查。明确指定仍在入队检查能力。

判断和生图共用本次执行超时、取消和独立并行进程规则。判断错误或取消不会启动生图；不增加任务数量限制、不恢复 Runner、不新增 API。两次调用的已知用量合并；缺少用量时仍标记未知。

已保存正文、配图和形象绑定不回写；不自动重跑历史图片。配图写入继续沿用当前全文及 revision/CAS，失败保留原文，用户可单独重试配图。

## API、MCP 与 CLI

无新字段、端点、权限或命令。现有 Web、MCP 小记保存与 CLI 小记创建的默认配图统一经过服务端路由，不能由旧令牌读取私有图库。现有 `identitySelection` 兼容；以后增加可操作的出镜策略设置时重新评估 CLI 同步。

## 验收

覆盖无人物分支不读取照片、需要人物时仅使用冻结引用、明确指定和禁用不经过判断、无效回答保守收口、取消不生图、总超时及用量。真实合成任务计划图和本人生活图需目视验收；实体设备与相似度仍由用户确认。

本次验证：后端全量测试 1736 项（22 项既有跳过），前端相关 15 项测试、类型检查、构建和 UI 检查通过。合并前将本地构建制品运行于 Windows2 独立回环验收服务，复用既有线上数据库、本人绑定及已登录 Codex；合成任务计划图没有人物，合成花园生活图按需使用本人。两篇正文及配图重新读取、浏览器展示均正常；验收记录已移入回收站，临时服务已停止。合成场景不代表真实日记，目视通过不代表承诺真人相似度。
