# 小记统一阅读器

2026-10-03，按用户确认的侧栏速览 Demo 实施。本规格扩展 `notes-card-full-preview-and-list-continuation.md` 和 `notes-fixed-height-reading-and-ai-settings.md` 的阅读入口；正文继续遵循 `notes-single-latest-content.md`。

- 卡片增加“预览”与方式菜单。桌面默认隐藏，鼠标悬浮卡片或键盘聚焦卡片内部时显示，不挤动卡片内容；触摸设备保留可见入口。编辑中的卡片不显示预览按钮。
- 单篇预览、卡片 Enter、图片总览和工具栏“阅读模式”共用一个只读阅读器。单击展开卡片和双击编辑继续保持原行为。
- 默认侧栏速览：左侧为当前筛选结果的小记目录，右侧为选中文章全文。全屏阅读隐藏目录、居中呈现单篇正文。顶部随时切换；菜单可直接指定布局。
- 本次阅读固定筛选后的 ID 顺序，正文读取当前单份最新内容。后台新增或重排不会把用户带到另一篇；当前文章失去可见性时选择剩余文章，没有剩余则退出。
- 当前小记页面内记住布局、选中文章和逐篇滚动位置；切换布局尽量保留当前段落位置，退出后恢复入口焦点和清单位置。切换账号或离开页面不持久保存阅读记录。
- 不把阅读内容变成编辑草稿，不发起保存或 AI 操作，不覆盖新建或编辑中的输入。图片保留正文位置，支持单独放大。
- 窄屏侧栏改为“目录”按钮展开；选择文章后收起，窗口放大时解除正文遮挡。长标题换行，布局不横向溢出。
- Tab 焦点限制在阅读器中；Esc 先关闭图片或手机目录，再退出阅读器。左右键翻篇、上下键和 PageUp/PageDown 滚动，Home/End 到首末篇。

这是浏览器展示能力，无新业务服务、HTTP API、数据结构或 MCP；不需要增加 CLI 命令。

验证和重跑入口见 [验收记录](../validation/notes-unified-reader-2026-10-03.md)。
