# Phase 1：飞书 @机器人个人任务收集

本变更扩展既有的群聊快速收集，不引入自由执行的 AI 代理。用户在已配置飞书群里
@ 机器人说一句未来要做的事，服务端只做可预期的文本解析，并创建一条真实 WAO 任务。

## 用户结果

- 普通群聊不创建任务；消息必须包含 @提及。
- `记录任务：……`、`任务：……`、`记录想法：……`、`想法：……` 及无前缀口语都能进入当前发言人的
  跨项目任务列表；任务/想法前缀不污染标题。
- “想法”仍是未排期的个人待办，不自动进入团队共享点子库；来源标签区分“群聊快速收集”与
  “群聊想法收集”。
- 新任务状态为待办、无虚构截止日期，因而默认进入 TODO 的“稍后”分组。
- 发言人必须已用同一飞书身份登录过 WAO。无法识别时回复绑定指引，不把任务错记给默认成员。
- 成功卡片显示真实归属人、项目和任务，并可打开任务。空内容、无项目或处理失败均给出明确回复。

## 一致性与安全

- 事件订阅继续校验 Verification Token / Encrypt Key 和目标群。
- 以飞书 `event_id`（缺失时用 `message_id`）在 MySQL 持久去重；重启、重试和多节点不会建出重复任务。
- 飞书回调仍快速返回 200，失败原因记入事件表并尽力回群，不让飞书无限重推。

## 验收

- 单元测试覆盖普通聊天忽略、任务/想法口语解析、飞书身份归属、未绑定拒绝、多节点去重、语音提示和异常回执。
- 线上验收使用真实已绑定成员发送一条 @机器人消息，证明群回执链接和 TODO 列表指向同一条任务。
