# 浏览器布局巡检与修复（2026-10-03）

## 背景与范围

自动化页面的「飞书任务收集配置」误用 26×26px 图标按钮样式，文字纵向溢出并覆盖标题、提示和表格。按用户要求检查其他浏览器页面的同类问题，不改变业务接口、数据或技术栈。

## 布局约定

- 自动化文字按钮按内容定宽，不被压成图标大小；操作图标保持尺寸。详情网格允许内部表格收缩并滚动。
- 小记标题和工具栏允许换行；手机搜索独占一行，筛选浮层以整个工具栏定位，不越出正文。
- 参考图库保留唯一自定义上传入口，原生文件控件隐藏但仍可通过按钮选择文件。固定提问栏以主内容容器宽度居中，避开侧栏；手机保留底部导航与新建按钮空间，输入和发送按钮可换行，正文留足滚动余量。
- 月历每周至少 96px，高度不足时在日历内滚动，避免日期和事件挤压。主内容小于 640px 时保留至少 490px 网格宽度并提供双向滚动提示；更窄时日期切换和「今天」分行。日历滚动容器支持键盘聚焦。
- 技能市场导航链接不收缩；窄屏和狭窄嵌入容器中，导航单独占行，从左开始横向滚动，所有入口均可通过键盘到达。

## 验收记录

本地 Vite 连接当前公开开发通道的既有服务与数据；没有创建数据库、测试任务或修改用户内容。当前通道使用既有 `wao_local`，不能据此宣称完成 Linux2 生产数据验收。

- 在 320、390、900、1440px 宽度检查首页、小记、待办、日历、项目、知识库、文件、参考图库、自动化、请求监控、润色、画图、天人一卦、看板、密码本、设置、功能探索、想法、系统报告、人生复盘、技能连接共 21 个主要页面的根容器溢出、文本按钮与控件边界。
- 补查导航、嵌入 HUB、嵌入技能市场、公开 HUB、技能市场、宠物仓库、下载入口。下载页装饰轨道超出局部容器但由页面裁切，不作为业务内容溢出处理。
- 五处修复复查 320×700、390×844、900×600、1440×900；月历键盘滚动、技能导航末端入口、自动化配置弹窗、小记筛选浮层、新建项目表单可用。
- 自动化实际已有提醒行与日历已有事件参与验收。项目列表为空，因此未覆盖有数据的项目详情；图库空态已检查，未上传测试图片或发起 AI 请求。外部应用、私人分享链接与已停用客户端不在本轮验收范围。
- 使用现有组件交互测试、类型检查、构建和修改文件 ESLint 验证，不添加只断言 CSS 字符串的测试。

这次巡检覆盖已列出的页面和状态，不代表对任意权限、数据规模和弹窗组合不存在布局缺陷的保证。
