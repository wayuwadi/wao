# 资源库

资源库统一浏览已授权的文件、图片和托管网页。全局未归类资源与项目资源保持现有权限；知识库及小记附件继续受来源文档约束。升级不迁移、删除或有损改写原文件。

## 浏览与展示

- 文件每页 30 条，图片每页 15 张，网页每页 10 条。先按完整授权列表检索和筛选，再分页；深链接定位到目标文件所在页。
- 三类资源分别保留搜索、排序、页码和滚动位置。浏览条件只写当前页签，并按账号和成员隔离。类型过滤使用原文件名和 MIME，改显示名称不会改变文件类型。
- 默认保持服务端最近优先顺序；同时间由 ID 确定次序。名称采用中文自然排序，大小排序优先准确字节数。旧响应只有格式化大小时显示“约”，未知项明确说明。
- 刷新时保留上次内容；失败显示原因和重试，不伪装为空列表。无内容与筛选无结果分别提供上传或清除筛选入口。
- 页面、预览和替换弹窗复用主题 token、WaoButton、WaoField、SettingsDialogShell、ConfirmActionDialog。窄屏重排，操作可通过键盘与触屏访问。

## 上传与编辑

- 文件和图片进入浏览器会话队列，离开当前页面继续上传。项目入口在入队时固定 projectId 和图片来源。不同账号的队列、进度和迟到响应互不混入；切换账号中止客户端传输，尚在准备连接的旧请求不能带新账号身份发出。已经被服务器收到的请求可能仍完成，取消不等于撤销已写入内容。图片请求取消不会回退为本地图片。
- 进度表示传输字节；100% 后仍等待保存确认，只有接口成功回执才能标记完成。可重试的失败保留原文件；空文件、非图片 MIME 和超限等确定性无效输入不可重试并立即释放 File。等待项可移除，成功项释放 File 内容、只保留轻量记录。重复触发同一个 File 对象不会重复入队。
- 刷新或关闭浏览器无法恢复所选文件，未完成队列提供离开保护。HTML 托管需要填写发布信息，未发布内容和文件不属于后台上传队列。
- 改显示名称的草稿按账号/成员/文件保存到页签存储，有效期为 7 天；存储不可用时使用最多 256 条的内存兜底。有效期内成功或明确取消才清理，内存达到容量后淘汰最早记录；翻页和筛选可恢复已保留的输入。保存携带开始编辑时的原始名称，服务端以原子比较检测冲突；409 时保留草稿并读取最新值，用户再决定采用哪一版。
- 同一资源的改名、替换和删除顺序执行，失败不阻塞后续重试。刷新快照合并请求期间已确认的修改，不能吞掉新上传或复活已删除记录。切换账号立即清空旧资源并失效旧请求。
- 托管网页编辑与正文替换携带开始时的 `revision`；数据库写入原子比较，两个窗口使用相同版本只能有一个成功。409 后保留本机内容，读取最新版本后由用户明确选择继续；读取失败不能盲目覆盖。省略版本的旧客户端兼容写入，但版本同样递增；AI 报告更新也使旧编辑版本失效。V207 只新增非空 BIGINT 版本列，原有和新建页面初始版本为 0，`updatedAtIso` 仅用于展示与排序。
- 替换保持资源 ID、链接、项目和自定义名称；失败保留所选文件。预览使用独立请求代次和取消信号，快速切换不会显示上一项结果，替换后读取当前正文。

## 图片预览与存储

PNG/JPEG/BMP 使用有界采样解码和最长边 768px 的派生预览，保留透明与 EXIF 方向。已有对象存储可保存派生图；历史 MySQL 图片通过有界进程缓存复用结果。缓存最多 24MiB / 256 项，单项最多 1MiB；同图缓存缺失时串行处理并复用可缓存结果，超过单项上限的结果不驻留、后续请求仍需生成。固定 16 组锁限制锁对象数量，不同图片落在同一组时也会排队。权限和记录存在检查先于缓存。

GIF/WebP/SVG 继续保留格式和动画行为；单边超过 32,768 像素或总计超过 1 亿像素的历史内容不尝试解码，沿原图兜底，不能把上述像素上限理解为所有图片的硬限制。原图 URL、内容和备份键格式保持兼容，不执行批量压缩或清理。私有图片禁止共享缓存；图片正文、公开小记图片别名和托管网页图标的 CSP 沙箱禁止脚本和外部加载。

## 验证

`npm run test:resources` 覆盖列表、筛选、分页、上传连续性、进度与重试、草稿、并发、账号隔离及预览/替换。此回归集进入公开 CI 和 Windows Jenkins 发布入口，并继续运行类型检查、既有稳定性集与构建。服务端覆盖真实 mapper 查询、改名比较与冲突、权限、图像尺寸/透明/方向、缓存容量与并发。

浏览器验收使用独立数据库和真实 API 持久化测试资料，检查上传、改名、预览、替换、删除与错误重试，并检查桌面、390px/320px、明暗主题和键盘。界面样本不作为生产数据验证。
