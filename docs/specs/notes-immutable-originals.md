# 小记不可变原稿与只读原文

本规格更新 `notes-single-latest-content.md` 取消原文切换的旧产品决定。默认仍读最新正文；阅读器的“查看原文”仅改变查看状态，不恢复正文、不回填编辑器、不触发 AI 或顺手发现。侧栏、全屏和卡片入口共用按篇阅读组件。

## 来源及真实性

新小记第一次成功保存时冻结用户的标题、原始 Markdown、富文本 JSON、blocks 和链接。未填写标题保留空值，不把系统生成的首行标题当成用户标题。保存前的手动操作先冻结完整私人草稿及实际模型输入，再入队；最终保存绑定稳定草稿 ID。首次记录指针只建立一次。

每个阶段 attempt 对应不可变来源快照、实际模型输入及摘要、输出和应用版本。来源正文不 trim、normalize 或移除图片；模型输入是另一份副本。去除自动图必须有真实生成任务与已插入 URL，不以 alt 判定。选段保留完整输入、选区、模型输出和完整候选正文；确认留存后才修改编辑器。

历史文档没有可信首次记录时标注“首次留存内容”，它可能包含先前 AI 文案。旧 `note_polish_version` 的来源按需兼容读取，标注“历史留存的润色前内容”；标题、富文本和精确来源版本缺失就是未知。旧行被后续兼容写入覆盖前，按文档、成员、更新时间及源/结果摘要幂等归档。更早已覆盖且无备份的内容明确无法恢复，不回填当前 AI 正文、不批量重跑。

## 持久化与并发

新增 `note_source_snapshot`（成员、文档/草稿 ID、来源身份唯一）、`note_original_record`（文档+成员首份指针）、`note_ai_transformation`（请求/attempt ID 唯一）及 `note_source_asset_ref`（现存资产保留引用）。新增 migration，不更改历史文件。

业务首次保存和原稿同事务。模型执行之前冻结输入；AI 写回、不可变结果及应用关联同事务并校验轮次、关闭代次和文档 CAS。快照失败不提交模型，结果关联失败不覆盖正文。重复请求返回原关联，新输入必须使用新请求号。旧结果可留存但不能采用到新版本。

草稿候选留存标为 `DRAFT_RESULT`，真正保存才标 `APPLIED`；候选之后用户又修改内容标 `MIXED_APPLIED`，不谎称整个当前正文等同于模型输出。已采用关联不会随下一次用户保存迁移到新版本。识别同次已采用的手动正文结果和生成图，避免自动重做相同阶段。

原稿引用的现存图片与附件使用索引保留，显式删除检查引用并与冻结来源使用同一资产行锁。永久删除文档按 FK 级联其历史及引用；私人未保存草稿不设置自动过期，以免删掉唯一记录。历史快照仍不能重建迁移前已经删除的二进制资产。

## API 与权限

响应使用 `ApiResponse<T>`，成员只来自真实登录会话。文档仍可访问且快照归本人才能读；当前共享文档不共享原稿。删除文档返回 404，恢复后按原权限读；归档可只读，停止自动处理。附件继续使用原资产权限。

当前浏览器知识库正文沿用已登录组织成员共享读取，没有新增篇级 ACL；私人来源叠加成员归属校验，不因正文共享开放其他成员快照。待办日视图复用小记编辑器时，同样传递 `sourceInputIds`，其可选字段为空时保持旧操作回执摘要兼容，不能让旧请求重试变成新记录。

|接口|用途|
|---|---|
|`GET /api/docs/notes/{id}/originals`|本篇最新采用润色前输入、首份可靠记录、真实性说明、应用版本|
|`GET /api/docs/notes/{id}/originals/{snapshot}`|指定本人快照，重新核对归属及文档存续|
|`POST /api/docs/notes/ai-inputs`|手动调用前冻结完整来源，携带稳定 ID、版本、阶段、请求 ID、实际输入与选区|
|`POST /api/docs/notes/ai-inputs/{request}/results`|确认真实本人任务结果；不写正文|
|小记创建/PATCH 的 `sourceInputIds`|事务绑定明确采用的候选和文档版本|
|`GET /api/docs/notes/polish-versions/reading`|旧有效阅读结果，不传输全量私人来源|

本期没有全部轮次列表，无无界历史接口。每篇最多返回本次和首份两份；快照遵循既有正文/结构大小与安全限制。读取只在用户进入查看时发生，离开不持久缓存；成员切换和卸载递增请求代次，迟到响应丢弃。来源切换分别保存阅读位置，退出恢复入口焦点，编辑草稿与光标隔离。

CLI/MCP、分享和搜索不附带私人原稿，不新增旧令牌权限。来源保留可为发现提供证据，但不实现发现算法；AI 派生写入复用其来源边界，查看不会产生保存事件。

## 验收证据边界

SQL/组件替身测试验证不变性、幂等、失败回滚、账号迟到响应和阅读切换；实际本机 MySQL、真实会话浏览器和模型任务另行记录。用户本轮已确认使用本机数据库，它不作为生产数据验收证据。
