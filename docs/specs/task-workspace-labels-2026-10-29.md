# 任务标签与待办工作台

用户批准统一改造标签、待办分栏和四象限，并保留已有能力。

待办默认进入任务导航、紧凑清单和详情分栏。导航包含所有、今天、明天、最近 7 天、收集箱、项目、标签和已完成。个人汇总仅限本人负责，未指派内嵌子项沿父链归属，无负责人主任务按创建者归属；显式他人负责、仅参与或可见的共享任务不进入个人汇总。显式项目清单保留共享任务范围。移除指派给我，旧筛选兼容回个人所有。所有和收集箱快速新增默认无日期，仅今天、明天入口自动带对应日期。每日回顾保留原按天工作区，原待办视图保留看板及既有筛选。待办跨项目清单暂不提供层级拖动，项目清单继续支持。

任务标签与小记标签独立。每个工作项最多 20 个标签，名称去空白、去重，单个最多 40 字符。主任务和内嵌子任务独立编辑，列表、详情抽屉、项目清单共享。标签通过独立表和版本号保存，旧任务全文保存不覆盖标签；冲突保留草稿，用户重新读取后再决定保存或取消。子树移动和提升在原事务中迁移标签；任务删除级联清理，失效子项不进入标签目录。

收集箱是 project 为空串的个人任务，按 owner 隔离，任务写入加锁后复核可见性。新建收集箱任务由当前成员负责。空项目任务不发送飞书群任务或评论通知，避免私人内容外发。筛选不复制任务，快速添加使用稳定 ID，失败重试提交原草稿。

今天、明天与最近 7 天匹配执行日期或截止日期，不使用活动日期推断计划。最近 7 天包含今天至第 6 天；逾期仅按截止日期。已完成仍使用完整收尾语义，未完成下级保留。

四象限默认保持 P0/P1/P2/P3 映射、项目父子层级和原拖动规则。每个象限可改名称、项目、标签、日期和优先级；维度间取交集，标签支持任一、全部、无标签。留空表示所有；自定义规则允许同一任务在多个象限出现。筛选命中的子项补回祖先作为背景，背景不计数。任一自定义规则启用时关闭跨象限拖动和快捷优先级迁移，避免隐式修改标签或日期；恢复默认可重新使用原行为。

象限规则及已保存筛选属于成员偏好，项目和个人象限分开保存。沿用离线草稿、失败重试与账号隔离机制。未实现已放弃/垃圾桶状态，因此不展示虚假入口。

新增 V197，只新增 task_labels 表。浏览器接口不扩展既有 MCP 或 CLI 令牌能力。

## 操作连续性与同步

项目清单／四象限和待办支持批量标签追加／移除、优先级、完成和移动清单。操作逐项写入既有版本校验接口，成功项退出选择，失败项留存并显示具体原因；内嵌子项独立选中，未选中的子项不递归完成。跨项目移动沿用服务器约束：独立任务有父子关联时需先解除关系，内嵌子项随主任务移动；只能将本人负责的任务移入个人收集箱。项目既有复制与 AI 批量能力保留，内嵌子项不误当成独立 AI 任务派发。

标签和优先级保存成功给出轻提示及撤销，撤销只恢复对应属性，校验账号、当前字段／标签版本和服务器编辑版本，不覆盖之后的编辑。普通子项允许清除显式优先级并恢复继承。

同一账号的窗口通过会话认证的 `/api/task-changes` SSE 接收无业务内容的失效通知；成功任务／标签写入后重新读取授权快照，合并期间保护本机草稿。连接一分钟重新认证，15 秒心跳，重连补读，轮询和焦点刷新继续兜底。不同成员的共享修改仍由既有后台同步读取；不将其他账号的事件或数据广播给当前账号。

视图状态只存本标签页的 sessionStorage，按账号与项目／筛选隔离，包含待办入口、清单／四象限模式、关键词、展开、详情选择与列表内部滚动。此状态不是业务草稿，也不向其他窗口同步。
