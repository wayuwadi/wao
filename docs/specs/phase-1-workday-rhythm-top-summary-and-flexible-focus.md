# Phase 1：今日节奏顶部摘要与可追加重点

对应任务：`t1787894137894`（今日节奏页面优化）。基础行为见
[今日节奏紧凑面板](phase-1-workday-rhythm-compact-dashboard.md)，本次布局和重点数量规则以
[ADR-147](../adr/147-workday-rhythm-top-hexagram-and-flexible-focus.md) 为准。

## 用户结果

1. 顶部主卡同时展示当前时间块、完整一天和天人一卦；已起卦时明确显示本卦、变化后的卦象及今日启示，点击可进入天人一卦详情。
2. 已保存 AI 自照时，今日启示显示其纯文本短摘要；尚无自照时只显示权威卦象组成的事实简介，不编造运势或自动调用 AI。
3. 今日重点、每日必做和精力补给在桌面端一行三列，窄屏按同一顺序纵向展示；页面不再提供单独打开和复制链接按钮。
4. 今日重点与安排明日在同一卡片入口表达；今日和明日都默认三个栏位，可继续新增，追加项可删除，所有栏位跨设备保存。
5. 至少三个非空重点保存成功后完成计划联动并按配置通知；新增的非空重点一并进入顺序推进、历史和飞书卡片。
6. 每日必做卡可直接打开配置，成员能停用默认的制定计划、上下班打卡，也能新增、修改和删除自定义项目。

## 验收

- 有变卦时顶部同时显示本卦与变化后卦象；无 AI 自照时显示可核对的卦象事实，有自照时显示最新 assistant 回复摘要。
- 点击顶部卦象或详情进入 `/tianren`；未起卦时由成员主动起卦，页面加载不产生新存档。
- 1180px 页面下三张执行卡单行排列；390px 下无横向滚动，重点仍可新增、删除、保存和安排明日。
- 第四个及之后重点刷新和换设备后不丢；编辑会重置该项及后续完成状态，历史最多投影 20 项，通知忽略空栏位并包含全部非空项。
- 每日必做配置入口可完成加载、保存、停用系统项、增删自定义项和失败重试，历史完成记录不因模板删除而消失。
