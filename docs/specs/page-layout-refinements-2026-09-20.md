# 页面布局优化补充规格（2026-09-20）

来源：分享任务 t17898827570030。本规格补充当前导航、知识库、日历、画草图和密码本展示行为，不迁移业务数据。

## 行为

- 任务和文档收藏统一在顶部快捷栏展示，复用既有收藏数据，与手动固定入口按资源键去重。取消入口同步取消收藏；项目收藏仍在项目菜单下。
- 知识库卡片采用上方图标封面、下方完整换行名称和资料摘要布局，移除左侧蓝线。收藏仅以卡片右上角星标呈现，不重复展示“常用”区域。
- 知识库、项目、文件设置、密码本与日历配置浮层支持 Esc 和点击遮罩关闭；有修改先保存，无修改直接关闭。校验不通过或保存失败保留窗口和输入，保存中不允许重复关闭或编辑。仅关闭最上层浮层，内部菜单消费的 Esc 不继续传递。
- 新建任务、项目和知识库等有内容时先保存，缺少必填名称时保留输入并提示。关闭按钮标识“完成并关闭”，避免“取消”却提交的歧义。
- 画草图固定工作区高度，文件列表内部滚动；密码本固定页面高度，分组、条目和详情内部滚动。窄屏保留原有详情页方式。
- 日历天气合并至工具栏，显示今日和明日摘要，不再挤占独立整块区域。默认武汉，已保存的城市和主动清空的位置不被覆盖。

在线创建项目和密码本分组请求失败时抛出错误，由表单保留输入，不再生成本地临时记录并当作服务端保存成功。

组件交互测试覆盖收藏去重和取消、浮层层级、知识库关闭失败保留与延迟保存、文件设置校验与重试、默认天气及既有城市保留；并回归日历、密码本、画草图、新建任务和项目设置。
