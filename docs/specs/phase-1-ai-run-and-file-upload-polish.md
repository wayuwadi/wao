# Phase 1：AI Run 与文件上传连续操作优化

对应任务：`t1787905746588`。

## 用户结果

1. 从首页“可 AI Run 的任务”清单启动一条任务后，清单弹层保持打开并移除已入队任务，用户可连续启动下一条；真实运行记录仍立即进入首页运行区。
2. 新建网页托管时，选择 HTML 后自动用文件名生成可修改的页面标题和合法链接后缀；文件名无法生成合法后缀时使用不冲突的随机默认值。
3. “文件与图床”提供不限制选择类型的统一拖拽入口：图片进入图床，HTML 进入网页托管配置，其余文件进入文件库。

## 真实数据与安全边界

- 自动分类只选择现有真实上传链路，不绕过文件、图片和托管 HTML 各自的服务端大小、内容、权限与隔离校验。
- HTML 在发布前仍需用户确认默认标题和链接后缀；一次拖入多个 HTML 时只配置第一个并明确提示其余文件再次拖入，避免静默发布或覆盖。
- 已入队任务立即退出可运行清单；现有后端幂等校验与任务运行状态继续防止重复创建。

## 验收

- AI Run 创建接口成功返回后，“可 AI Run 的任务”弹层保持可见，已入队任务消失且下一条仍可点击，用户明确关闭或点击遮罩后弹层才消失。
- 选择英文 HTML 文件时标题保留原文件名、后缀转成小写连字符格式；中文等无法形成合法后缀的文件得到 `page-` 开头的默认值，且两项都能继续编辑。
- 在统一入口分别拖入图片、HTML 和普通文件时，前端调用对应真实上传服务；HTML 打开已选文件且默认值完整的托管配置弹层。
