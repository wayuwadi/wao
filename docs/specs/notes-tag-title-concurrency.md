# 标签推荐与独立标题更新

补充小记单份最新正文与草稿保护规则。

标签推荐依据保存正文和已有标签集合。模型返回前，仅标题独立保存或自动更新，不应仅因 rev 增加就判定标签失效。最新正文结构与原始输入、已有标签均相同时，使用最新 rev 做 CAS，只提交 tags，不提交旧标题或正文。

正文或标签变化、存在未保存草稿或正在保存时，保留用户内容并提供重试。取回可用标签列表后再次检查草稿与任务有效性；该异步等待期间开始输入或删除，不得继续写回。读取最新文档之后的服务端竞争仍由 expectedRev 拒绝，不跳过 CAS。

不存在可推荐的已有标签时维持既有完成语义，不创建新标签。标题、配图、润色的写入条件不变。无 API、CLI、MCP 或数据库结构变更。
