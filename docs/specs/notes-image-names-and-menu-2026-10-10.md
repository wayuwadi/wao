# 小记图片名称与操作菜单

来源：小记分享 `7baa05b08e644efa99babd1f413d1a38`，2026-10-10。同一需求包括易读名称、自定义改名、菜单精简和复制操作字体一致。

## 名称与保存

- 图片引用和图片清单保留有意义的名称；空名称、通用 `image.png`、哈希、飞书附件和剪贴板自动文件名显示为「图片 N」，N 按正文中的图片顺序计算。
- 显示降级不写回已有正文、不改原图地址、不上传替代图片。名称保存沿用图片节点的 `alt` 和 Markdown 图片描述，无新增接口或权限。
- 编辑时右键图片／引用，或点击图片清单中的名称；输入名称后按 Enter 或点击对勾确认。名称随当前小记草稿保存，可撤销；明确提示仍需随小记保存。长名称单行省略，悬浮可看完整名称。
- 名称不超过 120 个字符，空名称回到默认编号；更新前核对当前选中节点与图片地址，位置变化时保留输入并提示重新打开。同一地址出现多次时，只更改选中的那一个节点。
- 阅读模式保持只读，不引入隐式自动改名。Markdown 序列化转义名称中的反斜杠和方括号，保留图片地址、尺寸、缩进、说明和正文。

## 菜单

- 默认呈现名称、全屏查看、单张／全篇范围、百分比、独占／并排及两个复制操作。
- 「更多尺寸与布局」默认折叠，包含固定像素尺寸、统一本篇图片高度和恢复原尺寸；保留原有范围、校验和撤销语义。
- 正文菜单宽 232px，外壳沿用 `ImageCopyMenu` 和现有圆角、阴影、主题 token；正文与复制操作继承相同 13px 字体。窄屏受视口宽高约束，展开后重新定位，内容可滚动。

## 验证

检查机器名称降级但不改数据、重复图片单独改名、撤销和 Markdown 重载、图片清单的改名入口与只读状态、旧尺寸和复制行为。以合成小记连接现有 WAO 数据验证编辑、保存、重新打开，并回收仅本次创建的验收内容。浅色／深色和 320／390px 为浏览器验收，不代表实体 iPhone 验收。
