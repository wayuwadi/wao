# Phase 1：网页端 WAO AI 宠物

对应任务：`t1787809149409`（把右下角「问问 AI」升级为网页端宠物，并承载 AI Run 与待办提醒）。

后续由宠物承载的“今日节奏”真实快捷记录见
[网页宠物今日节奏快捷动作](phase-1-web-ai-pet-rhythm-actions.md)。

## 用户路径

1. 登录后的 WAO 应用壳右下角展示品牌浣熊宠物，替代原来的紫色「问问 AI」胶囊浮钮；公开分享页和登录页不展示。
2. 点击宠物会播放一次基础互动动作并展开快捷操作，不再打开 WAO AI 问答工作台；问答继续由顶部入口和 `Ctrl/⌘ + J` 快捷键承载。
3. 宠物上方轮播真实任务提示，优先顺序为待验收、AI 进行中、待办；点击提示直接打开对应任务详情。
4. 提示随应用壳既有 `/api/tasks` 轮询更新，不新增演示数据、随机事件或第二套 AI Run 状态源。
5. 宠物状态点继续来自 `/api/assistant/status`：可用时显示在线，不可用时给出真实状态说明，问答入口仍保留在顶部。
6. 宠物空闲时会间隔播放伸展、蹦跳、左右探步等轻量基础动作；拖动、展开操作或系统要求减少动态效果时不播放。

## 状态与降噪

- 任务尚在加载时显示「正在读取任务动态」；读取失败时显示「任务动态暂时不可用」，不能把失败伪装成没有提醒。
- 同一时刻只展示一条提示，每 7 秒切换；待验收优先于执行中，执行中优先于普通待办；切换时仅淡入淡出，气泡本体不跳动。
- 提示使用带指向尾巴的对话气泡样式；非任务提示点击后只与宠物互动并打开快捷操作，不再作为 AI 入口。
- 提示包含真实任务数量与首条任务标题；标题过长时视觉截断，但按钮的辅助说明保留完整标题。
- 没有待验收、执行中或待办时，显示与助手在线状态一致的安静提示，不制造虚假事件。
- 尊重系统的减少动态效果设置；默认位置在桌面避开音乐入口，窄屏时同时避开音乐入口、底部导航与「新建任务」按钮。

## 验收

- 待验收、AI 进行中和待办同时存在时，宠物先显示待验收并可直达该任务，随后按顺序轮播其余真实状态。
- 任务状态被后台轮询更新后，提示数量、文字与目标任务同步变化。
- 任务读取失败、助手离线、长标题、窄屏和减少动态效果下仍能看清状态并完成对应操作。
- 点击宠物及非任务气泡不会打开 WAO AI；顶部入口和快捷键仍打开原有工作台，历史会话、来源筛选和只读安全边界不变。
- 页面不再显示宠物下方的“WAO AI”标签；点击与空闲基础动作不会妨碍任务气泡、拖动和快捷操作。
