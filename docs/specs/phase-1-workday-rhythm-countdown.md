# Phase 1：今日节奏倒计时项目

对应任务：`t1788399151206`。基础每日面板见
[今日节奏每日面板](phase-1-workday-rhythm-daily-dashboard.md)，数据与交互决策见
[ADR-194](../adr/194-workday-rhythm-countdown-items.md)。

## 用户结果

1. 成员在「调整每日节奏 → 每日必做」新增自定义项目时，可在普通打卡与倒计时之间选择；倒计时保存 1—1440 分钟的固定时长。
2. 倒计时项目在当天清单中显示剩余时间，支持开始、暂停、继续和重置；刷新或换设备后从服务端保存的状态继续，不因浏览器后台降频而延长。
3. 固定时长走完后，项目自动记为完成并显示明确结束反馈；倒计时未走完不能用普通勾选绕过。
4. 已生成的每日实例保留当日类型与时长快照，之后修改模板不改写已经完成、或已经投递提醒的历史事实。
5. 既有系统联动项与自定义普通打卡保持原行为；系统联动项不能改成倒计时。

## 验收

- 新增一个每天执行的 20 分钟倒计时，保存并刷新设置后仍显示“20 分钟倒计时”。
- 在今日节奏点击开始，页面逐秒递减；暂停后刷新不继续扣时，继续后刷新仍按真实经过时间恢复。
- 倒计时归零后自动完成并出现结束提示；重置后恢复完整时长且可再次开始。
- 390px 窄屏可以查看剩余时间并操作开始、暂停和重置，不产生业务区横向滚动。
- 普通打卡仍可完成与撤销，已有模板和实例通过数据库默认值兼容为普通打卡。
