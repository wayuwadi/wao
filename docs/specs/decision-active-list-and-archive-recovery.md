# 决策有效列表与废止失败恢复

落实个人决策管理原规格的“默认仅显示有效决策”，不修改废止接口或历史保留方式。

- 读取默认列表和搜索结果时显式传入 `state=active`，避免把已废止记录继续标为确认决策。
- 废止请求失败时，原处保留对象名称、错误原因、重试与重新加载核对入口；网络错误不武断宣称服务端一定未执行。
- 废止已确认成功后，先移除该对象，再刷新列表；列表刷新失败不能使已确认废止的对象重新显示为有效。
- 同一时间只执行一次废止操作，处理中暂时禁用卡片编辑和废止入口。
- 完整历史仍通过记忆中心查看；本次不会删除历史版本。

验收包括显式有效状态参数、废止失败后重试、成功后刷新失败，以及真实记录从有效列表消失并在记忆中心保留为已废止。
