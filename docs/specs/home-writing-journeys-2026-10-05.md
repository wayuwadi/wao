# 首页写点东西与三场随机写作入场

2026-10-05。用户确认三套交互预览全部实现并直接公网部署。

- 首页「休息一下」旁新增一个「写点东西」按钮，不增加常驻面板或选择菜单。
- 每次点击随机播放「伙伴的秘密写作室」「把首页翻成一本书」「抓住那个小念头」之一；同一页面生命周期内避免连续重复。四个伙伴沿用蓝色小画家、黄色眼镜、粉色墨镜、绿色青蛙的形象。
- 完整入场约 6 秒，提供「直接去写」与 Esc 等价快捷操作。追逐动画可主动接住停留的小念头；不点击也会自动完成。
- 成功进入现有 `/notes`，展开记录区，等真实编辑器与成员草稿就绪后把光标放到正文末尾。不写入示例、不创建文档、不更换草稿 id、不改变保存与自动整理流程。提示文案只作为空编辑器占位。
- 入场浮层首次渲染即覆盖视口，阻止背景操作并循环键盘焦点；切换标签隐藏时暂停，返回后继续；系统减少动态效果时直接抵达。离开路由或卸载时释放帧循环、事件、背景 inert 与滚动锁。
- 导航被拒绝或失败时保留首页与草稿，提供重试及返回，不反复自动跳转。普通访问小记或刷新不触发入场或抢焦点。
- 支持窄屏、短屏、深色主题与触屏；首页现有泡泡、长按与右键随机互动继续保留。

本次仅浏览器组件、入场状态与编辑器焦点交接变化，没有业务 API、数据库、CLI 或 MCP 能力变化。
