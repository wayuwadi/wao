# 首页四等分信息卡片

用户确认将今日卦象、Codex 周剩余额度、Pro 到期时间、重置卡融合为一张轻量卡片，桌面四等分、窄屏 2×2。保留天气与休息入口。

- 卦象沿用真实今日卦象接口和天人一卦详情路由，覆盖加载、失败重试及空状态。
- 额度与重置卡复用仍有效的 `/api/codex-memberships`，仅使用 `codex` 通用限额中 10080 分钟的周窗口；不调用已下线的 AI Run / evolution 接口，不恢复 Runner。保留的旧数据标记历史快照，刷新仅重新读取现存数据。
- 多账号不合计额度或卡数，摘要展示账号数量，详情分别列出账号、剩余比例、重置时间、同步时间和重置卡数量。无记录不伪造 0。
- Pro 到期日与无官方数量时的手工卡数沿用原首页个人 `codex-benefits-v1` 记录；到期日标明手工来源，完整日期、剩余天数、当天及过期状态均可见。它不是账号共享会员日期。
- 详情默认收起但权益编辑器保持挂载；复用原保存、失败重试、成员隔离、本机草稿及恢复语义。摘要只展示已保存数据；后台读取不覆盖表单草稿。关闭按钮、点击外部及 Escape 均可收起，键盘关闭返回原入口。
- 此次仅调整浏览器展示，没有新增服务、接口或权限，不涉及 MCP / CLI 能力变化、ADR 编号或数据库 migration。

验收覆盖真实数据卡片与详情、历史数据和多账号语义、权益草稿收起重开、读取失败重试、桌面四等分及手机 2×2。
