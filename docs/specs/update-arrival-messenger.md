# 新功能来敲门：版本到达提醒

2026-10-03，用户确认交互 Demo，并要求动效时间更长、幅度更大，形成有辨识度的产品体验。本规格替代 `update-entry-highlights-2026-10-02.md` 中「不自动展开」的行为，保留不抢焦点和草稿保存屏障。

- 检测到不同于当前页面的新版本，自动展开更新内容。工具入口光圈与图标敲动、卡片弹性展开、微笑信使眨眼及星屑组成约 10 秒的登场，随后静止；尊重减少动态效果设置，无声音、无自动刷新。
- 自动展开不抢正在编辑的焦点。后台标签页先记住新版，回到前台后再展示。相同目标版本不反复弹出；会话存储只记最近已提醒版本，存储失败不影响当前页面内去重。
- 稍后、外部点击、Esc、路由变化收起弹层并停止动效，工具入口保留「可更新」。工具内的更新记录可重新打开，不重复播放登场。用户主动打开才聚焦关闭按钮。
- 清单读取、目标版本匹配、连续版本响应失效保护沿用现有实现；只展示真实目标清单。缺失、错误、正在加载均有明确状态；保留自动 Git 更新内容与当前制品功能入口。
- 「保存并刷新」继续通过工作区、表单和 beforeunload 保存屏障。保存中停止动效、禁用刷新和收起；失败留在当前页、保留草稿与目标版本，可重试。刷新后沿用既有更新介绍。
- 弹层首次渲染前定位。窄屏菜单未打开时，其隐藏按钮不能充当定位锚点，改为视口右上角；内容内部滚动，操作区保持可见。短屏压缩插画及抬头，触屏按钮保持可点区域。

仅浏览器表现与状态变化，不新增业务接口、数据库、MCP 或 CLI 能力。旧标签页需先加载此版本，后续版本到达才会使用新动效。

验收覆盖主动展开与焦点、同版去重、前后台切换、动效结束/卸载清理、减少动态效果、隐藏锚点定位、清单竞态、草稿保存失败/重试、320px 和短屏。

补充保存屏障：小记编辑器注册刷新前保存，包含已收起但仍挂载的快捷小记；正在保存或保存失败时阻止刷新，原输入保留。复用既有保存接口，不新增数据操作。

本地真实链路验收：专用验收小记在模拟保存接口 503 时保留正文及当前页，恢复连接后重试保存、刷新并在小记列表回读正文。320×740 与 740×360 视口验证弹层边界、内容滚动及底部操作区；未进行真机软键盘验收。
