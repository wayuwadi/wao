# Phase 1：可配置的左下角图标链接

## 目标

WAO 侧边栏左下角只保留一个“链接”入口，集中承载 Jenkins、桌面宠物、GitHub 等跨系统入口。成员以后可在
“设置 → 左下角链接”自行新增、编辑、删除和排序，不再因为增加一个图标链接修改代码或重新发布。

Jenkins 不属于自动化任务业务本身，因此从自动化页面移除，默认指向受 WAO 会话和 Jenkins 登录双重保护的
`/jenkins/job/wao-main-cd/`。

## 数据与兼容

- 配置继续使用按成员隔离、跨设备同步的 `member_preference`，键为 `quick-links`。
- v2 保存 `{ version, links }`，每条包含稳定标识、名称、描述、Remix Icon 类名、地址和搜索关键词。
- 旧版数组首次读取时补齐原来写死在侧边栏的桌面宠物入口和新 Jenkins 入口；用户保存为 v2 后，明确删除的
  默认项不得再次恢复。
- 没有配置或配置损坏时展示安全默认值，并在设置页和弹层提供错误提示与重试，不使用损坏内容跳转。

## 安全与验收

- 站内地址必须以单斜杠开头；站外地址只允许无内嵌账号密码的 HTTPS URL。
- 标识必须唯一，图标类名只允许 `ri-` 开头的字母、数字和中划线，最多保存 20 条。
- 保存失败时保留当前编辑草稿和上一次成功加载的左下角入口，不用未落库内容冒充已保存。
- 默认弹层同时出现桌面宠物和 Jenkins；自动化页面不再出现 Jenkins 卡片。
- 设置修改保存后当前页面立即刷新，其他设备下次加载同一成员偏好时取得相同配置。
