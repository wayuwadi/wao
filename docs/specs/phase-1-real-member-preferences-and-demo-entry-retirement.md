# Phase 1：成员偏好真实生效与演示入口退役

需求来源：WAO 任务 `t1787800163678`。

## 用户结果

- 设置 → 偏好可按当前登录成员保存“每周起始日”和“庆祝动画”，刷新、换设备后仍读取服务端值。
- 周起始日立即影响日历周/月布局；庆祝动画立即影响任务、项目创建及任务完成反馈，选择动画时现场预览。
- 保存中不可重复提交；保存失败恢复服务端原值并提供原位重试，不把未落库值显示为已生效。
- 管理员可在组织与成员页用姓名、邮箱和初始密码创建真实成员账号；界面明确表达“创建账号”，不伪装成尚不存在的邀请邮件流程。
- 任务详情可从真实成员目录增加或移除参与人，结果进入任务自动保存链路。

## 演示入口收口

- 当前没有第二套完整界面翻译资源，因此移除可点击的语言切换占位；页面如实说明当前只提供简体中文。引入第二种语言时必须覆盖完整用户链路后再恢复选择器。
- 项目详情不再展示只有历史名称和大小、没有稳定文件 id 的“文件”页签；真实文件仍从文件库上传，并可在任务附件中关联和下载。
- 全局搜索只声明并执行当前真实的项目、任务和文档文字匹配；删除没有模型或向量检索调用的“语义理解”演示状态。
- 自动化列表只显示服务端返回的真实运行记录与耗时；没有耗时数据时显示“—”，不根据行号生成秒数，也不补不存在的历史运行圆点。
- 测试中的 Mock、明确限定于本地 profile 的开发账号与测试样本不属于生产演示数据，不从测试体系删除。

## 数据与权限

- 成员偏好继续复用 `/api/preferences/{key}` 和既有 `member_preference`，不新增 migration。
- 创建成员复用 `/api/members/accounts`；服务端继续执行管理员权限、邮箱唯一性与密码长度校验，浏览器不保存初始密码。
- 任务参与人继续保存在任务 `detail_json.parts`；不新增成员关系表或绕过项目可见性。

## 验收

- 偏好读取、保存、失败回滚、重试及登录成员切换有前端自动化测试。
- 成员账号创建、目录刷新及服务端权限边界有自动化测试。
- 任务参与人增删有组件测试，项目文件和语义演示入口不再出现在生产界面。
- 合并后确认 main 部署成功，并用登录账号验证设置页真实保存与刷新恢复；不为验收创建不可回收的生产成员账号。
