# 知识库目录默认展开与批量开关

知识库每次进入默认展开所有文件夹，包括从其他页签切回保留的知识库页面。目录标题右侧增加单个“折叠全部／展开全部”切换按钮，保留定位当前文档入口。

- 全部展开时提供折叠全部，否则提供展开全部；空目录禁用。
- 批量开关只改变展示，不改变当前文档、正文、收藏或持久化目录顺序。
- 搜索期间继续展示匹配文档，不因折叠隐藏搜索结果；退出搜索恢复手动开关状态。
- 当前文档切换或移动到其他文件夹时仍展开所在文件夹，普通数据刷新不反复打开用户收起的目录。

本规格替代既有首次默认收起约定，不涉及接口或数据库。

## 目录行与拖拽

侧栏目录使用固定的展开位和统一层级缩进，整行显示悬停和当前文档状态；操作按钮悬停或聚焦时浮在行末，不挤压标题。每行 38px，长标题省略并提供完整标题提示。

拖拽到节点上方或下方时放在同一父级的相应位置，拖到行中间时作为该节点的子项；拖动分组到顶层投放区可移回根目录。上方、下方用线条指示，中间用整行边框指示；自引用、移入后代及文档移到根目录不可投放。搜索结果不允许拖动，避免隐藏节点造成顺序误判。成功后同层顺序随目录关系一并持久化，刷新仍一致；失败保留重试入口。MySQL JSON 对象键不保持用户次序，完整节点顺序存入既有目录快照中的保留字段 `__order`，对外以 `directoryOrder` 数组提供，旧目录仍按原有顺序显示。
