# 规格：小记使用完整文档编辑能力

本规格扩展小记集中记录空间的输入能力，替代精简模式限制。

- 新建与编辑小记复用文档高级编辑器，开放一级标题、表格、代码、公式、图表、画板等内容块，以及链接维护、图片调整和附件上传。
- 选中文字可润色；沿用文档的原文对照、明确确认替换、失败重试及旧选区保护。确认后的内容进入现有富文本草稿和显式保存链路。
- 图片和文件必须上传成功才插入；断线、超限与上传失败明确提示，正文仍保留。
- 继续沿用成员隔离草稿、富文本 JSON、幂等新建和 expectedRev 冲突保护，不改接口及数据结构。

验收：小记中选择正文、润色、确认替换、保存、重新编辑验证结果；完整工具栏和内容块可用；既有草稿、标签、失败重试、冲突及全屏回归通过。
