# 项目表格可见字段

默认显示标题、优先级、状态、负责人、计划开始和截止日期，让常用任务内容在一般桌面宽度中可读。ID、分组、创建者、创建日期通过显示设置按需展开。标题必须显示，其他字段可自选；提供「常用字段」和「全部字段」快捷配置。

字段选择按本浏览器账号和成员保存，跨该成员的项目复用；保存失败说明当前调整仅临时生效。成员切换不带入其他人的选择。既有排序、分组、完成显示和正在编辑的行内输入保持；主任务与内嵌子项使用同一可见字段，添加与错误行跨度同步，不出现错列。

不改任务数据、权限、API、CLI/MCP。窄屏保留表格内部横滚。验证常用默认、完整字段、父子行对齐、字段与成员切换、行内输入和存储失败。
