# 任务入口默认项目的一致性

补充 `phase-1-system-function-optimization.md` 新建任务默认项目段和 `todo-recent-project-2026-10-06.md`：普通任务新建与待办快速添加统一优先级为已有草稿、入口明确当前项目、成员指定默认项目、最近成功创建所用项目。待办没有当前项目上下文。

只有当前可见且未完成的项目有效；草稿项目失效时保留标题并要求重新选择，不偷偷改归属。没有有效候选时明确显示选择项目，取代旧首个项目回退。派生任务仍不自动带入默认或最近项目，必须确认归属；明确入口和草稿可恢复。

读取项目与默认偏好稍晚完成时，仅补齐尚未手选、尚未开始输入的默认值，不覆盖手选、草稿或保存中的输入。成员切换和失效项目要隔离并清理无效选择。两个入口都只在服务端确认创建成功后更新该成员最近项目，失败不记忆、不重复创建。

本需求暂沿用最近项目的本浏览器成员存储；跨设备同步在后续独立需求处理。不更改 API、数据库、CLI/MCP。
