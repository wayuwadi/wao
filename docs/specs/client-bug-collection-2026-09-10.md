# 客户端 BUG 收集修复

来源：共享任务 `t17890254379610`，2026-09-10，共 14 条。本任务作为一个 PR 交付。

## 最终行为

- 项目空列和已完成列按项目记住展开状态。开始拖拽不改变列数量、宽度或位置；折叠的空列在看板下方提供始终可用的紧凑拖放目标。
- 聊天内同源任务分享链接直接打开任务抽屉，外部链接和组合键行为保留。聊天入口处于正常顶栏布局，任务抽屉不会被高层级悬浮按钮遮住。
- 外壳去掉重复品牌标识，顶栏由 64px 收紧到 40px，业务栏随之上移。更新后启动主动显示并恢复主窗口，保留 NSIS 更新器已有 `/R` 重启协议。
- 刷新不再弹出常规确认。先结束当前输入、等待任务与文档保存、调用注册表单的保存流程，再刷新。保存冲突、失败或剩余未保存表单均保持页面并提示处理。聊天等未发送内容保持本地草稿，不因刷新而发送。
- 仅桌面工作区缓存成员隔离的白名单读接口，任务 10 秒、项目与知识库 30 秒、目录 60 秒。失效后查询服务端；业务写入和退出清除缓存；请求失败不缓存、不将旧数据当成实时结果。并发读取合并但返回独立副本。
- 宠物不再展示悬停操作菜单、未读角标和重复关闭按钮；点击打开聊天、拖动调整位置。系统任务动态变化仅提示一次，8 秒后消失，不循环播放。
- 聊天消息只出现“有新消息，点击查看”，不显示作者、正文或快速回复表单，同一消息不重复提示。原快速回复草稿不会删除。
- 客户端独立透明置顶宠物窗口随启动打开，业务页面隐藏重复宠物。消息点击唤起原工作区聊天，不在宠物内部叠加聊天窗口；主窗口收起不影响桌宠。
- 聊天渲染图片提供右键复制 PNG；图片未加载、剪贴板权限或跨域失败明确提示，不伪报复制成功。

## 验收记录

本地验证已通过：10 个相关 Web 测试文件共 44 项、客户端 17 项（另 1 项既有环境测试跳过）、Rust 5 项；Web 类型检查与生产构建、客户端构建通过。覆盖任务/子任务链接、图片复制剪贴板调用、拖动布局与动画、消息提示去重、缓存过期/隔离/失效、保存失败保护。

实际页面验收受阻：Codex 浏览器新建标签和恢复后导航均在 30 秒超时，停留空白页；本机原生 UI 控制不可用，不能执行 Windows 更新后恢复及桌面窗口交互。没有将测试替代这些验收。发布 SHA、构建和清单证据发布后补充，任务保留待验证。

本规格调整 ADR-222 的常规刷新确认和 ADR-227 的宠物快捷回复/多按钮交互。原历史规格保留。
