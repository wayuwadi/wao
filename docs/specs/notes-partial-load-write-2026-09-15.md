# 部分数据超时时保持小记可保存

## 用户结果

- 首页出现“部分数据加载失败”时，已经成功连接的会话继续允许新建、编辑和重试保存小记。
- 领域、项目、任务或其他独立列表的超时仍在对应页面明确展示，不伪造成功数据，也不清除已有内容。
- 所有启动接口都失败或登录失效时继续禁止假保存，小记正文保留在本机草稿中等待原地重试。

## 实现边界

启动阶段的读取接口都要求登录，任一请求成功即可证明当前会话和后端可达。全局写入可用状态不再要求领域、项目、任务三项全部在十秒内返回；项目与任务同时拿到真实快照后才启动后台合并轮询，单项失败时保留当前数据并等待重试。

## 验收

- 模拟项目接口十秒超时、其他启动接口成功，页面保留项目错误提示，小记仍调用真实保存路径并清除已成功提交的草稿。
- 模拟全部启动接口失败，写入保持禁用且正文不丢。
