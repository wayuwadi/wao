# 首页 Codex 权益记录

## 用户结果

- 首页周额度卡片同时展示当前成员的重置卡数量、Pro 到期日期及按本地日历日计算的剩余天数；当天显示“今天到期”，过期显示已到期天数。
- 周额度继续来自现有自动同步链路；重置卡和会员到期日为用户维护的权益记录，在编辑区明确标注。读取不到时显示未设置或读取失败，不伪造零张或会员有效。
- 卡片内直接编辑数量和日期，允许清空；数量为 0–9999 整数，日期必须有效。保存后立即显示并跨设备恢复，续费或使用重置卡后可以再次修改。
- 七天内到期使用强调色，并用“让额度变成成果”提示将剩余权益用于实际任务。不自动兑换重置卡或执行续费。
- 编辑草稿按成员隔离保存到本机，收起、刷新或保存失败后可恢复；保存中禁用字段与重复提交，成功后清除草稿并显示已保存。服务器读取和成员切换不能覆盖正在编辑的其他成员草稿。

## 数据与兼容

- 复用 `/api/preferences/codex-benefits-v1` 和 `member_preference`，值为 JSON：`resetCards: number | null`、`proExpiresOn: YYYY-MM-DD | null`；无需新增数据库结构。
- 用户的实际数量及日期通过登录后的页面保存，不写入通用代码、默认值或 migration，不影响其他成员。
- 额度快照暂不可用时仍保留权益卡片和编辑入口。

## 验收

- 组件测试覆盖真实保存语义、失败重试、刷新恢复草稿、成员切换隔离、读取失败、清空以及日期到期边界。
- 完成前端类型检查、构建及首页回归测试；上线后在登录成员首页保存用户指定值并刷新验证。
