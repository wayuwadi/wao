# 规格：个人英语单词记录与复习

对应任务：`t1786518037520`（英语单词记录，遇到不认识的单词时复制到 WAO，方便以后回顾和学习）。

## 目标与边界

- 「单词本」是个人模块，所有记录按当前登录成员隔离；关闭登录保护的本地环境使用 `wg`。
- 收集入口优先服务于工作中看到陌生词后的快速粘贴，不要求先填写释义或完成复杂表单。
- 当前系统没有可靠的官方词典或翻译接口，因此不自动生成、猜测或用演示数据填充释义。用户记录自己的理解和原始语境。
- 支持英文单词和短语；内容必须含英文字母，去掉首尾与连续空白后不超过 128 个字符。

## 收集与去重

- `POST /api/vocabulary` 写入当前成员的单词本。
- 同一成员的内容按「忽略大小写、合并连续空白」去重。重复粘贴不新建记录，而是将 `encounterCount`
  加一，更新最近遇见时间并移到列表顶部。
- 收集输入从第一处修改起写浏览器草稿；只有服务端确认成功后才清空。失败保留输入并提供重试。
- 不同成员可以各自记录同一个词，数据互不可见。

## 学习笔记

- 每条记录支持个人释义（最多 1000 字符）、语境笔记（最多 2000 字符）和状态：
  `LEARNING`（学习中）或 `MASTERED`（已掌握）。
- 编辑内容立即写本机草稿；用户显式保存到服务端。保存中、已保存、失败与重试均有可见状态，失败不丢草稿。
- 支持按状态筛选，并可在单词、释义、语境中搜索。
- 删除一条记录必须经过确认，并只作用于当前成员。

## 主动复习

- 从学习中记录开始复习；先只展示英文，用户主动回忆后再揭示自己的释义和语境。
- 用户以「还要再学 / 这次记住了」完成本轮。服务端原子增加 `reviewCount`、记录最近复习时间，
  并分别将状态保存为 `LEARNING` / `MASTERED`。
- 只有服务端确认后才退出复习卡；失败时保留当前卡片并提供重试。

## 移动端

- 390px 宽度下收集输入与按钮均可见，触控按钮不低于 42px。
- 概览和复习入口排在单词列表上方；列表与详情纵向排列，不产生整页横向滚动。
- 复习卡使用视口内弹层并可滚动，窄屏上释义、语境和两个自评按钮始终可达。

## 验收

- 首次粘贴 `resilient` 后列表立即出现；刷新页面记录仍在。
- 再粘贴 `Resilient` 不生成第二条，遇见次数变为 2。
- 填写释义和语境后刷新仍存在；模拟保存失败时草稿仍在且可重试。
- 开始复习时先看不到笔记，揭示后选择结果，复习次数加一且掌握状态对应变化。
- 两名成员分别访问接口时，只能列出、修改和删除自己的记录。
