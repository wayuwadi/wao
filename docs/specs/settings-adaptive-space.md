# 设置页内容宽度分层

后续设置分类与常用入口调整见 [设置页：常用优先与左右分类](settings-common-first.md)，本页记录的宽度分层继续适用。

2026-10-03，按用户确认的整体空间 Demo 实施。设置导航从224px收至184px，正文横向内边距24px。成员列表、导航、AI账号、AI能力、版本记录使用最大1420px；其余简单表单保持860px上限。手机仍为可横向浏览的导航和单列正文。

只修改布局，不改变权限、字段、保存、草稿、HTTP、CLI或MCP。不存在数据时如实显示，不补充演示条目。

本地真实验收：5247连接既有18080服务，1912px下成员和导航内容1420px，个人资料860px；390px下成员、导航页面没有横向溢出，页签切换可用。没有为布局验收创建成员或修改账号资料。

重跑：打开设置，依次切换组织与成员、个人资料、我的导航；检查1912和390px，确认列表和普通表单宽度不同。`npm --prefix wao-web run build`类型检查与构建通过。纯可逆布局调整不新增镜像实现的单元测试。
