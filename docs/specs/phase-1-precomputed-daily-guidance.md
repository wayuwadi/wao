# Phase 1：首页每日建议提前准备

对应任务：`t1786627382418`。

> 2026-08-28 状态：预生成机制已由 ADR-151 重新用于成长教练；本页关于首页旧建议文案与缺失态仅重新读取的描述不再适用。

## 用户结果

1. 每日建议在成员进入首页前由后台定时任务生成并保存，不把 Codex 生成等待放到页面加载链路。
2. 首页只读取当天已保存结果；缺失时说明后台正在准备，不自动发起实时生成。
3. 同一标签页刷新先展示按成员隔离的当天会话缓存，再静默校准服务端结果，不重复出现生成等待态。
4. 用户明确点击“换一组”时仍可主动生成；失败保留原建议并可原地重试。
5. 预热继续使用真实成员任务、项目和只读 Codex Runner，不生成静态建议或演示数据。

## 验收标准

- 只有主节点启用 `WAO_DAILY_GUIDANCE_WARMUP_ENABLED=true`，从节点默认关闭。
- 主节点启动两分钟后执行首轮预热，之后每三十分钟补齐全部成员缺失的当天缓存，已有缓存不调用 Codex。
- 单个成员失败不影响后续成员，Runner 恢复后可由下一轮补齐；同一时刻至多执行一批预热。
- 长耗时预热使用独立单线程执行器，不占用 Spring 默认调度线程。
- 首页收到 `missing` 时不调用 `POST /api/daily-guidance`，只提供重新读取入口。
- 当天 `ready` 结果写入按成员隔离的 `sessionStorage`；刷新时可在服务端请求返回前展示，过期结果不使用。
