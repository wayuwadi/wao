# Phase 1：任务关联人工 HTML 与显式解除

对应任务：`t1788398094365`（关联里面）。本规格扩展
`phase-1-task-links-and-mobile-polish.md` 的任务关联类型与解除交互；原有知识、任务和普通文件行为保持不变。

## 用户结果

1. “关联到任务”选择器提供独立的 HTML 页签，候选来自用户已经手动上传的真实托管页。
2. 关联结果随任务持久化，刷新后仍可从任务详情打开同一份托管 HTML。
3. 已关联的普通文件、知识、任务和 HTML 在任务详情中都有明确的“取消关联”按钮，不要求用户重新搜索候选。

## 数据与失败边界

- HTML 关联只保存 `hosted_page.id` 到任务详情 `hostedPages`，不复制正文，不把托管页伪装成 `file_blob`。
- 选择器只列 `MANUAL_UPLOAD`；AI Run 报告继续通过执行档案查看，不混入人工文件候选。
- HTML 列表沿用当前成员可见项目范围；读取中、读取失败和空列表均给出真实状态，失败时可以重试且不改动既有关联。
- 托管页被删除或暂时不可见时，任务保留可解除的失效关联，不伪造可打开地址。

## 验收

- 上传一份 HTML 后打开任务关联选择器：HTML 页签能找到该页面，AI Run 报告不在候选中。
- 关联该 HTML 并刷新任务：任务详情仍显示它，点击可打开相同的公开托管页。
- 分别点击已关联普通文件和 HTML 的“取消关联”：保存完成并刷新后，两项都不再出现。
- 模拟 HTML 列表读取失败：选择器显示失败和重试入口，任务原有关联不丢失。
