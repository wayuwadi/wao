# 会话检查失败的连接恢复

对应审计 A10。沿用统一账号规格：身份由服务端会话确认，未登录由 HTTP 401 表达。

## 用户结果

首次进入受保护地址时，连接失败或服务端故障不再被解释为退出登录。页面说明尚不能确认身份，保留原目标地址并提供重连。重连期间避免重复请求，成功后回原地址（包括查询参数）；真实 401 仍走既有登录路径。

## 实现边界

Session store 区分已确认与连接错误，共享在途请求，失败后允许重试。路由守卫在连接错误时进入独立公开恢复页，未确认身份时不渲染受保护内容，不扩大权限、不读取本机身份替代服务端会话。不涉及已有页面编辑状态、后端认证、Cookie 或成员权限变更。当前初始化只在首次进入执行，运行期间业务请求的连接恢复仍由各页面负责。

## 验收

针对测试覆盖网络失败重试、401未登录、403不误判、并发去重与恢复原查询地址。类型检查和生产构建通过。本地前端连接真实数据库：临时代理仅阻断会话检查返回500，访问待办带查询参数进入连接恢复页；解除阻断并重连后回原地址且显示真实登录用户。没有退出登录、修改凭据或写入业务数据。
