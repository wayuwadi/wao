# 项目四象限扩大任务空间

2026-10-14 用户要求删除项目四象限上方圈出的项目计数筛选区，为四象限腾出空间。

- 四象限视图不渲染「项目计数／全部／待验证／等待反馈／逾期」快捷筛选行；表格、看板、分组沿用既有筛选。
- 进入四象限时清除快捷状态条件，避免隐藏的条件继续排除任务。负责人、创建人和关键词条件仍沿用原有行为。
- 项目四象限内部工具栏没有内容时不占位；个人顺序读取、保存、失败重试和已完成展开按钮出现时仍保持可见。
- 四象限利用释放的剩余高度，任务内部滚动、放大、批量选择及窄屏布局保持原有行为。无 API、数据、权限或部署流程变化。
- 窄屏工具栏按内容高度换行，不将横向布局的 `flex-basis: 100%` 用作纵向占满高度，保证四象限保有可用空间。

本规格补充 `project-action-filters-2026-10-03.md` 和 `project-task-quadrants.md` 的项目四象限布局约定。

验收：相关 5 个测试文件共 35 项通过，类型检查、生产构建和 UI 增量检查通过。本地连接既有数据库，在「一起做事的点子」的四个真实任务上验证计数区移除、工具栏空位消失、状态条件清除、键盘放大还原；明暗主题的 1920／390／320px 均能展示四象限且没有页面横向溢出。浏览器无页面脚本异常。
