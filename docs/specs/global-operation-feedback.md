# 全局操作提示可感知与可关闭

对应审计 A09/B18，共享壳层改动，不修改各业务模块内部。

- 既有信息/成功提示保持 2.6 秒；鼠标停留或键盘焦点在提示内时暂停，离开后继续剩余时间。
- 既有明确错误图标 ri-error-warning-line / ri-close-circle-line 默认成为持久错误；新调用可显式指定 tone 与 duration。普通图标不通过文案猜测错误。
- 每条提示提供键盘可操作的关闭按钮；普通反馈用 status，错误用 alert，装饰图标隐藏，文本可换行，列表可滚动，遵循减少动态效果偏好。
- 切换账号清空提示与计时器，不把上一账号操作内容留给下一账号。
- 错误提示只说明操作结果，不执行自动重试；关键流程仍应在页面原位保留输入和恢复入口。未声明错误语义的旧调用后续按具体流程迁移。

验收：191 个文件、1117 项前端测试通过（4 workers），类型检查与构建通过。本地真实数据库文件库→空托管表单→校验失败：错误持续超过原2.6秒、可见关闭符号、Enter关闭、返回原表单均通过；未上传或发布任何内容。已验证可访问树语义，未进行实际读屏软件测试。全量首次运行另有任务草稿用例不稳定，单测、主分支对照与最终全量均通过，未修改该业务模块。同步更新此前通知与嵌入状态变更遗留的两处文案断言。
