# Phase 1：全量导航中心与高频侧栏

## 用户结果

1. 登录成员在首页后的固定“导航”入口中，可以找到 WAO 全部仍可用的原生功能、已注册外部应用和自己的快捷链接。
2. 功能即使从侧栏隐藏，仍会留在导航中心并可直接打开，避免已开发能力因没有一级入口而被遗忘。
3. 侧栏默认只保留首页、导航、项目、聊天、待办、今日节奏、日历、记忆中心和知识库等日常入口；成员仍可在
   “设置 → 菜单配置”改名、换组、排序、显隐和打开方式。
4. 成员可以按名称、用途和关键词搜索目录；窄屏使用单列卡片，不需要横向寻找大量菜单项。

## 数据与兼容

- 原生功能目录由前端稳定模块 id 和分类元数据维护，独立于内置菜单的 `visible` 字段；兼容跳转或已经融合到其它
  页面中的入口不重复展示。
- 外部应用读取 `/api/settings/navigation/external-apps` 的真实注册表，包含侧栏隐藏项；成员快捷链接读取按成员隔离的
  `quick-links` 偏好，不硬编码或展示其他成员数据。
- 内置菜单注册表升级为 v24 并新增稳定 id `navigation`。旧版中仍保持系统默认名称、图标、分组、顺序和打开方式的
  低频菜单迁为隐藏；成员已经改名、换组、调序或隐藏的定制保持不变。
- 注册表或成员偏好读取失败时保留代码安全默认值，页面明确提示并提供重试，不用演示链接补空数据。

## 交互与验收

- `/navigation` 使用 WAO 主壳和独立页签；“导航”默认位于首页之后，桌面与手机均可直接进入。
- 原生功能遵守当前内置菜单配置的名称、图标和 `TAB/NEW_PAGE` 打开方式；外部应用和快捷链接遵守各自真实配置。
- 搜索同时覆盖名称、描述、稳定标识、地址和辅助关键词；无匹配项时显示可清除搜索的空状态。
- 自动测试校验目录覆盖全部非兼容模块、隐藏功能仍可搜索和打开、旧注册表升级不覆盖已有定制。
