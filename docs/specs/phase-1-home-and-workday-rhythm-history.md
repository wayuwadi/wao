# Phase 1：首页表达与今日节奏历史优化

对应任务：`t17871887864620`（系统功能优化&问题修复）中的“首页表达优化”和“今日节奏-优化”。决策见
[ADR-090](../adr/090-home-summary-and-workday-rhythm-history.md)。

## 首页

1. Codex 使用详情不再独占一块首页空间；理念 hero 卡片内展示真实周剩余额度、动态执行槽位和 AI 详情入口。
2. 额度只采用服务端或 Runner 已同步的真实七天窗口；未知、失败和失效数据不显示为 `0%` 或其他占位值。
3. 理念卡片把运行任务、各 AI 工具在线状态、执行槽位和仪表盘入口改为紧凑图标；图标均有悬停说明和无障碍名称。
4. 自主目标输入按当前成员保存本机草稿。离开首页、切换模块或重新挂载后恢复；成功派发才清理，失败继续保留。
5. 页面明确展示草稿已保存或本机保存失败状态，不把未派发输入误报为已保存到服务端。

## 今日节奏历史

1. “历史记录”入口与页面头部“调整节奏”按钮并列，打开后默认读取上海时间当前月份。
2. 成员可以按月查看有真实存档的日期；每天展示当日填写的目标、工作日/休息日状态，以及各精力补给项目执行次数。
3. 累计项目显示实际次数，每天一次项目显示已完成/未执行；项目名称优先使用保存当天的快照，避免后续改名篡改历史表达。
4. 没有保存记录的日期不生成演示或零值记录；整月为空时展示清晰空状态。
5. 历史接口按当前会话成员隔离，日期范围有界；单条损坏记录被跳过时页面显示真实跳过数量并可刷新重试。
6. 历史弹窗首次渲染即固定居中，加载、失败重试、空数据、长目标和 390px 窄屏均保持可用。

## 验收

- 首页真实周额度只在理念 hero 内出现，独立 Codex 大卡片和 AI 页签头部的重复额度均不再渲染。
- 输入自主目标后卸载并重新打开首页，原文完整恢复；模拟派发失败仍保留，成功后本机键被删除。
- 两个成员查询相同月份时只返回各自 `workday-rhythm-day-*` 记录，不能通过请求参数指定其他成员。
- 已保存三次累计项目和一次每天一次项目后，历史分别显示“3 次”和“已完成”，每日目标保持原文。
- 损坏偏好不会变成一条空白历史；页面显示跳过提示。无历史月份显示空状态，不生成假数据。
