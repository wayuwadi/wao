# 恢复重置卡增加飞书通知

2026-09-23 用户明确要求恢复原有通知。本变更对 ADR-227 的站内通知路由作范围明确的补充：仅 Codex 重置卡数量增加，继续向现有默认飞书机器人投递。

- 首次采样建基线；后续同账号数量增加发送账号及前后数量，持平或减少不发送。
- 复用默认 Webhook 注册表、启用状态及系统自动化通知/静默策略，不恢复其他系统消息或飞书聊天同步。
- 飞书返回明确成功码才推进基线；网络失败、异常响应、机器人缺失或停用保留基线，下次采样重试。两节点继续使用数据库行锁去重。
- 已在旧版本消费的历史事件不回退基线或自动重放，避免错误或重复通知；人工补发需按真实事件明确处理。
- 验收涵盖实际 HTTP 请求目标和卡片内容、明确成功/空响应/失败、静默及禁用机器人、跨 Runner 去重与重试。其他额度刷新继续站内通知。
