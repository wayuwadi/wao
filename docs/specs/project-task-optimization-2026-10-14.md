# 项目任务单行、层级拖拽与右键操作

来源：任务 `t17919417670180`，用户确认普通内嵌子事项和完整下级任务均可提升为主任务。

## 浏览器体验

- 共用四象限标题、项目、日期和状态在同一行，长文本省略但保留悬停提示；保存失败允许展开错误与重试。窄屏仍保留四格，可放大象限查看完整元信息。
- 项目表格完整任务拖到行中间挂到该任务下，边缘为前后排序；目标显示浅底或插入线。完整任务整棵树移动，不转换为内嵌子事项。
- 拖动时提供“成为主任务”区域：完整下级任务解除父级；内嵌子事项及其后代原子提升为同项目主任务。保留永久编号、标题、状态、优先级、负责人、日期、创建人和时间、正文、图片、文档关联与评论。提升后复制新任务链接，旧子事项分享地址不自动重定向；历史 AI 记录仍属于原任务，未结束执行阻止提升。
- 内嵌子事项拖到完整任务行上迁移整棵子树；同层子事项个人顺序沿用现有行为。
- 主任务与内嵌子事项支持右键、Shift+F10 和更多按钮：打开、复制分享链接、复制永久编号、添加子任务、移回／提升为主任务、删除。输入和选中文本保留原生菜单。公共浮层限制在视口内，支持方向键、Esc 和焦点恢复。
- 删除先确认：完整任务连同内嵌子事项删除，独立下级任务保留并回到顶层；删除内嵌子事项时其直接后代上移一级。失败保留任务或本机草稿并显示错误。

## 契约与数据保护

- 复用 `/api/tasks/{id}/parent` 与 `/api/tasks/{id}/subs/{subId}/move`；新增 `POST /api/tasks/{id}/subs/{subId}/promote`，请求 `expectedSourceSubs` 为完整读取快照，响应 `ApiResponse<List<TaskDto>>`，顺序为源任务、提升后的主任务。
- 成员可见性在锁前与锁内检查，旧快照返回冲突；迁移与编号在同一事务中。稳定目标身份使同一请求不重复创建，已删除的目标不被旧请求重建。
- 浏览器先保存草稿，操作期间禁止子事项编辑与重复迁移；成功只合并结构与版本，保留期间输入的其他字段；成员切换不污染新成员状态。
- 无新增数据库字段、migration 或部署方式变化。
- MCP 增加显式 `promote_subtask`，必填 `task_id`、`subtask_id`、`expected_source_version`；只读、未授权及范围外不可调用，旧令牌不扩权。CLI 提供 `wao subtasks promote SUB_ID --task-id TASK_ID --expected-source-version VERSION`，以实时 tools/list 为准，不自动重试写入。

## 验收

覆盖单行长标题、明暗和窄屏、浮层与键盘、排序和跨层级拖拽、循环拒绝、子树和编号保留、旧快照和重复请求、权限范围、保存失败及并发草稿。以本地连接既有线上数据库的真实浏览器链路验收后交付；实体设备与关闭由用户完成。
