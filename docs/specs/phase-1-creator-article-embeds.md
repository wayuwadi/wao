# Phase 1：创作者文章嵌入代码与画图

对应任务：`t1788439251173`（文章支持嵌入画图和可选语言代码块）。

## 用户结果

- 进入「自媒体 Agent → 内容工作台」，编辑文章正文时可从正文工具条插入代码块，并从常用语言列表选择语言；语言和代码内容随文章一起保存。
- 可插入流程图、时序图和思维导图，图形以 Mermaid fenced Markdown 保存，右侧实时预览立即绘制。
- 代码与图形进入既有草稿防丢、乐观锁保存、HTML 导出和复制排版链路；刷新后仍能还原，未保存时继续禁止发布与导出。
- 存入知识库时完整保留 fenced Markdown。知识库当前没有专用画图块，不能把嵌入内容静默丢弃或伪装成独立白板。

## 格式与安全边界

- 代码使用标准 ```` ```语言 ```` fenced block；画图使用 ```` ```mermaid ```` fenced block，不新增数据库字段或私有二进制格式。
- 实时预览和单文件 HTML 在无脚本沙箱内渲染常用流程连接、参与者消息与缩进层级；所有标题、代码、节点和消息先做 HTML 转义。
- 第一版不是多人白板，也不提供任意 Mermaid 语法全集。无法识别的图形保留并展示源码，避免保存后丢失。

## 验收

- 在正文中间放置光标，插入 Python 代码块，保存并刷新；正文保留 `python` 语言，右侧和导出 HTML 显示语言及代码。
- 分别插入流程图、时序图和思维导图；右侧预览出现对应图形，保存后刷新仍存在，下载的单文件 HTML 无网络和脚本也可查看。
- 代码中输入 `<script>`，预览与导出只显示文字而不执行；不可编辑的已发布内容中，画图和代码入口均禁用。
- 含代码与图形的文章存入知识库后，正文保留完整 fenced Markdown，不因知识库尚无专用图形块而丢失。
