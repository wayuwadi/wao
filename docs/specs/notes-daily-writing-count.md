# 小记页今日写字统计

- 小记页展示当前成员按上海时区今天新建的小记正文字符数；首页“今日输入”卡片展示同一数字。
- 统计依据已保存的小记正文与创建时间，不将今天编辑的旧小记重复计入；不计标题、空白、Markdown 格式标记或图片地址。字符口径复用统一字形计数规则。
- 统计仅使用当前成员、非自动、未归档且其正文对当前成员可见的小记。目录数据读取失败时显示错误与重试，不将未知状态显示为 0。
- 首页卡片保持紧凑，提供进入小记页的入口；两处数字与当天边界使用 Asia/Shanghai 时区。

验收：覆盖今日/非今日、本人/他人、自动记录、格式与图片排除、首页加载失败重试及宽窄屏显示。
