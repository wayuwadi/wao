# 小记编辑按钮按需显现

2026-10-03 用户对真实页面反馈：常显「继续编辑」按钮突兀，应在鼠标悬浮时显示。此决定取代 `notes-visual-refinement-2026-10-03.md` 中「常显继续编辑」一项，其余行为保持。

- 支持鼠标悬浮的设备：卡片静止时隐藏按钮，悬浮卡片时显示。
- 键盘焦点进入卡片时显示按钮；触屏等不支持悬浮的设备保持入口可见。
- 使用 opacity/visibility 保留位置，出现/隐藏不推动正文与元信息；沿用现有编辑处理和草稿机制。
- 设计偏好：阅读内容优先，次要编辑/管理操作按需显现，避免每条内容常驻醒目按钮。主要提交操作、异常反馈与触屏可达性不可因此隐藏。

验证：复用小记既有回归及类型/构建检查；正常登录的本地真实页面使用专用记录，检查静止隐藏、悬浮显示、移开隐藏、键盘可达及行内编辑打开。截图仅保留专用验收内容。未改变API、CLI、MCP、数据库与保存语义。
