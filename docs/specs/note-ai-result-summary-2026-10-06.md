# 本篇小记 AI 结果概况

整理结果面板内增加一行概况，按实际已加载成果区分「待你采用」和「已采用但未读」。PENDING + CURRENT 计入待采用，无论是否已读；APPLIED + CURRENT + seen=false 计入已采用未读。按成果 id 去重，排除旧来源、历史已采用、忽略及恢复状态。

没有下一页时标为「这篇小记」，存在 nextCursor 时标为「已加载结果」，不把分页数量伪装成整篇或全局总数。加载失败不展示零计数；成功的空结果显示零。原有采用、恢复、已读和草稿保护规则保持一致，概况随真实结果状态更新，不额外请求接口。

入口沿用按需打开的本篇 AI 面板，不在小记列表加入常驻面板，不自动展开或消费其他成果未读状态。本需求不更改 API、权限和业务能力，无新增 CLI/MCP 操作。
