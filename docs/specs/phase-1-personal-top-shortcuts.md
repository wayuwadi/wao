# 顶部个人资源快捷入口

补充菜单顶部停靠与成员快捷链接规格：顶部除已有全局菜单外，可接收真实项目、知识库、侧栏收藏的项目／任务／文档和个人快捷链接。

- 拖拽来源：项目列表卡片、知识库列表卡片、左侧收藏条目、左下角快捷链接弹层及首页「我的快捷链接」。普通文字、浏览器地址和页签拖拽不作为资源入口。
- 拖入后保留原位置，顶部增加按钮；相同资源不重复添加；个人按钮之间拖拽排序，关闭按钮只移除顶部引用，不删除项目、收藏或链接。
- 全局菜单继续沿用原全局注册表和拖拽流程，个人快捷按钮排列在其后。长名称截断并有完整 title，顶部箭头与横向滚动继续可用。
- 使用已登录成员的 `/api/preferences/nav-top-shortcuts-v1` 保存 JSON 数组；每项包含 key、label、icon、path 及可选 quickLinkId，不存复制的业务内容或外部 URL。项目、知识库点击原路由，快捷链接按当前真实配置的 TAB／NEW_PAGE 打开；链接已删除或读取失败时明确提示。
- 首次加载和保存中显示状态；加载未成功禁止写入覆盖；保存成功后更新按钮，失败保留上一份已保存入口与待重试操作；账号变化清空状态并忽略旧账号异步回包。
- 标签沿用源名称，项目、知识库和快捷链接重命名后优先展示当前数据名称。只允许受限站内资源路径及合法图标，最多 50 个个人入口。

验收：分别从项目、知识库、收藏和快捷链接拖到顶部，点击到达对应真实资源；刷新保留，重复拖入不重复、拖动排序生效、移除后原资源仍存在；保存失败可重试；桌面长名称和窄屏横向浏览可用。
