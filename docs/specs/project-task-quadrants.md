# 项目任务四象限

## 范围

项目任务区在表格、看板、分组旁新增四象限，与待办直接复用 `TaskQuadrantView.vue` 和 `taskQuadrants.ts`。沿用清单四象限规格；后续象限布局、拖动、快捷移动、完成状态、保存反馈和重试均维护在同一个组件内。

## 行为

- 项目页只传入当前项目且满足负责人、创建人筛选的任务；不混入其他项目任务。
- 沿用 P0 重要紧急、P1 重要不紧急、P2 不重要紧急、P3 不重要不紧急；移动只改优先级。
- 共用组件接受可选 `projectId`，象限内新建预选当前项目和对应优先级；待办未传项目时保留原来的项目选择流程。
- 支持详情、完成/重新打开、已完成展开收起、放大还原、拖动和快捷移动、失败重试及项目现有批量复制。
- 项目四象限由 `?view=quadrant` 表示，刷新保留；普通项目入口仍默认表格，不改变现有入口约定。
- 已完成开关沿用项目偏好；收起完成项或改变筛选时清理隐藏选择。
- 布局直接复用待办四象限，在项目内容区使用剩余空间和象限内部滚动。
- 无新增 API、数据库字段或 migration。

## 验收

覆盖当前项目范围、负责人/创建人筛选、象限新建的项目与优先级、刷新视图、批量选择和已完成收起；共用组件的移动、保存失败重试、完成及待办行为沿用四象限回归测试。
