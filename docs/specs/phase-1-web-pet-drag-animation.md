# 网页宠物拖拽动作

补充张三丰 v2 和原悬浮拖拽规格：按下与实际移动分开识别。按下不足4像素不算拖动，不播放走路。

- 开始移动后，向右播放图集第1行，向左播放第2行；反向移动即时切换行，同方向持续移动不能每次重置到首帧。
- 仅上下移动时保持最近朝向。暂停移动180毫秒或松开时恢复待机；仅按住不移动不原地跑。
- `idleAnimation=false` 只关闭自动空闲动作，不阻止真实拖拽走路；系统减少动态效果仍静止显示对应行首帧。
- 释放、取消、窗口失焦和卸载都清理移动计时器。拖后点击继续被吞掉，位置按原键保存；存储受限不阻断释放。
- 共用拖拽工具的其他入口不显示宠物动画，只保留原位置和点击行为。

验收：连续右移跨至少2帧，改向左移，暂停，释放，确认未误开菜单；刷新保留位置；触屏长按、静默和减少动态效果回归。
