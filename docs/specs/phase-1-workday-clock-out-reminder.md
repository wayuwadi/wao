# Phase 1：下班提醒仅在工作日发送

对应任务：`t1788606077473`（下班休息和下班提醒，工作日要，休息日不要有）。决策见
[ADR-207](../adr/207-workday-clock-out-reminder.md)。

## 用户结果

- 「设置 → 通知设置 → 系统 · 每日提醒」中的“下班休息与打卡提醒”标明为“工作日”。
- 周一至周五没有法定放假安排时照常发送；已收录的法定休息日不发送，调休工作日即使是周末也发送。
- 休息日的自动触发留下“已跳过”运行结果，不调用飞书；管理员主动试发仍真实发送，便于验证当前群配置。
- 其它早间、午餐和午休提醒保持原有每日规则，不随本需求改变。

## 真实数据与失败边界

- 工作日判断复用日历模块已收录的国务院办公厅节假日安排，不复制日期表；没有特殊安排时按周一至周五判断。
- Cron 继续每天推进，由执行器使用本次计划触发日期判断，避免服务延迟或断网补跑时错取恢复当天。
- 飞书凭据、目标群、总开关、提醒分类开关和沉默时段继续复用既有真实发送门禁；本功能不提供演示发送。

## 验收

- 普通工作日自动执行真实发送器；普通周末和法定休息日跳过；法定调休工作日执行真实发送器。
- 编辑下班提醒的时间、标题或正文后仍保留工作日规则，不能退回每日发送。
- 设置页明确显示“工作日”，刷新后仍来自服务端真实配置。
