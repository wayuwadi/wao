# 手机小记快速记录

本规格补充 ADR-324、`mobile-content-first-shell.md`，继续维护浏览器版本。

- 不超过 760px 时，小记顶部保持一行主要操作；收起/展开记录区使用有明确名称的图标，设置与回收站归入“更多”。桌面保持既有入口。菜单支持 Esc、外部点击及焦点恢复。
- 手机主要操作与筛选项提供至少 44px 触控高度；搜索输入采用 16px 字号。新建空输入区最小高度为 270px，让最近记录更早出现，全屏和长文编辑行为保持。
- 编辑操作区提供“书摘”入口。仅用户点击才请求读取剪贴板；不在打开 App 或切回页面时自动读取。安全上下文或读取权限不足、剪贴板为空时提供手动粘贴路径。
- 导入前可编辑原文、可选来源、感想；不凭文本猜测书名、作者、页码。剪贴板已有来源文字保留在原文中，用户可自行调整。
- 原文转换为纯文本引用节点，逐段保留；来源和感想位于引用外。剪贴板中的 HTML / Markdown 不作为指令执行，不自动获取外部图片。导入只追加至最新草稿，不替换现有正文、标题或标签，不自动提交服务端；沿用显式保存与失败重试。
- 异步读取不得覆盖用户已手动修改的预览；关闭后迟到结果失效。未导入预览按成员、文档/草稿范围和页签保留，关闭/刷新后可恢复；存储失败明确提示，编辑器未就绪时保留预览并允许重试。
- 导入弹窗首次渲染居中，支持焦点循环、Esc、关闭恢复；手机尺寸跟随 VisualViewport，避让安全区。实体 iPhone 的剪贴板确认与软键盘体验由用户最终验收。

本轮无 HTTP API、数据库、服务端业务能力、CLI 或 MCP 工具变更；录音转写、系统分享接收与离线同步另行评估。
