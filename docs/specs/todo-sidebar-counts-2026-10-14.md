# 待办侧边入口数量

用户要求每日固定和随手记收起时也能看到数量，补充辅助侧边栏规格；复用现有日视图与日常规则数据，不新增 API 或修改保存契约。

- 每日固定显示所选日期全部早晨／晚上 `OPEN` 实例数；已完成与今天跳过视为已处理，不计入剩余。完成、跳过、恢复、新建规则后以原有保存确认与重新读取结果更新，失败不提前扣减。
- 随手记显示所选日期全部记录条数，不受前三条显示或展开全部影响；补记计入其业务日期。使用日工作区 `notes.length`，保存确认后刷新更新。
- 两个数量在面板折叠与展开时均显示，数量变化不自动展开。零明确显示 0；日常读取中显示省略号，失败显示提示标记，展开沿用失败原因与重试，未知不冒充零。
- 日期／成员切换先清除旧日常数量；过期响应不能写入新范围。保留草稿、保存状态、默认收起与键盘焦点契约。
- 入口可访问名称包含“项未做”／“条记录”；数量在桌面竖排文字旁保持横排数字，窄屏与两个入口横排；使用已有主题 token 与设计参考的明确演示数量。

验收覆盖早晚合计、完成／跳过／恢复、全部记录数、零与未知、错误重试、日期与成员切换、明暗主题、窄屏与键盘。
