# 数据中心的使用前检查

补充现有只读数据中心规格，不改变目录聚合、来源定义或权限。

- 页首说明这是系统目录、统计时间与覆盖范围检查，不将记录数量解释为个人完成量，不把最新写入解释为持续同步。
- 明确 READY 只证明有记录与时间；保留 EMPTY、TIME_UNKNOWN、REGISTERED_ONLY 区分，未知状态保守展示，不中断页面。
- 提供全目录状态数量及筛选，可与既有分类组合；组合无结果可清除筛选。无数据不假装存在健康结论或示例数字。
- 来源卡片说明下一步核对方式；有既有功能页时链接到原入口，由原页面继续执行权限规则，不增加采集或跨模块写入。
- 不新增备份、恢复、同步、仓库采集能力；仅登记不能当作已取得正文或完整历史。

验收覆盖状态与分类组合、清除筛选、时间未知和未知状态、真实来源到原功能入口、刷新读取和空状态。
