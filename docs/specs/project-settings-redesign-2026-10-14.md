# 项目设置分项重设计

2026-10-14 用户确认交互原型并要求实现后直接上线。

- 沿用 SettingsDialogShell，桌面宽约 760px、自适应高度；手机全屏，正文滚动、保存栏固定。
- ProjectSettingsLayout 提供「基本信息 / 项目成员（数量）/ 更多」顶部页签，支持左右方向键、Home、End；隐藏面板不进入键盘焦点顺序，切换保留输入。
- 基本信息默认显示：名称旁 44px 图标按钮，4 列紧凑图标浮层，领域与可选截止日期并排、窄屏单列，描述 / 目标直接显示。空日期不显示「未排期」，已有日期可清空。
- 成员沿用真实组织目录和负责人权限；负责人不可移除、其他成员只读，添加和移除保存后生效。读取失败可重试；成员 CAS 与合入最新成员机制沿用成员管理规格。
- 更多单独放置删除项目，二次确认与取消删除。删除失败不提前移除本地项目和任务；知识库和文档始终独立保留。下线的 AI Run 不恢复展示、读取或默认写入。
- 固定底栏只有一个主按钮：未修改「完成」，修改后「保存并关闭」，失败「重试保存」，保存期间禁止编辑和重复提交。关闭按钮、遮罩及 Esc 沿用关闭时保存；图标浮层或删除确认展开时先收起当前层。
- 草稿按当前成员和项目隔离同步写入本机；刷新或重开恢复名称、图标、领域、日期、目标和成员编辑前快照。成员目录或后台刷新不能覆盖输入。仅提交实际编辑的基本字段，避免未编辑字段覆盖后台刷新。
- 恢复时已编辑基本字段与账号当前值冲突，保留输入并展示账号当前内容；用户选择保留修改或使用账号设置后才能保存。成员并发仍由服务端 expectedMembers 校验，不能恢复草稿时静默重设其版本。
- 存储失败明确提示并保留当前输入，可继续保存到账号。成功仅清理本窗口保存的草稿版本，不能清掉其他窗口更新后的草稿；账号切换关闭旧成员编辑窗口。
- 本次不增加 API、数据库、MCP 或 CLI 能力；保留既有浏览器会话权限边界。

验收覆盖：分项、图标、无修改关闭、名称校验、字段保存与清空、负责人 / 非负责人、成员读取失败与 CAS、保存失败刷新恢复、账号冲突选择、存储失败、其他窗口草稿、删除取消与失败、明暗主题、320 / 390px、键盘与设计参考。
