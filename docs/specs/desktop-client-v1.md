# WAO 桌面客户端 1.0

## 范围

Windows 10/11 x64 首发，复用现有 WAO Web 全部业务功能。macOS 使用同一工程，待用户切换到 Mac 后完成平台实机验收和发布，不把 Windows 完成状态扩展到 Mac。

## 界面与行为

1. 64px 紧凑工作区顶栏：品牌、后退/前进、刷新、连接状态、更新中心、窗口操作；下方完整 WAO 页面，无第二套业务导航。
2. 首屏连接中、超时重试、离线状态有清晰提示；不以静态页面伪造已登录或真实数据。
3. 更新中心展示已安装版本、检查中、最新版本、可下载、下载进度、已就绪、失败重试。下载不自动重启；安装前提醒保存。
4. 系统关闭按钮隐藏窗口保留输入；托盘可恢复、检查更新、退出。显式退出和刷新前提醒用户保存。
5. 后退/前进使用 Web 历史，表单和草稿沿用 Web；切换更新中心只隐藏工作区，不销毁 WebView。窗口缩放、恢复位置与窄屏保持可用。
6. 邮箱、飞书登录及持久会话沿用现有 HTTPS 原点；外链、附件下载、文件选择使用系统能力。拒绝未知原生协议，远程内容无本地命令权限。

## 开发发布

- 同仓库单需求 PR，独立客户端工作流；普通 Web 更新不用重打安装包。
- `npm run desktop:dev` 本地启动，`npm run desktop:build` 生成 Windows NSIS 安装包。
- 本地调试可连接 localhost Web，生产包固定线上地址。
- CI 开发宿主通过独立进程名 `wao-client-dev.exe` 启动，正式安装器不能因可执行文件同名关闭该宿主；下载制品保留，原生宿主更新需退出后替换，前端热更新不受影响。
- 版本发布脚本同步 package/Cargo/Tauri 版本，提交后创建标签触发 CI/CD；已有版本不可覆盖。
- 更新包签名由 CI 注入，公钥内置；清单与版本制品同域 HTTPS 提供，清单禁缓存。

## 必须留下的验收证据

- 前端单元测试、类型检查、Rust 测试及 Windows 打包结果。
- Windows 实际客户端截图与真实账号业务链路；实际安装包安装及启动。
- 最小化/关闭恢复、更新面板切换不丢输入、离线提示/重试。
- 生产制品、签名、更新清单和工作流终态；至少一次旧版至新版覆盖更新与会话保留。
- macOS 实机验收保持待办，记录 Mac 开发入口及后续步骤。

## macOS 1.0.1 扩展

依据 ADR-226，同一发布包含 Windows x64 与 macOS 11.3+ Universal。Mac 使用系统标题栏，不显示重复的 Windows 窗口按钮；提供原生编辑菜单、Cmd+Q 保存提醒、Cmd+W 收起工作区和 Dock 恢复。子 WebView 布局仍按内容区 64px 顶栏定位，关闭/恢复和更新面板不销毁会话。

`/download` 按平台独立读取和校验发布状态。Mac 首次安装按钮指向版本化 DMG；两个 darwin 更新平台必须指向同一签名 `.app.tar.gz`。DMG 大小、SHA-256 和路径需有效，缺失包和 HTML 回退不得作为可下载文件；Windows 下载失败不影响已验证的 Mac 下载。页面公开提供首次拖入 Applications、未公证状态与更新说明。

新增验收记录见 [Mac 验收](../runbooks/macos-client-acceptance.md)，不沿用 Windows 实测结论。

## Mac 文件下载修复（1.0.2）

WKWebView 下载需要显式注册处理器；工作区及新窗口均启用同源 HTTPS / Blob 文件下载，保存到用户下载目录，同名文件编号保留旧文件，顶栏提示下载中、成功或失败重试。远程页面仍无文件系统命令权限，跨域和本地文件协议不能通过此处理器下载。最低系统为支持 WKDownload 的 macOS 11.3；实机文件交互仍需用户验收。

## 窗口恢复侧栏稳定性（1.0.3）

最小化及无有效内容区的临时尺寸事件不得传给工作区 WebView，保留最后可用视口，避免恢复时侧栏先切换手机窄栏再展开。恢复后的有效尺寸与正常窗口缩放继续同步；不修改用户的导航折叠偏好，不刷新或重建工作区，草稿与会话保持。
