# WAO 桌面客户端 1.0

## 范围

Windows 10/11 x64 首发，复用现有 WAO Web 全部业务功能。macOS 使用同一工程，待用户切换到 Mac 后完成平台实机验收和发布，不把 Windows 完成状态扩展到 Mac。

## 界面与行为

1. 64px 紧凑工作区顶栏：品牌、后退/前进、刷新、连接状态、更新中心、窗口操作；下方完整 WAO 页面，无第二套业务导航。
2. 首屏连接中、超时重试、离线状态有清晰提示；不以静态页面伪造已登录或真实数据。
3. 更新中心展示已安装版本、检查中、最新版本、可下载、下载进度、已就绪、失败重试。下载不自动重启；安装前提醒保存。
4. 系统关闭按钮隐藏窗口保留输入；托盘可恢复、检查更新、退出。显式退出和刷新前提醒用户保存。
5. 后退/前进使用 Web 历史，表单和草稿沿用 Web；切换更新中心只隐藏工作区，不销毁 WebView。窗口缩放、恢复位置与窄屏保持可用。
6. 邮箱、飞书登录及持久会话沿用现有 HTTPS 原点；外链、附件下载、文件选择使用系统能力。拒绝未知原生协议，远程内容无本地命令权限。

## 开发发布

- 同仓库单需求 PR，独立客户端工作流；普通 Web 更新不用重打安装包。
- `npm run desktop:dev` 本地启动，`npm run desktop:build` 生成 Windows NSIS 安装包。
- 本地调试可连接 localhost Web，生产包固定线上地址。
- 版本发布脚本同步 package/Cargo/Tauri 版本，提交后创建标签触发 CI/CD；已有版本不可覆盖。
- 更新包签名由 CI 注入，公钥内置；清单与版本制品同域 HTTPS 提供，清单禁缓存。
