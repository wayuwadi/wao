# 成员页面布局风格

2026-10-04，用户确认“统一外框”设计，并要求把三个方案收口为成员可选偏好。本规格补充现有页面布局、小记自适应空间和成员偏好规格；不改变业务数据、草稿或权限。

## 用户结果

- 默认“统一外框”：登录工作台的页面外框铺满可用空间，共用桌面 16–44px、窄容器 12–16px 留边。能力中心、全部功能、功能探索与待办（按天、全部和四象限）切换时不再各自居中限宽。
- “全部铺满”：共用同一外框，阅读内容与设置内容也使用剩余宽度。
- “统一居中”：页面外框统一最多 1600px 并居中；正文和表单仍控制阅读宽度。小记编辑区拖拽比例、知识库目录、草图及密码本分栏不重建。
- 除全部铺满外，小记全文与知识库正文最多 840px，普通设置内容最多 760px，复杂设置最多 1000px。知识库主动选择的窄正文模式继续保持 650px。图片和表格沿用现有局部滚动及展示能力。
- 外框、正文和表单分别使用共享变量；不把弹窗、公开分享、登录、下载、外部应用 iframe 套进成员页面规则。匿名能力中心保留现有公开布局。

## 偏好与状态

- 在“设置 → 常用设置”和“设置 → 外观与陪伴”显示“页面布局”，与界面控件风格分开。三种选择用小型布局示意说明；保存成功后立即应用，显示加载、保存中、已保存及失败重试状态。
- 复用 `/api/preferences/page-layout-style-v1`，值为 `unified`、`fluid`、`centered`，服务端按当前成员隔离。缺失或未知值使用 `unified`，不迁移既有记录。
- 保存失败保持已保存布局；待重试的单项选择按成员保存在浏览器，刷新后仍可明确重试，不自动提交或覆盖服务端。浏览器存储失败提示，服务端保存仍可执行。
- 保存期间不重复提交；切换成员后，上一人的迟到读写响应不得改变新成员布局；读取中的迟到响应不得回退刚保存的选择。
- 切换风格只更新布局属性和 CSS 变量，不刷新页面、不改变路由、不重新挂载编辑器。跨设备读取复用现有成员偏好加载时机；这个单值偏好采用既有显式最后写入契约，不改写复杂 AI 设置的 CAS 协议。
- 页面滚动容器预留滚动条槽位，避免不同内容高度引起可用宽度变化；工作区仍使用原有内部滚动。悬浮页签继承当前成员的布局风格，并按自身可用宽度留边。

## CLI / MCP 边界

此次仅新增浏览器使用的偏好键和布局展示，复用既有 API；不新增服务、HTTP API 或 MCP 工具。布局不影响设备业务操作，不增加 CLI 命令或旧令牌权限。

## 验收

- 成员偏好默认值、持久化、非法旧值、失败重试、成员切换、迟到读写及浏览器未保存选择恢复。
- 本地前端连接既有业务服务，在真实成员的三个布局下检查重点页面边界、刷新恢复及保存失败重试；窄屏、侧栏折叠、工作区和编辑草稿保留均需检查。
- 类型、受影响组件交互测试、生产构建和工程一致性检查；以实际验收记录说明数据来源及缺项。
