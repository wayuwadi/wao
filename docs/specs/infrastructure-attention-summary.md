# 基础设施关注摘要

补充基础设施总览与 ADR-211 的只读体验，不改变采集、权限、资源阈值或服务启停能力。

- 汇总每个节点需要核对的信息：采集失败、无成功快照、过期或未在线快照、采集提示、待核对服务、缺失服务清单。优先让用户知道证据是否有效，再查看服务。
- 待核对服务包括未运行或已有健康检查显示 unhealthy 的项目；未运行可能符合预期，不直接判为故障。
- 摘要操作定位对应节点或待核对服务筛选，清除先前搜索条件，键盘焦点与滚动一起到达。
- 没有发现待核对项只描述当前快照，不声称全站健康；刷新失败明确保留的是旧摘要。无节点数据不能显示健康结论。
- 不引入任意 CPU、内存阈值，不自动重启或触发巡检。

验收覆盖正常、无节点、无快照、过期、采集失败、采集提示、服务缺失、未运行与运行但 unhealthy 的服务，以及摘要到跨节点服务筛选和刷新失败后的旧快照提示。
