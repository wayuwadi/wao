# Phase 1：自媒体自动化 Agent 独立应用接入

决策背景见 [ADR-037](../adr/037-media-agent-independent-application.md)，完整组件、接口和部署设计见
[技术架构方案](../architecture/media-automation-agent.md)，实施顺序见
[执行清单](../runbooks/media-agent-implementation.md)。

## 目标

在 WAO 工作台中提供一个“自媒体 Agent”菜单和可关闭页签，承载独立部署的自媒体自动化系统。首个纵向链路
覆盖“选题进入内容草稿 → Agent 生成 → 人工审核 → 导出或发布 → 记录结果”，并保证 WAO 与 Agent 可以分别
升级、回滚和扩容。

## 用户路径

1. 已登录用户点击 WAO 左侧“自媒体 Agent”，WAO 打开 `/media-agent` 页签并展示加载状态。
2. Agent iframe 完成来源校验后向父页面发送就绪消息；WAO 为当前会话创建一次性票据，通过限定来源的
   `postMessage` 交给 Agent。
3. Agent 后端兑换票据、建立自己的会话并映射本地用户。首次进入时创建个人工作区或引导加入已有工作区。
4. 用户创建选题，选择目标平台、内容形态、素材、语气和发布时间；未连接的平台明确引导授权。
5. Agent 创建一次可追踪的运行，逐步生成提纲、正文和平台变体。页面持续展示运行中、等待审核、失败重试和
   取消状态，刷新页面后仍能恢复。
6. 生成内容先进入审核，不会因为模型返回成功就自动对外发布。审核者可修改、驳回、重新生成或批准。
7. 已批准内容按计划发布；没有真实平台发布接口时只允许导出，不显示虚假的“已发布”。
8. 每个平台的发布结果单独记录。部分平台成功、部分失败时显示“部分成功”，允许只重试失败项。
9. 用户可在页签内使用，也可点击“在新窗口打开”；两种入口进入同一 Agent 账号和业务数据。

## 首版功能边界

### 包含

- WAO 菜单、顶部页签、iframe 容器、加载失败与独立打开入口。
- WAO 到 Agent 的一次性 SSO 和本地用户映射。
- Agent 工作区、成员与应用内角色：所有者、编辑、审核者、运营者。
- 平台连接管理；凭据加密保存，列表与日志不回传明文。
- 选题、素材、内容草稿、内容版本和平台变体。
- 可编排但受控的生成流程：输入校验、生成、人工审核、发布或导出。
- 异步运行记录、步骤进度、失败原因、取消、重试和幂等发布。
- 计划发布时间、逐平台发布记录、审计日志和基础运行指标。
- 至少一条使用真实数据的端到端纵向链路；首个平台在实施启动时依据正式 API 权限确定。

### 暂不包含

- 自动追逐热点并在无人审核时直接发布。
- 同时适配所有自媒体平台。
- 从 WAO 数据库直接读取任务、知识库、成员或密码库。
- 训练自有大模型、复杂多 Agent 自治协作和按效果自动改写策略。
- 为了演示而伪造阅读量、互动量、平台账号或发布成功结果。

## 状态与防丢要求

- 内容编辑必须覆盖草稿自动保存、保存中、已保存、失败重试、冲突提示和空数据状态。
- 服务端保存内容版本；Agent 运行产生新版本，不覆盖用户正在编辑且尚未落库的版本。
- 运行状态至少包含：`queued`、`running`、`waiting_review`、`approved`、`publishing`、`succeeded`、
  `partially_succeeded`、`failed`、`canceled`。
- 发布目标必须使用唯一幂等键。网络超时后的重试先查询或复用原平台请求，不得静默重复发布。
- Worker 心跳超时后任务回到可恢复状态；已经确认发布成功的步骤不得再次执行。

## 安全与权限

- iframe 只允许 `https://wao.wayuwa.cn` 嵌入，WAO 只允许加载 `https://agent.wayuwa.cn`。
- `postMessage` 双方同时校验 `origin`、`source`、协议版本和握手随机数；消息中只允许传一次性票据，不传
  `WAO_SESSION`、平台令牌或长期访问令牌。
- SSO 票据使用安全随机数，服务端只保存摘要，60 秒过期且原子消费一次；兑换接口同时校验 Agent 客户端身份。
- Agent Session 使用 `Secure`、`HttpOnly` Cookie；写操作执行 CSRF 防护，敏感发布操作要求近期有效会话。
- 平台 OAuth Token、LLM API Key 和对象存储凭据使用服务端密钥加密，禁止出现在 Git、浏览器响应和日志中。
- 工作区数据按服务端解析的本地用户授权；越权资源统一按不存在处理，关键操作写入审计日志。

## 验收标准

- Agent 前端或后端发布时，WAO 仓库没有新提交、构建和部署；WAO 仍可正常使用。
- Agent 不可用时，WAO 其他页面不受影响；Agent 页签在超时后显示失败、重试和独立打开入口。
- 未登录访问 `/media-agent` 仍先进入 WAO 登录；登录后 iframe 在一次握手内进入相同的 Agent 本地用户。
- 票据过期、重复兑换、目标应用不匹配、来源不匹配时均被拒绝，且响应和日志不泄露票据。
- 退出 Agent 后其 Session 立即失效；退出 WAO 后，新票据无法签发，Agent 的敏感发布操作不能继续使用陈旧身份。
- iframe 和新窗口模式均覆盖加载中、空数据、运行中、审核、保存失败、发布失败和重试链路。
- 刷新或关闭后重新打开页面，草稿、运行和逐平台发布状态均来自持久化数据，不回退到 fixtures。
- 同一发布任务重复点击、浏览器重试或 Worker 重启不会产生重复平台内容。
- 平台没有授权或正式接口时，页面显示真实限制并提供导出，不生成假账号、假指标或假成功状态。
- 至少完成一次真实用户链路验收：从 WAO 点击菜单进入，创建内容，完成生成和人工审核，导出或发布，并在
  运行记录中看到一致的最终结果。
