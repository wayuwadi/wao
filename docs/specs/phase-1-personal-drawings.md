# 规格：个人草图文件

对应任务：`t1786498876586`（把画图功能接入「个人」）。

## 目标

- 在左侧「个人」分组增加「草图」入口，使用 Excalidraw 完成无限画布绘图。
- 草图文件由 WAO 后端按当前登录成员归属；成员只能列出、打开、修改和删除自己的文件。
- 画布变更自动保存，页面始终给出加载、未保存、保存中、已保存和失败重试状态。

## 文件与权限

- 新建文件默认名为「未命名草图」，创建后直接打开空画布。
- 文件列表按最后修改时间倒序，支持新建、重命名和删除。删除前必须二次确认。
- 成员 id 只从服务端 Session 推导，请求体不接受归属人。访问别人的文件统一返回 404，不暴露文件是否存在。
- 文件内容保存 Excalidraw 开放 JSON 场景（元素、画布状态与已插入图片），不伪造示例数据。

## 保存与冲突

- 每个文件带有单调递增的 `revision`。保存时必须提交当前版本，服务端只在版本一致时更新。
- 另一页面或设备已经保存新版本时返回 409；当前画布保持在本机草稿中，不得覆盖服务端新版本。
- 每次画布改动先写入 IndexedDB 草稿，再防抖自动保存到服务端。意外关闭或网络失败后重新打开，优先恢复尚未落库的本机草稿。
- 保存成功后删除对应本机草稿。保存失败时提供明确的重试按钮。
- 画布内容与当前云端场景相同时不保存、不递增 `revision`；服务端按元素、画布背景与文件内容再次判重，避免初始化事件或重复请求产生空版本。
- 每份草图只保留最近三个有效场景快照。恢复历史快照时创建一个新的单调递增版本，不回退乐观锁版本号。

## 交互

- 桌面端为「文件侧栏 + 画布」布局；手机端可收起文件侧栏，画布不被固定宽度挤出可见区。
- 没有文件时显示空状态和「新建草图」，不自动创建示例文件。
- 切换文件、重命名或删除时不用旧文件的延迟保存覆盖新文件。
- 页面离开前如仍有未落库更改，由浏览器给出离开确认；IndexedDB 草稿仍保留可恢复。

## 验收

- 两个成员各自新建草图，列表只看到自己的文件；直接访问他人 id 得到 404。
- 新建后绘制图形和文字，页面状态从「未保存」经「保存中」变为「已保存」；刷新后内容完整恢复。
- 断网绘制后刷新，能恢复本机草稿并重试保存。
- 同一文件两个页面先后保存，后一个旧版本请求得到 409，两边的画布都没有被静默覆盖。
- 重命名和删除后刷新仍生效；390px 宽度下可收起文件列表并操作画布。
- 当前文件名可在画布标题栏直接编辑；右上角可进入全屏演示，退出全屏后仍保留未保存输入。
- 连续保存超过三次后只显示最近三个有效版本；恢复任一历史版本后内容正确，并以新版本继续保存。
