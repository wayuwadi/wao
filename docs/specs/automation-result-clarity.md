# 自动化计划与执行结果分离

## 问题与用户结果

对应产品体验审计 A05–A07 的展示部分。原页面把状态“正常”标绿，并将所有不含“失败”的运行记录标为成功色，导致启用、入队、跳过与执行完成混淆。

- 计划开关显示“已启用 / 已暂停 / 需要处理”，与上次运行结果分列。
- 仅明确成功前缀使用成功色；入队、提交、跳过、取消、部分成功和未知结果分别表达。无法判断的旧消息显示“结果待确认”，保留原始触发记录。
- 有真实 `aiRunId` 的历史显示“已提交执行”，可进入对应 AI 会话查看当前执行结果；不把创建成功当作执行成功，也不伪造关联。
- 最近五次圆点提供文字名称；详情长记录在窄屏可横向浏览；无记录时说明开始方式。

## 范围

仅修改自动化页及其展示工具，不改变任务调度、手动触发、权限、接口、数据库或知识库内部逻辑。复用现有语义颜色与 AI 会话路由。历史结果仍为自由文本，此兼容展示不是后端结构化结果契约，后续契约升级单独评估。
