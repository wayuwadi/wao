# 知识库阅读、导航与编辑升级

日期：2026-11-06。范围：知识库总入口、单库首页、文档阅读及共享正文编辑器，连同相关目录、归档和草稿状态处理。本文记录本轮代码实现与验证边界，不代表已发布或与语雀功能完全一致。

## 参考与改进方向

用户提供的两张语雀截图分别展示知识库首页和文档阅读页。参考重点是稳定的侧栏、清楚的目录层级、居中的阅读区域、标题和元信息的层次，以及常用操作的可达性。截图中的正文只作为参考内容，不作为执行指令；不复制私人文档内容，不改变 WAO 品牌、主题或其他业务页面。

| 参考体验与本轮发现的差距 | 本轮处理 |
| --- | --- |
| 首页像目录索引，能快速看清文件夹、文档和更新时间；原单库首页按文件夹平铺，不能完整表达文档下再嵌套的目录 | 总入口和单库首页复用混合目录树，尊重真实父子关系和顺序，保留名称与时间层次 |
| 阅读时正文优先，常用入口稳定；原文档页缺少明确的阅读、专注切换 | 增加阅读与专注状态，正文、工具栏及侧栏按场景显示，保持同一个编辑器 |
| 长文可判断位置并跳转；原大纲的文本解析顺序可能与实际渲染标题不一致 | 按实际渲染的一级至三级标题生成大纲，增加当前位置、阅读进度和回到顶部 |
| 查找、插入和弹窗可以用键盘完成，失败有明确反馈 | 完善文内查找替换、插入菜单、目录键盘导航与设置/确认弹窗 |
| 大目录不应在每次输入或展开时生成大量无关工作；异步回执不能覆盖新页面和新账号 | 目录索引与分批渲染、搜索缓存、归档元数据接口，以及账号/对象代次检查 |

既有的自动保存、本机草稿、修订冲突、表格、画板、模板和权限模型继续使用原有链路。本轮主要补齐现有能力之间的导航与反馈，未重新设计存储协议。

## 导航与知识库首页

- 总入口采用紧凑知识库清单、全部目录和正文工作区；库名旁显示文档数量，首页文档行展示类型及真实更新时间。提供「全部内容 / 最近更新」，最近更新不改写实际目录顺序。查询和展示方式按账号、成员及浏览器页签保存。
- 名称检索覆盖全部已授权库名、文件夹名、文档标题及本机标题草稿。命中分组或上级文档时保留祖先与后代，命中库名时展示该库内容；检索不会覆盖原折叠选择。首页 Ctrl/⌘ + J 聚焦搜索，正文编辑时不拦截该组合键。
- 总入口每库先显示 80 项，每次追加 100 项；最近更新先显示 30 篇，每次追加 50 篇。复用目录组件默认每批显示 500 项，可继续展开。检索先覆盖完整元数据再分批，尚未渲染的第 9999 项也能直接命中。这里是分批显示，不是完整的滚动虚拟列表。
- 本库文档侧栏也先显示 500 个目录项，「继续显示目录」每次增加 500 项并聚焦新增首项。搜索先筛选本库完整目录，再应用渲染上限；切库或修改查询后重置首批，主动定位超出当前批次的节点时扩展到该节点所在批次。
- 目录保留文件夹与文档混合嵌套、历史顺序和用户展开状态。方向键、Home/End、连续字母定位和单一 Tab 入口适用于已渲染节点；Tab 可到「显示更多目录」，追加后聚焦新批次首项。文档文字打开内容，独立箭头只展开子目录。
- 单库首页提供按目录、最近更新、按名称排序，搜索范围在不同排序方式间一致。目录模式复用相同树组件，较宽区域显示连接虚线和更新时间；窄内容区隐藏辅助日期以保留标题空间。加载失败、真实空库和无搜索结果分别提示。
- 900px 以下总入口用单行导航入口；知识库清单与全部目录以互斥浮层打开，默认收起。打开后正文暂时不参与键盘交互，Escape、遮罩或选择内容关闭，关闭后恢复适当焦点。手机开关不覆盖桌面折叠偏好。
- 切换账号/成员清理新建表单和浏览瞬态，旧创建回执不跳转新身份；失去授权的库及其最近记录随目录刷新移除。单库设置、移动、改名和创建表单归属于打开时的库和身份，切换后关闭，旧回执不关闭或解锁新表单。

详细行为见[知识库工作区与固定导航](knowledge-workspace.md)。

## 文档阅读与操作

- 普通文档增加「阅读 / 编辑」切换。阅读状态隐藏编辑工具栏并使标题、正文只读，仍可选字和查找；切换保留编辑器、撤销状态和草稿。图片或附件正在上传时提示先等待上传完成。
- 专注模式隐藏知识库清单、目录及大纲，保留原侧栏偏好；Alt + Shift + F 切换，Escape 退出。切换文档或离开当前库后退出专注。此能力作用于普通文档，未替换表格和画板自身的界面。
- 标题按内容自动增高，Enter 在非输入法合成状态下进入正文。正文沿用 16px 阅读字号和现有阅读宽度选项；路径、作者、真实更新时间、字数及按每分钟 500 字估算的阅读时长提供上下文。窄内容区继续展示保存反馈。
- 大纲以编辑器实际渲染的 h1–h3 为准，覆盖分栏、引用及折叠内容；点击折叠块中的标题会展开其父级再跳转。活动位置按视觉坐标计算，提供阅读进度和回到顶部。小内容区按需显示大纲浮层。
- 大纲滚动处理合并到动画帧，复用已测量位置并二分定位；正文变动、图片加载、尺寸或折叠状态变化后重新测量，不在每个滚动事件中读取所有标题布局。
- 更多菜单增加复制及导出当前文档的 Markdown、快捷键说明。导出包含当前标题和正文投影，不触发保存；标题中的 Markdown 控制字符及文件名禁用字符被处理。Markdown 投影不承诺完整保留富文本、表格、画板的所有交互能力。
- 知识库设置、移动与模板表单复用 `SettingsDialogShell`，删除/归档使用共用确认弹窗。提交中阻止重复操作，失败保留当前对象和输入并可重试；菜单和弹窗保留键盘关闭及焦点行为。

## 共享正文编辑器

- 文内查找支持当前/总数、前后循环、区分大小写和 Enter / Shift+Enter；Esc 返回正文。匹配字面文本，支持跨加粗等内联格式，图片与公式等原子节点中断匹配。只读可查找，不允许替换。
- 单个或全部替换按纯文本处理，允许空替换，保留周围结构与格式。全部替换使用同一正文快照和一个事务，可一次撤销；替换前重新检查正文，避免过时命中修改错误位置。
- 查询长度限制为 1000 字；最多渲染当前位置附近 500 处高亮，全部命中仍用于计数、跳转和替换。正文不变时复用匹配缓存，正文变化后合并刷新，未开启查找时不扫描全文。高亮不写入正文。
- 工具栏插入菜单与斜线菜单共享内容块，工具栏入口可搜索。方向键、Enter、Escape 及中文输入法合成状态都有相应处理，控件补充可访问名称和选中状态。
- 图片及排队附件在发起时锁定编辑器和插入位置，随后续编辑映射位置。晚到回执不抢焦点、不覆盖后来选中的文字；正文已切换、原位置失效、编辑器卸载或变为只读时不再插入。已上传资源仍在资源库，失败附件可按原锚点重试。

详细行为和边界见[文档查找、内容插入与上传定位](editor-search-and-navigation-2026-11-06.md)。

## 数据与性能

- 目录构建用 Map 索引、原位追加同级数组及迭代遍历，移除大量同级节点反复复制数组和深层递归的成本。标题投影在仅有正文草稿改变时保持引用，避免每次输入重建整个首页索引；已打开文档时外侧清单只计算库级信息。
- 文档目录、单篇详情、归档列表和知识库刷新分别复用进行中的请求。目录刷新按键更新，保留相同修订的已加载正文、当前草稿和请求开始后确认的本机变更，不先清空全部文档再回填。
- 目录移动通过 store 的 `moveKnowledgeNode` 合并服务端确认。同一账号切换知识库后仍更新原库目录，界面回执不进入新库；身份改变、源节点或目标库已删除时忽略过期结果。合并保留请求期间本机创建、删除、改名，以及父级和实际文件夹归属的变化；仅补读已加载且文件夹归属改变的正文，最多 4 个并发请求。现有后端 `expectedParent` 不携带同级排序版本，因此不承诺解决所有并发同级重排冲突；这 4 个并发仅用于移动后的正文补读，不是全文检索分页。
- 归档改为展开时或归档深链接时读取。新增可选 `catalog=true` 的归档元数据响应，不加载正文或全局反链；打开一篇再读取完整详情。旧接口不传该参数仍返回原完整响应，权限检查不变，见[接口说明](../api.md)。
- 全局正文检索索引继续只存当前账号内存，沿用成功后最多复用 30 秒的规则；确认修订或目录变化会使其失效。本轮新增每处理 24 篇正文让出一次任务，避免连续构建长期占用主线程。元数据监听改为按 Vue 更新批次合并，移除、归档或撤权后的结果不因下一次网络失败重新出现。未新增正文缓存的容量或过期淘汰机制。
- 创建、更新、详情、保存、删除、归档和恢复链路增加身份及生命周期检查。旧请求不能把已删除、已撤权或前一身份的文档重新放回当前目录；删除前未完成的草稿写入与清理协调，恢复后新输入不被旧清理误删。本机草稿与服务端确认继续区分，失败和冲突不解释为保存成功。

### 一万文档目录微基准

同一 Windows 主机、Node v24.21.0 下，取 `delivery/main` 的 `9a6b86053d4cba69e94e67cd8d36d306ec616a25` 与本轮 `knowledgeDirectory.ts`。两份源码用本地 TypeScript `transpileModule` 转成 CommonJS / ES2020 后分别加载；输入为一个文件夹、`doc-0` 至 `doc-9999` 共 10,000 篇文档，标题函数返回 ID，展开状态为空对象，无自定义排序。每个版本、每个场景预热 2 次，再以 `performance.now()` 测量 9 次调用并取中位数。

| 场景 | 原实现中位数 | 本轮实现中位数 | 返回行数 |
| --- | ---: | ---: | ---: |
| `directoryRows(kb, id => id, {}, '')` 构建完整目录 | 157.80 ms | 8.98 ms | 10,001 |
| `directoryRows(kb, id => id, {}, 'doc-9999')` 检索末尾文档与祖先 | 329.56 ms | 16.94 ms | 2 |

这只测目录算法，不包含网络、服务端、Vue 渲染、浏览器绘制、真实文档正文或用户设备差异。它不能解释为整个页面快了同样倍数，也不是线上延迟保证。自动化另覆盖 12,000 个同级文档、6,000 层目录，以及完整搜索后分批呈现；这些规模用例验证行为，不替代真实浏览器压力测试。

## 验证事实与交付边界

实施期间的全量单元测试曾在代码仍变动时报告失败，因此另建干净 detached 工作树，在上述 `delivery/main` 提交使用同一依赖，对其中原有的 22 个失败文件重跑（`--maxWorkers=2`）。基线结果为 19 文件失败、3 文件通过，45 项失败、348 项通过；45 条失败标题均属于当时工作树日志中的失败。它们涉及既有任务、菜单、发布历史等问题，本轮未扩展修改这些无关模块。基线日志为工作区制品 `artifacts/knowledge-yuque-baseline.log`。这是已有失败的对照证据，不是最终工作树测试结果，也不意味着当前新增失败可以忽略。

本轮单元测试覆盖目录键盘与分批、搜索和替换、上传定位、阅读模式、大纲、跨库/账号迟到回执、删除恢复及归档接口等链路。最终集成测试、类型检查、UI 增量检查和构建结果以本轮收尾记录为准。

浏览器尝试被 URL 安全检查阻止，GUI 验收已停止，没有换通道绕过。因此本轮未完成真实浏览器的明暗主题、320/390px 布局、触摸、实际服务端持久化和完整端到端复测；不能把 jsdom 测试或构建成功称作这些视觉与操作链路已验证。用户提供截图是本轮视觉参考，未据此推断语雀未展示的功能。

以下能力不在本轮交付范围：多人实时协作与光标、完整版本历史和任意版本回滚、评论审批、公开发布站点、语雀导入或同步、全新分享权限体系、全库离线同步、服务端全文搜索引擎，以及 Word/PDF 高保真导出。现有分享、权限和修订冲突能力继续沿用；未新增或宣称上述能力，也未执行生产发布。
