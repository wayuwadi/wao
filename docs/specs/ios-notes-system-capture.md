# iOS 小记系统采集

依据 ADR-323；来源为 2026-10-04 用户确认的微信读书、剪贴板及录音方案。

## 用户路径

- 默认进入小记。前台检测剪贴板有文字，显示“导入文字 / 暂不处理”；用户点击才读取。原生授权失败保留可操作重试，不猜测复制来源。
- 微信读书“分享到其他”选择 WAO。扩展接收文本、URL 或图片；图片只能识别实际收到的图片，不自动抓取书籍全文。预览可修正识别文字、附感想，成功上传后收起并返回源应用。网络/会话失败明确仅存本机；取消不上传。
- 书摘显示只读引用、来源仅采用实际提供的标题/URL；感想可为空。个人感想支持原生录音，结束后自动转文字，转写失败保留录音并重试，成功保存前不删除录音。权限拒绝、无语音、中断、后台返回和加载/保存状态明确。
- 新导入与现有编辑各自独立；草稿随成员隔离，存储失败不能显示已保护。存在服务器不同内容时保留本机输入，不覆盖其他设备或 AI 的最新正文。
- 已保存引用小记可阅读和查看配图，编辑感想携带 expectedRev。原始来源保留复用已有 originals 能力，不新增全量历史。

## 数据与 AI

统一格式 `## 书摘` + 引用块 + 可选来源 + `## 我的感想`；本地字段保存原始摘录，Markdown 转义不改变渲染文字。分享与剪贴板都创建稳定 ID，通过既有 PUT notes/{id} 新建。AI 正文阶段只送感想，结果由服务端拼回原始前缀；空感想不触发正文润色。标题/图/标签遵循现有成员配置。

无新增 HTTP/MCP 操作或旧令牌扩权。CLI 仍可使用已有小记写入能力传标准 Markdown；原生剪贴板、分享扩展及麦克风依赖设备用户操作，不作为服务端 CLI/MCP 能力。

## 验收

本地检查引用/空行/Markdown 特殊字符、重复提交、网络失败、成员迟到响应、草稿恢复、保存失败重试与转写追加；浏览器验证实际接口与手机布局。独立执行 iOS 编译，真机补签名安装、分享菜单显示、微信读书实际载荷、软键盘/安全区、听书中断、锁屏/来电及重新登录。未执行项保留为待验证，不宣称能安装或已上线。
