# 小记图片预览与总览图布局补充

本文补充 [小记与文档的文章总览配图](article-overview-image.md) 的展示约定；在线全尺寸图片可为原格式或像素无损 WebP，原 PNG 另入独立加密归档；现有 URL 与图片生成任务不变。

- 小记清单的卡片正文只展示文字。正文中所有图片按出现顺序，在正文下方以缩略图排列；多图换行，缩略图完整显示画面，不裁切文字。
- 小记清单及编辑页中 WAO 图床图片使用 `/api/images/{id}/preview` 小尺寸 JPEG 预览；`/raw` 提供全尺寸图片，点击缩略图或正文图片的大图浮层、复制图片与图片地址继续读取它。已完成无损优化的 PNG 在相同 URL 返回 WebP MIME 和字节，原 PNG 可由加密归档恢复。对象存储中的新图和迁移旧图可预存轻量预览，其他旧图按请求生成；浏览器缓存最多一小时后重新检查，避免优化切换后长期持有旧字节。不重写富文本地址。外部图片继续使用原地址，无法解码或已足够小的图片沿用原字节。
- 点击缩略图打开大图浮层，可点关闭按钮、背景或按 Escape 关闭；关闭后焦点返回原缩略图。完整文档和分享页继续展示原图。
- 新生成的文章总览图插入正文首位时，默认宽度为正文的 50%，水平居中；大小和对齐属性随富文本正文保存并在再次打开后保持。重复生成替换首张总览图时仍采用此默认布局，用户可继续手动调整。
- 旧小记富文本结构中有图片时以结构为准；只有旧 Markdown 而无结构时从 Markdown 提取缩略图。图片地址不计入文字内容或字数。
- 小记清单的正文字数位于卡片顶部作者、时间一行，与“已保存”并列；阅读区不再额外悬浮字数。原地编辑时，字数继续由编辑器自身显示，口径不变。
