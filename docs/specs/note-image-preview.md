# 小记图片预览与总览图布局补充

本文补充 [小记与文档的文章总览配图](article-overview-image.md) 的展示约定，不改变原图存储和图片生成任务。

- 小记清单的卡片正文只展示文字。正文中所有图片按出现顺序，在正文下方以缩略图排列；多图换行，缩略图完整显示画面，不裁切文字。
- 点击缩略图打开大图浮层，可点关闭按钮、背景或按 Escape 关闭；关闭后焦点返回原缩略图。完整文档和分享页继续展示原图。
- 新生成的文章总览图插入正文首位时，默认宽度为正文的 50%，水平居中；大小和对齐属性随富文本正文保存并在再次打开后保持。重复生成替换首张总览图时仍采用此默认布局，用户可继续手动调整。
- 旧小记富文本结构中有图片时以结构为准；只有旧 Markdown 而无结构时从 Markdown 提取缩略图。图片地址不计入文字内容或字数。
