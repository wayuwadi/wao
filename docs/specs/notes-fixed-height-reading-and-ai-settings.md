# 小记固定卡片、沉浸阅读与 AI 设置

## 用户结果

- 小记预览卡片统一固定高度，长文摘要在卡片内收口；标题始终显示。双击仍进入卡片编辑，按 Enter 或点击阅读入口开始阅读。
- 小记页提供全屏沉浸阅读。键盘方向键、PageUp / PageDown、空格和屏幕翻页按钮浏览当前筛选结果；Home / End 定位首末篇，Esc 退出。切换文章时阅读位置回到顶部，并显示阅读进度。支持窄屏和减少动态效果偏好。
- 阅读模式继续支持润色版与原文切换，图片统一在正文右侧总览，不重新嵌入正文排版。
- 编辑器现有配图提示词设置入口在小记中展开为“设置”弹层，集中提供标题、配图、润色模型选择，以及标题文案、图片生成和正文润色提示词。默认模型为 `gpt-5.6-sol`，可选 `gpt-5.6-sol`、`gpt-5.6-luna`、`gpt-5.6-terra`；偏好按当前成员保存。Linux 主节点现用 ChatGPT 登录态实际拒绝 `gpt-6-*`，旧偏好和旧网页请求统一映射到已验证可执行的 `gpt-5.6-sol`，避免标题、配图和润色连续失败。
- 标题、配图、正文润色分别在任务入队时固化所选模型，后续设置变化不影响已经排队的任务。模型和正文都通过原有隔离 Codex Runner 安全边界；图片任务仍只允许 `image_gen`，正文任务仍只读并满足原文事实保真要求。

## 路由与兼容

- 小记标题和正文润色固定路由至本地 Codex，以便确实应用页面选择的 Codex 模型，不再由通用文档润色账号路由到 DeepSeek。
- `ai_assistant_run.requested_model` 记录本次隔离任务所选模型；v2 Runner claim 返回该值，执行器以 `codex exec --model` 调用。没有传模型的历史及非小记任务保持现有默认路由。
- `NOTE_TITLE` / `NOTE_BODY` 请求可传模型和小记提示词；标题提示词只能补充表达偏好，服务端固定的单行、长度、事实边界不可覆盖。`ARTICLE_IMAGE` 请求可以传同一模型选择。
- 小记模型设置复用成员偏好键值接口；不增加新的 MCP 工具或 CLI 命令。标题、配图、润色是网页内已经保存正文的个人阅读增强任务，没有适用于终端脚本的独立业务动作；若未来要批量处理小记，再设计显式选择范围、版本条件与确认行为的 CLI。

## 验收

- 小记预览卡片等高，长标题、正文、图片、多标签和处理中状态不会把列表卡片撑高；编辑状态可以自然展开以避免裁切输入。
- 阅读模式可由顶部按钮、卡片按钮和卡片 Enter 打开；切换方向键、分页键、Home / End、Esc、润色原文、图片预览、最后一篇边界和无数据状态。
- 设置弹层读取当前成员已保存的三类提示词与模型，保存后刷新读回；保存失败保留输入并提供重试，不覆盖正文或原文版本。
- 未知模型在 API 层拒绝；三个自动阶段的 claim 均携带相同已选模型，Runner 实际调用参数使用该模型；旧任务缺少模型字段仍可执行。
- 本地验证覆盖相关前端测试、服务端测试、CLI 能力台账与迁移编号检查。线上 AI 生成成功需依赖实际可用的本地 Codex Runner 与账号模型权限。
