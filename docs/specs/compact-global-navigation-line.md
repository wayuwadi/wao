# 全局导航单行布局

## 用户结果

- 浏览器主界面在宽屏下将顶部快捷菜单、当前页面页签和常用操作收纳在同一行，减少导航区域占用的纵向空间。
- 快捷菜单和页签各自保留横向滚动及现有拖放、切换行为；页签区域维持可浏览宽度。
- 手机端继续保留紧凑的顶栏与页签布局，页签可另起一行以确保窄屏入口可用。

## 验收

- 宽屏浏览器视口下顶栏与页签呈现为同一行，页面正文随之上移。
- 顶部快捷菜单、当前页签、左右页签滚动及顶栏新建入口均可用。
- 手机视口继续显示紧凑顶栏与页签，应用壳不因合并布局产生整页横向滚动。

> 2026-10-03 后续调整：手机常驻顶栏与页签由 [窄屏内容优先应用壳](mobile-content-first-shell.md) 取代；本规格的桌面单行规则继续有效。
