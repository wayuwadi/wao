# 首页流动粒子背景

## 用户结果

参考用户指定的 `https://geo.xingshiapp.cn/login?redirect=/` 登录页，将深蓝到青蓝渐变、细网格及缓慢旋转变形的粒子球效果融入首页顶部起步引导。独立实现视觉效果，不引入参考站的品牌、登录逻辑或远程资源。

- 保留待办、文件库、项目三个真实入口、引导收起偏好与默认折叠的 AI Run。
- 粒子只作为背景，不拦截点击、不进入辅助技术阅读顺序；文字和入口始终可读。
- 提供暂停 / 播放动效按钮并记住本机偏好。系统要求减少动态效果时显示静态背景。
- 页面不可见、背景离开视口、引导收起或组件停用时停止绘制；卸载时清理动画帧和监听器。
- 小屏减少粒子数量，限制画布像素比与绘制频率；Canvas 不可用时保留渐变和网格。

## 验收

本地前端连接既有业务服务和数据库，检查动效、暂停后刷新恢复、三个入口导航、引导收起展开、桌面与窄屏。自动测试验证动画停止 / 恢复、减少动态效果和资源清理；执行首页回归、类型检查与生产构建。按 ADR-232 合并 PR 后结束，不等待发布。

## 本次验证记录

- `HomeView`、`HomeStartGuide` 原有 49 项与 `HomeParticleBackdrop` 新增 4 项测试通过。新增用例覆盖暂停持久化、系统减少动态效果及变化、收起 / 离屏 / 页面隐藏时停止、卸载清理、存储失败和 Canvas 不可用降级。
- 变更文件 ESLint、`vue-tsc --build`、`vite build` 与差异检查通过；构建保留既有大包提示。工程一致性检查无错误，保留 4 个历史 ADR 重号警告。
- 本地 `127.0.0.1:5231` 复用 `127.0.0.1:18080` 的既有业务服务与真实登录会话。首次全量数据加载超时，点击重试后恢复；之后验证待办、文件库和项目入口均能读取真实数据。
- 浏览器检查 1280px 桌面和 390px 窄屏：粒子持续流动，暂停后刷新仍暂停，播放恢复，起步引导收起展开正常，AI Run 保持默认折叠。窄屏暂停按钮放在左下角，避开右下角既有浮动入口；实际点击通过，内容可以纵向浏览。
- 系统减少动态效果由自动测试验证，未修改本机操作系统偏好。没有新增接口、业务数据、数据库迁移或第三方资源依赖。
