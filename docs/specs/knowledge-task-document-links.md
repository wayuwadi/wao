# 知识库独立于项目，任务明确关联文档

本规格取代 `phase-1-project-document-creation.md` 的项目知识库与自动项目出链规则。

- 知识库不再属于项目。列表取消项目分类、项目标记，知识库页取消关联项目入口；历史项目知识库允许独立编辑名称、简介和删除到回收站，自动化知识库原规则保留。
- 项目文档页只读汇总该项目主任务及全部子任务明确关联的文档，去重并排除已归档/删除文档。空状态引导从具体任务关联，前往知识库创建文档，不再创建项目知识库。
- 文档选中文字建任务、小记建任务和上传附件，不再根据知识库自动推断项目。任务与文档的关联及文档间引用保持可用。
- 项目动态、按项目筛选的 AI 知识来源只使用任务文档集合，不读取历史知识库项目归属。
- 新建知识库接口兼容但忽略 `project`；知识库响应的 `project` 固定为空。历史数据库字段保留，无批量迁移、不删除/移动历史知识库或文档。删除项目不移除知识库。
- 文档响应及新写入的 `links` 不再包含 `type=project`；历史存储出链不批量改写。项目详情历史 `docs` 不再参与文档汇总。
- 旧 `POST /api/projects/{id}/brief-doc` 返回业务错误，提示在知识库创建文档并关联到任务，不再写入数据。
- 旧点子转项目仍保留点子与项目的既有流程，但历史资料沉淀到独立的点子资产库，不再为知识库或资产文档新增项目关联。

验收覆盖历史项目库独立编辑、文档新建不继承项目、任务与子任务文档去重及跳转、取消关联后移出汇总、旧出链不扩散、项目删除不移除知识内容、按项目检索不泄漏整个库。
