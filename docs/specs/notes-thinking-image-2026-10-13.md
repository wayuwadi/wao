# 小记第二张思考图

用户确认保留现有总览图，保存后自动生成第二张思考图。总览图的提示词、出镜策略、80字符门槛、已有图片保留及独立重试不变。

- 新增独立 `thinking` 阶段，与标题、总览图、正文、标签并行。成员开关默认开启，关闭及取消代次独立；只对新建或正文变化后的保存执行，不扫描或重跑历史小记。重复保存、元信息修改、派生写回不重复调用。旧 MCP `withoutAuto` 边界继续有效。
- 固化本次已保存正文及来源版本，只分析当前篇，最多12000字符；过长或没有文字明确跳过，不静默截断、不调用历史检索或外部搜索。
- 本机只读模型先返回结构化提纲：一个发现、1至3个逐字观察、1至3条带依据序号的推测、1至2个其他解释/信息缺口、1至2个具体问题、一个小验证。观察必须是原文连续引文，关系序号、字段长度、类型和总文字量由服务端校验。语义仍需用户判断，不以逐字校验证明因果。
- 通过校验先保存可复制提纲，再以中文字体排版为2048×1536 PNG。图片失败时，伴读仍展示已保存提纲、具体问题与重试入口。图中的文字与可复制提纲使用同一份数据，明确标注原文观察、AI推测、待验证。目标200至350字，最多550字；没有可用字体或版面溢出时失败保留原文，可重试。
- 使用现有 `note_ai_stage_attempt`、`text_polish_job`、`note_ai_artifact` 持久保存真实来源、执行状态与成果。思考图是独立AI衍生成果，不插入正文、不覆盖总览图、不成为后续自动分析的用户事实。失败、关页、取消、来源更新沿用持久队列和按代次校验；旧图保留并标注原文已更新。
- 小记卡片与阅读图片清单展示第二张AI图片，可全屏、复制提纲、围绕问题继续聊，伴读已有未发送问题不得被覆盖。第一张和正文图片保留位置；思考图不提供“返回正文”入口。
- 图片在落库同一事务中持久标记为私有，匿名原图/预览不可读。私人伴读与工作流数据仍仅成员本人可读。公开分享继续只分享作者明确生成的已保存阅读快照，不隐式附加私人AI历史。

## 契约与权限

`GET /api/docs/notes/ai-settings` 新增 `settings.thinking`、`thinkingEpoch`；旧客户端省略时保留当前选择。关闭递增代次，CAS与设置草稿保护不变。

`GET /api/docs/notes/ai-workflows` 新增 `thinking` 和 `thinkingImage`（图片地址、提纲、标题、问题、来源版本、是否当前）；`stages.thinking` 提供失败/跳过原因。`POST /api/docs/notes/{docId}/ai-stages/thinking` 复用幂等请求号与expectedRev，仅作者可重做。伴读成果增加 `stage=thinking`、`thinkingImage`；不得通过通用采用/恢复接口把提纲写进正文。

CLI/MCP未获得私人AI消费、成果或模型配置权限，本次不扩充旧令牌、不新增命令。以后增加独立AI scope 时重新评估命令及按篇授权。
