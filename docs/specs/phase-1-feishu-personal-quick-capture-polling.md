# Phase 1：飞书个人收集主动轮询

本规格扩展 `phase-1-feishu-personal-quick-capture.md`，不改变其个人归属、未排期待办和持久去重结果。

## 用户结果

- 管理员已配置群聊归档的 App ID、App Secret 和目标群后，只需打开“群聊快速收集”，
  不再强制先配事件回调。
- 成员在目标群 @ 当前 WAO 机器人后，任务最迟在一个轮询周期后创建并回群。
- @ 其他成员、机器人自己发的卡片、已撤回消息和普通聊天均不创建任务。
- 后续再配事件回调时，同一条消息仍只创建一次。

## 验收

- API 客户端正确解析消息 `mentions[].id.open_id` 并读取当前机器人 `open_id`。
- 轮询测试覆盖开关、精确提及、发送者类型、撤回和重叠时间窗。
- 实机开启后日志不得出现飞书权限或 Bot Info 错误；用真实成员 @ 机器人验证回执、任务归属和去重。
