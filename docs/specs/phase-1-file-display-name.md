# Phase 1：文件展示名

对应任务：`t1788397920729`。

## 用户结果

1. 普通文件上传后，可在项目“文件”页签或全局“文件与图床”中修改 WAO 内展示名称；项目“HTML”页签也可修改上传后页面的 WAO 显示名称。
2. 修改结果持久化，并同步用于文件下载确认页、音乐播放器和后续任务关联等站内展示入口。
3. 展示名不覆盖上传时的原始文件名；下载文件名、类型识别、正文和既有分享地址保持不变。

## 数据、权限与失败边界

- `file_blob.display_name` 可空，历史文件和未改名文件回退显示 `name`，不猜测或批量生成展示名。
- 展示名去除首尾空白后须为 1～255 个字符；项目文件修改前继续校验当前成员的项目访问权限。
- 保存中禁止重复提交；保存失败保留用户输入和重试入口，取消编辑恢复服务端已保存值。
- 项目 HTML 改名复用已有托管页标题更新能力；只改名称时保留 HTML 正文、原文件名与现有分享后缀，公网地址不变。

## 验收

- 在项目详情打开“文件”，修改一个文件的展示名并刷新页面，新名称仍存在；原文件名仍作为辅助信息可见。
- 在全局“文件与图床”找到同一文件，名称同步更新；再次修改后返回项目页也显示最新结果。
- 用既有分享地址进入下载确认页时显示新名称，下载所得文件仍使用上传时的原文件名。
- 输入空名称时页面提示必填且不发请求；模拟保存失败时输入不丢失，点击“重试”可再次提交。
- 在项目“文件 → HTML”页签点击“改名”，保存并刷新后新名称仍存在；原始 HTML 文件名和分享地址保持不变。
