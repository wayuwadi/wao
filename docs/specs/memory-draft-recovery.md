# 记忆编辑：草稿与服务端保存结果分离

补充统一记忆中心规格；不改变接口、权限、审核或版本规则。

- 本机读取失败或格式异常时仍可编辑，显示恢复限制，不自动删除或覆盖旧草稿。只恢复已知字符串字段。
- 本机写入失败时保留页面内容，明确尚未落盘，提供重试保存草稿；不声称草稿已保存。关闭含未落盘内容的表单前提示备份。
- 保存进行中锁定输入、关闭与重复提交，服务端失败后恢复编辑并保留内容。无效时间在发送前提示。
- 服务端成功与本机清理、列表刷新独立处理。清理失败持续提醒核对旧草稿，不把已完成的服务端写入显示成失败。

验收包括存储读写异常、恢复重试、保存期间关闭、服务端失败、成功后的本机清理失败，以及真实页面的草稿刷新恢复和取消退出。
