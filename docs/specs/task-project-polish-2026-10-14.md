# 任务详情与项目表格交互优化

来源：[娃弟记录的 WAO 项目优化](https://wao.wayuwa.cn/api/share/tasks/t6850479a0d7547ada18e5b6bc0bc18d.md)。本规格根据 2026-10-14 用户反馈修订任务详情分区的默认行为，保留原自动保存、权限与草稿约束。

| 用户条目 | 交付行为 |
| --- | --- |
| 快速新建的空框收起 | 有标题时 Enter 创建并保留连续输入；创建后的空框按 Enter 或 Esc 收起，输入法组合不触发。Esc 保留未提交输入，重新打开同组恢复；提交中禁止收起。 |
| 详情默认展开属性 | 桌面任务与子任务首次打开默认显示属性与关联，评论在主栏末尾连续展示。对象切换保留各自手动选择；手机保留正文优先和属性切换，避免遮挡描述。 |
| 顶部删除入口 | 顶栏直接提供删除当前任务或子任务按钮，确认窗明确显示对象名称；取消不删除，失败保留窗口并允许重试，保存期间禁止重复提交。原属性栏删除入口保留。 |
| 概览直接编辑描述 | 概览复用现有描述编辑器，短描述按内容增高，概览最大高度为 min(360px, 42vh)，长内容在区域内滚动；描述页签进入全文。页签切换不重建编辑器，正文、图片、上传与自动保存继续使用原数据链路。 |
| 收藏项目排序 | 侧栏项目收藏可上下拖动，按落点决定前后；Alt+上下键也可调整。成员偏好保存，失败保留本机顺序并可重试；拖向顶部快捷栏的原行为保留。 |
| 表格列宽拖动 | 各列标题边界提供拖动柄及左右键微调，标题最小 160px、其他列最小 48px，最大 2000px；主任务与子项共用 colgroup。按成员和项目保存，刷新恢复，隐藏字段不删除已保存宽度。 |
| 类型选择器美化 | 使用现有工作项图标与带选中态的浮层菜单，图标与名称保持固定间距和左对齐，当前项以主题背景高亮表示，不追加对勾；保留 menuitemradio / aria-checked 与原 workItemType 保存链路。 |

## 持久化与权限边界

新增偏好键 `favorite-project-order-v1` 和 `project-table-widths-v1:<projectId>`，复用当前成员的 GET/PUT preferences；无业务接口、数据库字段、迁移或 CLI/MCP 授权变化。偏好串行保存，迟到读取不覆盖新编辑，成员与项目切换忽略旧请求，失败草稿可重试。收藏顺序只影响个人展示，不改变导航菜单、项目领域或共享成员。

## 验收

覆盖快速新建成功/失败/重复提交与输入法；任务与子任务默认属性、概览编辑及刷新恢复、草稿与冲突；顶部确认/取消/失败重试及对象隔离；真实收藏拖动与刷新；列宽拖动、键盘、失败重试、项目与成员隔离；类型菜单及自动保存；明暗主题、桌面与 320/390px。真实链路使用本机前端、隔离业务服务和既有数据库，仅操作本轮明确标注的专用验收样本，不改真实工作任务。

列宽补充：显示设置中的‘恢复默认列宽’清空当前成员在当前项目的宽度偏好，不改变可见字段。

2026-10-15 补充：类型菜单去除对勾，避免选中项与其他项的文字错位。知识库首次打开文档、切换文档及刷新重开默认展示右侧一至三级大纲；同一篇文档可通过大纲开关、关闭按钮或 Esc 收起，关闭后恢复开关焦点。无标题时显示现有空状态；仅切换展示状态，不修改正文、草稿或保存语义，无业务 API、MCP / CLI 或数据库变化。
