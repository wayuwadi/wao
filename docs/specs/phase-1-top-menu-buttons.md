# 规格：顶部菜单按钮停靠区

任务原文：<https://wao.wayuwa.cn/api/share/tasks/t1788926424901.md?openOnly=true>。

## 用户结果

在应用顶部标题与操作按钮之间增加菜单停靠区。侧栏菜单、左下角停靠图标可拖入这里，变成带原图标和名称的按钮；可在顶部拖拽排序，也可拖回侧栏分组或底部图标区。点击仍按菜单原有路由和打开方式进入真实功能。

## 对既有规格的扩展

扩展 `phase-1-sidebar-menu-direct-management.md`：内置菜单注册表与外部应用注册表的 `placement` 新增 `TOP`，与 `MENU`、`DOCK` 互斥，旧值和缺省规则不变。继续使用现有设置接口和持久化 JSON，不新增数据库 migration。顶部跨分组统一按 `order` 排序，保留 `group` 以便移回；外部应用仍不能移入顶层分组。

菜单位置沿用现有全局注册表及权限，设置 → 菜单配置增加“顶部按钮”选项，不新增成员级偏好或快捷链接副本。

## 交互与验收

- 空区显示拖入提示；跨侧栏与顶部共享菜单拖拽状态，不接受普通文本或页签作为菜单。
- 拖拽落点有可见反馈；保存中禁止重复拖动，成功提示已保存，失败恢复服务端位置并提示重新拖拽。读取失败提供重试。
- 按钮保留文字，长名称截断并以悬停标题提供全名。顶部独立横向滚动，左右按钮和边缘拖动辅助浏览与排序，不挤掉右侧动作。
- 手机保留顶部按钮浏览和点击，关闭桌面拖拽；不改变既有手机侧栏和页签行为。
- 验收：菜单→顶部→底部→侧栏往返；不同分组和外部应用混合排序；刷新后位置保持；按钮按原方式打开；失败后重试；窄屏和长名称仍可浏览。
