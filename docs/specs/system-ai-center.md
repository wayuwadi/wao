## 用户结果

能力中心新增「系统 AI」区域，保留发现能力、我的连接、我的发布。左侧可搜索、按 AI / Python / AI + 工具筛选功能，右侧为能力介绍、功能设置、运行记录。原功能入口保留；中心通过现有组件和接口修改同一份成员配置，不建立第二份设置。

首批登记实际在用的小记整理、配图、文档配图、伴读、顺手发现、卦象解读、卦象配图、文本润色和页面问答。历史 Runner / 手动挖掘不恢复。Python 与混合类型先提供真实空状态，不能把设计演示的文件解析和附件摘要当作已实现功能。

## 配置与运行边界

- 小记整理、配图和文档配图共用现有小记配置保存组，页面明确影响范围；天人一卦使用独立保存组。提示词、模型目录、成员隔离草稿、版本冲突和重新读取复用原表单。
- 设置在页面内展示，卦象表单使用同一组件的内嵌模式，不创建弹层、焦点陷阱或全局遮罩。切换区域后草稿仍保留。伴读采用方式与顺手发现沿用各自 CAS 版本，失败保留选择，冲突必须明确处理。
- 文本润色方法复用原工作台的仅设置模式；不恢复或清空原文草稿、不继续待执行任务。页面问答执行能力按单次对话选择，无全局伪开关。功能无可编辑参数时明确说明，并链接实际入口。
- 运行记录只读实际接口：本人伴读队列与回执、顺手发现执行状态、今天卦象状态及配图状态、本人润色记录与问答会话。记录不可读取时展示失败与重试，暂无记录与尚未接入跨功能日志分别说明；不自动触发模型、起卦或重跑。
- 模型与执行展示 WAO 服务主机的本地执行器、实际模型目录、允许选择的模型 API，以及各依赖可影响的功能。配置检查通过不等于模型调用成功；目录无更新时间不伪造。API 只关联实际支持 API 选择的页面问答，不推断其他功能自动使用或自动回退。
- AI 账号管理复用原管理组件与原接口权限。原设置入口保留；中心不会增加任何设备令牌授权。

## 数据与开放能力

功能目录是与现有代码对应的类型化注册表；运行状态与设置来自已有认证 API。仅登录成员挂载系统 AI 页面，切换账号销毁旧表单和请求，迟到响应丢弃。局部接口失败不阻塞其他资源，保留明确错误。

本次无新增 HTTP / MCP / CLI 业务操作或数据库结构。设备令牌没有成员设置管理权限，目录和设置只为浏览器会话展示；CLI 仍以实时 tools/list 为准，不扩展旧令牌。后续注册 Python 执行器需先定义实际健康接口、成员权限和工具登记，再补充对应能力。
