# WAO 柔环 W 品牌标识

2026-10-04，用户对比三种概念后确认第一款「柔环 W」。本规格替代 [蓝青丝带标识](wao-ribbon-brand-identity.md) 在浏览器版本中的当前应用；原规格与历史图片保留。

## 图形与资源

- 延续 W 与连接的含义，使用紧凑、圆润的连续环形轮廓，取消立体渐变。图形颜色为蓝紫 `#5665e9`；配套 WAO 字标继续继承页面文字色。
- 唯一矢量母版为 `wao-web/public/brand/wao-soft-loop-v3.svg`，`viewBox="0 0 100 100"`，线宽 8，圆角连接与端点。正式轮廓与用户确认的第一款 Demo 一致。
- 页面 `WaoLogo` 直接加载矢量图，固定为 32 × 32 CSS 像素，首次渲染即预留尺寸。资源路径使用主站 `/brand/` 固定前缀，避免不可变发布目录仅开放 `/assets/` 时资源失效。
- 浏览器图标优先声明 SVG，同时提供由母版直接导出的 64px 透明 PNG；保留根路径 `favicon.svg` 与包含 16 / 32 / 48 / 64px 图像的 `favicon.ico` 兼容入口。
- Apple 图标为 180px 白底 PNG；manifest 的 `any` 图标为 192 / 512px 透明 PNG。单独提供 512px 白底 `maskable` 图标，母版居中缩放至 80%，使图形位于中心安全圆内，避免系统裁切。
- 所有新品牌资源使用 `v3` 文件名，浏览器不复用历史图标缓存。已安装的浏览器应用图标是否刷新、何时刷新由浏览器管理。

## 应用范围

已有 `WaoLogo` 的侧栏、任务分享、文档与小记分享、文件下载、桌面宠物下载入口统一使用新图形；其他采用该公共组件的入口也同步生效。浏览器标签页、添加到主屏幕与浏览器安装入口使用同一套资源。

保持导航折叠、手机布局、登录与分享权限的现有行为，不改业务接口、数据、主题配置或独立客户端安装包。

## 验收

- 对比母版与已确认 Demo，检查 16 / 24 / 32px、明暗背景、字标组合与页面首屏布局。
- 类型检查、生产构建、受影响导航与分享回归；检查版本化构建后的 HTML 图标地址及公共资源可访问性。
- 本地前端连接既有业务服务，验证真实用户侧栏、展开与折叠、窄屏以及公开入口。图形变更不要求修改用户数据。
- 检查各 PNG 的尺寸、透明背景与白底，以及 `maskable` 图形未越过安全圆。
