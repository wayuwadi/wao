# 能力中心规划信息收纳

按用户确认的系统精简建议，增补能力中心规格的应用接入展示边界。

- 尚无真实提供方的外部应用接入从资源类型筛选和可选能力列表移除，发现与连接区域底部使用默认折叠的简短规划说明。
- 旧 `type=应用接入` 深链自动展开规划说明，同时提供真实能力列表及 Skill 资源入口；不变成假授权页面或空筛选结果。
- 原 CLI/MCP 真实目录、连接草稿、权限签发、Skill/Pet 发布工作台及游客边界保持原行为。
- 仅调整浏览器呈现，不变更接口、CLI/MCP 工具、账号权限或已保存数据。

验收：默认筛选与列表不混入规划项；旧深链与 Skill 跳转；游客、目录失败和发布文件草稿回归。
