# 按天待办切换四象限

补充日视图与现有四象限规格。用户要求在按天待办切换四象限；不改变 API、数据结构或部署方式。

- 当天任务提供清单／四象限按钮，四个象限始终显示。沿用 P0＝重要紧急、P1＝重要不紧急、P2＝不重要紧急、P3＝不重要不紧急，不从截止日期推断。
- 两种布局使用同一日期工作区：当天安排和当天推进过的未收尾任务归入四象限；其他日期和无当天记录的任务不混入。当天推进但未排期继续明确标注。待验证以及主任务完成但子项未收尾仍是待办。
- 真正已收尾的任务保留独立已完成区，保存中、保存失败与记进展的条目保持可见。切换保留日期、标题和项目草稿、子项选择及进展草稿；日期和成员隔离沿用现有机制。
- 今天与未来可通过任务象限下拉框修改既有优先级，使用本机任务草稿与串行保存。保存失败仍显示当前选择及处理保存入口。排时、进展和子事项操作复用日视图，历史及未来的完成限制不变。
- 历史 API 未保存当日优先级，象限仅按任务现有优先级组织阅读，并显式说明；标题、状态、步骤和进展仍来自当日快照，不补造历史优先级。历史不提供象限编辑。
- 清单默认，浏览器按账号与成员记住布局，与全部待办布局独立。存储不可用仍允许切换并显示重试；不新增同步接口。
- 宽屏两列、窄容器单列；长标题、明暗主题、键盘焦点和空态使用既有组件与主题 token，页面统一滚动。

验收：当天范围、四象限映射、未收尾子项、草稿保护、保存失败、历史只读、日期与成员切换、空态、明暗主题、窄屏和键盘。
