# 网页宠物：张三丰 v2

本规格补充 `phase-1-web-ai-pet.md`：默认宠物从静态浣熊更换为用户提供并完成升级的张三丰 v2。品牌标识和桌面客户端素材不变。

- 图集为 1536×2288，8列11行，每格192×208；前9行保留原有57帧动作，后2行是16个顺时针视线方向，0行6列为正面默认姿势。
- 网页通过逐帧切换显示待机和点击互动，停止使用整张静态图片缩放来模拟这些动作。待机开关关闭时不播放自动动作；用户主动互动仍可播放。
- 宠物收起后的恢复入口使用同一角色；图片加载中/失败时保留“張”占位和原有按钮功能。
- 系统减少动态效果、标签页不可见或组件卸载时停止动画计时器；动作时长沿用图集契约。
- 任务提示、今日节奏、点击/长按、静默期限、个人偏好和浏览器位置键不变，不迁移数据库。

素材来源：用户提供的 `zhang-sanfeng` 包，原角色作者 anthony，参考页 https://codex-pets.net/#/pets/zhang-sanfeng 。v2 方向为本次用户授权生成；原始作者、图集尺寸和文件摘要见素材目录说明。
