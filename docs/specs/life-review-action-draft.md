# 从人生回顾创建行动草稿

补充周期人生回顾和个人行动计划规格，保持既有 API、提醒和权限规则。

阅读回顾 → 选择一条问题或建议 → 创建本机行动草稿 → 行动计划页确认来源 → 填写目标、日期、每周动作 → 保存计划。

- 使用现有行动编辑器，不把回顾问题自动改写成承诺，不额外调用 AI。
- 保留来源周期和原文；长度允许时带入愿景，标题和动作由用户填写，默认提醒关闭。
- 回顾草稿按成员和来源隔离，重复进入恢复已填内容，不覆盖普通新建草稿；不打断目标页已打开的编辑器。
- 本机写入失败不跳转，目标草稿缺失或损坏时明确提示返回回顾。
- 保存成功只清理当前草稿，失败保留表单；服务端成功与本机清理结果分开提示。
- URL 只含草稿标识，不放回顾正文。

验收覆盖来源带入、草稿隔离、刷新恢复、提醒关闭、确认保存、失败重试和真实跨页路径。
