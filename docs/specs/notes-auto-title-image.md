# 小记自动标题、配图、润色和图片复制

## 用户结果

- 新小记首次保存时先可靠保存正文。标题、配图和润色默认开启，作为小记的默认 AI 能力，集中放在「设置 → 个人 → 偏好」中按成员保存；记录页面不再逐篇展示开关。旧成员没有设置时三项默认开启。保存成功后，只按当前成员设置执行；三项都关闭时只保存正文，不启动 AI 任务。后续编辑已有小记不自动重生成。AI 暂不可用时保留已保存的小记和可恢复任务，不把正文保存失败说成生成失败。
- 小记整理方式默认并行、同时生成上限为 3 项。并行时标题、配图和润色按当前成员的并发上限启动；多个小记共享该上限。设置可切换串行或调整 1–5 项并发；串行时按标题、配图、润色的顺序执行且上限为 1。新小记的工作流由服务端持久续跑，不依赖浏览器保持打开；模型选择和 Runner 并发仍遵循现有设置。
- 原文始终是可编辑事实源；润色版按成员保存为阅读版本，卡片悬浮或获得键盘焦点时可在“润色 / 原文”间切换。原文变化后旧润色版失效，不能覆盖新正文。
- 卡片更新时间后展示标题、配图、润色三个语义图标；成功的三个阶段默认收起，正在执行或失败时展示进度，失败可重试。编辑中的小记点击重试时先保存草稿，保存失败则保留草稿并显示可再次操作的重试入口；保存成功后再续跑未完成步骤。收起编辑后若仍留有未保存的本地草稿，点击重试会打开该草稿并提示先确认保存；与当前服务端内容完全一致的旧草稿可直接清理并重试，不让按钮看似无响应。总览图在正文旁作为小封面，置顶与分享操作在悬浮时出现。右上角集中筛选标签、有无图片、今天 / 昨天 / 以前，并选择排序。
- 对没有自动整理历史的旧小记，也始终显示三个默认状态的按需操作图标。点击标题、配图或润色图标只启动对应步骤；正在执行时不可重复启动，失败时续跑未完成任务，已完成或跳过的步骤可再次单独生成。存在未保存草稿时先引导保存，不让 AI 结果覆盖草稿。
- 手动点击小记编辑器的“总览配图”时，同时提炼标题。已有总览图时先展示新图，用户明确选择“保留原图”或“替换为新图”；选择前正文和原图保持不变。
- 小记清单缩略图、打开后的大图，以及文档正文中的图片和预览图，右键提供“复制图片”“复制图片地址”。复制失败显示可操作提示。

## 状态与冲突

- 新小记首次保存后，仅对已启用阶段调度任务；标题和正文通过现有持久只读 AI 队列及 `/api/text-polish/jobs` 幂等接口执行，标题单行最多 30 字，正文保留事实、数字、原意和 Markdown 结构。`NOTE_TITLE` 与 `NOTE_BODY` 允许同一成员多任务并存；这些任务不写入润色历史或聊天历史，任务表仅保存正文哈希用于幂等核对。
- 并行模式下，多篇小记的标题、配图、正文润色共用当前成员设置的服务端并发上限；同一小记的写回使用文档行锁及最新版本，防止彼此覆盖。正文润色结果待图片等正文写回结束后，再核对正文并保存对照版本。串行模式按标题、配图、正文润色的顺序执行。普通 AI 问答保持原有成员互斥行为；独立阶段失败不阻断其他阶段，失败步骤保留原任务并可重试。
- `GET /api/docs/notes/polish-versions` 读取当前成员的对照版本；`PUT /api/docs/notes/polish-versions/{docId}` 保存 AI 结果时校验源 Markdown 与当前文档一致。持久化表 `note_polish_version` 不改写 `doc`，每成员每篇保留最近一次原文与润色版。
- 新小记的自动整理状态、任务 ID 和阶段结果由服务端持久保存，正文始终从已保存文档读取；关闭浏览器后仍会继续执行。未启用阶段标记为“已跳过”，刷新或重试不会重复提交已完成或跳过的阶段。原标题和正文在后台生成时仍可正常阅读、编辑。旧版浏览器续跑任务仍按原本地兼容状态恢复。
- 自动写回标题、标签和图片使用 `expectedRev`。如果用户在等待时修改了小记，生成结果不会覆盖新版本；页面明确提示。自动结果之间使用最新自动写回版本继续校验；润色版在其他写回完成后以最终原文保存。AI 错误保留重试入口。自动图片只对新小记首次生成；已有小记可手动重生成并决定是否替换。
- 手动生成的新图先预览，确认后插入正文，并沿用编辑器原有保存机制。图片复制采用图床原图；地址复制为可打开的绝对 URL。

## CLI 与权限

`NOTE_TITLE` 与 `NOTE_BODY` 是小记页面的自动编辑辅助动作，结果需结合文档版本条件写回或保存为对照版本，不新增独立 `wao` CLI 命令，也不自动向工作区 MCP 旧令牌暴露。若以后需要终端批量整理小记，应设计带版本条件和明确权限的独立业务命令后重审。

## 本次本地验收（2026-09-25）

- 浏览器使用本地前后端与既有线上数据库，实测标签、有无图片、今天筛选和窄屏封面布局；新建验收小记后，标题任务失败并展示重试入口，验收小记已移入可恢复回收站。本地服务未配置与线上一致的加密密钥，无法解密已配置的 AI 账号，因此标题成功后的实际配图、润色链路此次未能走完；页面显示的“系统繁忙”是通用错误提示，不代表 AI 服务端繁忙。
- 自动并行/串行、并发上限、同一小记条件写回、旧正文冲突、润色对照和删除后的任务取消由针对性测试覆盖；前端类型检查和生产构建通过，服务端润色任务、对照保存与 Flyway 编号测试通过。V164 新表迁移在本地服务连接的既有数据库上成功执行。
