# 小记自动标题、配图和图片复制

## 用户结果

- 新小记首次保存时先可靠保存正文，再异步生成简短标题和总览图；后续编辑保存不自动重生成。AI 暂不可用时保留已保存的小记和可恢复任务，不把正文保存失败说成生成失败。
- 手动点击小记编辑器的“总览配图”时，同时提炼标题。已有总览图时先展示新图，用户明确选择“保留原图”或“替换为新图”；选择前正文和原图保持不变。
- 小记清单缩略图、打开后的大图，以及文档正文中的图片和预览图，右键提供“复制图片”“复制图片地址”。复制失败显示可操作提示。

## 状态与冲突

- `NOTE_TITLE` 使用现有持久只读 AI 队列和 `/api/text-polish/jobs` 的幂等任务接口，返回单行标题，最多取 30 字；只对当前成员可见，不写入润色历史或聊天历史。润色任务表只存正文哈希用于幂等核对，不另存正文副本。小记标题生成和配图任务并行启动。
- 保存后自动生成任务只保留成员、文档、任务 id 和版本号在浏览器本地；正文由服务器已保存文档读取。刷新后继续查询原任务，不重复提交。原标题和正文在后台生成时仍可正常阅读、编辑。
- 自动写回标题和图片使用 `expectedRev`。如果用户在等待时修改了小记，生成结果不会覆盖新版本；页面明确提示。AI 错误保留重试入口。自动图片只对新小记首次生成；已有小记可手动重生成并决定是否替换。
- 手动生成的新图先预览，确认后插入正文，并沿用编辑器原有保存机制。图片复制采用图床原图；地址复制为可打开的绝对 URL。

## CLI 与权限

`NOTE_TITLE` 是小记页面的自动编辑辅助动作，结果需结合文档版本条件写回，不新增独立 `wao` CLI 命令，也不自动向工作区 MCP 旧令牌暴露。若以后需要终端批量整理小记，应设计带版本条件和明确权限的独立业务命令后重审。
