# 小记默认私有与限时分享

用户确认：主动生成有期限、可撤销的免登录链接，并明确提示持有链接的人可读。

- 小记不再通过文档 ID 的公开 JSON、Markdown 和飞书正文预览读取。任务与普通知识库文档沿用原有分享契约。
- 只有小记作者能创建、查看和撤销分享。默认 7 天，另提供 1 小时、1 天；打开分享设置和复制给 AI 均不自动开启公开访问。
- 分享固化已保存的阅读版本及配图，不包含本地草稿、后续修改、原文对照与来源信息。链接使用 256 位随机令牌，数据库只保存令牌摘要。
- JSON、Markdown 和分享配图每次请求检查期限、撤销状态、源小记存在和作者归属；失效统一返回 404，使用 no-store / noindex。
- 移入回收站撤销所有既有分享，恢复小记不会恢复旧链接权限。
- 小记使用过的图片和附件保持私有标记，删除引用不恢复匿名访问。小记图片仅通过有效分享及快照内图片 ID 读取；附件仍需登录。
- 明确告知分享范围和“持有链接的人无需登录即可读取”；撤销不能收回对方已下载的内容。已有无期限小记链接失效，需要作者重新生成。
- 复制给 Codex/ChatGPT 使用正文快照和逐张图片剪贴板，不隐式创建公网链接；需要远程直读时主动生成限时分享。
- 不为新分享生成飞书正文/配图预览；第三方曾缓存或下载的内容无法追溯撤回。

## 接口

作者会话：`GET/POST /api/docs/{id}/public-shares`，POST `{durationHours:1|24|168}` 返回一次性令牌及期限；`DELETE /api/docs/{id}/public-shares/{shareId}` 撤销。

公开只读：`GET /api/share/notes/{token}` 返回 `{doc,expiresAt}`；同路径 `.md` 返回完整 Markdown；`/images/{imageId}/raw` 返回快照配图。浏览器页面 `/s/n/{token}`。

CLI/MCP：此次新增为浏览器内明确授权的分享操作，不自动赋予已有工作区令牌公开私人小记的权限。暂不新增 CLI/MCP 创建分享命令；能力台账记录边界。

## 验收

公网联调补充：统一 HTTP 层将业务错误的状态放在 `Error.status`，分享页同时识别该字段及原始 Axios 响应状态。404 显示链接无效/撤销/到期及主动生成分享提示；网络故障保持失败重试反馈。

知识库编辑入口补充：以真实文档所属知识库及当前小记路由识别私有小记，图片上传使用“小记”来源，附件携带 `privateNote`。上传后、正文保存前即受服务端持久私有标记保护。

覆盖作者/其他成员/匿名、旧 ID、配图和附件旁路、无效/过期/撤销/删除、快照隔离、图片跨分享访问、默认不创建、失败重试、草稿不受影响、明暗主题和窄屏键盘操作；本地复用既有真实数据库，发布后核对版本及匿名旧入口失效。
