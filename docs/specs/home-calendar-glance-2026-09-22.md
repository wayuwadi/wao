# 首页常用信息与日历总览

本规格取代日历待安排清单的展示约定，并调整首页默认折叠 AI Run 时的信息层级。

- 首页常驻 Codex 真实周额度、重置时间及已有会员权益信息，独立于 AI Run 的折叠状态；保留读取失败、重试和过期快照处理。天气以小卡片复用成员已保存城市、显示偏好及真实预报，不引入额外定位请求。
- 移除日历待安排任务面板，保留日历内任务拖动改期。考勤事件仍叠加在日历中，统计、同步及设置移到右侧默认折叠的“我的考勤”；展开后的统计独立滚动，选择打卡记录时自动展开以便编辑。折叠不卸载组件，不丢草稿。
- 月视图用剩余高度均分周行，完整显示本月日期；单日超量内容在格内浏览。周、日时间轴只有日历卡片一个滚动容器，保留 24 小时刻度和拖动创建。
- 桌面日历工具栏合为一行，日期输入、前后切换、今天组成一个导航组；搜索默认图标，悬浮、键盘聚焦或点击展开。窄屏允许必要换行保证操作可达。
- 日视图上方显示成员保存的每日节奏时间段、名称和指导文字，明确标注参考安排；未配置时沿用每日节奏现有默认模板，不冒充已经创建的日程。其他成员日历不展示本人的模板，读取失败提供重试，调整模板沿用每日节奏入口。

无新接口、数据库或部署配置变更。验收覆盖首页默认可见、考勤折叠不影响日历事件、模板数据及失败重试、成员切换、搜索、日期切换、月视图总览和周视图滚动。

## 本次验证

- 60 项首页、日历及计划组件回归通过，覆盖模板失败重试、跨日说明、月份日期校正、折叠考勤仍加载事件；类型检查、生产构建和变更文件 ESLint 通过。
- 本地 Vite 前端通过 SSH 转发复用 Linux1 既有业务服务及数据库，以已有本人会话验收；未启动本地 JVM，也未执行迁移或修改业务记录。实际读取首页额度与会员权益、月份打卡记录及个人保存的 7 个计划时间段，验证考勤弹窗打开/关闭、搜索及跨月日期切换。
- 默认桌面 1684×887 下工具栏单行、月历完整可见，周/日时间轴自身不滚动，仅外层卡片滚动；另检查 1024×768、390×844 无整页横向溢出。窄屏工具栏允许换行，月份事件保持行高在格内浏览。
- 天气真实接口返回服务暂不可用，已验证错误及重试入口；成功预报此次未能现场验证，没有用模拟天气替代。
- 工程一致性检查 0 错误；保留仓库已有的 4 组重复 ADR 编号警告。构建保留已有大体积资源提示。合并后由用户验收上线效果。
