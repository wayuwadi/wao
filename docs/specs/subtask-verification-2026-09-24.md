# 子任务待验证与 AI 交付约定

子任务在未开始、进行中、已完成之间增加待验证。沿用 Step.status，待验证写入 status=待验证、done=false；仅用户验收关闭才写入 done=true。旧数据及无状态字段继续视为未开始，done=true 优先显示已完成。无需数据库迁移。

表格、列表与任务抽屉共用状态菜单；隐藏已完成时保留待验证条目。状态保存继续复用任务更新接口的草稿、失败重试和冲突保护。公开分享显示待验证，未完成筛选和统计仍以 done 为准。

AI 从当前用户、本项目收集中任务开始执行时改为进行中，验证并提交 PR 后追加结论并改为待验证。部署交给 Jenkins；用户负责验收关闭。

MCP 与 CLI：现有 update_task 支持主任务状态，get_task 返回内嵌子任务 status。当前工具没有独立子任务更新能力，本次不增加工具或扩大令牌权限；子任务状态在 Web 中操作，后续若开放独立子任务写入，需补齐权限和并发冲突校验及 CLI 命令。
