# 小记未保存时的全屏编辑提醒

小记左侧新建 / 继续编辑区在有未保存正文时，按成员偏好提示进入全屏。提醒用于缓解正文与图片总览同时占用空间时的拥挤；不自动切换编辑模式，也不妨碍继续输入或保存。

## 用户可见行为

- 设置位于「设置 → 偏好 → 小记全屏提醒」，按当前成员跨设备保存启用状态与间隔。默认开启，默认间隔 1 分钟；可关闭，或选择 1、2、3、5、10、15 分钟。
- 从最近一次正文 / 富文本内容、标题或标签编辑后开始计时。计时到期时仅当正文非空、内容仍有未保存变更、编辑器不在全屏且偏好已成功读取时显示轻提醒。
- 提醒提供「进入全屏」「稍后提醒」与关闭。进入全屏保留当前编辑器实例、正文和草稿，并停止提醒计时；稍后提醒在同一间隔后再次提示；关闭后本轮草稿不再提示，用户继续编辑后重新计时。
- 卡片内原地编辑不显示此提醒：该模式没有全屏编辑入口。
- 全屏状态下保存成功后自动退出全屏，保存失败或版本冲突时继续留在全屏，保留正文并提供原有重试路径。
- 偏好尚未读取或读取失败时不显示提醒；设置保存失败时保留设置页中的选择并提供重试，不伪装成已生效。

## 数据与权限

- 使用现有成员级 `/api/preferences/{key}` 键值存储，键为 `note-fullscreen-reminder-v1`。不新增 HTTP API、数据库字段或 migration。
- 延续小记既有本地草稿防丢、显式保存、冲突处理和失败重试；提醒不改写草稿或自动保存正文。

## 验收

1. 首次读取默认值为启用、1 分钟；设置更改后保存并刷新仍按成员恢复。
2. 正文存在未保存编辑时到期显示提醒；保存成功、空正文、关闭开关、设置不可用、全屏编辑和卡片内编辑均不误提示。
3. 「进入全屏」保持原编辑器与正文；「稍后提醒」延后同一时长，关闭后只有下一次编辑才重新开始提醒周期。
4. 全屏保存成功自动退出；保存失败与版本冲突保持全屏并可重试。
5. 窄屏提醒内容和操作均可见；偏好读取 / 保存失败有明确状态和恢复入口。
