# 移动端团队聊天

日期：2026-09-10。承接 ADR-221 和 ADR-227，Android/iOS 共用 Vue + Capacitor，不新增飞书桥接或会话系统。

底部新增聊天入口，读取当前登录成员所属 WAO 团队的最近 100 条消息；前台定时同步，后台暂停。未读来自服务端，只有聊天可见且滚到最新消息时提交已读。聊天支持文字、引用、表情、图片和文件附件；链接按安全协议展示，受保护图片经原生会话读取。手机文件上传限 20MB，图片限 10MB；下载后可由用户选择保存/分享。使用键盘语音输入，不引入新的语音服务。

草稿与未确认的发送请求按账号保存。发送前保存客户端去重 token，响应丢失后重试复用同一 token；有未确认请求时先重试，期间新的输入保留。重新登录同一账号可恢复，切换账号不展示之前的消息或附件。会话失效后停止请求；晚到响应不得修改新账号数据。草稿存储失败显示错误并阻止发送，避免发送后重启丢失去重信息。

原生 HTTP 上传使用 Capacitor 支持的 multipart base64File 数据，下载到缓存后交由系统保存/分享。仅允许固定 WAO 图片/文件 API 通过携带会话的请求访问，任意外链不携带原生会话。图片 Blob URL 在切换账号/卸载组件时释放。

验收覆盖发送成功、断网重试去重、发送期间继续输入、草稿恢复与账号隔离、隐藏/滚动历史不标已读、新消息不抢滚动、图片附件错误、中文换行和窄屏。通过独立移动端流水线发布新版本并更新站内下载清单；未实际进行的设备安装与双人收发需明确说明。
