# 六个休息世界与伙伴小游戏

用户在 2026-10-02 确认六套页面设计及六类小游戏，并要求实现。此规格增补公共呼吸入口，保留现有认证、深链接回跳、计时及备案行为；不恢复桌面客户端。

- 顶部常驻六种风格：伙伴小剧场、休息俱乐部、环游小队、像素游乐场、涂鸦手账、极简美术馆。各自拥有排版、配色、角色场景，选择在当前浏览器按访客/成员隔离保存。
- 提供“歇一会儿 / 玩一小会儿”。进入游戏先暂停呼吸，返回后主动继续；换风格不重建呼吸计时器。小游戏切换/登录弹窗/后台页面时暂停时间和输入，不在隐藏页面继续跑物理或播放动作序列。
- 小剧场：观察角色动作序列，按顺序回应，逐级增加长度；错误可重放当前轮，不清空最佳记录。
- 俱乐部：拖动伙伴与抱枕，重力、家具支撑和碰撞形成可摆玩的休息角；提供键盘选择及移动，跌落触发短趣事。
- 环游小队：旋转引力箭头规划路线，发射伙伴、逐格展示轨迹；循环、撞边和到达终点均有反馈，五关逐步增加路线复杂度。
- 像素世界：左右移动/跳跃/切角色/技能；星星照亮、记录小本搭桥、机器人推箱、闪电冲刺、资料方块压开机关，集齐五份休息贴纸再到出口。支持触屏按钮及键盘，跌落回到安全点。
- 涂鸦手账：角色贴纸拖放、旋转、删除，绘线、撤销，短文字草稿自动保存，可导出本地 SVG；明确空画布和保存失败状态。
- 美术馆：调整角色角度与灯光方向，让实际投影轮廓与目标重合；有角度误差反馈、重试及递进关卡。
- 伙伴趣事只取自用户实际触发事件，跨场景展示最近一条；不伪造记忆、在线排行或业务数据。

小游戏进度只保存在当前浏览器，不承诺跨设备。存储版本校验、字段范围限制、账户隔离、损坏提示、失败重试与跨标签页冲突提示必须覆盖。同步不得覆盖未保存输入；返回后台前及时写入。所有文字/贴纸是纯文本与自有图形，导出不执行用户输入。

技术继续使用 Vue 3 / TypeScript / 原生 SVG 与 CSS，不新增游戏引擎依赖，不修改服务端/API/MCP/CLI/数据库。验收包含纯逻辑测试、组件暂停/保存测试、真实服务下六个小游戏和呼吸/认证切换、桌面/窄屏、类型检查与构建。按一个 PR 交付，合并后不跟进发布。
