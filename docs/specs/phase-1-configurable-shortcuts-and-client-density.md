# 规格：可配置快捷键与客户端紧凑工作区

来源：<https://wao.wayuwa.cn/api/share/tasks/t17890954465643.md?openOnly=true>。原任务中的
`10`、`9`、`8`、`7` 只有编号，没有可验证的需求内容，本规格不为其补造功能。

## 用户结果

- 快捷键帮助页同时承担查看与配置：窗口内默认使用 `Alt+Q` 新建任务、`Alt+E` 打开小记、
  `Alt+F` 打开聊天；成员可以直接录入新的修饰键加字母／数字组合，配置跨设备保存。
- 桌面客户端运行时可以配置系统级快捷键；默认 `Alt+Shift+Y` 唤起 WAO 并打开小记。
  系统级组合可关闭；被系统或其他软件占用时客户端明确提示修改后重试。浏览器不冒充窗口外能力。
- Mac 安装包使用带透明安全边距的专用图标，Dock 中的视觉面积与相邻应用保持一致；Windows 图标不受影响。
- 桌面客户端将网页第二层顶栏的折叠入口、当前功能和成员已有顶部按钮同步到原生顶栏，网页正文不再重复占一行；
  浏览器继续保留完整网页顶栏与顶部拖拽管理。
- 复杂页面的“本页内容”不再占据正文宽度，收成悬浮目录按钮；展开后仍展示真实分区并可平滑定位，完成定位后收起。
- 移动端聊天首次取得真实消息后直接稳定在最新消息；离开底部后显示“回到最新消息”，一次点击直接到底。
- 聊天中的同源小记／文档分享在当前登录工作区打开对应知识库文档；无权限或内容已删除时保留聊天并提示原因。

## 状态、失败与安全边界

- 快捷键配置沿用成员偏好接口 `keyboard-shortcuts-v1`，覆盖读取中、保存中、已保存与失败重试；同一作用域不允许重复组合。
- 原生桥只接受 `new-task`、`new-note`、`chat` 三个固定动作，以及经过限制的组合键；远程页面仍不能执行任意原生命令。
- 系统级快捷键只由本地客户端外壳注册和注销。成员切换或配置刷新后以当前服务端配置为准。
- 小记跳转只识别 WAO 同源 `/s/d/{id}` 与 `/api/share/docs/{id}.md`，外站仿冒路径保持普通外链行为。

## 验收

- 在快捷键页分别修改三个窗口内组合，保存、刷新并逐个触发；重复组合被阻止，失败时可重试且旧配置仍可用。
- 在桌面客户端设置系统级小记组合，隐藏客户端后触发，窗口恢复并进入真实小记；占用冲突显示可执行提示。
- 在桌面客户端核对只剩一层工具条，折叠、当前功能及已有顶部按钮可用；浏览器仍能拖拽管理顶部按钮。
- 进入带至少三个分区的首页，目录默认只占一个悬浮按钮，展开和定位不改变正文宽度。
- 手机打开已有长聊天时首屏为最新消息；上滑多屏后点“回到最新消息”，一次回到底并同步已读。
- 将一条真实小记分享到聊天并发送，点击消息链接后直接打开对应完整文档；删除内容或移除权限时显示错误。
