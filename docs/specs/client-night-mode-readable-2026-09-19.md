# 客户端夜间模式可读性修复

## 问题与范围

客户端侧栏在深色模式仍保留浅色背景，菜单使用浅色文字而无法辨认；部分本地外壳页面、业务控件和提示区仍使用固定浅色表面。原有 `:global([data-theme='dark']) .desktop-shell` 被 Vue 编译为全局主题选择器，无法覆盖客户端容器上的浅色变量。

## 行为

- 客户端业务侧栏直接继承全局背景变量，移除容器上的固定浅色覆盖；网页与客户端使用同一套深浅表面层级。
- 深色模式提高辅助文字、占位文字和弱提示的亮度。品牌文字使用 `--wao-primary-text`，与实心按钮底色分离，避免为了白字按钮压暗背景后同时压暗文字。
- 补齐已有组件引用的文字、表面、输入框、分隔线、状态和阴影语义别名；Ant Design 控件及浮层使用随当前有效主题切换的算法。
- 常用任务、项目、待办、聊天、日历、知识库编辑器、AI 账号和 Webhook 设置，以及工作日节奏、食库和衣库等页面的表面、状态提示和输入区使用语义颜色。保留图片、画布、衣物色块和用户主动设置的内容颜色。
- 客户端本地顶栏、连接页、版本更新页和确认弹窗共用主题调色板；启动时沿用上次工作区主题，首次启动读取系统主题。工作区重连时的未就绪占位消息不再将深色重置为浅色。
- 客户端外壳修复随 `1.1.10` 安装包交付；网页部分沿用 Web 发布，不要求为业务样式修改重新安装客户端。

## 验证边界

按本次用户要求优先修改代码，由用户执行完整业务体验和跨平台客户端验收。本地执行网页与客户端类型检查、生产构建及现有主题和外壳定向测试；另外使用本地外壳预览检查了深浅更新页和深色退出弹窗；不把这些检查表述为真实账号链路或 Windows/macOS 安装包验收。未修改接口、数据、权限或已执行的数据库迁移。

用户体验复核重点：深浅主题来回切换、侧栏菜单与收藏项、设置页输入框、任务抽屉和编辑器提示块、客户端更新及退出弹窗，以及刷新或重连期间的主题连续性。
