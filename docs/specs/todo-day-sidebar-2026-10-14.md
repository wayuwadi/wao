# 按天待办辅助区收起到侧边

用户要求每日固定与随手记收到侧边，默认不展开。本规格补充并取代 2026-10-07 布局规格中辅助区默认展开的行为，沿用日常规则与小记保存契约，不改变 API、数据或部署行为。

- 桌面右侧保留每日固定／随手记两个窄入口；初次打开以及日期或成员切换默认折叠，主任务使用剩余空间。点击展开对应区域，再次点击或“收起”关闭；同一时刻最多展开一个。
- 展开仍使用线框页面布局与主容器滚动，不增加遮挡任务的模态层、背景阴影或独立滚动区域。四象限与清单均可使用侧边入口。
- 容器宽度不超过 800px 时入口横排，打开的面板显示在任务上方；不使用竖排文字，不发生窄屏横向溢出。
- 收起与切换面板只隐藏，不卸载每日固定或随手记编辑器。尚未保存的输入、保存中和失败重试仍保留，重开即可继续；后台刷新不自动打开面板。日期／成员切换依赖已有隔离草稿。
- 每日固定保留早晚切换、完成／跳过／恢复、管理及历史／未来只读；随手记保留写一条、补记、前三条／展开全部、提交回执与失败重试，不修改正文或记录数量。
- 所有入口提供名称、展开状态与对应区域引用。收起与 Esc 将焦点回到当前入口；明暗主题使用已有 token 与 WaoButton。
- `TodoDayLayout` 的业务页面与 `/design` 示例同步采用侧边入口，不用生产数据构建设计示例。

验收：默认折叠、两入口切换、主区宽度、日期／成员重置、草稿与失败保留、日常管理及提交、明暗主题、390px 窄屏和键盘焦点。
