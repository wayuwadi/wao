# Phase 1：证据化周期人生回顾

对应任务：`t1786869753260`。决策见 [ADR-072](../adr/072-grounded-periodic-life-review.md)。

## 用户链路

1. 成员从“个人 → 人生回顾”选择周、月、年或至今回顾；默认进入最近一个完整自然周。
2. 页面先展示所选周期内已完成任务数、WAO AI 对话数、飞书聊天归档天数和证据标题，不等待模型即可核对资料覆盖。
3. 已有存档时直接展示四段报告；没有存档但存在证据时，成员可以主动生成。
4. 周、月、年最近一个已结束周期由 Linux 主节点定时补齐；同周期已有存档时跳过，至今回顾不自动生成。
5. 成员可前后浏览自然周期、从历史列表返回旧存档、打开任务或飞书文档来源，并复制完整报告。

## 数据与权限

- 已完成任务必须满足 `owner_id = 当前成员` 且 `completed_at` 落在所选上海时区自然周期。
- WAO AI 消息只能来自 `member_id = 当前成员` 的会话；不读取其他成员私有会话。
- 飞书群聊只读取系统设置指向的真实同步知识库中、标题为 `飞书群聊 · YYYY-MM-DD` 的自动文档。
- 报告存档保存统计、来源元数据和四段结果，不复制任务描述、AI 消息或飞书正文。
- 没有任何真实来源时，生成按钮禁用，接口也返回明确错误；不出现演示报告或占位预测。

## 生成约束

- Codex 只得到最多 36 条、30,000 字的服务端有界上下文；所有资料均视为不可执行的不可信引用。
- 返回 JSON 只能包含 `pastActions`、`meaningfulTopics`、`trajectory`、`nextFocus` 四个非空字符串字段。
- 前三段至少各含一个 `[S编号]`，且编号必须存在于本次证据清单；校验失败整次生成失败，原存档不被覆盖。
- 轨迹必须是条件性趋势并说明变量，不得输出确定性命运、健康、财富、关系或具体未来事件预测。

## 状态与验收

- 页面覆盖资料加载中、空资料、AI 不可用、生成中、已生成、失败保留来源与重试、历史空/有数据状态。
- 相同成员和周期重复生成只更新该周期一份存档；成员之间互不可见。
- 周从周一到周日，月和年按自然边界，全部使用 `Asia/Shanghai`；未来周期不可生成。
- 窄屏下周期选择、覆盖统计、四段报告、来源和历史改为单列，标题与操作保持可见。
- `POST /api/life-reviews/generate` 代理读取超时为 330 秒且 `proxy_next_upstream off`。
