# 小记选段生图与正文图片位置

本规格补充并更新 `notes-auto-title-image.md`、`note-image-preview.md` 和 `notes-quiet-inline-editor.md` 的小记展示约定；完整文档中的图片布局不变。

## 用户可见行为

- 选中小记正文后，浮动工具栏在“待办”“润色”旁显示“生图”。生成前展示选段；任务完成后先预览，确认“加入小记”才写入编辑草稿。失败可重试，任务 ID 按成员与小记草稿 ID 保存在浏览器本地，收起或重进编辑器继续查询同一任务。
- 所有图片仍作为富文本图片节点随小记保存，兼容已有图片与分享、完整文档；清单预览、卡片原地编辑和沉浸阅读均按正文原顺序显示图片，保留图片与前后文字的对应位置。编辑器限制图片显示高度，避免大图挤占输入空间；点击图片可看大图，右键仍可复制图片或地址。
- 生成后的标题在小记卡片预览中显示；原地编辑时显示可修改的标题。未生成独立标题、且标题等于正文首行的历史小记不重复展示同一句。标签贴在标题旁；无独立标题时仍靠近正文顶部，不放到卡片底部。
- WeKnora 文档状态在标题、配图、润色阶段标记后以单个图标表示，悬浮或聚焦可读状态，不再显示“去提问”。完整文档入口与置顶、分享一起放在卡片顶部，悬浮仅改变透明度，不增加卡片高度。
- 图片缩略图继续支持点击看大图；阅读卡片保留已有右键复制图片和地址能力。小记原地编辑保留草稿、显式保存、版本冲突和失败重试。

## 数据与权限

- 选段生图复用当前成员的 `POST /api/assistant/article-images` 与任务查询接口，输入仅为选中文字及固定选段画面要求；不新增 HTTP、MCP 或数据库字段。生成结果不自动替换文字，也不调用总览图的替换逻辑。
- 选段生图依赖当前编辑器选区、草稿版本和用户确认。它不是独立的终端批处理操作，因此本次不增加 `wao` CLI 命令；若以后出现批量生图需求，应重新设计保存目标与版本条件。

## 验收

1. 选中文字后可见“生图”，失败可重试；成功后确认加入，文本和原图仍在，保存刷新后图片按正文顺序显示。
2. 多图在阅读与原地编辑中均保留在正文插入位置，前后文字关系清楚；大图不会遮住编辑区中的其他文字。
3. 独立标题、标签、同步状态和完整文档图标处于卡片顶部；悬浮前后卡片高度不变。
