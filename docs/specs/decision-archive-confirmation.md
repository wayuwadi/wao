# 决策废止确认弹窗

补充个人决策管理与废止失败恢复规格。将废止操作的浏览器原生确认框换成页面内的原生 dialog，复用 WAO 主题 token；不改变服务端废止及历史保留规则。

- 明确展示对象名称、有效列表和默认检索的变化、历史版本去向。
- 默认聚焦取消；取消和 Escape 不发请求，焦点返回触发入口。遮罩不触发废止。
- 通过 showModal 进入浏览器顶层，限制键盘焦点在弹窗内，避免桌宠遮挡。
- 点击确认后显示执行中并禁用重复提交和关闭；失败保留对象与原因，可原处重试或取消后重新加载核对。
- 成功关闭弹窗并沿用已确认成功后先移除再刷新的行为。账号切换关闭旧确认框，旧请求回包不得影响新账号。
- 长标题自然换行，窄屏不横向溢出，操作控件至少 44px 高。

验收覆盖打开但未确认、取消、Escape、提交中、失败重试、成功关闭、账号切换；真实页面核对键盘焦点、窄屏和既有数据读取。
