# 知识库首页检索与读取状态

知识库首页沿用目录顺序，提供标题与文件夹名称搜索、最近更新和名称排序。首页与侧栏共享搜索词，搜索结果自动展开，清空后恢复原折叠选择。首页排序只改变展示，不写入目录顺序。切换知识库时清空筛选和首页排序。

首页展示分组文档数、搜索结果数、全组展开/折叠及新建文档入口。标题检索和排序读取元数据及本机标题草稿，不转换文档正文。窄屏工具栏换行，长标题省略并保留完整标题提示；颜色、字体、圆角沿用现有主题 token。

目录加载中、失败和空库分别展示；失败保留已有列表并提供重试。归档加载按当前知识库与请求序号隔离，旧请求返回时不能覆盖新库的加载或错误状态。历史群聊归档不展示没有服务端依据的同步时间、数量或运行状态，实际同步状态由自动化页面提供。

文档正文、草稿、冲突、保存和权限继续由现有文档链路负责。本改动不增加 API，不改变数据库与用户资料。

验证入口：`KbDetailView.spec.ts`、`KbDetailArchive.spec.ts`、`knowledgeDirectory.spec.ts` 及文档草稿生命周期测试；浏览器覆盖真实库搜索、排序、阅读返回、320/390px、明暗主题和键盘操作。
