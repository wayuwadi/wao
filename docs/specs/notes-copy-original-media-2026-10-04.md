# 小记图文分步复制

2026-10-04 实测后经用户确认：正文与原图分步复制，先粘正文，再逐张粘原图，保留各张图片。不能把 HTML 含图片地址或同时写入 HTML、文字、PNG 当作 ChatGPT 实际接收图片的证据。

- 卡片悬停操作、右键复制内容及阅读模式提供图文复制入口。编辑器全选复制包含图片的选区时，先复制正文并打开原图步骤；纯文字选区仍走普通富文本复制。
- 面板使用固定内容快照，正文保留段落、列表、链接与原图片位置的图号。显示正文及各张图片的步骤、复制状态、下一步和完成。每次用户主动复制后自行切到 ChatGPT 粘贴；不自动向第三方发送内容。
- 原图请求使用存储中的原始地址，不取预览缩略图。剪贴板每次只包含独立 PNG 图片表示，其他格式按完整像素尺寸转换为 PNG、保留透明通道。动画图片按 PNG 静帧复制。
- 复制失败不标为成功，不推进步骤，支持重试。读取或复制过程中避免重复操作。Esc 关闭面板、Tab 焦点循环，关闭后返回入口焦点；窄屏和矮屏保持步骤、内容及操作可见。
- 不改变原文、图片布局、草稿、图片来源或已有普通复制行为。不新增 API、MCP 或 CLI 权限。

真实浏览器验收：本地连接既有数据库，专用合成小记正文和图号粘贴成功，两张 480×300 原图分别成为 ChatGPT 图片附件，正文保持；未发送聊天。较大的自动配图复制到剪贴板成功，但自动化浏览器粘贴时连接中断，此图的接收结果未确认；不把这次中断报告为已验收。回归覆盖选区原文不变、步骤推进、失败重试及完整尺寸转换。
