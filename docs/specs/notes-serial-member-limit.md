# 小记串行整理共用成员上限

补充 `notes-workflow-queue-progress.md`，保持单份最新正文与本机单 worker。

- 串行模式的服务端自动标题、配图、润色共用成员上限 1；并行模式沿用成员设置的 1–5。不能只限制一篇内部的阶段顺序。
- RUNNING 计入上限，包含已提交排队、执行中和模型完成但尚待回写的阶段，不等于正在运行的 Codex 进程数。
- 已入队阶段始终允许查询结果；从并行切换到串行不会中断旧任务，也不能让等待中的前置阶段挡住旧任务收尾。已有任务超过新上限时先等待释放。
- 设置显示“同时整理上限”，串行显示禁用的 1 项；切回并行保留原并行上限。手动生成及浏览器标签推荐不属于这三个服务端自动阶段的槽位。
- 不新增 API、数据字段、migration、CLI 或 MCP；不承诺多个不同服务进程同时调度同一成员时的全局互斥。当前日常部署使用一个工作流推进 worker。
