# 天人一卦：首页预览与统一页面

用户确认先预览再进入详情的交互 Demo。本规格调整首页四等分卡片的卦象入口及卦象详情的信息层级，不改变每日唯一、私有解读、公开分享和通知的既有规则。

- 首页点击卦象打开轻量预览，展示服务端卦象、变爻、之卦及已保存 AI 解读的文字摘要。摘要按需读取；没有存档时明确空状态，不使用演示建议替代真实解读，不触发起卦、AI 或通知。
- 预览可展开六爻，关闭、外部点击或 Escape 均留在首页；显式「查看完整解读」进入 `/tianren`。卦象与 Codex 详情互斥，窄屏浮层不超出视口。
- 完整页沿用 WAO 字体、主题色与简洁标题；概要卡之后分为当日解读、卦象结构和往日记录。结构页折叠方法说明，通知继续复用已有状态与配置入口。
- 关注点即时保存在当日本机草稿，明确标注本机保存；不新增云端日记语义。请求失败保留草稿和上份解读，生成期间禁止切换日期，避免串写结果。历史仅恢复存档，不通过今日接口补生成。
- 保留真实加载、空状态、离线、保存、失败重试、分享回退和文化反思边界。界面中不保留 Demo 示例数据。

本次为前端呈现与交互变更；HTTP、MCP、CLI 和持久化结构不变。

验收包括首页预览关闭与主动导航、六爻和历史切换、草稿刷新恢复、离线状态与窄屏，自动化覆盖摘要按需读取/失败重试及既有起卦、解读、分享、通知回归。
