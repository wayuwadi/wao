# 能力中心

用户于 2026-10-04 确认整合 Demo 和权限粒度。决策见 ADR-322。

## 用户结果

- 一级功能 `capabilities`（能力中心）承接 CLI、MCP、Skill、应用接入、Pet；设置不再承载工作区授权。
- 页面分为发现能力、我的连接、我的发布。类型筛选与搜索共用左侧卡片，右侧提供详情和类型适用操作。连接签发、授权、吊销均为页内交互。
- CLI/MCP 目录来自服务端显式工具定义，包含操作说明、命令和工具对应关系。逐项选择操作，再收窄到指定项目／知识库；支持分组、单项、表格三种授权视图。
- 工作流 Skill 保留文件、版本、扫描、审核、收藏、固定包下载和作者身份；Pet 保留图集预览、私人保存、来源许可、公开确认和下架。复用既有工作台组件与成员隔离草稿，不复制业务流程。
- 应用接入目前没有真实提供方，显示规划与空状态，不提供假授权。安装资源不获得 WAO 账号权限，也不声称已读取本机安装状态。
- 公开浏览和详情免登录；连接和发布管理要求登录。旧管理菜单退役，旧资源／分享路径转向能力中心的对应区域，二进制 API 保持不变。
- 游客使用公开布局，不挂载成员工作台及其私有接口；登录后使用统一菜单与页签工作台。

## 授权契约

- 公开 GET `/api/public/capabilities` 读取完整工具元数据；浏览器会话 GET `/api/workspace-mcp/resources` 读取当前成员可见资源。目录不使用某一设备令牌裁剪，也不返回用户内容。
- POST `/api/workspace-mcp/tokens` 新增 `permissions`、`projectIds`、`knowledgeBaseIds`、`clientType`。有 `permissions` 时逐项授权（至少一项）；缺失时保留旧 `canWrite`/`canPublishHostedPage` 创建契约。未知操作、重复或过量资源拒绝；限定 ID 必须为当前成员可见资源。
- 日常首批补全后，48 个 MCP 工具与 CLI `publish_html` 为明确白名单。只读 19 项；新令牌的操作集合为签发时快照，不随新工具扩权。HTML 发布不进入 MCP tools/list。
- 范围数组缺失/null 表示账号当前可见范围；非空数组表示指定范围。列表先按范围过滤再分页/截断；详情、创建、更新和目录操作再次检查目标归属，直接工具调用不能绕过。
- 限定项目的任务和子任务更新在同一事务内锁定任务并检查当前归属，防止检查之后并发移入未授权项目。
- 新建项目／知识库沿用站内规则，不自动加入限定范围；它们的创建操作单独授权。项目范围不代替独立知识库范围，历史关联仍需成员项目可见性。
- 旧令牌 policy 为 NULL，仍沿用旧读写和发布权限；详情标注旧版整体授权。新授权复制为新连接，迁移后再吊销旧连接，不能原地扩权。
- 明文只在创建响应和当前页面内存出现，不保存到草稿、URL、日志或后续列表。签发后不可重复查询；关闭/离开创建内容清除明文。列表及签发 no-store，吊销按当前成员校验。
- 连接草稿按成员隔离保存，只含名称、类型、权限和资源 ID。刷新、切换区域保留未签发草稿；请求失败保留输入并提供重试，不把读取失败当作空列表。
- Skill 文件草稿按发布身份和目标资源隔离保存到本机 IndexedDB，刷新后重新检查包内容并保留已编辑表单；切换管理区域保留工作台。实际创建成功后清除对应文件草稿。公开昵称草稿按成员隔离，保存失败保留、成功清理。浏览器存储失败明确提示，不能假报草稿已保存。

## CLI/MCP 同步

既有 CLI 命令沿用，不新增 Skill/Pet 上传或令牌签发命令。后者由浏览器会话管理，不能授权设备令牌给自身扩权。终端必须以实时 tools/list 为准；新令牌仅列出获准工具，隐藏工具强行调用失败。HTML 发布控制器复用显式 publish_html 权限。

## 验收

覆盖菜单旧版升级、深链接、游客与成员区域、真实目录/资源、权限草稿保留、独立读写、受限列表/详情/写操作、未知授权拒绝、旧令牌兼容与新旧范围隔离、HTML 独立授权、吊销、失败重试和窄屏无溢出。连接已有线上数据库完成本地浏览器链路；合并后由用户验收线上。

2026-10-04 日常能力首批补全：授权草稿增加「日常完整」选项，一次选择当前 48 项工作区操作，保留项目与知识库范围，不自动签发或包含 HTML 发布。新增工具遵循既有不可变授权快照，完整业务契约见 [工作区日常能力](workspace-mcp-daily-capabilities.md)。
