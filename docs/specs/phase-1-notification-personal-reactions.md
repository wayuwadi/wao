# 通知原生个人表情

依 ADR-215 实现：

- 做到了 → 原提醒上的 CheckMark；没做到 → CrossMark；作者必须等于真实回调用户。
- 不发群聊反馈消息，不以卡片成员摘要替代。
- 未授权仅向点击者弹出授权提示；设置 → 账号与登录、以及新提醒中的「授权个人表情」链接提供入口。
- 首次授权明确用途，成功显示实际授权的飞书成员名称，回到原提醒再次点击即可。授权失败提供重试，取消不保存凭证。
- 凭证由通知机器人的同一应用获取，以 app_id + open_id 隔离，服务端加密存储并串行刷新；无授权/失效绝不回退机器人身份。
- 同人改选删除自己之前的反向表情，不影响其他成员；视觉失败仍保存真实记录。
- 不自动把历史选择补贴为用户表情，不替用户点击同意或制造完成记录。

## 授权失败恢复（ADR-217）

- 飞书成功响应中的空 `error` 不误判失败，仍校验有效令牌和个人表情 scope。
- 令牌兑换失败按应用凭据、授权码、权限、响应或请求异常说明原因，并提供不含凭据的诊断号。
- 回调后跳转不含授权码的结果页；十分钟内刷新仅查看当前会话结果，不重新兑换。结果失效后可从按钮发起新授权。
