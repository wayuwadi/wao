# 小记清单删除

小记卡片右上角分享图标的右侧常显红色删除图标。首次点击只展开当前卡片的确认区，选择“确认删除”后才复用知识库文档的软删除接口；取消或按 Esc 不删除。成功才从清单移除，并提示可在知识库回收站 7 天内恢复。原地编辑时确认区提示未保存内容会丢失，成功删除后清理该小记的本机编辑草稿。删除失败时卡片和正文保持不变，原地显示原因与重试入口；服务未连接或正在删除时禁止重复操作。

此操作不删除“小记”知识库，不改文档接口或数据结构。原地编辑和新建草稿不受其他卡片的删除影响。

验收：从清单删除一条小记后刷新仍不出现，知识库回收站能找到并恢复；失败时仍可阅读和重试；桌面、窄屏上的删除入口均可见。
