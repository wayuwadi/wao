# 首页底部入口收起

本规格更新 `home-daily-workspace.md`、`home-desktop-quiet-2026-09-19.md` 与 ADR-234 中关于首页底部入口的展示约定。

- 普通首页在项目速达之后结束，不再展示「MCP · AI 连接」「快捷入口」「AI Run」三块内容；不留下空白占位。
- MCP 连接能力、待办／文件／项目导航和 AI Run 业务能力保持可用。带 `console` 查询参数或 `#ai-launcher` 锚点的现有直达链接仍展开 AI 控制台，用户可在页面内收起它。
- 额度、天气、今日待办、最近创作和项目速达继续使用原有真实数据与加载、失败状态。本次不增加接口或数据结构。

验收：普通首页无三块底部入口，页面高度随内容收口；带 `console` 的链接可打开和收起 AI 控制台，已有目标草稿不丢失。
