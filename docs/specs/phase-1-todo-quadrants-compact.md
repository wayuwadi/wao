# 规格：四象限紧凑清单体验

2026-09-07，用户反馈现有四象限不符合预期，要求参考滴答清单 APP。
本规格更新 `phase-1-todo-quadrants.md` 的布局和快捷操作约定，保留原有任务范围与优先级契约。

## 用户可观察的结果

- 四格等宽等高，使用内容区剩余高度，每格标题固定、任务列表独立滚动；任务多时仍可同时浏览四个象限。
- 顺序保持 P0 / P1 / P2 / P3，依次使用红 / 黄 / 蓝 / 绿区分。沿用已有优先级映射，不根据日期重新归类旧任务。
- 紧凑任务行显示标题、日期、项目与进行中状态。长标题省略并保留完整悬停提示，点击标题打开原任务详情。
- 圆形勾选操作为完成 / 重新打开；完成后短暂原地停留，保存中或失败时始终可见。失败保留本机草稿并可重试。
- 拖动任务换象限，目标象限高亮；行末紧凑移动控件提供键盘和触屏操作，不再每行常驻整行下拉框。
- 每格标题提供新建与放大入口。新建预设该象限优先级；每个象限独立保存新建草稿，恢复草稿时保留用户已改的优先级，不覆盖普通入口草稿。
- 桌面和手机均保留四格；手机可放大任一象限浏览长清单，再还原全局视角。
- 批量选择进入单独模式，保留现有全选、合并复制及筛选清理行为；完成操作与批量选择含义明确区分。
- 保留读取中的加载提示、读取失败重试、空态、保存中 / 已保存 / 保存失败回执与视图偏好。

## 验收

验证四象限归属、拖动与取消、移动保存失败重试、完成失败可恢复、新建草稿隔离、批量复制、筛选与偏好；检查桌面与手机四格可见、长清单独立滚动、放大还原；发布后操作真实任务验证刷新持久化。

参考：[滴答清单官方四象限帮助](https://help.dida365.com/articles/6950398710203285504)，对照其桌面四格清单、配色及象限新建 / 拖动操作。
