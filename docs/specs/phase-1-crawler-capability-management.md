# Phase 1：爬虫能力管理

对应任务：`t1788177005780`。

## 用户结果

1. 用户可以从工具导航或工作台进入“爬虫能力”，查看组织内已保存的真实源码资产。
2. 用户可以新增、查看、编辑、启停和删除爬虫能力；名称、说明、语言与源码刷新页面后仍由后端返回。
3. 新建和编辑覆盖加载中、空数据、保存中、保存失败重试和本机草稿；服务端版本检查阻止多人静默覆盖。
4. 页面明确区分源码资产和运行实例，不展示伪造的运行次数、成功率或采集结果。

## 数据与安全边界

- 支持保存 Python 与 JavaScript 源码，单项上限 256KB；源码不得包含密码、Token、Cookie 或私钥。
- “启用”表示允许未来的受控执行器引用。本期不执行任意源码，不为未提供的群聊脚本创建演示数据。
- 实际爬取必须另行确认目标站点许可、认证、限流、依赖和隔离策略，并通过已登记的真实执行器产生运行记录。
- 源码资产当前组织共享，创建人和最后修改人从服务端会话记录，不信任请求体传入身份。

## 验收

- 空库进入页面显示明确空状态；新增真实源码后卡片显示语言、源码行数、启用状态和更新时间。
- 刷新后仍能读取新增项，编辑保存后版本号递增；用旧版本提交返回 409 并保留本机输入。
- 后端失败时页面显示原因和重试入口；重新打开编辑器能恢复同版本的本机草稿。
- 删除需二次确认，成功后列表消失；若服务端版本已变化则拒绝删除并要求刷新。
