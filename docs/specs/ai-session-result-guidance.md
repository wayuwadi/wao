# AI 会话结果与下一步

对应审计 B04/B05，延续 ADR-208/209 的会话与报告数据，不改变执行或任务验收逻辑。

- 执行成功称为“执行结束”，不等于用户验收；无需部署是独立维度，不能遮盖失败或暂停状态。
- 终态会话在对话之前展示本轮结果、真实失败名称（缺失时说明未知）、报告、结果原文和下一步。技术过程仍可展开。
- 结果仅来自当前运行持久化字段，不推断未记录的完成项、产物或自动重试。没有报告/摘要明确说明。
- 有会话绑定时“补充或修正要求”只定位输入框，不覆盖草稿、不自动发送；等待接收时禁用重复操作。无绑定时进入已有新会话表单，不自动派发。
- 不添加验收状态、不修改关联任务或项目管理内部，不把 AI 自述作为用户已验收证据。

补充：历史终态默认从结果顶部阅读，运行中继续保留跟随最新消息；从活动转为终态且用户原在底部时显示结果，不打断正在阅读历史的用户。明确的账号模型不兼容原文可确定性映射为原因与账号检查入口，其余缺失信息仍标未知。

验收：14 项测试、类型检查及构建通过。本地连接真实数据库，失败会话显示模型不兼容原因与报告入口，继续按钮只定位输入；成功历史会话刷新后从结果顶部阅读，真实历史报告可打开。无绑定时只进入新会话表单由回归测试覆盖；未派发或续跑 AI，未修改关联任务。
