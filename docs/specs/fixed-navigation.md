# 统一主菜单

主菜单由 `wao-web/src/config/nav.ts` 的 `FIXED_NAV_IDS` 与模块元数据统一维护，按代码发布生效。固定顺序：

首页、小记、待办、项目、知识库、草图、密码本、日历、番茄钟、倒数日、习惯打卡、全部功能。

桌面侧栏和手机完整菜单使用同一顺序。可折叠侧栏与调整宽度，不能改名、隐藏、拖拽、分组或固定到顶部。手机底栏维持产品固定快捷操作。旧全局菜单和个人布局不再参与主菜单渲染，不删除历史偏好或项目/知识库收藏数据。

能力中心和 Jenkins 部署中心位于设置 → 管理与连接。旧 `settings?tab=navigation` / `quick-links` 地址落到该分类。Jenkins 保留同源 `/jenkins/job/wao-main-cd/` 地址，新窗口打开，沿用既有登录与访问权限。

`PUT /api/navigation/layout` 和 `PUT /api/settings/navigation/builtin-menus` 返回 400，提示菜单由开发人员统一维护。通用偏好写入口同样拒绝旧导航布局、个人顺序、手机底栏、顶部快捷入口与快捷链接键；其他个人偏好不变。外部应用注册地址读取仍供全部功能使用，不能注入主菜单。

变更菜单位置时修改固定清单；变更标题和图标时修改 MODULES；不再通过数据库或设置界面修改。

个人收藏的项目、知识库分别显示在对应固定菜单下方，点击可直接打开；桌面收起侧栏时隐藏子项，展开及手机完整菜单可见。收藏仍按成员隔离，不改变主菜单顺序或恢复菜单自定义。
