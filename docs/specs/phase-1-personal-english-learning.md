# Phase 1：个人英语训练闭环

对应任务：`t1786521948608`（用 WAO 系统学习英语，持续记录和迭代听说读写，达到日常交流不胆怯）。
决策见 [ADR-058](../adr/058-english-learning-evidence-loop.md)。

## 用户链路

1. 成员首次进入“个人 → 英语训练”时写下自己的交流目标、开始日期和每天可投入的时间；草稿在接口成功前保留。
2. 系统按已完成天数推进 14 课程序员职场英语基础循环，每课提供同一场景下的听、说、读、写材料和常用表达。
3. 听力使用浏览器英文语音朗读，先隐藏原文再核对；口语可申请麦克风录音并立即本机回放，音频不上传、不评分。
4. 课程表达可直接加入当前成员单词本；需要每日飞书提醒时进入已有行动计划设置真实提醒。
5. 练习过程可以随时保存；完成当天前必须勾选听说读写四项并选择 1—5 的开口信心。写作、复盘和下一次重点跨设备保存。
6. 最近 14 条记录可回看；完成第 14 课后进入下一轮但不清空历史，用户按上轮复盘增加一个练习难度。

## 数据与边界

- `english_learning_profile` 按 `member_id` 唯一保存目标、每日分钟数和开始日期。
- `english_learning_session` 按 `(member_id, study_date)` 唯一保存课程、四项完成事实、实际分钟、信心、写作和复盘。
- 所有读写从服务端会话确定成员；请求体不能指定成员。未来日期不可读取或写入训练记录。
- 连续天数只统计带 `completed_at` 的相邻日期；当天还未完成时允许从昨天继续计算，超过一天未完成则归零。
- 14 课内容是 WAO 自有固定课程，不是原型业务数据；页面明确不提供自动翻译、发音评分或能力等级认证。
- 浏览器不支持语音合成或麦克风权限不可用时明确提示，用户仍可用自己的音频来源跟读并完成自评。

## 状态与移动端

- 首次设置、训练写作和复盘都覆盖草稿防丢、加载中、保存中、已保存、失败和重试。
- 保存失败不清空本机草稿，不覆盖服务端已有记录；历史日期切换前提示未保存修改仍保留在对应日期草稿中。
- 390px 宽度下听说读写内容纵向排列，朗读、录音、单词收集与保存按钮可见且触控高度不低于 42px。

## 验收

- 首次保存目标后刷新仍存在；另一成员不能看到该目标或任何训练记录。
- 未完成四项或未选信心就点击完成时，服务端和页面都拒绝累计完成天数。
- 完成一课后刷新仍显示课程、实际分钟、写作、复盘和完成时间，累计天数与连续天数正确增长。
- 编辑写作后模拟接口失败，本机草稿仍在；重试成功后清除草稿。
- 正常与慢速朗读均使用当前课程英文；录音可本地回放且网络请求中不包含音频。
- 点击课程表达后真实写入现有个人单词本，重复表达沿用单词本的遇见次数语义。
