# 飞书每日归档与事件快捷记录

2026-10-07，依据 ADR-328，优先于机器人能力中心先前关于十分钟轮询和停用归档的描述。

## 浏览器行为

能力中心 → 机器人 → 接收应用与群，共用既有应用和 WAO 目标群。@ 快捷记录仅接收认证消息事件，不扫群或读表情；继续把待办/小记归属于消息发送者绑定的成员。没有事件订阅时不能因配置或发送测试成功宣称已可接收。

在共享配置选择真实归档知识库，保存后独立启用每日归档。每日归档显示实际群、知识库、下一次午夜与最近一次结果，失败在此处提示；不增加常驻统计面板。归档开关草稿按成员隔离，失败/冲突保留本地输入，读取失败不视为空配置；显式重新读取才可基于最新状态继续保存。

每日上海时间 00:00 读取前一天完整时间范围，只执行一次任务。飞书消息分页和图片读取按真实数据发生；不读取消息表情，不历史补扫，不通过普通自动化 API 手动启动。未启用、未配置时无群消息调用。

## 服务与持久化

独立 `feishu-daily-archive` 自动化记录与每天唯一运行记录负责开关、下一次执行和持久尝试登记。外部请求前提交登记，失败/中断当天不再次自动访问；后续日期正常运行。现有两个退役聊天同步 handler 仍不可恢复。

知识库归档沿用群/知识库/日期匹配与版本校验；历史文档保持可读，已有站内编辑冲突时不覆盖。普通聊天复盘和原生群聊导入不恢复。消息队列有限重试只处理已接收事件，不重新拉取群历史。

## 权限与终端能力

开关读取/保存仅允许管理员浏览器会话，拒绝普通成员、匿名和设备令牌。复用配置不返回密钥明文，不新增 CLI/MCP 工具或旧令牌权限；自动执行与认证回调不适合开放为通用终端发起入口。HTTP 见 [每日归档接口](../api/feishu-daily-archive.md)。
