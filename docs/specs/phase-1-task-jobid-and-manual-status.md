# 规格：任务 JOBID 与人工状态优先级

对应任务：`t1787706646271`（任务定位与状态回退修复）。本规格补充任务属性中的稳定标识，
并明确人工把任务退出 AI 执行链路后的状态优先级；AI 状态轮询的其它规则继续遵循
`phase-1-task-links-and-mobile-polish.md`。

## 1. 任务 JOBID

- 每条任务的属性栏展示真实任务 `id`，界面名称为 `JOBID`，不生成另一套编号或演示数据。
- 点击 JOBID 复制完整任务 `id`，成功和失败都有明确反馈；复制失败时原值仍可见，用户可以手动选择。
- 长 JOBID 在窄属性栏中不能撑破布局，完整值可通过按钮标题查看并复制。

## 2. 人工回退状态优先于历史 AI Run

- 用户把“进行中 / AI 进行中 / 待验证”任务拖回“待办 / 收集中”并保存后，这一状态代表任务已经
  人工退出当前 AI 执行链路。
- 打开任务详情加载全部 AI Run 历史时，旧的排队、活动、成功、失败或暂停记录都不得覆盖已经持久化的
  “待办 / 收集中”。查看详情本身不能产生任务状态变化。
- 仍处于“进行中 / AI 进行中 / 待验证”的任务继续按既有规则投影最新 AI Run；“已完成”继续受人工验收保护。

## 验收

- 打开任一真实任务，属性栏显示其完整 JOBID；点击后剪贴板内容与任务 `id` 完全一致。
- 分别把有成功、失败和活动运行历史的任务移到“待办”与“收集中”，重新打开详情后状态保持不变。
- 回归未人工回退的任务：活动运行仍显示“AI 进行中”，成功仍进入“待验证”，失败或暂停仍回到“进行中”。
