# 小记 AI 独立任务并行（2026-10-07）

本规格补充 ADR-306 和 `notes-auto-title-image.md`，取代其中按成员配置 1–5 个阶段、串行执行器及手动生图单任务的数量规则。用户要求 WAO 不自行限制润色、生图数量，20 个独立任务应能同时开始。

- 本机执行器的短调度事务与模型调用分离。持久队列分批读取 100 条只是取数分页；独立任务立即交给可扩展工作线程，每项拥有独立 Codex 进程、工作目录、超时与结果。
- 删除成员生图互斥、自动阶段名额与全局 100 条入队拒绝。当前及历史 `executionMode` / `maxConcurrent` 不再影响调度；设置读取统一返回 `parallel` / `0`，保存同样规范化，0 表示 WAO 不设置数量上限。保留字段兼容旧客户端、策略快照和 CAS 设置版本，不新增迁移、不重写历史配置。
- 浏览器不再有自动阶段并发槽位。选段生图可同时保存多项任务，切换选段创建独立任务；待完成和待加入图片分别保留，关闭页面后可恢复。网络不明时复用 requestId，已明确失败后再发起新的请求。
- 同一 requestId 继续复用已有运行，成员权限、claim token 原子领取/完成、同一文档写回版本保护、原稿、草稿及设置关闭代次继续有效。连续聊天的会话顺序与主动发现的业务预算不属于本次取消的独立任务数量限制。
- 停机中断所有本实例任务，等待线程/进程收尾后释放目录锁；未领取任务仍留在持久队列。新实例继续只回收自己目录标识下的中断运行，不碰其他执行器。
- 不承诺 Codex 或宿主资源无限。实际超时、调用失败、登录/额度问题保留在各项任务上，不以 WAO 数量规则拒绝，也不自动转付费 API。

## 契约与 CLI

继续使用现有 `/api/assistant/article-images`、文字任务和小记工作流接口，无新增对外业务操作，无需新增 CLI / MCP 命令或扩大旧令牌权限。小记设置结构保留兼容字段，仅其调度语义变为不设数量上限。

## 验收

验证 20 项同成员生图请求入队、20 个执行任务在任何结果完成前同时开始、同一编辑器 20 个选段同时提交、20 篇小记的图片与正文阶段不受历史串行偏好阻挡。并覆盖重复请求/派发、外成员隔离、版本冲突、停机中断与原文保留。自动化替身用于确定性并发检查；真实数据库、本机 Codex 和浏览器链路独立验收并如实记录数量。
