# Phase 1：今日节奏紧凑面板

对应任务：`t1787884656138`（重点攻坚页面优化）。本规格扩展
[今日节奏每日面板](phase-1-workday-rhythm-daily-dashboard.md)，并取代其中“今日节奏统一展示每日工作文档”和
“逐段完成打卡”的页面表达；每日文档和既有时间块完成记录仍保留在服务端，不删除历史数据。

## 用户结果

1. 页面标题和说明在同一行，顶部提供“单独打开”“复制链接”和成员级“收藏”；复制的是登录后私有页面地址，
   不把个人节奏、重点或卦象公开给匿名访客。浏览器页签置顶仍由成员在新页签中手动操作。
2. 顶部主卡同时展示当前时间块、完整一天的紧凑指导列表和当前所在段数。时间块列表只说明此刻及后续应该做什么，
   不再提供完成打卡，也不根据时间流逝伪造完成事实。
3. “今日三个重点”与“每日必做”桌面端并排；“每日卦象”与“精力补给”桌面端并排。窄屏按重点、必做、卦象、
   补给顺序纵向展示，不产生横向滚动。
4. 明日重点保留真实跨设备保存、草稿防丢和失败重试，但默认收起，需要时从今日重点卡片原位展开。
5. 今日节奏不再展示每日工作记录编辑器，也不再加载工作文档、知识库和模板数据；成员仍可从知识库使用已有文档。
6. 每日卦象显示服务端权威卦名、变卦和最近一次已保存 AI 自照的短摘要；没有起卦、没有 AI 自照、摘要加载中和
   加载失败均明确显示，不用静态运势文案冒充真实解读，不输出确定性吉凶预测。
7. 收藏复用成员收藏持久化，换设备后仍可从左侧“收藏”打开“今日节奏”；失败时回滚乐观状态并可重试。

## 验收

- 桌面宽度下两组核心卡片分别为两列，底部不再出现可点击的“完整的一天”大时间轴和每日工作记录。
- 顶部七段指导来自成员保存的真实节奏配置，当前段高亮；页面没有修改时间块完成状态的入口。
- 已有 AI 自照时显示其纯文本短摘要；没有会话时只提示进入详情生成，读取失败可原位重试。
- 单独打开使用同一个 `/workday-rhythm` 私有路由；复制成功和失败都有反馈，不新增匿名分享接口。
- 收藏、取消收藏、刷新恢复以及从侧栏收藏打开页面均落到当前登录成员，未知模块收藏不会成为死链接。
- 390px 窄屏仍可编辑并保存今日重点、展开明日重点、完成每日必做、记录精力补给和进入完整卦象。
