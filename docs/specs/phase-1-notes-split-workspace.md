# 规格：小记左右工作区与标签

本规格调整 phase-1-notes-hub 的纵向布局。桌面左侧为常驻编辑器，右侧为记录清单；窄屏纵向排列，入口及历史文档不变。

- 左侧编辑器支持页面全屏，原实例保持挂载，Esc 或退出全屏恢复；输入、标签和保存状态保留。全屏是本页面专注编辑模式。
- 右侧顶部提供正文与标签关键词搜索、全部／我记录的、更新时间／创建时间倒序。标签条展示标签及未归档记录数量，点选过滤，可直接新增标签。
- 标签为小记共享分类，沿用当前小记可见范围；新建标签持久化后立即可选，未关联小记的标签也保留。新增失败保留名称并重试，不展示假成功。
- 编辑器可选已有标签；正文和标签同一次请求原子保存。标签草稿沿用成员草稿隔离、版本冲突及幂等重试约束。记录卡片显示标签，继续编辑可调整标签。
- 标签去除首尾空白、去重，每个 1–32 个字符，每篇最多 20 个；不从正文隐式解析 # 号。旧请求不传 tags 时保留旧标签，传 [] 时清空。已有文档默认为无标签。
- 保存后清除筛选、显示新记录；排序默认更新时间倒序，稳定使用 id 作为并列次序。

## 持久化与接口

新增 V141：doc.tags_json 与 note_tag 字典表。DocDto 增加 tags:string[]；PUT /api/docs/notes/{id}、PATCH /api/docs/{id} 可携带 tags，仅小记支持标签。标签修改提升文档 rev/updated，沿用 expectedRev 并发检查。

GET /api/docs/note-tags 返回字符串数组；POST /api/docs/note-tags 接受 {name} 幂等创建，返回保存后的名称。两个接口沿用现有登录保护。搜索、计数和排序使用现有已授权小记列表，无额外全库检索入口。

## 验收

覆盖新增标签刷新持久化、带标签保存及修改、标签过滤与搜索组合、两种排序、全屏进出不丢正文、刷新恢复正文和标签、失败重试、旧请求保留标签与版本冲突。桌面和窄屏真实页面验证；编译通过不替代上线操作。
