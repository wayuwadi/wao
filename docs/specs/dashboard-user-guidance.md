# 使用统计的解读与下一步

补充使用统计规格和 ADR-174。保留后端聚合口径、建议生成和采样频率。

- 以系统范围、本页读取时间、各图表不同统计周期解释数据；不把 Token、运行次数解释为个人效率评分。
- 基于真实摘要提示进行中运行、本周创建的失败运行和近三十天用量回传缺口，并提供 AI 运行、首页入口；不自动重试或调整模型。
- 现有带证据的交付效能与建议放在额度趋势之前，不重新生成建议。
- 首次读取失败保留错误与重试；刷新失败持续显示旧统计及读取时间，成功后清除提示。不用反复短 Toast 代替状态。
- 本周完成任务与本周创建的 AI 运行成功/失败明确区分；在线电脑仅代表近期心跳，不保证配置已具备。

验收覆盖首次失败、刷新失败保留与恢复、摘要到运行入口、建议顺序和真实数据只读浏览。
