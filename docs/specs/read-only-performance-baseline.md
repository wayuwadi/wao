# 可复跑的只读性能基准

## 结果

把已完成的性能治理测量方法固化为显式启用的本地命令。报告记录代码版本、采样时间、预热/样本数、服务方法耗时、SQL 查询次数、Mapper 返回行数和 DTO 字节数，不保存业务正文、SQL 参数、成员信息或连接凭据。

## 范围

- 使用当前真实 `DashboardService` 的首页汇总、30 天 AI 趋势、7 天任务趋势、引擎统计和 30 天用量建议。
- 明确指定文档 ID 后，增加 `KnowledgeService.getDoc` 与 `getDocRevision`；未指定时明确跳过，不随机读取某篇业务文档。
- 直接构造必要服务和 MyBatis Mapper，不启动 Spring、定时任务、Flyway、Redis、Nacos 或外部通知。
- 使用既有 MySQL 的单个只读一致性快照，关闭 MyBatis 一级跨语句缓存和二级缓存。执行器拒绝所有非 SELECT，连接使用 READ ONLY 事务，结束后回滚。
- 单并发、默认两轮预热和五轮采样；样本有上限，每条 SQL 有超时，不执行写入和压力测试。
- 默认测试跳过；只有显式设置基准开关和完整连接环境时运行。报告是本地服务与数据库往返测量，不是浏览器、HTTP、线上 P95 或生产容量。

## 对照

提供报告对照工具，展示中位耗时、查询次数和返回行数的变化，并提示样本配置、代码工作区状态和数据概况差异。不同时间的真实数据库数据可能变化，不能据两份报告直接断言代码加速；需要稳定数据和同条件复测。结果一致性只检查同轮输出，不把字节数相等当作内容相等。

## 验收

自动验证统计计算、SELECT 计数、写入拒绝、报告不含 DTO 正文和对照格式；本地连接既有 MySQL 跑完基准并生成可读报告。普通测试不应连接该数据库，也不改动业务功能或部署配置。
