# Phase 1：一句话生成结构化周报

对应任务：`t1786662335502`。决策见 [ADR-064](../adr/064-grounded-weekly-report-generator.md)。

## 用户链路

1. 成员从“个人 → 周报生成”输入一句话或按行输入多条工作记录。
2. 页面调用现有本地 Codex 只读队列，生成“本周完成、进展与结果、问题风险、下周计划”四段内容。
3. 原始记录始终留在页面左侧；生成结果可逐段编辑，编辑稿和输入按成员保存在本机草稿中。
4. 成员可复制包含四个 Markdown 标题的最终全文；复制失败时显示明确提示。
5. 已有编辑稿时再次生成只产生候选版本，成员明确采用后才替换当前内容。

## 真实性与数据边界

- 生成上下文只包含成员本次输入的原始记录，不默认检索任务、项目、群聊或知识库。
- 只允许改写、归类和组织输入事实，不补写项目名、完成或上线状态、数据指标、时间、责任人和下周承诺。
- 原文没有完成语义时不得扩大成“已完成”；下周计划只收录原文明确表达的下一步。
- 任一栏信息不足时返回 `【待补充：具体缺失信息】`，不得使用静态演示内容冒充结果。
- 服务端只把本次原始记录放入现有短期 `ai_assistant_run` 队列；完成后按既有机制清除提示正文，不写入成员 AI 聊天历史。
- 原始记录、最终编辑稿和候选版本保存在浏览器 `localStorage`，键包含当前成员 id；本期不伪装成跨设备存档。

## 状态与验收

- 页面覆盖 AI 状态检查、生成中、生成成功、失败重试、空结果、草稿保存中、已保存和保存失败重试。
- 一句话和多条记录都通过相同接口生成；服务端要求四个非空字符串字段，缺字段、额外字段或非法 JSON 均拒绝。
- 页面刷新后恢复原始记录和逐段编辑稿；生成失败不清空输入；重复生成不覆盖当前编辑。
- 窄屏下输入区、四段编辑区和候选版本纵向排列，操作按钮和文字均保持可见。
- Nginx 为 `POST /api/weekly-report/generate` 提供 330 秒读取窗口且关闭写请求自动重放。
