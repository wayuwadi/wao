# 无效页面地址的恢复入口

审计 A12：未匹配的前端地址原来直接跳转首页，用户无法分辨链接是否失效。

未匹配路由现在保留原地址并展示通用找不到页面说明，提供全部功能、首页入口；存在站内上一页时可以返回。使用既有设计变量。该说明不读取业务对象、不回显查询参数或对象标识，也不推断对象是否存在。

此静态页面可免登录访问，查找功能与首页仍走原有认证；现有文件、任务分享等已匹配路由及其404/权限处理保持。前端SPA回退仍依赖既有Nginx配置，本次不更改服务端HTTP状态码或部署规则。

验收：2项针对测试覆盖未知路由、已知文件/任务分享路由、恢复入口与不回显查询内容；TypeScript检查和生产构建通过。本地真实会话从无效链接进入说明页，再点击查找功能抵达真实功能目录，截图检查标题和主操作清晰。
