# 待办随手清单：本地试用

用户要求在待办页面增加独立入口，参照层级清单和常驻详情交互，先本地试用，不影响项目任务。

- 「按天／全部待办」旁新增「随手清单」，不调用项目任务写入 API，不改变已有数据模型。
- 左侧全部、今天、自建清单、已完成；中间快速添加和可折叠层级；右侧直接编辑标题、正文、日期及子任务。所有输入自动保存在本机，标题与正文不弹窗。
- 子任务继承所属清单，主任务换清单时整棵移动；子任务可提升为主任务。未完成子项阻止父项完成，重新打开子项同时重新打开祖先。完成内容默认隐藏，可显示或在已完成查看。
- 本地存储按成员 id 隔离，独立预览使用 local-preview；草稿也保存。读取异常不写入，写入失败显示重试并保留内存输入；跨标签页改变阻止继续写入，提供 JSON 导出备份，刷新前由用户保留输入。当前不跨设备同步，不提供后端或 MCP/CLI 能力。
- 空清单开始，不植入参考截图里的业务内容；窄屏分类横排、清单与详情上下排列。主题复用 WAO token 与公共按钮。
- `quick-preview.html` 为独立本地开发预览入口，无登录、无业务 API。正式构建仍以 index.html 为入口，不包含预览入口。原待办集成代码可在登录后的 /todo 查看。

本次仅本地开发，未发布。
