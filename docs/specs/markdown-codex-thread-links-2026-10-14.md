# 知识库与小记中的 Codex 聊天链接

知识库与小记允许以 `[打开聊天](codex://threads/<UUID>)` 记录工作讨论入口。点击由浏览器交给本机 Codex；浏览器可能要求确认打开应用，本机需要安装 Codex 并可访问相应聊天。

- 共用 Markdown 渲染器、文档编辑器和富文本复制粘贴保留合法聊天链接；Markdown 与版本化 JSON 保存、重新编辑、阅读及表格内链接均保持地址。
- 链接编辑浮层支持聊天地址，继续支持既有网页、邮件、电话与站内相对地址。由用户点击才打开，沿用新窗口、`noopener noreferrer` 与编辑选区行为。
- 只开放 `codex://threads/<UUID>`，不开放其他 Codex 路径、命令、额外查询参数、任意自定义协议或资源 URL。图片、脚本、事件和聊天复盘输出仍遵守原有净化策略。
- 服务端富文本校验仅在 `link` 文字标记的 `href` 中允许合法聊天地址，其他资源字段继续使用原有白名单。不改变 API、数据库、草稿、保存或冲突语义。已保留原地址的内容刷新即可使用，过去已经丢失的地址需要重新粘贴。
- CLI 与 MCP 继续复用既有文档读写工具，共享服务端校验；未新增操作或权限，不需要新命令。工具可见性仍以当前令牌的 `tools/list` 为准。

验收覆盖链接编辑、Markdown/JSON 重新加载、富文本复制粘贴、知识库与小记阅读点击，以及危险 URL 与净化隔离回归。实体设备的 Codex 唤起交由用户验收。
