# 天人一卦：每天九点自动起卦并发群

见 [ADR-218](../adr/218-tianren-daily-nine-automation.md)。

- 今日节奏 → 通知设置 → 卦象解读可开启“每天 9:00 自动起卦并解读（北京时间）”，与原有开关和独立通知群一起保存，默认关闭。
- 开启后每天执行，周末照常，无需打开网页。九点生成当天唯一卦象，解读成功后向已选群发送原有通知卡片。
- 提前手动起卦或解读会被复用。九点以后启用或服务重启会补齐当天，历史日期不自动起卦或补发。
- 自动起卦先保存真实结果；AI 离线、繁忙时稍后恢复，已入队后失败最多自动尝试三次，间隔至少五分钟。仍失败时可在卦象页重新解读。
- 总开关、卦象通知关闭或目标未选择时，不开始新的自动流程。发送仍受统一群通知政策约束，不误报发送成功。
- 顶部通知状态区分“解读中”“解读失败”和卡片发送状态，未生成解读不伪报已发送；卡片重试入口不会替代 AI 解读重试。
- 验收覆盖服务端时间门槛、成员隔离、目标配置、双节点及手动并发、重启恢复、失败重试、开关持久化与真实群投递。
