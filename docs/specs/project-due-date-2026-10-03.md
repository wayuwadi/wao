# 项目截止日期自主设置

- 新项目不指定截止日期时未排期，不再自动加两个月；已有日期原样保留，无历史批量改写。
- 项目设置在名称下提供可选截止日期，可填写、修改、清空。输入在保存失败后保留，成功提示后关闭；请求期间禁用表单，不让后台刷新覆盖输入。未编辑日期时不发送 `due`，避免保存其他属性覆盖并发变化。
- 列表无截止日期显示「未排期」，截止日期排序仍空值置底，不更改个人顺序。
- `POST /api/projects` 新增可选 `due`：省略、null、空串均未排期；`PATCH /api/projects/{id}` 的 `due` 省略/null 不改，空串清空。非空值必须为有效 `yyyy-MM-dd`。
- 沿用项目 `due_date VARCHAR(16)` 可空列；新建未排期及清空规范化为空串，确保 MyBatis 更新清空会实际落库；兼容历史 null，无需 migration。
- MCP `create_project`/`update_project` 同步可选 `due`，保持现有写权限门禁及成员可见范围。只读令牌不可发现或调用写工具，不新增权限。旧调用未传日期兼容。
- CLI 继续通过实时 tools/list 解析字段：`wao projects update ID --due 2027-01-15`；清空用 `wao projects update ID --input '{"due":""}'` 或 JSON 文件，避开部分 shell 对空字符串参数的处理差异。

验收包括未排期新建、历史日期保留、设置/修改/清空、保存失败重试、刷新持久化、非法日期、只读拒绝及 CLI 实际请求参数。
