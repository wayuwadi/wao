# 表格字段与最近项目的成员同步

## 范围

项目任务表格可见字段和最近成功创建任务的项目从本机偏好提升为成员偏好。同一成员在其他设备打开相关页面时读取账号配置；不增加页面栏目，不改变项目表格分组、排序、视图和固定默认项目的含义。

## 存储与迁移

- 复用已存在的 `GET /api/preferences/{key}`、`PUT /api/preferences/{key}`。服务端依据当前登录成员存储，浏览器缓存以账号与成员双重隔离。
- `project-table-columns-v1` 存储规范顺序的字段数组，标题始终可见；非法数据回退常用字段。
- `task-recent-project-v1` 存储最近成功落库任务的项目 id；创建失败不能更新。项目仍须在当前可用项目中，默认项目优先级沿用任务选择规格。
- 账号已有值优先旧浏览器缓存；仅成功读取账号为空时迁移现有本机值。读取失败保留本机选择并提示重试，不能冒充账号为空。
- 未同步选择有独立本机标记。刷新保留此选择，显示待同步，由用户重试；不能被迟到读取覆盖。远端与待同步值相同时确认同步并清理标记。
- 同一页面的保存串行，最新选择最终写入。成员切换使旧读取与保存回调失效，旧排队请求不在新成员身份下发送。
- 这是轻量键值偏好，现有接口无 CAS；多设备同时编辑采用服务端最后成功写入，其他设备重新打开页面时读取。没有后台实时推送。

## 交互与验收

- 项目显示设置内显示读取中、同步中、已同步及失败重试；字段立即生效，失败不还原或丢弃选择，标题输入不受影响。
- 任务成功落库后异步保存最近项目；偏好同步失败不让任务创建失败，不要求重复提交任务。待办和全局新建入口提示最近项目同步失败并允许独立重试。
- 服务端不可用且浏览器缓存也不可写时明确提示需保持页面；恢复网络可重试。
- 验证旧缓存迁移、另一个独立浏览器来源的账号恢复、保存失败刷新重试、迟到读取、连续保存、成员隔离和表格主子任务列对齐。

## 契约边界

不修改后端服务、HTTP API、MCP、CLI 或数据库。两项为现有成员偏好接口上的 Web 展示键，不新增业务操作、工具或令牌权限；保留此前表格分组等本机偏好。
