# 知识库写作布局

## 范围与既有约束

沿用 ADR-198 和富文档编辑器的数据、自动保存及离线草稿机制，不改变接口或数据库。
本规格调整 `phase-1-editor-toolbar-toggle.md` 在知识库正文中的入口；小记及其他编辑器仍使用原有折叠工具栏。

## 交互

- 知识库文档的格式工具栏常驻顶部文档操作区下方、标题上方，正文滚动时保持可见，不再出现“编辑工具”开关。窄屏允许工具换行。
- 输入 `/` 在光标附近打开内容块菜单，可搜索、上下选择、回车插入，Escape 关闭。提供正文、一至四级标题及既有列表、表格、图片等能力；菜单限制在视口内，页面滚动或点击外部时关闭。
- 侧栏搜索及新建入口在上，下面依次为带图标的首页、目录及文档树。桌面行内更多和加号默认隐藏，悬停、键盘焦点或菜单打开时显示；触屏保留可见入口。
- 文档操作区的“大纲”按钮控制右侧悬浮大纲，提供关闭按钮和 Escape 关闭。大纲显示既有一至三级标题并支持跳转，开关不改变正文宽度，窄屏同样可用。无标题时显示提示。
- 页面切换保留原有草稿、收藏和保存失败重试机制；布局调整不重新创建编辑器或改写正文。

## 验收

验证常驻工具栏操作、斜线插入与键盘选择、目录悬停操作、首页与文档跳转，以及有/无标题大纲开关、关闭、定位和正文宽度不变。完成编辑器及知识库相关单测、类型检查和构建，并在本地真实账号链路验收。
