# 行动计划：当天复盘可靠保存

来源：2026-09-19 产品体验审计 A01/A02。补充 `phase-1-personal-action-plans.md`，不改变 ADR-057 的计划、日期、打卡和成员权限规则。

## 用户结果

- 保存失败后保留原文和待保存目标，点击重试确实重新提交。
- 同一计划同一天串行保存；输入新内容时，旧回包不能覆盖新内容。打卡刷新也不能替换未保存输入。
- 草稿按成员、计划和日期隔离，即时写入本机；重新进入时提示“草稿待保存”，由用户确认恢复保存，不自动覆盖服务端。
- 页面切换时已编辑的防抖内容继续保存；失败草稿留在本机，刷新关闭前提示未保存。
- 本机存储失败明确提示保持页面或复制备份；服务端保存仍可继续。
- 仅备注保存回包确认备注，不把其中的整张计划快照覆盖到当前日期与打卡状态。

## 边界

不修改 API、数据库或后端最后写入生效规则；不声称新增跨设备协作锁。本机草稿不代表云端已保存。多个设备同时编辑同一条复盘的冲突检测仍需后续接口规格支持。

## 验收

覆盖首次输入、失败后重试、连续输入/慢回包、打卡并发刷新、计划/日期切换、成员草稿隔离、恢复草稿以及本机存储失败。真实链路使用单独命名、关闭提醒的验收计划，检查保存后刷新读回，不修改已有个人计划。

- 前端全量：182 个测试文件、1055 项测试通过；新增针对性用例单独运行 11 项通过。
- `vue-tsc --build` 与 Vite 生产构建通过。构建保留原有大包提示。
- 本地前后端连接既有数据库，以关闭提醒的独立验收计划操作：输入后显示已保存，刷新能读回原文。
- 仅在本地开发代理对复盘保存请求返回 503：界面显示“保存失败 · 重试”，原文保留；新页面恢复相同草稿并提示待保存。
- 撤销本地故障后点击重试，显示已保存；刷新后的页面再次显示同一复盘内容。未修改已有个人计划。
