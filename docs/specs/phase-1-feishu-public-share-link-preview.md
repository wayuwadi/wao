# Phase 1：WAO 公开分享链接飞书预览

决策见 [ADR-196](../adr/196-feishu-public-share-link-preview.md)。公开任务、文档和卦象的字段边界继续分别遵循
[ADR-013](../adr/013-public-task-share-links.md)、[ADR-060](../adr/060-tianren-public-reading-share.md) 与
[ADR-067](../adr/067-tianren-share-latest-ai-reflection.md)。

## 用户结果

成员把 WAO 已支持的公开任务、子任务、文档、小记或“天人一卦”链接粘贴到飞书会话或群置顶后，不打开链接就能看到
内容类型、标题和少量关键摘要，并可从卡片直接打开原分享地址。Markdown 直读地址与对应的人类分享页得到一致预览。

## 规则

- `url.preview.get` 复用 `/api/feishu/events`；先完成已有 Verification Token / Encrypt Key 校验，再处理链接。
- 只接受与当前 WAO 公网根地址同源的 HTTP(S) URL，不跟随重定向，不请求回调里的任意地址。
- 任务卡片展示状态、优先级/截止/项目中存在的字段、未完成子任务数量和描述摘要；`openOnly=true` 继续使用现有过滤结果。
- 子任务卡片只展示该子任务自己的公开内容；不能借预览扩大到主任务或其他子任务。
- 文档与小记卡片展示更新时间和正文摘要；卦象卡片展示日期、本卦、变爻/之卦和已有的最新公开自照摘要。
- Markdown、HTML、换行和卡片语法必须转为单行纯文本；标题和摘要限长，避免用户内容改变卡片结构或产生超大响应。
- 卡片只有“打开分享内容”跳转，不提供写操作。无效、已删除、外域或不支持的链接返回空对象，让飞书使用默认 URL 展示。
- 预览处理不得进入快速收集、共享聊天或表情派工链路；其他飞书事件维持原行为。

## 验收

- 任务分享页和 `.md` 地址都返回“WAO 任务”内联标题及同一任务的真实状态、摘要和原链接；`openOnly=true` 的未完成数量正确。
- 子任务只显示自身；文档与小记能区分类型；有效卦象凭据展示真实卦名，无 AI 自照时不伪造摘要。
- 外部域名、错误端口、非 HTTP(S)、未知路径、非法 id 和不存在的公开内容均返回空对象，且不访问对应业务服务。
- Verification Token 错误仍返回 400；URL 校验、群消息、卡片按钮、表情及撤回的既有测试继续通过。
- 飞书正式应用发布链接预览配置后，在真实飞书会话粘贴线上分享地址可看到内联标题和卡片，卡片按钮打开原地址。
