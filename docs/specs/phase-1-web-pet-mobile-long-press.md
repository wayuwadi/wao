# Phase 1：网页宠物移动端长按操作

对应任务：`t1787972966017`（改善手机上的网页宠物操作，并为右键功能提供触屏入口）。

本规格补充[网页宠物与应用壳交互配置](phase-1-web-pet-and-shell-interaction-controls.md)，
不改变成员已保存的宠物触发设置和真实数据源。

## 用户路径

- 手机短按宠物继续执行成员配置的“左键动作”，长按宠物执行同一成员配置中的“右键动作”；默认情况下分别打开快捷操作气泡和宠物功能气泡。
- 长按超过 520 毫秒后立即生效并提供轻微震动反馈；设备不支持震动时安静降级，不影响功能。
- 触点移动超过 8 像素时取消长按识别，继续沿用原有宠物拖动链路；拖动结束不得误触发短按或右键动作。
- 长按触发后屏蔽浏览器可能补发的点击和上下文菜单，避免菜单被再次切换关闭，也不得出现文字选择、复制粘贴或图片长按菜单。
- 手机上的快捷操作和宠物功能气泡改为在宠物正上方展开，窄屏下保持完整可见且不遮挡宠物本体。

## 边界

- 桌面端左键、悬停、右键、拖动和键盘操作保持不变。
- 长按复用成员级 `web-pet-settings-v1` 的右键动作，不新增第二套移动端设置或演示数据。
- 全站业务右键守卫继续负责取消浏览器原生菜单；本功能只补齐宠物自身的触屏手势和 iOS 长按选中抑制。

## 验收

- 在手机触控视口短按宠物，快捷操作正常展开；长按宠物，宠物功能气泡只打开一次，松手后不切换回快捷操作。
- 长按过程中不出现文字选择、复制粘贴或图片菜单；设备支持时有一次轻微震动反馈。
- 按下后移动超过阈值可继续拖动宠物，且不会打开宠物功能气泡。
- 在 320 像素宽视口分别展开两类气泡，所有按钮均在视口内可见、可点击。
- 桌面右键与现有宠物自动化回归测试继续通过。
