# 能力中心：飞书机器人与个人收集

2026-10-07 用户确认双群机器人接入，并统一收纳到能力中心。延续 Webhook 注册表、个人快速收集和系统 AI 的页面布局；修改现行行为见 ADR-326。

后续同日用户明确修订：删除轮询，保留午夜归档与事件 @ 快捷记录。现行行为以 [每日归档与事件快捷记录](feishu-daily-archive-and-event-capture.md) 和 ADR-328 为准；下文的十分钟轮询与不恢复归档属于先前方案记录。

## 用户结果

- 能力中心新增「机器人」区域，左侧真实机器人清单支持名称／用途搜索与筛选，右侧为能力介绍、机器人配置、运行记录。窄屏清单横向浏览，详情单列显示。
- 原「设置 → Webhook 配置」及历史 `?tab=webhook` 转向 `/capabilities?area=bots`。自动化的飞书任务收集配置转向同一区域的接收应用表单。所有入口使用同一份数据库配置，无第二套 Webhook 或凭据。
- 复用 `feishu_webhook_config` 的稳定 ID、密文、默认通知标记和历史业务引用。每项可选择仅发送通知、@ 后创建待办、@ 后创建小记；关联既有接收应用与目标群。
- 发言人登录现有 WAO 账号，在账号设置绑定飞书；接入消息后，待办的创建人和负责人、小记的作者均来自消息发送者的已绑定成员。正文中提及别人不能改变作者。未绑定、身份冲突、非用户消息、错误群和未知 @ 不创建内容。
- 只去除入口机器人的结构化 @ 标记，保留正文与换行；首行作标题，全文作描述／正文。待办不猜测截止日期，不自动拆分或启动 AI；一条消息同时 @ 多个收集入口时拒绝猜用途。
- 被哪些功能使用由实际默认路由、收集绑定及数据库中保存的业务选择计算。历史保留但当前已改站内通知的引用明确标注，不冒充正在向群发送。
- 停用、修改收集绑定、切换默认或删除前展示影响。引用读取失败不进行危险变更。删除默认项仍按已有契约选择剩余项接管，确认里注明接管目标；其他指定 ID 的引用不重写、不静默改发。
- 发送测试与业务发送记录分开，收集记录显示真实事件结果和保存对象入口；配置存在、认证已配置、发送测试成功都不能冒充真实群消息已保存。错误显示在对应机器人及详情，不增加常驻全局错误面板。

## 真实性与可靠性

群自定义 Webhook 机器人不能直接接收 @，既有飞书应用负责目标群消息接收。配置群消息接收事件而非只订阅 @ 应用自身的事件；平台后台权限与订阅需真实核对。继续保留十分钟低频轮询和额度冷却，不恢复聊天归档。

回调创建入口必须验证真实来源及对应应用／群，未配置事件认证不接受匿名写入。认证后将消息加密持久接收，快速响应，再由后台处理与有限重试；失败可在记录中查看，不因提前响应丢消息。事件与轮询复用消息幂等。绑定匹配优先稳定标识，显式精确名称仅作兼容；已登记停用入口不能被旧名称兜底重新开启。

作者匹配同时检查 Open ID 与适用范围内的 Union ID 是否一致；不使用相似昵称或默认成员。飞书编辑同步检查源记录与 WAO 最新版本，存在站内修改时保留内容并显示冲突。沿用撤回关联对象处理，仅影响真实来源记录。

全局 Webhook 和共享接收配置仅允许浏览器会话中的管理员／超级管理员管理。普通成员只显示自己的绑定指引，设备令牌不得管理应用密钥、Webhook 或收集路由。公开能力目录不包含机器人凭据或群内容。

## 编辑与草稿

机器人配置采用服务端版本 CAS；失败和冲突保留草稿。用户可使用服务器配置，或明确基于最新版本保存自己的草稿。刷新、切换区域、切换机器人保留按成员与配置 ID 隔离的非密钥草稿；WebHook 地址、App Secret、认证 Token、Encrypt Key 仅保留在当前页面内存，不进入本机持久草稿。

未保存密钥离开前提示；本机存储失败明确提示并保护输入。异步迟到响应与切换账号后的响应不更新当前界面。共享接收应用与快速收集依旧各自使用原 API，保存局部成功时明确说明并保留失败组供重试；不把 API 部分成功显示为整体已保存。

## 验收

测试覆盖授权拒绝、角色分流、身份冲突、未绑定、双 @、错误群、未知 @、机器人消息、重复投递、认证缺失、持久接收重试、编辑冲突、默认接管、真实引用、影响读取失败、草稿隔离和迟到响应。浏览器以真实账号连接既有数据库验证清单、配置保存、引用和历史入口、桌面及窄屏；真实飞书 @ 与两名成员最终验收单独记录，不能用构造事件替代。

## CLI / MCP

本次增加管理员浏览器配置与诊断 API，不增加设备令牌工具或模拟飞书消息入口。待办／小记的常规业务操作沿用已授权工具；机器人配置涉及全局凭据与共享路由，设备令牌不得扩权。将来需独立管理员 CLI 授权契约时再评估命令。
