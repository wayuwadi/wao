# Phase 1：独立润色工作台

对应任务：`t1787916105896`（新增机器人自带润色功能）。本规格复用
`phase-1-document-selection-polish.md` 与 ADR-086 已定义的真实 AI 账号和只读 Runner 边界，不改变知识库选区润色交互。

## 用户结果

- 登录成员可从侧栏「润色」菜单进入独立工作台，粘贴口语化长文并得到可复制的结构化表达。
- 每位成员可以编辑并跨设备保存自己的润色提示词；首次使用提供「看明白、想明白、说明白、干明白」默认方法。
- 每次成功润色都保存当次提示词快照、润色前原文和润色后结果，历史记录只对当前成员可见。

## 真实数据与 AI 边界

- 提示词复用 `member_preference` 的成员级键值存储；历史记录新增 `text_polish_record`，不使用浏览器样例或随机结果。
- 润色复用现有文档润色路由：优先使用设置页已启用的受信模型网关或 DeepSeek，无配置时使用安全只读 Codex Runner；上游失败不伪造结果、不写成功历史。
- 自定义提示词只能定义表达方法。服务端始终追加保持事实、数字和原意、不引入外部信息、只返回润色正文的安全约束。
- 单次原文最多 12,000 字，提示词最多 4,000 字；历史接口最多返回当前成员最近 50 条。

## 交互与失败恢复

- 页面覆盖加载、空数据、提示词未保存、保存中、已保存、保存失败重试、润色中和润色失败重试状态。
- 原文与尚未保存的提示词写入本机草稿；服务端加载完成时不能覆盖仍未落库的本地输入。
- 润色中保持原文可见但禁止重复提交；成功后展示结果并刷新历史，失败时保留原文和提示词。
- 历史记录可展开查看完整前后内容，并可将某次原文恢复到输入区再次润色。

## 验收

- 修改提示词并保存，刷新或换设备重新登录后仍读取同一成员的服务端值；模拟保存失败时草稿不丢失并可重试。
- 输入真实文字后触发真实 AI，结果可复制，历史同时出现相同原文、结果和提示词快照。
- 切换成员后不能读取其他成员的提示词和历史；AI 离线、上游失败或空响应时不新增成功历史。
- 首次无历史时明确显示空状态，刷新过程中不显示演示记录；窄屏下输入、结果、保存与重试操作保持可见。
