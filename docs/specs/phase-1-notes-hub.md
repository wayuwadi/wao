# 规格：小记集中记录空间

## 用户结果

首页菜单下新增「小记」，打开 `/notes` 即可写，不再弹窗后回到原页面。输入框和已有记录在同一页面，保存成功后清空输入框，并在下方立即显示新记录；无需先选知识库或起标题。

## 页面与兼容

- 首页下方、工作台之前增加默认可见的 `notes` 内置菜单；服务端旧注册表补齐该入口，保留已有菜单定制。
- 顶栏新建小记、工作台卡片、命令面板与旧 `openModal('note')` 调用统一进入 `/notes`。
- 上方为紧凑高级编辑器，支持格式、列表、链接、粘贴图片与 Ctrl/⌘+Enter 保存；下方以正文卡片按创建时间倒序呈现。
- 默认展示已有权限内、未归档的全部小记，可按「我记录的」和正文关键词筛选；每批展示 30 条，支持继续加载。
- 历史小记复用已有知识库、作者、文档与时间数据，不复制、不迁移。高级文档、分享和归档仍可从「完整文档」进入。
- 卡片支持原地继续编辑。编辑草稿按成员与文档分别恢复，提交携带原始 `expectedRev`；版本冲突保留草稿并显示失败，可「保留为新小记」，不自动覆盖服务端。

## 防丢与失败

- 新建沿用旧弹窗的成员草稿键与稳定文档 ID，关闭或刷新可以继续输入，失败重试使用相同 ID。
- 初始化或刷新列表时可输入、暂不可提交；真实服务未连接时拒绝内存假保存。
- 请求期间禁用编辑和重复提交；服务端成功才清理对应草稿，旧请求不得清除页面重开后继续输入的新草稿。
- 草稿存储失败明确提示保持页面打开；服务端保存失败保留正文与原地重试；加载中、读取失败和空结果独立呈现。
- 保存新小记时清除搜索和作者筛选，确保用户立刻看到刚记录的内容。

## 验收

验证首页入口、旧入口统一跳转、新建并立即回看、刷新持久化、搜索、原地编辑和草稿恢复。覆盖服务端失败后同 ID 重试、未连接禁止假成功、并发版本冲突、存储异常与手机窄屏可操作。

本规格调整旧小记弹窗规格的入口形态，保留其幂等创建和草稿防丢约束。未新增接口或数据库 migration。
