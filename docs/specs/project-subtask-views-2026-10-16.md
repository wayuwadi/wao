# 项目四视图子任务展示

用户于 2026-10-16 确认交互设计稿，范围为项目任务四象限、分组、看板和表格。

- 四视图工具栏直接展示「显示子任务」「显示已完成」。子任务默认显示，包含普通内嵌子事项和完整下级任务；关闭后仅展示顶层任务，详情数据不变。
- 「显示子任务」与层级展开选择按账号成员、项目、视图独立记忆。复用成员偏好 `project-layout-v1:subtasks:<project>:<view>`，含 `show` 与 `collapsed`；保留离线选择、读取／保存状态、失败重试和迟到读取保护。不修改 API、数据库结构、MCP 或 CLI 能力与权限。
- 分组沿用根任务所在组，表格沿用现有可编辑列。父子缩进、单项折叠、展开全部和收起全部；隐藏不丢弃行内子事项草稿。筛选命中的后代保留同项目祖先上下文。
- 看板子事项按自己的状态展示：未开始对应待办列，进行中、待验证、已完成对应同名列；不支持的收集中／AI 状态拒绝且提示。四象限按自己的优先级展示，历史未设置优先级沿用 P2 归类，不写入或继承父任务优先级。显示父任务来源，点击定位，当前视图不含父任务则打开其详情。
- 子事项投影仅用于展示，身份为所属任务＋稳定子事项 id。所有详情、分享、修改及重试映射回真实记录；禁止将投影 id 发送到任务写入或排序接口。跨看板列／象限只更新当前项属性，父子关系不变。完整任务保留原排序、编辑和批量操作；普通子事项不冒充完整任务参与 AI 批量派发。
- 只显示开关不改变任务详情、项目总数或完成口径。已完成但仍有未完成后代的上下文保留；保存失败项仍有重试入口。

验收覆盖两类子任务、多层级、不同父子优先级／状态、独立偏好与刷新、负责人筛选、完成过滤、草稿、失败重试、明暗主题、窄屏和键盘。实体设备最终验收由用户完成。
