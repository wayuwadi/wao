# 日历视觉精修（2026-10-03）

依据四页推荐 Demo 的实施授权，以现有浏览器日历为基础。此规格仅补充视觉层次，不改变任务执行安排、截止日期、权限或持久化契约。

## 行为

- 执行事项采用紫色实线边，截止事项采用浅橙底与虚线边，月视图、时间轴与全天事项一致。保留「执行／截止」文字，不能只依靠颜色识别；同日合并、跨日续段与拖动/撤销规则不变。
- 天气、卦名、大小周、考勤开关及天气摘要放入默认收起的「天气与辅助信息」。展开/收起仅改变布局，不写个人偏好、不清天气数据，也不关闭日历中的已启用信息。
- 已完成任务开关、年/月/周/日、日期、成员、查找和日历设置仍直接可用。天气不可用/更新中的摘要状态仍可见；原有节假日/卦名读取失败与重试不隐藏。
- 考勤侧栏原已默认收起，节日设置原在次级菜单；直接沿用，不重复建设。
- 手机辅助开关两列换行、40像素触控；展开区和任务项提供键盘焦点。日历继续在自身区域横滚。
