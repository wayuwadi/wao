# 浮层关闭与焦点一致性

2026-10-03，补充顶栏工具、版本提醒、通知中心和首页卦象预览规格。

- 自定义浮层共用关闭栈；一次 Esc 或外部点击最多交给最后打开的一层，不能关闭后继续穿透底层。输入法组合输入和已被内层菜单消费的 Esc 不处理。
- 工具和更新预览的外部点击不抢焦点；主动关闭或 Esc 回到入口。通知中心主动打开聚焦关闭按钮，关闭返回工具入口；独立使用时返回自身按钮，路由变化收起不抢焦点。
- 首页卦象预览遵循同一 Esc 顺序；上层仍打开时不响应底层外部关闭。
- 快捷小记沿用明确收起和 Esc，保留草稿；保存期间不关闭。全屏编辑及任务浮层继续使用既有保存/关闭屏障，不因统一交互丢弃输入。编辑型浮层不新增外部点击丢稿路径。
- 自动更新提示仍不抢输入焦点；维护分流与十秒新功能动画保持既定行为。

仅浏览器交互，无业务 API、数据结构、MCP 或 CLI 变化。
