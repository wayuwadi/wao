# 今日节奏本机草稿与异步响应归属

补充 `phase-1-workday-rhythm.md` 的成员隔离与草稿恢复验收要求，不改变服务端接口、数据结构或通知策略。

## 用户结果

- 今日重点、明日重点与节奏配置的草稿只在当前成员下恢复。日记录同时按上海日期隔离。
- 切换成员时，包含设置、历史、成长启发在内的页面状态重新建立，旧成员异步结果不能覆盖新页面、清理新草稿或继续触发联动保存和通知。
- 跨午夜的旧保存不能清理新日期草稿；配置弹窗关闭但保留尚未提交的本机输入。
- 保存基于提交时的独立快照。成功后仅清理与本次提交完全相同的草稿；新增修改及其他标签页写入的不同草稿不被清除。
- 浏览器存储失败不打断编辑或服务端保存，页面明确提示输入仅在当前页面，并提供本机写入重试。不得在这种情况下宣称草稿已持久化。

## 兼容边界

- 新键使用 `wao-workday-rhythm-config-draft-v2:<成员>` 与 `wao-workday-rhythm-day-draft-v2:<成员>:<日期>`；成员标识进行 URI 编码。
- v1 配置草稿和仅含日期的旧日草稿没有可信的成员归属，保留原值但不读取、自动迁移、认领或删除。
- 路由入口仅在已登录成员下挂载页面，并以成员标识重建页面；原页面布局与业务操作移至内部页面组件。不是全局路由重构。
- 已经发送到服务端的请求不能因切换成员撤销；本次保护客户端结果与后续请求，不声称实现服务端取消或跨标签页协作编辑。

## 验收

- 当前成员草稿刷新恢复，其他成员及无归属旧草稿不显示。
- 保存、读取未结束时切换账号，旧结果不能污染新页面或启动后续请求。
- 跨午夜旧保存返回不删除新日期输入。
- 保存期间配置新输入和其他标签页草稿保持可恢复。
- 本机存储写入失败可继续输入和重试；服务端失败后草稿保留，恢复连接可保存成功。
