# WAO CLI 托管页发布规格

## 用户目标

用户可从 Windows 或 macOS 终端，把本地单文件 HTML 发布到 WAO，得到一个可以分享的公网链接，并确认匿名访问到的 HTML 与本地文件完全一致。

## 范围与交互

- 命令：`wao pages publish --file FILE --title TITLE --slug SLUG [--project-id ID] [--yes]`。
- 仅接受 `.html` / `.htm`、有效 UTF-8、非空且最大 10 MB 的单文件；标题为 1～200 个字符，slug 遵循服务端相同格式。
- 每次交互执行都显示标题、slug、文件名/大小、项目和预计公网 URL；用户输入 `yes` 后才发出创建请求。非交互执行必须显式提供 `--yes`。
- 项目归属可选；指定项目时服务端按令牌成员检查项目可见性。页面本身为公开链接，CLI 不静默修改或删除已存在页面。
- 创建成功即打印公网地址，然后发起不带身份凭据的匿名 GET，确认 HTTP 成功、`text/html` 和服务端隔离外壳中的 HTML 字节与本地文件一致。
- 页面已创建但响应超时或核验失败时，不自动重试；错误信息保留链接并提示先检查，避免重复发布。

## 授权与凭据

- 现有工作区令牌创建表单增加独立的“允许发布 HTML 页面”授权，默认关闭；旧令牌迁移后保持关闭，不能因既有可写权限而隐式获得发布权限。
- 权限仅用于 `POST /api/hosted-pages` 及权限预检 `GET /api/hosted-pages/publish-access`，不开放托管页列表、更新、删除、MCP 工具或跨成员数据。
- 令牌成员创建页面；关联项目必须对该成员可见。浏览器会话既有上传路径保持有效。
- CLI 登录分别使用 Windows 当前用户 DPAPI 与 macOS Keychain；`WAO_TOKEN` 可供自动化使用。令牌不进入命令参数、仓库、日志或匿名验证请求。

## 验收

- 本地 CLI 测试覆盖参数/编码校验、确认拦截、授权失败、项目预检、multipart 上传、匿名无凭据访问和远程字节比对。
- 服务端测试覆盖旧令牌默认无权限、新令牌权限持久化、发布端点范围、项目可见性和浏览器会话兼容性。
- Windows 凭据测试使用模拟 PowerShell runner，确认令牌通过标准输入传递且不进入命令脚本；不读写开发者真实凭据。
