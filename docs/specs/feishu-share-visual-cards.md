# 小记与卦象分享的飞书图文卡片

补充 [公开链接预览](phase-1-feishu-public-share-link-preview.md)，沿用 ADR-196 的同源、回调校验和公开只读边界。

- 小记展示已保存标题、润色阅读版本中的首张站内配图和最多 240 字正文，点击打开原分享页。有效历史润色对照仅在作者与来源正文仍一致时进入公开阅读投影；过期或他人的结果回退当前正文。公开页面、Markdown 和卡片使用同一版本，不附带私人原稿或 AI 输入。
- 卦象展示日期、本卦、变爻/之卦、最多 240 字快速总结和「查看详情」。优先读取已保存的快速总结小节；旧存档没有此小节时使用公开解读正文开头，删除图片语法及替代文字。不额外调用文字模型，不修改解读的既有九章节。
- 图片由当前飞书应用上传获取 `image_key`，卡片使用图片组件；上传缓存按应用、内容版本隔离。首次上传最多等待 1.8 秒，超时保留文字与按钮，后台上传成功后再次预览可复用；失败允许后续重试。回调不生成图片、不发送群消息。

## 卦象私有配图对接

ADR-320 已实现解读绑定的私有配图、领域表和本人鉴权 HTTP API。本次按分享卡片需求，由领域服务提供有效分享凭据对应的图文投影，不读取本人鉴权图片端点，也不改变配图生产流程。

`TianrenVisualService` 实现 `TianrenShareVisualProvider`，卡片使用以下只读协议：

1. `findSharedVisual(shareToken)` 只返回有效分享凭据对应的最新成功解读，以及绑定该版本的成功图片。分享已撤销、正文已更新或摘要不完整时返回 null；记录无图或图片生成失败时仍返回已保存摘要，图片字段为空。读取不得生成或重试。
2. `Visual.interpretation` 必须与 `TianrenReadingService.shared(token).interpretation` 完全一致；不匹配时卡片拒绝摘要和图片。领域服务还须核对成员归属、解读运行与当前图片指针，防止迟到结果或相同正文的旧图片串版本。
3. `summary` 是可公开的快速总结，可由已保存视觉标题、变化点、保持点组成；不得包含私有关注点、提示词或画面生成指令。
4. `imageVersion` 为不可变图片版本，PNG 内容与 MIME 由服务端读取，不调用本人鉴权图片 HTTP 端点。图片只上传给当前飞书应用，不新增公开二进制地址；不得将此接口暴露给旧 MCP 令牌。
5. 卡片仅在公开解读有效、版本一致时采用提供者结果，私有模块异常不影响文字卡片。提供者未安装时支持旧解读中已经公开的 `/api/images/{id}/raw` 配图；没有图片时保持文字卡片。

提供者同时核对分享记录、成员、解读所属会话、最新成功正文、图片 attempt 的成员与 run 归属和成功状态。分享撤销后不能再读取投影；飞书已收到的卡片副本遵循飞书自身保留规则。原有私有图片 HTTP 接口继续要求本人鉴权，不新增匿名 PNG 地址。

## 验收

覆盖有效/过期/其他作者的小记阅读结果、正文图片与替代文字剔除、真实卡片图片组件、快速总结小节边界、旧解读和无解读、私有图片版本不匹配、私有存储失败降级、上传失败与缓存复用，以及原链接跳转。另行用既有数据库与真实飞书图片上传验证小记数据链路；飞书客户端实际渲染和平台 URL 规则需如实记录验收边界。

CLI/MCP：调整现有公开分享投影与飞书回调展示，没有新用户操作或工具权限；不增加 CLI 命令。将来若开放主动向会话发送卡片，须独立设计成员授权、目标和幂等语义后重新评估。
