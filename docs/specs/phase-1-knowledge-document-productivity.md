# Phase 1：知识库文档模板、拖拽整理与写作导航

## 目标

1. 成员可以把当前文档另存为自己的模板，并在新建文档时从空白或模板创建。
2. 模板可加载、重命名、修改说明和删除；加载、空数据、保存中、失败重试均有明确状态。
3. 文档可以在左侧树中拖拽排序，也可以拖入其他文件夹；顺序与归属跨设备保持一致。
4. Markdown 编辑器按下 Tab 不离开编辑区：列表项缩进，普通正文插入缩进；Shift+Tab 反缩进列表项。
5. 知识库文档支持一级、二级标题；只要正文存在任一一级或二级标题，右侧悬浮目录就出现，并区分层级、跟随滚动高亮、点击定位。
6. 桌面端左侧文件夹树与右侧文档编辑区各自在应用壳剩余高度内滚动，浏览长文档时目录位置不跟随正文移动。
7. 文件夹首次进入默认收起，只展开当前文档所在文件夹；手动切换仍即时生效，从分享链接、收藏或跨文档链接进入时当前文档必须可见。
8. 知识库首页可按真实知识库名称、简介、文件夹名和文档标题检索，并按全部、项目、共享、个人范围筛选；命中文档标题时可以直接打开对应文档。
9. 一次性文档可归档后长期保留：它退出普通文件夹树、全局搜索、项目资料和 AI 知识检索，在原知识库的“已归档”区域仍可打开并恢复到原文件夹。

## 边界与数据口径

- 模板来自真实文档正文快照，不提供固定演示模板；模板按当前登录成员隔离。
- 删除模板不删除来源文档，也不修改已从模板创建的文档。
- 拖拽接口必须收到当前知识库的完整文件夹和文档集合；缺失、重复或跨知识库数据整体失败。
- 一级标题只在知识库文档场景开放，任务描述等共用编辑器的页面仍从二级标题开始，避免正文标题压过页面标题。
- 老文档标题块没有 `hLevel` 时按二级标题兼容。
- 第一版首页检索只对已从后端加载的真实字段做关键词匹配，不冒充 AI 语义搜索；没有真实外部邀请接口时不展示演示邀请链接。
- 归档与删除是独立状态：归档不进入 7 天回收站清理；删除知识库或文件夹时，其中已归档的文档仍跟随父级进入回收站。
- `GET /api/docs` 与知识库文件夹只返回日常文档；`GET /api/docs/archived?kbId=...` 返回指定知识库的归档文档，`POST /api/docs/{id}/archive` 与 `DELETE /api/docs/{id}/archive` 分别归档和恢复。

## 验收

- 文档另存模板后刷新页面仍能看到；从模板创建的新文档正文与保存快照一致。
- 账号 A 不能列出、修改、删除或使用账号 B 的模板。
- 同文件夹重排和跨文件夹移动刷新后保持；构造缺文档或重复文档的请求返回 400 且顺序不产生部分更新。
- 在正文与列表中按 Tab，焦点不跳到图片按钮；列表可缩进与反缩进。
- 只有一个一级或二级标题时目录也显示；混合一级、二级标题时层级清晰，滚动与点击定位正确。
- 长文档与长目录分别滚动且互不带动；首次打开多文件夹知识库时只有当前文档所在文件夹展开，切换文件夹后可正常展开和收起。
- 用知识库名称、简介、文件夹名或文档标题均能筛出所属知识库；项目、共享、个人筛选只展示对应真实资料，空结果可一键恢复全部资料。
- 搜索结果中的文档标题可直接打开目标文档；页面不再出现“AI 语义搜索”演示结果或 `.example` 邀请地址。
- 归档一篇文档后刷新页面，它只出现在“已归档”区域，正文和原文件夹身份不变，也不会进入回收站、全局搜索、项目资料或 AI 知识候选；取消归档后刷新仍回到原文件夹。
- 归档读取和状态变更失败时页面保留原状态并提供重试反馈，不把仅在本地变化的结果冒充为成功。
