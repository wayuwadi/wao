# 请求监控体验摘要

补充现有 HTTP 请求监控规格，保留指标采集、成员权限、巡检和聚合排序规则。

- 首屏解释当前账号、统计窗口与采样时间。先给失败关注提示，其次慢请求提示；无失败或慢请求只描述当前样本，不宣布全站健康。
- 摘要提供定位接口的入口，复用现有失败数或平均耗时排序并回到第一页，焦点和滚动到达接口表；保留已有巡检历史入口，不自动启动 AI。
- 空数据明确无法判断，引导继续使用后刷新或扩大时间窗口；说明慢与失败可能重叠、P95 的含义以及指标不等于根因。
- 切换窗口不显示旧窗口数据，过期响应不能覆盖最新选择。同一窗口刷新期间保留并标明旧样本，失败保留原位重试。
- 本轮不改变巡检的启动、配置和执行语义，不修改其他模块内部。

验收覆盖失败、只有慢请求、无异常样本、空样本、旧请求晚返回、跨窗口失败恢复、同窗口刷新失败，以及摘要到接口与巡检历史的真实路径。
