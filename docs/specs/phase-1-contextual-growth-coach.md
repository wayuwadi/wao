# Phase 1：基于真实工作的每日成长教练

对应任务：`t1787896534113`（在使用 WAO 的过程中主动激发新的思考，帮助有经验的工程师把经验转化为 AI 时代优势）。
决策见 [ADR-151](../adr/151-contextual-growth-coach.md)。

## 用户结果

1. 登录成员打开首页即可看到“今天别只比 Coding”；内容从本人正在进行和最近完成的真实 Task 中识别一个成长信号，
   不再提供与实际工作脱节的泛化建议。
2. 成长教练以 L1 写代码、L2 完整功能、L3 系统与拆解、L4 产品/决策/Owner、L5 找到值得解决的问题作为思考框架，
   但不凭少量 Task 武断给成员定级，也不贬低 Coding 的基础价值。
3. 每份启发固定给出一个真实依据、一个新视角、一个追问和一个当天可观察的小实验；资料不足时明确说明不足，不补造经历、
   角色、团队或成果。
4. 用户可点击“带着这个问题继续聊”，把当天启发带入 WAO AI 的新会话草稿；草稿不会自动发送，用户可以修改后再决定是否提问。
5. 同一天刷新或换设备恢复服务端已保存结果；主动“换个角度”才覆盖当天内容。读取、后台准备、生成、失败和 AI 不可用均有明确状态和重试入口。

## 数据与权限边界

- 上下文只读取 `owner_id = 当前成员` 的 Task：最多 8 条未完成任务，以及最近 30 天内最多 6 条有真实
  `completed_at` 的已完成任务；项目名称只来自这些 Task 的真实所属项目。
- 内容继续通过成员隔离的只读 Codex Runner 生成，运行后清除短期提示；当天结果保存到新的成员偏好键
  `growth-coach-v1`，不混用已暂停的旧建议缓存。
- Linux 主节点为每位真实成员每天最多自动准备一次；从节点保持关闭。没有真实 Task 或 Runner 不可用时不展示静态文案冒充结果。
- 继续对话复用成员级持久化 WAO AI 会话和其现有资产权限，不把每日生成运行伪装成长期聊天记录。

## 验收

- 服务端生成上下文同时包含符合边界的进行中与最近完成 Task，提示明确约束 L1–L5、真实任务标题、单一追问和单一行动。
- 首页优先读取当日会话缓存并静默校准服务端；`ready / missing / unavailable / 请求失败 / 主动生成失败` 均能继续操作。
- 点击继续聊后打开 WAO AI 新会话，输入框包含可编辑的当天启发且尚未产生用户消息或 AI 请求。
- 主节点 Compose 启用 `WAO_DAILY_GUIDANCE_WARMUP_ENABLED=true`，从节点不启用；自主进化调度仍保持关闭。
- 受影响服务测试、前端组件测试、生产构建、合并后部署、线上真实页面与飞书通知全部通过。
