# 呼吸首页与彩虹七世界设计 A2

状态：2026-10-03 提案，等待整体设计确认。A2 纳入用户补充：七个游戏页面按红橙黄绿青蓝紫排列，各有不同颜色风格；新增干净的纯呼吸首页。本文不覆盖既有六世界规格；确认后逐款新增正式规格与确认记录。用户目标是七种值得反复游玩的完整体验，不是同时制作七个浅层游戏。

## 页面与视觉设计

`/breathe` 内共八个视图，不增加站外跳转。默认是纯呼吸首页：中性留白、标题、细线呼吸圆、时长、开始/暂停；没有伙伴插画、游戏推荐卡、战绩、记忆中心或装饰面板。顶部仅保留 WAO 首页、七个轻量入口与明暗切换，窄屏收为一个页面选择器。

七个游戏按固定彩虹顺序：恐龙荒野红、裂隙远征橙、星野奇旅黄、幻兽领地绿、最后一座营地青、遗迹旅人蓝、疾风赛道紫。主色同时体现在页面背景、场景与交互控件，不仅变更入口色点。角色、警告和地形保留必要辅助色与足够对比度，不能用颜色作为唯一判断依据。

保留原有六种风格的构图切换能力，在游戏页“页面风格”面板中选择；默认对应关系见下表。切换构图不切游戏、不改游戏固定彩虹主色、不重置存档。原有静坐保留次级入口，不放到纯呼吸首页主内容中；呼吸与静坐组件继续留在主站。以上次级入口位置仍属于待确认设计。

桌面中央一个大游戏舞台，上方是名称、简短目标、风格/记忆/音效/沉浸，下方是核心操作与存档状态；删除 A1 的大标题和七张选择卡，减少占用。顶部七个轻量入口横排或换行，不新增独立导航页面。背包、地图、技能等在舞台内侧面板打开，并暂停单机玩法。手机入口用有名称的选择器，舞台独占一行，HUD 精简，双拇指触控留足 44px 按钮；面板在舞台内替代舞台内容，可返回。横屏用于动作与竞速的推荐体验，但竖屏也可操作，不能强迫旋转。

沉浸模式收起 WAO 装饰、风格条与其他入口，保留返回、暂停、音效和必要 HUD；占据页面可用空间，可额外请求浏览器全屏但不依赖它。保存进入前滚动位置，退出恢复；Esc 先关面板，再暂停，再退出沉浸。暂停后只由用户明确继续，不因标签页重新可见自动开跑。

## 有限首发范围与独立玩法循环

以下是待确认的首发边界；确认后不可用减少内容的方式宣布达标。数量只是覆盖边界，实际差异必须经玩法验收。

1. **恐龙荒野**：无尽模式+1000米里程挑战；仙人掌 3 类、飞鸟 3 高度、通过运动可达性约束的组合；长短跳和地面蹲伏；昼夜与3类轻彩蛋；渐进速度有上限。选择模式→跑跳躲避→失误/到达终点→成绩与纪录→一键再跑。空格/↑/点击跳，↓蹲，触控两键。核心验收：操作者能用跳/蹲应对不同障碍；高分速度下测试生成器不能连续产生不可达状态；完成挑战和失败重开。
2. **裂隙远征**：剑刃（近战连击/弹反窗口）与星枪（远程蓄力/位移）两职业；3章、每章2战斗段+独立Boss房；6种普通敌人、3种精英变体、3个机制Boss（跳过震地/破盾后输出/分身辨识）；12件装备、每职业6个技能节点，3个主动槽。选择职业装备→进关→移动跳跃/普攻/技能/闪避连招→掉落与胜负→成长→重挑战。WASD/方向移动，空格跳、J普攻/KL技能/Shift闪避；触控虚拟方向与动作键。验收：真实通关两职业至少各一章并完成全部Boss机制；站桩自动攻击无法代替闪避，装备与技能存在可行不同组合。
3. **星野奇旅**：3个章节区域、9个任务节点、6名可配置角色（队伍3人）和3种协战宠物；4属性相克、速度顺序、护盾/灼烧/迟缓/禁疗等状态；每角色4技能、两条成长分支；12装备、6类敌人、3个Boss。探索→选任务路线→配队→看行动意图选技能/目标→结算→装备技能成长→新区域。鼠标/触控选目标，方向切目标、Enter确认。验收：完整三章可通，治疗/控制/打断及属性选择影响行动结果，宠物行为与配置一致。
4. **幻兽领地**：4区、12只幻兽（攻击/守护/支援/控制），每只至少两种成长方向、6个明确进化形态；三兽出战，4类协同；捕获、即刻可完成的孵化条件、资源培养；4个区域守卫和图鉴阶段目标。选路线与风险→遭遇/资源/捕获→分配培养资源→配队协同→解锁新区域。遭遇采用有可暂停指令的短阵容战斗，玩家决定带谁/技能优先级/捕获时机；不复制回合RPG的逐人选招。验收：完成探索捕获培养进化与四区解锁；至少两组不同队伍能过守卫；无强制现实等待和付费随机抽取。
5. **最后一座营地**：3张路线布局不同的地图（单线弯道/双路汇合/交错双入口）、5类塔（速射/炮击/减速/贯穿/支援），各2升级分支；6类敌人、3个Boss、2主动技能；每图12波、通关解锁无尽。布塔→发波→操作技能与资源→升级或出售→守住/失守→解锁重试。验收：建造升级出售闭环；护甲、飞行/快速、护盾等针对性清晰；每图至少3种预算相近有效布局的测试与人工验证，不能锁死唯一解。
6. **遗迹旅人**：2幕共12层分叉路线+最终Boss；36张机制不同卡（连击/护盾反击/灼烧抽弃3流派）、12遗物、10个有代价事件、商店/休息/精英；6类普通敌人、3精英、2个最终Boss候选；卡升级与移除。选路线→读意图出牌→奖励取舍→改善构筑→Boss→胜负开新局。验收：真实完成一局和失败重开，3流派均能成型；费用/抽牌/弃牌/状态与遗物触发正确；长期解锁只扩充选项，无无上限加属性。
7. **疾风赛道**：3条连续闭合赛道（海湾宽弯/峡谷发夹/云城连S），每赛道3圈；计时赛与4名明确电脑对手；3车（轻敏/均衡/重稳）转向、抓地、质量/加速区别；漂移蓄能与出弯释放氮气，路肩/碰撞减速、驶出复位。车库选车→选赛道/模式→有效检查点与圈数→名次/最佳圈速→解锁挑战。W/↑油门，S/↓刹车后倒车，A/D转向，Shift漂移，Space氮气；触屏对应按钮。验收：三条跑完有效圈数；倒开/切弯跳检查点不能记圈；实际体验漂移+蓄能+出弯，电脑不伪称真人；驾驶差异不能只换颜色。

## 游戏记忆

不读取 WAO userId，不发 API，不上传。稳定标识上述七项，与构建 SHA、URL、账号无关。正式由主站轻量存档服务持有 IndexedDB 事务，游戏经校验后的消息提交自身快照；免登录同源父页加载。

- 本机自动保存与仅本次两个模式。切到仅本次保留已有本机档，后续写入只在内存；切回本机需提示将覆盖的内容，不能静默合并。
- 恐龙保存永久纪录/里程解锁；竞速保存车型/赛道解锁/最佳圈速/完赛纪录，不恢复半圈。其他五款保存成长与安全局内状态：动作在检查点恢复；回合在行动提交后；宠物在遭遇结算或区域节点；塔防波间；卡牌在完整动作边界。导出按钮注明“从哪个位置继续”。
- 格式：`formatVersion`、每游戏 `gameId`/`rulesVersion`/`savedAt`/`revision`/`payload`；所有字段有 schema，摘要由通过校验的状态生成，不信任文件提供的HTML/说明。单档上限2MiB，总包10MiB、最多7游戏；限制字符串长度、数组数量、递归层数，拒绝重复游戏、未知规则及非有限数、非法资源/装备/任务引用。
- 导入先读取与完整验证全部记录→预览名称/时间/关卡和冲突→选择恢复项→取消或备份后原子覆盖。不允许部分成功后才发现剩余文件坏掉；失败保留原档，导出备份/重试可用。备份恢复也须校验，保留至少最近3版，不默认删除旧正式版本。
- CAS revision + 单次 IndexedDB 读写事务检测跨标签并发；BroadcastChannel只是通知。冲突暂停自动写入、保留内存草稿，提供导出本页/读取其他页/确认覆盖；不能只靠 storage 事件最后写赢。
- 保存显示“仅本次 / 保存中 / 已保存 / 失败，重试或导出 / 另一页有更新”。关键奖励和配置提交立即保存，短局纪录结束即保存；离开事件仅兜底。新规则迁移先备份、纯函数迁移后重新校验，失败可继续旧版本或导出，不破坏原档。
- 六款旧游戏与账号隔离旧档不删。不同玩法不伪造自动迁移；替换时保留可导出的历史档入口与说明，历史SVG不是新游戏可续玩记忆。

## 生命周期与输入

只挂载当前游戏，进入时轻量加载屏，失败可重试/回呼吸。输入只在已聚焦舞台与运行状态处理；输入框、弹层、文本选择、主站快捷键不被拦截。blur、visibilitychange、切模式、切游戏清空按键、停音频、停帧循环；切游戏先确认最后快照/失败出口，再卸载iframe。恢复通过按钮触发音频上下文，不自动播放。触屏 pointercancel 清除按键，长按动作不滚动舞台但页面其余区域正常滚动。

## 每款共同验收与发布

逻辑/组件测试、真实浏览器代表性完整循环，明确区分模拟与手操；通关/失败/暂停/继续/重开/返回；记录保存/刷新/跨存储导入续玩；坏档、规则不兼容、存储配额、跨标签冲突；桌面与360px、浏览器控制台和代表性性能；类型/Lint/生产构建/相关功能回归。正式验收不以A2设计Demo代替。

一款一个 PR，确认后范围全实现并验收才能合并、发布及公网核验；公网SHA包含合并、游戏清单和资源校验、健康、入口均通过后报告，再制作下一款Demo。全部完成前目标保持未完成。
