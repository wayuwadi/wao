# Phase 1：网页宠物今日节奏快捷动作

对应任务：`t1787811982759`（让网页宠物承载无需进入多层菜单即可完成的高频真实动作）。基础宠物行为见
[网页端 WAO AI 宠物](phase-1-web-ai-pet.md)，今日节奏的数据与通知边界见
[个人工作日节奏](phase-1-workday-rhythm.md) 与
[今日节奏精力补给群通知](phase-1-workday-rhythm-energy-notifications.md)。

## 用户路径

1. 登录成员点击宠物、悬停宠物或用键盘把焦点移入宠物操作区时，宠物旁展开本人“今日节奏”中排在前面的最多三个精力补给项目。
2. 点击累计项目会把当天真实次数增加一次；点击“每天一次”项目会完成当天记录，完成后不可重复点击。
3. 保存成功后气泡立即显示真实次数或“已完成”；成员离开当前页面后再次展开时，从服务端恢复最新记录。
4. 宠物快捷记录沿用项目已有的飞书通知选择。记录先保存，通知后发送；通知失败不能回滚或重复增加记录，可在原气泡重试通知。
5. 快捷清单提供“宠物设置”，直达“今日节奏”的精力补给项目编辑区；项目按账号保存，保存顺序就是宠物展示顺序。
6. 点击宠物本体只触发互动并展开快捷清单，不再打开 WAO AI；任务动态气泡仍按原顺序轮播。

## 数据与失败边界

- 项目配置继续来自当前成员的 `workday-rhythm-config-v1`，当天结果继续写入
  `workday-rhythm-day-YYYY-MM-DD`；不新增固定“运动”项目、不生成演示次数，也不把未配置的动作伪装成可用。
- 项目不足三个时只展示实际项目；项目超过三个时只在宠物展示前三个，完整维护与记录入口仍是“今日节奏”。
- 首次展开有明确加载状态；配置或当天记录读取失败时显示真实错误并允许重试。
- 保存中禁止重复点击；保存失败时把待提交记录保存在本机，原位重试不再次累计。通知失败与保存失败分别呈现。
- 如果同一浏览器已经存在“今日节奏”的未保存当天草稿，宠物不得覆盖它；快捷动作改为提示先回到页面完成保存。
- 点击可把清单保持展开，悬停只是鼠标快捷方式，键盘焦点同样可以展开和操作；减少动态效果时不播放展开或宠物动作动画。

## 验收

- 配置喝水、运动、冥想和第四个项目时，宠物依次展示前三项；累计项目连续成功点击后次数递增，每天一次项目成功后禁用。
- 保存请求失败后气泡明确提示失败；点击重试只提交原记录，不把一次操作累计成两次。
- 记录成功但通知失败时显示“已记录、通知失败”；重试只发送通知，不修改当天次数。
- 当前浏览器有未保存的今日节奏草稿时，宠物不给出可写按钮，并提供回到“今日节奏”的恢复入口。
- 点击宠物播放互动动作并展示清单，“宠物设置”直接打开真实项目编辑区；任务提示、宠物拖动、窄屏布局和键盘操作继续可用。
