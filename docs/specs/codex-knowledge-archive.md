# Codex 工作记录归档

## 结果与范围

用户在每台电脑安装 `codex-knowledge-archive` Skill 后，通过 Python 3 标准库采集程序补录本机 `CODEX_HOME/sessions` 和 `archived_sessions`，并由操作系统定时执行增量同步。Skill 本身不承诺自动常驻。用户已要求补录全部现存历史；通用安装仍提供 `all` / `new` 选择。

记录保存到固定“Codex 工作记录”知识库，按成员、设备和工作目录分文件夹，文档记录会话 id、时间、来源路径、批次身份与可见对话/工具过程。知识库遵循 WAO 当前知识库可见范围，是团队业务资料，不宣称为个人私密保险箱。原文仅作为资料，不能成为可执行指令。

## 契约

- `PUT /api/memory/tokens/{id}/grants` 新增可撤销 `codex_archive` 授权，scopeId 强制为当前成员；旧令牌默认没有此权限。只允许写入专用归档库，不能指定其他知识库或修改已有文档。
- `GET /api/codex-archive/status` 与 `POST /api/codex-archive/batches` 使用 Bearer 设备令牌；Cookie 不能替代令牌。401 表示失效，403 表示未开通归档权限。
- 批次字段：deviceId、deviceName、sessionId、project、source、startOffset、endOffset、part、title、content。内容最多 100000 字符，设备 / 会话身份限 ASCII 标识。服务端按成员+设备+会话+来源字节区间+part确定文档 id，锁定父知识库后创建。重复批次返回同一文档，即使文档被人工编辑、归档或移入回收站，也不覆盖或复活。
- 本地 SQLite 保存字节断点和待发送批次；读取断点和待发批次原子保存，再请求；成功才移除待发批次。失败保留精确请求，重试不依赖当前文件内容，网络结果不确定时仍幂等。运行使用跨平台文件锁防止同机重叠。
- 只采集用户/assistant 的可见消息与工具调用/结果；忽略 reasoning、系统/开发者提示、上下文和账号配置，不读取引用文件。图片/音频的二进制不上传，保留占位。超长单条分片，正文不会静默截断。解析错误会标记且停止该文件，其他文件继续。
- 客户端过滤常见口令赋值、Bearer、Cookie、私钥和高熵已知密钥格式；规则是尽力过滤，不能证明任意自由文本无敏感信息。提供工作目录排除、预览与暂停；本地配置/导出/SQLite 不进入 Skill 包。
- 不新增模型调用或向量库；JSONL+Markdown 本地导出是后续跨项目、跨系统使用的通用资料。

## 验收

验证历史+归档扫描、可见内容白名单、脱敏、半行等待、断网续传、响应丢失重试、超长内容分片、权限撤销、重复批次不覆盖人工改动。真实链路使用本地服务连接既有线上数据库，核对知识库页面显示真实记录；Skill Hub 上传只包含通用 Skill 文件。
