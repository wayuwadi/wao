# Phase 1：日历考勤与每日节奏联动

本规格扩展 [大小周日历](phase-1-alternate-work-week-calendar.md) 与
[今日节奏每日面板](phase-1-workday-rhythm-daily-dashboard.md)，技术与安全决策见
[ADR-195](../adr/195-calendar-attendance-and-moka-session.md)。

## 用户结果

1. 「日历」提供独立的「我的考勤」开关。开启后叠加当前成员自己的考勤、工时与异常；关闭后完全恢复原日历表达。
2. 月、周、日视图中的考勤日显示有效上下班时间、工时、请假、缺卡或 Moka 异常。考勤不可切换到其他成员查看。
3. 点某日可写入模拟上下班时间、次日下班标记和日期类型；模拟值参与全部计算，并可一键恢复最后一次 Moka 原值。
4. 每日工时按 `max(0, 下班 - 上班 - 60 分钟)` 计算，以小时显示两位小数；打卡不完整时不伪造工时。
5. 周均和当前范围日均只使用上下班完整的非请假日；请假不进入分母。大小周与当天覆盖决定预期工作日和缺卡提示，大周周日纳入预期工作日。
6. 上下班考勤事实自动完成「每日节奏」对应系统项并使用真实打卡时间。考勤缺失时不会伪造完成，原有未完成提醒继续生效。
7. Moka 自动同步默认每 15 分钟刷新当天；打开当天「每日节奏」且缓存超过 5 分钟时触发一次容错刷新。

## 配置、安全与失败状态

- Moka 密码只保存在当前成员的 WAO 密码本；考勤配置仅保存密码本条目 id，不复制密码，也不把密码返回前端。
- Moka 会话使用与密码本相同的 AES-256-GCM 密钥加密保存，优先复用，失效后才重新登录。
- WAO 不提交 `force` 登录。Moka 要求验证码或确认挤下其他会话时，状态变为「需要重新登录」并指导成员先在浏览器处理。
- 只持久化日期、上下班时间、日期类型与异常摘要，不保存定位、附件、打卡照片或完整远端响应。
- Moka 员工端接口改变或网络失败时保留最后成功数据与模拟值，页面显示原因并可重试；每日节奏仍可正常打开。
- 所有编辑表单具备加载、保存、成功、失败重试和本机草稿防丢状态。

## 验收

- 09:00 上班、21:00 下班显示 `11.00 h`；跨午夜下班正确归到次日时间。
- 两个完整工作日和一个请假日的日均分母为 2；缺任意一张卡的日期不计入日均。
- 关闭考勤开关后，考勤图例、指标和日历事件全部隐藏，任务、提醒、节假日和 CalDAV 不变。
- 小周周日默认不提示缺卡，大周周日按工作日提示；当天工作日手工覆盖优先。
- Moka 或模拟值出现打卡后，每日节奏上下班项以 `ATTENDANCE` 来源完成；用户手工完成的事实不被同步覆盖或撤销。
- Moka 未配置、同步中、成功、需要登录、失败均有明确页面状态；失败时已展示的数据和草稿不丢失。
