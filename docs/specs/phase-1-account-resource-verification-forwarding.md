# Phase 1：账号资源库与验证码转发

对应任务：`t1788226704498`。安全与幂等决策见
[ADR-190](../adr/190-account-resource-verification-forwarding.md)。

## 用户结果

1. 用户可从工具导航进入“账号资源库”，新增、查看、编辑、启停和删除组织共享账号；平台、登录标识、手机号、备注与
   加密密码刷新后仍由后端返回，列表永不返回密码明文。
2. 用户可选择一个真实飞书机器人作为“验证码接收”群目标；手机短信到达标准入站接口后，页面展示真实短信、解析码、
   匹配账号和转发状态，失败可以重试。
3. 手机使用独立入站令牌，爬虫使用独立只读令牌；两枚令牌可分别轮换且只显示一次，读取设置只返回是否已配置。
4. 爬虫用手机号查询最近验证码；`+86` 与无区号的大陆手机号匹配同一账号，默认只返回五分钟内的最近有效码。
5. 账号编辑覆盖加载中、空数据、保存中、失败重试和本机草稿；递增版本阻止多人静默覆盖。验证码页面覆盖空数据、刷新、
   飞书失败和重试状态。

## 数据与安全边界

- 账号资源是组织共享资产，不并入按成员私有的个人密码本。创建人和修改人由服务端会话确定，不接受请求体指定。
- 账号密码、短信正文和验证码使用 AES-256-GCM 加密；入站和爬虫 Token 只保存 SHA-256 摘要，不写入日志或读取接口。
- 只有明确验证码语境中的 4–8 位数字会被解析；未识别消息仍真实保存并转发，页面明确标记“未识别”。
- 入站请求以 `externalId` 优先幂等；没有 `externalId` 时使用手机号、发送方、来源、正文和接收时间指纹。相同请求重试
  不重复发飞书消息。
- 爬虫取码窗口为 1–600 秒，默认 300 秒；消息保留三十天。验证码不受普通通知静默时段抑制；飞书不可用不丢短信，
  成功投递不重复发送。
- 不附带演示账号、静态验证码或假成功。没有生成 Token、没有真实 Webhook 或外部设备未配置时，页面如实显示未接入。

## 验收

- 空库显示“还没有账号资源”；新增真实账号后刷新仍存在，密码列表只显示占位，显式查看才返回明文。
- 同一账号的旧 revision 更新或删除返回 409；保存失败保留表单和同版本本机草稿。
- 用入站 Token 提交含“验证码：621059”的短信后，验证码记录显示 `621059`、规范化手机号、匹配账号和真实飞书状态。
- 相同 `externalId` 重试返回 `duplicate=true` 且飞书不重复收到消息；不带验证码语境的订单号不会误解析。
- 用爬虫 Token 按 `+86` 或无区号手机号都能读取五分钟内最近验证码；用入站 Token 调取码接口或反向调用均返回 401。
- 飞书目标停用或发送失败时短信仍保留并显示失败，恢复配置后点“重试”可变为“已转发”。
