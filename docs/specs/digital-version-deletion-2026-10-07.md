# 数字成员形象版本删除

补充 ADR-330 与数字成员图库规格。一个版本可删除并恢复；私有照片、不可变身份快照、已生成小记图片、使用记录及排队任务的冻结参考保持原样。

使用既有 `digital_appearance_version.state` 的 `deleted` 状态，无数据库结构变更。`confirmed_at` 保留：恢复后有确认时间的是 confirmed，否则为 candidate。版本号不会复用，形象仍可添加新版本。

DELETE `/api/digital-versions/{id}` 和 POST `/api/digital-versions/{id}/restore` 接收 `{expectedRevision}`（所属 Look 的 CAS），返回 Subject。仅当前会话拥有者可操作，归档成员先恢复。状态已达到目标的重试幂等；跨设备过期状态变化返回409，草稿保留。

删除默认版本时，仅清除对应 version_id 并推进 binding revision，本人 subject_id 和主参考保留。恢复不自动重设默认。已删除版本不能确认、绑定或用于新配图；任务在删除前已入队则继续使用其冻结快照。尚未入队但明确选择被删版本的保存周期如实失败，不能悄悄替换人物。

每个版本提供“删除版本”，确认说明默认设置及历史保留。默认隐藏已删除版本，通过“已删除版本”查看并恢复；不提供永久清空入口。形象版本草稿、资料草稿及账号隔离继续有效。

CLI/MCP 沿用图库独立私有权限边界，此次不向旧 workspace token 开放照片及版本生命周期操作；未来需新增私有形象 scope 后同步终端命令和权限测试。

验收包括默认版本删除、候选/确认版本恢复、历史及冻结引用、匿名/跨拥有者拒绝、CAS冲突、版本号递增、取消删除以及正在编辑的草稿保留。
