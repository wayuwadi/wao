# 小记三栏阅读

按用户确认的三栏交互 Demo 实施，扩展 `notes-unified-reader.md`，修订其中正文内展示图片、全屏隐藏目录的展示行为。继续遵循 ADR-198 的 JSON 事实源和既有只读原文契约。

- 桌面阅读器左侧为本次筛选的小记目录，中间为文字正文，右侧为当前文章的图片清单。侧栏速览与全屏阅读均保留三栏；全屏正文限制阅读宽度。
- 图片节点在正文原位置显示轻量图号引用与原有说明，不在正文加载图片。按出现顺序逐个编号，相同 URL 的两处图片仍各有独立图号；列表、引用、表格等嵌套位置也保留。
- 点击引用仅定位、突出并聚焦右侧对应图片；“返回正文”定位并聚焦原引用。点击右侧图片或全屏按钮复用既有原图查看器，关闭/Esc 恢复入口焦点。继续支持键盘访问和焦点限制。
- 图号仅为只读 NodeView，不改文档节点、尺寸、JSON、Markdown 或版本，不发起保存、上传或 AI。复制正文仍复制原文 Markdown，双击文字进入编辑仍沿用原文档光标位置。
- 查看原文、切换本次润色前/最初记录时，图号与清单从实际选中的原文同步产生；加载或失败时清空旧来源图片，正文保留加载、错误、重试与缺失状态。
- 换篇重置当前图片突出状态，保持既有逐篇正文滚动记录与固定阅读顺序。无图文章有明确空态；预览加载失败保留查看原图入口。
- 650px 及以下目录使用既有目录入口，正文与图片清单上下分区，正文仍只包含引用。图片完整显示，不裁切；长说明与标题不横向溢出。

仅浏览器展示变更，无服务、API、持久化结构、权限或部署行为变化，不新增 CLI/MCP 能力。验收记录见 `docs/validation/notes-reading-columns-2026-10-04.md`。
