# Phase 1：WAO Skill 市场

## 用户结果

1. 游客可在 `/skills` 搜索、筛选、查看、分享和下载已通过审核的 Skill；公开详情页可安全渲染概述、按不可变版本浏览文件与历史，并复制带版本下载地址和 SHA-256 的 AI 安装提示词。
2. WAO 成员首次发布时建立独立公开身份；handle 不可变，昵称可修改，公开页不暴露内部成员 id 和角色。
3. 上传支持 ZIP 和浏览器文件夹，顶层必须有 `SKILL.md`；作者先选择包，系统只读预检并用 frontmatter 的 `name`、`description` 自动预填发布信息，作者确认分类、授权、版本和平台后才保存草稿并提交审核。
4. 管理员查看文件树、`SKILL.md`、校验和扫描结果后通过或驳回。驳回必须填原因。
5. 新版本未通过时旧版继续公开；已发布 Skill 只能下架，不破坏版本与审核记录。
6. 项目设置可从市场显式启用最多十个当前公开的 Codex Skill；绑定固定审核版本，不自动跟随新版。
7. 成功 AI Run 可把真实验收中形成的新方法写成候选包，由 Runner 上传为发起人的市场草稿；同名候选递增补丁版本，仍需作者确认授权并走人工审核。

## 包与安全

- 包大小不超过 10 MiB，解压后不超过 20 MiB / 200 个文件；可去掉一层共同根目录。
- 拒绝绝对路径、`..`、符号链接、加密 ZIP、重复路径、超限解压和可执行二进制；上传内容永不在服务器执行。
- 公开文件预览只读取已审核版本中的单个文件；UTF-8 文本最大预览 512 KiB，二进制、非 UTF-8 或超大文件只提示下载 ZIP，不在服务端执行或转换。
- `SKILL.md` YAML frontmatter 至少含 `name` 与 `description`。系统展示结构兼容平台与作者已测平台。
- 预检不持久化包；正式创建草稿时必须再次扫描，私钥、Token、Access Key 或疑似密码配置命中后直接拒绝，不能把含敏感信息的包保存为草稿。
- 授权必选 `MIT`、`Apache-2.0`、`GPL-3.0`、`CC-BY-4.0` 或 `ALL-RIGHTS-RESERVED`。
- 发布包保存 SHA-256；下载永返回不可变的审核版本。

## 边界

一期不导入第三方市场，不做付费、评论、第三方作者认领，也不允许公共下载触发执行。项目 Skill 只有管理员
显式绑定后才由 Runner 装配；服务端仍不执行上传内容。AI 候选只能创建未确认授权的草稿，不能自动发布或覆盖
已审核版本。

## AI Run 装配与验收

- 入队时把项目绑定固化到运行快照，至少包含 Skill、版本、SHA-256 和兼容平台；配置变化只影响新运行。
- Runner 通过本次运行专用接口下载包，再校验 10 MiB 压缩上限、20 MiB 解压上限、200 文件、SHA-256、路径和符号链接，装配到该 Run 独立的 `CODEX_HOME/skills`。
- 当前只支持 Codex；带 Skill 的运行改用 Claude 或 Qoder 时失败关闭并记录“不兼容”，不能静默忽略。
- 运行详情展示固定版本和实际加载、失败、不兼容或未回传状态。旧 Runner 不回传时明确显示未知。
- AI 仅在工作已成功交付且方法可跨任务复用时生成最多三个候选目录；Runner 上传后复用市场扫描，作者未建立公开身份、包不安全或格式错误时明确失败，不伪造草稿。
