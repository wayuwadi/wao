# 配图完成状态以当前正文为准

保存信号中的 `cover_url` 只是历史关联，不证明当前正文仍有配图。新格式文档优先检查真实图片节点；没有结构化文档时检查 Markdown 图片引用，普通文字或链接中的地址不算图片。

读取状态时，历史“已有配图”或“配图已采用”若已不在正文中，显示“原自动配图已移除，可重新配图”，不再计作四连已完成。读取本身不提交 AI。保存时清除失效关联；正文未改变时不自动补回用户删除的配图，用户可通过单项或长按四连重新生成。下一次真实正文更新也可按既有设置配图。润色写回不得把已移除的旧图重新插回。

内部状态修正沿用既有阶段接口，未新增 CLI/MCP 命令或权限；既有通用文档更新能力保持原权限。
