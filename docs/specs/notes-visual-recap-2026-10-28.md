# 小记图文整理

用户希望已有文字获得微信 AI 录音笔式的内容组织与图文排版，视觉表达是核心验收项。

入口：本人小记的更多菜单，以及阅读工具栏「图文整理」。先保存编辑再生成；不会改写正文、标题或标签。复用私人 AI 执行队列与成员的小记模型配置，生成完整静态 HTML/CSS。模型按内容选择流程、分支、时间线、对比或卡片，短文不强制配图。图示附逐字来源依据，保留否定、条件和不确定性。

结果独立持久化，保存来源版本与正文快照。页面重开可读，生成中可关闭，失败可重试；同篇生成中的请求不重复入队。来源正文变化时提示过期。每次读取验证本人所有权、未归档与未删除状态。V196 的文档、成员外键在物理删除来源或成员时级联清理原文快照与图文结果。没有自动分享或向 MCP/CLI 增权。

浏览器用 DOMPurify 白名单清理，空 sandbox iframe 隔离，CSP 禁止脚本、外部资源、表单和 base URL，去除链接与嵌入元素。统一图文主题变量、320px 自适应与明暗阅读色板；模板可自主布局，但不能执行交互代码。当前只支持 details 展开依据，不承诺任意交互原型。

验收：真实生成应保持原意、有清晰阅读层级、合适图示与来源依据；桌面/390/320px 和明暗色均检查。合成样例仅验证渲染，不作为真实模型生成质量或持久化验收。[验证记录](../validation/notes-visual-recap-2026-10-28.md)分别标明真实模型生成、隔离测试与尚未完成的线上链路。
