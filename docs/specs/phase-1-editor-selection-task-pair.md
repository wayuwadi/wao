# 规格：编辑器选区待办与润色绑定

扩展文档划词操作至小记及后续通用编辑区域。

- 开启编辑器的润色能力时，同时显示“添加到待办”，不再要求页面单独开待办开关。只读和空选区不显示操作；已有 taskable 调用兼容同一组选区动作。
- 编辑器提供默认待办行为，页面可以传入来源信息或保留既有 add-task 扩展；小记和知识库共用选区转待办草稿的逻辑。
- 已保存文档或小记携带真实来源文档、标题和知识库项目。未保存小记也能收集待办，只复制选区，不强制保存小记、不伪造文档链接或关联；无项目时由用户选择。
- 标题取选区前 200 字，描述保留完整原文；草稿按成员、来源与选区隔离，同一选区重开恢复。原编辑器正文和小记草稿不变。
- 全屏小记打开待办表单时退出全屏，正文实例保留，确保弹窗可见。最终创建、失败重试、项目选择和关联文档沿用现有任务表单。

验收：只开润色即同时出现待办按钮；新小记和已有小记划词打开表单；来源与项目正确，未保存内容无失效链接；关闭表单后原文与草稿仍在；全屏可打开；确认创建后待办能在目标项目找到。
