# 手机 Web 小记入口与输入

依据 ADR-324，用户从 Safari 登录、分享菜单添加到主屏幕后，能够快速进入小记，输入、保存和继续阅读。沿用 `mobile-content-first-shell.md` 的完整导航、权限、草稿与桌面行为。

- manifest 的稳定 id 和 scope 保持 `/`；启动 `/notes`，首个快捷入口为小记。旧安装的启动地址由系统更新 manifest 决定；必要时从小记页重新添加，不删除网站数据。
- 不自动抢焦点或在启动时弹键盘。未登录时走正常登录与回跳。
- 手机小记新建区单列、正文至少 16px；全屏按钮、保存与主要列表操作可触控。仅普通新建区压缩初始空白，长正文仍可滚动，全屏与卡片编辑不裁剪内容。
- 760px 及以下隐藏桌面样式滚动条及预留槽，页面、编辑区和快捷标签仍支持滑动、滚轮与键盘浏览。空编辑器的正文由 flex 填满内容区，不继承外层包含边框的最小高度，避免空白也产生纵向滚动；长内容仍保留滚动。
- 手机小记页的悬浮新建打开既有快速小记，使用独立的 floating 草稿，不覆盖页面记录区输入；其他页面保留新建任务。
- VisualViewport 在未缩放的窄屏下用于全屏编辑区域。编辑焦点且可见高度减少超过 120px 时隐藏底部导航和悬浮新建；失焦或键盘收起恢复，不卸载编辑器。没有 VisualViewport 时回退至现有动态视口布局。
- 全屏编辑避让顶部、底部与横屏左右安全区。已有保存中、草稿恢复、失败重试与刷新前保存屏障保持有效；不引入服务工作线程或自动强刷。
- “更多”提供折叠的 Safari 添加到主屏幕说明，主屏幕独立模式隐藏说明。若仍为桌面布局，提示 Safari 请求移动网站；不根据机型猜测数据或绕过浏览器偏好。
- 暂停原生 main push 自动构建，保留历史工程。

## 验收边界

在本地浏览器连接既有业务服务，检查 320 / 390 / 760 / 1024px 导航与正文、菜单往返及未保存输入，创建一条明确标识的验收小记并核对持久化。VisualViewport 事件、焦点、缩放与清理用回归测试验证。实体 iPhone 的 Safari、主屏幕启动、刘海与软键盘由用户真机验收，不将桌面模拟写成真机通过。
