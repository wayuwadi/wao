# 登录页：想法舞台与交互音效

用户确认 2026-09-29 的 WOW 舞台 Demo 后接入浏览器登录页。延续统一账号规格；微信登录按 ADR-295 已退役，本次不恢复。

- 黑色网格背景、亮粉主按钮、双行标题“把想法，变成 WOW.”与五个原创 SVG 角色；角色支持鼠标和键盘互动，遵守减少动态效果偏好。
- 登录、创建账号打开原生模态框，首帧居中、限制屏幕内高度并允许滚动，关闭后焦点回到入口。飞书容器内继续自动免登，失败显示真实错误与可用入口。
- 飞书二维码按需加载；关闭、切换和卸载使旧请求失效并清理消息监听。加载失败可重试或授权登录；授权请求失败显示可读提示。
- 邮箱登录和注册使用现有真实接口与重定向逻辑；忙碌时禁止重复提交、切换与关闭，失败保留输入供重试。切换/关闭弹窗保留本页输入，不将密码写入浏览器存储，成功清空密码。
- 音效默认关闭，用户主动开启后才创建 Web Audio 上下文；按钮、角色、邮箱成功与错误对应轻量合成音，不下载参考网站素材。静音立即暂停，离开页面释放音频；音频不可用不阻断认证。
- 页面保留真实站点备案信息；没有演示二维码、演示账号或模拟登录成功。

验收：桌面及 390px 手机视口；入口、焦点、关闭重开草稿、飞书失败与重试、邮箱提交失败/成功回跳、快速切换期间迟到二维码、静音及卸载释放。
