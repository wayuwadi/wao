# Phase 1：右上角通知中心

对应任务：`t1787902991274`。决策见
[ADR-153](../adr/153-grounded-notification-center.md)。

## 用户链路

1. 已登录成员点击应用右上角铃铛，在当前位置直接打开通知抽屉；再次点击、点遮罩、按 Escape 或完成跳转后关闭。
2. 铃铛用红点和数量提示最近未读事件；打开并成功读取后自动标记当前成员已读，失败时保留未读状态并提供重试。
3. “最新动态”按真实发生时间倒序展示任务创建、任务完成、AI Run 终态和成功登录；任务与 AI Run 可回到对应任务。
4. “成员使用”展示所有真实成员最近 7 天、30 天成功登录次数与最后登录时间。发布前没有历史流水时明确显示
   “尚未记录”，不把空记录解释成从未使用。
5. “查看统计”收口 AI 使用统计、系统报告和请求监控三个已有页面入口，点击后沿用 WAO 页签与路由。

## 数据与隐私

- `account_login_event` 只保存账号、成员、登录方式与成功时间；失败登录不记录，也不保存 IP、设备、浏览器、
  邮箱、外部 open id 或凭据。
- 邮箱登录、邮箱注册、首次成员认领、非绑定场景的飞书/微信登录计入频率；已登录状态下绑定新身份不计入。
- 动态直接读取 `task.created_at`、`task.completed_at`、`ai_task_run.finished_at` 与登录事件。没有可靠操作者字段的
  任务完成事件不显示操作者，不从任务创建人推断。
- 成员已读水位使用 `member_preference.notification-center-read-at`，成员之间隔离。

## 状态与验收

- 抽屉覆盖首次加载、刷新中、失败重试、无动态、登录统计为空和标记已读失败状态；一次刷新失败不清空已显示数据。
- 后端测试覆盖事件排序、首次 7 天未读边界、成员已读隔离、登录统计和绑定身份不计数；Migration 测试约束表、
  索引和隐私字段边界。
- 前端测试覆盖开关抽屉、真实数据渲染、自动已读、失败重试、入口跳转、Escape 与窄屏全宽布局。
