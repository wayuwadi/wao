# 首页额度与天气速览收口

本规格调整 `home-daily-workspace.md` 的顶部信息布局，不改变额度或天气数据来源。

- 额度从首页独立整行移到日期右侧、天气左侧，只常显真实 Codex 周剩余百分比。点击小入口展开原有周额度、重置卡及 Pro 权益，保留草稿、加载、过期快照、失败重试和低额度提醒；关闭后不卸载权益编辑器。
- 天气首页速览只显示成员已保存城市的短名称、当天真实天气文字和对应图标，例如「🌧️ 武汉 · 有雨」。日历和节奏页的隐藏开关只控制各自页面，不隐藏首页天气。未知天气不得猜测为晴或雨。
- 天气设置仍可进入；未设置城市、加载中、读取失败、预报失败或过期时只显示简短状态和对应重试入口。城市的完整名称仍保留在设置中。
- 宽屏额度与天气并排，窄屏允许换行；额度详情不覆盖页面操作，支持按钮、外部点击和 Esc 关闭。

无新接口、迁移或部署配置。验收覆盖真实额度与权益、天气关闭日历显示后的首页速览、雨天图标、缺失和失败状态、详情展开及宽窄屏。
