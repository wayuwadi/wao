# 规格：文档与小记高级编辑器

## 用户链路

- 知识库文档打开即写，顶部提供吸附常用工具栏；选中文字出现格式浮层；输入 `/` 可搜索并用键盘插入内容块。小记保留紧凑入口，支持常用格式、列表、链接、图片和轻量斜杠菜单，保存并打开后获得完整能力。
- 基础排版包括 H1–H4、粗体、斜体、下划线、删除线、行内代码、固定文字/高亮色、对齐、列表、引用、分隔线和清除格式。
- 内容块包括信息/成功/警告/危险提示、折叠块、二/三分栏、可编辑表格、带语言高亮的代码、KaTeX 行内/块公式与 Mermaid 流程图/时序图/思维导图。窄屏分栏纵向排列，表格横向滚动。
- 图片支持粘贴、拖入、上传、比例/像素缩放、替代文字、标题、对齐和原图查看；附件复用文件库，登录态音视频可内嵌播放。外部 HTTPS 链接只显示安全卡片，不抓取远端页面或运行 iframe。
- 可引用或新建个人 Excalidraw 画板，文档保存稳定画板 ID 和跳转地址。顶层块有稳定 ID、拖拽手柄、复制和删除操作。
- 文档支持 Ctrl/⌘+F 查找替换；中文输入法合成期间不触发斜杠菜单选择。

## 保存、兼容与失败

- 高级正文结构按 ADR-198 保存；Markdown 投影继续供分享、AI、检索和旧客户端使用。模板创建、编辑和复制保留同一完整结构。
- 自动保存停顿 600ms 后写入；每次编辑先保存 IndexedDB 草稿。页面隐藏、离开或卸载前尝试写透；失败明确显示重试，已有文字继续可编辑。
- `expectedRev` 不一致时服务器正文保持不变，本机草稿保持完整，页面提供“载入服务器版”和“本机草稿另存副本”。
- 有序列表兼容编辑器默认的 `attrs.type = null`，以及 `1/a/A/i/I` 编号样式；仅有序列表允许该属性，其他节点、文字样式与未知属性仍按白名单校验。保存被拒绝时页面保留服务端的具体原因，重试成功后清除失败提示。
- 公开分享用净化后的只读 JSON 展示高级结构；音视频降级为确认下载卡片；Markdown 地址继续返回可读投影。
- 非文档场景的任务描述、聊天输入等沿用紧凑 Markdown 编辑器，不显示高级工具栏。

## 验收

- 完成“输入 → 自动保存 → 刷新 → 模板复制 → 公开分享 → Markdown 直读”，结构、顺序、图片尺寸和安全属性保持。
- 覆盖所有节点/标记、表格增删合并、未知代码语言、非法公式/Mermaid、危险 URL、超限/畸形 JSON和图片/附件上传失败。
- 两窗口制造版本冲突，确认服务器不被覆盖，且两种冲突处理均可完成。
- 小记提交时切换只读不得破坏编辑器浮层；失败后恢复可编辑且正文不丢，保存并打开成功后必须完整移除弹窗和遮罩。
- 草稿恢复路径中的 Vue 响应式正文须能再次写入 IndexedDB；连接中断后刷新页面，内容完整恢复，恢复连接保存后不残留草稿失败提示。
- 切换、新建或另存文档时同步地址中的文档 ID，刷新仍打开当前文档；兼容草稿也须检查版本冲突，并在连接未就绪时提供保存重试。
- 真实创建含表格、代码、公式、流程图、图片、附件、分栏与画板的文档，并验证刷新、小记保存并打开和手机窄屏。
- 手机窄屏下目录置于正文上方并限制高度，目录和正文独立滚动，正文不能被固定宽度目录挤出视口。

## 边界

- 不开放任意字体、字号、行距、原始 HTML、第三方 iframe或服务端抓取外部网页。
- 不包含字符级多人协同、划词评论、@通知、修订模式和历史版本。
