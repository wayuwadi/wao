# 小记标签右键管理

补充常用标签轻量快选规格。输入框普通、全屏和卡片编辑中的标签支持右键、Shift+F10 或菜单键打开「修改标签 / 删除标签」菜单，左键继续选择或移除当前小记的标签。

- 复用共享标签字典的现有合并、删除接口。修改名称同步已关联小记，目标名称已存在时提示合并并去重；删除仅移除标签及其关联，保留文章。
- 修改和删除在锚定标签的浮层中确认，明确展示影响范围。取消、Esc、点击外部关闭；首次渲染先测量再显示，长标签及窄屏不溢出。
- 保存中禁用重复操作，失败保留名称和错误，可重试；成功刷新字典和已保存小记，不替换正在输入的正文。
- 当前成员的已缓存草稿及已打开编辑器同步标签名称或移除标签，保留正文、标题、页签身份和原有版本条件；同源其他页签接收变更通知，防止旧标签随草稿保存重新出现。
- 无新增 Web API、数据结构、CLI 或 MCP 能力；右键菜单只让既有浏览器标签管理更直接，不扩大连接权限。
