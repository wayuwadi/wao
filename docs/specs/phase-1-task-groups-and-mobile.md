# 规格：项目分组视图与移动端任务录入

对应任务：`t1785200670094`（系统优化功能）。本规格覆盖分组视图、首页理念表达、移动端录入与
子任务详情、飞书子任务通知与活动时间线四件事的验收口径。

## 1. 分组视图

### 为什么

一个项目里常常同时压着好几个 domain 的事（证件、装修、上线前……）。列表视图按时间铺开、
看板按状态切分，两个都答不上「这一摊事还剩多少」。分组按人自己的说法切，组内只关心做没做完。

### 规则

- 项目任务区新增第三个视图「分组」，与列表 / 看板同级，选择记在 `wao-task-view-v1`，URL 上的
  `?view=group` 优先。
- 分组是项目级的自定义列表，存在 `project.detail_json.taskGroups`，**最多 6 个**（服务端
  `ProjectService.MAX_TASK_GROUPS` 也拦一道），名称由用户自己写，最长 20 字。
- 一个项目还没建过分组时，前端给一个 id 为 `tg-default`、名为「未分组」的兜底分组。**兜底分组
  不落库**：用户改名或加第二个分组时才连它一起写透。
- 任务归属存在 `task.detail_json.groupId`。为空、或指向已删除的分组时，一律显示在**第一个分组**里
  —— 任务不会因为分组变动而从视图里消失。
- 分组内的任务行**只有完成态和标题**，不再堆状态 / 优先级 / 负责人 / 截止日期。已完成的沉到组内
  底部并默认收起。
- 每个分组头上有「+」：就地展开一行输入框，回车即建，新任务直接带上这个分组（`POST /api/tasks`
  的 `groupId`）。连着敲可以一次录好几条。
- 删除分组不删任务：里面的任务落回第一个分组。最后一个分组不给删，否则没地方放任务。
- 换组方式：桌面上把任务卡拖到目标分组；手机上在任务详情的「分组」属性里选。

### 验收

- 新项目进分组视图，能看到「未分组」和项目里的全部任务，计数为「未完成 / 全部」。
- 点分组名可改名，刷新后仍在；建到第 6 个后「新建分组」消失并给出说明。
- 分组头「+」建出的任务，关掉再进来仍在同一个分组里。
- 删掉一个分组后，原来在里面的任务出现在第一个分组，一条都不少。

## 2. 首页 slogan

首页 hero 第一行是核心理念「娃有多大胆，AI 有多大产」，紧跟一句把它说清楚的副标题（想法有多大、
产出就有多大；提出来之后拆解、执行、交付交给 AI）。原来的「现在有 N 个任务在跑」降为理念下方的
状态胶囊，信息不丢。

## 3. 移动端任务录入

在外面只能靠手机操作，录入链路必须一次到位：

- **常驻悬浮新建按钮**：顶栏的新建图标在屏幕最上沿，单手够不着；手机上在底部导航之上加一个
  拇指区的圆形「+」，点开即新建任务。
- **新建任务弹窗改成底部整页表单**：居中弹窗被键盘顶得只剩一条缝，标题框还常被推出屏幕。改成贴底
  升起、最高 92dvh，标题框始终在键盘正上方，创建 / 取消固定在底部（含 `safe-area-inset-bottom`）。
- **打开即聚焦标题**：录任务的第一件事一定是敲标题；已有草稿标题时不抢焦点，免得顶掉恢复的内容。
- **触控目标放大**：标题输入 46px 且字号 16px（iOS 不自动放大页面的下限），选项按钮 34px，
  底部按钮 44px。
- **分组视图行内快速添加**：不进弹窗也能连着录任务，见第 1 节。

## 4. 手机上的子任务详情

原来点子任务，详情排在正文下面，手机窗口小，得往下滑一段才找得到，滑到了也认不出看的是哪一条。

- 手机宽度（`max-width: 760px`，见 `composables/viewport.ts`）下，点子任务盖出一整页：固定顶栏写
  「子任务 i / n」和所属任务名，右侧一个「标记完成」，返回键退回任务。
- 桌面维持原样（右侧属性栏切换成子任务详情）。

## 5. 飞书子任务通知

娃哥往娃弟建的任务里加子任务时，卡片必须回答两个问题：**谁**加的、加在**谁的**任务下。

- 标题带上操作人：「娃哥新增了 2 条子任务」。
- 字段里给出「添加人」，操作人与任务创建人不是同一个人时再给出「任务创建人」。
- 正文开头 @ 该知道这件事的人：任务**创建人 + 负责人**，去掉操作人自己；没绑飞书的人跳过。

## 6. 活动时间线的时间与主语

- 活动正文不再带主语（存「创建了任务」而不是「你创建了任务」），操作人记在 `activity.by` 里，
  主语在展示时按「看的人是谁」现算：自己干的写「你」，别人干的写对方名字。
- 活动时间写真实时刻（ISO 8601 带 +08:00），不再写死「刚刚」——否则过多久都显示「刚刚」。
- 历史数据没有 `by`、正文里已经带着「你」，原样展示，不去猜是谁干的。
