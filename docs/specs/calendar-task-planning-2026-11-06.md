# 日历任务排期

用户授权完整对齐任务管理体验。本轮在已有年/月/周/日视图与按天移动上补齐任务与日历并列操作。

- 日历左侧提供可收起的任务排期面板，默认未安排执行时间；任务有截止日期但没有执行安排仍属于未排期。可切换全部未完成任务，并按清单、标题搜索。一次展示 50 项，继续展示不会丢弃其余任务。
- 面板与日历使用当前选择成员的同一授权任务集，不展示笔记与已放弃任务。账号变化后切回当前成员，清除本窗口的编辑、拖动与撤销上下文。
- 拖动到月历日期修改执行日，保留已有时段持续长度；拖到日/周视图时间格以 15 分钟为落点，未排期任务默认一小时，已有时段保留持续长度。跨日续段保持与原开始的相对偏移。
- “安排”可在键盘和触屏精确选择全天、开始与结束时间，结束可跨日；可取消排期。执行安排的写入均不修改截止日期。日期与时间按上海时间的本地时钟字符串保存，不随浏览器时区隐式转换。
- 提交前复核任务所属范围、已完成状态、编辑版本、原执行快照以及既有保存/冲突状态。失败保留任务草稿，页面顶部提供既有重试/打开任务入口。成功提供带版本检查的撤销；后续编辑后不再覆盖撤销。
- 排期表单草稿按账号、当前日历成员、任务隔离。收到更新时保留输入并阻止覆盖，明确重新读取后再保存。
- 重叠时段按列布局，保持每个任务可点击；全天和跨日续段沿用日历文字标识。日历搜索恢复当前日期范围内的任务。
- 当前日期、年/月/周/日视图、排期面板开合及滚动位置按账号保留，返回日历无需重新定位。
- 窄屏排期面板与日历上下排列；触屏无需拖动，也可通过“安排”完成同样操作。控件使用 WaoButton、WaoField 与现有语义 token。

验证：`CalendarView.spec.ts`、`taskSchedule.spec.ts`、`calendarPlanning.spec.ts`、`CalendarTaskPlanner.spec.ts`。包含截止独立、跨年/午夜/续段、并发冲突、失败输入恢复、账号切换、时段调整与撤销、重叠布局、列表渐进加载。
