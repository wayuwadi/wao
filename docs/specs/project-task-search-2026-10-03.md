# 项目内关键词查找

沿用 ADR-303 下线边界和项目表格默认入口。在任务页提供紧凑查找框，限定当前已授权项目的已加载任务，匹配编号（含 # 前缀）、标题、正文及内嵌子项编号、标题、正文。大小写不敏感，按输入的完整关键词做字面包含匹配，不调用模型。

默认包含已收尾任务，查找区独立开关可仅看未收尾；收尾复用项目计数判定（主任务完成且所有内嵌子项完成）。此开关不修改普通视图的完成显示偏好。负责人和创建人继续按现有组合规则过滤。先在项目全集查找，再计算筛选排除数量，区分没有命中、其他筛选排除、完成范围排除、加载中和加载失败。失败不能当作空结果。

结果按任务分组，显示命中字段和有限长度的上下文；内嵌子项保留父级路径，打开沿用稳定子项 id 定位。独立下级任务显示同项目祖先标题，不读取其他项目内容。普通视图保持挂载，清除查找恢复原排序、筛选和展开状态，查找不写任务、个人顺序或布局。

当前页面本已加载可访问任务全文，先复用客户端数据，不新增接口、权限、CLI 或 MCP 能力。记录授权环境真实规模，只据实判断该环境；后续出现大型项目的实际延迟证据再考虑查询架构。结果分页显示，防止大量命中一次生成全部 DOM。输入使用 Vue 原生 v-model 的组合输入支持，长文本换行，窄屏查找独占一行。
