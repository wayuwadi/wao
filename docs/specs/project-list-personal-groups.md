# 项目列表个人分组与排序

## 目标与范围

项目列表支持按登录成员自定义分组和项目顺序。右键菜单只在项目画布、项目卡片和分组标题内拦截浏览器原生菜单；其他页面区域保留浏览器默认行为。

这是项目列表的个人展示布局，不改变共享项目的领域、负责人、可见范围或项目数据。项目详情页、任务视图及其他成员的列表布局不受影响。

## 交互

- 初次使用时按现有人生领域创建同名默认分组，并将项目放入对应领域；无领域时使用“未分组”。已有成员布局优先保留，新增领域和项目自动补入。
- 画布右键提供新建项目、新建分组、刷新项目列表；项目卡片右键另含打开项目、复制链接和移动到分组；分组标题右键另含重命名及折叠/展开。
- 从分组菜单新建项目，创建成功后仅将其加入当前成员选中的列表分组，项目实际领域仍由项目表单决定。
- 项目卡片可在组内重排或拖入其他组；分组标题可上下拖动调整顺序。右键移动分组和键盘操作仍可完成主要管理动作。
- 切换“不分组”后，卡片按单一列表展示。手动排序在该视图中只调整全局个人顺序，不改变卡片所属分组；切回分组视图时，各组保留对应的相对顺序。
- 支持按截止日期、进度、名称和手动排序；筛选与分页不丢弃未显示项目的顺序。

## 持久化与恢复

- 复用现有成员偏好接口 `GET/PUT /api/preferences/project-layout-v1:overview`，由服务端 `CurrentMember` 隔离。偏好包括分组顺序、名称、颜色、项目归属、项目顺序、折叠状态、分组模式和排序模式。
- 偏好最大 60,000 字符；其他偏好的 4,000 字符限制保持不变。不新增 HTTP 业务端点、数据库字段或 Flyway migration。
- 页面显示读取、保存、失败和未保存状态。写入失败时保留成员本机草稿并提供重试；在途连续编辑串行保存最新布局；成员切换时忽略旧请求迟到结果。
- 用户项目和领域列表加载后才启用布局操作。刷新项目数据时，新项目按来源领域加入布局，已不存在项目的引用会清理。

## CLI 与 MCP 边界

列表分组是浏览器 UI 的个人偏好，不是可独立执行业务的项目操作。CLI 和工作区 MCP 不暴露通用成员偏好读写，也不新增项目分组命令或工具；不得借本功能扩大旧设备令牌权限。若未来提出脚本化布局需求，再单独设计字段白名单、并发冲突和审计边界。

## 验收

- 验证默认初始化、持久化读取、重载恢复、组内/跨组移动、未分组手动排序、连续保存、失败重试、删除项目清理及成员切换隔离。
- 验证项目创建表单的领域数据不受个人列表分组影响；项目画布右键使用应用菜单，画布外保留浏览器菜单。
- 类型检查、相关前端单元测试、后端偏好额度测试和生产构建通过。
