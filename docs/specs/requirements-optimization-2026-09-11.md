# 需求优化收集：持久化、聊天与桌面体验

来源：https://wao.wayuwa.cn/api/share/tasks/t17890359607439.md?openOnly=true

## 可验证结果

- 任务写入始终等待真实服务器确认；初始化、重新加载、轮询不移除待保存任务，刷新恢复失败新任务并沿用原 ID 重试。新任务与编辑复用串行队列；草稿按成员隔离，旧缓存只迁移可确认创建人的记录。搜索覆盖标题、正文和子任务，不受项目看板筛选影响；未查到的历史内容不伪造恢复。
- 项目名称与任务常用属性保持可见；图标、领域、目标、执行配置及任务辅助属性可展开，折叠不删除数据。
- 共享聊天本人发送的 WAO 消息可修改正文，保留创建时间、引用、附件和已读；PATCH /api/chat/messages/{id} 接收 content、expectedContent，以原正文条件更新，冲突返回 409，禁止修改其他人的消息。编辑失败和收起保留草稿，轮询不覆盖正在编辑的内容。
- 任务、文档、小记、文件分享均追加到聊天草稿，由用户发送；任务链接在原工作区打开抽屉，文档和文件进入真实分享页，不修改访问权限。
- 聊天气泡操作位于消息内部，长文、代码和图片不撑宽聊天框。手机底部固定首页、聊天、待办、小记入口；未读提示持续到实际查看。
- Windows 顶栏和左栏统一表面颜色、紧凑菜单；聊天固定在侧栏首位，默认公共组显示为协作；保留用户菜单排序、自定义分组和改名。主题图标反映实际明暗状态，客户端同步主题；更新按钮有红点。
- 小记标题压成一行，减少上下留白。首页权益定时读取，自动卡片来自真实官方账号快照；账号不能唯一识别时列出账号，不猜测归属，手工日期草稿不被刷新覆盖。
- 透明桌宠页不挂载通用版本更新弹窗，悬浮显示关闭按钮，托盘切换显示/隐藏。

## 验收边界

逐项验证真实页面操作、刷新和恢复。桌面安装包独立发布；Windows 实机安装、托盘与升级需要真实客户端证据，不能用 Web 构建代替。系统级测试、发布证据记录于提交和 PR；功能报告单独生成。
