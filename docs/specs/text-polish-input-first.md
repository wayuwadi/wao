# 润色以原文为起点

补充独立润色工作台规格，落实体验审计 B10。

- 原文、开始润色与结果先于方法设置展示；沿用服务端当前成员的既有方法，不替换个人提示词或模型路由。
- 方法默认收起，原生可键盘展开的“润色方法”提供用途、语气示例及后续生效范围说明；用户可直接粘贴原文开始。
- 恢复未保存方法或保存失败时展开设置；即使用户手动收起，主操作旁也持续说明会先保存方法，并能定位到修改处。
- 原文、结果、历史的保存、恢复、复制与失败重试行为保持不变。本文案和布局不改变提示词持久化或 AI 执行语义。

验收覆盖默认输入优先、无需展开即可润色、未保存方法恢复展开、保存失败展开、修改处定位以及真实生成与历史读回。

本地前端使用已授权登录的真实线上润色 API 完成生成；生成时没有展开或修改方法。另验证本机临时方法刷新恢复与自动展开，并将其恢复为原有值，未向服务端保存修改。账号草稿及旧请求保护回归继续覆盖。
