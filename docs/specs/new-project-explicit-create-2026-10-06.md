# 新建项目显式创建与草稿

用户本轮确认优化关闭行为。本规格仅取代 `page-layout-refinements-2026-09-20.md` 中新建项目的关闭即创建约定；其他编辑窗口仍沿用原规则。

- 创建按钮或项目名称输入框回车才提交。关闭按钮、遮罩、Esc 只保留草稿并关闭，不创建项目。
- 草稿在当前浏览器页签按账号和成员隔离，关闭重开和刷新恢复名称、目标、领域与可见范围；草稿不改变服务器数据。不同页签可独立填写。
- 本机草稿写入失败明确提示并阻止有内容的表单关闭。损坏草稿保留原副本，提示不能自动恢复；重新输入后可保存为新草稿。
- 保存中禁止编辑、关闭和重复提交；失败保留输入并支持重试。成员切换后不将原成员保存结果导航到新成员界面。
- 创建成功清理对应草稿，保持现有分组归属、成功提示和项目详情导航。

无 API、数据库、CLI/MCP 权限变更。验证关闭不创建、草稿恢复、成员隔离、存储失败、创建失败重试与成功清理。
