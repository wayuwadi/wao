# WAO 单色品牌资源路径修复

补充 `wao-brand-refinement-2026-10-06.md`：不可变静态发布的版本目录只开放构建 assets，公共品牌 SVG 仍从主站 `/brand/` 获取。CSS 中直接写公共 URL 会被 Vite 的发布 base 改写，使呼吸页的单色标识与背景纹样消失。

单色标识及纹样共用运行时主站 URL，通过组件样式和 CSS 变量传递，构建后仍指向 `/brand/wao-soft-loop-mono-v4.svg`。深浅模式保持当前文字色，透明穿插及既有尺寸、低对比纹样保持。

验收使用带精确 SHA 的生产构建，检查生成 CSS 不再引用版本目录的品牌 URL；浏览器验证单色图形及纹样实际加载。无业务、接口或部署拓扑变化。
