# WAO 应用壳与首页品牌表达

2026-10-04，用户对比三版 Demo 后确认组合方案。本规格补充 `wao-soft-loop-brand-identity.md` 与 `navigation-light-single-row.md`，只维护浏览器版本。

## 用户结果

- 桌面侧栏折叠时，顶部菜单与页签前显示柔环 W 图形和 WAO 字标；侧栏展开时只在侧栏左上角显示这组品牌，不在顶栏重复。
- 品牌可点击回到首页，侧栏折叠按钮、菜单停靠区、页签滚动与拖拽保留原行为。
- 应用各页面的页脚右下角始终保留柔环 W、WAO 和轻量 Life OS 签名，不随侧栏状态消失。备案与下载信息继续显示；窄屏允许信息换行，签名避让已有手机操作与安全区。
- 首页在「一呼一吸」旁显示同一组图形与字标，保留留白、信息卡和四个伙伴。左下角头像继续表示真实登录成员。
- 全局「新建任务」默认无底色，与小记、动态保持相近分量；悬停、焦点和编辑锁定行为保持可用。
- 手机沿用内容优先布局，不新增常驻顶栏或侧栏；打开完整菜单时左上角显示品牌。

## 边界与验收

复用唯一矢量母版与 WaoLogo 组件，使用既有主题变量。不修改业务 API、数据库、权限、成员头像或独立客户端发布，因此无需扩展 MCP / CLI。

验收覆盖本地前端连接既有业务服务：首页、项目页、展开 / 折叠、品牌返回首页、任务入口与关闭、手机完整菜单、浅色 / 深色和窄屏。运行受影响导航与首页回归、类型检查和生产构建；合并不等于公网已上线。
