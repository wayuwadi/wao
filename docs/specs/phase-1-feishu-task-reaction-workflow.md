# Phase 1：飞书任务表情工作流

本规格增量替代既有快速收集表情的阶段含义；原有身份、可信回调、幂等和失败恢复边界继续有效。
决策见 [ADR-172](../adr/172-configurable-feishu-task-reaction-workflow.md)。

## 用户结果

1. 群聊 `@机器人` 成功保存任务后，原消息显示 Get；它表示“WAO 已收下”，不再提前显示 Done。
2. 已绑定的任务创建者给原消息再添加一个 Get，立即触发一次 Plan AI Run；执行期间保持 Get。
3. AI Run 成功并进入待验收后，原消息新增 Done；失败沿用可恢复的错误反馈。
4. 管理员可在「自动化 → 飞书群聊同步知识库 → 群聊快速收集」查看并修改“已收下 / 人工派工”与
   “完成待验收”表情，保存失败时保留当前输入并可重试。

## 配置与边界

- 默认值为 `GET` / `DONE`，可选值为 `GET`、`DONE`、`StatusInFlight`、`CheckMark`。
- “已收下”设置同时控制机器人创建回执与成员手工触发条件，不能配置成两个互相矛盾的值。
- 人工派工必须在飞书开放平台订阅 `im.message.reaction.created_v1`，并由 Verification Token 或
  Encrypt Key 建立可信回调；仅启用消息轮询时页面必须明确说明不能收到表情事件。
- 只有原快速收集消息、任务创建者、已绑定账号和真实可用 AI 工作流同时成立时才能派工；重复事件只产生一次运行。

## 验收

- 新建快速收集任务后只新增 Get，不发送成功卡片。
- 给原消息添加 Get 后只创建一个 Plan AI Run；飞书重推同一事件不重复创建。
- AI Run 入队和执行中不追加飞机或其他表情；成功待验收后新增 Done。
- 修改两个表情并保存后，新任务、人工触发和成功回执使用同一份最新配置。
