# Phase 1：全站业务右键交互基础

对应任务：`t1787901821458`（系统交互优化）。

## 用户结果

- WAO 主站和同仓发布的自媒体 Agent 不再弹出浏览器原生右键菜单，保持接近桌面应用的操作体验。
- 页签等已有业务右键菜单继续正常打开；后续模块可以监听标准 `contextmenu` 事件扩展自己的操作菜单。

## 边界与实现约束

- 在每个 WAO 自有前端文档的捕获阶段取消 `contextmenu` 默认行为，但不得停止事件传播或覆盖模块自己的监听器。
- 主站与 Agent 使用独立文档，必须分别安装守卫；Agent 无论通过 iframe 还是新窗口打开都保持相同行为。
- 浏览器控制区和跨域第三方 iframe 不受页面脚本控制，不以演示代码或代理页面冒充全局能力。
- 本任务只建立全站交互基础，不为尚未定义操作集合的模块添加空白或占位菜单。

## 验收

- 在主站普通内容、输入框和 Agent 页面右键，浏览器原生菜单均不出现。
- 在页签上右键，WAO 自有的关闭菜单仍出现且可操作。
- 自动化测试确认默认行为已取消，同时业务 `contextmenu` 监听器仍被调用。
