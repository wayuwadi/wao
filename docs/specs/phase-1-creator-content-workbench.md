# Phase 1：创作者一体化内容工作台

对应任务：`t1788171366302`（编辑与预览双栏、内容能力合并、账号定位完善）。

## 用户结果

- 自媒体 Agent 的一级入口精简为「内容工作台、话题与热点、账号管理、素材库」；内容创建、编辑、状态和发布不再分散在三个重复页面。
- 打开任意内容后，文字编辑与最终排版预览同时出现；标题、正文、标签或封面变动立即反映在右侧，不需要先保存或点击预览。
- 内容工作台继续显示真实平台、目标账号、创作进度、更新时间与发布时间。状态来自既有后端状态机，只有成员人工确认才提交官方发布，不把生成完成等同于已发布。
- 账号定位除领域、受众、语气和禁区外，还持久化常用主题、篇幅结构、更新频率、主要平台和配图风格，并进入真实模型的选题与成稿约束。
- 成员可输入实际创作需求，使用节点已配置的真实模型一次初始化九项定位；结果立即持久化且可继续修改，模型不可用时明确失败而不填演示数据。
- 「话题与热点」支持不依赖模型地手动记录灵感并保留在工作区话题池；热点推荐与手动话题都可采用为草稿，重新推荐不会删除手动话题。

## 图片与真实能力边界

- 编辑区可从当前工作区真实素材库选择或上传/替换图片；所选图片作为封面进入实时预览和 HTML 导出。视频素材如实标注为发布素材，不伪装成图文封面。
- 图片原文件通过登录会话与工作区归属校验后以内联响应返回，不暴露节点路径。上传、列表和预览固定到 Linux 主节点，确保本地媒体卷一致。
- 当前没有可靠接口的自动配图生成、智能裁剪和跨平台自动发布不显示假入口；素材库独立页继续用于复用已落库素材。

## 状态与恢复

- 切换文章、切换一级入口和关闭页面前继续保护未保存草稿；后台状态轮询不得覆盖本地输入。
- 加载、创建、上传、保存、发布、失败重试和空数据状态保持可见；存在未保存修改时，实时预览正常更新，但 HTML 导出和发布继续禁用。
- 没有官方发布接口的平台允许成员在完成站外发布后手动确认“已发布”；有官方接口的平台仍必须走真实提交，不能用手动状态绕过。
- 桌面使用任务列表加编辑/预览双栏；窄屏按任务列表、编辑、预览顺序纵向排列，所有操作仍可达。

## 验收

- 进入「自媒体 Agent → 内容工作台」，首次打开内容即可同时看到编辑区和实时预览；修改标题或正文后预览立刻变化，保存后刷新内容不丢失。
- 上传图片或从素材库选择图片后，右侧显示真实封面；保存后刷新仍可预览，其他工作区素材不可读取。
- 可在同一页面查看待完善、等待确认、发布中、已发布和失败内容，并仅在官方能力与真实授权满足时人工提交发布。
- 账号定位九项字段保存后刷新不丢失；Agent 前后端测试和生产构建通过，线上 `/agent/`、`/api/agent/health` 与素材路由可用。
