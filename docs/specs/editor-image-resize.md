# 编辑器图片缩放与块入口

- 知识库、小记和任务详情复用的图片节点在编辑状态显示四角缩放点；图片引用模式与只读模式不提供缩放。
- 拖动按原图比例调整显示宽度，限制在当前文字栏内；松手后一次性保存宽度、自动高度和左对齐，并清除图片缩进。不修改源图片。
- 尺寸写入既有 JSON 属性与 Markdown 图片标题尺寸元数据。重新打开、撤销和重做沿现有编辑器保存流程工作。
- Escape、pointercancel、窗口失焦取消当前拖动，卸载时移除监听；方向键可在控制点上微调宽度。
- 块入口使用小型加号，编辑区左侧保留 26px 操作空间、右侧 6px。打开菜单不修改正文，选择命令后在当前块后插入内容；原有斜杠入口保留。
