# 历史段落内图片加载兼容

2026-10-04 公网发布验收发现：旧 JSON 和同行 Markdown 会把块图片放入段落，UniqueID 初始化更新段落属性时报 `Invalid content for node type paragraph`。

- 沿用 ADR-198 的版本 1 JSON 事实源；编辑器加载时将段落或标题里的图片拆成相邻块，保持文字顺序、标记和图片 URL、尺寸、缩进等属性。
- 首次加载、外部 JSON 回灌及 Markdown 解析/插入使用同一兼容规则；列表图片仍满足首段落约束。
- 不修改传入对象，不批量改历史数据；只读展示不触发内容保存，用户真实编辑后仍沿用现有保存与草稿保护流程。
- 回归覆盖历史 JSON、同行 Markdown、外部更新和列表图片；公网含图小记加载不再出现段落 schema 异常。
