# 小记标题输入意图

飞书 `@小记创作` 收集的消息只有正文，创建请求的标题为空。小记服务继续推导可读临时标题，但自动标题阶段不应把临时标题当作人工输入。任务机器人自身的任务标题规则保持不变。

小记编辑器清空标题时，保存空字符串表达“没有手填标题”，不能回填旧标题或客户端推导标题再作为人工输入提交。服务端保留可读临时标题，保存信号将标题来源切回 `AUTO`。仅清空标题不隐式运行模型，提示可手动润色；同时修改正文时按原有设置进入新一轮自动处理。未改动的真实人工标题继续保留，自动阶段不覆盖；未知来源的旧记录仍保守保护。

重试无自动授权的历史保存时，已可靠记录的 `AUTO` 来源不得被现有占位标题改成 `MANUAL`。历史误判记录按用户明确报告逐篇处理，不以“标题像首句”全库推断人工意图。

浏览器已有文档 PATCH 的空标题在小记场景表示回到自动标题，省略标题表示不改；前端保留修订号及草稿合并保护。CLI/MCP 沿用现有文档更新工具，其实时 schema 仍要求非空标题，本次不开放终端清空标题或模型执行能力，不新增工具或扩大令牌权限。
