# 每日提醒已保存配置诊断

对应体验审计 B12，沿用 ADR-163 的总开关、提醒类型和沉默时段门禁，以及 ADR-227 的站内持久化渠道。以当前执行代码为准，不沿用旧规格中的飞书群投递承诺。

- 设置页的当前状态只读取最后成功加载或保存的配置；未保存修改单独提示，不冒充已生效。
- 每条每日提醒解释已保存的启停、系统总开关、提醒类型、计划时刻与沉默窗口（开始包含、结束不包含、支持跨午夜）、工作日门禁和个人可见性。
- 展示后端的下一计划检查时间和最近结果，不把计划时间、启用、试发返回冒充已发送或已读。配置未知不得默认允许。
- 阻断项提供对应设置锚点；普通成员明确提示由管理员修改共享策略。
