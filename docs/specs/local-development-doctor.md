# 本地开发环境体检

## 用户结果

开发前用一个只读命令确认运行时、前端依赖、数据库连接参数、数据库端口以及本地业务服务是否就绪。失败项给出下一步动作；不把端口可连接表述为账号可用或真实用户链路通过。

## 行为

- 使用 Python 3 标准库，无额外安装依赖；Java 基线来自根 POM，Node 范围来自前端 `engines.node`，Maven 使用 README 的 3.9+ 基线。
- 默认读取进程环境；只有显式 `--env-file` 时才读取指定本地文件，环境变量优先。文件按数据解析，不执行 `source`、命令替换或变量展开。仅处理本地连接所需变量，不输出变量值。
- 检查 Java、Maven、Node 可执行文件与版本、前端 Vite 是否安装、连接必需变量、数据库 TCP 端口。本地 API 健康检查需要返回合法健康 JSON，前端检查需要返回 WAO HTML；不把端口被其他进程占用当作服务健康。
- HTTP 检查仅允许无凭据的 loopback 源，禁用代理及跳转。`--offline` 跳过所有网络检查；参数可指定工具路径和本地端口，兼容独立 worktree。
- 终端和 JSON 输出均只含安全的检查编号、结果、版本和修复建议，不输出数据库地址、用户名、密码、HTTP 原文或子进程错误原文。
- 不启动、停止、安装或修改任何服务；不建立 SSH 隧道、不执行 SQL、迁移或部署。默认失败退出 1，全部必需检查通过退出 0；参数错误退出 2。

## 验收

覆盖运行时缺失/版本不符、环境文件特殊字符及恶意命令文本不执行、配置缺失、连通/拒绝、超时、HTTP 错误/跳转/错误服务，以及输出不泄露凭据。实际运行分别展示当前未配置 shell 的缺项和正确指定既有工具、真实数据库连接参数及本地应用后的结果。
