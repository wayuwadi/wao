# 导航与持久页签名称一致

审计 B01：全部功能、链接空间的导航标题已更新，但旧浏览器页签以及后台菜单同步仍可能使用“工作台”，两个功能无法区分。

- 读取本机页签时，系统模块默认标题按稳定功能 ID 更新；显式 customLabel、实体名称、外部应用和链接标题不被覆盖。路径、顺序、激活项与置顶状态保持。
- 初次打开模块与后台菜单同步都使用导航 itemMeta 的已规范化标题和图标，避免原始旧名再次覆盖；用户自定义菜单名与独立页签名继续按现有优先级保留。
- 只修改全局壳层与页签元数据，不涉及项目、知识库等内部逻辑或后台数据迁移。

验收：53 项页签、导航和页签栏测试通过。旧默认标题迁移、显式自定义和实体标题保留及持久化覆盖。本地连接真实数据库，从全部功能搜索打开链接空间，两页签名称一致且可区分；刷新后仍正确。通过 UI 重命名页签后刷新，自定义名称保留，验收页签已关闭。
