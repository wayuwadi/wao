# WAO 浏览器版：按对象提供右键操作

日期：2026-09-24。本规格修订 `phase-1-native-context-menu.md` 的全站拦截规则，保留其已交付的业务菜单。

## 用户结果

- 在普通文字、输入框、链接和无业务操作的区域右键，浏览器原生菜单可用。
- 在有 WAO 专属操作的对象上右键，显示命中对象的操作，不出现空菜单。
- 业务操作不能只靠右键发现；对应区域保留可见按钮或“更多”入口，并支持键盘。

## 本次接入

- TODO 列表行、看板卡片与四象限任务：打开任务、复制分享链接、复制编号、完成或重新打开。沿用各视图既有任务状态保存链路。
- 小记卡片：编辑、复制内容、复制分享链接、分享到聊天、置顶、移入回收站。删除只展开原有确认区，不直接删除。
- 知识库卡片：打开、复制站内链接、添加或取消常用、打开设置。设置中的删除仍使用原确认。
- 已有页签、侧栏、聊天图片、文档表格和网页宠物右键继续走各自已实现的操作；后续迁移共用菜单时不改变业务动作。
- 同仓 Agent 页没有已定义的专属菜单，恢复浏览器原生菜单。

## 交互约束

- 仅由命中对象的业务处理器取消 `contextmenu` 默认行为。文本选区、链接和输入框保留浏览器菜单；小记图片按[小记图片复制规格](notes-auto-title-image.md)提供复制图片与地址。
- 菜单先测量并限定在视口内再显示；窗口边缘、长标题和低高度窗口仍可操作。
- `Shift+F10` 或键盘菜单键从可聚焦对象打开；方向键、Home、End 移动，Enter 执行，Esc/Tab 关闭并返回触发对象。点击外部、页面滚动、窗口缩放、路由切换也关闭。
- 菜单动作重用页面现有业务入口。无权限、数据未读到或保存中的动作不可伪装为成功；删除保持原确认与恢复规则。
- 多选范围若尚未定义批量操作，继续使用现有批量工具，不把右键到单行误解释为批量操作。

## 后续接入

项目、知识目录内的文件夹与文档、聊天消息和日历事件应按真实操作和权限分别设计。只有“打开”一个动作的对象不强制添加 WAO 菜单。移动、批量操作及新状态变更在服务端契约明确后单独实现。

## 验收

- 鼠标、键盘和可见入口指向同一对象；菜单操作刷新后回读正确。
- 普通文字、输入框、链接右键可用；既有页签、文档表格、聊天图片右键不退化。
- 视口四角、窄屏、滚动容器、Esc、切路由与焦点返回行为正确。
- 剪贴板失败、只读、离线、保存失败和删除确认沿用现有反馈与恢复路径。
