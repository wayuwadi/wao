# 小记默认作者与记录区宽度

2026-10-11 用户确认。本规格取代 `notes-personal-view-2026-10-10.md` 的默认作者规则，并补充 `notes-writing-pane-resize.md` 的默认宽度与恢复规则；其余草稿、权限、拖拽和账号隔离行为继续沿用。

- 首次打开和清除筛选默认“全部作者”，展示后端已授权可见的小记；仍可主动选择“我的小记”、系统或指定作者。默认全部作者不计为额外筛选。
- 列表偏好使用按成员隔离的 `wao-note-list-preferences-v3:<memberId>`。首次从 v2 恢复时只将作者重置为全部，其余排序、标签、图片、时间及系统文章开关保留；v1/v2 原存储不删除。v3 中主动选择的作者刷新后恢复。未登录不读写空成员键，切换账号清空临时搜索并独立恢复偏好。
- 未手动设置桌面宽度时，记录区以 600px 为目标，工作区较宽时至少约三分之一、较窄时不超过 60%，并继续为列表保留至少 320px 和分隔线 20px。常规桌面为身份、书摘、复制给 Codex、保存按钮与状态提供同一行空间，按钮文字不折行。空间不足及手机仍允许重排，按钮不隐藏、不溢出。
- 已手动调整并保存的记录区比例继续沿用；双击分隔线或 Home 清除固定比例并恢复自适应默认宽度。键盘微调从当前自适应比例开始，宽度数值反映两栏实际约束；窗口变宽后默认值自适应，手动值保持比例。
- 1100px 及以下仍采用上下布局。记录区实例、未保存正文、草稿保护和保存流程保持，不改 API、MCP、CLI 或数据库。

验收覆盖默认全部作者与清除筛选、v2 迁移与 v3 刷新、账号切换、延迟登录、响应式默认宽度、手动宽度与恢复、拖拽清理和草稿保留。浏览器另核对明暗主题、窄屏、键盘及按钮同排。
