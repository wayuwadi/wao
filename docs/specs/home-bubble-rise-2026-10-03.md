# 首页满高休息空间与点击升空

本次用户反馈替代 `home-adaptive-space.md` 的短内容高度及 `home-rest-activities-2026-10-03.md` 的左键开菜单约定。首页用于休息，保留原有留白，不新增常驻入口。

- 首页主体占满导航栏与备案页脚之间的可用高度。顶部信息卡保留；宽屏左侧文案随主区域垂直居中，右侧伙伴停在底边，中间作为活动空间。窄屏上下排列，内容不足以容纳时正常滚动，不裁掉入口。
- 左键单击、触屏轻点、Enter/Space 只与当前伙伴互动，不打开菜单。右键或 Shift+F10/菜单键打开既有六种十五秒集体活动菜单。
- 被点伙伴在约 2.7 秒内升至活动区域顶部，然后散为同色浅色泡沫，泡沫约 1.1 秒消散；伙伴从底部平滑重现，总计约 4.6 秒。无声音、自动循环或业务请求。
- 各伙伴独立升空；重复点同一个不重置进度。拖动仍是原有拖动回弹，不触发升空。启动升空会结束集体活动，启动集体活动会结束升空并归位。
- Esc、安静、编辑、离页、后台、调整窗口或减少动态效果时收回临时动效；WebGL 降级时轻点有简短静态回应，右键菜单仍可达。安静偏好与系统减少动态效果继续有效。
- 沿用既有 Three.js 场景，泡沫几何体共享；卸载统一释放资源。无 API、CLI、MCP、数据库变更。

## 回归与使用

在 `wao-web` 执行：

```powershell
npm exec -- vitest run src/__tests__/companionScene.spec.ts src/__tests__/companionActivities.spec.ts src/__tests__/companionPlay.spec.ts src/__tests__/homeCompanions.spec.ts src/__tests__/HomeView.spec.ts
npm run build
```

正常登录首页，单击一位伙伴，看它独自升空、散开、归位；依次点多个伙伴和连续点同一个，确认没有菜单、重复计时或半空残留。右键选择集体活动，检查与升空切换、Esc、拖动和 390px 窄屏。桌面场景底边应与主体底边对齐，页脚仍可见。

本地验收使用既有 Windows1 后端与正常登录数据，不创建业务记录。物理触屏长按与低性能设备帧率需额外设备验证。
