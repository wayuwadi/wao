# 今日行动通知独立选群

## 用户结果

- 今日节奏顶部提供「通知设置」，原「调整节奏 → 行动通知」入口继续可用。
- 精力补给、今日重点、卦象解读各有发送开关和目标群。一个下拉框同时列出已启用 Webhook 和飞书机器人真实所在群，按来源分组；切换一类不改变另两类。
- 用户可自行调整三类群。本次成员配置在发布后通过真实设置页保存：精力补给 → WAO通知群；今日重点、卦象解读 → WAO。群名和 id 不写死在代码中，不为其他成员自动改群。
- 总开关暂停全部行动通知但保留各类选择；精力补给内的项目级通知开关仍生效。
- 明确显示读取中、暂无可选群、已保存但当前不可用的目标，以及部分通道读取失败和刷新入口。刷新选项不改草稿，失败时不回落默认群。
- 未提交选择沿用节奏草稿恢复；保存失败可重试，成功后按账号跨设备恢复。配置保存本身不增加补给次数、不保存重点，也不重复发送已投递的卦象。

## 数据契约

扩展成员偏好 `workday-rhythm-config-v1.energyNotification`：

- 原 `enabled` 总开关、`notifyFocus`、`notifyTianren` 保留。
- `notifyEnergy` 可选，缺省 `true`，仅控制精力补给（包括网页宠物快捷动作）。
- 原 `channel / webhookId / webhookName / chatId / chatName` 作为精力补给目标。
- 新增 `focusTarget`、`tianrenTarget`，各含上述五个目标字段。
- 独立字段未出现时沿用旧共用目标。前端首次规范化时复制为独立对象，保存后固定为独立目标；已显式配置但为空/损坏时不得合并或回落旧群。
- Webhook 地址、凭据继续留在服务端。发送服务仍按登录成员读取持久化偏好和已保存业务数据，不接受请求体指定临时目标。
- 卦象准备、状态、发送前校验及重试均使用其独立目标。冻结快照不变，变更卦象群后不能把旧卡片重试到新群；精力补给改群不再影响卦象目标。

## 验收

覆盖旧 CHAT/Webhook 配置迁移、各类目标隔离、空目标不回落、独立关闭、部分列表失败与重试、保存失败草稿恢复、重新打开恢复目标，以及 390px 窄屏可操作。服务端验证精力补给和重点各自的传输目标、卦象独立目标及冻结重试保护。
