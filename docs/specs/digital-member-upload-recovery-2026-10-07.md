# 数字成员图片上传与预览修复

补充数字成员图库规格，不改变私有资产、生成参考、账号及版本权限边界。

真实问题：较大 JPEG 上传成功并规范化为 PNG 后，公网读取可超过通用 HTTP 客户端的 10 秒超时；界面显示图片读取失败。小尺寸图片不能覆盖此链路。

参考照片区支持多文件拖入、拖入提示，沿用当前参考照片/形象图片用途；选择上传按钮继续支持键盘及触屏。上传中阻止重复提交，逐文件保留失败项并显式重试，不自动重放写请求。选择器与提示限定服务端支持的 JPEG、PNG，单张 10MB。

GET `/api/digital-assets/{id}/raw?preview=true` 在现有拥有者鉴权之后生成最长边 640px 的展示预览；不放大，不透明图片转 JPEG，透明图片保留 PNG。仍使用 no-store 与 nosniff，不新增公共资源或匿名权限。省略 preview 仍返回原规范化资产；生成、哈希、主参考及版本继续引用原内容。

浏览器使用轻量预览；仅图库上传/读取设置 60 秒传输超时，其他接口保持既有超时。候选版本表单提示点击照片选择参考，选中展示“已选择”；必须明确选择后才能保存，不能将图片读取失败或空选择误称为上传失败。

此修复不增加 CLI/MCP 暴露：仅优化已有会话私有图片展示与上传入口，原图库规格关于独立私有权限的要求继续有效。

验收覆盖较大照片上传及预览、原图内容不变、透明细长图片、拖入多文件的部分失败与重试、选择照片后保存候选并确认。实体设备最终体验由用户验收。
