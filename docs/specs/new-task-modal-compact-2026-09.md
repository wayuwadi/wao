# 新建任务弹窗紧凑布局

来源：WAO #1204。

- 标题是主要输入，默认聚焦；以具体行动作为占位示例，避免误创建无意义的通用标题。外部内容转任务时继续使用来源标题。
- 项目与工作项类型在同一行展示，项目沿用当前项目或成员设置的默认项目；可在表单里切换和设置默认项目。
- 普通新任务由当前创建人负责，优先级为 P2。四象限入口保留其优先级上下文；失败重试保留原本已提交的负责人和优先级。创建时不占用表单空间修改这两项。
- 时间安排默认折叠；由日历带入的日期或时间段自动展开。描述、图片、草稿恢复和保存失败重试流程保持可用。
- 弹窗顶部与创建操作区固定，中间内容独立滚动；长描述和窄屏时创建按钮仍可见。
