# 规格：文档关联任务返回入口

对应任务：`t1788512841533`。

## 用户结果

- 任务通过现有「关联知识、任务或文件」选择器关联文档后，打开该文档时，在文档标题和作者信息下方显示「关联任务」及任务标题。
- 点击关联任务直接打开该任务详情；文档页保留在背景中，关闭任务详情即可继续阅读或编辑原文档。
- 一篇文档关联多项任务时展示全部当前成员可见的任务；长标题保持在标签范围内，不撑破文档页。
- 任务解除文档关联或任务不可见后，文档页不再显示该任务入口。

## 数据与权限

- 任务到文档的权威关系继续使用任务 `detail_json.docs[]`，文档不重复保存任务 id。
- 文档页只反查当前会话已经按项目权限返回的任务，不因展示反向入口扩大任务可见范围。
- 文档自身已有的项目、任务、文档出链以及文档间反向链接保持不变。

## 验收

- 给一个真实任务关联当前文档，刷新并打开文档后可看到任务标题，点击后打开正确任务详情。
- 同一文档关联两项任务时两项都可见、可分别打开；解除其中一项关联后只剩另一项。
- 没有任务关联的文档不显示空的「关联任务」区域；原有文档出链与反向链接仍可使用。
