# AI 会话启动配置的失败恢复

## 问题与结果

审计 A08 指向的旧 AiRunLauncher 已由 PR #706 关闭入口，不修改该隐藏功能，也不重新启用任务/项目 AI Run。复核当前 AI 会话入口发现：配置失败与“没有工作流”混淆，且草稿保留项目 ID 时仍可能提交。

当前入口仅在配置成功读取、所选项目和指定执行电脑仍在可用列表时允许派发。读取失败持续显示原因与重试；读取中可继续填写目标。成功后显示检查时间和刷新入口。失效草稿选择明确提示重新选择，不静默改派其他项目。重试保留目标、执行方式等输入，旧请求不覆盖更新的配置或成员。

## 边界

不修改后端任务创建、调度、工作流配置或项目管理内部实现，不变更既有离线电脑排队规则。预检不是权限替代，最终权限和执行能力仍由后端校验。

## 验收

- AI 会话组件 8 项测试通过，覆盖配置失败不能提交、失败不是空数据、恢复保留目标及失效项目重新选择，既有会话流程回归。
- TypeScript 检查与生产构建通过。
- 本地前端连接既有数据库，临时代理模拟工作流配置连接失败：错误原位保留，发送禁用，目标可填写。移除代理故障后点击重试，恢复真实工作流且目标保留、发送可用。未点击发送或创建生产任务。
