# 天人一卦主动群卡片

决策见 ADR-201；扩展天人一卦与今日行动通知，不改变公开分享和成员私有会话边界。

1. 在今日节奏的调整节奏 / 通知区启用今日行动通知、选真实群或 Webhook，再勾选「卦象解读完成后发群」。旧成员默认不启用。
2. 卡片保留用户设计的横幅、紫色标题和图标；正文包含真实日期、本卦、之卦/变爻、已保存的 AI 解读、文化反思边界及完整公开结果链接。长解读做有标识的截断，不发关注点字段、用户消息或完整会话。
3. 服务端在首次成功解读后主动发送；关闭页面不丢投递，重复解读不增加卡片。开关在当天解读完成后开启也会处理当天结果。
4. 天人一卦页显示未启用、等待解读、待发送、发送中、已发送、策略跳过、配置失败或结果未知。状态读取不触发发送；失败可手动重试，未知必须先确认群中没有收到。
5. 持久状态和冻结快照位于 `tianren_notification`，每个 reading_id 唯一；跨节点只能有一个抢占者。发出后数据库未确认、超时或进程崩溃不自动重发。
6. 重试继续使用原目标与快照；若群配置改变，提示恢复原目标，避免把已经公开的内容静默发到另一个群。
7. 图片 key 使用用户提供值，需实测该发送应用 / Webhook 可用；不可用时不假报成功，提示检查图片和发送权限。

## API

- `GET /api/tianren/readings/{id}/notification`：当前成员该卦投递状态 `{state, targetName, message, retryable}`。
- `POST /api/tianren/readings/{id}/notification/retry`：重试已存在的 FAILED / SKIPPED / UNKNOWN 记录；UNKNOWN 必须提交 `{confirmNotReceived: true}`。已发送不重发。
- 开关使用既有成员偏好 API，目标与权限保持原规则；无历史投递的过去卦象不能补发。
