# Phase 1：今日节奏单屏执行布局

对应任务：`t1787896982778`（今日节奏优化）。基础行为见
[今日节奏顶部摘要与可追加重点](phase-1-workday-rhythm-top-summary-and-flexible-focus.md)，本次视觉层级与入口收口以
[ADR-149](../adr/149-workday-rhythm-single-screen-layout.md) 为准。

## 用户结果

1. 桌面端顶部通铺卡的当前时间块、完整一天和天人一卦分别占 60%、20%、20%，当天最重要的信息获得主要空间。
2. 下方今日重点、每日必做和精力补给保持三卡并排且等高，所有执行项在各自卡内铺满一行，每日必做不再拆成双栏。
3. 默认桌面内容填满应用壳内的一屏且页面不出现纵向滚动；项目超过当前卡片高度时只滚动该卡片。窄屏仍按三卡顺序纵向浏览。
4. 三张执行卡不再显示独立设置或跳转入口；时间线、每日必做、通知目标和补给项目统一从顶部“调整节奏”配置。
5. 默认页面不再显示“打开真实待办”“安排明日”“草稿已保存在本机”“新增重点”及补给计数规则说明；明日展开、追加重点、
   草稿防丢、保存和失败重试能力保持可用。

## 验收

- 1180px 桌面内容宽度下，顶部三部分计算宽度接近 3:1:1，下方三张卡等高且每日必做条目均为通栏。
- 1180 × 768 及更高桌面视口中，默认数据下应用内容区没有纵向滚动，页脚紧随单屏面板；三张执行卡填满剩余高度。
- 三张执行卡内找不到单独配置、待办跳转和通知目标选择按钮；顶部“调整节奏”仍能编辑并保存全部真实配置。
- 今日与明日重点可通过图标追加，未保存时显示“待保存”；保存成功、失败保留草稿和原位重试行为不变。
- 390px 窄屏无横向滚动，三张执行卡纵向显示且重点、必做与精力记录仍可操作。
