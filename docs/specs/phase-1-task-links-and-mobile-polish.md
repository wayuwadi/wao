# 规格：任务关联、AI 状态同步与移动端项目页优化

对应任务：`t1785286828103`（系统优化 + 小需求收集）。本规格补齐任务详情里的真实关联入口、
AI 执行状态同步，以及项目页在手机上的完整浏览口径；既有移动端录入与子任务详情规则继续遵循
`phase-1-task-groups-and-mobile.md`。

## 1. 长子任务可以正常派工

- 子任务标题不因为超过一行就截断，详情页仍可完整编辑。
- 从长子任务打开 AI Run 选择器时，范围摘要最多占两行，选择器自身可以在视口内滚动，底部
  「开始运行」始终可达；完整标题仍原样提交给服务端与分享 Markdown，不做静默裁剪。
- 手机上 AI Run 选择器使用贴底面板，并为底部安全区留白，不能被长标题或软键盘推出屏幕。

## 2. 关联知识、任务或文件

- 任务详情的「关联知识、任务或文件」打开真实选择器，候选项来自当前后端已经返回的文档、任务和
  文件，不生成演示数据。
- 支持搜索、按类型切换、勾选建立关联和再次点击解除关联；不能把任务关联到自己。
- 关联结果写入任务详情 JSON：文档使用 `docs`，任务使用 `linkTasks`，文件使用带稳定 `id` 的
  `files` 引用。保存失败沿用任务自动保存的失败 / 重试提示，不伪装成功。
- 已关联文档跳到对应知识库文档，已关联任务在当前任务抽屉内打开，已关联文件进入真实文件下载确认页。

## 3. AI 执行状态及时更新

- AI 运行列表每 5 秒刷新；任务抽屉打开期间始终轮询，因此从另一页面或另一台电脑发起的运行也会出现。
- 每次拿到 AI 运行状态后，直接把服务端控制的任务状态投影到当前列表：排队 / 运行中为「AI 进行中」，
  成功为「待验证」，失败或暂停为「进行中」。这次投影不触发任务 PUT，避免旧页面把服务端新状态写回去。
- 普通项目 / 任务协同轮询仍保留本地草稿保护，不能为追求状态及时而覆盖尚未落库的标题、描述或子任务。

## 4. 手机项目页

- 手机不再显示桌面多页签条和顶栏新建按钮：模块切换由底部导航承担，新建任务由拇指区悬浮按钮承担。
- 项目头压缩为两行：返回、项目名 / 状态、领域 / 日期、成员和设置均可见；桌面版布局不变。
- 项目内任务 / 文档 / 文件 / 动态页签可以横向滚动但不换行，当前页签保持可见。
- 任务视图切换占满一行，创建人筛选和批量动作另起一行；按钮触控高度至少 40px。
- 列表任务改成标题在上、状态 / 优先级 / 负责人 / 截止在下；长标题换行，不横向撑破屏幕。
- 看板在手机上改为纵向状态分区，不再露出半张下一列或要求横向拖动；每张卡完整占满内容宽度。
- 分组、文档、文件和动态均为单列，页面任一业务区不得产生整页横向滚动。

## 验收

- 用超过 300 个中文字符的子任务标题打开 AI Run，仍能看见并点击「开始运行」。
- 关联一个真实文档、另一个真实任务和一个真实文件；刷新后仍存在，三者分别能进入正确页面；解除后刷新不再出现。
- 模拟运行从 `running` 变为 `succeeded`，5 秒刷新后运行记录显示「等待验收」，项目任务状态同步为
  「待验证」，同时未保存的本地描述不丢失。
- 在 390px 宽度检查项目任务的列表、看板和分组三种视图：无整页横向滚动，标题和主要操作均可见，
  悬浮新建按钮不遮住最后一条内容。
