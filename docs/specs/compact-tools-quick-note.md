# 顶栏工具收纳与原地快速小记

2026-10-03 用户逐轮确认 Demo：常用新建留在外面，采用带加号图标和「任务」「小记」短文字；低频操作收到「工具」。补充 `compact-global-navigation-line.md`、`mobile-content-first-shell.md` 与 `notes-tab-draft-isolation.md`。

## 用户行为

- 顶栏只常驻「图标＋任务」「图标＋小记」与「工具」，保留可见文字和完整无障碍名称。触屏扩大点击区域，窄屏沿用底部「更多」中的全局操作。
- 工具展开为轻量浮层，包含通知、更新记录、外观、快捷键；未读通知或可用新版本使入口显示提示点。继续使用既有通知中心与更新面板、真实未读数及版本事件，不另造数据。
- 新建小记不跳转路由、不关闭任务详情、不更换页签；打开右上方浮层，窄屏限制在视口内。保存成功收起浮层并提示，继续原页面。
- 浮层复用 NoteComposer 的富文本、上传、显式保存、失败重试、全屏与 AI 偏好。新建草稿独立于小记页的新建区，以现有成员和浏览器页签隔离键追加 `:floating`；复制页签继续受既有身份锁保护。
- 收起保留编辑器内存及浏览器草稿；存储失败时明确提示，内存仍可继续写。服务端请求期间禁用收起；失败保留正文与稳定 id，原地重试。空正文不能保存。
- 按 Esc 优先收起最上层浮层，全屏编辑先退出全屏。打开时聚焦编辑器，关闭后恢复入口焦点；初始化使用异步编辑器原有加载状态。

## 能力边界

仅浏览器入口与呈现变化；不新增 HTTP API、业务服务、MCP 或 CLI 能力，不修改数据结构和 migration。保留历史 QuickNoteModal 源码，但全局新建实际改用复用现有编辑器的 QuickNotePopover。

## 验收要求

覆盖工具各入口、未读/版本点、键盘关闭、窄屏标签可读；真实服务保存并回读；浮层和小记页各自草稿隔离、收起重开、刷新恢复、保存失败重试、请求期间防重复保存和误关闭。

本地验收：5257 代理既有 18080 真实服务，以本机开发成员创建两条明确命名的专用小记；项目页保存后路由不变，小记清单可回读。通过仅影响该本地代理的小记 PUT 故障注入验证失败保留和恢复重试，延迟请求期间收起按钮禁用；验收后已关闭注入。320px / 390px 实际页面浮层左右各保留 12px，320px 的任务和小记按钮均约 62px，文字无溢出。未测试实体手机软键盘。
