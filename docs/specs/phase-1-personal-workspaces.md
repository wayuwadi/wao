# 规格：个人工作台与项目空间

对应任务：`t1787046286664`（在 WAO 内建立可扩展的个人工作系统）。

## 目标

- 在 WAO 内提供内置“工作台”，替代浏览器收藏夹或文档中散落的工作环境、管理后台和常用页面登记。
- 每位成员拥有彼此隔离的空间；一个成员可以按项目或工作场景创建多个空间。
- 空间可以关联一个当前成员可见的 WAO 项目，但不要求项目已经启用 AI Run，也不伪造外部系统状态。

## 数据与权限

- 空间记录按当前服务端 Session 推导出的成员 id 隔离；列表、详情、保存和删除都必须携带成员归属条件。
- 空间名称、说明、关联项目、分组和链接以一个版本化快照原子保存，刷新和跨设备登录后不得回退。
- 每个空间最多 12 个分组、240 个链接。链接只允许 `http://` 或 `https://`，兼容内网环境，同时拒绝脚本和数据 URL。
- 删除空间只删除 WAO 中的导航资料，不访问或删除链接对应的外部系统。

## 页面行为

- “工作台”是个人组内置菜单，路由为 `/workspaces`；空数据时明确引导创建第一个空间。
- 支持创建、切换和删除空间；编辑时可维护名称、说明、关联项目、分组、链接标题、地址、环境标识、备注和收藏状态。
- 分组和链接可上移、下移；保存顺序以服务端返回结果为准。
- 浏览态支持按标题、地址、环境和备注即时搜索；收藏链接集中显示，链接始终在新页签打开。
- 编辑中的完整快照写入本机草稿。保存失败时保留草稿并提供重试；加载、保存、已保存、失败和空数据均有明确反馈。
- 服务端刷新不得覆盖当前空间尚未保存的本地输入；放弃编辑前必须确认。
