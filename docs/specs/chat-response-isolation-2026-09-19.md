# 聊天异步响应与成员隔离

沿用现有单组织共享聊天权限和成员独立草稿，不新增会话或账号体系。

- 登录成员改变时立即清空当前消息、编辑草稿、引用、未读和上传状态，再恢复新成员的本机草稿。富文本编辑器随成员会话重建，避免保留上一成员聚焦输入。
- 发送、上传、已读、表情、编辑和消息加载只允许当前会话的回调更新界面。退出后重新登录同一成员也不接受之前会话的晚到响应；失败回调不能污染新会话提示或发送状态。
- 未登录时不轮询聊天。组件卸载后停止轮询并丢弃剩余回调。
- 消息读取记录发起时的版本；读取期间发生编辑、发送、表情或已读更新，旧读取结果丢弃，下一轮重新同步，避免覆盖已确认的新状态。
- 切换成员时取消语音识别及其已排队回调，避免旧语音追加到新成员输入。

验收覆盖 A→B、A→退出→A、旧附件成功/失败、旧已读响应、旧刷新覆盖刚保存修改以及语音取消。真实双成员操作结果在交付记录中单独列明。
