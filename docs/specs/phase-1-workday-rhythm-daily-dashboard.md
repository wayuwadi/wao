# Phase 1：今日节奏每日面板

本规格扩展 [个人工作日节奏](phase-1-workday-rhythm.md)，决策见
[ADR-101](../adr/101-workday-rhythm-daily-dashboard.md)。

页面紧凑布局、每日工作记录移出与指导型时间线见
[今日节奏紧凑面板](phase-1-workday-rhythm-compact-dashboard.md)，其页面表达条款优先。

## 用户结果

1. 「今日节奏」统一展示带时间窗的每日必做、今日三个重点、时间块、精力补给、每日工作文档和每日卦象。
2. 首次使用自动建立「制定今日计划」「上班打卡」「下班打卡」；名称、分类、适用日、时间窗、通知和排序可维护，系统联动类型不可改。
3. 三个今日重点全部非空且服务端保存成功后，计划项自动完成；开启通知时再把服务端重读的三项发到成员选择的真实群。页面只突出第一个未完成重点，成员确认完成后才转到下一项。
4. 成员可提前保存明日 1—3 个重点，次日直接沿用同一条按日期记录，不复制任务或生成演示数据；其他考勤和自定义项由成员主动确认。
5. 项目记录完成时间并区分提前/准时、逾期、逾期完成；跨午夜项归属开始日期，次日截止前仍在面板展示。
6. 工作日默认为周一至周五及大周周日；「自动跟随大小周」可关闭，当天手动覆盖优先且可恢复自动判断。
7. 工作日展开每日文档编辑器；首次真实输入时才按所选知识库、文件夹、模板和标题格式幂等创建文档。
8. 每日卦象不自动生成；成员可主动起卦、查看摘要并进入「天人一卦」详情。开启「纳入必做」后，起卦成功自动完成。

## 数据与安全边界

- 清单模板与每日实例分开持久化；模板改动不改写历史和已完成事实。
- 当天尚未完成且尚未投递提醒的实例可同步最新模板；已发送提醒或已完成的快照保持不变。
- 外部通知默认关闭。每项可独立开启飞书私聊、一个群聊和一个 Webhook；到点仅向未完成项投递。
- 今日重点群通知复用 `workday-rhythm-config-v1.energyNotification` 中的成员目标，以 `notifyFocus` 独立开关；服务端只接收日期，不接收前端自报的目标、成员或群。
- 顺序完成状态保存在当天成员偏好的 `focusCompleted` 中；它是成员主动确认的执行事实，不反向伪造待办进度。修改某项会清除该项及后续项已完成状态。
- 投递按「每日实例 + 通道」唯一，失败五分钟后重试，最多六次，多节点不重复发送。
- 真实上下班考勤按 [日历考勤规格](phase-1-calendar-attendance.md) 自动完成对应系统项；仍不读取定位、不保存打卡照片，也不自动推断到家。
- 已进回收站的每日文档只提示恢复，不静默创建重复文档；本机草稿在恢复或重选目标前保留。

## 验收

- 大周周日自动显示工作日三项默认必做，小周周日不生成工作日项；当天覆盖和恢复自动均立即生效。
- 保存三个重点后计划项自动完成；任一项为空或保存失败时不伪造完成。
- 三项落库后才发群；通知失败不回滚已保存目标，页面原位重试且不重复保存。关闭重点通知时不读当天记录、不调飞书。
- 列满三项后只有第一个未完成项显示「完成并开始下一项」；刷新、换设备后保留当前位置。
- 明日计划保存后刷新和换设备仍能恢复；保存失败时保留本机草稿并可原位重试，次日打开后同一记录直接成为今日重点。
- 下班打卡可在次日 07:00 前完成，跨日刷新后仍能看到前一日项。
- 并发首次编辑只产生一篇每日文档；刷新、换设备、保存失败和回收站均有真实状态。
- 提醒前完成不发送；三类通道成功各发一次，失败记录可重试且不重复已成功通道。
- 390px 窄屏可完成清单、编辑文档、起卦和调整设置，不产生业务区横向滚动。
