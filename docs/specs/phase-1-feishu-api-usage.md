# 飞书 API 调用量诊断与节流

扩展现有飞书群聊同步、个人快速收集和共享聊天规格，决策详见 ADR-225。

用户从「自动化 → 飞书群聊同步」查看本月已观测的真实 API 排名、次数和占比。界面必须标明
北京时间观测起点，只涵盖 WAO 群聊客户端上线后数据；无法还原过去历史，不是飞书租户剩余额度。
空数据不能展示演示排行；加载失败可重试且保留上一份数据；刷新只读 WAO 数据库。

后台实时消息保留现有周期和事件回调，成员读取按群与令牌缓存五分钟，空消息窗口不读成员。
编辑、撤回和旧消息飞机表情的全天回看默认由一分钟调整为五分钟；未订阅回调时接受此延迟。
双节点依共享租约、水位和成功后冷却周期防止交错重复调用；失败不推进水位。
租户额度只能按飞书官方方案提升，不能用换应用、伪造身份或虚构剩余额度代替解决方案。

验收入口与步骤：
1. 打开飞书群聊同步，看到真实调用排行与观测起点，刷新后同一接口累计次数不倒退（自然月切换除外）。
2. 多次刷新统计不产生飞书请求；等待后台下一轮，再观察消息接口真实计数增长。
3. 读取当前群成员仍返回真实名单；后台同步不会每次重复读取成员表。
4. 已有群消息继续进入共享聊天与快速收集；编辑/撤回/表情由事件回调或五分钟兜底同步。
