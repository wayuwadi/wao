# 文档限时分享

2026-10-28，参考用户提出的微信分享链接理念，将既有小记令牌机制扩展到知识库文档。目标是作者主动授予持链接访问权限，避免仅凭文档 ID 读取站内内容。未取得微信实现源码，不推断其令牌是否一次性。

## 契约

- 默认登录后读取原文。旧 `/api/share/docs/{id}`、`.md` 和飞书旧 ID 链接预览均不再返回正文；旧 `/s/d/{id}` 显示重新生成链接提示。站内原文链接保持原有登录与权限规则。
- 作者通过既有 `/api/docs/{id}/public-shares` GET/POST/DELETE 管理链接。非作者不能列举、创建或撤销。有效期为 1 小时、1 天、7 天，最多同时 20 个有效链接。
- 复用 `note_public_share` 表、`ns_` 格式的 32 字节密码学随机令牌和 `/s/n/{token}`、`/api/share/notes/{token}[.md]` 路径，保持已有小记链接兼容。名称含 notes 不改变文档范围；数据库只保存 SHA-256 摘要，原始令牌只在创建响应返回一次。
- 分享保存当时正文与富文本/工作簿快照，不包含未保存草稿或未来编辑。持有链接者有效期内可多次只读访问，支持刷新、预览和 AI 读取；不做打开一次即消耗，避免预览机器人提前消耗权限。
- 每次 JSON、Markdown、图片读取验证令牌、到期、撤销、原文删除与作者归属。撤销一个链接不影响其他链接。原文移入回收站撤销全部链接，恢复原文不恢复分享。
- 本站图片改写为同一令牌下的地址，只允许读取快照出现的图片 ID。文档和小记素材均持久标为私有，原始图片和附件地址需要登录；附件不因正文分享获得匿名下载权限。外站素材仍遵循原站权限。
- API 成功及失败响应使用 `private, no-store`、`noindex, nofollow, noarchive` 和 `no-referrer`。分享 HTML 在应用加载和配图加载之前设置 robots/referrer 元信息；不把搜索引擎是否遵守 noindex 当作访问授权。

## 体验与兼容性

知识库沿用 `NoteShareDialog`、`SettingsDialogShell`、`WaoButton` 和主题变量。分享菜单保留原文链接，外部分享进入限时分享设置，可复制页面或 Markdown 地址，也可撤销。明确说明持链接可转发、仅分享已保存快照、附件需登录、已下载内容无法追回。旧 ID 外链会停止匿名读取，这是本次收紧权限的预期效果。

历史已被搜索收录或下载的副本不会因新令牌自动消失；上线后须对真实旧 URL 验证不能再读，并按搜索平台流程申请移除历史结果。生产反向代理访问日志含令牌路径，须按私有凭据保护并配置脱敏/不记录；不得将真实链接写入公共日志或工单。

## 验证

覆盖作者隔离、无隐式分享、随机令牌摘要、快照稳定性、独立撤销、精确到期边界、删除/转移失效、跨快照配图拒绝、旧地址封闭、响应缓存/收录头，以及文档/小记共用界面的加载、失败重试和关闭保护。新增 V195 对历史文档素材补齐持久私有标记，不修改既有迁移。

## CLI 与 MCP

此次不新增工作区 MCP 工具或 CLI 命令，旧令牌不会获得发布文档的权限。分享管理仍使用作者的浏览器登录会话。若需要终端创建外链，先增加独立分享发布 scope、内容快照确认与审计，再同步 CLI。
