# 决策编辑保存期间的输入保护

补充个人决策管理规格，沿用统一记忆接口、发布规则与版本检查，不改变后台业务语义。

- 保存提交时捕获内容、对象和成员；保存期间允许继续输入，并持续保存本机草稿。
- 成功回包只代表提交的那一版已保存。存在新增输入时保留弹窗并提示继续保存；新建成功后采用真实对象 ID 和版本，后续更新同一条决策。
- 已知服务端成功与本机草稿清理、列表刷新分开反馈。清理失败不能误报为服务端保存失败，也不能继续按新建处理。
- 成员切换或页面卸载后，旧响应不能修改当前表单、清理当前草稿或继续刷新列表。搜索响应也必须对应当前搜索条件。
- 草稿恢复只接受已知字符串字段；保留编辑所基于的版本 ID，避免刷新后静默改用新版本覆盖其他设备修改。格式错误或存储异常不删除原草稿。
- 存储失败明确说明输入仍在当前页面，并提供重试；关闭前提示备份。保存失败保留包括请求发出后新增的全部输入。

验收覆盖保存中追加输入后的成功和失败、新建后继续更新同一对象、账号切换、旧列表响应、本机写入与清理失败，以及真实记录的两个版本往返。

边界：版本冲突沿用服务端拒绝规则，不自动覆盖；网络超时且无法确认创建结果时，本次不提供服务端幂等保证。废止失败的原位恢复和冲突比较界面另行处理。
