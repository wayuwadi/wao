# 日历天气与每日卦名

关联任务：t1788476494396。今日节奏和日历共用成员级城市设置，支持浏览器定位和搜索后手动选城；首次不猜测城市、不请求定位权限。点击定位后将经纬度四舍五入到两位小数，通过 WAO 服务端请求 Open-Meteo。

天气来自 Open-Meteo 真实未来 7 日预报，日期统一按 Asia/Shanghai，与 WAO 日历一致；标明来源、获取时间和预报范围。无数据、加载中、失败重试分别展示。超过半小时视为待更新，旧数据不继续作为当前天气展示。天气开关分别控制节奏和日历；位置和开关复用成员偏好接口，保存失败保留草稿，刷新或同步不能覆盖未保存输入。

雨雪、雷暴、雾、最高温≥35℃、最低温≤0℃或最大风速≥39km/h 显示页面出行提醒。提醒为预报提示，不冒充气象部门预警，不主动发送群消息。

日历卦名默认显示，可独立隐藏；仅按当前登录成员和可见日期范围读取已起出的卦。浏览日历不会生成卦象，不因选择其他成员而泄露个人卦象。未起卦日期留空。

验收覆盖：真实城市搜索、选择和预报回读，节奏与日历共用设置，窄屏、显示开关、草稿保留、保存失败重试、定位失败、真实卦名和空日期。

数据源：[预报接口](https://open-meteo.com/en/docs)、[城市搜索](https://open-meteo.com/en/docs/geocoding-api)。当前个人开发使用免费非商业接口；商业化前切换供应商套餐。
