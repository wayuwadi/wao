# 正文编辑器实时字数

- 所有使用统一 MarkdownEditor 的输入入口（小记、知识库文档、任务描述、聊天等）在正文底部显示当前字数；空内容显示 0 字，只读及保存期间保留统计。
- 按正文可见字符统计，中文、英文字母、数字、标点及完整 emoji 均按一个字形计数；空白、格式标记、图片地址及附件元数据不计入。悬停显示统计口径。
- 初次装载、输入、删除、粘贴、撤销/重做、草稿恢复及外部正文替换均更新；选区变化不重新计算。窄屏不溢出，长内容滚动时在底部保留统计。
- 选中正文文字时，在相同位置显示“已选中 X 字 · 全文 Y 字”；取消选中后恢复“Y 字”。选中字数沿用正文统计口径，随选区变化实时更新；只选中空白或表格单元格时不显示选中字数。
- 统计只读当前正文，不修改保存、草稿、协同或接口，不代表历史累计创作量。

## 固定工具栏页面的可见性修正

- 小记详情和知识库文档使用独立工具栏时，字数显示在顶部固定工具栏下方右侧，不再随正文滚出视口；只读、保存期间同样保留。
- 内嵌编辑器继续保留底部字数，统计区域不得被弹性布局压缩；统计口径和保存行为不变。
