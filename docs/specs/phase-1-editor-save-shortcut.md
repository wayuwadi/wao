# 规格：编辑时保存快捷键行为

对应任务：`t1786943678029`（编辑笔记时不打开浏览器“另存为”）。

## 问题

知识库文档、小记和任务描述已有自动保存或明确的页面内保存流程，但用户按下习惯性的 `Ctrl+S` 时，
浏览器仍会打开网页“另存为”窗口，打断正在进行的编辑。

## 规则

- 登录后的 WAO 应用壳统一拦截 `Ctrl+S` 与 macOS 的 `Command+S`，不打开浏览器“另存为”。
- 拦截在输入框、文本域和富文本编辑器获得焦点时同样生效。
- 快捷键只阻止浏览器默认行为，不额外发起一次写入；正文继续沿用所属编辑器的自动保存、草稿防丢和失败重试流程。
- 登录页和公开分享页不挂载应用壳，因此不改变这些公开页面的浏览器快捷键行为。

## 验收

- 在知识库文档、小记或任务描述中编辑时按 `Ctrl+S`，浏览器不出现“另存为”窗口，编辑内容不丢失。
- macOS 下按 `Command+S` 得到相同行为。
- 不带修饰键输入字母 `s` 时，正文输入不受影响。
