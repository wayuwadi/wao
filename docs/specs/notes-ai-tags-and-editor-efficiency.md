# 小记智能标签与编辑效率

本规格补充小记 AI 自动整理、图片总览、小记筛选与阅读模式的编辑约定，不改变历史文档内容和标签权限。

## 标签选择与自动推荐

- 全屏编辑时默认显示最多 6 个快捷标签；正文输入 `#` 打开成员已有标签候选。候选以浏览器本地、成员隔离的使用频次和最近使用时间排序，选中后将标签加入小记并在正文插入 `#标签`。编辑区提供低对比度的“输入 # 选择标签”提示。
- 新增标签使用标签行内的加号，展开小输入框；回车创建并选择标签。已存在标签可通过快捷标签切换，也可从标签候选插入。
- 新建小记的标题、正文润色和配图沿用成员个人偏好；存在已有标签时，保存后自动推荐标签并入整理流程。推荐 1–3 个小记标签字典中已持久化的标签，服务端重新校验当前标签清单，过滤模型返回值，仅允许逐行精确匹配的现有标签进入响应。不得新建标签。
- 智能标签使用持久只读 `/api/text-polish/jobs` 的 `NOTE_TAGS` 类型，幂等请求包含正文与允许标签清单摘要。任务状态及成员现有标签清单保存在该成员的小记自动整理记录中。写回前检查文档版本与本地草稿；使用 `expectedRev` 合并标签，不覆盖用户已有标签。失败可重试，正文保存结果不回滚。
- 阅读模式显示标题、配图、润色、标签四类处理状态；只有失败状态提供重试。

## 图片、筛选和阅读操作

- 小记图片在正文中保持原始顺序与插入位置；编辑器限制大图显示高度。点击图片可查看大图，右键可复制图片或地址。
- 小记标签、作者、图片、更新时间筛选与排序方式在当前浏览器按成员保存，刷新恢复上次选择；清除筛选会保存默认值。输入搜索词、分页和阅读位置不持久化。
- 阅读模式中，← / → 切换上一条 / 下一条小记；↑ / ↓ 在当前文章内滚动，PageUp / PageDown 按较大步长滚动。Esc 退出阅读模式，图片预览打开时忽略阅读快捷键。

## CLI 与工作区权限评估

`NOTE_TAGS` 是保存后小记的上下文编辑步骤，输入依赖单篇已保存正文及当前小记标签字典，写回还要求当前文档版本匹配。它不提供独立批量终端操作，因此不新增 `wao` CLI 命令或工作区 MCP 工具，也不扩展旧令牌权限。若未来提供批量小记标注，再另行设计有界选择、版本冲突与授权审计。
