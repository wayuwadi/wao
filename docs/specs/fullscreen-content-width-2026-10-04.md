# 全屏与文档正文宽度

根据用户的后续优化，修订 `notes-width-mode-2026-10-04.md` 中新建与卡片编辑均显示宽度开关的规则，及 `notes-reading-columns-2026-10-04.md` 的固定全屏正文宽度。

- 普通新建、卡片内编辑、快速输入不显示宽窄屏开关，也不因已保存的窄屏偏好缩窄容器。
- 全屏编辑顶部保留宽屏/窄屏开关，宽屏最大 1100px，窄屏最大 650px。
- 全屏阅读顶部提供相同开关，中间正文宽屏最大 1100px、窄屏最大 650px；左侧目录与右侧图片清单保持三栏。侧栏速览不显示开关，仍使用原布局。
- 知识库文档操作栏提供开关；宽屏沿用可用容器宽度，窄屏正文和标题最大 650px 居中。知识库首页及文档目录保持原布局。
- 复用既有按成员隔离的浏览器宽度偏好，同成员的全屏编辑、全屏阅读、文档同步；不写入正文或服务端偏好。
- 切换不重建编辑器、不修改正文、JSON、图片尺寸、撤销记录或草稿；按钮可键盘访问，窄屏自然收缩并保留操作入口。

仅浏览器布局变更；没有服务、API、数据库、CLI 或 MCP 能力变化。
