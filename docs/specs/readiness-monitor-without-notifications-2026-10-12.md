# 就绪检查停止飞书通知

- 日期：2026-10-12
- 来源：用户要求取消截图中的「WAO 基础设施告警」通知。
- 取代范围：ADR-333 中连续失败、恢复、去重及重试的飞书通知行为；原 ADR 保留历史记录。

云端 `wao-health-watch.timer` 继续每分钟检查唯一在役公网 `/api/edge/ready`。保留真实健康结果、连续失败计数、发布窗口与退出码，供日志排查；失败和恢复都不再发送飞书消息。

监控脚本移除 webhook 请求和消息生成，systemd 服务不再加载通知凭据。既有私有配置文件与历史聊天消息不删除，其他功能的飞书通知沿用自身配置。

下一轮采样清理状态中的旧 `notified` 和 `sent` 字段，并写入 `notificationsEnabled=false`。不能为消除告警将实际失败写成健康，不能关闭业务服务或提升数据库。

本地验收覆盖持续失败、恢复、旧告警状态与通知配置残留；核对真实公网就绪。通过既有云端授权通道原子安装脚本与服务单元、保留备份，核对实际脚本哈希、服务配置、定时器及下一轮采样。云端监控安装独立于 Windows Jenkins 应用发布。
