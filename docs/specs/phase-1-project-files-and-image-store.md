# Phase 1：项目文件与图床

对应任务：`t1788145591957`。

## 用户结果

1. 项目详情提供“文件”页签，可上传并查看当前项目的普通文件、Markdown、图片与单文件 HTML；所有正文复用全局“文件与图床”的真实存储。
2. Markdown、图片和 HTML 均可在 WAO 弹层内预览；HTML 在隔离 iframe 内运行，不跳出系统，也不能读取 WAO 登录态。
3. 普通文件继续复制带人工确认和一次性票据的公网分享链接；图片与 HTML 继续使用原有公网地址。
4. AI Run 生成的 HTML 报告自动归入运行所属项目，并仍出现在全局网页托管列表。

## 数据、权限与失败边界

- 三类资产只增加可空 `project_id`；历史资产保持“未分类”，不根据名称或上传人猜测项目。
- 项目列表和项目上传先校验当前成员对项目可见；公开下载、图片与 HTML 分享行为不变。
- 项目上传复用普通文件 50MB、图床 10MB、HTML 10MB 等现有服务端上限与格式校验；失败时保留当前页并显示可重试原因。
- Markdown 只读取 2MB 以内的 UTF-8 `.md` / `.markdown` 或 `text/markdown`，由统一净化渲染器展示；未知二进制不伪装成可预览内容。

## 验收

- 在任一可见项目打开“文件”，分别上传 Markdown、图片和 HTML；三项只出现在当前项目，同时在全局“文件与图床”可见项目标识。
- 点击 Markdown“预览”看到净化后的正文；点击图片或 HTML 后在当前 WAO 页面弹层查看，关闭后仍停留原项目。
- 复制三类资产分享地址后，普通文件仍进入下载确认页，图片和 HTML 仍能通过公网只读链接打开。
- AI Run 报告上传成功后，在运行所属项目的 HTML 列表和全局“AI Run 报告”筛选中都能找到同一公开地址。
