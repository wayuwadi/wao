# Phase 1：成员每日情境建议

对应任务：`t1786619457834`。

## 用户结果

1. 登录成员打开首页即可看到“给此刻的你”；建议来自本人真实未完成任务，而非前端 fixtures 或固定 seed。
2. 当任务体现次日入职、新团队或岗位变化时，建议至少覆盖合适心态、快速融入团队、发挥自身优势和一个当天行动。
3. 同一天刷新或换设备直接恢复已生成建议，不重复占用 Codex；用户主动点击“换一组”时才覆盖当天结果。
4. 首次读取、生成中、成功、生成失败、本地 Codex 离线都有明确状态；失败和离线都可原地重试。
5. 页面只说明已使用本人 WAO 任务上下文，不声称读取未授权资料；AI 不得伪造上下文中不存在的工作经历或团队信息。

## 验收标准

- `GET /api/daily-guidance` 返回当前成员当天缓存，或 `missing` / `unavailable` 及真实原因。
- `POST /api/daily-guidance?refresh=false` 在没有当天缓存时生成；已有缓存时幂等返回。
- `POST /api/daily-guidance?refresh=true` 重新生成并覆盖当天缓存。
- 上下文只查询 `owner_id = 当前成员` 且状态不是“已完成”的 Task，最多向 Codex 提供 12 条及其真实 Project 名称。
- 建议生成复用 `ai_assistant_run` 与只读 Codex Runner，不写入成员私人聊天历史；运行完成后清除提示词。
- 前端对 AI 返回的 Markdown 使用统一净化渲染，移动端保持正文、重试和刷新入口可见。
