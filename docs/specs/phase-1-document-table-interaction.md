# 规格：文档表格安静编辑与按需操作

## 用户结果

- 单击单元格、在单元格内输入或按 Tab 切换，只聚焦内容，不弹出表格操作工具栏。
- 在同一表格选中多个单元格时，显示一个横向选区工具栏并明确高亮选区；普通文字选区继续使用格式工具，不混入表格结构操作。
- 右键单元格显示表格菜单；在已选中的多个单元格内右键保留整组选区，在选区外右键只操作命中的单元格。
- 菜单提供向上/下插入行、向左/右插入列、删除行列、切换表头、合并/拆分单元格和删除表格。不可执行的操作置灰，删除操作与普通操作视觉区分。
- 右键菜单与划词工具栏互斥。菜单首次可见时已经位于视口内，窄屏和低高度窗口可滚动；Esc、点击外部、正文滚动、切换只读和卸载都会收起菜单。
- Shift+F10 可在表格中打开菜单；菜单支持方向键、Home、End 和 Enter，Esc 返回编辑器。Tab/Shift+Tab 沿用表格与代码块自身的键盘逻辑。
- 每次表格结构操作是独立的撤销步骤，不与前一次插表或后续文字输入合并。

## 文档体验范围

本轮按用户确认优先对齐日常编辑手感：安静输入、右键操作、划词格式、键盘操作和保存反馈。继续采用 ADR-198 的版本化正文、自动保存、本机草稿、失败重试和冲突保护；评论与字符级实时协同另行推进。

本规格修订 `phase-1-document-selection-actions.md` 中表格操作的触发条件，不覆盖历史规格。参考飞书文档的按内容提供操作入口与所见即所得方向，不宣称功能全量一致。

## 验收

- 单击空/非空单元格不弹菜单，文字仍可输入；选中文字可改格式。
- 多选空白或有内容的单元格均有高亮和工具栏；右键范围保持正确，合并后拆分、插行后撤销不丢数据。
- 鼠标右键、键盘打开、Esc、点击外部和窄屏边缘定位均真实操作验收。
- 文档编辑后自动保存，刷新仍保留表格及文字；保存失败和恢复路径沿用既有文档回归。
- 通过相关测试、类型检查与生产构建，按 PR 合并、发布上线、线上验收完成交付。
