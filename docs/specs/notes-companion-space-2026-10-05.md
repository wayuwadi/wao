# 小记编辑区与伴读空间

补充 `notes-ai-companion-2026-10-05.md`，替代其左侧固定高度分配。用户授权按推荐 Demo 实现并直接部署。

- 桌面（超过 1100px）左上记录、左下伴读、右侧小记不变。编辑区默认占可分配高度 65%；移除旧 370px / 正文 220px 上限，编辑器在区域内滚动。
- 上下分隔线有 16px 命中区域，拖动立即分配高度。通常保留编辑区 230px、伴读 200px；极矮窗口采用受限比例并在区域内滚动，禁止固定最小高度造成页面溢出。调整窗口只约束显示比例，不覆盖用户偏好。
- 分隔线可聚焦，上下键调整 1%、Shift 加上下键 5%；双击 / Home 恢复 65%，End 调至可用最大值。指针释放、取消、失焦、窗口变化、收起、阅读浮层及卸载均停止拖动并清理监听。
- 伴读右上角提供收起。收起后在左侧底部显示 44px 全宽入口，编辑区使用其余空间。入口展示真实执行 / 排队 / 新成果状态，无数据时只写“随时继续”；新结果不自动展开。
- 点击底部入口恢复上次比例、栏目、选择、问题和滚动位置。布局变化不销毁编辑器与伴读实例、不清空草稿、不触发 AI、不修改模型、预算或采用策略。后台执行继续；折叠内容不计已读。
- 明确点击卡片伴读 / 新成果时展开对应内容；阅读伴读继续作为独立浮层，打开、关闭不改变原桌面收起偏好。手机保留现有紧凑入口与全屏伴读，1100px 以下隐藏上下分隔线并上下排列。
- 高度比例和收起状态保存在当前浏览器成员隔离键 `wao-notes-companion-layout-v1:<member>`，刷新恢复。损坏回默认，存储失败提示重试且当前页面仍可使用；切换成员不继承私人偏好。
- 既有左右宽度拖拽保留。本次不改变 HTTP、数据库、CLI 或 MCP 能力。

验收：覆盖拖拽和键盘、取消与卸载、成员隔离、短窗口约束、折叠未读、草稿与栏目恢复、阅读浮层、真实数据页面及手机断点。
