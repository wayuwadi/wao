# Phase 1：得到大脑音视频纪要入口

对应任务：`t1787802840545`（上传录屏并由得到大脑产出会议纪要）。

## 用户结果

- 已登录成员在 WAO 左侧“工具”分组看到“得到大脑”，点击后使用新页面打开得到大脑官网。
- 成员在得到大脑完成登录、导入音视频、AI 转写和纪要查看；音视频及结果由得到大脑账号持久化。
- 入口不嵌入 WAO 页签，避免跨站 Cookie、CSP 或登录跳转导致页面不可用。

## 当前能力边界

- 得到大脑网页和 App 支持导入 MP3、WAV、M4A、MP4、MOV、AVI 等音视频，并生成转写和总结笔记。
- 截至本规格落地时，官方 OpenAPI 只开放纯文本、链接和图片笔记写入，以及既有笔记、音频原文和总结读取；
  官方 Skill、MCP 和 CLI 也未公开“上传本地音视频并触发转写”的稳定接口。
- 因此 WAO 本阶段不接收视频、不保存第三方账号凭据、不伪造上传进度或纪要结果，也不使用浏览器自动化绕过官方接口。
  官方开放音视频上传、任务状态与结果读取接口后，另立规格实现自动闭环。

## 注册表升级与验收

- `navigation.external-apps` 注册表升级到 v4；v1 至 v3 在读取时补入 `getnote`，已升级到 v4 后允许管理员隐藏或删除，
  后续读取不得再次恢复。
- 新入口固定使用 `https://www.biji.com/`、`NEW_PAGE` 和空健康检查地址；外部站点可用性不冒充 WAO 服务健康。
- 注册表接口失败时，前端安全默认值仍包含“得到大脑”；接口成功返回的显式空列表继续代表不展示任何外部应用。
- 验收覆盖旧注册表升级、升级后删除不恢复、设置页可管理入口、侧栏点击新开官网，以及官网真实到达。
