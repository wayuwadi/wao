# WAO → WeKnora 内容同步

## 用户目标
WAO 的业务内容自动进入 WeKnora，支持夜间定时同步、手动触发、运行记录和后续扩展。

## 产品行为
- WeKnora 入口增加「内容同步」。WAO 为唯一事实来源；独立的「WAO 同步知识库」保存派生副本，源链接可回到 WAO。
- 所有已登录成员可打开同步中心、查看共享运行状态并手动入队；仅系统管理员可修改连接、范围与计划。同步内容仍固定属于配置者，其他成员的私有内容不进入目标库。凭据加密保存且接口不回传。
- 默认每天北京时间 02:00，可修改、暂停；手动触发异步返回，重复点击复用待执行或运行中的任务。
- 各内容适配器显式声明字段和权限，不遍历所有数据库表。页面给出每类实际数量及不支持的类型，不能将索引副本描述成数据库备份。
- 增量比较正文指纹；远端文档保存稳定来源标识。重试、重启及请求响应丢失时先核对远端，再更新，不制造重复副本。
- 默认每轮最多 20 篇变化文档，串行提交；未处理数量可见，下轮继续。未变化内容不重新调用模型。Wiki 异步处理状态与传输成功分开显示。
- 删除及取消范围仅影响本集成创建的副本；先核对完整源清单，源读取失败不得推断删除。删除同步可关闭，默认开启；不触及手工资料。
- 无 Embedding 时采用 Wiki-only 目标库；同步不等同于问答已经可用，页面说明 Wiki 生成仍调用已配置模型并可能计费。
- 附件在正文中保留来源引用，二进制、图片识别、原始运维日志、凭据及内部状态不作为文本批量发送。后续以独立适配器增加文件解析，不冒充已同步文件内容。
- 配置草稿持久化但 API Key 不进入浏览器持久存储；轮询只更新运行状态，不覆盖输入。保存失败保留草稿，可重试。

## 验收
真实配置连接、范围预览、手动同步、远端内容及源链接、第二轮跳过未变化项、失败可见、夜间调度配置、权限边界、双节点互斥和重启恢复。新增/修改/删除及失联重试使用受控测试夹具验证。

## 当前适配范围

| 内容类别 | 导出方式 |
| --- | --- |
| 知识库、随手记、项目、任务、点子及迭代 | 显式字段转 Markdown，保留层次和稳定来源 |
| 共享聊天、AI 助手、AI 执行公开对话 | 聊天按天、对话按会话整理，长正文分段 |
| 已发布统一记忆、项目记忆、个人生活记忆 | 只读取正文与证据，个人记录限定配置者 |
| 行动计划、行动项、打卡、每日记录、人生回顾 | 业务事实与复盘文本 |
| 英语学习、生词本、文字润色、天人日课 | 学习和记录文本 |
| 个人工作台、饮食、形象、画图 | 结构化内容提取可读文本，图片不冒充已识别 |
| 家庭重要日期、日历、托管页面、已发布 Skill | 日期事件、页面可见文本、已发布说明正文 |

共 28 个显式适配器，数量来自当前权限范围；来源预览可以核对导出内容。成员凭据、API 账号、密钥库、会话 Token、模型配置、二进制包、原始日志、指标时序和内部队列不导出。新业务模块通过注册适配器扩展，不自动放行新表。
