# 规格：每日节奏固定保存入口

对应任务：`t1788483771537`。

本规格调整 ADR-186 第 5 条中每日面板保存入口的位置，仍保留每日面板与其他节奏配置各自的保存接口。

- 四个配置分类的保存按钮统一放在弹窗固定底栏，替换“稍后再说”；表单滚动时保存入口始终可见。
- 每日必做使用“保存每日面板”，其余分类使用“保存节奏”，不将不同存储误示为一次原子保存。
- 每日面板未加载成功或正在保存时禁用提交；保存中不能通过关闭按钮或遮罩关闭弹窗。
- 每日面板保存成功和失败在固定底栏显示；失败保留表单，允许原位重试。
- 验收覆盖长清单、滚动后点击保存、重新打开后读取、其他分类保存入口回归。
