# 浏览器版本更新亮点与功能探索

日期：2026-09-27。本规格取代 `changelog-v1.md`、`discovery-maturity.md` 和 `navigation-preview-order.md` 中将 `changelog` 视为长期示例预览的要求；这些文件继续保留历史决策与验收记录。真实交付时间线仍以 `phase-1-update-diary.md` 为准。

## 用户结果

1. 浏览器发现公共网页新版本后，成员点击“保存并更新”；只有全部工作区草稿和页面表单安全落库后才刷新。
2. 刷新进入新前端制品后，如果该发布批次有精选说明且成员未读，展示一次全屏更新介绍。成员可以逐条浏览、进入对应功能、稍后再看或关闭。
3. 更新介绍的完成页进入“功能探索”：上方展示当前制品的精选变化，下方按目标浏览 WAO 已经存在的新旧全部功能。
4. “设置 → 版本与更新”始终提供“查看本次更新”和“探索全部功能”，自动介绍被跳过后仍能主动找回。
5. `/updates` 继续只展示真实成功交付事件；功能探索不替代或伪造更新日记。

## 入口与兼容

- 稳定功能 id 继续使用 `changelog`，成员已有的显隐、分组、排序和自定义名称不重置。
- 主路由改为 `/features`，导航默认名称为“功能探索”；旧 `/changelog` 永久重定向到 `/features`。
- 只维护浏览器版 WAO，不恢复桌面客户端发布说明或独立更新流程。

## 内容来源

- `data/featureCatalog.ts` 只补充功能分类、用户收益、详细说明、视觉色调和推荐入口；名称、图标、路由继续读取 `MODULES`。
- 目录只收录已有真实浏览器路由，不使用规划能力、随机数据或接口健康状态填充。
- 当前发布批次 `CURRENT_RELEASE` 随不可变前端制品构建；`id` 变化代表一批新的精选说明。没有用户可感知变化时不修改 `id`，普通工程发布不会重复打扰。
- “NEW”只出现在当前发布批次精选区域，不永久写进功能目录。
- 更新文案由代码评审确认；AI 可以协助起草，但不能仅根据提交标题自动公开。

## 触发与已读状态

- `VersionUpdateNotice` 将目标网页版本传给现有工作区保存屏障。
- `App.vue` 仅在两次工作区落库、页面保存回调和 `beforeunload` 检查全部通过后，把目标版本写入当前标签页的 `sessionStorage`，随后刷新。
- 更新介绍 Host 只消费一次这份安全刷新标记；普通首次登录、直接访问、手动刷新不会自动弹出。
- 已读状态复用成员级 `/api/preferences/release-highlights-state-v1`，并保存本机成员隔离回退，偏好暂时不可用时不会循环打扰。
- “稍后再看”只关闭本次自动介绍，不写成已读；“关闭”“完成”或进入功能探索记录已读。成员仍可从设置手动重开。

## 失败与恢复

- 任一草稿保存失败：停留当前页面，不写刷新标记、不显示新版本介绍，沿用现有错误提示与重试。
- 已读偏好读取失败：允许展示已确认进入的新制品；关闭时先记本机状态。
- 已读偏好保存失败：不阻止关闭，明确提示尚未同步到其他设备。
- 功能卡片只打开 `MODULES` 内稳定路由，不接受清单提供任意外部 URL。

## 体验与无障碍

- Tour 支持左右方向键、Esc、明确焦点样式、关闭后焦点恢复和 `aria-modal`。
- 桌面使用轻量 CSS 层次和透视，窄屏改为单列；`prefers-reduced-motion` 下移除位移动效。
- 功能目录支持分类胶囊、查看更多、键盘打开详情和返回浏览；长标题不遮挡主要操作。
- 展示图由已有功能图标和 CSS 场景生成，不依赖第三方图片或运行时截图。

## CLI 与 MCP 边界

本期是浏览器展示和成员界面偏好，没有新增业务操作、HTTP API、数据库结构、MCP 工具或 CLI 命令。`wao-cli` 与工作区令牌能力不变；以后若新增后台编辑、分群发布或发布说明审核服务，再同步评估 CLI / MCP 和权限台账。

## 验收

1. 保存失败与表单阻止离开时不刷新、不记录待展示版本；成功链路刷新后只自动展示一次。
2. 跨设备偏好已读时不重复自动弹，设置页可以主动重开。
3. Tour 依次展示欢迎、3 条精选和完成页；稍后、关闭、功能跳转与全部功能入口结果明确。
4. `/features` 展示当前精选、全部真实目录、分类筛选、查看更多、详情和站内跳转；旧 `/changelog` 重定向。
5. `/updates` 原有真实时间线、加载、错误重试和空状态不回归。
6. 390px 无横向滚动，深浅主题内容可读，减少动效生效；组件卸载后移除事件监听并恢复页面滚动。
