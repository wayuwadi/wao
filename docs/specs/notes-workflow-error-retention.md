# 小记未解决阶段的失败原因保留

补充 `notes-workflow-stage-failure.md`，沿用单份最新正文、既有阶段状态与失败重试接口。

- 一个阶段开始、完成或跳过时，不能清空其他仍处于 FAILED 的阶段的最近失败原因。
- 只保存标题且配图或润色仍失败时，保留原失败提示。正文改变导致旧任务失效、所有失败阶段重新等待时，清除旧提示。
- 重试只复位失败阶段，并清除原失败提示；已经完成的阶段不重做。
- 当前数据库只保存一条最近失败原因。当多个阶段失败、其中一个被用户操作解除时，无法证明这条原因属于哪一个阶段，改为提示剩余失败阶段可重试，不把已解除阶段的原因误归给其他阶段。
- 本次不追溯补写历史已经丢失的原因，不新增数据库字段、HTTP API、CLI、MCP 或权限，不声称一次提示包含所有失败原因。

验收见 [失败原因保留验收](../validation/notes-workflow-error-retention-2026-10-03.md)。
