# 小记列表移除顺手发现提示条

2026-10-10，用户明确要求删除截图中位于搜索工具栏与小记清单之间的 AI 发现提示条。本规格取代 ADR-314、《小记顺手发现》及《支持关闭小记顺手发现提示条》中关于默认列表展示发现条的规定。

- 小记默认列表从搜索、筛选与排序工具栏直接进入列表状态和正文卡片，不再展示顺手发现或其撤销提示，不保留占位区域。
- 打开列表、滚动、新建与编辑保存不再读取当前发现；移除列表专用的每分钟轮询、延迟插入及位置补偿。
- 已收藏的发现、旧版生成内容及来源校验继续通过现有主动入口访问；保留历史产物、反馈、图片和成员偏好。
- 本次只调整浏览器列表，不改变后台生成服务、API、CLI/MCP 权限或正文、草稿和 AI 润色等独立能力。

验收覆盖真实小记搜索、筛选和阅读，以及明暗主题、窄屏与键盘。现有小记测试更新为即使服务端存在发现，默认列表也不加载或显示它，列表保存和刷新仍正常。

- `NotesView.spec.ts` 的 106 项测试通过，包含已有发现不加载、不展示、刷新及重开后仍不展示，以及从收藏入口打开来源时的成员切换隔离。
- `npm run ui:check -- --base origin/main` 通过；版本说明 JSON 与 `git diff --check` 通过。
- `npm run build` 通过，包含类型检查与生产构建；首次检查缺少游戏模块的 Vue 依赖，补齐仓库锁定依赖后通过。构建仍报告现有大文件体积提示。
- 浏览器真实链路、明暗主题、窄屏和键盘尚未验收：本次环境未提供可用浏览器控制通道，也没有已配置的本地业务服务连接。保留这些缺项，交付前补齐，不以构建或单测代替。
