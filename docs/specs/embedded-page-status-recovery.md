# 外部页面载入与可用性区分

审计 A11，遵循 ADR-039。外部应用和快捷链接 iframe 的 load 事件只显示“页面已载入”，不用绿色连接成功暗示已登录或业务可用。外壳持续说明白屏、登录或无法嵌入时可独立打开。

等待15秒没有load时说明加载较慢并移除遮挡，保留原iframe继续加载，不自动重载或中断应用。手动重新加载重新计时，离开时清理计时器。快捷链接增加error事件的错误说明与重试。已有健康检查、URL限制、身份共享和浏览器嵌入策略不改变；没有应用ready协议时不猜测业务状态。

外部知识库的内部同步组件不修改，本次仅调整通用嵌入外壳。

验收：9项针对测试覆盖载入文案、超时后保留iframe、重试重新计时、快捷链接错误恢复和既有配置行为；类型检查与构建通过。本地真实数据库读取注册表与快捷链接：外部应用健康失败保留原原因；真实仓库嵌入超过15秒显示慢加载说明，独立打开链接指向已保存地址。浏览器工具未返回独立窗口，未声称验证目标站登录或业务功能；本次不改变目标站或浏览器安全策略。
