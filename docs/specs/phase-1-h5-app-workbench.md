# Phase 1：H5 应用壳、个人底栏与工作台

对应任务：`t1787886569595`（手机端重新设计）。本规格只重组手机入口与登录保持方式；各业务页继续使用
既有真实 API 和已有移动端交互，不复制数据、不创建演示页面。

## 用户结果

1. iOS 与 Android 浏览器可把 WAO 安装到主屏幕，并以独立应用窗口打开；项目、任务、小记和其余功能仍
   使用线上同源接口。
2. 手机底栏默认只放「项目」「小记」和固定的「更多」，避免把整套桌面导航横向挤进拇指区。
3. 每名成员可从「更多 → 工作台 → 编辑手机底栏」选择最多四个常用入口；配置通过
   `/api/preferences/mobile-bottom-nav-v1` 按成员跨设备保存。底栏长按 420ms 后可直接拖动排序并立即保存。
4. 「更多」始终可见，打开包含全部内置功能、真实接入应用和成员快捷链接的工作台；即使某入口未放在
   底栏或被全局侧栏隐藏，仍能从工作台找到。
5. 登录成功后 `WAO_SESSION` 使用 HttpOnly、Secure（生产）、SameSite=Lax 的 30 天持久 Cookie；服务端
   共享会话也以 30 天不活跃超时失效。显式退出仍立即删除会话。

## 状态与边界

- 底栏配置覆盖读取中、保存中、已保存和失败重试；损坏、空值或首次使用回退到「项目 + 小记」。
- 固定「更多」不占四个自定义名额；至少保留一个自定义入口，避免底栏退化成单按钮。
- 编辑底栏只改变当前成员的手机入口，不修改管理员维护的全局菜单注册表，也不影响桌面侧栏。
- 不注册缓存私有响应的 Service Worker。安装形态不代表离线能力；断网继续显示既有失败与重试状态。
- 原生 iOS 客户端继续存在；本任务新增的是用户明确要求的跨 iOS / Android H5 安装入口，不以 H5 冒充
  原生包，也不删除原生工程。

## 验收

- 390px 视口首次登录看到「项目 / 小记 / 更多」，按钮不横向滚动且位于安全区上方。
- 点击小记打开既有真实小记表单；点击更多进入工作台，能打开侧栏隐藏的真实模块。
- 编辑底栏选中、取消和超出四项限制都有明确反馈；保存成功后底栏立即更新，刷新后从成员偏好恢复。
- 在底栏长按入口后拖到另一入口位置，顺序即时变化并持久化；普通轻点仍正常导航。
- Web App Manifest 声明 `standalone`、WAO 名称、图标、项目与工作台快捷入口；iOS 专用主屏幕元信息完整。
- 登录后关闭浏览器或主屏幕应用再打开仍可恢复会话；30 天未活动或显式退出后需要重新登录。
