# 首页底边四个伙伴

用户在交互 Demo 后确认 A「底边探头」布局，要求精修并接入首页。本规格补充首页现行布局，保留四等分真实信息卡、天气、原有文案、休息与功能入口，以及中央留白。

## 交互与视觉

- 四个独立程序化三维毛绒角色沿首页卡片底边探头：蓝色画家、黄色书虫、粉色开心和绿色青蛙。参考用户提供的 dot 页视觉方向，自建轮廓、配饰和纤维，不加载外站模型；不声称逐像素复刻或具备智能体能力。
- 初始仅轻微呼吸、眨眼和目光跟随。轻点或键盘 Enter/空格得到简短回应；指针拖动有形变、倾斜与有界惯性，松手回到各自位置。邻居朝被拖动伙伴倾斜。取消指针、失焦捕获、Esc、离开页面均收口，不遗留拖动。
- 拖动限定下方伙伴区域，不覆盖信息卡与业务入口。透明画布不拦截背景操作；只有角色按钮拦截指针。触屏角色区域关闭默认滚动手势，其余页面照常滚动。
- 「安静陪伴」放在次要位置，桌面悬浮或键盘聚焦时出现，触屏可见。开启后停止自动动作及连续绘制，仍能轻点回应。遵循系统减少动态效果设置。设置只在当前首页组件生命周期有效，不新增个人配置中心。

## 性能与失败

- Three.js 场景按需加载，沿用既有依赖。限制像素比 1.5，空闲最多 30fps，拖动时跟随浏览器刷新；纤维仅覆盖可见半球，眼部小凸起减少纤维数。
- 后台、页面停用、离开可视区域停止动画帧；卸载清理帧、观察器、监听、定时器、几何体、材质与 WebGL 上下文。安静/减少动态效果下按需单帧绘制。
- 加载中先显示静态伙伴，WebGL 不可用或上下文丢失时保留可交互静态显示，提供「重试动效」。失败不阻塞信息卡与导航。没有新增 API、CLI、MCP、数据库或模型调用。

```powershell
npm.cmd run test:unit -- --run src/__tests__/companionScene.spec.ts src/__tests__/homeCompanions.spec.ts src/__tests__/HomeView.spec.ts src/__tests__/HomeOverviewCard.spec.ts
npm.cmd run build
```

本地正常登录验证真实首页信息卡、拖动回位、轻点回应、安静模式、原有入口、离开返回和 390 像素布局。结果见 [验证记录](../validation/home-companions-2026-10-03.md)。
