# 小记保存后自动整理

本规格更新 notes-single-latest-content 与 notes-passive-ai-visual-triad 的触发语义，原草稿保护继续有效。浏览器、人工快速收集从业务保存入口统一持久化信号；MCP 写入只使旧来源失效，不新增 AI 授权。仅正文实质变化创建新轮，标签、目录和重复提交不重做。手动标题保留；新文未输入标题可以自动生成，历史来源未知标题保守保留。

小记与全局设置复用三开关、模型、提示词和并发设置。沿用 note-ai-defaults-v1，缺省三开关开启，显式 false 保留。GET/PUT /api/docs/notes/ai-settings 采用配置指纹 CAS；读取失败不作为已保存默认值，失败保留草稿。聚合保存同事务，兼容偏好写入也经过该服务。正文提示词归一为 text-polish.prompt.v1。

关闭阶段递增取消代次，未启动任务不再执行，运行中的结果不得写回；重新开启不恢复旧代次。手动执行一次独立于自动开关。成员行锁串行化并发占用，调用在既有本机队列执行，浏览器关闭不影响。结果必须通过来源代次、任务归属与正文 CAS。

短标题/正文的 12/40 门槛取消；自动配图保留 80 字符保守门槛。整篇润色 12000 字符、配图 60000 字符超限明确提示；选段润色 4000 字符。不截断整篇润色。阶段原因区分关闭、手动标题、已有图、不适用、长度限制、等待名额、排队、运行、失败及来源更新。正文已保存与 AI 故障独立报告。

新增 note_ai_save_signal、note_ai_stage_attempt 记录来源、轮次、策略快照和执行关联；不修改历史 migration。不恢复 Runner，不扩大 MCP/CLI 权限，不固定开发模型。

## 保存路径及授权

小记页、顶栏浮层和首页纸条复用 NoteComposer → data.addNote → PUT /api/docs/notes/{id}。已有小记、完整文档页和通用创建最终进入 KnowledgeService 的事务。人工快速收集采用真实作者身份；MCP 的 create/update 使用 withoutAuto，保存及来源失效仍发生，不授予新的 AI 消费能力。旧 QuickNoteModal 不编排标题/正文/配图，标签推荐保持现有行为。

优先级为身份及文档权限、明确手动操作、成员已保存策略、单篇 false、手动标题/真实自动图/文字限制及执行条件。单篇 true 不能越过成员关闭。无工作流旧文实际改正文时建立来源；仅元数据或格式变化和相同正文不重建。历史标题来源未知保守保留。

## HTTP 契约

GET /api/docs/notes/ai-settings 返回 settings、version、configured、availability。settings 包含 title/polish/image、executionMode、maxConcurrent、model 和三提示词；关闭 epoch 是服务端字段，客户端不能自选。PUT 携带 settings 和 expectedVersion；409 时保留本地草稿，重新读取后明确保存。会话缺失返回 401，无默认成员回落。

思考深度作为同一成员设置的 `reasoningEffort` 字段保存，历史配置缺少该字段时明确按 `medium` 执行。表单在模型旁展示可配置档位，选项来自本机 Codex `model/list.supportedReasoningEfforts`；不支持的组合在入队前报错。新任务入队时将档位写入 `ai_assistant_run.reasoning_effort`，本机执行显式传 `model_reasoning_effort`；已入队任务保持原值，历史小记任务空值按 `medium` 执行。模型目录缓存升级前缺少档位数据时仅展示 `medium`，刷新成功后展示真实列表。该设置适用于小记本机标题、正文、配图、标签和自动发现；不改变天人一卦、Runner 或付费 API 的参数。

POST /api/docs/notes/{id}/ai-stages/{title|image|polish} 携带 expectedRev 和 32 位请求号；相同身份/文档/阶段请求重试返回原阶段，不重新消费模型。手动操作单独使用发起成员设置与并发名额，允许自动开关关闭时执行一次，不取消其他阶段。旧自动失败重试仍遵守当前开关。

工作流查询兼容原三阶段字段，增加 stages 的 reasonCode/message/retryable/action/jobId/sourceVersion。界面只读展示轻量状态。排队、成员名额和实际执行状态分别读取持久任务，不把等待名额冒称模型正在执行。暂不能读取设置的正文照常保存；只有重新保存或明确重试建立可确认策略。

## 数据与执行安全

V176 新建 note_ai_save_signal（文档唯一）及 note_ai_stage_attempt（轮次+阶段+尝试号唯一）。信号保存原策略、来源文档及用户代次；旧轮运行仍占并发名额直至模型终态。调度锁成员再处理文档，与业务保存保持锁顺序。每阶段稳定请求号关联既有本机任务，提交与入队同事务。

遗留 note_ai_workflow 的投影三阶段固定 SKIPPED，使并行旧服务不能再消费新信号；新查询按真实 attempt 发现待执行文档。写回同时核对当前轮、关闭 epoch、标题原值、实际正文指纹与文档 expectedRev；不同小记的接续不得误取消同成员另一篇。AI 派生写回不再触发同一自动循环。

Flyway 允许顺序之外的新增迁移，保留默认校验和验证；原因与依赖审查见 ADR-315。不得修改成功执行的迁移。
