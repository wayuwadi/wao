# 知识库工作区与固定导航

知识库采用三栏工作区：固定宽度的知识库清单、可调宽度的目录、文档正文。两侧独立折叠，不因折叠重建编辑器。目录同时保留嵌套文件夹及文档，首页提供全部授权知识库的目录索引与名称检索；选择知识库后复用其首页、目录编辑、设置与原有文档保存链路。

左侧可显式创建知识库；关闭创建窗口不自动创建，失败保留输入供重试。普通跳转使用 `/knowledge?kb=<id>&doc=<id>`，兼容既有 `/kb/:id?doc=<id>` 链接。

固定主菜单增加资源库和算一卦，原文件与图床显示名改为资源库。知识库与文档不再提供收藏到左侧菜单的入口。全局导航在没有已存偏好时默认收起，已有展开/收起偏好保持不变。

验证覆盖首页检索、文档打开、折叠保持编辑器、新建失败输入保留、默认导航与旧偏好，以及原目录、草稿和文档回归。手机两侧栏以可折叠浮层方式显示，避免挤压正文。

知识库主入口按账号/成员恢复最后打开的文档，位置标识保存在当前浏览器。显式文档链接优先，全部内容入口使用 home=1 主动进入首页；首次无记录仍展示首页。同一页签恢复原路由不重建编辑器，保持页内滚动位置。

默认展开通向分组的目录路径，末级分组的文档按需展开；文档作为上级节点时仍显示通往子分组的路径。打开指定文档会展开祖先，同一页面保留手动调整；首页索引仍展示全部授权内容。知识库清单标题旁的加号用于创建知识库。

## 总入口与目录体验（2026-11-06）

知识库总入口沿用三栏结构，清单以紧凑单行展示库名和文档数；首页按阅读索引排列知识库、文件夹和文档，文档行同时展示类型及真实更新时间。首页提供「全部内容 / 最近更新」切换，最近更新汇总当前授权库的文档元数据，按更新时间倒序展示，不修改实际目录排序。展示方式与查询按账号、成员及浏览器页签保存。

名称检索不区分大小写，覆盖库名、文件夹名、文档标题及当前本机标题草稿。命中知识库名称时展示其全部目录；命中文件夹或上级文档时带出其后代，并保留祖先路径。侧栏与首页共享查询，搜索时自动展开命中路径且不覆盖用户的折叠选择。首页支持 Ctrl/⌘ + J 聚焦搜索，文档编辑页面不拦截该快捷键。清空搜索后恢复目录折叠状态。已读取内容刷新时继续可用，读取失败独立显示重试，不将失败解释为空库。

首页每个库首批渲染 80 个目录项，按「显示更多内容」每次增加 100 项；最近更新首批 30 篇，按需增加 50 篇。检索始终覆盖完整已授权元数据，未渲染条目仍可直接查到。目录构建采用索引和迭代遍历，避免同级数组反复复制与深层递归；首页不解析文档正文，也不产生详情请求。

标题投影在正文草稿变化时保持引用，避免每次输入都重建目录；已进入文档时，外侧清单只计算数量，不重建全部目录索引。账号切换清空创建表单与当前浏览瞬态，旧账号创建回执不写回或跳转；离开工作区后创建请求仍可完成，但成功回执不强制拉回页面。失去知识库访问后，缓存索引和最近更新条目随授权目录移除，专注模式退出以恢复导航入口。

全部目录复用 `KnowledgeDirectoryTree`：单一 Tab 入口，↑/↓ 浏览可见节点，→ 展开或进入下一层，← 折叠或返回父级，Home/End 到已渲染首尾，连续字母键按名称跳转。Enter/空格沿原生按钮语义打开文档或折叠文件夹。文档拥有子节点时，文字打开文档，箭头只切换其子目录。节点显示有层级、同级总数和展开状态的读屏语义；触屏行高至少 44px。

目录组件每批显示 500 项，避免展开大文件夹时一次生成上万个按钮。Tab 可到「显示更多目录」，加载下一批后聚焦新增首项；搜索仍先对完整目录筛选再分批，末尾匹配可以直接出现在首屏。组件提供标题及尾部插槽和预加载事件，供单库首页复用相同层级与键盘行为并保留文档时间。目录检索可显式启用 `includeMatchedDescendants` 以带出命中节点下的内容，不改变其他调用方原有默认搜索语义。

本库文档侧栏同样以 500 项为一批，点击「继续显示目录」增加 500 项并聚焦新增首项。搜索覆盖完整目录后才截取当前批次；切库或修改查询重置首批，主动定位未渲染节点时扩展到其所在批次。此行为保留现有目录编辑和拖动入口，不把未渲染条目当作不存在。

900px 以下总入口用单行知识库切换栏，清单与全部目录默认收起，按需作为互斥侧栏覆盖打开，不再常驻两个窄栏挤压正文。打开后聚焦侧栏并暂时停用其后正文的键盘交互。点击遮罩、Escape 或选择内容关闭侧栏；Escape/遮罩关闭后回到触发器。桌面折叠偏好不因手机开关而变化。文档专注模式通过 `focus-change` 隐藏外侧知识库清单，保留编辑器实例与原折叠偏好。
