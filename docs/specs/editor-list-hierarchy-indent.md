# 小记列表标记与层级缩进

2026-10-04 用户进一步明确：缩进时，数字序号和圆点也要一起移动，体现完整层级。本规格修订 `editor-safe-selection-indent.md` 中首项无动作、混合列表仅缩进文字的规则；普通正文、图片、表格、代码与草稿保护继续沿用该规格。

## 列表操作

- 在有序、无序或待办列表中按 Tab，选中的多个兄弟项存在前一项时成为前一项的真实子列表；Shift+Tab 将真实子项提升一级，仍保持列表，不把根列表退成普通段落。
- 首项或整组选中时，没有前一项可成为父项：整组列表容器独立增加一级位置缩进，编号、圆点、待办框、内容、长行换行及既有子列表同时移动，不创建空白父条目。每级 24px，最多八级；窄屏实际左留白不超过容器宽度的一半。Shift+Tab 先减少容器独立缩进，回到零级后再按真实层级提升。
- 只选中首部或中间部分项时，必要时将列表拆为相邻片段，仅修改选中片段；有序列表保留原起始编号及编号样式。反缩进后的相邻片段只在列表类型、编号样式、位置缩进一致且编号连续时合并；原有默认有序列表顺延行为继续保留。不同位置缩进不合并。
- 混合选区中的列表逐组应用上述规则，不再向列表正文加 NBSP。选中父项时，其内部多段正文、图片及子列表整体跟随，不重复缩进子项；选区只在同一个子列表内时操作该层列表。列表项是整体语义单元：部分选中其内部普通段落，也按该完整列表项移动，未选中的同项上文与子块会随项一起移动，但相对结构保持。仅在同一个代码块内选择文字时仍按代码逻辑行缩进，不改列表层级；单独选中图片仍只改图片属性。
- 原有正文空白是用户内容，不自动清理。保留格式、链接、图片属性、选区方向与对应文字；一次缩进 / 反缩进是一个撤销步骤。只读不改内容；全屏焦点保护与表格内部 Tab 导航继续保留。非空选区不向无内容的自动尾段落添加空白，光标所在空行仍可缩进。

## 保存与兼容

沿用 ADR-198 的版本 1 JSON 事实源，为 `bulletList`、`orderedList`、`taskList` 添加 `attrs.indent`，默认 0，服务端仅对这三种节点接收 0–8 的整数，其他节点或文字标记不获得该属性，任意 style 仍拒绝。无数据库迁移，无新 HTTP、MCP 或 CLI 操作，不扩大旧令牌权限；已有文档保存能力负责持久化。

真实子列表继续采用标准 Markdown 嵌套。独立容器缩进用紧贴列表的不可见引用定义 `[wao-list-indent]: # "N"`（N=0–8）往返：有位置偏移时写入；相邻列表也写入定义，明确彼此边界，0 表示回到原位置。每条定义只消费紧随的一组列表，不通过全局重复引用值决定样式。普通独立零级列表的 Markdown 保持不变。编辑器、Markdown 阅读/分享按严格数字白名单生成布局，元数据不进入正文、标题与文字计数；普通 Markdown 阅读器仍可阅读列表，不显示元数据。浏览器与服务端白名单须同批发布。

## 验收

覆盖三类列表的多个兄弟项真实下沉 / 提升，首项与整组移动，部分选区拆分及连续编号回合，嵌套层级、父项子块整体跟随，混合正文/列表/图片，双向选区、单步撤销/重做、代码内选区、只读、全屏和保存失败保护。JSON 与 Markdown 保存回读保留位置和编号样式；非法属性、越界数字和任意样式拒绝。真实浏览器验收核对编号/圆点和换行块实际位置、刷新重开及失败重试，由本次验收记录补充。
