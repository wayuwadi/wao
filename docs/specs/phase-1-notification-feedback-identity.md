# 通知反馈人展示

依 ADR-214 补充 phase-1-feishu-scheduled-notification-feedback：

- 「做到了 / 没做到」记录经过现有鉴权的飞书回调 operator.open_id。
- 新提醒以共享卡片发送，按钮下汇总各成员最新选择，使用飞书身份标签显示真实姓名。
- 点击者不能通过 action.value 提供另一个人的姓名或身份；不以机器人原生表情代替个人响应。
- 重复点击幂等，每位成员只有一条最新反馈；不同成员互不覆盖。
- 旧卡片以原消息回复中的共享反馈卡兼容，重复点击更新同一回复。保留原卡，不把旧机器人表情重新解释为个人表情。
- 刷新失败提示「反馈已记录，显示失败，请重试」，实际选择仍可报表查询。
- 新卡更新保持发送时标题和正文。原通知删除/未知时拒绝新增反馈；任务后续删除不影响已发送新卡更新。

发送共享回复前保存原消息绑定；若上次发送成功但回执丢失，重试取得去重后的消息 ID 后仍刷新完整摘要，不能将旧摘要误报为最新反馈。
