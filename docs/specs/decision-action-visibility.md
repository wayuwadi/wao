# 决策管理：主操作与表单可见性

来源：产品体验审计 A03。沿用 ADR-182 和个人决策管理规格，不修改保存、版本、废止或权限规则。

## 问题与修复

页面引用不存在的 `--wao-accent`、`--wao-text-1`、`--wao-bg-soft`，主按钮最终成为透明底白字。改用现有主色、主色文字、正文和次级背景 token，不给全局补另一套同义变量。按钮与输入补充键盘焦点反馈。

## 验收记录

- 页面引用的所有 CSS 变量均在既有 token 文件中声明。
- 既有决策组件 7 项测试通过，Vite 生产构建通过。
- 本地前端连接既有数据库：空状态入口能打开表单，保存后刷新能读回专用验收记录。
- 浅色主按钮计算背景为 rgb(67,88,214)，深色为 rgb(91,111,232)，均不再透明；两种主题已截图检查。
- 390px 窄屏中保存按钮完整位于视口；键盘 Tab 聚焦后有 2px 可见边框。主题和临时视口恢复原值。
- 无后端、迁移、接口或弟弟负责的五个模块变更。
