# 小记恢复草稿后的原地保存

补充 `notes-ai-draft-coexistence.md`：版本保护必须提供把当前编辑保存到原小记的可执行入口。

- 浏览器草稿除版本号外保存编辑开始时的正文、标题和标签快照。收起、刷新或重开后仍以这份快照识别后台标题和配图更新，能安全合并时正常保存。
- 历史草稿没有可信快照、远端正文另有变化或双方编辑同一字段时，保持输入并自动展开最新已保存预览；预览包括标题、标签和正文。
- 提供“用当前编辑保存本篇”。用户核对后明确选择时，用刚核对过的服务器版本号保存到原小记；若版本再次变化，刷新核对信息，不自动覆盖新版本。
- 同时保留“保留为新小记”；不强制另存，不让“重试保存”陷入永久失败。
- 成功保存后更新编辑基线与版本号、清理已提交草稿，继续输入可再次保存。

验收覆盖有快照的恢复草稿与 AI 标题变化、旧草稿核对保存原篇、核对后版本再变化、保存成功后继续输入并再次保存。
