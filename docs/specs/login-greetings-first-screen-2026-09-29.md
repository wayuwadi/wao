# 登录页：角色问候、首屏自适应和单一登录入口

本规格按用户确认的优化要求补充并取代 `login-wow-stage-2026-09-29.md` 中的注册入口和首屏排版约定；认证服务、账号创建 API 与管理员创建账号能力不变。

- 登录页和登录弹窗移除所有注册入口。唯一舞台登录按钮放在右上角，与音效开关并排；手机同样保持可见。中央只呈现标题、文案与伙伴。
- 灵感“嘿，有新点子吗？”、记录“今天有什么想记下的？”、AI“准备好了，一起开工！”、行动“来，把想法变成现实！”、资料“你的积累，都在这里。”：鼠标 pointerenter、键盘聚焦/激活、手机点击均显示 3.2 秒问候气泡；触摸模拟 hover 不重复触发。
- 默认静音。用户最终要求只保留“文字气泡＋短音效”，不朗读问候，也不加载配音文件。主动开启后沿用各角色不同音高的合成轻响；同角色六秒冷却，音效播放中只更新气泡，不叠加、不排队。静音立即暂停，卸载释放音频；音效不可用不阻断气泡或登录。
- 首屏布局用视口高度分配标题、角色及留白，顶部登录与底部真实备案信息均保持可见。手机和矮屏同步压缩排版；横屏减少装饰性英文并将主标题合为一行。不以裁切业务内容换取没有滚动条。
- 原生登录弹窗独立滚动，最大高度跟随 visualViewport 的高度及偏移，适配软键盘与缩放。输入草稿、认证忙碌状态、失败重试及关闭焦点保持原有约定。

验收：桌面 1280×720、手机 390×844/320×568、横屏 844×390、矮屏 1024×480；主页面和舞台无溢出，登录入口及备案信息在视口内，角色可见可操作；弹窗在受限可视高度下可滚动至输入与提交；真实邮箱登录与刷新会话；默认静音、问候音效不叠加/冷却/不可用/卸载回归。
