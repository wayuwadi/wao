# 规格：手机端密码库查看与复制密码

对应任务：`t1785456686860`（手机端目前密码本没有查看和复制密码的地方）。本规格只覆盖密码库页面
在手机宽度下的布局与操作口径；服务端加密、按需解密接口和默认分组身份沿用
`docs/adr/009-vault-server-side-encryption.md` 与 `docs/adr/036-vault-default-group-identity.md`，不变。

## 为什么

密码库桌面版是固定宽度的三栏并排：分组 158px + 条目 252px + 详情自适应。手机上前两栏就吃掉了
410px，比常见 390px 视口还宽，唯一放着「查看」「复制」两个按钮的详情栏被挤出可视区。页面里原本
写着的 `@media (max-width: 760px)` 只处理了 `.vault-main`、`.toolbar` 这些当前模板里已经不存在的
选择器，等于没生效。用户的感受就是「手机上没地方看密码」——不是功能缺失，是入口不可见。

## 规则

- 手机断点沿用 `useIsMobile()` / `(max-width: 760px)`，与其它页面一致。
- 手机上密码库改成三段纵向布局：
  - **分组**变成一行可横向滚动的胶囊，不换行、不挤压条目列表；处于「分组管理」状态时恢复纵向排列，
    保证重命名输入框和删除按钮点得准（排序仍是 HTML5 拖放，触摸端不生效，本次不改）。
  - **条目列表**占满整宽，每行右侧给一个 `>` 提示可以点进去，行高不低于 56px。
  - **详情**不再是并排的第三栏，而是盖住整屏的一页，顶部固定「返回 + 条目名」，返回退回列表。
- 手机上**不沿用桌面「默认选中第一条」的行为**：只有显式点过条目才打开详情页，否则一进密码库就
  盖着一个没人点开的详情页，反而看不见列表。
- 详情页里的字段改成键名单独一行、值可换行：长密码整段折行显示，不产生整页或整栏横向滚动。
- 「查看」「复制」在手机上的触控尺寸不小于 40px；密码明文仍然只在点「查看」时按需解密一次，
  直接点「复制」时先解密再写剪贴板，列表接口不返回明文这一点不变。
- 切换条目、切换分组、保存编辑后，已展开的明文一律收回成掩码。
- 桌面布局不变，仍是三栏并排且详情默认落在第一条上。

## 验收

- 390px 宽度进密码库：先看到分组胶囊和整宽条目列表，没有详情页盖屏，页面无横向滚动。
- 点任意条目进入详情页，顶栏显示条目名；点「查看」出明文，点「复制」提示已复制密码。
- 不点「查看」直接点密码行的「复制」，同样能复制到明文（按需解密一次）。
- 长密码在 390px 下完整折行可见，详情页不出现横向滚动。
- 点顶栏返回键回到条目列表；「分组管理」在手机上排成纵向，重命名和删除都点得中。
- 桌面宽度回归：三栏并排，进页面即展示第一条条目的详情。
