# 工作区入口、通知与原生聊天完善

来源：[任务原文](https://wao.wayuwa.cn/api/share/tasks/t17890337995500.md?openOnly=true)。本规格补充现有原生聊天与客户端规格，不覆盖旧决策。

## 用户结果与边界

- 客户端标题栏以 WAO 标识替换“工作区”，移除正常连接时“工作区已打开”。网页左栏保留品牌，支持原生顶栏的客户端不重复展示；退休尚未实现的组织切换按钮。
- 新任务必须由服务端确认保存，才关闭表单并打开新任务详情；失败不跳转，重试沿用原任务 ID。所属项目和负责人改为紧凑选择框，仍支持默认项目、完整草稿与日程。
- 顶栏新建小记与兼容小记动作均关闭任务抽屉，进入 `/notes`。任务已有草稿保存逻辑继续保留。
- 通知中心列表与未读数共用规则，只展示明确 @ 当前成员的 WAO 聊天/任务评论，以及当前成员发起的已结束 AI Run。普通任务创建、完成、登录、旧通用群通知不再进入通知中心，历史源记录不删除。私有项目评论仅项目所有者或成员可见；不依赖飞书绑定。AI 成功/失败仍受个人设置控制，旧无效个人筛选入口退休。
- 组织目录收起线上核验过的“娃妹”“ChatGPT对话功能验收”“WAO-HUB 验收专用 armttk”，只留下娃哥、娃弟。新增 `member.directory_visible` 可逆字段，不删除历史业务、登录账号或外键引用；未来真实新建成员默认正常展示。
- 客户端 1.1.4 启动与每 30 分钟检查签名更新，无新版本不显示顶栏更新按钮，有新版显示黄点。点击即下载验签，期间不替换工作区；准备安装时提示保存工作。失败保留重试入口，菜单手动检查仍可用。
- 顶栏桌面宠物按钮切换独立窗口显隐；右键宠物本体打开聊天，左键保留已有工作区开关，拖动不误触。
- 任意页面顶栏聊天在移动端与桌面端均复用持久化 WAO 消息流，无需飞书。新增“文件”操作，使用现有 `/api/files`（当前最高 200MB、登录鉴权）上传后追加真实下载链接到草稿，由成员确认发送，失败保留原文，不产生虚假附件。文件与聊天不增加新的外部存储或接口（上限调整见 ADR-296）。
- 支持真实 Web Speech API 的宿主显示语音输入，中文识别结果追加到当前草稿，由成员检查后发送；未支持的浏览器不展示无效入口。录音失败/拒绝授权可重试，收起或卸载时结束识别。浏览器服务可能联网处理声音，按钮提示说明；不提供伪造转写或声称全面跨平台支持。

语音能力依据：[MDN SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/start)。实际麦克风、系统权限与服务可用性仍需实机验收，不能以模拟事件代替。

## 功能验收

1. 顶栏创建任务，保存成功后直接编辑其详情；断网时保留输入并重试。随后点新建小记，详情关闭，小记空间显示。
2. 新建表单项目/负责人仅占一行；设置→组织与成员仅展示娃哥、娃弟，历史作者仍能溯源。
3. 普通任务操作不增加通知；其他成员明确 @ 自己后有提醒，自己的 AI Run 结束后有结果；看过后未读清除。
4. 顶栏聊天发送文字和上传的文件链接，重新打开消息仍在，点击链接可下载；上传失败可重选，原草稿保留。
5. 有识别服务时点击语音输入，授权后说话，确认中文转写追加而不自动发送；拒绝权限时有错误说明。
6. 升级客户端后检查品牌、更新黄点、无新版隐藏入口，宠物连续点击显隐、右键打开聊天。完整原生体验须安装新客户端，Web 发布不代表已安装升级。
