# 首页日常工作区

替代首页额度默认展开和大幅起步引导的展示约定，保留整体导航与配色。

- 顶部日期和紧凑天气，失败显示简短提示及重试；仍复用已保存城市和天气偏好。
- 额度常驻一行摘要：真实周剩余、重置卡与 Pro 剩余天数；详情默认收起但不卸载，保留权益草稿、失败及到期提醒。多账号卡数分别展示，不相加；历史采样明确标注。
- 今日待办沿用本人负责或参与、今天及逾期未完成的口径，按截止日和优先级排列，最多五项，点击打开原任务抽屉。
- 最近创作展示本人创建的非自动小记和文档，按更新时间取四篇；排除归档和不可见知识库。正文目录不足以计算字数时只补取当前四篇，加载失败可重试，不伪造零字。字数按统一编辑器的非空白字形口径计算。
- 项目速达展示可见、未完成未搁置项目，沿用项目列表顺序，最多三项。现有接口的 updated 是历史展示文案，不能用于最近更新排序，也不在首页显示成新鲜时间。
- 起步引导默认收成轻量快捷入口，保留成员显式展开偏好。AI Run 无活动时显示轻量入口，有活动时展示数量和最新进度；折叠不丢输入和运行状态。
- 知识库页签复用原有键，显示当前文档标题并保留文档查询参数；用户手动重命名优先。
- 所有区域覆盖加载、失败重试和空状态；不增加累计创作统计或新接口，不修改业务数据结构。

验收：本人任务与文档筛选、正文未加载不显示零字、失败重试、导航携带文档 ID、权益折叠草稿、宽窄屏及真实数据入口。
