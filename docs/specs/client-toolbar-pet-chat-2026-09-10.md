# 客户端顶栏、宠物点击与聊天发送修复

来源：任务 `t17890290261220`，截图原文保留于该任务的公开分享页。补充 ADR-228，不修改已经发布的旧规格。

## 用户结果

- 客户端将截图红框内的新建任务、新建小记、主题、快捷键、聊天、通知六个入口移至最上方 40px 标题栏、连接状态左侧。动作继续使用当前工作区，不刷新页面；聊天和通知未读来自原组件。窄窗口保留图标和明确提示。
- 未点击时宠物待机帧时长加倍，周期从 1100ms 到 2200ms；拖动、挥手和减少动态效果行为不变。
- 新版桌面宠物本体点击切换 WAO 窗口显示/收起；收起不销毁窗口与草稿，最小化状态点击恢复。消息气泡始终打开聊天，任务气泡保持定位任务，拖动结束不触发点击。
- IM 在 Enter 或按钮发送成功后立即清空可见输入内容并保留焦点；失败、重试和请求期间新增草稿继续保留。

## 实现边界

客户端 1.1.3 声明顶栏能力并请求 `native=3` 宠物页。远程页面仅向固定同源地址发送就绪状态与两个受限未读计数；原生不接受任意脚本、URL 或文件命令。标题栏六个动作由本地壳调用，原生校验当前工作区原点及固定动作白名单，再复用页面按钮。未登录或页面切换时禁用业务入口。

旧客户端继续显示网页按钮；宠物本体退回打开 WAO，不发送旧版不认识的开关动作。Web 与桌面更新独立发布，完整顶栏和窗口开关需要安装 1.1.3。

编辑器保留聚焦时不回灌后台内容的原有保护。仅发送成功时携带原文确认清空：当前编辑内容仍相同才清空，并取消待回灌旧值；不通过重建编辑器打断输入。

## 用户验收步骤

1. 升级客户端，确认六个入口位于最上方，原业务导航中不重复出现；逐个点击，核对新建、主题、帮助、聊天和通知对应功能，并在窄窗口检查可点击性。
2. 保留未提交输入，点击宠物收起窗口，再点恢复；文本仍在。最小化后点宠物恢复；拖动宠物不改变工作区显示状态。
3. 有真实未读消息时点击气泡，工作区打开聊天；查看真实未读角标随已读更新。
4. 在聊天输入文字后按 Enter，成功后内容立即消失，再输入下一条不会带回旧消息；失败时原文保留，等待响应时新增文字保留。
5. 观察待机动画节奏放慢，拖动和消息挥手不受影响。
