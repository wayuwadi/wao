# 本地工程一致性检查

## 目标

把 ADR-014 和 AGENTS 中要求人工核对的 ADR / Flyway 语义冲突转成轻量本地命令，同时检查本次修改的 Markdown 文件引用是否仍指向存在的本地路径。只读执行，不自动重编号、不改写 migration、不提交或发布。

## 检查范围

- 明确解析本地基线引用，输出完整 SHA；默认 `origin/main`，不替用户联网刷新。要求基线已包含在当前 HEAD，未同步时明确失败，避免漏掉远端新加的同号文件。
- 扫描受 Git 管理及未被忽略的新 ADR、SQL 文件，按数字归一化检查编号，包含尚未暂存的内容。
- 基线已有的 ADR 重号作为历史警告，本次新增/扩大的重号作为错误。Migration 重号始终是错误；不通过历史基线豁免启动风险。
- 基线已存在的 migration 内容或路径变化一律报错，防止编辑、删除和重命名已交付 migration。只读比较文件字节，不输出 SQL 内容。
- 仅检查本次新增/修改的 `docs/**/*.md`、根目录 `README.md` 与 `AGENTS.md` 中常见内联链接、图片及引用式目标的本地路径，忽略围栏代码块、行内代码、外部 URL 和锚点。校验文件是否存在，不声称校验标题锚点、HTML 链接或网络地址。
- 支持简短文本与 JSON 输出，退出码 0 为无新增错误，1 为发现错误，2 为无法执行检查。历史警告保留在结果中，不称为零问题。

## 验收

用独立临时 Git 仓库验证并行分支同号、新文件未暂存、历史 ADR 重号、前导零、不可变 migration、链接相对路径与空格、代码示例忽略、缺失基线和未同步主分支。对 WAO 当前真实工作区运行一次，保存数量和历史问题，不输出私有文件内容。
