# 项目与全局文件保持地址重新上传

来源任务：`t17897276079220`，子任务 `s17897276113821`。
用户确认范围为 HTML 与普通文件（PDF、Word 等），不包含图床。

## 用户结果

- 项目文件、项目 HTML、全局文件与网页托管列表均提供“重新上传”。
- 弹窗显示目标名称与原访问地址；支持点击或拖入新文件，确认后替换内容。
- 普通文件保留 id、自定义展示名、项目归属和创建信息，更新原始下载文件名、类型、大小与正文；原分享页及下载地址不变。
- HTML 保留 id、分享后缀、标题、icon、来源和项目归属，只更新 HTML 正文、文件名和更新时间。旧链接读取新内容，仍使用隔离沙箱。

## 保存与失败

- 先读取和校验完整新文件，再用单条更新语句替换内容；读取、校验或数据库更新失败不会先删除旧文件。
- 替换接口只更新内容相关列，避免陈旧的客户端标题、链接或归属覆盖并发修改。
- 登录和项目可见性校验与既有修改操作一致；普通文件沿用系统大小上限，HTML 沿用 UTF-8、非空、10MB、html/htm 扩展名校验。
- 保存中禁止重复提交、更换文件或关闭；失败保留已选文件并显示重试；关闭未保存选择前提示，浏览器刷新前防丢提醒。
- 不创建新资产记录、不自动按同名覆盖、不保留版本历史；取消选择不发请求。
- 下载与 HTML 正文禁止缓存，避免重新访问仍显示旧内容。

## 验收

分别在项目和全局列表重新上传普通文件、HTML，检查列表更新且数量不增加，刷新后仍为新内容；保留的分享与下载地址读取新版本。覆盖空文件、错误 HTML 类型、超限、失败重试、保存中重复点击、取消和窄屏长文件名。
