# 项目功能使用优化（娃弟）：2026-09-18

来源：分享任务 t17897352672531 的 17 项未完成清单，全部在一个 PR 内处理。

## 表格视图

- 点任务行的「+」添加子任务时，输入行出现在该任务下的第一行；给某条子任务加下级时，输入行紧跟在那条子任务下面。新子任务本来就插在最前，所以输入框和刚加的那条在同一个位置。
- 状态、优先级、负责人的下拉改成悬浮菜单（`CellMenu`，挂在 body 上固定定位），不再撑开表格；点单元格任意处都能打开；第一次按 Esc 就收起，Esc 不会冒泡关掉外层弹框。
- 新增负责人筛选（按项目记在本地）：主任务归此人，或者有子任务派给此人，都算他的任务；主任务不是他的时，只显示派给他的子任务及其上级。
- 去掉交付阶段按钮（全部阶段 / 方向探索 / 待开发 / 待验收 / 已验证）；旧链接里的 `stage` 参数不再过滤任务。
- 表格视图去掉批量选择；「不分组 / 按分组」和「显示已完成」开关挪到原批量选择所在的右侧，与视图切换、筛选同一行。看板和分组视图保留批量选择。
- 头部压缩：项目名一行（图标、字号、按钮缩小），页签与工具一行，交付阶段行和表格工具条行取消，原来四行的头部变成两行。
- 新增「创建日期」列（计划开始左侧）；负责人、创建者列从 120px 缩到 88px。子任务的负责人改成点名字弹出菜单，不再常驻下拉框。没排期的日期格不显示「年/月/日」占位。
- 第一层、第二层（以及更深层）有下级的子任务显示收起箭头。
- 子任务整体往右缩进一格（与主任务错开一个层级）。
- 表格去掉最左侧的选择列。

## 子任务

- 子任务新增「进行中」状态：完成与否仍记在 `done`，「进行中」另记在 `status`，分享、通知、统计等只认 `done` 的读取方不受影响。表格、详情列表和详情属性栏都是三态悬浮菜单。
- 新建子任务的负责人、创建者默认是录入人，并记录创建时间；表格与详情展示创建者和创建日期。
- 子任务可以关联知识文档、有自己的评论。子任务评论随任务全文保存，不触发 @ 通知（主任务评论照旧走原子评论接口和通知）。

## 任务弹框

- 关联（知识文档 / 任务 / 文件 / HTML）与评论从主区挪到右侧属性栏；子任务属性栏同样有「关联知识文档」和评论。属性栏从 290px 加宽到 330px。
- 属性栏的「JOBID」改为「编号」，与子任务一样显示井号编号；点击仍复制 JOBID，复制失败时提示里给出 JOBID。
- Esc 按弹框内的浏览足迹退回一层：从表格直接点开的（不论层级）按 Esc 回到表格；在弹框里从子任务再点开的下级，按 Esc 回到上一个子任务。点面包屑回到足迹里已有的一层视为后退。

## 其他

- 顶栏去掉「问问 AI」按钮（Ctrl/⌘ + J 快捷键保留）和「项目 · 切换」下拉。
- 取消项目状态：项目详情头部、项目列表卡片、状态筛选和「按状态」分组都去掉；项目设置去掉项目状态。AI 执行配置按 `AI_RUN_ENABLED` 隐藏且不读取，保存设置时不会用空白默认值覆盖服务端已有配置。
- 新建任务的截止日期默认「不设置」；项目分组里的快速新建也不再填今天；服务端 `POST /api/tasks` 未传截止日期时不再默认今天。
- 页面铺满：`--wao-content-max` 改为 `none`，项目首页、知识库、日历、密码本、TODO、首页、文件、自动化等共用该变量的页面铺满；其余写死 1080–1800px 上限的应用页面（知识库文档栏、小记、仪表盘、设备、周报、节奏等）同样取消上限。下载页、游戏页和设置表单保持原宽度。

## 数据与接口

- `Step`（子任务）新增可空字段 `status`、`createdBy`、`createdAt`、`docs`、`comments`，存放在原 `detail_json.subs` 中，不需要 migration。新增字段为空时序列化省略，历史子任务的 JSON 与 `subtaskVersion` 摘要不变，升级不会引发一次性保存冲突。子任务移动、编号回填保留这些字段。
- `docs/api/board.yaml` 的 `Step` 同步补充字段说明。
