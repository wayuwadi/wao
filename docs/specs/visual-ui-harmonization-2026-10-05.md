# 页面视觉节奏与信息密度统一

2026-10-05，用户确认把视觉检查提出的页面优化全部纳入，并逐项修改。此变更延续成员页面布局偏好规格与已确认的统一外框，不改变路由、业务数据、权限或操作语义。

## 设计约定

- 全部功能、能力中心、待办和功能探索共用页面外框及顶部留白节奏；阅读型工作区可以保留适合阅读的内层宽度。
- 全部功能在桌面宽屏下使用双列短卡，窄屏回到单列，减少横跨视口的空行。
- 能力中心区分管理区域、资源类型筛选和资源详情中的操作页签；资源筛选以独立次级控件呈现。
- 功能探索按可用宽度排列卡片，减少卡片底部无内容的留白，保持桌面 6 项与窄屏 3 项的分页和深链行为。
- 待办日期、当天摘要、固定安排及任务列表维持清晰的垂直分组；状态文字与辅助说明保持可读对比。
- 页面布局偏好继续提供“统一外框 / 全部铺满 / 统一居中”，使用可辨识的结构预览；保存和成员隔离行为不变。

## 验收

- 桌面与窄屏检查外框、页头、导航卡、能力中心层级、探索卡片和待办摘要分组。
- 检查三个布局示意、页面现有筛选/分页/深链与待办行为未改变。
- 完成类型检查、受影响页面回归、生产构建和工程一致性检查；不以构建成功替代浏览器视觉验收。
