# 表格新建任务默认 P2

主任务现有表格新建和任务弹窗继续默认 P2；新建子任务（含任意层级）也明确写入 P2，不继承父任务优先级。表格优先级列显示子任务真实保存值，沿用 P0–P3 菜单可独立修改。

## 数据与兼容

任务内嵌 `subs[]` 新增可选 `pr: "P0" | "P1" | "P2" | "P3" | null`，随既有任务保存接口和 detail JSON 持久化，无新接口或数据库迁移。服务端校验范围；移动、重编号保留值。历史缺省不补写、不改变子任务版本摘要，展示未设置；新建由录入端传 P2。旧调用构造器保持兼容。

验收覆盖主任务 P2、新建根及下级子任务 P2、独立修改与刷新持久化、移动保留、非法值拒绝和历史摘要兼容。保存失败沿用任务草稿及重试机制。
