# Phase 1：共享聊天与飞书群双向消息流

对应任务：`t1787729205924`。协议与数据决策见
[ADR-127](../adr/127-shared-chat-feishu-bridge.md)，首版边界见
[ADR-126](../adr/126-shared-lightweight-chat.md)。

## 用户结果

1. 聊天页可从飞书自建应用真实所在群中自主选择一个双向同步目标；切换不会改变知识库归档群。
2. WAO 消息在飞书中以普通图文消息表达，不再使用系统通知卡片；Markdown 正文和图片仍先可靠保存到 WAO。
3. 所选飞书群的成员消息最多约 15 秒后进入 WAO；消息编辑、撤回和引用关系更新同一条记录，不制造重复消息。
4. 页面显示进入时的未读分界、WAO 阅读事实和飞书实际回传的已读人数。没有官方回调时不显示推测人数。
5. 输入统一使用现有所见即所得 Markdown 编辑器，支持 Markdown 快捷输入、粘贴/选择图片和本地草稿防丢。
6. 可以插入 Unicode 表情、引用回复消息，并用四种稳定飞书 emoji 类型进行表情回复；失败保留可重试错误。
7. 群选择面板可按秒或分钟配置 5 秒～60 分钟的入站轮询；配置跨刷新持久化，无需重启服务。
8. 飞书一条富文本中的多张图片按原顺序显示在同一 WAO 气泡；引用与表情操作横向放在气泡外侧，不占用消息纵向高度。
9. 每日 00:10 自动核对前一日完整消息，页面也可立即核对当日，并逐次展示扫描、新增、更新和新增正文/图片字节。
10. AI 控制台“执行电脑”以最近 Runner 心跳展示各节点 CPU、内存和工作盘容量；旧 Runner 或离线快照明确标时。

## 真实数据与失败边界

- 群列表、消息、图片、回复关系、已读和表情都来自飞书开放 API 或事件，不提供静态演示群或随机状态。
- 未绑定 WAO 的群成员仍保留飞书稳定外部身份；只有 Open ID / Union ID 能安全命中账号绑定时才归属 WAO 成员。
- 普通消息由轮询兜底。要同步飞书已读与其他成员的表情，在开放平台事件订阅中为现有
  `https://wao.wayuwa.cn/api/feishu/events` 增加 `im.message.message_read_v1`、
  `im.message.reaction.created_v1`、`im.message.reaction.deleted_v1`，并保持 Verification Token / Encrypt Key 一致。
- 飞书失败不回滚 WAO 消息；重新选群后可逐条重试。飞书图片下载失败时不伪造图片成功，只保留能确认的文字。
- 双节点以主库租约共享轮询水位；飞书消息指纹未变化时不重复转存图片。空间增量只统计可归因正文和图片字节，
  不把 MySQL 索引页或其它进程造成的磁盘变化归到聊天同步。

## 验收

- 选择机器人真实所在群后，WAO 发送 Markdown 与图片：WAO 刷新后仍存在，飞书出现普通图文而非卡片。
- 飞书群成员发送文字、图文和回复：15 秒内 WAO 出现相同真实作者与父消息；双节点轮询只插入一条。
- 飞书编辑或撤回后 WAO 更新原消息；WAO 发送失败后以相同消息 id 重试，飞书不出现第二条。
- 一个 WAO 成员打开页面后未读分界消失并持久化；飞书阅读回调只增加对应消息的飞书已读人数。
- WAO 添加/撤销表情后飞书原消息同步变化；飞书成员新增/删除表情事件更新 WAO 聚合且不重复计数。
- 保留未发送 Markdown 与引用草稿时发生轮询、上传失败或刷新，草稿不被服务端消息覆盖。
- 同一未变化图文被实时、编辑回看和夜间核对重复看到时，只第一次下载图片；双节点同一窗口只有一个节点拉取。
- 夜间与手动运行无论成功或失败都保留终态；成功记录的字节增量与实际新增正文、图片原始大小一致。
