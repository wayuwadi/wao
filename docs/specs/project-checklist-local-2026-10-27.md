# 项目清单视图：本地试用

按最新反馈撤下独立待办清单和新增待办子菜单，在 WAO 项目任务视图中增加「清单」。原试用本机数据不删除，旧 quick-preview.html 入口返回项目。

- 左侧显示现有任务及子事项层级，右侧常驻详情卡片。点击任务不弹窗；更多操作和保存冲突处理使用现有完整详情。
- 复用项目人员筛选、完成项开关和展开收起。关键词搜索在清单内显示结果及祖先上下文。
- 正文复用 MarkdownEditor，仅保留带格式的无边框编辑。任务与子事项分别写入原始数据，沿用现有草稿、自动保存、错误回执与并发冲突处理；无新增数据库和 API。
- 桌面左右布局、窄屏上下布局，使用主题 token 与公共卡片按钮。
- 本地前端连接既有 WAO 服务；修改现有任务会保存到该服务的数据库。本次未部署。

验证：类型检查、相关 Vitest、UI 规范检查、构建；浏览器验证真实验收项目的详情编辑保存、子任务切换、搜索及窄屏。

验收结果：新增 3 项测试通过；原搜索测试 5/6 通过，其中第 119 行的折叠状态断言在 origin/main 原组件也失败。类型、UI 规范、构建通过；明暗主题及 320/390px 无横向溢出；真实验收任务和子事项正文修改后刷新保留。

第二轮视觉调整：单行紧凑清单只展示完成勾选，保留日期；详情标题 16px，去掉分区标签和源码入口。移除项目计数栏；显示子任务/已完成改为颜色表示状态的按钮，展开/收起合并。完成开关操作沿用原任务保存，未勾选的原业务状态不做迁移。

第三轮：清单共用表格分组，拖动行中间更改父级、上下边缘改变同级位置，拖到顶层区域提升；拒绝循环归属。移除显示子任务按钮，层级始终可见；任务数量移入项目标题，文档等入口收进更多菜单。统一原生复选框的外观与尺寸。首版 tquick-UUID 未保存草稿先备份再恢复合法 ID，不重编号已保存任务。

本轮验证：24 项相关测试通过，类型/UI 规范/构建通过。真实验收项目拖动 A 到 B 下并刷新后层级保留；父子复选框均 14×14px；320/390px 无横向溢出。旧草稿备份后保存成功；多窗口重复恢复只在可编辑内容完全一致时清理副本，内容不同仍保留冲突。
