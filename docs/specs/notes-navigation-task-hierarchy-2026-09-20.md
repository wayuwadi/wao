## 存储与接口

完整任务保持原 ID、永久编号、正文、附件、内嵌子任务、PDCA 和执行记录。新增 task.parent_task_id 可空列和外键；删除父任务时子任务回顶层，不级联删除。

POST /api/tasks/{id}/parent，输入 parentTaskId（null 表示顶层）与 expectedParentTaskId，返回完整 TaskDto。需要当前会话可访问源和目标，只允许同项目，拒绝自身/后代/环；同项目任务按 ID 锁定，校验锁后当前树与旧父关系，过期关系返回 409。普通 PUT 忽略此字段，防止旧客户端覆写；有父或子的任务跨项目移动需先解除关系。

关系更新只写一列。前端只接收 parentTaskId，不回灌正在编辑的正文；未保存草稿先写透，失败不移动。编号分配与 DTO 副本保留父关系。表格分组继承父任务，原分组仍保留以便移回顶层；筛选隐藏父任务时匹配的子任务仍可见。看板等其他视图保留各任务独立状态，详情提供关系入口。
