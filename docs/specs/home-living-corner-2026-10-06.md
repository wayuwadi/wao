# 首页伙伴的天气与街角日常

用户确认「四个伙伴的街角日常」交互预览。第一版接入真实天气、基础衣库、生活闲聊与少量已有通知；新闻热点和个人衣库接入不在本次范围。

- 使用成员已保存城市、今日每日预报与原有有效期。无城市、加载、失败、过期、未知代码时回到普通陪伴，不伪装实况。天气场景明确属于「今日预报」；阴晴雨雪雾雷暴分别表现，风为可叠加因素，强风不撑伞。
- 气温与雨风决定穿搭，保留四个伙伴脸、原配饰、颜色及轮廓。同一输入得到稳定衣服，不因点击或刷新随机换装。缺少温度不猜冷热；四套基础风格与衣服层集中定义，未来可替换来源。没有新衣库入口、购物推荐或穿搭管理面板。
- 底边场景淡而可辨，不覆盖信息卡、文案或入口，不引入声音；静态降级仍显示衣服。复用既有动画帧与暂停规则，安静/减少动态效果时保留静态天气与衣服。
- 18 秒无输入后才允许自动对话，首次排期约 25～40 秒，轮次间隔 75～105 秒；每轮两三句话轮流冒泡，单句约 3.6 秒。生活语料只描述已知天气和日常，不联网生成、不伪造新闻。输入、拖动、升空、彩蛋、右键、长按、休息/写作入场及其他浮层优先，自动气泡立即收起。
- 同时只有一条气泡。聚焦气泡时不自动移除控件；通知最多一轮一条，与聊天共用间隔。天气改变中断旧天气对话。停用首页、后台、离开可视区域或编辑内容时停止排期，返回重新等待，不补播。
- 通知复用通知中心的真实读取快照与轮询，不再请求第二路 API。仅候选近期未读的任务完成、AI 终态和可跳转的普通内部通知，排除登录、新建任务和警告；重要提醒继续走原通知渠道。默认只说通知类别，不把完整私有标题常驻首页。
- 按成员与日期去重，最多保留 100 个显示过的事件 id；只有实际显示才记入，切换成员清空待播与气泡。未读水位改变后重新检查候选。短暂显示与点击不修改通知中心的已读水位，跳转复用原目标并拒绝外部地址；路由失败可重试。
- 本次浏览器变化不增加业务 API、数据库、CLI 或 MCP 能力；不改任务提醒策略。真实用户链路使用既有后端与数据库验证，不向生产写入演示通知。
