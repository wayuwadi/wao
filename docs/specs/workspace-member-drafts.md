# 链接空间草稿归属与保存保护

对应审计 A04，延续个人空间按成员隔离、失败可恢复的规格。

- 新建、编辑与上次打开空间的本机记录都按成员ID隔离。切换账号立即清空画面，再读取该成员草稿，旧请求不得回填。
- 无归属的旧版草稿原样保留，不自动导入任何账号；不猜测创建人。
- 编辑期间包括正在保存时的输入立即写本机草稿。保存发送独立快照，返回时若还有新输入，保留新草稿并显示待保存，不覆盖或误清理。
- 新建请求进行中暂时锁定创建字段与关闭按钮，避免返回后吞掉期间修改。存储异常显示持续提示并可重试；不把存储失败混同服务端保存失败。
- 不改接口、数据库、成员权限或项目管理内部逻辑。

验收：成员切换、旧草稿保留、保存中新输入、存储失败重试和既有空间操作共6项测试通过；类型检查与构建通过。本地真实数据库新建“【验收记录】链接空间草稿恢复”，模拟保存失败→刷新→整理恢复草稿→解除故障重试→刷新读回通过。专用验收空间保留，不含真实工作链接；未删除或修改原有空间。
