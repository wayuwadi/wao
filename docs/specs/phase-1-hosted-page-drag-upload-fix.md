# 规格：网页托管拖拽文件连续发布修复

对应任务：`t1787911270330`。

## 用户结果

1. 从“文件与图床”的统一入口拖入 HTML 后，托管弹窗明确显示已选文件，用户确认标题和链接后缀即可直接发布，不再被浏览器要求重复选择文件。
2. 托管弹窗的 HTML 与可选 icon 区域都支持拖拽和点击选择，并显示当前选中的真实文件名。

## 真实数据与安全边界

- 拖拽只把浏览器提供的本地 `File` 交给现有 `/api/hosted-pages` 上传链路，不预读、不伪造文件，也不绕过服务端对 HTML、icon、大小、权限和隔离策略的最终校验。
- 新建页面仍必须选择 HTML；编辑页面不选择 HTML 或 icon 时，继续保留服务端现有文件。
- 弹窗内拖入错误类型时保留当前选择并明确提示，不把普通文件误发到网页托管接口。

## 验收

- 在统一入口拖入 HTML，弹窗显示该文件名；不重新选择文件，点击“发布”即把同一个 `File` 传给保存接口。
- 在弹窗内分别拖入 HTML 和图片，两个区域显示对应文件名，发布请求同时携带两份真实文件。
- 选择普通文件作为 HTML 或非图片作为 icon 时不替换当前有效选择，并提示正确类型。
