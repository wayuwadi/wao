# 新会话目标与执行边界

对应审计 B02/B03。以 ADR-093、ADR-169 和当前 Runner 为准，不新增人工确认关卡、不更改默认模式或发送参数。

- 先填写目标，再确认归属项目和执行方式；执行电脑及推理强度折叠到高级设置，沿用现有值和草稿。
- 直接执行明确可能执行修改；Plan 明确先计划后连续执行、常规选择自动采用推荐项，不等待人工确认；持续目标说明多回合和额度消耗。
- 非 Codex 不提供 Plan/持续目标，旧草稿不静默改成其他模式；选择不支持的模式时提示重选并阻止派发，避免后端忽略 Plan 或拒绝目标。
- 发送前说明会创建关联任务，按钮“创建任务并开始”。纯讨论可以在目标中明确范围，但不宣称这是技术权限隔离或批准流程。
- 不修改项目管理内部、Runner、接口、自动执行或验收规则。

验收：11项会话测试、类型检查与构建通过；本地真实数据库读取项目和在线节点，切换Plan显示自动执行边界，刷新恢复目标/模式草稿，高级设置可展开。验收草稿通过界面清除，未创建任务、未派发AI。非Codex旧Plan草稿阻止提交与显式重选由测试覆盖。
