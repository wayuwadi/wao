# 恐龙荒野：核心玩法 Demo D1

日期：2026-10-03。整体设计 A2 与工程拆分方案已获用户“设计我已确认，开始吧”确认。本文件定义阶段 B，不能将整体确认视为尚未体验过的核心手感确认。

## 这次必须可以体验

珊瑚红原创恐龙、暖红荒野、固定侧视；空格/↑/舞台点击跳跃，按住更高、松开短跳，落地前短输入缓冲；↓按住下蹲、空中按↓加快落地。触屏提供大跳跃按钮和可锁定下蹲按钮，离开焦点会清空。

小/高/成组仙人掌与低/中/高飞鸟。中鸟必须蹲或谨慎跳越，低鸟跳过，高鸟站立即可通过。练习段有6个固定教学障碍，无尽与300米试跑用于感受渐进速度、随机组合、失败/终点结算和快速重开。300米是Demo的短体验，不取代已约定的正式1000米挑战。

碰撞范围比美术轮廓略收紧；固定120Hz物理步进，短帧卡顿不穿透；每次跳跃只由按下边沿触发，不因一直按住而自动连续跳。障碍边缘间距按最高预计速度、最大滞空时间、恢复时间和反应时间共同约束，另用离散控制搜索验证生成序列可通过。

日夜渐变、奔跑/蹲伏/跳跃/受击表情、速度远景、轻尘粒子与合成音效形成可判断的美术样例。音效默认关闭，只在用户操作后创建上下文。提供暂停、继续、重开；后台/失焦/父页面切换停止并清空输入，恢复不自动跑。
