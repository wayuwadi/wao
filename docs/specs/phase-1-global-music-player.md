# 规格：全局音乐播放器

对应任务：`t1786845948721`（在 WAO 网站中加入参考图所示的音乐播放器）。

补充任务：`t1786971178525`（播放器默认关闭，并由每个成员设置默认开合与入口显隐）。

## 目标与范围

- 登录后的 WAO 应用壳提供全局悬浮播放器；切换路由不销毁音频节点，播放可以连续进行。
- 播放器包含当前曲目、进度与时长、播放 / 暂停、上一首 / 下一首、音量 / 静音、播放列表和最小化入口。
- 桌面端固定在右下角；手机端避开底部导航，并限制面板高度，长列表可独立滚动。
- 新成员默认不展开播放器，只显示右下角入口。“默认打开”与“显示播放器入口”使用 `music-player-settings-v1` 成员偏好按登录成员隔离保存；切换登录成员时必须先清除上一人的内存偏好再重新读取。偏好读取失败时不覆盖服务端值，设置页提供重试。
- 播放器在当前页面生命周期中保留开合状态，并在本机记住当前曲目、音量、静音和列表开合；刷新后按成员的默认开合决定是否展开，但不自动播放，遵守浏览器自动播放限制。

## 音乐来源与账号隔离

- 播放器提供“WAO 文件”和“网易云”两个明确来源；切换来源会停止并结算上一来源的播放，不混合列表。
- 网易云只使用官方开放平台 H5 OAuth。每个 WAO 成员独立授权自己的网易云账号，OAuth `state` 绑定成员且十分钟失效；不收集网易云密码、Cookie，也不允许复用其他成员令牌。
- access token 与 refresh token 使用 `WAO_VAULT_KEY` 做 AES-256-GCM 加密后持久化；API 和前端状态永不返回令牌。授权过期时要求当前成员重新绑定。
- 已绑定成员读取自己的红心歌单，分页加载；每次播放实时取得官方短时 HTTPS 地址，不把地址当长期文件保存。
- 每首网易云歌曲按官方要求回传一条 `startplay` 和一条 `play`；暂停和拖动不结束本次上报，切歌、自然结束、异常和页面中断使用对应结束原因，播放秒数排除暂停和拖动跳跃。
- 开放平台应用尚未审核或环境变量不完整时，网易云入口展示“管理员尚未完成配置”，WAO 文件播放器保持可用。

## 真实数据与上传

- WAO 文件曲目只来自现有 `/api/files` 真实文件库；网易云曲目只来自当前成员的官方红心歌单，不内置示例歌曲、远程假链接或伪造歌手信息。
- 文件列表返回持久化的 `contentType`；前端按 `audio/*` MIME 识别音频，并兼容已有文件的常见音频扩展名。
- 播放器可直接上传 MP3、M4A、AAC、WAV、OGG、FLAC、Opus 与 WebM 音频，复用文件库 50MB 单文件限制；上传结果同时出现在“文件与图床”。
- 没有曲目、文件库加载中、加载失败、上传中、上传失败、音频缓冲和播放失败都必须有明确状态及可行的重试入口。

## 音频流接口

- `GET /api/files/{id}/stream` 只允许登录会话访问，且只以内联方式返回明确的音频文件。
- 接口支持单段 HTTP `Range`，正常范围返回 `206`、`Content-Range` 和 `Accept-Ranges: bytes`，使浏览器可拖动进度并按需取流。
- 不合法或越界范围返回 `416`；非音频文件返回业务错误，不把任意上传内容以内联资源暴露。
- 既有公开下载确认、一次性票据和附件下载行为保持不变。

## 验收

- 已登录用户上传真实音频后可播放、暂停、拖动进度、切歌、调节音量；跨 WAO 页面切换时音频不中断。
- 文件库为空时不展示虚构曲目；加载或播放失败时页面不伪装成功。
- 桌面和窄屏均可看到当前曲目、主要控制和播放列表浏览入口，播放器可最小化且不会遮住公开分享页或登录页。
- 未设置过偏好的成员进入 WAO 时播放器不展开；两名成员的默认开合和入口显隐互不影响，换设备登录后仍按各自设置生效。
- 两个 WAO 成员分别绑定不同网易云账号时，各自只能看到自己的昵称、红心歌单和播放状态；解除绑定只删除当前成员的数据。
