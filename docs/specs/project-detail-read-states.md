# 项目详情读取状态

项目详情保留当前紧凑、任务优先布局，本项只修复读取状态，不改项目关闭保存契约或任务判定口径。

- 尚未读取项目时显示加载；请求失败说明无法确认是否可访问并提供重试；只有请求成功但无对应项目，才提示不存在或无访问权限。
- 项目信息刷新失败保留已读取内容并标明旧信息。
- 任务首次加载或失败且没有已读任务时，保留工具栏与查找输入，暂不显示四种视图中的空数量、空分组、空象限和引导创建文字。重试入口持续可用。
- 有已读任务时刷新失败保留视图、搜索、人员筛选、展开和行内输入，并明确数量及结果可能不是最新；成功后自然恢复，不因状态切换销毁视图。
- 读取成功后真正空数据与人员筛选无结果分开说明。任务页签提示与计数同步服从读取状态，不通过悬停提示声称“暂无任务”。
- 新建项目有内容时关闭即保存沿用 `page-layout-refinements-2026-09-20.md`，本项不更改。

回归：`ProjectDetailLoading.spec.ts`，覆盖项目加载/失败/缺失、四视图任务首次失败及恢复、已有数据刷新失败后搜索和视图保留。无业务接口、权限、CLI 或 MCP 变更。
