# 小记选区润色：可靠替换与轻量执行

补充 [选区润色](phase-1-document-selection-polish.md)、[不可变原稿](notes-immutable-originals.md) 与 ADR-258。用户反馈候选已生成，却因“结果没有保留对应 AI 输出”无法替换，重试又重新执行模型。

## 应用和重试

- 服务端继续核对当前成员、可访问文档、真实已成功任务、请求号、完整冻结输入及不可变结果。标题和图片 URL 的校验保持原样。
- 正文完整输出允许展示等价：CRLF、软换行、段间空白和 Markdown 标点转义。只归一化这些表示，不删文字、数字、链接或图片地址，不接受截断、修改事实或未完成任务。来源与候选按原值留存，归一化仅用于校验。
- 通过编辑器同一插入命令生成未派发事务，留存该事务的完整正文和富文本；留存成功后派发同一事务，避免跨段空段导致候选与最终保存不同。
- 留存失败保留原文、完成候选与任务号，显示“重试替换”；再次应用同一结果不调用 AI。应用中禁用重复操作。只有明确“重新润色”才清空旧候选并新建任务。
- 等待生成或留存期间正文变化，旧选区不得覆盖新输入。刷新恢复已完成候选时清除临时“正在替换”状态，仍重新检查完整来源。

## 执行耗时

`DOCUMENT` 是当前无模型/推理档位选项的短选区功能。复用原有默认模型，单独以 `low` 推理执行；不改变工作台方法、小记自动整理的用户模型和推理偏好。获准 API 路由保持既有准入。独立选区任务允许并行，仍保留请求幂等和任务归属，不人为按成员串行。

延迟以真实任务和浏览器测量为准，不承诺固定耗时。保留已完成候选避免应用重试带来另一轮模型等待。

## 能力同步和验证

既有 HTTP 请求/响应及登录权限不变，无新增数据库结构。选区应用依赖浏览器未保存草稿、ProseMirror 位置和确认替换，未新增 CLI/MCP 命令或令牌权限；现有小记创建、读取、保存能力保持兼容。

回归覆盖跨段原图/标题保留、留存与保存一致、留存失败只重试应用、应用中重复点击、等待期间新输入保护、完整结果展示等价以及事实修改/截断/未完成任务拒绝。真实链路使用明确标注的合成小记，在既有数据库上验证生成、替换、保存、重开和原稿留存；验收后移入回收站。
