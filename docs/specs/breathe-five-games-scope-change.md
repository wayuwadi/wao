# 游戏交付范围缩减为五款

2026-10-03，用户在第四款已经正式上线、第五款制作中明确要求：“补充：做完第五个游戏就结束，后面的两款游戏不要了”。该指示覆盖 `breathe-seven-games-design.md` 中七款数量和最后两款交付要求，不修改前五款已经约定的完整玩法与验收标准。

正式范围：恐龙荒野（红）、裂隙远征（橙）、星野奇旅（黄）、幻兽领地（绿）、最后一座营地（青），以及纯呼吸首页、原有静坐及六种构图风格。遗迹旅人和疾风赛道取消，不制作、展示占位或上线。第五款接入时移除剩余旧小游戏入口，旧账号历史档保留可导出，不清空数据。

持续目标完成条件调整为前五款全部达到首发规格、逐款合并发布与公网核验，并完成本地/仅本次/导出导入续玩验证。第五款完成即结束，不自动展开新游戏或其他工作。旧进度文件保留稳定路径 `docs/plans/breathe-seven-games-progress.md`，其开头记录当前范围；早期历史事件不追写成五款。
