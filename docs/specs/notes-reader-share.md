# 小记阅读模式分享与复制

2026-10-12：公开链接行为由 [小记默认私有与限时分享](notes-private-expiring-share-2026-10-12.md) 替代。阅读器“分享”现在打开权限设置，不自动复制或开启公网链接；正文复制、阅读位置和草稿保护沿用本规格。以下为原行为记录。

2026-10-04 用户要求在阅读模式增加分享按钮，并允许补充方便的阅读操作。本规格扩展 [统一阅读器](notes-unified-reader.md)。

- 侧栏速览和全屏阅读顶部均显示“分享”，点击复制当前选中小记的既有公开只读链接 `/s/d/<id>`。翻篇、选择目录后操作目标随当前小记变化；查看历史原文时分享仍指向当前小记，不发布历史快照或未保存草稿。
- 同时增加“复制正文”，复制当前显示的小记最新正文 Markdown，保留链接、列表和图片引用；不混入其他文章、新建或编辑草稿。查看历史原文时禁用该按钮，并提示返回当前内容后复制，避免复制内容与阅读视图不一致。
- 复制中避免重复操作，成功与失败均在阅读器内提供可访问反馈；失败可再次点击重试。迟到的结果不能显示到另一篇小记或另一成员的阅读器。
- 两种操作均保持阅读模式、选中文章、滚动位置和编辑草稿，不触发保存或 AI。兼容现有焦点限制与 Esc 退出。
- 窄屏按钮保留图标与文字，操作栏可换行，不遮挡正文或横向溢出。

复用现有文档分享与剪贴板能力，无业务服务、HTTP API、数据库或 MCP 变化；操作属于浏览器阅读工具栏，无新增 CLI 命令。
