# 今日节奏配置可读性

落实体验审计 B16/B19 与现有 UX 规范，保留 ADR-186 的分类配置和固定保存入口。

- 配置正文、字段名、错误与操作文字不再使用 9–11px 的微小字号；正文采用 13px，辅助信息至少 12px。
- 每日必做名称和时间/提醒摘要允许换行，不靠截断隐藏用户需要核对的内容。
- 窄屏保留联动类型和启停状态，编辑与恢复操作显示文字；字段按空间纵向排列。
- 窄屏输入采用 16px，弹窗内容独立滚动，固定保存入口保持可见。
- 不修改保存请求、提醒条件、启停或删除业务逻辑；既有批量新增幂等问题另行处理。

验收：真实桌面与390px配置页，四类配置切换、每日必做展开/收起、状态和摘要可读、表单及保存入口无横向溢出。纯样式修改复用既有组件回归，不编写镜像样式测试。
