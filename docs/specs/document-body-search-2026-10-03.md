# 全局正文搜索与定位

普通文档目录 `/api/docs/catalog` 不带正文，不能充当完整全文检索。当前授权环境目录9篇、其中4篇无正文；既有完整 `/api/docs` 返回9篇、约9.6KB。首次打开全局搜索读取独立完整快照与知识库目录，不回灌编辑 store。现有规模不支持新增搜索服务或索引的必要性；若实际规模增加，重新测量读取成本后评估服务端有界查询。

全局搜索保留功能、项目、任务，增加小记/文档的已保存标题及可读正文匹配，展示来源和命中片段。完整读取前显示加载，失败清空快照并重试，不把旧缓存或局部正文称为无匹配。每组明确结果数量与展示上限。中文组合输入期间不以 Enter 打开结果。

结果限定完整接口返回且仍在当前知识库日常目录中的文档。继承现有登录会话访问范围；不包含归档、回收站或目录外内容。现有知识库接口尚未实现独立成员级私有文档 ACL，不将展示文案当作已存在的权限能力；权限承诺与后端范围对齐另行记录，不在搜索中新增权限或扩展旧 MCP 令牌。

点击结果进入正确小记/文档，通过编辑器只改变选区与滚动位置，不写正文。已存在草稿保持原样；若草稿里已不存在关键词，明确显示未命中。小记页同样提供片段和定位，搜索期间保留编辑中的卡片；清除关键词恢复此前列表位置及分页，不重置个人筛选。

复用已有 Web GET 与登录规则，CLI/MCP 已有文档读取契约不变。本轮浏览器定位不新增服务端操作。
