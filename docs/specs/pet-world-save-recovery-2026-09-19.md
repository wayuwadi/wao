# 松风庭院存档读取失败与成员切换

补充单人庭院存档规则，不增加玩法、接口或数据库结构。

- 本地存档读取异常时保留原存档，不在进入、失焦、重置、后台或离开时用默认坐标覆盖；仍可临时游玩，但明确提示本次位置暂不保存。
- “重试读取存档”成功后恢复原坐标；写入失败继续使用原有“重试保存”，两种失败不混淆。
- 同一页面成员切换时，先保存旧成员位置，再恢复当前成员自己的存档。无存档回到出生点；退出登录不把坐标写入空账号或另一成员。
- 保留原有移动、碰撞、镜头、跳跃、触屏、后台停止及场景资源释放行为。

验收包含读取异常而写入可用、读取恢复、成员切换、普通写入失败，以及真实浏览器移动和刷新恢复。
