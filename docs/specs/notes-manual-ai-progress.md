# 小记手动 AI 完成状态

补充单份最新正文及后台整理规格。自动工作流的 SKIPPED 表示该自动阶段没有执行，不代表后来手动发起的阶段没有成功。

- 自动阶段已结束或已跳过时，保留浏览器手动任务的运行、失败和完成状态。
- 服务端有新一轮 PENDING、RUNNING 或 FAILED 时，旧的本地完成记录不能掩盖它。
- 单独重做标题、配图、润色或标签，只更新本次运行的阶段，不把其他已完成阶段重置成跳过；刷新恢复时采用同样的完成记录。
- 完成状态只描述执行记录，不声称模型输出质量通过，也不意味着已取消其他模型调用。
- 不改变任务入队、重试、保存规则，不新增 API、CLI、MCP 或数据库字段。
