# 记忆中心：以用户用途解释范围与生效方式

补充统一记忆中心规格与 ADR-110、ADR-129，保持既有权限与发布规则。

- 默认个人范围入口显示「关于我」，首先展示个人、组织、项目三个常用入口。电脑和应用记忆通过显式展开进入；技术范围深链自动展开，不能收起当前选中入口。
- 页面与编辑器说明实际保存位置；个人保存立即生效、不向其他成员共享，获授权的设备仍能读取。共享提交说明审核责任和不立即替换已生效内容。
- 操作名称采用「保存并生效」「提交审核」「修改记忆」；生效状态仍保留版本号以便追溯。
- 新建时折叠选填的变更说明、来源、失效时间；修改已有记忆默认展开，保存原字段不变。
- 保留原 scope、scopeId、分类、审核、失效、版本、草稿与 API 行为；不修改项目内部的记忆面板，也不调整设备授权。

验收：默认个人范围、技术范围深链、共享提交边界、补充字段传递、原有草稿恢复和冲突保留，以及真实会话下从列表到编辑器再退出的完整路径。
