# 唯一功能目录与版本更新

用户认可系统精简建议并要求实施。此前功能探索与全部功能重复维护目录，本规格取代两份历史更新规格中功能探索的重复目录设计；历史记录保留。

- `/navigation` 是唯一功能目录，继续保留功能搜索、个人布局与未固定功能访问。
- `/features` 稳定地址和 `changelog` id 保留，显示“版本更新”，只保留本次更新和最近更新。
- `/features#all-features` 兼容旧书签，替换跳转到 `/navigation`；当前与最近更新深链继续有效。
- 更新浮层的全部功能入口进入唯一目录；旧默认菜单名称显示为版本更新，成员自定义名称保留。
- 不修改个人布局、不改变权限、不删除历史发布记录。

验收：更新页中无重复功能卡片；键盘切换与旧深链有效；真实目录可搜索和打开功能。
