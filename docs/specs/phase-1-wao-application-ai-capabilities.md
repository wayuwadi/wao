# Phase 1：WAO 应用级 AI 能力

对应任务：`t1787754998982`（WAO 长期 Skill 与 MCP 能力范围）。

## 用户结果

- 管理员在“设置 → WAO AI 能力”一次性启用通用 Skill；之后新建的 WAO Codex Run 自动把这些固定审核
  版本装配到隔离环境，不需要在每台电脑或每个项目重复安装。
- 项目设置仍可固定同一 Skill 的另一个审核版本，并优先于 WAO 默认版本；运行详情能核对来源、版本、哈希
  和 Runner 实际加载结果。
- 加载失败不会显示旧数据为成功；保存期间不可重复提交，失败保留当前选择并提供重试，空市场和零启用状态
  都有明确说明。

## 数据与权限

- `wao_application_skill_binding` 只保存应用 id `wao`、Skill、固定版本、操作者和时间；同一 Skill 只有一个
  WAO 默认版本，最多十项。
- 只有管理员或超级管理员可整体替换 WAO 默认绑定；读取接口供已登录设置页和项目配置页使用。
- 新绑定只接受市场当前公开且已审核的 Codex 版本；已经绑定后即使 Skill 下架仍保留可见，直到管理员主动
  撤销或替换，避免配置静默变化。

## 运行装配

- 入队快照先读取 WAO 默认绑定，再用项目绑定按 Skill id 覆盖，固化 `activationScope`、版本和 SHA-256。
- 设置变化只影响新运行；历史快照、包下载授权和实际装配审计保持不可变。
- 当前 Runner 只支持 Codex。有效清单遇到其它引擎时在入队前明确失败，不能静默丢弃 Skill。

## MCP 边界

本期没有通用 MCP 仓库、受控 Secret 引用、运行级短期凭据和跨 KAI 适配器，因此不实现 MCP 注册或
“对 WAO 生效”开关。个人记忆 MCP 保持成员隔离，不进入项目自动任务。后续 MCP 能力必须完成真实的
注册、授权、装配、工具白名单和调用审计闭环后再进入本页面。

## 验收

- 管理员可加载、选择、保存和撤销 WAO 默认 Skill；普通成员保存得到权限错误。
- 同一 Skill 同时配置 WAO 默认与项目版本时，新 Run 快照只包含项目版本并标记“项目设置”。
- 仅有 WAO 默认 Skill 时，新 Codex Run 下载并校验固定包，详情显示“WAO 默认”和实际加载终态。
- 数据库 migration 编号唯一；受影响服务测试、前端组件测试和生产构建通过。
- 合并后 Jenkins 部署成功，登录线上设置页能读取真实配置，并核对飞书部署通知。
