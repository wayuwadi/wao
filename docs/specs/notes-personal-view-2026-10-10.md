# 小记个人视图与筛选隔离

本规格取代 notes-author-filter-and-image-default.md 中“作者默认全部、清除恢复全部”的列表行为；配图规则不变。

小记首次打开默认“我的小记（当前账号）”，根据实时登录成员匹配文档所有者。本人通过 Skill 创建的系统文章仍属于本人的小记，受现有“显示系统文章”开关控制。成员可以主动选择全部作者、系统或某个作者；清除筛选回到我的小记。

筛选与排序以当前成员的 `wao-note-list-preferences-v2:<memberId>` 在本机保存。新版本首次使用不继承旧版 v1 的作者、标签、图片、时间或系统文章隐藏条件，旧存储不删除；之后刷新恢复本人在 v2 中明确选择的条件。切换成员先暂停偏好写入、恢复本人默认及已保存偏好，再恢复写入；未登录时不读写空成员键。

成员切换清空当前搜索、搜索定位及打开的筛选浮层，避免上一人的临时查找继续隐藏下一人的小记。偏好损坏或存储失败时使用默认个人视图，筛选仍可在当前页面操作。改动仅涉及浏览器视图，不改变文档可见性、权限或 API，不重写小记、草稿、标签或服务端数据。

验收覆盖：两个成员在同一个组件内来回切换、延迟登录、旧版条件重置、刷新恢复、全部作者和系统文章、清除筛选与原有草稿保护。
