# 规格：内置节假日日历

对应任务：`t1786587037907`（日历显示中国与国际节假日）。

## 用户结果

- 日历无需配置第三方账户，即可显示中国节假日和常用国际节日；母亲节、父亲节等按年度规则自动计算。
- 中国法定假期的休息日显示“休”，调休上班日显示“班”；中国传统节日和国际节日作为全天事件进入月、周、日、年视图。
- 节假日数据加载失败时明确提示并允许重试，不以静默空列表冒充“当天没有节日”。

## 数据真实性与边界

- 中国农历日期和法定放假、调休安排由 `cn.6tail:lunar:1.7.7` 提供；该版本已收录国务院办公厅发布的 2026 年安排。
- 未发布年度官方安排时，只按历法显示可确定的节日本日，不推测未来连续放假或调休日期。
- 国际节日采用稳定历法规则：情人节、复活节、愚人节、母亲节、父亲节、万圣节、感恩节、平安夜和圣诞节。
- 本功能是内置只读日历，不写入个人 CalDAV，也不要求外部网络在运行时可用。

## 交互与视图

- 图例固定展示“中国节假日”和“国际节日”，当前日期窗含调休上班日时补充“调休上班”。
- 月视图日期格最多显示三项，节假日与原有任务、里程碑、CalDAV 事件共用“还有 N 项”展开交互。
- 年视图查询完整自然年，月、周、日视图只查询各自可见日期窗；快速切换日期时后返回的旧请求不得覆盖新日期窗。
