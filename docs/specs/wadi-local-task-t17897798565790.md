## 本轮行为

1. 知识库总首页保留真实分类、检索、分组管理，增加常用区。常用知识库保存为成员级偏好 `knowledge-favorites`，同步显示在左侧菜单；失败可重试，不以假数据替代。
2. 无 `doc` 参数进入知识库时展示知识库首页：名称、简介、真实文档数、按分组列出的文档和更新时间。左侧始终保留目录，顶部可以切换知识库。
3. 选择文档即进入原有直接编辑器，继续使用原有自动保存、本地草稿、冲突恢复、协同机制；返回首页清除 `doc` 参数。文档大纲默认收起，由右上角按钮展开。
4. 目录提供统一新增与更多菜单：新建文档、从模板新建、文件夹分组；重命名、移动文档、另存模板、归档、回收站。已有文件夹→文档层级与文档拖拽排序继续落库。本轮不新建多级目录数据模型或新增表格编辑器。
5. 普通草图入口只请求列表，不自动打开第一张、请求版本或加载画布组件；带明确 `drawing` 参数的链接仍可直达。
6. 密码本按名称、账号、网址筛选；新建默认放在当前分组，分组用直接选择按钮展示。保存中阻止重复提交，失败保留表单；成功后选中新条目，移动分组同步列表；切换实际条目清除已显示密码。
7. 桌面只保留侧栏自身的收缩按钮；折叠菜单显示图标和短标签，保留完整名称提示。移动端保留顶部入口。
