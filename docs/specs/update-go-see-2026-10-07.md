# 更新卡片：保存刷新后去看看

日期：2026-10-07。补充更新说明开箱规格，保留卡片和按需演示窗。

每条有真实功能入口的更新增加「去看看」。有待更新版本时，点击沿用全局保存屏障：失焦提交、工作区保存、等待各编辑器保存、再次保存工作区、离开拦截检查。通过后记录用户选择，再刷新页面。保存、存储或会话检查失败时保留页面并提供错误与重试。保存期间禁用入口，重复点击只执行一次。

刷新后的已认证布局仅兑现同成员、同标签页、十分钟内、匹配当前制品的选择，并且只兑现一次。旧制品不打开功能，提示从卡片重试；成员变化、过期或无效选择丢弃。普通保存刷新清除旧选择。普通刷新无用户选择时不自动跳转或弹出介绍。

入口沿用 releaseActions.json 与功能地图；清单不得携带 URL 或业务写入动作。未知功能、错误动作关联与维护更新不展示按钮。已有目标动作按登记打开具体分类或编辑器，已有小记阅读与 AI 成果沿用真实数据与空状态。关于 WAO 登记 settings-about，对应 /settings?tab=about；更新后可直接体验，不再强制刷新。

旧制品允许读取新版的动作标识与纯文本说明，不执行尚未登记的入口。待更新时仅传递符合标识格式的选择；刷新后必须在新版登记表中严格匹配动作与功能，不能退回无关页面。当前制品未登记动作时隐藏体验入口，其他说明仍可阅读。

验证覆盖保存失败、编辑器拒绝、第二次保存失败、离开拦截、会话变化、存储失败、刷新失败、并发去重、制品错配、过期、跨成员与一次消费，并在真实后端浏览器中验证具体分类及失败保护。纯浏览器体验变化，不新增 HTTP、MCP 或 CLI 业务能力。
