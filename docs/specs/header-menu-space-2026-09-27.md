# 顶栏菜单空间优化（2026-09-27）

## 用户结果

- 普通浏览器顶栏不重复显示当前功能名和顶部菜单空状态说明，让页签菜单从顶栏左侧开始排列，并伸展填充右侧操作按钮之前的可用宽度。
- 顶部快捷菜单为空时保留一个紧凑的拖入停靠位；静止时仅显示图标，拖拽时显示状态反馈，保留原有停靠行为。
- 屏幕阅读器和悬停提示仍能识别停靠位用途；加载失败、保存状态和已有快捷菜单继续使用原有反馈。
- 新旧桌面客户端的页面上下文桥接保持不变，移动端保留紧凑布局。

## 验收

- 宽屏浏览器打开任意普通功能页时，顶栏左侧不显示“小记”等当前功能名或“拖动菜单…”提示；页签栏紧跟顶栏起始区域。
- 空顶部菜单停靠位可接收侧栏菜单、项目、知识库或快捷链接拖入，出现拖拽反馈并保留原来的保存与失败行为。
- 页面名称、层级上下文和菜单操作在旧客户端桥接模式下继续可用；窄屏下菜单、页签与顶栏按钮仍可浏览。
