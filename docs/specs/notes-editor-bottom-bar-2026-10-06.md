# 小记编辑底部信息区

补充 `notes-single-title-editor-2026-10-06.md`：卡片及阅读内编辑的标签和字数不再占用正文滚动容器。标题后仍保留新增标签、全屏与更多入口。

- 快捷标签及新增标签输入进入底部操作区第一行；保存状态、实时正文字数和保存/退出按钮位于下一行。窄屏标签可横向浏览，状态允许换行，按钮仍可触控。
- 编辑器只保留正文与图片列，正文可以显示到操作区上方。折叠卡片内编辑的正文容器最小高度为 200px，长文仍独立滚动；展开和全屏沿用已有高度行为。
- 字数使用编辑器已有 `character-count` 事件，统计实际富文本正文，不计空白、格式标记或图片地址。宿主显示时关闭编辑器内部字数，避免重复和空白行；其他文档及新建记录默认行为保持。
- 标签快捷选择、取消、新增、右键管理和失败提示保持；切换全屏不重建编辑器。保留保存失败重试、退出确认、草稿恢复和已有阅读位置。

验收：唯一字数与标签属于底部区，正文容器不含这两行；长文滚动可看后续段落；标签切换与新增失败保留正文；全屏和390px无横向溢出；真实账号读取与保存失败保护。
