# 知识库首页目录排版

按用户提供的语雀首页截图，采用浅灰背景、居中白色纸面、图标与标题同列、真实文档数量、紧凑目录与悬停浅灰底。目录统一缩进和 38px 行高，以虚线连接标题与右侧日期；日期显示到分钟，今天使用“今天”，悬停显示完整时间。长标题省略且可悬停查看。分组可折叠，文档点击继续打开原文；窄屏隐藏日期并缩小留白。一般知识库保持现有目录数据结构和排序，不伪造字数或作者统计。

小记知识库的侧边目录右上角提供“时间倒序 / 时间正序”，默认按文档更新时间从新到旧。切换后，侧边目录与首页同一分组中的小记同步按更新时间排列；分组层级与其他知识库的手动顺序不变。时间相同以文档 ID 保持稳定顺序，不改动持久化的目录结构。
