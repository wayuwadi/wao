# Phase 1：飞书个人收集表情回执

本变更收口 `@ 机器人→创建个人任务` 的群内回执，避免每次记录都产生一张卡片干扰正常聊天。

## 用户结果

- 任务创建成功后，机器人只在原消息上添加 `DONE` 表情，不发送“已加入你的任务列表”卡片。
- 语音、空内容、未绑定账号、无可用项目或创建失败时，在原消息上添加 `ERROR` 表情，不伪装成功。
- 快速收集链路不再发送任何群卡片，不触发通用“新建任务”通知，也不回落到全局 Webhook。
- 表情回执失败只记服务端日志；已成功创建的任务不回滚、不重复创建。

## 不变行为

- 仍只处理目标群中明确 @ 机器人的消息。
- 成员身份归属、未排期待办、项目选择和 MySQL 幂等规则不变。
- 其他业务的飞书卡片和 Webhook 通知不受影响。

## 验收

- 单元测试验证成功使用 `DONE`、失败使用 `ERROR`，且不调用群卡片或通用新建任务 Webhook。
- 真实群内新发一条 @ 机器人消息：任务只创建一次，原消息显示完成表情，群里不出现新回执卡片。
