# Phase 1：外部应用 Skill 接入入口

对应任务：`t1787754826156`（其他应用 Skill 能力接入）。

## 用户结果

- WAO 登录成员可从「公共」分组的一级菜单进入「Skill 接入」，把微信读书、得到等外部应用
  Skill 的后续接入集中在一个入口管理，不与 WAO 自有的 Skill 市场混在一起。
- 入口在尚未接入任何外部应用时展示明确空状态，并说明后续接入必须具备官方或可靠的能力接口、
  可撤销授权和真实连接状态；不得用静态卡片、演示数据或浏览器明文凭据伪装已接入。
- 页面提供 WAO Skill 市场的关联入口，帮助用户区分「安装经过审核的工作流包」与「授权外部应用
  账号能力」是两条不同链路。

## 本期范围

- 新增稳定模块 id `skill-connections`、受保护路由 `/skill-connections`、WAO 页签和内置菜单注册项。
- 既有内置菜单注册表读取时自动补上新入口，保留成员已经配置的菜单名称、分组、排序、显隐与
  打开方式；设置页仍可统一调整新菜单元数据。
- 本期不接入具体第三方应用，不收集 API Key，不展示虚假的应用、能力或连接状态。后续每个提供方
  必须基于可核验接口和凭据保护方案另行补充规格、实现与验收。

## 验收

- 桌面和手机导航均能看到「Skill 接入」，点击后在 WAO 页签中打开 `/skill-connections`。
- 页面在无真实连接时显示「还没有已接入的应用 Skill」，且没有新增、授权或配置等不可用按钮。
- 服务端读取旧版内置菜单注册表时自动补齐 `skill-connections`，保存时仍拒绝未知或缺失的稳定 id。
