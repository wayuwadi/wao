# 规格：日历大小周

对应任务：`t1786585781488`（大小周工作制）。

## 目标

- 当前登录成员可以在日历中启用或关闭大小周，并指定任意一个参照周是“大周”还是“小周”。
- 大周表示该周周日上班，小周表示周六、周日双休；相邻自然周始终交替。
- 本需求的初始使用场景是“本周双休”，配置界面默认把今天所在周作为小周参照，用户保存后即可向前、向后查询。

## 数据与计算

- 配置使用成员级偏好 `alternate-work-week`，通过 `/api/preferences/{key}` 按当前登录成员隔离持久化，不生成伪造日程或 CalDAV 事件。
- 偏好值为 JSON：`enabled` 表示是否启用，`anchorWeek` 保存参照周周一的 `YYYY-MM-DD`，`anchorType` 为 `big` 或 `small`。
- 工作周固定按周一至周日计算，不受个人日历“周一开始 / 周日开始”的显示偏好影响；参照周前后的所有周均可确定性计算。
- 空配置、损坏配置或读取失败时不显示工作周标识，避免把默认值误当成用户已经保存的安排。

## 交互与状态

- 日历顶部展示“我的大小周”入口；启用后入口直接显示本周是大周还是小周以及周日是否上班。
- 月视图在每个周日标明“大周 · 周日上班”或“小周 · 双休”；周视图在周日表头标明本周状态；日视图表头标明当天所属周状态。
- 配置浮层覆盖读取中、读取失败重试、保存中、已保存与保存失败重试；未保存草稿按登录成员暂存在浏览器中，主动取消或保存成功后清除。
- 关闭大小周只停止日历标识，不删除已保存的参照周，重新启用时可继续使用原轮换。
