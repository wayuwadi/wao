# 裂隙远征首发规格与设计基线

2026-10-03。恐龙荒野已正式上线并完成公网核验后开始本款。基于已确认A2，用户取消逐款Demo确认；仍按一个完整游戏逐款验收、合并、发布，不减少已约定内容。稳定gameId=`rift`，橙色/像素游乐场布局；原创明亮琥珀峡谷、大头小队、橙金刀光，固定2D侧视像素边缘插画。

## 核心操作与成长循环

A/D或左右移动，空格跳跃，J普攻（剑刃三段连击；星枪按住蓄力、松开发射），Shift消耗体力闪避，K/L/U对应三个主动技能槽。W/上键同样跳跃，S/下键落地防御/快速落下。输入仅聚焦舞台，弹层/失焦/后台清按键、停帧、停音效；明确按继续恢复。鼠标点击菜单，触控左侧移动跳跃、右侧攻击闪避和技能，最小44px，竖屏保持可读角色尺寸，不整体压缩游戏。

营地选职业、装备与技能→选章→两段实际战斗→独立Boss房→奖励结算→装备/技能成长→新章或重挑战。失败回检查点/营地，消耗的本房临时资源重置，不清永久成长。没有自动战斗按钮；普通攻击、技能、敌方攻击均有位置、方向、范围、前摇、命中和受击反馈。

剑刃靠近敌人，普攻三段有不同范围/硬直，弹反在短窗口内化解命中并反击；星枪需保持距离和管理蓄力时机，远程弹丸有真实飞行和碰撞，位移技能改变射线角度。基础闪避体力有限，连续站桩不能抵消所有Boss机制。

## 完整首发内容

3章，每章两战斗段和独立Boss房：

1. 琥珀峡谷：追击与远程夹击；Boss岩鼓守卫以蓄力震地要求跳跃，冲撞要求移位/闪避。
2. 棱镜工坊：正面护盾、跃击和空间封锁；Boss棱镜机核需击破两侧供能晶体，限时破盾输出，护盾恢复后再次处理机制。
3. 映光回廊：爆弹与治疗支援，目标优先级影响战斗；Boss映光游侠有三个分身，真身脚下金环，错误命中诱发反击，阶段切换重辨识。

6种普通敌人：追击者、弧光射手、盾卫、跃袭者、爆弹手、织光医师。3种精英变体：带冲撞的破岩卫、三向蓄力射手、护盾治疗师。各自前摇/范围标记明确，不以血量换皮充数。

12件装备：剑刃3武器（均衡/重击/快刃）、星枪3武器（侦察/蓄能/散射）、6护符（生命防御/闪避机动/能量恢复/灼烧/高伤低防/技能冷却）。职业各一武器槽与一护符槽；属性有取舍，不能只换颜色。房间和Boss掉落装备，重复装备转为锻造材料，营地可定向打造已解锁层级装备，不强制等待或付费随机。

每职业6个技能节点，最多3个主动槽，可升阶、换槽；剑刃为弹反、升龙、旋风、突刺、震刃、战意；星枪为贯穿、地雷、闪移射击、弹幕、涡流、过载。有限技能点在节点间分配，可免费重配，避免早期试错锁死玩法。每个技能有不同范围/位移/控制/防御用途与资源代价。

## 界面、素材和记忆

中央Canvas舞台，顶部简短房间目标/生命体力能量，底部核心控制；营地、章节、装备、技能、暂停及奖励均为页内面板。原创Canvas角色、敌人、刀光/枪弹/预警与合成音效，默认静音，用户手势后启用。未引入大引擎或商业素材。

本机/仅本次、单款/全部导出、严格导入校验、备份恢复和CAS冲突沿用已上线记忆契约。规则v1保存职业、等级经验、材料、已拥有及已装备的装备、两职业技能成长/槽位、章节解锁、通关纪录、声音偏好，以及安全检查点（章/房间/种子）。每房开战前与奖励确认及时保存，恢复从该房开始，界面写清不恢复半次挥刀；防止刷新重复领取同一次房间奖励。

第二款实际需要时才抽取账号无关记忆注册表、通用容器与消息封套。恐龙规则v1与已有数据库键保持兼容，导入两款先完整验证再原子写；首款必须回归，不因共享调整更换其游戏制品。

## 2026-10-03 实战平衡与触控补充

- 星枪触控可选“轻触蓄力、再点发射”，默认仍为按住/松开；键盘J不变。暂停/切换/失焦一律取消蓄力。屏幕显示蓄力百分比与就绪状态。
- 首章第一房保留单次教学遭遇，其余普通/精英房增加第二次有1.5秒可见入口预警的侧后方增援。第二次遭遇使用盾卫/治疗/爆弹/跃袭/精英的不同方向组合，迫使玩家转身、聚怪或优先处理支援；房间奖励只在全部遭遇结束后结算，不增加重复奖励刷取。
- 后两章敌人生命随预期成长提高，避免贯穿构筑在其前摇展开前秒掉整房。精英医师为附近伙伴提供3.5秒护盾，贯穿或优先击杀医师可处理。
- 供能中的主核吸收贯穿弹，必须转移站位处理两侧晶体。幻镜分身吸收弹丸并反击，不能靠直线贯穿绕过辨真；真/假共享名称，通过金环辨识。重新执行这些变化后的真实关卡与Boss验收，旧基线通关截图不代替最终验收。
