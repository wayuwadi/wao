# Phase 1：个人记忆驱动的图文创作与发布数据

决策见 [ADR-197](../adr/197-grounded-personal-content-context-and-metrics.md)。

## 用户结果

- 成员在内容工作台新建图文时，可以写下话题和自己的想法，或直接粘贴一段对话；这部分原文与草稿一起持久化。
- 开启“结合 WAO 内容”后，生成会自动检索当前成员的个人记忆、知识库、私人 AI 对话和过往成稿，并继续遵守账号定位中的受众、主题、结构、语气与配图风格。
- 成稿展示本次实际参考的来源类型、标题和摘录，成员可以打开仍然存在的站内来源核对；关闭上下文时不读取这些资料。
- 内容继续在 WAO 内完成创建、编辑、审核、待发布和已发布管理。首篇待审核稿为《为什么我要做 WAO：我想成为朋友们随时可以找到的程序员朋友》。
- 已发布文章可保存真实发布链接，并按时间追加阅读、点赞、评论、收藏和分享数据；未填写的数据保持未知。

## 状态与数据边界

- 新建、生成、加载、保存和数据记录失败时保留页面输入，并提供明确重试入口；后台轮询不得覆盖未保存的正文或数据草稿。
- 上下文按当前 WAO Session 推导账号和成员，不接受前端传入其他成员 id。仅自己知识库只读取本人创建的文档，成员可编辑知识库可以作为共享来源。
- 生成来源保存为当次快照；知识库或记忆后续变化不修改历史来源。内容导出和平台发布只包含人工审核后的标题、正文、标签与素材，不附带私人来源。
- 发布数据只接受非负整数。手工录入不会伪装成平台自动同步，官方接口不可用时不显示实时数据承诺。

## 验收

- 输入话题和想法创建草稿，刷新后原文仍在；关闭“结合 WAO 内容”生成时没有上下文来源。
- 开启上下文后，测试数据中的个人记忆、本人知识文档、私人对话和过往成稿各自最多进入两条，其他成员私人数据不出现。
- 生成完成后页面能看到来源快照，编辑正文、导出 HTML 和保存到知识库的既有流程仍可用。
- 将内容标记为已发布后可保存发布链接与一组数据；再次保存产生第二个带时间的快照，历史值仍可查看。
- Agent 后端测试、Agent 前端测试、类型检查和生产构建通过。
