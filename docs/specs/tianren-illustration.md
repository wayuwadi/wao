# 天人一卦图文结合配图

依据 ADR-320 与用户确认的第一版 Demo，扩展 `tianren-local-codex.md`；完整设计和默认提示词见 `../plans/tianren-illustration-design-2026-10-04.md`。

## 用户链路

在当前页面「解读与配图设置」修改两项提示词、恢复默认、启用/关闭解读时一起配图。保存只影响之后的新任务；自动图片按文字任务入队时快照生成，手动重画使用当前图片提示词。多设备冲突返回 409，客户端保留草稿并展示新旧设置供比较。

正文顶部由真实 DTO 展示卦象事实，旁边显示图片及变化、保持短句，下方保留其余八章节。只对符合全部九标题的受控 Markdown 去掉第一节重复事实，无法确认结构时保留原文。

文字任务以 `TIANREN` 入队，注册 `tianren-interpretation-v2` 协议；成功后纯 Markdown 进入私有会话，图意进入领域记录。正文有效但摘要不完整时为 `BRIEF_FAILED`，保留文字，要求重新解读；JSON/正文无效时本次文字失败，旧成功内容保留。历史旧协议运行无视觉记录，继续原有完成方式。

开启配图时，文字成功持久化 `PENDING`；现有本机 worker 推进到 `TIANREN_IMAGE`，以真实 PNG 完成。状态查询将持久待办映射为 `QUEUED`，并依据图片运行状态恢复排队/运行/超时或中断失败；不因状态读取而生成图片。

同一解读重画时旧图继续可读，失败后可单独重试。解读版本变化时前端释放旧图并读取新的图意，不把旧图片展示为新结果。关闭页面后 worker 继续；可见页面有活动任务才约 5 秒查询。

入队被拒绝或持久待办超过一小时时结束为失败，提供主动重试。通用聊天另写入最新回复后，不继续展示与新正文不对应的旧配图；下一次从卦象页面正式解读可重新建立对应关系。内置图片工具在同一线程重绘时，只接受该线程中最后落盘的唯一 PNG；时间相同、目录归属不明或字节校验失败均拒绝保存。

## 权限和数据

所有新增接口要求真实成员身份、卦象所有权。图片不存入匿名图床或参考图库；状态响应不含提示词、关注点和二进制。图片接口校验 reading/attempt/member 的关联，返回 PNG、no-store 和 nosniff，前端鉴权读取 Blob 并释放 Object URL。

成员设置存在 `member_preference:tianren-ai-settings-v1`，每项提示词 1–4000 字。整个 JSON 可超过通用偏好 4000 字上限，只能经专用设置入口保存；通用 PUT 拒绝该 key。

新增 migration `V181__tianren_private_visuals.sql` 创建两张表，已执行版本不可修改。公开分享页面保留现有文字投影；有效分享链接在飞书预览时，可按 `feishu-share-visual-cards.md` 读取与当前正文一致的已保存摘要和成功图片，并上传给飞书应用，不新增匿名图片接口。群通知不等待图片、不自动启用。历史仅看已有图；今日有效摘要可主动重画，包括自动配图关闭时。

接口契约见 `../api/tianren-visuals.md`，数据结构见 `../database/tianren-visuals.md`。现有 MCP/CLI 没有私有起卦授权，本次不扩权，台账记录于 `wao-cli.md`。
