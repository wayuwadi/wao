# 项目任务收尾计数

取代项目卡片持久化 `progress` 的展示口径，不恢复项目状态或项目总览。

- 一条任务实体（含 `parentTaskId` 关联的独立任务）按 ID 计一次。主任务状态为「已完成」且其全部内嵌清单子项 `done=true` 才算收尾。「待验证」仍未收尾；不自动改写任何任务状态。
- 内嵌清单以 `subs` 中每个条目计一次，扁平存储覆盖全部层级；单列「内嵌子项未收尾 X／共 Y 项」，不加入任务实体总数。完成父子项不意味着自动完成其下级。
- 卡片显示「未收尾 X 项／共 Y 项任务」，空项目显示「暂无任务」。不显示目标进度百分比。原个人「按进度」偏好键保留，界面改称「按任务收尾率」，按已收尾任务数 / 任务总数降序，零任务置底。
- 任务页签统计整个项目，不随负责人、创建人筛选变化；标题说明范围。筛选提示单独显示筛选内未收尾及总任务数，收尾仍按该任务全部子项判定，避免隐藏别人负责的子项后误判完成。
- 表格、分组、四象限、看板都保留未收尾任务。主任务已完成时明确显示剩余子项数；看板仍按真实主状态放在「已完成」列，但只折叠已收尾任务。不改变状态、个人布局、排序或现有完成缓冲。
- 任务数据加载失败/加载中不展示确定计数。全局搜索的项目摘要使用同一口径，不显示旧项目状态和持久化进度。

本轮是浏览器派生展示，没有新增 API、数据库变更、CLI/MCP 工具或权限。既有 `progress` 字段保留兼容，不回写历史数据。

回归与使用方法见 [项目能力回归](../runbooks/projects-regression.md)。
