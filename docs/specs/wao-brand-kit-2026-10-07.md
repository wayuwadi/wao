# WAO 品牌验收与资源交付

沿用用户确认的 v4 柔环 W、圆角字标和伙伴方向，补充 `wao-brand-refinement-2026-10-06.md` 与 `wao-brand-runtime-mask-2026-10-06.md`，不覆盖历史规格。

## 可观察结果

- 图形、字标、横向组合、单色深浅版本、小尺寸图标和浏览器图标能独立下载，并有一个包含规范与文件摘要的完整 ZIP 资源包。
- `/brand/guide.html` 展示正式素材、背景用法、16/24/32px 图标、留白、最小尺寸、配色和下载入口；是独立品牌参考页，不新增工作区常驻入口或界面内容。
- 应用字标与导出字标从同一份几何数据生成，路径及线宽一致；标准图形继续使用已确认 SVG 母版，品牌公共路径保持 `/brand/`，不受不可变发布 base 改写。
- `docs/design/wao-brand-usage.md` 为当前使用规范，列出适用素材、导航折叠规则、角色特征及复用方式。ZIP 只包含当前正式素材、此规范、参考页和摘要，不打入用户资料、历史方案或工作区文件。

## 验收

在连接既有业务服务的本地浏览器检查登录入口、桌面展开/折叠、320/390px 呼吸及分享页、浅深色与资源下载；分享页使用真实既有对象，不创建演示账号或业务数据。生产构建检查主站资源地址；用独立 ZIP 读取器验证完整性与内容摘要，核对 SVG 可渲染、PNG 尺寸与透明度。发布后核对版本、品牌摘要、参考页和受影响页面。

手机宽度是视口模拟，实体手机、系统主屏幕图标和浏览器缓存刷新由用户最终验收；不以模拟宽度宣称实体设备已测。无 API、数据库、MCP、CLI 或部署拓扑变化。
