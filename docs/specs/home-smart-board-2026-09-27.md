# 首页智能看板（2026-09-27）

## 目标

首页作为看板保留天气、今日卦象和 Codex 额度三个实用信息入口；其余当前首页数据卡片暂时从首页移除，并留出等待自动推荐数据的空白区域。

## 展示与行为

- 顶部保留真实天气、真实 Codex 额度及权益信息，以及今日卦象入口。
- 今日卦象仅调用现有 `GET /api/tianren/readings/today` 读取服务端结果。未起卦时展示空状态并链接到「天人一卦」；不得因访问首页而调用创建卦象接口。
- 主看板显示「这里是一个看板」「有自动推荐能力的数据可以在这里显示」「暂时没有好的想法，先留空」，不生成或伪造推荐内容。
- 原今日待办、最近创作、项目速达、笔记挖掘和准则卡片从首页视图移除；其数据、功能及其他入口保持原状，不执行删除或数据迁移。
- AI Run 控制台及其现有深链行为保持原状。
- 3D 视觉由 CSS 图层和变换构成，支持窄屏布局及 `prefers-reduced-motion`；无需新增运行时依赖。

## 验收边界

首页天气、卦象和额度沿用各自既有加载、错误和重试逻辑。卦象读取失败可独立重试，不影响天气或额度。此变更不更改后端 API、持久化结构或自动起卦策略。
