# WAO 蓝青丝带品牌标识

用户从九种候选中选择第 4 款「未来科技」：蓝青至靛蓝的立体连续丝带，表达 AI、连接与无限。使用 ImageGen 从已选概念提取纯图形，移除编号与浅色字标；保留透明背景。内置工具提示词要求保留丝带轮廓、折叠和颜色，仅移除文字。PNG 原始资产位于 `wao-web/public/brand/wao-ribbon-v1.png`，尺寸派生由 sips 等比例导出，不重新绘制。

## 应用范围

- 侧栏、登录页（包括窄屏卡片）、Skill 市场、HUB、桌面宠物下载页及任务、文档、文件分享入口使用统一 `WaoLogo`。
- 图形旁的 WAO 使用继承页面文字色的字标，兼顾明暗背景；不使用概念稿的浅蓝文字。
- 侧栏展开时展示品牌；窄屏隐藏字标保留图形，折叠按钮仍可操作。原生客户端已有顶栏时，保留网页侧栏不重复展示品牌的规则。
- 浏览器 favicon 使用 64px PNG，Apple 图标使用 180px PNG，manifest 使用 192 / 512px PNG。版本化资源路径避免旧图标缓存；512px 图形用于页面显示。
- 本次不改变主题配色、登录行为、接口或数据。独立客户端安装包和原生系统图标继续由对应客户端发布流程管理。

## 验收

类型检查、生产构建及登录/分享/移动导航回归；连接既有本地后端的真实数据页面，检查侧栏展开与折叠、窄屏不遮挡操作、公开市场导航及分享入口。检查登录页与明暗底色下的标识和浏览器图标资源。
