# 小记保存回显与编辑区域一致性

补充小记左右工作区及完整文档编辑规格。

- 清单以保存的富文本 JSON 为正文来源，复用文档编辑器只读渲染，保持嵌套列表层级、编号和文字格式；只有旧数据没有 JSON 时才从 Markdown 恢复。
- 编辑正文填满可用区域，空白处可点击输入。图片入口位于正文下方底部，长内容在正文区域滚动；桌面和全屏中入口不随内容漂移，窄屏保持可操作。
- 编辑区标签选择面板可直接新增标签，调用现有持久化接口；成功后选中并更新清单字典，失败保留名称并支持重试。沿用名称长度、每篇最多 20 个、草稿及原子保存约束；标签创建期间禁止提交正文，避免异步标签遗漏。

验收：嵌套编号列表保存、回看和重新编辑一致；正文底部空白可输入；短文、长文、全屏、窄屏图片入口可见；编辑区创建标签失败重试、保存并刷新后标签仍在。
