# 星野奇旅首发规格

2026-10-03。第三款独立交付，前置裂隙已正式上线并完成公网核验。沿用已确认A2金色星野/奶黄浮岛/等距探索+固定阵列战斗方向；用户已取消后续Demo确认，直接实现。不得删减A2的六角色、三宠物、四属性、三章九任务、四技能/两成长分支、十二装备、六敌人/三Boss范围。

## 核心循环和内容

在浮岛探索地图选择任务→接取任务并选择路线/援助决策→配置三人队伍与协战伙伴→读取速度顺序、敌人行动意图→选择技能及具体目标确认→奖励、装备/技能分支成长→完成该章两条支线解锁守关任务→下一章或重访挑战。三人手动逐回合行动，宠物是有限蓄能的协战指令；不做自动战斗或单目标反复点击。

三章每章三任务，共九个可接取/完成/重访节点，前两条可交换探索顺序；第九任务结束本篇旅程，保留章节重挑战。每个任务先有一个短探索决策，影响本场资源、敌人或奖励，不依赖大段对白：

1. 晨穗浮岛：修复风铃渡桥、找回信使行囊、唤醒日晷守卫。追击/盾卫教学，守卫蓄力与反击姿态要求控制、护盾或防御，不是普通敌人加血。
2. 潮墨书湾：清理墨潮航道、援救档案员、对抗封页司书。吸能、治疗支援与禁疗结合，优先处理支援、净化或改变输出目标。
3. 雷芽天台：追踪迷路星轨、重接四象灯塔、修复星轨仪。敌人控制/集火，最终Boss每阶段转换属性，以克制攻击积累破绽打断强力群攻，队伍属性与行动安排影响打法。

六类普通敌人：疾行斥候、护阵盾卫、织露医师、灼羽蜂、吟咒者、汲能灵。每个有可识别的行为与实际目标/资源/状态区别。每章独立机制Boss。必要时使用有限增援，不增加无限重复关卡凑数量。

## 队伍与策略

六名从营地可配置的原创队员，出战三名：炽芽（炎/输出）、露弥（潮/治疗）、叶铃（森/控制）、闪尾（雷/游击）、晶芽（雷/支援）、岩芽（森/守护）。每人四技能（含零耗基础动作），另有统一防御恢复资源；角色剪影、图标和名称并用，不靠颜色区分。

四属性循环：炎克森、森克雷、雷克潮、潮克炎。技能有自身属性；克制/抵抗倍率、护盾、灼烧、迟缓、禁疗、眩晕/打断与增益由纯战斗逻辑计算。速度决定每轮顺序，迟缓改变后续轮次、延迟技能可改变当轮尚未行动目标的位置。玩家先选择技能，再选合法目标，确认才消耗资源；取消不耗费行动。敌人意图显示动作与目标，控制/击杀可取消其行动。

每人两条成长分支，各三阶，有限等级点在两条间分配，可免费重配。分支改变技能用途（净化/扩散/反击/护盾分摊/资源返还等），不仅加生命。十二件装备（六武器、六饰品），每人一武器一饰品；所有人可用但效果与职责配合，有速度/输出/治疗/生存/费用取舍。任务奖励与营地定向制作提供明确获取路径，不付费、不强制等候。

三种协战宠物：晨灯鸟（补充异属性伤害）、露团（治疗与净化）、磐角（队伍护盾与本轮下一次群攻减伤）。行动与有效克制积累协战能量，一轮至多一个协战指令；配置和时机改变战斗结果。不是宠物收集养成玩法，避免与第四款重叠。

## 表现、输入与保存

地图用原创SVG等距浮岛和可见路线，战斗用固定两阵营角色卡/原创矢量角色、意图、行动顺序、短命中特效与合成音效。Vue3/TypeScript/Vite，不增加依赖。桌面战场居中，右侧操作；窄屏上下阵列、目标卡至少44px，操作面板整块切换，不等比缩成小按钮。

鼠标和触屏选择，方向键切合法目标、Enter确认、Escape取消/暂停；焦点只在游戏舞台，输入框不拦截。回合动画与敌人行动计时器在暂停、失焦、后台和父容器切换时停止，恢复由明确按钮触发。没有持续空跑帧循环。页面内队伍/装备/任务/暂停/结算面板，沉浸沿用已验收容器。

稳定gameId=`starfield`，规则v1，账号无关。保存角色经验、技能分支、阵容、宠物、装备、任务/路线/章节、资源、通关纪录，以及**已提交行动后的完整回合快照**；刷新恢复后先暂停，继续才执行下个行动。行动和奖励使用幂等标识，不能刷新重复领奖。逻辑与存档结构分离，严格校验属性/实体/技能/装备引用、队列、阶段、状态时长与数值范围；导入不执行文本内容。全部导出扩展三款，保留前两款v1及稳定DB键。每次关键行动/奖励保存，不靠关闭事件。

## 不降低的验收标准

- 六角色、每人四技能/两分支、三宠物、十二装备、六普通敌人和三Boss全部可用；速度/属性/目标/资源/状态真正影响结果，至少两套有效配队。
- 真实浏览器完成三章九任务、三Boss及队伍成长，覆盖治疗/控制/属性破绽和宠物协战；另一次失败重试，重访挑战能重新开始。
- 核心逻辑测试覆盖行动队列、死亡跳过、状态时机、禁疗净化、护盾/克制/费用、敌方策略、分支与宠物、奖励幂等；组件覆盖选技能/目标/取消/确认、暂停和恢复。自动模拟平衡与真实操作分别留证。
- 行动中本机刷新暂停恢复；真实单款及全量导出、独立存储导入续玩；损坏/不兼容/越界/超限、失败重试、跨页冲突与备份、仅本次模式。
- 桌面/360像素实际操作，声音可关闭、输入归属、后台分支与真实失焦、控制台及代表性性能；类型/Lint/构建，受影响恐龙/裂隙与呼吸静坐/六布局回归。
- 仅构建本款和实际受影响主站，前两款制品不重建；中文提交→独立PR→合并→复用现有发布批次→静态发布→公网版本/资源/健康与真实游戏→报告后才开始幻兽领地。

本规格不新增HTTP API、业务数据库或账号存储，wao-cli-sync无需扩展。消息仍用版本1并校验origin/source/instance/seq；新增游戏登记按真实依赖扩充host和发布工具，部署边界沿用ADR-310/312，不为游戏改后端。
