# 小记正文选区安全缩进

2026-10-04 用户反馈：小记选中文字后按 Tab，选中内容丢失，预期是缩进。本规格补充 `notes-list-and-selection-ux.md`，修订 `editor-image-tab-indent.md` 与 `phase-1-knowledge-document-productivity.md` 中普通正文及代码选区的 Tab 规则；图片单独选中、表格导航与列表层级规则继续沿用。

## 用户可见行为

- 普通正文光标按 Tab 缩进当前逻辑行；选中文字按 Tab 缩进所触及的逻辑行，不替换任何正文。一个段落中的硬换行按独立逻辑行处理；选区末端恰好位于下一行开头时，不缩进下一行。
- 普通正文每级增加两个可见空格，最多八级；Shift+Tab 从行首减少一级，兼容历史制表符与普通空格。没有行首空白时不删正文。选区方向、原文字格式、链接、图片及块结构保持；选区与光标随变动映射，不跳到文末。
- 单一列表范围沿用层级下沉 / 提升，首项不能下沉时保持原文。跨普通正文、列表、图片、代码或表格的混合选区逐行处理，保留列表与表格结构，列表文字在行首增加空白，不改变列表层级。选中的图片沿用已有 0–8 级图片缩进，不改变 URL、长宽、标题及原对齐属性；单独选中列表内图片也仅调整图片。
- 表格内部 Tab / Shift+Tab 继续切换单元格。代码块光标 Tab 继续在光标处输入两个空格；非空代码选区按所触及的完整逻辑行增加 / 减少两个空格，跨出代码块时仍保留代码与后文节点，不用纯文本替换跨块选区。
- 每次缩进或反缩进是独立撤销步骤，不与前后输入合并；支持一次撤销和重做。其他单独选中的原子节点不改动。只读编辑器不会因 Tab / Shift+Tab 改写内容。
- 全屏小记的父层焦点循环忽略编辑器已经处理的 Tab，焦点留在正文；快捷键帮助说明当前行、所选行、列表和图片的区别。

## 保存与能力边界

遵循 ADR-015 与 ADR-198：现有版本 1 富文本 JSON 与 Markdown 投影继续使用，不新增节点、属性、数据库字段、API、MCP、CLI 命令或权限。普通正文缩进使用两个 NBSP，避免 Markdown 将行首 Tab / 四个普通空格识别成代码块；标题 Markdown 将其行首缩进编码为安全 `&nbsp;` 实体，读取时还原，其他标题正文与格式不变。图片继续使用既有缩进元数据。小记保存、草稿保护、失败重试和冲突处理沿用 `notes-single-latest-content.md`。

## 验收

- 普通部分选区、反向选区、多段全选、硬换行、末端行首均保留原文和选区；粗体、链接、图片属性及列表节点保持。
- 选区跨代码、列表、图片和表格不丢正文或结构；单独图片、单一列表、表格导航和代码光标行为回归。
- 缩进上限、连续反缩进、单次撤销 / 重做、后续输入撤销、只读与全屏焦点保护通过编辑器测试。
- Markdown 与版本 1 JSON 回读后缩进、文字格式、列表和图片一致；真实小记保存后刷新重开验证由本次浏览器验收记录补充。
