# Web 版本更新提示不打断编辑

本规格修订 `phase-1-long-lived-page-deploy-recovery.md` 中的居中升级弹窗和直接刷新行为。

## 用户结果

- 已打开的 Web 页面继续每分钟和重新聚焦时检测真实构建版本。发现新版后，仅在右上角显示明显的红色通知；通知不遮盖全屏、不抢焦点、不改变当前输入。重复事件只保留一个通知。
- 用户点击“保存并更新”后，等待工作区待保存内容、注册的表单保存任务及 `beforeunload` 守卫。任一步失败都留在当前页面和草稿，显示错误并允许重试；全部成功才刷新。
- 设置页的手动版本更新也走同一保存屏障。动态分包加载失败仍只提示手动恢复，不自动刷新。
- 桌面容器自身的安装更新继续通过原生顶栏进入，下载与安装由用户确认；WebView 内的 Web 版本通知遵循上述规则。静态资源 Service Worker 激活不主动刷新页面。

## 验收

- 模拟新版事件时输入框焦点和文字保持不变，无模态遮罩或自动刷新。
- 点击通知时，保存失败不刷新；保存成功才调用页面刷新。设置页也覆盖表单保存屏障。
- 在真实 Web 页面注入版本事件，确认通知位置、编辑不中断和窄屏可见性。
