# 规格：系统功能优化与日历排期

对应任务：`t1785374821595`（系统功能优化&BUG 收集）。

## 首页

- 首页各区域均使用独立卡片，压缩 hero、运行中与历史记录的留白；运行信息、空状态与失败入口不丢失。
- 桌面和手机均应在首屏看到理念、运行状态入口和至少一个内容区。
- 桌面宽屏将理念 hero 与「给我一个目标，剩下的交给 AI」并排放在首页顶部；空间不足时回落为单列，
  不压缩目标输入和运行状态内容。
- 「给此刻的你」与自主进化建议已从首页下线；首页不再生成、展示或派发这两项能力，生产主节点也关闭对应
  定时生成与自动派发。AI 控制台继续只读展示真实 Codex 周剩余额度；服务端实现和既有数据暂时保留，后续
  需要时可重新评估入口与启用方式。

## 新建任务默认项目

- 默认项目是成员级偏好，键为 `default-project`，由 `/api/preferences/{key}` 按当前登录成员隔离。
- 新建任务仍优先采用入口明确传入的项目和未提交草稿；没有这两者时才使用个人默认项目。
- 默认项目已完成、删除或当前不可见时，回退到首个进行中项目。

## 子任务排序

- 未完成子任务可使用拖拽调整顺序，排序后整任务写透服务端。
- 排序只移动数组位置，不修改子任务稳定 id，既有分享链接和 AI 子任务运行关联不失效。

## 日历成员隔离与任务清单

- 日历默认选中当前登录成员，展示该成员负责且已设置日期或时间段的任务；已完成任务保留在原排期位置并以删除线标识，查看他人日历必须显式切换成员。
- 右侧「待安排任务」默认只展示所选成员未分配时间的任务与已逾期未完成任务，不把正常排期中的任务重复堆入清单。
- 清单集中提供「未排期 + 已逾期」「仅未分配时间」「仅逾期未完成」三种筛选；先按优先级
  `P0 → P3`，同优先级再按截止日期升序，未排期任务最后。
- 清单中的任务可拖到月视图日期格完成或调整排期；时间段任务保留原始起止时刻。

## 项目状态维护

- 项目设置提供「规划中 / 进行中 / 有风险 / 已完成」状态维护入口，保存后通过项目 PATCH 接口持久化，
  刷新页面后状态不回退。

## 项目与知识库

- 新建项目只创建项目本身，不再自动生成或关联知识库，避免未使用的空库堆积在知识库首页。
- 既有默认项目知识库种子进入回收站并保留 7 天；用户自行创建的知识库和后续主动建立的项目关联不受影响。

## 日、周、月视图与时间段

- 日视图和周视图共享 24 小时时间轴；在空白小时格按下并拖动可框选连续整点时间段新建任务。
- 新建任务和任务详情都能设置 `startAt/endAt`；两个字段写入 `task.detail_json`，不修改已执行 migration。
- 时间段必须满足结束晚于开始；月视图按开始时间展示 `HH:mm`，日/周视图按起止时间定位。
- 普通任务继续使用 `due` 截止日期，兼容历史数据。

## 菜单统一管理

- 外部应用注册表继续管理应用入口和健康检查。
- 新增内置菜单注册表 `/api/settings/navigation/builtin-menus`，统一维护名称、Remix Icon、分组、排序和显隐。
- 内置菜单稳定 id 与路由不可增删或修改；配置损坏时回退代码默认值，避免导航被清空。
