# 规格：系统功能优化与日历排期

对应任务：`t1785374821595`（系统功能优化&BUG 收集）。

补充任务：`t17872045480150`（删除保护与 AI 运行停止入口）。

## 删除保护与 AI 运行停止

- 对服务端持久数据执行删除前必须经过二次确认；确认内容应点明对象名称、级联影响、是否可恢复，取消后不得调用删除接口。
- 知识库、文件夹和文档删除进入回收站前仍需确认；回收站彻底删除必须明确提示不可恢复；文档模板删除也需确认。
- 回收站可恢复知识库、文件夹和文档本体；恢复知识库时其下随库删除的文件夹与文档一并回来，原项目关联、分组、权限与内容不得丢失。
- 任务评论、子任务和自定义属性等会立即写透服务端的删除同样需要确认。仅编辑尚未保存表单时移除一行不属于持久数据删除，不额外打断用户。
- 首页 AI 运行详情对 `queued / claimed / running` 状态提供“停止任务”按钮，任务详情的既有停止入口使用同样的确认保护；确认后调用真实暂停接口，运行进入 `cancelled`，任务回到进行中，Runner 终止本地 AI CLI 进程树。终态运行不展示停止入口。

## 首页

- 首页各区域均使用独立卡片，压缩 hero、运行中与历史记录的留白；理念 hero 内保留真实 Codex 周剩余额度、动态执行槽位与 AI 详情入口，运行信息、空状态与失败入口不丢失。
- 桌面和手机均应在首屏看到理念、运行状态入口和至少一个内容区。
- 桌面宽屏将理念 hero 与「给我一个目标，剩下的交给 AI」并排放在首页顶部；空间不足时回落为单列，
  不压缩目标输入和运行状态内容。
- 「给此刻的你」与自主进化建议已从首页下线；首页不再生成、展示或派发这两项能力，生产主节点也关闭对应
  定时生成与自动派发。真实 Codex 周剩余额度只读展示在首页理念 hero 内；服务端实现和既有数据暂时保留，后续
  需要时可重新评估入口与启用方式。

## 界面控件风格

- 设置 → 偏好提供成员级的「系统默认 / 极简风格 / 详细风格」选择，键为 `control-style-v1`，
  通过 `/api/preferences/{key}` 按当前登录成员跨设备保存。系统默认当前跟随极简风格，以后可调整默认映射，
  但用户明确选择的极简或详细不随默认变化。
- 极简风格只收起选中值或控件文案已能清楚表达用途的可见标签；自主目标和 AI Run 派工的工作流、
  执行电脑、模型、推理强度和账号，以及待安排任务筛选和工作空间切换等高密度控件按该规则紧凑展示。
  不能仅凭选中值理解的配置表单保留标签。
- 可见标签收起后仍必须保留 `aria-label` 和悬停提示；Plan 模式等开关本身始终显示名称，并用颜色与开关位置
  同时表达状态。详细风格继续显示原有用途标签。

## 新建任务默认项目

- 默认项目是成员级偏好，键为 `default-project`，由 `/api/preferences/{key}` 按当前登录成员隔离。
- 新建任务仍优先采用入口明确传入的项目和未提交草稿；没有这两者时才使用个人默认项目。
- 默认项目已完成、删除或当前不可见时，回退到首个进行中项目。

## 子任务排序

- 未完成子任务可使用拖拽调整顺序，排序后整任务写透服务端。
- 排序只移动数组位置，不修改子任务稳定 id，既有分享链接和 AI 子任务运行关联不失效。

## 日历成员隔离与任务清单

- 日历默认选中当前登录成员，展示该成员负责且已设置日期或时间段的任务；已完成任务保留在原排期位置并以删除线标识，查看他人日历必须显式切换成员。
- 右侧「待安排任务」默认只展示所选成员未分配时间的任务与已逾期未完成任务，不把正常排期中的任务重复堆入清单。
- 清单集中提供「未排期 + 已逾期」「仅未分配时间」「仅逾期未完成」三种筛选；先按优先级
  `P0 → P3`，同优先级再按截止日期升序，未排期任务最后。
- 清单中的任务可拖到月视图日期格完成或调整排期；时间段任务保留原始起止时刻。

## 项目状态维护

- 项目设置提供「规划中 / 进行中 / 有风险 / 已完成」状态维护入口，保存后通过项目 PATCH 接口持久化，
  刷新页面后状态不回退。
- 项目任务列表的状态胶囊可以直接展开完整状态清单，选择后立即写透任务；保存中、保存失败和原地重试均有
  明确反馈，不必先打开任务详情。

## 项目与知识库

- 新建项目只创建项目本身，不再自动生成或关联知识库，避免未使用的空库堆积在知识库首页。
- 既有默认项目知识库种子进入回收站并保留 7 天；用户自行创建的知识库和后续主动建立的项目关联不受影响。

## 日、周、月视图与时间段

- 日视图和周视图共享 24 小时时间轴；在空白小时格按下并拖动可框选连续整点时间段新建任务。
- 新建任务和任务详情都能设置 `startAt/endAt`；两个字段写入 `task.detail_json`，不修改已执行 migration。
- 时间段必须满足结束晚于开始；月视图按开始时间展示 `HH:mm`，日/周视图按起止时间定位。
- 普通任务继续使用 `due` 截止日期，兼容历史数据。

## 菜单统一管理

- 外部应用注册表继续保存真实应用入口、健康检查及打开方式，但设置页不再展示独立的注册表编辑器；已注册应用自动作为普通菜单项并入统一菜单管理。
- 内置菜单注册表 `/api/settings/navigation/builtin-menus` 统一维护名称、Remix Icon、分组、排序、显隐和打开方式。
- 所有一级菜单支持 `TAB`（WAO 页签）和 `NEW_PAGE`（浏览器新页面），新增项及旧配置缺省均为 `TAB`。
- Skill 市场从菜单进入时使用 `/wao/skills/**` 融入 WAO 主壳；既有 `/skills/**` 继续作为公开独立页面和新页面目标。
- 内置菜单稳定 id 与路由不可增删或修改；配置损坏时回退代码默认值，避免导航被清空。
- 菜单设置按「顶层 / 公共 / 个人 / 工具」真实分组呈现，分组字段使用完整下拉选项；支持同组上下移动、拖拽排序和拖拽跨组。保存前把可见项排在当前分组前部、隐藏项排在底部，并由界面重建顺序值，不要求成员手工维护数字序号。
- 菜单管理与成员快捷链接在同一设置页左右排列，窄屏时改为纵向；两类配置各自显示加载、未保存、保存中、已保存和失败重试状态，离开未保存草稿前必须确认。
