# Phase 1：通知设置内嵌系统设置

对应任务：`t1788158221536`。决策见 [ADR-173](../adr/173-embedded-notification-settings.md)。

## 用户链路

1. 用户在“设置 → 通知设置”打开通知策略时，左侧设置分类保持可见且“通知设置”保持选中。
2. 通知中心的设置按钮直接进入 `/settings?tab=notifications`；旧 `/notification-settings` 地址兼容跳转到同一位置。
3. 系统群通知、当前成员站内偏好和项目通知继续在同一内容区展示，不改变真实数据源、权限或保存行为。
4. 通知策略存在未保存修改时，切换设置项、离开设置页或退出登录都沿用离开确认；拒绝离开后保留当前草稿。

## 验收

- 从设置侧栏打开通知设置后不覆盖设置页面，可继续选择菜单配置等其他设置项。
- 从通知中心和旧独立地址进入时，均落在带设置侧栏的通知设置页。
- 前端测试覆盖内嵌入口、兼容跳转与未保存草稿保护，生产构建通过。
