# Phase 1：个人行动计划

对应任务：`t1786517457972`（需要系统提醒和规划长期“逆袭”目标）。决策见
[ADR-057](../adr/057-personal-action-plans.md)。

## 用户链路

1. 成员从“个人 → 行动计划”新建长期目标，填写愿景、开始/目标日期和每周行动。
2. 页面只展示选中日期真实安排的行动；成员逐条打卡，未来日期不可提前完成，休息日明确为空。
3. 成员可按日期回看打卡与当天事实复盘；复盘自动保存，失败保留输入并提供重试。
4. 修改计划时历史打卡和复盘保留；结束计划不删除记录，可重新开始。
5. 开启提醒后，服务端在上海时区到点检查当天行动，并私聊当前账号绑定的飞书身份。

## 数据和边界

- `action_plan` 保存成员私有长期目标和提醒设置；`action_plan_item` 保存有生效区间的行动版本。
- `action_checkin` 按行动和日期唯一；`action_day_note` 按计划和日期唯一；所有查询由服务端会话限定成员。
- `action_reminder_delivery` 按计划和日期唯一，保存成功、失败、错误与重试次数；双应用节点不能重复发送同日提醒。
- 系统不根据参考图片或短视频推断健康情况，也不提供诊断、饮食、药物或训练处方。

## 验收

- 新建计划后刷新仍存在；页面可在桌面和窄屏完成日期切换、打卡、复盘与设置。
- 同一行动同一天反复切换只保留零或一条真实打卡；不同成员不可读取或修改彼此计划。
- 调整行动后历史日期仍能显示当时动作和完成状态，当前编辑器只加载仍生效的动作。
- 缺少飞书身份或自建应用配置时投递记录明确失败；配置齐全时只向当前成员私聊发送，并附 WAO 入口。
- 加载、空状态、保存中、已保存、失败重试、完成计划和无行动日都有可见反馈。
