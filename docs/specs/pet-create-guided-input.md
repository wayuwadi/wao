# 宠物创建输入引导

落实体验审计 B20 的既有素材创建路径，保持宠物包格式、私人保存和分享授权不变。

- 入口区分直接挑选现成宠物、导入已有包、使用完整动作图集；单张照片尚不能直接变成动作宠物，明确说明并给出下一步。
- 根据图片实际尺寸自动识别既有 v1/v2 格式，加载期间不可提交；解码错误、尺寸不符原位显示，换成正确素材后清除旧错误。
- 标识由系统生成默认值，可在高级选项中修改；不会覆盖恢复的草稿或用户指定值。
- 保留名称、描述、素材来源和授权的用户确认，已有真实动作预览保持可用。
- 不引入图像生成服务、不上传第三方素材、不调整后端契约。

验收覆盖两种图集尺寸、非法图片、选择新文件后的过期回调、草稿恢复、生成标识及真实页面预览。
