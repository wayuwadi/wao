# 小记标题、卡片与图片交互优化

来源：用户小记 `3ad5141f08fe43aa81364f7486518064` 及本次补充的图片方向键需求。承接阅读优先规格；本次只改变浏览器交互，不改变 API、内容事实结构或用户 AI 提示词。

- 卡片标题在顶行，单行省略，完整标题可悬浮查看；标题宽度在悬浮前后保持不变。右侧作者与更新时间在桌面悬浮或键盘操作时让位给 AI 图标及操作，字数与更多操作保持可达。窄卡片通过更多菜单承载次要操作。
- 标签位于卡片底部左侧，桌面悬浮或焦点进入时展示；展开、收起在右侧。触屏直接展示必要入口，长标签横向浏览。
- 输入区顶行支持可选手写标题，底线提示可输入。沿用既有标题草稿、保存、失败与冲突处理；空标题沿用自动标题行为，手写标题保留。
- 小记设置之后增加回收站。复用既有七天软删除与恢复接口，根据现有回收站来源分类显示小记文档；不提供永久删除，不清空正在编辑的草稿。加载失败可重试，恢复失败保留条目，成功刷新清单。
- 去除吸顶工具栏负边距，发现条在正常文档流中完整显示。
- 图片引用保持版本 1 的块节点。点击引用选中图片，Tab / Shift+Tab 调整缩进；两侧光标入口以及方向键定位到相邻段落，缺少段落时新增普通段落，前后文字和图片均正常保存、撤销。阅读模式继续只读。
- 卡片缩略图直接放大原图。阅读、编辑与卡片图片预览提供本篇图片清单的循环前后切换，四个方向键均支持，Home / End 到首末张；显示序号，单图禁用切换。关闭保留原有返回位置。预览不保存文章、不重传图片。
- 所有小记均可打开复制面板。ChatGPT 保留正文、原图分步复制；“交给 Codex”复制完整内容快照、机器可读原文 URL、正文顺序原图 URL 和执行指引。未保存快照优先，内容不截断；复制不自动发送、不扩大现有授权。无文档 ID 的编辑器选区仅描述为复制快照。

验收包括标题草稿刷新和保存、悬浮前后标题宽度、工具栏与发现条位置、图片引用选中缩进和前后文本、缩略图直接放大和方向键、复制内容完整性、回收站恢复与失败重试、成员切换和窄屏可达性。实体 iPhone 系统键盘与触屏手感由用户最终验收。
