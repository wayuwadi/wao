# Phase 1：原生 iOS 客户端

对应任务：`t17866728549710`。本规格取代 `phase-1-ios-home-screen-app.md`，原生交付边界见 ADR-070。

## 用户路径

1. 用户安装经自己签名或后续 TestFlight 分发的 WAO，在原生登录页使用已绑定的邮箱密码登录；登录成功后
   复用服务端会话，重新打开应用自动恢复，退出时清除本机会话 Cookie。
2. “项目”页从真实 `/api/projects` 与 `/api/tasks` 加载数据。进入项目可以查看任务，并在保存中状态明确时
   切换完成/重新打开；失败时保留当前服务端结果并允许刷新重试。
3. “AI”页读取最近运行，可选择真实项目输入目标并调用 `/api/ai/goals` 派发；排队、运行、成功、失败和
   取消均显示服务端状态，不制造本地假运行。
4. “自动化”页读取真实任务，可立即运行、暂停、恢复或在待修复时重新授权；每项操作显示保存中和失败状态。
5. 所有列表支持下拉刷新；加载中、空数据、失败重试、提交中均有原生可访问状态。

## 规则

- 客户端使用 SwiftUI、URLSession 和系统 Cookie 存储，不使用 WKWebView、Capacitor、Cordova 或远程页面壳。
- API 基址由构建配置写入，生产值为 `https://wao.wayuwa.cn`；只请求现有 `ApiResponse<T>` 接口。
- 首期只展示已实现且可操作的原生模块，不为知识库、日历、文件等页面放空入口。
- 邮箱密码只进入当前 HTTPS 请求，不写入 UserDefaults、Keychain、日志或源码。业务数据不做离线快照。
- Bundle ID 固定为 `cn.wayuwa.wao`；版本更新必须递增构建号。本地覆盖安装要求使用同一签名身份。
- macOS CI 必须先跑模拟器单元测试，再输出不含凭据的未签名 IPA；真机签名和安装由用户现有工具完成。
- 没有固定签名发布源时不实现应用内更新入口；取得 Apple Developer 账号和发布方式后另开任务补齐。

## 验收

- CI 在 iOS 模拟器编译并通过 API 信封解码、登录请求和错误透传测试，随后上传 `WAO-unsigned.ipa`。
- 未签名 IPA 中的产品名为 WAO、Bundle ID 为 `cn.wayuwa.wao`，源码中不存在 WebView。
- 使用测试账号时，登录、项目/任务状态切换、AI 目标派发和自动化操作均命中生产真实接口；断网或 401 有明确
  错误且不展示旧数据为最新结果。
- 相同 Apple 身份和 Bundle ID 签名的新构建可覆盖旧构建；不同签名或签名工具改写 Bundle ID 时明确不承诺
  覆盖升级。
