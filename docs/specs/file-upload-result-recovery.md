# 全局文件上传结果与失败恢复

关联体验审计 A09：上传反馈不能只短暂显示总数；图片上传未持久化不能宣称完成。

- 全局文件库和图床上传只将服务端持久化确认视作成功；图床使用已有 requirePersisted 选项，禁止失败后本机图片冒充上传结果。
- 同页显示每个文件的目标位置、等待、上传中、成功和需处理状态；部分成功分别呈现，单项异常不阻断后续文件。
- 失败文件在当前页面内保留，逐项重试，成功项不重传。大小超限明确要求压缩并重新选择。
- 未收到确认不等于服务端一定未保存。提供刷新列表核对入口，提示先核对再重试；不承诺服务端幂等或自动重试。
- 明示刷新或离开需重新选择失败文件；清除上传记录仅清理本页结果，不删除资产。账号切换清空队列并停止后续排队请求。
- 不变更上传接口、共享权限、项目内部、HTML 发布与资产替换逻辑。

验收：图片持久化失败不报成功，批量部分失败与单项重试，异常后继续上传，超限说明，真实页面失败→恢复→列表读回。
