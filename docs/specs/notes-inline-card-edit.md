# 小记卡片原地编辑

本规格调整 `phase-1-notes-double-click.md` 和 `phase-1-notes-split-workspace.md` 的编辑位置。沿用 ADR-198、小记完整文档能力、成员隔离草稿、显式保存和版本冲突保护，不改接口或数据结构。

- 左侧始终是新建小记编辑器；编辑已有记录不重建左侧实例、不替换新建草稿。
- 右侧已发布卡片提供“编辑”入口，双击正文或聚焦卡片按 Enter 也可进入原卡片内部编辑。单击保留阅读与选中文本，链接、标签及控件不误触编辑。
- 每条卡片复用 NoteComposer 的正文、标签、全屏、上传、保存和失败重试；仅已打开编辑的卡片创建编辑器，各自保留独立草稿，可同时编辑不同记录。
- 保存成功后原卡片恢复阅读，显示已保存；普通修改保持筛选和滚动位置，按用户已选排序更新。失败保留卡片编辑状态及正文，不显示假成功。冲突仍可保留为新小记。
- “收起编辑”保留浏览器草稿，重新打开或刷新后再次编辑可恢复。后台同步不覆盖正在编辑的内容，保存继续携带开始编辑时的 expectedRev。
- 筛选、排序和分页之外的在编卡片仍保留在列表尾部并显示说明，防止卸载正在输入的正文。保存或收起后恢复正常筛选。
- 窄屏卡片内编辑器不横向溢出，工具栏和操作可换行；保存期间保留明确状态并防止重复提交。

验收覆盖原地编辑、左侧草稿与实例不变、收起/重开恢复、筛选期间防丢、两个卡片独立编辑、成功与失败重试、并发版本保护、真实富文本保存刷新和窄屏交互。
