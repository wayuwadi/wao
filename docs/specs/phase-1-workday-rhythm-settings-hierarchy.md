# Phase 1：今日节奏配置分层与系统项移除反馈

对应任务：`t1788177053418`（调整每日节奏-BUG）。基础配置能力见
[今日节奏顶部摘要与可追加重点](phase-1-workday-rhythm-top-summary-and-flexible-focus.md)，本次配置页层级与系统项移除行为以
[ADR-186](../adr/186-workday-rhythm-settings-hierarchy.md) 为准。

## 用户结果

1. “调整每日节奏”按每日必做、行动通知、精力补给和时间线分区，一次只展示一类配置，成员不再面对连续铺开的表单墙。
2. 每日必做默认展示项目名称、联动类型、适用日、时段、通知数量和启停状态；只有成员主动编辑的项目展开完整表单。
3. 点击系统联动项的移除按钮后立即保存停用状态，并明确展示成功、失败和恢复入口；不再只改变本地复选框造成“没有反应”。
4. 自定义项目仍采用软删除，系统联动项和既有历史记录不做物理删除；停用项目可以恢复。
5. 新增项目自动展开，窄屏配置分类与项目摘要保持可浏览，不产生横向滚动。

## 验收

- 打开“调整节奏”时默认仅展示每日必做配置，可从四个分类间切换；宠物设置链接直接打开精力补给分类。
- 每日必做列表初始没有展开的项目表单，点击某一项目“编辑”后只展开该项目，再次点击收起。
- 移除“制定今日计划”等系统项时调用清单更新接口保存 `active=false`，成功后显示“已停用”和恢复按钮；失败时项目保持原状态并显示可重试错误。
- 删除自定义项目仍调用删除接口，刷新后不再出现；历史实例不受影响。
- 390px 宽度下分类导航变为两列，项目名称、编辑、移除或恢复操作均可见。
