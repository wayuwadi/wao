# 菜单分组的添加菜单弹窗

## 用户结果

成员在侧栏菜单组右键选择“添加已有菜单”，或创建新分组后，可以完整看清菜单名称和当前位置，搜索并多选已有功能，一次确认添加到目标分组。

## 布局与交互

- 弹窗居中，桌面宽度最多 600px、高度最多 680px，并为短视口预留安全边距，使用现有明暗主题变量。标题为“添加菜单”，说明中显示真实目标分组。搜索或筛选时高度和位置保持稳定。
- 搜索覆盖当前名称、原始名称、用途与功能关键词，复用功能目录搜索规则。清除搜索保留选择。
- “全部菜单 / 未显示 / 已在本组”筛选展示实际数量；切换筛选保留选择。“选择当前结果”只影响当前结果中可添加的菜单。
- 菜单使用纵向整行布局，展示图标、完整名称和当前位置；长名称自然换行，外部应用标明类型。已经显示在本组的菜单标为“已添加”并禁用，不能重复加入。
- 底部保持已选数量、移动说明、取消和“添加 N 项”可达；只有列表主体滚动。窄屏按钮换行，菜单名称不挤压到横向小卡片。
- 选择菜单不立即保存。取消、关闭、点击遮罩或 Escape 放弃本轮选择；打开时聚焦搜索，Tab 不离开弹窗，关闭后焦点回到来源分组。账号切换关闭旧账号弹窗。

## 保存与恢复

- 沿用当前个人导航布局接口与版本号，以一次请求保存整批选择。内置菜单与外部应用共同追加到目标分组末尾，其名称、图标、打开方式和稳定 id 不变。
- 添加后菜单变为可见侧栏入口，从原位置移到目标分组；已有菜单保持原相对顺序。不改变全局注册表、服务端接口、数据库或成员权限。
- 保存中显示“添加中…”，冻结选项布局并禁止重复提交、编辑和关闭。成功后关闭弹窗并提示实际添加数量。
- 保存失败沿用布局整批回滚，弹窗保留搜索、筛选和选择，原位显示错误与重试入口。版本冲突时不自动覆盖：成员显式读取最新布局后保留仍可添加的选择，以新版本提交。

## 验收

- 从分组右键和新建分组两条入口打开；搜索原名、别名与无匹配关键词，切换筛选，跨结果多选、取消当前结果选择和取消弹窗。
- 同时添加来自隐藏、顶部、底部和其它分组的菜单，核对一次保存、目标顺序及未选菜单配置。成功关闭并恢复分组焦点。
- 覆盖慢请求、重复提交、网络失败重试和跨设备版本冲突；失败不丢选择，不出现部分成功。
- 核对长名称、桌面、窄屏及深色模式的布局、滚动与键盘操作；真实账号下保存后刷新保持位置。

## 实现与验收记录

原弹窗中通用 `.group-dialog > div` 的 flex 规则覆盖列表布局，把菜单挤成横向小卡片。本轮将选择弹窗拆为独立的 [MenuGroupPicker](../../wao-web/src/components/nav/MenuGroupPicker.vue)，两个原有入口继续由 [SideNav](../../wao-web/src/components/nav/SideNav.vue) 提供，复用现有导航 store、布局版本与保存接口。
