# Phase 1：项目化点子箱与多轮 AI 迭代

## 目标与边界

- 点子库展示当前成员可见的“规划中”项目；快速记录只需标题和可选最终目标。
- 快速记录静默创建项目，不发送团队通知。首次点击“开始推进”或从项目启动 AI Run 时才进入“进行中”并通知一次。
- 项目是长期目标容器；任务是一轮可验收工作；AI Run 是任务的一次执行。三者状态不得互相冒充。
- 不限制迭代次数，不要求调研、会议或固定阶段表单，也不默认读取全部项目知识库。

## 项目闭环

1. 无任务时可一键创建“第一版”任务并启动 AI；AI 成功后任务只进入“待验证”。
2. 待验证任务可打开任务抽屉，携带人工反馈在原会话继续优化；所有 Run 历史保留。
3. “本轮满意”只完成当前任务；“开始下一轮”新建任务；两者都不完成项目。
4. “项目已达成”需人工二次确认，未完成任务只提示并保留。“暂时搁置”同样保留全部数据并可恢复。
5. “项目说明”首次使用时幂等创建项目知识库和稳定文档；普通文档继续自动带项目出链。

## 存量点子

- 独立点子只出现在“历史点子待归并”，不再允许从新入口创建。
- 归并优先使用用户指定项目，其次使用点子已关联项目，再次使用全部关联任务唯一所属项目，否则新建规划中项目。
- 归并生成“原始点子与迭代历史”文档并补齐旧资产的项目出链；不改任务所属项目，不移动旧文档，不删除点子记录。
- 重复归并返回同一项目和稳定文档，不产生副本。

## 体验验收

- 快速记录具备本地草稿、记录中、静默已保存、失败保留与重试状态；手机为单列项目卡片。
- 第一版 Run 完成后，项目仍为进行中且清楚展示“反馈并继续优化 / 本轮满意 / 开始下一轮 / 项目已达成”。
- 项目说明、旧资产、历史 Run 和归并档案刷新后仍能从项目访问。
