# 小记删除确认靠近操作入口

本规格调整 `notes-list-delete.md` 与 `notes-inline-card-edit.md` 中删除确认区的位置。

- 删除图标首次点击后，在该按钮附近显示轻量确认浮层，说明移入回收站及 7 天可恢复；确认删除后才执行既有软删除。
- 浮层挂载在页面顶层，不受折叠卡片的固定高度、裁切或正文渐隐影响；不要求先展开小记。
- 首次可见时即定位在按钮下方靠右处；下方空间不足时放在上方，窄屏保持在可视范围内。窗口尺寸或滚动变化时跟随按钮位置。
- 取消、再次点击删除图标、按 Esc 或点击外部关闭确认。取消与 Esc 返回删除图标焦点；删除期间禁用重复提交和关闭。
- 服务未连接、删除失败与重试提示都收在同一浮层中；失败保留小记与当前草稿。编辑状态仍明确提示未保存内容会丢失。

验收覆盖折叠长小记中的完整确认提示、按钮附近定位、窄屏和下方空间不足、取消及 Esc、失败重试。
