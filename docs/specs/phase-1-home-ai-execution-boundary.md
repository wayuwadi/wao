# 首页 AI 启动的执行边界

对应审计 B02/B03，与新建 AI 会话保持相同说明，沿用 ADR-093 无人值守 Plan 语义。

- 首页目标输入保留，项目字段改为“任务归属项目”。
- 原两个可反选的模式按钮改为明确的三个互斥选项：直接执行、先规划再自动执行、持续执行目标。
- 当前模式说明始终可见；Plan 明确不会停在计划阶段等待确认，目标模式说明持续推进与额度消耗。非 Codex 仍按原逻辑直接执行。
- 主按钮明确“创建任务并开始”，不暗示仅生成方案或提供新的确认闸门。
- 执行配置加载/失败在高级设置折叠时仍可见，失败保留目标并提供重试。
- 不改变默认模式、派工参数、Runner、授权或实际执行行为。真正的计划审批仍需独立业务规格，不在本批实现。
