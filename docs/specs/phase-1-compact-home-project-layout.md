# 首页与项目任务页紧凑布局

按 2026-09-08 已确认视觉稿落地。

- 首页顶部在桌面宽屏下将额度、重置卡和 Pro 到期日横向排列，收起装饰性槽位大卡；保持真实额度与成员权益数据。权益仍可编辑并保留原有草稿、保存和失败重试语义。
- AI 目标保留输入、工作流和模式入口，电脑与思考深度按需展开，收起不卸载输入或覆盖已选设置。
- 正在运行与最近运行共用一个列表／卡片切换，默认紧凑列表；原卡片的媒体区、详情、筛选和分页继续保留。视图选择按本机成员记忆，存储不可用时仍可切换并提示。
- 项目页顶部压缩为标题、页签与视图、交付阶段三行；简介、收藏、设置、记忆和动态归入更多菜单；新建任务保持直接可用。
- 批量选择入口按需展开全选、清空、合并复制与 AI 派发，完成选择后收起。看板任务标题最多三行，详情保留全文。
- 空状态列默认折叠并有显式展开入口；开始拖拽时临时展示全部目标状态，结束拖拽恢复。已完成列继续可独立展开；任务状态、筛选、分组和归属规则不变。
- 窄屏工具栏换行，使用原有主题颜色与真实数据，不引入固定示例权益或任务。

验收包括两种运行视图切换与恢复、详情与分页、目标草稿、批量选择与复制、分组和拖拽，以及桌面／窄屏真实页面操作。
