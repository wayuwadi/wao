# 系统伙伴：偶尔露面

状态：用户已确认交互 Demo，按推荐方案实现。沿用首页四个程序化毛绒伙伴及原有留白，不新增常驻悬浮球或配置中心。

## 可观察行为

- 小画家：用户点击小记保存并收到服务端成功结果后，操作旁的空白处短暂停留。快捷键保存后仍在输入时直接略过。
- 小开心：用户把任务改为已完成，且最新版本保存成功、内嵌子项全部完成后轻跃。乐观状态变更、后台同步、草稿回放、撤销、失败及未收尾子项不触发。取代任务详情原先提前显示的成功提示与全屏礼花；保存状态仍由原有文字反馈。
- 小书虫：真实项目列表或知识空间加载成功且为空、没有查找或范围筛选时短暂露面。每位成员在当前浏览器标签页会话至多一次；加载中、错误、筛选无匹配不是空空间。不创建引导任务。
- 小青蛙保留在首页，不在工作页主动提醒休息。
- 版本提醒继续使用现有信使、版本去重、关闭行为和保存屏障；其面板打开时抑制其他轻回应，不增设更新浮层。

## 频率、位置与编辑保护

工作页无常驻角色。一次至多一个，约 2.2 秒退出，动画本身不超过 1.6 秒；同类反馈至少间隔 30 秒。延迟超过 5 秒的确认结果、切页前的操作均不补播。没有队列：正在输入、后台或安静模式下的回应直接丢弃，离开输入后也不补播。

显示区 56×56 像素，在操作周围查找空白，不改布局，不挡文字、按钮、正文输入区，不跨页追随。仅检查当前可见层，抽屉下面被遮住的控件不误算为障碍；没有安全空间或超大页面超出限定查找范围时跳过。滚动、缩放、切页、Escape、开始输入立即收起。装饰不接收点击、不进入键盘或读屏顺序。

工具菜单中的「安静陪伴」与首页同名开关联动；开启后首页保持静态，工作页停止轻回应，版本信使停下动画，版本信息仍可阅读。设置按成员保存在当前标签页会话，不写共享偏好。编辑焦点也会暂停首页伙伴与版本动画。

支持系统减少动态效果：只绘制静态一帧。工作页按需加载三维代码，只创建当次角色；退出后停止 RAF 并释放材质、几何体与 WebGL 上下文。图形失败时静默退出，不影响保存。

## 范围与契约

只修改 Vue 前端，不新增业务服务、HTTP API、MCP、CLI 命令、模型调用或依赖；既有保存、错误重试、草稿恢复及权限契约不变。CLI/MCP 同步评估：无对应新业务操作，无需扩展工具或旧令牌权限。

与 [首页伙伴规格](home-companions-2026-10-03.md)、[版本信使规格](update-arrival-messenger.md) 并用；本规格仅调整陪伴频率和动画互斥，不取代更新说明内容与关闭逻辑。

## 使用

在小记中点击「保存修改」或「记下来了」；有空白位置且未处于冷却时可看见蓝色伙伴。任务详情选择已完成，等自动保存成功后可看见粉色伙伴。到工具菜单开启「安静陪伴」可暂停；再次关闭即可恢复偶尔回应。键盘保存后继续输入没有角色出现是预期行为。
