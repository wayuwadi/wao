# 小记记录区宽度与标题操作

2026-10-03，补充 `notes-adaptive-space.md`，取代其桌面记录区 240–360px 的固定宽度规则。

- “收起记录区 / 展开记录区 · 继续写”紧随今日写字统计，与标题同排；窄屏可自然换行，按钮不遮挡统计。
- 桌面记录区默认占工作区约三分之一。中间分隔线支持左右拖拽，两边实时重新分配空间；比例范围 25%–60%，同时保留记录区至少 240px、列表至少 320px。
- 拖拽结束将比例存入当前浏览器本地存储，下次进入或刷新采用该比例，不跨设备同步。存储损坏使用默认值，保存失败提示再次调整重试，不影响正文草稿。
- 分隔线可获得键盘焦点，左右方向键每次调整 1%，Shift 加方向键调整 5%；双击或 Home 恢复三分之一，End 调到最大比例。
- 收起、窗口尺寸变化、指针取消、失焦及页面离开时结束拖拽并清理监听。编辑器实例不因调整或收起重新创建，保留输入与草稿。
- 1100px 及以下继续上下排列并隐藏分隔线，不覆盖已保存的桌面比例。
- 不改变保存、AI、权限或服务端接口；不增加 CLI / MCP 能力。
