# 面向使用者的版本说明

2026-10-03，补充 release-highlights-feature-explorer、update-arrival-messenger 规格。

- 当前版本说明从真实构建 HEAD 的提交标题生成，去除 Conventional Commit 前缀及 PR 编号；展示改进、修复或性能优化类型，并为已知有效功能提供体验入口。
- 不将最近五条历史提交重复包装为本次新增；最新提交以外的全部祖先继续保存在不可变 Git 档案，按制品 SHA 校验。未知功能归属保留说明，跳转到更新档案，不猜测入口。
- 清单增加可选 attention（feature / maintenance）；旧清单缺省保持功能提醒兼容。文档、测试、CI、重构和日常维护只保留可更新入口，手动可读、可保存刷新，不自动展开或播放新功能登场。
- 新版本先读取并匹配真实清单，再决定自动提醒。清单缺失、失败、错配保留可更新入口和手动重试，不抢编辑焦点；真实功能更新仍使用已确认的十秒动画与同版去重。
- 首页功能说明同步使用周重置时间，替代已过时的 Pro 到期文案。

仅静态制品清单和浏览器交互变化，无业务 API、数据库、MCP 或 CLI 变更。
