# WAO 柔环与伙伴品牌精修

2026-10-06，用户授权直接实施图形、字标、小图标、呼吸页品牌及伙伴一致性五项优化。本规格增补 `wao-soft-loop-brand-identity.md` 与 `wao-shell-brand-expression.md`，历史资源保留。

## 可观察结果

- 保留柔环 W 的两侧轮廓，将中央双重堆叠改为单次穿插；透明镂空区分上下线条，背景不被白色填充。标准母版使用 v4 路径；16/24px 图标采用扩大有效图形和穿插留白的光学校正版。根 favicon 与 manifest、Apple 图标一起更新，保留白底 maskable 的安全区。
- WAO 使用固定的圆角矢量字标，不依赖设备字体；页面字号仍允许按导航、页脚和手机场景调整。字标继承页面文字色，图形默认蓝紫；呼吸页使用继承页面颜色的单色版本，兼容深浅背景。
- 呼吸页左上角、非简约呼吸入口复用 `WaoLogo`；品牌名称固定为 WAO，页面名称为“一呼一吸”。保留工作区已确认的展开/折叠与右下角品牌规则，不增加重复常驻标识。
- 呼吸空间的背景纹样复用柔环曲线，低对比、静态、非交互；计时及吸呼指引仍清楚，减少动态效果下不新增动画。
- 首页毛绒、呼吸伙伴共用角色配色与名字。蓝色保留贝雷帽，黄色保留眼镜与收窄顶部，绿色恢复凸眼与蝴蝶结；材质可随场景柔化。呼吸动画、旅程位置、按钮及键盘访问行为保持。

## 验收

检查标准/小尺寸/单色、透明/白底/深浅底；真实本地服务下核对侧栏展开折叠、首页、呼吸选择和练习、手机无横向溢出、分享入口。运行受影响导航、公开呼吸、伙伴旅程测试、类型检查与构建。发布核对精确前后端版本、品牌文件摘要、服务就绪和首页/呼吸页实际效果。

纯浏览器视觉改动，无业务 API、数据库、MCP 或 CLI 能力变化。
