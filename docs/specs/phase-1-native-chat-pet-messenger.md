# WAO 原生聊天与宠物传话

来源：`t1789013082654`；决策见 [ADR-227](../adr/227-native-chat-and-pet-messenger.md)。

## 使用流程

1. 任意业务页点击顶部聊天按钮；Task 抽屉保持打开，聊天最小化或 Escape 后继续编辑任务。
2. 任务右上角分享菜单选择“分享到聊天”，将任务或当前子任务的标题和对应范围链接追加到聊天草稿。原草稿继续保留，成员可补充说明后发送。
3. Enter 发送，Shift+Enter 换行；中文输入法确认候选字不发送。文字、粘贴图片、引用、表情和已读均由 WAO 保存，发送无需飞书配置。
4. 聊天收起后每 10 秒获取消息；有未读时顶部角标和宠物气泡提示。气泡明确显示真实发送者，“帮我传话”向团队共享聊天发送引用回复。输入期间新消息不会改变正在回复的对象；失败保留草稿并允许重试。
5. “和宠物聊 · AI”进入独立的 AI 问答，不把团队消息冒充宠物生成的回答。已有 AI 对话权限和持久化逻辑保持。
6. Windows/macOS 客户端 1.1.0 增加“桌面宠物”按钮和托盘入口。宠物使用独立透明置顶窗口，主工作区收起后仍可查看气泡和回复；拖动把手改变位置，隐藏后从客户端或托盘恢复。聊天/AI 打开时扩大窗口，收起后恢复紧凑形态。

## 通知与历史

- 任务、评论、AI 运行结果和定时提醒等原系统群通知保存到 WAO 通知中心；个人日历提醒仅所属成员可见，旧 `GROUP` 标识兼容映射为 WAO 内部提醒。
- 通知中心请求 `includeInternal=true` 声明支持新增 `INTERNAL` 类型；旧页面继续接收原有类型，避免滚动发布时发生渲染错误。
- 移除共享聊天的飞书桥接、轮询、同步配置/重试接口，暂停夜间同步任务。当前聊天和新复盘不再引入飞书消息；原数据库历史和已有复盘留存。
- 登录、知识采集、用户主动外发卡片、验证码转发等独立飞书功能不是本次共享聊天桥接改造对象。
- 快速回复面向当前组织共享聊天，不引入私聊、分组会话或音视频。全面复刻飞书是后续范围。

## 交付与验收状态

本地需通过相关前端交互、Java 服务/权限、客户端外壳和 Rust 来源限制测试，以及 Web/客户端构建。Web 与桌面安装包分别发布，必须核对线上 SHA 和客户端更新清单版本。

真实双成员收发、任务编辑中开关聊天、独立桌面窗口、跨窗口会话、气泡快捷回复及安装升级均待实际操作验收。浏览器控制连接异常或本机无法连接生产服务时，不把编译/单测或 HTTP 200 当作这些验收已经完成。
