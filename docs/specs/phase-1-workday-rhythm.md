# Phase 1：个人工作日节奏

对应任务：`t1786968251081`（把 07:00—次日 07:00 的工作日安排变成 WAO 内可执行的提效产品）。决策见
[ADR-079](../adr/079-member-workday-rhythm.md)。

## 用户结果

1. 登录成员从“个人 → 今日节奏”进入自己的工作日执行页，默认模板忠实覆盖任务提出的七段安排。
2. 页面按上海时间突出“此刻该做”的时间块，展示时段进度、剩余时间和下一段安排；跨午夜的睡眠时段仍能正确识别。
3. 成员可填写当天三个重点、逐段完成打卡、记录实际喝水次数和是否至少冥想一次；所有结果都来自本人操作，不生成演示完成记录或健康结论。
4. 默认周一至周五启用、周末休息；加班、调休或请假时可手动切换当天是否执行，系统不臆测法定调休。
5. 成员可调整七段时间、名称与行动提示。时间块必须首尾相接并覆盖完整一天，避免重叠或无法判断当前时段。
6. 模板和每日记录按登录成员隔离并跨设备恢复；加载、保存中、已保存、失败重试和本机草稿均有明确反馈。

## 数据与边界

- 复用成员级偏好接口保存 `workday-rhythm-config-v1` 和按日期区分的 `workday-rhythm-day-YYYY-MM-DD`，不使用只读的
  `schedule_item` 种子数据冒充个人日程。
- “今日三个重点”是当天执行焦点，具体任务、状态和进度仍以真实待办为准，页面提供直接入口而不复制任务数据。
- 喝水只记录成员主动点击的实际次数，不设置或宣称医学上的饮水目标；冥想也只保存是否完成，不推断健康效果。
- 本轮不发送定时通知。没有用户授权且可靠的通知条件时，不把页面计时器包装成后台提醒能力。

## 验收

- 首次打开能看到七段默认模板；07:00、09:00、23:00 和次日凌晨等边界时刻只命中正确的一段。
- 填写重点或打卡后刷新、换设备仍能恢复；不同成员不能读取彼此模板和每日记录。
- 保存失败时输入和打卡保留在本机，可原位重试；服务端旧值不得覆盖未保存草稿。
- 修改模板为不连续时间时保存被拒绝；合法修改保存后立即影响当前时段判断。
- 390px 窄屏可查看当前时段、填写重点、完成精力记录和全部时间块，不产生业务区横向滚动。
