# ADR-322：统一能力中心与设备逐项授权

状态：已接受（2026-10-04，用户确认 Demo 并要求实现）。

## 决策

用独立能力中心收口 WAO-HUB、工作流 Skill、应用接入、Pet 和 CLI/MCP。入口属于功能菜单，移除设置中的授权弹层；发现、连接、发布为同一功能的三个区域，按类型展示详情和适用操作。替代独立管理页面但兼容公开分享与下载链接。

设备权限用明确操作白名单及项目／知识库范围表达，在 tools/list、tools/call 与 HTML 发布控制器执行。保留旧权限字段和空 policy 的兼容行为，原有令牌不得自动增加权限；新授权必须重新签发，可在页面内复制旧授权为草稿。

资源的审核、作者、可见性、版本、许可证和草稿生命周期继续复用既有服务。外部应用没有可靠提供方时保持空状态。管理浏览器会话与设备调用分离，不把令牌签发接口开放给设备本身。

## 影响

新增 workspace_mcp_token 的 JSON 权限快照和客户端类型元数据；不回填或改写现有令牌。资源范围只收窄业务可见性。CLI 操作保持不变，能力台账与权限拒绝测试同步维护。
