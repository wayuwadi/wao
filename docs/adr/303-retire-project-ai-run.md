# ADR-303：下线项目与任务 AI Run

- 状态：已接受
- 日期：2026-10-02

用户要求移除项目 AI Run。此前任务按钮隐藏但首页控制台和自动派工仍可运行，本次同时关闭项目配置、派工、自主目标、进化建议、运行查询和公开运行分享，以及项目队列领取端点。首页保留呼吸、天气和天人一卦，不再加载 AI Run、工作流或执行电脑。项目任务按钮继续关闭，历史任务的 AI 进行中状态保留展示。

停止注册闲置待办与进化派工定时器、HTTP 性能 AI 巡检执行器；自动化服务忽略历史巡检调度并拒绝手动触发。请求监控保留真实 HTTP 统计及历史，移除巡检启动与配置。飞书快速收集保留普通任务收集，表情不再派工。历史项目、任务、配置、运行与报告数据不删除，不改已执行迁移。

Runner 配对、助手协议与配图协议由独立下线需求处理。工作区 MCP 和 CLI 没有项目 AI Run 专属命令，本次不增加权限；能力台账同步记录退役边界。

验收覆盖首页不加载队列、项目任务入口、旧 HTTP 端点不可达、表情不访问任务数据或派工、自动化退役门禁以及生产构建。新后端接口以自动化验证，既有真实数据库服务仅用于本地浏览器验收，不执行生产数据修改。
