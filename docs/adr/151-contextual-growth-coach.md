# ADR-151：把已暂停的每日建议收敛为可追问的成长教练

## 状态

已采纳。取代 ADR-062 的泛化“此刻建议”产品形态，并重新启用 ADR-063 的主节点预生成机制；旧接口的成员隔离、
只读 Runner、自然日缓存和失败边界继续有效。

首页入口与 Task-only 上下文已由 [ADR-177](177-workday-rhythm-growth-coach.md) 修订；生成框架、AI 权限与继续对话边界仍有效。

## 背景

旧首页“给此刻的你”只从未完成任务生成三段建议，真实使用后被判断为没有使用价值，于 2026-08-20 与自动预热一起暂停。
它能读取真实资料，但产出容易变成与一次普通问答无差别的建议，没有帮助成员观察自己做过什么、正在训练什么，也没有进入深入对话的入口。

新需求不是再增加一张静态的 L1–L5 说明卡，而是希望 WAO 在日常使用中主动帮助成员处理“经验是否还值钱、接下来应刻意训练什么”
这类抽象但影响具体行动的问题。WAO 已有真实 Task、完成时间、项目归属、成员级持久化助手和有界重试的只读 AI 链路，
无需建立演示画像或引入新模型凭据。

## 决策

1. 首页重新提供每日入口，但改名为“成长教练”。生成上下文包括当前成员最多 8 条未完成 Task，以及最近 30 天内按
   `completed_at` 倒序的最多 6 条已完成 Task；只有这些 Task 的真实项目名称会随上下文提供给模型。
2. 生成提示使用 L1–L5 作为观察框架，要求从真实 Task 标题给出证据，但禁止凭少量数据给成员定级。输出固定为“今天看到的成长信号、
   换个角度、问问自己、今天做个小实验”；追问和实验都只有一个，避免再次形成泛化建议清单。
3. 新结果使用成员偏好键 `growth-coach-v1`，不复用旧 `daily-guidance` 正文；接口路径保持 `/api/daily-guidance`，
   继续复用现有超时、成员鉴权、只读运行和自动重试协议，不增加 migration。
4. Linux 主节点重新启用每日预生成。已有当天结果不调用 Codex，单成员失败不影响其他成员，用户主动“换个角度”才覆盖缓存；
   自主进化调度保持暂停，避免把本次需求扩张为自动创建任务或无边界消耗额度。
5. 首页保留会话级当天缓存并覆盖读取、准备、不可用、请求失败、生成中、成功与生成失败。后台结果仍缺失时，成员可明确点击
   “现在生成”；失败时保留旧正文和重试入口，不用静态鸡汤兜底。
6. “带着这个问题继续聊”只把当天正文放入 WAO AI 的新会话输入草稿并打开助手，不自动发送。助手读取草稿后立即清除跨组件状态，
   防止以后打开助手时覆盖用户已经输入的内容；正式发送后仍遵循成员会话与资产检索权限。

## 后果

- 每天至多为每位成员增加一次只读 AI 生成，换来打开首页即可看到与真实工作变化关联的思考入口；人工刷新仍会明确消耗一次生成。
- 已完成 Task 让教练能观察结果而不只催办，但当前 Task 没有结构化的“关键判断”字段，因此模型只能依据标题和描述；资料不足时必须诚实收口。
- 把继续对话设计为可编辑草稿，既保留主动启发，又避免系统替用户发言或制造没有确认的长期聊天记录。
