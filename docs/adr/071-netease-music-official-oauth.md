# ADR-071：网易云音乐官方 OAuth 与成员级播放

## 状态

历史已采纳；音乐功能已按 [ADR-300](300-retire-music-player.md) 下线（2026-10-02），以下内容仅保留为历史设计记录。

## 背景

WAO 的全局播放器原先只播放成员上传到文件库的音频。新需求希望成员绑定自己的网易云音乐账号，直接播放喜欢的音乐，并确保不同 WAO 成员之间数据不串台。非官方登录、用户 Cookie 和反向工程接口在安全、版权、稳定性与合规上都不可接受；官方开放平台又要求应用审核、RSA 签名、可信设备参数、短时播放地址和播放行为回传。

## 决策

- 只接入网易云音乐官方开放平台 H5 OAuth 和已审核 API，不接收网易云账号密码、扫码 Cookie 或第三方代理接口。
- OAuth `state` 是十分钟有效的随机值，服务端将其绑定到当前 WAO 成员和稳定设备 id；公开回调只凭一次性 state 确定成员，不依赖浏览器当时的 WAO 会话。
- 每个成员一条 `netease_music_binding`。access token、refresh token 分别使用现有 `WAO_VAULT_KEY` 做 AES-256-GCM 加密，令牌不进入日志、URL 或前端响应；解绑按当前成员主键删除。
- 前端只展示当前成员的连接状态与红心歌单。播放前由服务端使用当前成员令牌获取短时 HTTPS 地址；不缓存成公共曲库，不跨成员共享播放 URL。
- 按官方要求使用 PKCS#8 RSA 私钥执行 `SHA256withRSA` 签名，设备 id 在一次授权及其后续绑定期内稳定。客户端出口 IP 由可信反向代理转发，应用和设备字段必须来自审核配置。
- 每个播放会话回传且只回传一条 `startplay` 和一条 `play`；暂停和拖动不产生结束上报，切歌、异常、自然结束与应用中断结算真实播放秒数，透传歌单来源和 `alg`。
- 所有开放平台配置均为可选生产环境变量。默认禁用；配置缺失时 UI 明示管理员未配置，不阻断既有 WAO 文件播放器和部署。

## 影响

- 正式可用前必须完成网易云开放平台应用审核、回调白名单、API 权限和设备参数确认，并安全注入 APP Secret 与 RSA 私钥；仓库无法替代这一步。
- 主、从节点必须共享同一个 `WAO_VAULT_KEY`，否则切换节点后无法解密成员令牌。
- 官方授权或版权状态变化会让歌曲不可播放或要求重新授权，界面必须展示真实失败，不回退到非官方接口。
- 新增 `V68__netease_music_binding.sql`；已上线后不得修改该 migration。
