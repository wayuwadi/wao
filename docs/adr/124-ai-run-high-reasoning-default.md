# ADR-124：AI Run 默认使用高推理强度

- 状态：Accepted
- 日期：2026-08-26
- 调整：[ADR-091](091-ai-run-model-selection.md)

## 背景

ADR-091 为 Codex AI Run 提供 `medium / high` 两档受控推理强度，并把 `medium` 设为默认值。WAO 的 AI Run
主要处理需要定位根因、修改代码、测试、提交和部署验收的完整开发任务；真实使用中，这类任务更需要默认保证
推理深度，用户不应每次派工都手动把强度切换为高。

## 决策

1. Codex AI Run 的后台默认推理强度从 `medium` 调整为 `high`，模型默认值仍为 `gpt-5.6-sol`。
2. 服务端继续作为默认值和允许列表的唯一来源；前端打开派工面板时使用服务端返回的
   `defaultReasoningEffort`，不单独维护默认值。
3. 调用方留空时，服务端同样按 `high` 校验并固化，保证绕过前端的入队链路行为一致。
4. 用户仍可为单次运行显式选择 `medium`；已创建运行和重跑沿用其固化值，不迁移历史数据。
5. Claude、Qoder 和自定义 Responses API 账号不使用此参数，保持原行为。

## 后果

- 新建 Codex AI Run 默认投入更高推理强度，用户仍能为速度或成本需要主动选择中等强度。
- 前端选择器、直接 API 入队和自动派工共享同一后台默认值，不会因入口不同产生参数漂移。
- 单次运行固化的 `reasoning_effort` 仍可在运行详情和领取协议中审计。
