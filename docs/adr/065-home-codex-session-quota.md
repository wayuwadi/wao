# ADR-065：首页展示 Codex 会话剩余额度

## 状态

已暂停。随首页自主进化区域于 2026-08-20 下线；额度同步能力本身不受影响。

## 背景

WAO 已经把 Codex OAuth 用量响应的主窗口和次窗口完整保存在额度快照中，但首页只读取七天次窗口。
用户要判断当前一轮 Codex 是否还能继续工作，必须进入设置页展开账号额度，无法在首页直接看到五小时
会话周期的剩余百分比。

OpenAI 没有提供适合 WAO 服务端直接依赖的稳定公开会话余额 API。现有 Codex OAuth 客户端已按照
ADR-031 隔离 `backend-api/wham/usage` 非稳定契约，并具备失败保留上次快照、隐藏凭据和手动重试能力，
因此继续复用同一真实数据源，不引入第三方估算工具。

## 决策

- `/api/ai/evolution` 新增 `sessionQuotas`，只从已启用 Codex 集中账号的真实用量快照读取五小时
  `primary_window`；不使用本地运行 Token、七天窗口或套餐常量估算。
- 首页新增“Codex 本轮剩余额度”卡片，展示 `100 - used_percent` 与重置时间；原周额度卡片继续保留，
  自主进化和低额度提醒仍只使用七天窗口。
- 五小时窗口不存在、额度同步失败或快照未知时不显示会话额度卡片，不以 `0%`、`100%` 或演示数据占位。
- 首页继续每分钟读取服务端快照；供应商同步频率和出站节点沿用 ADR-059 的现有调度与安全边界。

## 后果

- 用户打开首页即可同时判断当前 Codex 会话和本周额度，不必进入设置页逐层展开。
- 页面展示的数字可追溯到同一份供应商原始快照；上游契约变化时会安全隐藏，而不是产生误导余额。
- API 增加一个向后兼容字段，不需要数据库 migration，也不改变已有自动派发行为。
