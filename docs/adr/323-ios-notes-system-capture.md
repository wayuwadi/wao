# ADR-323：仅恢复 iOS 小记的系统采集入口

状态：接受；日期：2026-10-04。

用户确认 iPhone 12、iOS 27（用户提供，真机待核实）与微信读书场景，并明确要求开发：剪贴板导入提示、系统分享接收、录音结束自动转文字；书摘逐字保留引用，感想放在下方。此决策仅更新 ADR-264 的 iOS 小记范围，安卓、macOS/Windows 客户端与桌面发布继续暂停。

复用 ADR-221 的 Vue + Capacitor iOS 工程及既有小记 API，不复制服务端业务。新增原生分享扩展、剪贴板桥与本机录音/Apple Speech 转写；不引入付费转写提供商。麦克风/语音权限在用户操作时申请，录音保留到文字成功保存；中断停止录音并保留，首期不承诺后台录音。

扩展用共享 Keychain 取得主应用真实会话，App Group 只保存成员绑定的导入草稿，不保存凭据。每次提交先校验服务端会话成员，复用稳定草稿 ID；存在不同正文时不使用 PUT 覆盖。过期登录、断网与响应丢失保留草稿并明确“仅存本机”。未登录的分享不自动绑定下一位登录成员，须在主应用明确领取。

剪贴板仅自动检测是否有文本，点击导入才读取内容；拒绝或已导入的同次剪贴板不反复提示。剪贴板与分享不覆盖当前草稿。引用和感想以标准 Markdown 保存；后台正文润色仅接收感想并由服务端原样拼回引用，标题/配图可结合全文。不依赖模型遵守提示词来保证书摘原文。

iOS 专用构建与浏览器 Jenkins 解耦，安卓不随本次发布恢复。无签名 IPA 不是可安装交付；Mac/Xcode 编译、签名、微信读书真实载荷和实体手机验收分别记录。
