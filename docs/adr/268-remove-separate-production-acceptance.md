# ADR-268：主线发布去掉独立生产验收

- 状态：已采纳
- 日期：2026-09-24
- 来源：用户要求 Jenkins 只负责打包和部署，去掉「部署并验收」中的额外验收
- 调整：ADR-267 的发布后独立验收部分

## 决策

`wao-main-cd` 的第四个阶段改为「发布部署」。它只调用 `ci-deploy.sh`，不再运行 `ci-production-verify.sh` 中的演示页面、JumpServer、飞书授权、路由等公网功能检查。

部署脚本仍负责 Linux1、Linux2、云端的滚动发布，确认目标版本的节点健康、云端可回源，以及发布期间公共入口可用。这些是部署完成的基本条件，不作为单独的验收阶段。完整用户功能验收由开发和 PR 本地流程承担。

## 影响

减少每次生产发布中的重复公网请求及外部系统依赖。独立功能检查不再阻断发布；若演示页、JumpServer 或其他非核心入口发生故障，需要通过各自的监控或人工排查发现。
