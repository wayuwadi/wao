# ADR-279：小记链接预览使用飞书图片组件

- 状态：已接受
- 日期：2026-09-25

## 背景

PR #922 把小记配图写成 `lark_md` 里的 `![小记配图](https://.../api/images/.../raw)`。真实飞书会话把它显示为文本和 URL，卡片没有出现图片；只检查响应 JSON 的测试没有发现客户端渲染差异。

## 决策

- 沿用 ADR-196 的公开分享投影和同源边界，从图床按 ID 读取已经公开的小记首图，不按回调 URL 发起任意请求。
- 使用已配置的同一飞书应用上传图片，取得 `image_key` 后返回卡片 `img` 元素。成功的 key 按应用和不可变图片 ID 在进程内复用，不在卡片正文放图片 URL。
- 图片上传最多等待 1.8 秒，给三秒链接预览回调留出余量；超时的上传可在后台完成，后续预览复用结果。图片缺失、配置缺失或上传失败只降级图片，标题、纯文本摘要和原文按钮保持可用。
- 飞书图片缓存属于外部平台派生资源；重启后允许重新上传，不增加数据库表或公开接口。

## 验收

测试检查富文本和旧 Markdown 图片都产生 `img_key` 元素，图片失败时不泄漏 Markdown 语法或图床 URL。最终客户端是否展示图片以用户线上飞书分享验收为准，合并 PR 不等于飞书已刷新旧消息卡片。
