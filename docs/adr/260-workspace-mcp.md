# ADR-260：工作区 MCP 使用独立令牌和显式工具目录

状态：已采纳。

## 背景

现有 `/api/mcp` 与上下文记忆 MCP 只面向记忆。用户希望把 WAO 中的项目、未完成任务和知识库连接到外部 AI，并在首页像 ONES 一样生成带认证令牌的连接指令。直接复用记忆设备令牌会使历史令牌在未重新授权的情况下获得新的业务写权限。

## 决策

- 新增 `/api/mcp/workspace` 和独立 `workspace_mcp_token`。令牌按成员和设备签发，只存摘要，可独立吊销，并固定为只读或可读写；个人记忆令牌不兼容该入口。
- MCP 工具显式列举项目、任务、知识库能力，`tools/list` 按令牌写权限过滤；调用时再次检查令牌、成员可见性和业务服务约束。未来扩展按工具逐项评估，不能把所有 HTTP API 自动映射为 MCP。
- 首页一键签发并显示一次包含令牌的连接指令，后续仅能查看令牌前缀和吊销。连接说明要求客户端安全保存 Bearer、调用 `tools/list` 验证，并只推荐实际可用场景。
- 不暴露删除和通知工具。文档正文更新沿用 `expected_rev`，避免 AI 覆盖同时编辑的内容。

## 结果

外部 AI 能在用户明确授权后读取未完成任务和项目，并对项目、任务、知识库做常用写入。记忆权限与工作区权限不会因已有设备令牌互相扩张。后续功能迭代以 `docs/specs/wao-workspace-mcp.md` 和工具目录为同步清单。
