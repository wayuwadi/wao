# ADR-299：下线今日节奏

- 状态：已接受
- 日期：2026-10-02

用户要求下线今日节奏。移除浏览器路由、功能探索目录、导航注册、旧布局入口、手机导航和历史页签；移除 /api/workday-rhythm/** 专属控制器及后台提醒轮询。日历不再展示今日节奏模板或跳转到已退役页面，天气设置不再展示退役功能的开关。

历史日期、模板、草稿、提醒记录和已执行 migration 保留，不删除业务数据。日历考勤、天人一卦与其既有通知仍保留；卦象通知配置迁至设置的通知页，不恢复节奏仪表盘。共享内部数据服务暂保留，停止节奏专属入口与轮询。

工作区 MCP 与 CLI 未提供今日节奏专属工具或命令，不新增能力。验收覆盖旧地址、菜单与目录、旧接口、日历，以及天人一卦通知配置入口。
