# ADR-239：三节点同版静态制品与云端兜底

状态：采纳（制品阶段，浏览器自动选择尚未启用）

## 问题

目前每次云端发布会删除旧版哈希资源，已打开页面的懒加载可能失败。家庭节点还没有可校验、可回退的前端副本，不能直接把入口指向家庭域名。

## 决策

- 同一次前端构建打包一次，以完整 Git SHA 作为不可变目录名；完整清单记录每个文件 SHA-256 和长度。
- 按 Linux2 本地、Linux1、云机顺序校验并原子安装，再更新云端入口。同 SHA 不允许覆盖不同内容；损坏已有版本明确失败，不伪装幂等成功。
- 安装器拒绝软链接、路径穿越、重复文件、隐藏文件、源映射和常见私密文件；总解包上限 1 GiB。安装中断只留下不可公开的临时目录。
- 公共节点仅开放指定版本 assets 与制品清单，固定主站 CORS，不开放 API、用户文件或 SPA 回落。健康接口的 businessRoutingEnabled 保持 false。
- 云端保留同版制品，同时保留旧的 /assets 哈希文件；入口 HTML 最后原子替换。暂不自动删除历史版，后续根据磁盘占用设计保留窗口，至少保留当前和上一稳定版本。
- 本次不改变浏览器加载地址。只有完成真实浏览器选择、超时回退、懒加载、当前草稿保护验证后才启用静态直连。API 会话桥接独立实施。

## 运维与边界

Linux2 存储在 Jenkins 主目录的 wao-static/releases；Linux1 在 ~/deploy/wao-public-edge/releases；云端在 /var/www/wao/releases。Compose 必须显式提供 WAO_EDGE_RELEASES_DIR。静态副本不等于业务高可用，不等于数据库自动切主。

回退节点配置时恢复先前的 Nginx 模板与 Compose；保留版本目录不会改变既有请求。流水线失败不得切换浏览器入口。磁盘空间不足应让安装失败并清理本次临时目录，不删除其他版本以强行发布。
