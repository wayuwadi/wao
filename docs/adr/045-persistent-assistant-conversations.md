# ADR-045：AI 助手使用成员级持久化会话

## 状态

已采纳。取代 ADR-041 中“页面历史只保存在浏览器当前会话”的决策；Runner 路由与只读沙箱继续遵循
ADR-044。聊天资料检索范围已由 ADR-046 的统一 WAO 资产检索取代。

## 背景

右下角助手原本是 420px 临时抽屉，消息仅存在 Vue 组件内存。刷新页面、退出登录或更换设备后记录都会
消失，也无法像常见聊天产品那样从左侧历史继续过去的问答，因此不能成为以个人聊天记录为内容的问答知识库。
WAO 已经把飞书群聊按天同步成知识库文档，但原助手也没有检索这些真实聊天文档，无法回答“之前聊过什么”。

`ai_assistant_run` 是短期执行队列：完成后必须清除包含页面上下文的提示词，不能直接把它改成长期聊天表，
否则会混淆队列生命周期与用户数据权限。

## 决策

- 新增成员级 `ai_assistant_conversation` 和 `ai_assistant_message`，会话列表只返回当前成员的数据；删除会话
  级联删除消息，仍有问答执行时拒绝删除。
- `ai_assistant_run` 只增加可空的会话、用户消息关联；仍在完成后清除拼装提示词，执行队列与长期消息分离。
- 首次发送时创建会话并根据第一条问题生成标题；用户问题入队时原子保存，Codex 成功回传时保存助手回复。
- 续聊的最近上下文从服务端持久化消息读取，不信任客户端自行声称的历史；每个成员仍只允许一个活动问答。
- 每次提问在服务端从“飞书群聊同步”所配置的知识库最近 120 篇文档中做本地文本相关度排序，最多把 3 篇、
  8,000 字候选资料作为不可信只读上下文交给 Codex；回答必须标注实际使用的聊天记录标题，没有依据时明确说明。
- 右下角入口打开宽屏聊天工作台：左侧提供新对话、搜索、切换与删除历史，右侧展示对话和固定输入区；
  窄屏时历史栏改为可收起抽屉。
- 聊天内容属于成员个人数据，不复用任务或知识库的组织级共享权限；本期不提供公开分享和跨成员搜索。

## 后果

- 刷新页面和更换登录设备后仍能恢复最近 50 个会话及每个会话最近 200 条消息。
- 已同步的飞书聊天记录成为问答资料源，引用可以通过知识库文档地址追溯；没有配置同步时仍可进行普通问答。
- 含聊天资料的本地 Codex 回复允许最多等待五分钟，SSE 与 Nginx 超时同步留出十至三十秒收尾余量。
- 短期 Runner 队列可以按既有清理策略维护，不会误删用户明确保留的聊天记录。
- 历史持续增长，需要后续根据真实规模增加分页、导出和保留期设置；本期先以边界查询保护页面性能。
