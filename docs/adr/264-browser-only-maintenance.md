# ADR-264：仅维护浏览器版本

- 状态：已采纳
- 日期：2026-09-24
- 来源：用户明确决定，多客户端维护成本过高

从本决策起，WAO 只维护浏览器版本。新增需求、缺陷修复、真实用户链路验收与正式发版都以 Web 为目标。macOS、Windows 等独立客户端停止功能维护与新包发布，Jenkins 的 `wao-client-release` 任务禁用。

保留历史源码、已发布安装包、更新签名密钥的受限存储以及兼容入口，不删除现有用户数据、不自动卸载应用、不撤销已发布包。保留并不表示继续承诺客户端兼容性。客户端专属任务注明停止维护决策；已有修复如实记录已验证结果。

主站继续保留测试、不可变制品、滚动部署和健康检查。发布速度优化针对浏览器交付路径实施，避免为了快而省去必要的生产校验。重新启动客户端维护需要用户明确更新本决策。
