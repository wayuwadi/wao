# ADR-319：下线回顾、报告、历史点子及过时设置

状态：已采纳（2026-10-04）。来源：产品所有者要求下线人生回顾、系统报告、历史点子归并，以及设置中的 WAO AI 能力、版本与更新、断网时段；另明确移除系统与个人通知设置里的 AI Run 成功、失败四项配置。

## 决定

- 人生回顾、系统报告、历史点子归并从浏览器路由、导航、功能目录、手机导航及持久页签恢复中退役。通知中心不再提供系统报告入口。
- 设置页移除 WAO AI 能力、版本与更新、断网时段面板及加载、保存、草稿守卫。旧 query 入口回退到组织与成员，已打开设置页收到旧链接时同样回退。网页更新检测与保存草稿后刷新继续保留，功能探索继续使用原有独立入口。
- 专属 API `/api/life-reviews/**`、`/api/system-reports/**`、`/api/ideas/**`、`/api/settings/network-outage-window`、`/api/ai/application-skills`（含各根路径）统一返回 HTTP 410 与 `ApiResponse` 错误码 41000，拒绝全部方法，避免旧浏览器继续读写或产生 AI 工作。
- 人生回顾与系统报告的调度器、专属执行器不再注册，旧环境变量不能重新启用。Runner 不再领取点子研究队列；旧运行完成回执兼容保留，不派发新工作。
- 断网时段不再限制自动调度，即使保存过启用或跨午夜的旧配置也不生效。定时任务仍沿用现有 Cron、补跑和显式调度开关，不改写生产计划。
- 系统与个人通知设置不再展示 AI Run 成功、失败选项。兼容 JSON 字段保留为固定 `false`，读取历史配置与接收旧客户端保存时均不能重新启用。任务通知、每日提醒、Jenkins、天人一卦通知保持现有策略。

## 数据与共享能力边界

本次不删除表、历史业务记录、成员配置和本机草稿，不新增 migration；需要清理历史数据时另行明确授权。保留仍被其它模块复用的 AI 助手、项目与知识库服务及其底层记录，不将下线设置面板扩大成全部 AI 能力退役。

这些能力未在当前工作区 MCP 工具目录和 wao CLI 中开放，本次无需新增或删改 CLI 命令，也不扩大令牌权限。相关旧规格与 API 文件是历史设计记录，以本 ADR 的退役规则为当前行为；覆盖 ADR-072、ADR-109、ADR-121 与 ADR-107 中对应的存续条款。

## 验收

检查导航与历史页签、旧 URL 与设置 query 回退、通知中心残留入口、通知草稿保护与失败重试、旧配置不可重新启用、API 所有方法返回 410 及相邻存续接口可用。验证本地真实服务连接既有数据库，不执行迁移、自动任务或破坏性数据操作。按照 ADR-232，合并即交付，线上验收由用户负责。
