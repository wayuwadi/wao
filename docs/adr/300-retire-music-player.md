# ADR-300：音乐功能下线并保留文件库音频

状态：已采纳（2026-10-02）。来源：产品所有者要求“音乐功能下线”，并提供全局音乐播放器截图。

## 决定

浏览器不再挂载全局音乐播放器，不展示悬浮入口、音乐列表或网易云来源。设置页移除播放器默认开合与入口显隐，成员偏好加载不再请求 `music-player-settings-v1`；历史成员偏好与浏览器本地状态保留但不再使用，不能重新开启播放器。

移除网易云专属控制器、服务、配置、实体、映射及部署环境变量，`/api/music/netease/**` 不再注册，旧 OAuth 回调不再享有公开访问豁免。已有客户端请求无法发起新授权、续期、歌单读取、取播放地址或播放回传。

复用 ADR-297 已合并的资源不存在异常响应：已登录客户端访问旧音乐地址时返回 `404` 和统一 `ApiResponse`，避免把已下线接口误报为服务器故障；未登录访问继续受会话认证保护。

音乐功能没有独立工作区 MCP 工具或 CLI 子命令，因此不增加替代入口，也不扩大旧令牌权限。

## 数据与兼容边界

文件库中的音频属于通用文件资产，上传、文件预览、流读取和下载继续保留。共享 `/api/files/{id}/stream` 仍支持音视频的 Range 读取，不随播放器下线删除。

本次不新增删除数据的 migration，不修改历史 `V68__netease_music_binding.sql`，不删除网易云绑定、OAuth 状态或既有文件。绑定数据不再被运行代码读取；如后续需要清理历史表、偏好或撤销外部授权，应另行确定范围并取得授权。

本 ADR 取代全局音乐播放器规格及 ADR-071 的继续提供音乐功能决定；原文保留作为历史记录。独立桌面客户端不恢复开发或发布。

## 验收

登录后首页、设置页与跨页面导航均没有播放器、音乐按钮或专属音频节点；即使成员以前开启默认展开，当前浏览器也不读取音乐偏好。个人偏好中其余设置可读取、保存且保留成员隔离和迟到响应保护。

后端启动后的路由目录没有 `/api/music/**`，文件流接口仍注册。前端类型检查、构建、偏好测试及后端上下文和文件流回归通过；本地浏览器使用当前公网临时实例同源的 `wao_local` 数据库完成真实用户链路验收；原 Linux2 生产数据库未在本次复验。按 ADR-232，PR 合并后交付，线上验收由用户负责。
