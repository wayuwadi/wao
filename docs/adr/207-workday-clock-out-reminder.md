# ADR-207：下班群提醒使用法定日历门禁而非仅限制 Cron 星期

## 状态

已接受（2026-09-08）。

## 背景

预置“下班休息与打卡提醒”与其它固定提醒共用 `feishu-notification`，Cron 每天 18:00 触发，执行器不判断日期性质，因此休息日也会发到真实群。只把 Cron 改成周一至周五会漏发周末调休工作日，也会在落于工作日的法定假期误发。

## 决策

1. 新增 `workday-feishu-notification` 执行器，在实际发送前复用 `HolidayService` 的国务院放假调休事实；有官方特殊安排时以其为准，否则按周一至周五判断。
2. 只有“下班休息与打卡提醒”迁移到工作日执行器；其它提醒保持每日规则。
3. Cron 仍按每天 18:00 产生计划点。执行器使用 `scheduledFireAt` 的上海日期判断，休息日返回可审计的“已跳过”，调休工作日委托既有飞书执行器发送。
4. 手动试发没有计划时间，直接委托真实发送器；设置页返回只读 `workdayOnly` 标志并显示“工作日”。编辑已有提醒时保留原执行器，避免修改文案或时间后丢失日期门禁。

## 后果

- 法定休息日不会产生飞书发送副作用，周末调休工作日不会漏掉下班提醒。
- 未收录未来年度的具体调休不做推测；发布新的国务院安排后应更新日历依赖或数据并复验。
- 自动化运行历史能区分策略跳过与发送失败，管理员仍能在任意日期主动试发真实配置。
