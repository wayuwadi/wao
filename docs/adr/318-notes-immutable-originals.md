# ADR-318：小记不可变原稿及私人输入关联

状态：接受；日期：2026-10-03。

最新内容仍是唯一编辑正文。新增只读原文查看，更新旧的取消原文切换决定；原稿永久性由不可覆盖快照、首份指针与事务约束保证，入口存在本身不是保证。

首次原稿、每轮完整来源、实际模型输入与结果分开存储，以稳定请求/阶段 ID 幂等关联。先冻结再执行，结果关联与文档 CAS 同事务；保存前候选私人留存，实际保存才确认采用。历史覆盖对照只作真实有限的兼容来源，缺失早期内容不推断重建。

成员私有历史需要现存文档及本人快照，分享不附带历史；按篇按需读取，不提供版本管理或恢复操作。现存资产引用阻止误删，永久删除文档级联历史。浏览器来源查看状态与编辑草稿隔离，切换成员丢弃迟到响应。

依据见 [规格](../specs/notes-immutable-originals.md)。
