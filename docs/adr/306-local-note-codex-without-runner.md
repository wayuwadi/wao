# ADR-306：小记通过本机 Codex 执行，旧 Runner 继续退役

- 状态：已接受
- 日期：2026-10-02

用户明确要求保留小记配图，并使用本机已有 Codex / ChatGPT 登录重新接通 AI。ADR-304 的 Runner 退役决定继续有效；本决策仅补充小记执行出口与配图入口。

恢复浏览器总览配图、图片提示词及小记阶段按钮。服务器在显式启用 `wao.ai.local-notes.enabled` 后，直接启动本机 Codex 子进程，完成小记标题、正文润色、标签和配图；默认模型为 GPT-6 Astra，已保存的有效模型偏好继续有效。未启用时文字任务保留既有获准 API 路径，配图立即报告未启用；启用后失败不得转用额外付费 API。

沿用 `ai_assistant_run`、`note_ai_workflow`、润色持久任务及图床，不增加通用执行平台、数据库迁移或外部领取 / 回调接口。本机目录持有独占锁，随机持久实例标识隔离队列；只消费本实例任务。领取和完成均使用状态与 claim token 条件更新。执行默认最多 300 秒，排队最多 60 分钟；同实例重启将中断运行标为失败供用户重试，不自动重做未知结果的调用。未领取队列可继续。业务原文、版本和草稿由既有小记体系保护。

CLI 仅沿用服务运行账号已有 ChatGPT 登录，忽略用户配置、工作区规则及外部 MCP，禁用 shell、子代理、查看文件图片与联网搜索，使用只读沙箱；只有配图允许内置图片工具。移除子进程环境中的数据库凭据与 API Key，不复制登录文件。PNG 仅从 CLI `thread.started` 对应生成目录读取唯一文件，验证类型、尺寸和归属，忽略模型自报路径。入库完成被取消时清理新孤儿；数据库提交结果未知时保留图片以免误删已引用结果。

不开启旧 `/api/ai/runner`、`/api/ai/runners`、配对、凭据分发、节点管理、生命周期调度或 Runner 安装。原退役接口仍返回 410。管理员须在持有登录的主机显式启用；本次本机验收不等于公网服务已更新，部署必须单独确认。

回归与启用说明见 [本机小记 AI](../runbooks/local-note-ai.md)。此前验收专用替身仅用于隔离测试；日常服务通过产品主入口启动。
