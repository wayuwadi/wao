# ADR-213：今日行动按通知类别独立选群

状态：已采纳（2026-09-08）。补充 ADR-081、ADR-120、ADR-201。

原精力补给、今日重点和卦象解读共用一份发送目标，无法满足补给进通知群、重点和卦象留在讨论群的需要。

在现有成员偏好中保留原目标给精力补给，新增 `focusTarget` 和 `tianrenTarget`；同时增加可选 `notifyEnergy` 开关。未迁移成员继续投递原群，显式独立目标为空时拒绝发送，不回落系统默认或其他类别的群。

前端把两个真实来源合并进分类下拉框，并提供页面顶部「通知设置」入口。三类可分别启停、选群，草稿和跨设备保存沿用既有机制。服务端按类别解析独立目标，卦象冻结目标和重试保护继续生效。

不新增数据库表或迁移；群名及 id 属于成员设置，不硬编码或批量替换其他成员偏好。系统通知、每日必做提醒等不在本次范围内。
