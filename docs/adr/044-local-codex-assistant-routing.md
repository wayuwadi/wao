# ADR-044：AI 助手路由到任一在线本地 Codex

## 状态

已采纳。取代 ADR-041 中“只有 Linux Codex Runner 可以领取页面问答”的决策，其余安全边界保持不变。

## 背景

WAO 已能通过 Runner 调用 Codex CLI，但右下角 AI 助手的可用状态和领取条件被限制为 Linux。
用户的 Windows 和 Linux 电脑都可能已安装、登录 Codex；主节点短暂重启时，页面还会把一次状态请求失败
一直保留为“不可用”，即使 Runner 已恢复心跳。

## 决策

- 任一在线且上报 `codex` 能力的 Runner 都可以为 AI 助手完成对话，不再限制操作系统。
- 面板打开且尚未连接时，每 5 秒重新检查真实 Runner 状态；状态请求禁用中间缓存。
- 可用状态显示实际提供对话的本地执行电脑，不再将实现细节暴露为“Linux 节点”。
- 问答仍在临时空仓库和 `read-only` 沙箱中执行，不因扩大节点选择而获得主机文件或命令权限。

## 后果

- 任一已接入的本地 Codex 都能为右下角助手提供对话，某一操作系统离线不再导致整个助手不可用。
- 短暂的 502、网络闪断或部署重启恢复后，打开的面板会自动回到可输入状态。
- 真实修改代码或生产数据的需求仍必须从任务详情发起 AI run，不会被伪装成只读对话绕过审计链。
