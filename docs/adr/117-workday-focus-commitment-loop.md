# ADR-117：今日三个重点建立群承诺与顺序执行闭环

## 状态

已接受（2026-08-25）。

## 上下文

成员在「今日节奏」填写的三个重点通常是真实且正确的，但原流程只保存文本并自动完成「制定今日计划」，没有对外承诺和「现在只做什么」的约束。结果是目标正确，执行仍可在工作、工具研究和其他事项之间频繁切换。

仓库已有成员级的 Webhook / 飞书应用群聊目标与服务端加密凭据，也已有按日期的真实重点记录。不需要复制任务或引入演示状态。

## 决策

- 复用 `workday-rhythm-config-v1.energyNotification` 中的真实通知目标，增加向后兼容的 `notifyFocus` 开关。旧的已启用配置默认允许发送重点，成员可在「今日行动飞书通知」中单独关闭。
- 前端先把三个重点落库并完成计划联动，三项均非空时再调用独立通知端点。通知失败不回滚已保存记录，前端保留待通知日期并原位重试。
- 通知端点只接收日期。服务端从会话确定成员，重读该成员当日偏好中恰好三个非空重点，再用服务端凭据发送；不接受前端自报成员、目标、群或 Webhook。
- 当天记录增加 `focusCompleted[3]`。页面仅突出第一个未完成重点，只为它提供「完成并开始下一项」；完成由成员主动确认并跨设备保存。编辑某项会重置该项及其后状态。

## 后果

- 成员从「列对目标」进入「群内承诺—当前唯一重点—完成后切换」的可观察闭环，但具体任务进度仍以真实待办为准。
- 复用已存在的成员通知目标，不新增凭据、不复制群配置。尚未配置真实目标时保持通知关闭，不模拟发送成功。
- 同步投递沿用 ADR-081 的至少一次语义；如果飞书已收到但响应丢失，手动重试可能出现重复卡片。需要统计或严格去重时再增加独立投递记录。
