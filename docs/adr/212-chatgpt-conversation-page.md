# ADR-212：ChatGPT 日常对话独立入口

## 状态

已采纳（2026-09-08），扩展 ADR-044、ADR-045。

## 需求与依据

任务 t1788853747082 要求不用切走桌面 Codex，在 WAO 菜单直接进行简单问答，左右布局并保留历史。
现有助手已经具备真实 Runner / 集中 AI 配置与成员隔离的持久会话，因此复用它，避免另起会话服务或复制历史。

## 决策

- 新增默认可见菜单「ChatGPT对话」与 `/chatgpt` 路由，在工作台完整目录中也可找到；稳定功能 id 为 `chatgpt`。
- 页面左侧新建、搜索、切换与删除会话，右侧 Markdown 问答与固定输入区，窄屏收起历史。
- 页面与悬浮助手使用应用壳中的同一实例；切换业务页签不销毁正在接收的回复。
- 继续使用 `/api/assistant`、实际可用 AI 能力及已有个人历史。菜单名称不代表嵌入 ChatGPT 官方客户端，实际能力名称在输入区显示，不宣称复制语音、附件、GPT 或外部 ChatGPT 历史。
- 草稿按登录成员和会话分别保存在本机，服务器完整答复成功后清空；失败保留原问题并提供重试，错误不作为模型消息展示。本机存储不可用时明确提示。
- 切换历史使用请求版本拒绝迟到结果，历史读取失败可重试；中文输入法确认文字不会触发发送。
- 不修改接口契约、数据库表、执行权限与部署拓扑；菜单注册表补充默认项，保留已有定制。

## 验收结果定义

进入菜单，真实提问并收到回答；追问能使用上轮内容；刷新恢复服务端记录；草稿切换与刷新不丢失；新建、搜索、删除与窄屏历史可用。
