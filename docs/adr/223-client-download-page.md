# ADR-223：统一客户端下载页与移动端公开分发

日期：2026-09-10。状态：采纳。

## 决策

新增无需登录的 `/download`，从登录页/应用公共页脚及快捷链接进入。参考大留白、设备展示的下载页结构，移动端优先提供 Android APK 与需用户个人签名的 iOS IPA；Windows 使用已有完整工作区发布清单，macOS 未发布时只展示状态。桌面宠物保留 `/desktop` 独立入口。

安装包通过 WAO 自有域名公开分发，不依赖私有 GitHub 仓库登录。移动端使用 `/downloads/mobile/<version>/` 不可变文件目录，`latest.json` 禁止缓存；文件必须校验 SHA-256 后才原子切换清单，拒绝降级或同版本不同字节覆盖。安装包不含账号凭据，业务数据仍需要登录。主站部署不得删除独立制品目录。

GitHub 移动端发布 job 在双端编译成功后生成清单，使用已有云 SSH secrets 上传、服务端校验、原子发布，并从公网下载核验。首次用已验证的 1.0.0 制品补齐分发，不重打包。主站仅消费清单，日后客户端升级不需要重新发布主站。

## 验收

清单必须是 JSON 且平台、版本、文件名、大小与校验和合法；200 HTML 不得当成有效发布。各平台独立加载/失败重试，按钮只对真实存在的二进制制品开放。检查桌面及 390/320px 窄屏、无登录访问、下载响应与 SHA-256、不存在文件返回 404、清单禁止缓存。
