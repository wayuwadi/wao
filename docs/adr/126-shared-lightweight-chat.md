# ADR-126：组织共享轻量聊天与飞书出站同步

## 状态

已采纳。

## 上下文

WAO 已有成员级 AI 助手和飞书聊天复盘，但前者是人与 AI 的私有会话，后者是对既有飞书群聊的离线分析，
都不能让已登录成员临时互发文字和电脑截图。现有图床可以持久化并公开读取截图，通用飞书 Webhook 注册表也
已经提供经过加密管理的真实群机器人目标，因此不需要新造演示群聊或把凭据写进代码。

## 决策

- 新增组织内唯一的共享聊天室。所有已登录成员可读取最近消息和发送文字或一张截图；发送者身份只从服务端
  会话推导，请求体不能指定作者。
- 消息与截图先落入 MySQL，再尝试投递到通用 Webhook 注册表中的系统默认机器人。飞书不可用不能回滚已发送
  的 WAO 消息，消息保存 `SENT`、`FAILED` 或 `UNAVAILABLE` 状态，失败项可以显式重试。
- 客户端为每次发送生成稳定 `clientToken`，服务端按成员和 token 去重，避免超时重试产生重复消息或重复飞书
  投递。文本最多 2,000 个 Unicode 字符；一条消息至少包含文字或一张已持久化图片。
- 截图复用 `image_blob`，飞书卡片提供可公开访问的原图链接和返回 WAO 聊天室的按钮。首版不伪造飞书消息
  入站：机器人 Webhook 只支持出站，现有飞书事件订阅也只处理经过配置验证的快速收集事件。
- 页面每五秒增量读取新消息，只追加服务端结果；未发送文字保存在浏览器草稿，轮询和失败重试都不能覆盖输入。

## 后果

- 成员在不登录飞书的电脑上也能把文字或截图发到 WAO，并由已有真实机器人同步给飞书群成员。
- 飞书目标沿用“设置 → Webhook配置”的系统默认项；未配置或停用时 WAO 聊天仍可用，并明确显示未同步。
- 首版不包含已读回执、消息撤回、多个聊天室、飞书入站镜像和历史分页；最近 100 条足以覆盖临时沟通场景，
  后续应根据真实使用规模决定扩展方向。
