# ADR-215：以真实用户身份回复原生表情

- 日期：2026-09-08
- 状态：已采纳
- 替代 ADR-214 的共享反馈卡片展示方案，保留真实反馈数据和消息绑定。

## 用户纠正

用户验收后明确要求：原消息下显示各人的原生表情（✅ 娃哥、✅ 娃弟），不另发反馈消息，也不以卡片正文摘要替代。

## 决策

飞书添加/删除表情 API 支持 user_access_token，以该凭证所属用户为作者。按钮回调仅提供身份，不能作为个人授权。新增独立的个人表情授权入口，仅申请表情权限和离线刷新；复用已登记的飞书登录回调地址，通过前缀区分流程，不改变 WAO 登录绑定。OAuth state 绑定发起浏览器会话，服务端兑换授权码并用 user_info 校验真实 open_id，凭证以机器人 app_id + open_id 隔离、AES-GCM 加密持久化，严禁前端、日志或机器人回退泄露/冒用。

回调继续每人保存最新真实选择，以此人授权凭证在原消息添加 CheckMark/CrossMark；本人改选仅移除本功能此前创建的相反表情，不能删除其他成员的表情。授权缺失、过期或被拒绝只返回个人 toast，引导授权或重试，不在群中新增回复。旧卡和之前的共享回复按钮仍归属原通知，后者也只对原消息贴表情。停止所有新增共享反馈回复与成员摘要更新。

## 验证与运维

覆盖 OAuth state、真实用户绑定、凭证加密刷新、无授权不借用机器人、两人分别调用自己的凭证、改选不动他人、API 失败保留实际选择，以及不调用发送/回复消息接口。需要飞书应用启用用户表情权限，并由成员各自首次授权；自动化不能代替成员同意 OAuth。线上验收要验证个人表情作者和无新增群消息。
