# ADR-228：客户端刷新保存与安静桌宠

- 状态：已采纳
- 日期：2026-09-10
- 来源：任务 `t17890254379610`

依据用户对客户端的 14 条反馈，调整 ADR-222 的每次刷新确认和 ADR-227 的多按钮宠物快捷回复体验。

桌面刷新改为调用同源页面保存屏障：任务、文档和已注册表单完成保存后再刷新，失败或剩余未保存状态阻止刷新。桌面识别标记仅控制界面与短时缓存，不授予远程页面原生权限。白名单业务读取按已验证成员隔离，过期查询服务器，业务写入、账号切换和退出失效。

宠物只保留本体与一次性提示，点击消息回到原工作区聊天。客户端启动独立透明置顶宠物，网页不再重复展示；旧客户端使用同源成员校验的存储事件兼容唤起工作区。新版只增加 `open-chat` 固定动作及字符白名单约束的任务 id 动作，继续验证来源路径与同源，不接受脚本、文件路径或任意外部 URL。

客户端版本 1.1.2，与 Web 分开发布。Windows 构建和实际更新/窗口验收分别记录；构建成功不等于实机体验验收。具体交付范围见 `docs/specs/client-bug-collection-2026-09-10.md`。
