# ADR-275：云端使用 Linux1 专用反向隧道回源

- 状态：已采纳
- 日期：2026-09-24
- 来源：构建 #506 使用 Linux1 公网地址直连 `:9000`，在 Linux1 本地服务健康后云端仍连接超时
- 取代：ADR-274

## 决策

云端 `/etc/hosts` 中的 `linux1.wayuwa.cn → 127.0.0.1` 是专用反向 SSH 隧道，云端访问 Linux1 Gateway 应走这条隧道。公网 Nginx upstream 地址、云端 Gateway 健康检查和每分钟重渲染必须使用云端本机的同一解析结果。公网 DNS 的 Linux1 地址不可直接替代隧道；它在 #506 的真实部署中超时。

Jenkins 不在 Linux2 上渲染云端 Nginx 配置，改由云端安装好脚本后本地渲染。常规发布和纯网页发布均先安装云端渲染脚本。首台可验证通知仍以云端隧道回源和公网 API 实际检查通过为条件，最终持续可用性采样仍保留。
