# ADR-218：宠物小世界采用按需加载的 Three.js 场景

- 状态：采纳
- 日期：2026-09-09

## 背景

用户要求基于张三丰宠物，交付能进入、能走动的 Web 3D 小世界原型。现有 Vue / Vite 技术栈和二维宠物图集需要继续复用。

## 决策

新增受登录保护的 `/pet-world` 路由，在该路由内按需加载 Three.js 0.184.0。Vue 继续负责页面和交互，Three.js 只负责三维场景；角色使用既有 v2 图集的面向镜头精灵，方向帧与网页宠物共用坐标契约。移动、碰撞和跳跃规则独立于渲染，便于测试和后续替换场景。

本次庭院全部使用原创程序化几何构建，不引入参考仓库中来源独立的游戏地图、模型或纹理。参考 https://github.com/portons/codex-pet-share 的“3D 场景 + 2D 角色”交互形式，不移植其 React / Cloudflare 架构。

## 边界与兼容

原型为单人场景，无虚构玩家、联机状态或奖励。位置仅在当前浏览器按真实登录用户隔离保存；失败时保留本次游玩并提供重试。无需接口、数据库、部署配置变化。关闭路由释放帧循环、纹理、材质、几何和 WebGL 上下文；后台页面暂停操作。原有网页宠物、通知、聊天和游戏厅不变。

后续增加地图、NPC 和任务时应独立建模；联网同步和永久游戏资产需另行定义后端契约。该选择不将二维角色宣称为可自由旋转的三维骨骼模型。
