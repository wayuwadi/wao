# ADR-320：天人一卦配图绑定解读版本并私有保存

- 状态：已接受
- 日期：2026-10-04

用户确认「图文结合」Demo：卦象事实旁展示一张配图及变与不变短句，当前页面可配置解读和配图提示词，并在解读后一起出图。

## 决策

- 沿用 ADR-308 的本机 Codex 和当前天人默认模型。一次文字调用输出完整九章节 Markdown 与视觉摘要，再由既有 worker 进行一次真实绘图；不新增执行平台。
- 新协议以 `tianren_visual` 持久记录标识，旧运行继续使用 Markdown。文字运行成功、私有会话回复和图意待办同事务提交；图片失败不回滚已保存文字，不影响现有文字分享和通知。
- 配图以解读运行及图片 attempt 绑定，重复网络请求幂等；旧 claim 和旧 attempt 不能替换当前图。同版本重新配图成功前保留旧图，新版本不展示旧图为新结果。
- 设置按成员 CAS 保存，两个提示词与开关原子生效。自动配图使用解读发起时的设置，手动重画使用当前已保存的画面提示词。
- 通用图床原图可匿名读取，个人关注点可能进入图意，因此生成 PNG 存于成员专属领域表，通过鉴权接口读取。首版不扩展公开分享图片。
- 无变爻如实说明守持与深化，卦象事实来自既有服务端结果，图片里的汉字和爻线不作为权威信息；标题与短句由页面显示。
- 历史只读已有图，不批量生成；当前私有算卦授权不延伸到既有工作区 MCP/CLI 令牌。
- 实测内置图片工具会在同线程重绘。绘图提示要求只调用一次；执行器仍以可信 `thread.started` 对应目录中最后落盘的唯一图片收取结果，不采信模型回答路径，时间并列或无效图片拒绝保存。

## 验证与边界

事务、失效 claim、重发、成员隔离、无图历史、设置冲突及前端草稿由相称回归覆盖。真实本地解读及生图、刷新与窄屏操作记录于本需求验收文档；PR 合并与线上发布分别报告。
