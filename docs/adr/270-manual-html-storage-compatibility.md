# ADR-270：人工托管 HTML 的隔离存储兼容层

## 状态

已采纳。

## 背景

WAO 的人工 HTML 托管地址 `/api/pages/{slug}` 使用 CSP sandbox 形成不透明来源，避免上传脚本读取 WAO 会话或调用站内受保护 API。部分第三方单文件 Demo 在加载时直接写 `localStorage`；写入失败会中断后续脚本，让已更新的页面看起来仍是旧版。用户需要继续在 WAO 托管文件、不修改第三方原文件，并在刷新后保留 Demo 数据。

## 决策

- 人工上传的 HTML 字节原样存储。公开地址仍为 `/api/pages/{slug}`，列表与上传入口不变。
- 人工页面的 HTTP 响应改为 WAO 可信外壳。外壳把上传原文置入 `sandbox` iframe，且不赋予 `allow-same-origin`，因此第三方脚本仍无法取得 WAO 主站身份。AI Run 报告维持原有受限直出行为。
- 外壳在原文脚本运行前注入只针对该 iframe 的 `localStorage` 兼容对象。读取是同步的；写入经 `postMessage` 交给可信外壳，以稳定页面 ID 为命名空间保存在浏览器本地存储中。外壳只接受自己 iframe 的消息，并限制每页数据大小；不把 WAO 其他存储键或会话交给上传页。
- 外壳的浏览器标题从原 HTML 的 `<title>` 取得，WAO 管理名称只用于列表。原始 HTML 内容不做标题、icon 或脚本删除；用户另行上传的 icon 仍可作为标签页 icon。
- 站内预览让可信外壳访问主站存储；上传的 HTML 仍在外壳内部的不透明来源 iframe 中运行。

## 边界

- 兼容的是常见的 `localStorage` 读写与刷新恢复。此方式不把上传页变成 WAO 同源应用；依赖 WAO 登录态、Cookie、同源 API、`indexedDB` 或直接访问顶层页面 DOM 的 HTML 仍可能受浏览器隔离限制。
- 浏览器禁用本地存储、存储空间不足或超过每页 2 MB 限额时，当前页面仍可打开，但无法保证刷新后保存。不同浏览器设备间不自动同步 Demo 数据。
- 仍只托管 UTF-8 单文件；外部资源和相对路径遵循原有单文件约束。
