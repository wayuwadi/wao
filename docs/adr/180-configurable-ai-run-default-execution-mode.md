# ADR-180：AI Run 默认执行模式可直接配置

- 状态：Accepted
- 日期：2026-08-31
- 调整：[ADR-093](093-ai-run-codex-plan-mode.md)、[ADR-134](134-ai-run-dispatch-mode-and-reasoning-depth.md)、[ADR-169](169-codex-native-goal-mode.md)

## 背景

任务派工面板已经支持直接执行、Plan 和目标三种 Codex 模式，但前端每次打开都固定选中 Plan。用户长期采用
目标模式时只能重复切换，改变硬编码又需要重新发布。单次运行选择与长期默认偏好也需要区分，避免一次临时改选
意外改变之后的派工行为。

## 决策

- `/api/ai/run-options` 除模型和推理强度外，下发服务端持久化的 `defaultExecutionMode`；未保存或存量值无效时
  回落到现有的 `plan`，保证升级和回滚兼容。
- 任务派工面板在三种模式旁展示当前默认值。用户先选择本次模式，再显式点击“设为默认”；保存过程展示保存中、
  已保存和失败重试，单次切换本身不写配置。
- 保存接口只接受 `direct / plan / goal`。任务派工与首页自主目标初始化时使用同一服务端默认值，最终仍分别固化为
  运行记录中的 `plan_mode / goal_mode`，不改变 Runner 协议和历史运行。

## 结果

用户可以在实际派工入口直接调整以后默认选中的模式，无需改代码或进入另一处设置；临时选择和长期默认仍有清晰边界。
