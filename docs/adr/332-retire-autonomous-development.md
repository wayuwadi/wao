# ADR-332：终止并回滚 WAO 自主建设

- 状态：已接受
- 日期：2026-10-07
- 取代：ADR-331 的自主代码协调授权与实现。
- 依据：用户在当前会话明确宣布项目失败，要求终止并回滚。独立执行器不能复用 Codex 本身完整的浏览器能力，收益不足以支持长期维护。

撤回自主建设工作台、首页伙伴提醒、看板摘要、独立 Agent 派工、代码验证/交付协调器、专用浏览器助手接入和飞书决定路由。既有普通自动化、业务只读 AI、飞书任务/小记收集和数字成员图库继续按原规格运行；不恢复退役 Runner，不扩大 CLI/MCP 权限。

停止新审视和领取，终止仅属于此项目的在途编码/验收子进程，移除持久运行参数。数据库通过新增迁移关闭策略、暂停尚未收口的记录、失效租约和待决定，保留原方案、证据和工作区；V190 原文和历史 ADR 保留，不删除表或用户数据。已合并的其他功能提交保留，应用采用独立回滚 PR 与正常公网发布，不将整个站点切回旧版本。

以后恢复自主代码执行须有新的用户决定与 ADR；本次剩余任务不得自动恢复、派工、提交、合并或发布。
