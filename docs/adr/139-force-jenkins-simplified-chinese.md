# ADR-139：Jenkins 控制器统一使用简体中文界面

## 状态

已采纳。

## 背景

WAO 成员从站内链接进入 Jenkins 查看发布证据时，控制器只有英文资源。仅依赖浏览器语言也会让不同设备显示
不一致，手机端更难快速找到构建阶段、控制台日志和失败入口。自行覆盖 Jenkins 页面文案不可维护，也会在升级后失效。

## 决策

- 使用 Jenkins 官方插件中心维护的 `localization-zh-cn` 提供简体中文资源，使用 `locale` 插件控制界面语言；
  两者都在版本锁定的 `deploy/jenkins/plugins.txt` 中安装。
- JCasC 将 `systemLocale` 固定为 `zh_CN`，忽略浏览器语言且不开放用户覆盖，保证从 WAO 打开的所有控制器页面
  使用同一语言。插件没有翻译的专有名词、任务名和历史日志保持原文，不伪造翻译。
- 插件和语言配置继续通过现有控制器配置更新阶段安装并 `safeRestart`，不改变 WAO 单点登录、角色授权、Webhook
  或生产流水线行为。

## 后果

成员无需调整浏览器即可看到中文 Jenkins 导航和常用操作；固定语言会降低多语言灵活性，但当前控制器只服务
中文 WAO 团队。插件升级仍需显式更新锁定版本并通过控制器重启与真实登录页面验收。
