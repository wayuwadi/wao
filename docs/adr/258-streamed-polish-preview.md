# ADR-258：润色流式预览和付费网关一致准入

日期：2026-09-22。补充 ADR-237/238，取代 ADR-257 中醒市网关不受用途与预算约束的例外。

## 决定

用户希望润色边生成边看到文字并缩短等待。实测旧请求排队约 0.19 秒、调用及处理约 6.90 秒，浏览器另有 2 秒查询间隔。

- POLISH 的 API 队列调用 Chat Completions SSE，stream=true、stream_options.include_usage=true、thinking disabled。使用精简润色系统规则，正文只消费 delta.content，不展示推理内容。
- 第一个正文增量立即写入 response_text，后续写入最多每 250ms 一次；写入须匹配 provider_running 与 claim_token。终态、旧 worker 均不能被迟到增量覆盖。无需修改数据库结构。
- 持久任务 GET/POST 响应增加 preview，仅 RUNNING 返回；polished 和历史记录仍仅成功后返回。浏览器首分钟每 500ms 读取，长等待退回 2 秒；这是上游 SSE 与前端短请求增量预览，不依赖跨节点长连接或代理缓冲设置。
- 编辑器和润色工作台展示真实增量。预览与最终结果分开，完成前不允许替换或复制；原文和草稿不变。重连沿用请求标识，只读原任务，不重新生成。
- 流必须含正常 stop 和 DONE 才成功。空流、长度截断、协议错误、连接中断明确失败，清除候选，不自动重发流式调用，避免半篇被接受或重复计费。非流式旧接口保留。
- DeepSeek 与醒市网关共用既有用途白名单与每天 1000 万 Token 预算。默认仅润色，未知用途拒绝；流式和非流式发送前均预占，有有效最终 usage 时结算一次，缺失时保留预占。原设置接口、计数和管理员草稿不变。

## 体验与边界

增量预览不等于模型总生成时间缩短；模型和网关首字时延需真实测量，不承诺固定秒数。Codex 回退仍显示既有进度，尚无正文流。
不调整用户已选模型，不把私钥发往其他供应商，不改变部署和发布等待策略。

## 验证

测试覆盖正文增量与推理隔离、最终用量结算、断流/截断不成功不重发、网关禁止用途零 HTTP、预览不进历史、旧 claim/终态写入保护、前端半篇不可复制、原文保留及幂等查询。

本地验收：完整后端回归及新增测试汇总 1368 项，0 失败，9 项 Docker 相关测试因本机环境跳过；
前端 76 项相关测试、TypeScript/Vite 构建和定向 ESLint 通过。连接既有真实数据库，以真实成员会话操作本地新版润色工作台，
验证网关增量预览、最终复制入口、原文不变与刷新历史。实际留下 4 条明确标注验收的润色历史，没有替换业务文档。
网关 3 次带耗时记录的真实调用：首段 3038/1536/1500ms，全文 6424/2101/3376ms；文本长度、重复输入与网关缓存可能影响结果，
不能据此承诺固定提速倍数。耗时日志只记供应商、毫秒和增量次数，不记录正文、模型凭据。
