# ADR-294：小记 AI 阶段并行调度与成员并发偏好

## 状态

已采纳（2026-09-28）。补充 ADR-237、ADR-292 与 `notes-auto-title-image` 规格；本 ADR 取代 ADR-292 中小记自动整理阶段顺序及图片单成员互斥部分。

## 背景

新小记保存后的标题、配图、润色和已有标签推荐属于相互独立的 AI 阶段。顺序等待会增加用户等待时间；多篇小记的等待也可同时利用现有 AI 队列。用户要求由已有个人偏好管理串行 / 并行和并发数量，不改变模型选择与 Runner 并发能力。

## 决定

- 小记 AI 自动整理默认并行，服务端按成员统计已排队的标题、配图和正文润色任务；并发上限默认为 3。上限可在现有「设置 → 个人 → 偏好」中选 1–5；串行模式固定容量为 1。旧版偏好缺少字段时按并行、3 项读取。服务端任务在浏览器关闭后继续执行，读取最新保存的成员偏好。
- 并行模式可同时运行标题、配图和正文润色；多篇小记共享成员并发上限。调度只限制服务端自动工作流入队数量，已提交任务的实际执行能力仍由现有文本队列、在线 Runner 配置及 AI 供应商限制，不调整模型或 Runner 配置。已有的标签推荐属于独立浏览器步骤，不改变其既有触发与权限。
- 串行模式依次运行标题、配图、正文润色。各阶段独立失败并保留重试状态；一个阶段失败不阻断其他阶段。
- 标题、标签、图片写入使用同一文档级互斥队列和最新版本号条件，阻止自动阶段互相覆盖或覆盖用户新编辑。润色生成可并发执行；保存对照版本前重新读取文档并确认正文与生成时一致。
- 自动小记配图以稳定请求标识区分任务，可并发入队；没有稳定标识的手动配图仍遵守每成员同时一张的既有限制。此偏好仅属于浏览器中已保存小记的自动整理，不新增 CLI 命令或工作区 MCP 权限。

## 验收

前端针对默认与旧偏好读取、并行阶段启动、多个小记共享上限及串行顺序提供测试；服务端验证持久工作流按成员上限启动、串行模式只启动一个阶段、稳定标识的自动配图可并存且手动配图仍受互斥限制。真实 AI 用户链路需由使用者提供可保留的小记内容后执行。
