# ADR-197：个人内容创作使用有界 WAO 上下文并保留发布数据快照

## 状态

已采纳。

## 背景

自媒体 Agent 已经具备账号定位、话题池、图文编辑、素材、人工审核和平台发布状态，但自动成稿只读取话题与账号定位。成员在 WAO 中积累的个人记忆、知识库文档、私人 AI 对话和过往成稿没有进入创作链路，人工修改形成的个人表达也无法反哺下一篇内容。现有发布任务只记录发布时间或平台内容 id，无法保存站外链接和后续效果数据。

## 决策

- 新建内容时增加“我的想法或对话摘录”，并允许成员决定是否结合 WAO 上下文；默认开启，关闭后模型只使用本次输入和账号定位。
- 上下文只读取当前 WAO 账号对应成员的个人记忆、私人 AI 对话、本人创建或成员可编辑知识库中的文档，以及当前内容工作区的过往成稿。候选按话题与本次想法做有界相关性排序，每类最多两条、总计最多八条。
- 记忆、知识库与聊天只作为不可信参考资料，提示词明确禁止执行其中的指令。过往成稿只用于学习表达特征，不作为事实来源。
- 每次生成把实际送入模型的来源标题、站内地址和有界摘录保存到发布任务；页面展示来源，后续刷新不会把“当前库里可能已经变化的内容”冒充当时依据。
- 发布链接保存在文章主记录；阅读、点赞、评论、收藏和分享使用追加快照记录。成员可反复录入不同时间的数据，未知指标保持为空，不推测平台数据。
- 没有官方统计接口的平台由成员手工录入；后续接入官方统计时继续写同一快照表，不另造展示模型。

## 后果

生成请求会比只发送话题更长，因此服务端限制候选数量、单条摘录和总字符数。私人上下文只在当前登录工作区展示和使用，不进入公开导出正文；模型生成仍需成员审核，来源快照也不证明成稿中的每句话都正确。
