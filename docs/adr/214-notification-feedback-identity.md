# ADR-214：通知卡片显示实际反馈人

- 状态：已采纳
- 日期：2026-09-08
- 补充并替代 ADR-035 的机器人表情回执展示决策。

## 问题与决策

使用 tenant_access_token 添加原生表情，作者始终是应用机器人，无法表达谁点击了卡片。保留真实回调的 operator.open_id 和每人最新选择，停止在通知反馈链路添加机器人 CheckMark/CrossMark。新通知发送共享卡片，在原卡片追加「✅ 飞书成员：做到了 / ❌ 飞书成员：没做到」，成员由飞书原生 at 标签根据回调身份解析，不能使用按钮参数冒充身份。

持久化发送时标题、正文和共享消息 ID，更新不受之后编辑自动化任务影响。每张通知加数据库行锁，串行保存反馈和刷新完整摘要，避免双节点并发覆盖其他成员。视觉更新失败仍提交实际反馈，并明确提示再次点击重试；不返回虚假的显示成功。

旧通知未声明共享卡片，首次点击创建一条挂在原消息下的共享反馈卡片，再次点击更新同一条回复；使用通知 ID 派生发送去重键。旧卡标题从仍存在的任务取，任务删除时使用「通知反馈」，不重构旧正文。旧机器人表情不作为个人反馈使用，也不删除其他人的真实表情。

## 验收

两人不同选择同时展示；同人改选只更新自己；非法、未知通知无写入；消息身份不匹配不接受；API 失败反馈仍保存；共享卡片 PATCH 和旧卡回复协议覆盖测试。部署后用真实用户点击验证姓名渲染，不伪造用户完成记录。
