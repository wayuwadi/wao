# ADR-326：飞书机器人统一管理与认证消息收集

已采纳，2026-10-07。修订 ADR-089、ADR-102、ADR-104、ADR-266 的入口、入站认证和编辑一致性边界，不恢复聊天归档。

## 决策

用户在能力中心统一管理 Webhook 和专用待办／小记机器人。保留现有配置 ID、密文和引用，设置与自动化旧入口跳转，不创建第二套配置。机器人和全局接收应用管理需要管理员浏览器会话，普通成员通过自己的账号绑定使用群入口。

每个机器人可绑定明确的收集角色、结构化提及标识／兼容精确名称、接收应用和目标群；已显式配置的停用入口不由旧名称兜底复活。入站写入要求事件认证与应用／群范围匹配，作者用已绑定飞书身份确定并检查冲突。

通过加密持久 inbox 先接收后处理，使飞书快速应答与可重试保存共存。消息与轮询复用幂等；失败保留可诊断状态。源消息编辑不能覆盖已在 WAO 修改的内容，使用目标版本检查发现冲突。

引用信息取真实数据库选择，明确区分当前使用与历史保留配置。停用、路由变更和删除需要展示并确认影响，读取失败不得继续危险变更；删除系统默认保留原接管契约，其他指定引用不自动转移。

Webhook 测试、业务发送和消息收集记录分别提供证据；认证配置状态不代表飞书事件订阅或真实收集已经成功。机器人编辑采用 CAS，非密钥草稿按成员隔离；秘密只在页面内存和服务端加密存储，所有日志和诊断不包含消息正文与秘密。

## 后果

无需迁移旧 Webhook 或改写业务引用；全局管理权限收紧，并需对真实管理员入口进行验收。飞书后台授权、群订阅及成员绑定仍是外部接入条件，未完成不得声明双机器人已端到端可用。CLI/MCP 不新增全局凭据管理或模拟消息能力。
