# ADR-333：Windows2 接管后只监控在役公网入口

- 状态：采用
- 日期：2026-10-09
- 续接：ADR-255、ADR-291

用户已将原 Linux2 机器重装为 Windows，并完成 Windows1 业务数据到 Windows2 的迁移。当前 WAO 使用 Windows 原生服务，由云端 Nginx 经 Windows2 主动建立的反向 SSH 隧道提供 `https://wao.wayuwa.cn`。本决策取代 ADR-291 中 Linux2 为在役应用节点的监控假设，不改写其历史数据库恢复记录。

云端独立 `wao-health-watch.timer` 仍每分钟探测 `linux2.wayuwa.cn:9443`，旧节点持续失败，即使公网实际就绪也重复发出飞书告警。

监控目标改为唯一在役公网 `/api/edge/ready`。该探针验证真实应用与可写权威数据库，覆盖当前 Nginx、Windows2 隧道与服务链路；不新增不存在的 Windows 公网 9443 入口。停止旧 Linux2 探测及其专用 DNS 逻辑，旧节点告警状态在下一轮采样自然移除。

保留连续两次失败告警、四小时去重、连续十次成功恢复、通知失败重试和正常 TLS 校验；不关闭整个监控，不影响发布通知、不提升数据库、不重启业务服务。只修改云端监控脚本并原子安装，保留备份与既有私有通知配置。部署与验证见 [运行手册](../runbooks/windows2-public-readiness-monitor.md)。

探针只证明采样时公网读写就绪，不代替浏览器业务体验、备份恢复或 Windows 主机资源监控。未来新增在役节点须另行确认拓扑后登记，不能恢复历史主机名作为默认目标。
