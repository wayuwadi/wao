# ADR-224：以供应商周期推进记录 Codex 官方重置时间

## 状态

已采纳。补充 ADR-174，不改变额度采样来源、频率和既有额度上涨记录。

## 背景

数据仪表盘已经把相邻真实采样的剩余额度上涨记为“额度刷新”，但该信号既可能来自官方自动重置，也可能来自成员使用重置卡；
页面展示的还是系统发现上涨的采样时间，无法据此判断官方自动重置通常发生在上午还是下午。Codex 七天额度采样已经保存供应商返回的
`resetsAt`，因此不需要估算或增加演示数据。

## 决策

- 同一 Codex 七天窗口连续采样的 `resetsAt` 向后推进，且上一周期的时间已经到达时，确认发生一次官方自动重置。
- 官方重置时间取上一周期由供应商返回的 `resetsAt`；首次观察到周期推进的采样时间单独保留为确认时间，不冒充重置时间。
- 剩余额度是否上涨不作为官方重置判据，避免重置后立即发生消耗时漏记；普通额度上涨记录继续保留，也不把手动刷新卡混入官方趋势。
- 数据仪表盘用官方重置日期作为横轴、上海时区的具体时刻作为纵轴，并展示上午 / 下午次数和精确时间记录。没有真实跨周期样本时显示等待状态。

## 后果

- 用户可以按真实官方周期判断重置时间范围，再决定何时使用刷新卡。
- 查询会额外读取起始日期前八天采样，以识别窗口边界处的七天周期推进；返回的采样数和每日趋势仍只统计请求范围。
- 如果采样在多个周期内完全中断，系统只记录能够由前后真实时间确认的周期，不推测缺失周期。
