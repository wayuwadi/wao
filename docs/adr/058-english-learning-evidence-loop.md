# ADR-058：英语训练采用固定原创课程与成员事实记录闭环

- 状态：已接受
- 日期：2026-08-12

## 背景

用户希望用 WAO 系统学习英语，长期提升听说读写并克服不敢开口，但过去多次从头看资料都没有形成持续闭环。
仓库已经有成员私有单词本、行动计划与本地 Codex 助手，不过没有可靠的官方词典、翻译、发音评分或语言能力测评接口。
如果把浏览器朗读、用户自评或生成文本包装成专业评分，会制造并不存在的能力。

## 决策

- 新增成员私有“英语训练”模块，以 14 课原创程序员职场英语基础课程组成一轮；完成后不清空历史，带着上一轮复盘重复练习并提高难度。
- 每天围绕同一场景完成听、说、读、写：浏览器语音合成提供真实朗读，麦克风录音只在本机回放，不上传；不提供虚假的发音分数。
- 学习目标与每日训练记录由服务端按当前成员隔离保存。同一成员同一天只有一条记录；只有听说读写全部完成且填写信心自评，才写入完成时间并累计连续天数。
- 写作、复盘和下一次重点在编辑时先写浏览器草稿，服务端确认后清除；失败时保留草稿并可重试。
- 课程中的陌生表达调用现有 `/api/vocabulary` 进入真实单词本；长期提醒继续使用已有行动计划与飞书身份私聊链路，不另造模拟通知。
- 固定课程明确标注内容边界，不宣称自动翻译、动态个性化、AI 评分或语言等级认证。以后接入可靠服务时另写 ADR。

## 结果

- 用户每天有一条约 25 分钟、可实际完成的职场英语路径，并能跨设备回看投入、信心和迭代重点。
- 连续天数来自完整训练事实，不因打开页面或简单签到增长；录音隐私边界清楚。
- 第一版课程强调建立表达习惯而非无限资料量。后续可根据真实复盘扩展场景，但不能覆盖既有日记录或伪造学习效果。
