# ADR-313：浏览器业务 AI 共用本机 Codex

- 状态：已接受
- 日期：2026-10-03
- 关联：ADR-304、ADR-306、ADR-308

## 背景

Runner 已退役，小记与算卦通过本机已有 ChatGPT 登录执行。文档选区润色、润色工作台和公共只读助手仍拒绝 `local-codex`，提示 Runner 下线；聊天复盘、小记挖掘、人生复盘、首页建议和系统改进分析共享这条路由。

## 决策

1. 将公共只读业务接入 ADR-306 的显式启用执行器，复用稳定实例能力 ID、持久队列、目录独占、CAS 领取、超时和重启收口。不新增 Runner、领取接口、账号上传或执行平台。
2. 服务主机启用本机执行时，默认路由为 `local-codex`，默认模型沿用动态目录校验后的 `gpt-6-astra`。不可用或执行失败反馈真实原因，不静默改用付费 API。显式选择且用途获准的服务端 API 继续有效；未启用本机时保留已有获准 API 配置行为。
3. 能力列表增加 `LOCAL_CODEX`，不展示退役的 `RUNNER`。旧复盘策略中仍启用的集中 Codex 能力 ID 通过脱敏元数据转换为本机能力，不读取旧 Codex 凭据。已删除或停用的配置必须重新选择。
4. 带图问答只传递当前成员明确选择且已鉴权的图片字节，最多四张、每张不超过既有 10MB 上限，暂存于本次工作目录；图片输入通过 CLI `--image`，不开放任意路径、文件工具或联网。任务结束按既有机制清理临时目录。
5. 选区润色保持对照、保留原文、确认替换、文档版本保护及失败重试；问答结果与成员私有会话在同一事务完成。后台分析不追加聊天历史。
6. 项目 AI Run、自动代码派工、性能自动派工和飞书反应派工继续退役。保留历史记录和迁移，不将停用的自主执行功能改为本机自动执行。

## 影响

不修改数据库结构或已有 migration，不新增 HTTP 路由、MCP 工具和 CLI 权限。服务主机仍须显式启用 `wao.ai.local-notes.enabled` 并拥有可用的 Codex 登录；本机指的是该主机已有执行环境，与算卦一致。共享业务请求消费该登录额度并遵守已有队列容量限制。

具体接口、依赖清单及验收见 [业务 AI 本机执行规格](../specs/business-ai-local-codex.md)。
