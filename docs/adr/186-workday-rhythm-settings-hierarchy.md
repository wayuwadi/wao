# ADR-186：今日节奏配置采用分类导航与渐进式项目编辑

## 状态

已接受（2026-08-31）。本决策细化 ADR-149 中“从顶部统一调整节奏”的配置页表达，不改变其单屏执行布局。

## 背景

“调整每日节奏”把每日面板、每个必做项目的全部字段、行动通知、精力补给和时间线连续铺在一个弹窗内。真实项目一多，成员先看到的是
大量同形表单，而不是项目名称、状态和边界，难以快速找到要改的内容。

系统联动项不能物理删除，因为计划、打卡、卦象的自动完成和历史实例仍依赖其稳定类型。原界面却给系统项和自定义项使用相同的删除图标；
点击系统项时只把前端草稿中的 `active` 改为 `false`，条目仍留在原位，也没有服务端请求或结果反馈，表现为删除没有反应。

## 决策

1. 配置弹窗增加每日必做、行动通知、精力补给和时间线四个稳定分类，一次只显示当前分类；外部宠物设置入口直接定位精力补给。
2. 每日必做采用“摘要清单 + 单项展开”结构。摘要展示项目身份、适用日、时段、通知和启停状态，完整字段只在主动编辑时出现。
3. 系统联动项的移除语义实现为立即持久化停用：使用既有更新接口写入 `active=false`，成功后折叠并展示停用状态和恢复入口，失败时保留原状态并展示错误。
4. 自定义项目继续通过既有删除接口软删除；所有历史实例保留。系统项恢复使用同一更新接口写入 `active=true`。
5. 每日面板配置沿用独立保存按钮；其余三个分类共享既有节奏草稿与“保存节奏”动作，避免把不同后端存储伪装成一次原子保存。

## 后果

- 默认可见控件显著减少，成员先按配置领域定位，再按项目定位具体字段。
- 系统项“移除”获得真实跨设备结果，同时保留可逆性和历史完整性。
- 不新增接口或数据迁移；停用项目仍由模板接口返回，因此恢复入口始终可用。
- 四个分类的非每日面板配置仍共享同一份本机草稿，切换分类不会丢失未保存输入。
