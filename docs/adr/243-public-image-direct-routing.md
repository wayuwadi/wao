# ADR-243：保持历史地址的公开图片直连

## 状态

已采纳，扩展 ADR-240 的公共资源范围，独立开关默认关闭。

## 原因

API 和静态资源直连后，富文本中既有图片地址仍通过主站云机，受其带宽限制。
现有 ImageController.raw 和 AuthInterceptor 已公开 `/api/images/{id}/raw`，并按不可变内容缓存。
图片二进制保存在权威 MySQL；此变更不扩大原图片权限，也不迁移或替换历史正文地址。

## 决策

- 同一主站 Service Worker 仅处理 destination=image、GET、无查询参数、无 Range 的既有 raw 路径。
  相对地址和历史主站绝对地址都会归一为同一主站请求；不处理其他域名、页面导航和普通 API fetch。
- `publicImagesEnabled=true` 且 enabled=true、forceCloud=false 才尝试两台受信任节点。
  每节点最多一次，失败冷却60秒，最后只回退原主站请求一次，不刷新页面或重放写操作。
- 节点请求不携带 Cookie/Authorization，不跟随重定向；要求 CORS 可读响应、允许的图片 MIME、
  非空正文、最多10MiB（与后端现有上传上限一致）。首响应1.5秒、完整正文12秒的预算保持独立。
  图片不套用前端发布清单哈希，内容信任来自受信任 TLS 节点和既有权威数据源。
- 公共入口只开放既有 raw 图片 GET/HEAD，保留精确主站 Origin；不开放图片列表、上传、删除，
  不开放私有文件、验证码下载票据、视频流或 Agent 接口。响应不向客户端转发 Set-Cookie。
- 对浏览器保持原请求地址、图片类型和不可变缓存行为，不将节点 URL 写入业务数据库。
  Service Worker 不保存凭据、不建立新的持久图片缓存。

## 验收与限制

2026-09-20，隔离子路径上的真实浏览器加载既有1536×1024图片，1576864字节，Linux2直连232ms。
仅对验收IP注入图片503后，另一张1920×911图片从原主站完成加载，未保存输入保留。
两个结果使用不同图片，不用于声称倍率提升。

另一次并发读取同一1576864字节图片：主站3609ms、Linux1 2312ms、Linux2 234ms，
三处 SHA256 均为 `7a72243da96dab74256d6de0d1c38a4b28261ef41ba338922e75b075e52b4bc2`。
这是当前电脑网络下单次测量，不是稳定时延承诺。

十项 Worker 测试通过，包含私有路径不拦截、开关关闭、错误 MIME、空正文、超限和网络失败回退；
两节点实际 Nginx 语法通过。故障规则已撤销。

私有附件、图片上传、历史其他域名、Range和流式调用仍走原入口，属于后续独立契约验收范围。
旧浏览器禁用 Service Worker 时正常走云端。关闭 publicImagesEnabled 的生效上限为配置缓存30秒，
已开始的请求和浏览器已有缓存不被强制中止。
