# ADR-218：每日卦象可在北京时间九点自动生成并解读

状态：已采纳（2026-09-09）。扩展 ADR-047、ADR-192 和 ADR-201 中仅由手动操作开始起卦的行为。

## 决策

- 在成员 `workday-rhythm-config-v1.energyNotification` 中新增布尔值 `autoTianrenAtNine`，默认 false；成员主动开启后，需同时启用行动通知、卦象通知并配置该成员的独立目标群。
- Spring Cron 使用 `0 0 9 * * *` 和 `Asia/Shanghai`，每天（含周末）09:00 触发；另有每分钟的有界分页恢复扫描。九点前不执行，九点后启动或 AI 恢复时只补当天，不补过去日期。
- 起卦先独立提交，再把专用 AI 解读放入原有持久队列。页面关闭不影响起卦、解读或群投递；“09:00”是起卦触发时间，卡片在解读完成后发送，不承诺 09:00 同秒收到。
- 手动提前起卦沿用当天记录；成员行锁串行化多节点和手动操作的同日生成、会话准备与解读入队。已有成功回复或活动运行不重复入队；失败至少间隔五分钟，自动最多三次，仍可手动重新解读。
- 自动首次生成同步“每日一卦”完成项；后续扫描不覆盖用户手动撤销的完成状态。AI 离线时保留已生成的真实卦象，未入队部分事务回滚，不遗留空会话。
- 卡片继续复用 ADR-201 的群目标快照、策略开关、接收不确定确认和发送去重，不改成服务器全局默认群，不因新增定时功能再发已发送卡片。

## 验收

- 九点前不生成，九点后只对明确开启且目标有效的成员生成；周末计划仍为九点。
- 双节点同时扫描、手动操作并发和多次恢复只有一份当日卦象及一次活动解读；已保存解读不重新生成。
- AI 离线保留卦象，恢复后正常入队；失败冷却及次数上限有效。
- 开关保存失败保留草稿，重试和刷新后恢复；上线后核对成员真实配置、卦象和群投递回执。
