# ADR-231：飞书 API 降频并退役群聊润色机器人

## 状态

已采纳（2026-09-15）。修订 ADR-103、ADR-112、ADR-183、ADR-191 与 ADR-225 中关于快速收集轮询、历史回扫和群聊润色机器人的现行行为；不改变每日群聊知识库同步、手动同步与聊天复盘。

## 背景

飞书租户月调用量接近额度上限。实际代码中，快速收集每 15 秒读取一次消息，另有每 5 分钟回扫近 24 小时消息的任务；未绑定成员的 Open ID / Union ID 转换没有复用已有成员缓存，同一条消息也可能重复查询表情。群聊润色机器人复用了这两条轮询，并另有每秒唤醒的持久任务推进器。

用户确认：实时轮询改为 60 秒，删除历史回扫，优化成员身份转换和表情检查，保留知识库同步、手动同步和聊天复盘，并删除群聊润色机器人。

## 决策

- 快速收集增量消息的默认轮询周期从 15 秒改为 60 秒，仍读取最近两分钟并使用数据库水位、租约和消息幂等；事件回调继续作为低延迟入口。
- 删除每 5 分钟读取近 24 小时消息的快速收集回扫任务。消息编辑、撤回和稍后添加的派工表情不再依赖历史回扫；已配置的飞书事件回调继续实时处理这些事件。
- Open ID 与 Union ID 的群成员快照按令牌、群和 ID 类型分别缓存 5 分钟。手动“读取群成员”仍调用实时接口，缓存读取失败不留脏数据。
- 主动轮询对同一消息的表情查询结果缓存 5 分钟；查询失败立即释放缓存以允许下一轮重试。事件回调不使用该缓存。
- 删除群聊润色机器人的配置接口、配置界面、消息收集与后台推进器。V153 只把旧启用开关设为 `false`；`feishu_text_polish_run`、Mapper、旧配置键和历史数据保留，便于审计与回滚。
- 网页“文字润色”工作台及其 `/api/text-polish/**` 接口、个人提示词和历史记录不变。
- 每日 23:59 的飞书群聊知识库同步、手动内容同步、聊天复盘和共享聊天能力不变。

## 后果

没有事件订阅时，快速收集新消息最长通常等待 60 秒；发送后编辑、撤回或稍后添加派工表情不再由 24 小时回扫兜底。相对原方案，空闲期消息列表调用约降为四分之一，并完全消除 24 小时历史分页回扫与群聊润色后台调用。实际节省量继续以 WAO 飞书 API 用量面板和飞书租户账单为准。

## 验收

- 调度器默认周期为 60 秒且不存在历史回扫入口，关闭快速收集时不调用飞书。
- 同一成员身份转换在 5 分钟内只读取一轮 Open ID 与 Union ID 成员列表；同一消息表情在 5 分钟内只主动查询一次，失败可重试。
- 群聊同步配置不再出现群聊润色机器人，旧配置接口不可用；网页文字润色仍通过现有测试。
- Flyway 版本唯一，V153 仅关闭旧开关，不删除历史表或记录。
