# ADR-304：下线 WAO Runner

- 状态：已接受
- 日期：2026-10-02

用户决定不再保留 Runner。关闭节点配对、管理、唤醒、脚本分发、心跳、领取、集中凭据下发和结果回传；旧 /api/ai/runner 与 /api/ai/runners 返回 410。停用生命周期定时器，新的 Python 启动直接退出，Windows 安装器不再创建任务，部署精确关闭已知系统和用户 WAO Runner 服务。保留本地令牌、源码、会话、worktree、节点记录及集中账号，不卸载 Codex 或其他通用 AI CLI。本机检查未发现 WAO Runner 计划任务。

助手能力列表仅列服务端 API，旧 Codex 选择明确不可用，不再向本地队列写入新工作。API 页面问答不继续排入 Runner 联网阶段，不宣称已完成联网核验。保留获准的 DeepSeek / 模型网关润色；小记标题和标签仅在 API 已获准用于后台时执行，不自动放宽供应商用途。没有可用 API 时立即返回明确错误，不等待节点恢复。Runner 配图启动和设置入口关闭，已有图片、正文和运行记录保留。

后台 AI Run 已由 ADR-303 关闭。工作区 MCP 与 CLI 没有 Runner 专属命令，不增加权限。验收覆盖旧协议 410、凭据不可下发、旧配置不会入队、API 润色继续工作、浏览器入口与类型构建。Linux 停用由正常部署执行，本次未远程运行退役脚本。
