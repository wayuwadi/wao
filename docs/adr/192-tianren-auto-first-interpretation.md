# ADR-192：“天人一卦”起卦后自动生成首次解读

## 状态

已接受（2026-09-02）。修订 [ADR-047](047-tianren-daily-ai-reflection.md) 中起卦与首次 AI 解读需要分别主动触发的交互，
不改变每日唯一卦象、成员私有会话、AI 安全边界和历史回看规则。

## 上下文

现有页面在服务端保存并展示今日卦象后，还要求成员再点击一次“请 AI 解读今日一卦”。首次解读本来就使用这份服务端
权威卦象和默认关注点，额外点击没有增加必要信息，反而把一次连续的起卦体验拆成两个动作。成员在看到首次结果后，仍需
要能根据当下关注的内容主动生成新解读。

本地 Codex 可能正在连接、离线或执行失败。自动触发不能用静态内容冒充真实结果，也不能因模型失败回滚已经成功保存的
卦象。

## 决策

- 成员仍须主动点击“起出今日一卦”；页面打开和今日节奏等其它入口不自动创建卦象或调用 AI。
- 今日卦象保存成功后，页面等待当前本地 Codex 状态检查完成；在线时立即复用现有专用 SSE 接口生成首次成员私有解读，
  无需第二次点击。
- 本地 Codex 离线时只展示真实卦象和离线状态，不生成替代文案；自动解读失败时保留卦象、关注点草稿和原有重试入口。
- 首次解读完成后，成员可填写或修改关注点，通过“根据关注点重新解读”继续复用当天的成员私有会话；公开分享仍只投影
  当前最新一条 AI 回复。

## 后果

- 在线成员用一次点击即可得到今日卦象和首次联合解读，之后仍能按内容需要重新解读。
- 起卦保存与 AI 生成保持两个可独立失败的真实步骤：前者成功、后者失败时不会丢失当日唯一卦象。
- 不新增接口、模型调用来源或演示数据，既有长连接路由、医疗边界和历史不可补做规则保持不变。
