# ADR-254：带认证媒体直连与有界回退

状态：采用，独立mediaEnabled开关默认关闭，按实际双节点验收启用。主域和原文件链接保持不变。

## 问题与决策

静态和任务API直连后，文件上传与受保护附件仍经3Mbps云入口。保留既有MySQL文件存储、权限检查、主站登录与匿名下载票据契约，只把明确允许的媒体操作路由到已经受信任的两个HTTPS节点。

- 图片/文件列表与文本预览通过既有HTTP客户端路由。首次图片/文件上传等待节点认证准备，正文只发送一次；连接中断显示结果待确认，不重放POST。节点不通或Cookie无法建立时，发送前选择原云路径。
- 根Service Worker只截获主域无query的GET /api/files/{id}/download或stream；每次重新由主站CSRF、一次性票据和节点会话确认取得权限，不跨账号缓存凭据。
- 私有下载必须保持attachment；stream只接受audio/video。转发Range并保留206/416及范围响应头，输出private/no-store、nosniff。不能把任意HTML托管搬到可信认证origin。
- 流式转发最多52MiB，响应体预算120秒，不在Worker完整聚合50MiB文件。已给出响应头后发生断流，只结束当前流，绝不自动重新下载或重复写入。
- 节点连接先用1.5秒readiness探测；文件响应头预算30秒允许现有数据库读取。响应头前的网络/502/503/504可尝试另一可信节点，再回云一次；认证失败不绕过到别的身份。
- 节点Nginx流式接收上传，避免50MiB请求写满16MiB边缘tmpfs；每客户端最多4个、每节点最多8个并行上传，超过返回429。后端已有大小、身份、Origin和CSRF限制继续生效。

## 兼容与回退

公开下载ticket query、Agent/SSE、其他写API及文件内容替换继续原路径；现有匿名图片合同保持不变。mediaEnabled不等于所有流量都已直连。首次登录与每次私有下载的小型授权请求仍经过云入口，云故障时不能承诺新私有下载继续工作。

配置清单30秒刷新；mediaEnabled=false或forceCloud=true撤回新媒体请求。已在传输的流不强行中断，保留主域完整旧路径。单节点enabled=false用于受控摘流；前端API仍校验允许发布版本。只有明确可信节点可成为目标，不接收用户自填转发地址。

## 验收证据与性能边界

实际Edge受控页复用生产HTTP客户端与Worker，只替换配置URL并限定验收scope。20MiB随机文件经Linux2上传13.330秒，下载经Linux1哈希一致40.722秒；同一样本经云代理81.537秒，SHA256均为fe89bcf29e6c6829c6821983dad5b88085b39b4d84e330816f51a39698e2ced3。数字是当前网络单次样本，不是家庭1000M承诺。

最初Linux2下载响应头过慢，WireGuard内数据库读取48.114秒；ADR-253私网TCP通道实测3.385秒，仍须在应用滚动更新后复测浏览器。不能以数据库通道测试代替公网用户验收。启用媒体开关前保留默认关闭状态，重复执行实际上传、下载哈希、单节点失败及云回退。

Worker测试覆盖新身份引导、认证拒绝、Range、安全attachment、流中断不重放；HTTP测试覆盖POST只发送一次、CSRF与上传前认证。Safari、第二真实账号、办公网络需实际客户端配合，不伪造已覆盖。
