# ADR-150：首页 AI Run 卡片采用稳定信息骨架

- 状态：Accepted
- 日期：2026-08-28

## 背景

首页运行控制台同时承载活动运行、最近终态记录和无人值守策略。现有卡片按数据有无条件增减图片区，导致同一网格内
标题和进度位置漂移；最近运行又把业务类型与运行结果复用为同一个标签，失败记录会失去类型位置。完整历史支持分页，
但首页八条摘要不能原位翻页，用户需要频繁打开弹窗。自动推进表单长期独占一个区块，而这项低频设置只在修改时需要
完整展开。

## 决策

1. 活动运行卡片固定保留等高媒体区和两行标题区。有真实任务图片时继续展示受控预览；没有图片时只显示装饰性 AI
   工具图形，不生成或伪造业务图片。长标题统一截断并保留悬停全文。
2. 最近运行卡片固定把“功能开发 / 聊天复盘”放在类型位置，把“运行成功 / 运行失败”放在结果位置；标题统一为
   两行，项目、能力、失败摘要和操作各归其位。
3. 最近运行仍按每页八条读取真实统一活动接口，但首页直接提供上一页、下一页和当前页数；“查看全部”继续用于
   打开二十条一页的完整历史。
4. ADR-114 中自动推进策略、草稿防覆盖、保存和失败重试语义保持不变；展示入口改到“正在运行”标题旁，以当前
   开关状态说明功能，完整表单按需在设置弹窗中展开。此条取代 ADR-114 和任务 Runner 规格中关于该表单独占
   “最近完成”上方区块的展示位置描述。
5. 390px 窄屏下，运行入口和最近分页允许独占一行；设置弹窗字段改为单列，所有操作继续可见且不产生横向滚动。

## 后果

- 图片、标题长度和运行结果变化不再改变卡片主要信息的起点，用户可以按固定位置扫描类型、状态和时间。
- 用户可在首页连续翻阅最近运行，同时保留完整历史入口；低频策略不再拉长首页。
- 默认图形只表达“该任务没有预览图片”的视觉占位，不成为任务内容或真实数据的一部分。
