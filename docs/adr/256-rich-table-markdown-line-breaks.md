# ADR-256：允许高级文档 Markdown 投影中的安全换行

已采纳，2026-09-22。补充 ADR-198 的原始 HTML 限制。

## 原因

小记与知识库共用的 Tiptap 表格序列化器把单元格内的换行和多段文本投影为 `<br>`。后端拒绝全部 HTML 标签，导致结构合法的表格能编辑却无法保存。

## 决策

- 高级正文 Markdown 校验仅豁免不带属性的 `<br>`、`<br/>`、`<br />`（大小写不敏感）；其他标签、带事件/样式等属性的换行标签继续拒绝。
- 只调整校验，不替换落库内容，Tiptap JSON 仍是事实源；单元格段落、列表、换行和布局完整保留。
- 小记、知识库文档、模板复用同一服务端规则，无需用户删除表格或重建草稿。
- 保留节点与属性白名单、危险链接拒绝及版本冲突保护。

## 验收

编辑器真实序列化多段表格并输出 `<br>`；服务端保存并读回相同正文/结构；带属性标签和脚本继续拒绝。
