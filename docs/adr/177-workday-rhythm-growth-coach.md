# ADR-177：成长教练迁入今日节奏并融合当天重点

## 状态

已接受（2026-08-31）。本决策修订 ADR-151 的首页入口与 Task-only 上下文，并保持其生成格式、AI 权限和继续对话边界。

## 背景

ADR-151 把成长教练作为首页独立大卡。真实使用中，这张卡打断首页的 AI 控制链路，入口与成员当天正在安排的目标相隔较远，
点击动机不足。与此同时，成长教练只读取 Task；成员已经在「今日节奏」明确写下的今日重点没有进入上下文，生成结果难以围绕
当天真正要完成的事情发散。

今日节奏已把当天重点按成员和上海自然日持久化，并采用顶部方向、下方三张执行卡的单屏布局。直接追加一张长内容卡会破坏
ADR-149 的单屏约束；读取浏览器草稿又会把未确认输入冒充成服务端事实。

## 决策

1. 首页删除成长教练的状态、请求和独立大卡；入口迁到今日节奏“今日重点”卡片标题旁，用带文字的“成长教练”按钮建立
   目标与启发的直接关系。
2. 完整内容在模态浮层中展示，复用已有读取、准备、生成、刷新、失败重试和继续聊状态，不增加执行面板高度；窄屏浮层按
   可视高度内部滚动。
3. 服务端从当前成员当天 `workday-rhythm-day-{date}` 偏好读取已保存的非空 `focus`，与既有进行中和最近完成 Task 一起作为
   不可信只读上下文交给 Codex。浏览器本地草稿不进入生成请求。
4. `growth-coach-v1` 缓存额外记录生成时的重点快照。读取或非主动生成时，仅在日期和重点快照同时一致时复用；旧格式缓存、
   新增、删除或修改重点都会回到 `missing`，由成员明确决定是否重新生成。
5. 当天没有已保存重点时仍可基于真实 Task 生成，但提示必须说明没有已保存重点，不补造当天目标。主动“换个角度”仍覆盖
   同一重点快照下的结果。

## 后果

- 成长教练从首页噪声变为今日目标旁的按需能力，今日节奏单屏布局保持不变。
- 后台预生成若早于成员保存重点，重点保存后该结果会失效并等待成员按需重生成；这比展示过期内容真实，但可能增加当天一次
  明确生成。
- 旧 `growth-coach-v1` JSON 无需迁移；由于缺少重点快照，它会安全失效并在下一次生成时自然升级。
