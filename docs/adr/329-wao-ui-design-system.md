# ADR-329：固化 WAO 界面设计系统与 Agent 约束

日期：2026-10-07 · 状态：已接受

## 背景与决定

用户确认设计参考 Demo，并要求把现有颜色、线框、卡片、弹窗及状态沉淀为工程记忆和约束，使不同 Agent、不同开发者保持相同风格。

采用「留白线框为主，浅底分区为辅，阴影集中在浮层」。新增 `docs/design/wao-ui-system.md` 作为通用规范总入口，保留品牌与设置规范各自的权威范围。在 `AGENTS.md` 和 `wao-web/AGENTS.md` 写入必读、复用、例外记录、检查和视觉验收要求。仓库中的版本化文档为跨人和跨机器工程记忆，不依赖某次聊天或个人记忆。

设置 → 关于 WAO 提供设计参考入口 `/design`。参考页复用真实 Vue 组件和主题 token，明确展示演示数据，免登录可读，不写入成员配置；主题预览局部生效。颜色展示取自实际 CSS 变量，组件样例随产品一起构建发布。

增加通用卡片、按钮和字段组件，以及增量 UI 样式检查，检查新增颜色字面值、圆角和阴影。历史声明按 Git 基线保留，不全仓重写；必要例外必须逐声明登记理由。检查不等于视觉验收，业务行为和草稿安全仍遵守原规格。

## 影响与边界

- 不更换技术栈、图标库或标识几何，不统一改写所有页面。
- 不增加业务 API、MCP / CLI 能力，不扩大令牌权限。
- 参考页没有真实账号保存、AI 调用或业务数据读取；交互演示清楚标注。
- 弹窗圆角 token 对齐已有设置外壳的 16px，补齐浮层主题别名。组件或规范调整必须在同一需求更新参考，并验证主题、窄屏、状态及键盘体验。
