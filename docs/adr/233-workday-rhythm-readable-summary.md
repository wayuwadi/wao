# ADR-233：今日节奏顶部摘要优先保证可读性

## 状态

已接受（2026-09-19）。根据产品体验审计 B16，局部修订 ADR-149 的顶部比例与单屏约束；执行卡、设置入口及业务行为保持原有决策。

## 上下文

当前实现将顶部空间按 70% / 15% / 15% 分配，辅助信息字号低至 8.5–9.5px。实际 1280px 浏览器中，侧栏展开后时间段名称逐字换行，启示与重试入口还可能被五行截断隐藏。继续缩字以满足一屏要求会妨碍阅读。

## 决策

- 当前时间块继续作为主信息；完整一天与今日启示各保留至少 210px 的外框宽度。
- 按页面实际内容宽度响应布局，不仅依赖浏览器宽度：900px 及以下主信息独占一行，辅助信息并排；560px 及以下依次纵向排列。
- 一天指导正文和启示正文使用 13px，辅助标题和说明至少 12px；长内容允许换行。
- 顶部内容自然撑高，需要时允许页面滚动，不为单屏目标压缩文字。启示移除 CSS 行截断，既有摘要长度限制不变，失败信息和重试按钮完整可见。
- 手机阅读顺序为当前状态、完整一天、今日启示，与 DOM 顺序一致。
- 不更改工作日判断、重点保存、每日必做、通知或起卦逻辑，不调整其他功能模块。

## 验收

- 本地连接既有数据库，验证桌面及 390px 手机宽度的阅读、设置入口打开与关闭、启示详情跳转及返回。
- 回归今日节奏与启示摘要现有组件测试，执行前端类型检查和构建。
- 三张执行卡的其余小字号与草稿账号隔离另行处理，本决策不声称整个页面的可读性与草稿问题已经完成。
