# ADR-145：可安装 H5 壳与成员级手机底栏

## 状态

已被 [ADR-156](156-mobile-dense-desktop-shell.md) 的手机高密度左栏决策取代；H5 安装与 30 天持久会话部分继续有效。

## 背景

手机端原先把桌面所有可见菜单横向排列在 64px 底栏。功能增长会持续增加滑动距离和误触成本，HTML5
`draggable` 在触屏上也不能提供可靠长按排序。系统已经有全量导航目录、真实菜单注册表、成员偏好接口和
小记创建链路，重新建立一套手机专属功能副本会形成三端重复维护和数据漂移。

当前服务端会话虽设为 7 天，但 `WAO_SESSION` 没有 `Max-Age`，属于浏览器会话 Cookie；移动浏览器或主屏幕
窗口结束会话时可能清除它，造成“每天重新登录”的体验。

## 决策

- 保留 Vue 单一业务实现，手机只替换应用壳和入口组织；不复制业务页面。
- 手机底栏使用成员偏好 `mobile-bottom-nav-v1`，最多四个可配置入口，固定保留「更多」。默认入口为
  「项目 + 小记」，直接对应当前最高频真实链路。
- 触控排序使用 Pointer Events：长按进入排序，移动时按命中的底栏入口重排，抬手后通过既有偏好接口保存；
  桌面侧栏的既有拖拽、折叠和全局菜单管理不变。
- 将既有全量导航页定位为手机「工作台」，完整目录继续从代码注册表、服务端应用注册表和成员快捷链接合成。
- 恢复 Web App Manifest 与 Apple 主屏幕元信息，使同一 H5 可从 iOS 和 Android 安装；不缓存登录页、
  API 或私有数据。
- 将 HttpOnly 会话 Cookie 和 Spring Session 不活跃时长统一为 30 天。保持 SameSite、生产 Secure、会话轮换
  和显式注销行为，不改为前端 Token，也不把身份写入本地存储。

## 与既有决策的关系

ADR-070 关于原生 iOS 客户端的决策继续有效。本 ADR 不取代原生客户端，而是记录任务 `t1787886569595`
新增的跨平台 H5 安装与导航策略；用户可按场景选择原生 iOS 或 H5 主屏幕入口。

## 影响

- 新功能只需接入统一导航目录，即可进入工作台并被成员选到底栏，不再额外维护三套菜单页面。
- 30 天持久登录提高手机使用连续性；共享或遗失设备的暴露窗口相应增加，因此继续依赖 HttpOnly、Secure、
  显式退出与服务端会话失效，后续如引入设备管理应提供会话列表和远程注销。
- H5 安装不等于离线可用，也不提供 APNs、后台任务等原生能力；界面不得暗示这些能力已存在。
