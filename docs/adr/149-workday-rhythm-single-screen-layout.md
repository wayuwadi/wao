# ADR-149：今日节奏采用单屏执行布局

## 状态

已接受（2026-08-28）。本决策修订 ADR-147 的顶部三栏比例、下方卡片配置入口与每日必做双栏表达。

## 上下文

ADR-147 把今日重点、每日必做和精力补给并排后，三张卡内部仍分别使用输入框、双栏清单和操作块，视觉节奏不一致；
每张卡又各自暴露待办、通知或模板配置入口，与页面顶部的统一“调整节奏”重复。默认内容高度不一致时，应用滚动区底部还会
留下大块空白，成员无法在一屏内获得完整执行面板。

顶部主卡的通铺样式已经满足浏览需求，但当前时间块、完整一天与天人一卦使用近似等宽布局，主信息不够突出。

## 决策

- 桌面端顶部主卡按 60% / 20% / 20% 分配当前时间块、完整一天和天人一卦；天人一卦关闭时继续使用两栏布局。
- 今日重点、每日必做和精力补给仍按一行三卡排列，但各项都使用卡内通栏；每日必做不再拆成左右两列。
- 三张执行卡等高并填满应用壳和页脚之间的剩余空间。默认数据在桌面单屏内完成浏览；条目超过可用高度时只滚动对应卡片，
  不把整个页面拉成长。窄屏继续使用纵向文档流，避免压缩操作区。
- 三张执行卡不再提供各自的待办、明日文字、清单配置、通知目标或补给设置入口；所有节奏、清单和通知配置统一从页面顶部
  “调整节奏”进入。明日重点和追加重点保留为无文字图标按钮，并提供可访问名称。
- 删除默认态中重复解释真实待办、本机草稿和补给计数规则的长文案；未保存输入改用简短“待保存”，保存中、已保存、失败重试
  与本机草稿恢复能力不变。

## 后果

- 默认桌面视图在一屏内形成“顶部方向 + 下方执行”的完整结构，三张执行卡的行式表达和高度一致。
- 配置入口从卡片移除不代表能力删除；每日必做模板、重点通知目标和精力补给项目仍由同一个配置弹窗按真实账号持久化。
- 追加大量重点、必做或补给项目时，卡片内部会出现滚动；这是保留全部真实数据和页面单屏边界之间的明确取舍。
