# ADR-235：通过显式授权的本机采集 Skill 归档 Codex 工作记录

## 状态
已采纳。本决策仅替代 ADR-078 中“不从本机目录抓取历史”的旧限制，个人与组织长期记忆契约保持原样。

## 决策
用户明确要求各电脑自动记录 Codex 使用过程并补录全部历史。采用独立、可停止的操作系统定时采集器读取当前用户明确授权的本机 JSONL；不把 Skill 自动匹配误当成持久后台服务，不依赖未承诺稳定的 transcript 格式，遇到解析失败保留断点并报告。

采集器支持 macOS LaunchAgent、Linux 用户 systemd timer、Windows 当前用户计划任务。Python 标准库实现和开放 JSONL / Markdown 导出让资料能迁移到其他知识系统。每台设备生成不同设备 id，服务端令牌增加显式归档授权；旧令牌不扩大权限。归档库沿用现有知识库可见范围，界面与安装说明明确团队可见。

只保存可见对话与工具过程，去掉内部推理与系统上下文；凭据规则过滤先于本地待上传内容落盘。分批文档不可被同步更新覆盖，保证人工编辑和已删除状态；本地持久队列配合服务器幂等键处理掉线与响应丢失。

## 取舍
本地 JSONL 是可变化的实现格式，版本变动需要维护解析器；云端且尚未落盘的任务和二进制附件不在此版本采集范围。规则脱敏不保证覆盖自由文本全部敏感信息；可在安装前预览或按工作目录排除。默认周期 5 分钟，不在每条消息上发起网络请求。
