# ADR-007：飞书网页登录采用 OAuth 授权码流

## 状态

已采纳

## 决策

WAO 使用飞书企业自建应用的 OAuth 授权码流。四个入口只改变授权入口和工作台配置，最终都回到统一的前端回调页并由后端交换授权码与读取用户资料。`state` 以 HMAC 签名并包含五分钟有效期，防止 CSRF 和参数篡改。

不在浏览器、日志或 Git 中保存 `app_secret`、飞书 access token 或真实用户凭据。配置由环境变量注入；本地默认禁用。

## 后果

需要在飞书开发者后台配置网页应用、回调白名单和使用范围。上线前需配置本地用户映射及资源授权，不能仅凭前端展示的用户资料保护业务 API。
