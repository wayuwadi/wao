# ADR-308：天人一卦复用本机 Codex，保持 Runner 下线

- 状态：已接受
- 日期：2026-10-03

用户明确要求天人一卦统一使用本机 Codex，不再依赖独立 AI Run / Runner，并使页面宽度与其他页面一致。扩展 ADR-306 的本机执行出口，ADR-304 的 Runner 退役继续有效。

## 决策

- 算卦只使用管理员已启用的本机 Codex 与现有 ChatGPT 登录，保持 GPT-6 Astra；不依据旧 Runner 在线状态、不读取旧集中 AI 账号、不回退额外付费 API。复用动态模型目录确认默认模型可用。
- 复用本机执行队列、目录锁、超时、重启失败收口及无工具只读子进程。队列中保留 `TIANREN` 用途，沿用成员私有会话和服务端权威卦象；不建设另一执行平台。
- 排队与运行都参与每日解读幂等检查与会话删除保护。成功终态及私有助手回复放在同一事务提交；失效 claim 不追加回复，事务失败保留可重试失败，不把仅在浏览器显示的结果当作持久化成功。
- 页面只读查询本机可用性与本人今日运行状态。重新打开时恢复等待状态，完成后读取已有会话，不重复调用模型。卦象、已保存解读和关注点草稿沿用原边界。
- AI 提示词保留卦象事实、文化 AI 概括与 AI 延伸分层及既有医疗边界；移除不适用于本机执行的联网和 AI Run 指引。
- 页面使用公共 `--wao-content-max`，移除专属 1180px 限宽，保留已有窄屏单列布局。此次是既有页面一致性修正，不另做视觉重设计。
- 旧 Runner 接口、配对、节点注册与任务领取继续关闭。数据库结构及已执行 migration 不变；群通知开关与发送逻辑不变，验收不启用群通知。

## 影响与验证

本机日常服务显式启用后，可为已有算卦功能执行任务；仍需实际部署才生效。停用本机执行时卦象和历史继续可读，AI 说明需检查本机 Codex。

接口、回归及真实验收记录见 [天人一卦本机执行](../specs/tianren-local-codex.md)。
