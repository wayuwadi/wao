# ADR-309：本机 Codex 独立维护与验证后自动升级

- 状态：已接受
- 日期：2026-10-03

用户要求后续 CLI 新版本自动升级、新模型可选。延续 ADR-043 的主机维护与业务 CD 分离，以及 ADR-304/306/308 的旧 Runner 退役与本机执行边界。

本机 updater 从官方 npm 注册表读取 `@openai/codex/latest` 稳定版，安装到独立版本目录；不覆盖 Codex App、全局 CLI 或登录文件。新候选通过版本、参数、ChatGPT 登录、模型目录、合成文字和真实配图验证后，才原子替换 `current.json`。所有调用保持已有 GPT-6 Astra 默认和成员模型选择，不转用 API Key；旧进程继续使用原版本，新调用解析新版本并校验制品摘要。

更新失败保留已验证指针，检查间隔至少十二小时；当前 Windows 主机每天 06:15 检查，离线或关机错过时在可用且用户已登录后补做。只有发现新版本才调用合成验收，不每日重复生成图片。保留历史版本供显式回退，回退暂停自动升级，避免立即重装问题版本。首次启用前无历史指针时，原配置的 CLI 仍保留作为运维回退路径。

新模型使用现有动态目录刷新，不重新固化前端名单；账号尚未开放的模型不伪造为可用。更新机制不恢复 Runner，不购买额度、不重置额度、不重启业务服务或在运行中覆盖二进制，不新增 HTTP/CLI/MCP 用户权限。

本机文件系统管理员原本即可修改执行路径，本次指针不扩大信任范围；指针只接受受管理 versions 目录内且摘要匹配的文件。升级脚本、任务安装、回退及证据说明见 [运行手册](../runbooks/local-codex-updates.md)。
