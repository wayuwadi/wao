# ADR-328：飞书仅保留每日归档与事件快捷记录

已采纳，2026-10-07。按用户最新明确要求，修订 ADR-266、ADR-326、ADR-327。

## 决策

- 用户移除的是旧 WAO 聊天中的群消息导入、表情同步和持续扫群，保留每天上海时间 00:00 归档前一天消息、@ 快捷记录。既有历史数据不删除。
- @ 快捷记录仅由现有飞书应用的认证消息事件驱动，保留加密持久接收、作者绑定、幂等、有限处理重试和编辑冲突保护。删除消息与表情轮询调度，不提供无事件时的定时兜底；事件订阅未验证时如实显示缺项。
- 每日归档使用独立窄任务，不恢复退役的手动同步、批量历史补录或原生聊天夜间核对。只归档前一天，启用后下一次午夜生效；不补扫停用期间的历史。
- 每个上海日期先持久登记执行尝试，再访问飞书。同日跨节点只执行一次；失败和进程中断均不自动重领或重复拉取。消息分页和图片资源可能产生多次 HTTP 请求，因此不将一天一次任务描述成严格一次 API 调用。
- 复用既有共享应用、群、知识库配置与自动化任务/运行表，无数据库 migration，不修改已执行迁移。午夜归档按群、知识库和日期定位独立文档，版本冲突不覆盖站内编辑。
- 管理入口位于能力中心机器人接收设置，@ 和每日归档各自开关、独立保存；旧群聊收集/聊天同步入口退役。Webhook 稳定 ID、通知引用、飞书登录和人主动操作的通知反馈保持已有契约。
- 本地主机关闭全局调度时，既有显式飞书专用开关只负责认证事件队列处理、清理和午夜归档，不注册扫群任务；一般部署使用常规调度，避免双重注册。

## 验收

覆盖上海午夜前一天范围、跨实例同日只执行一次、失败不重复拉取、无表情读取、未启用无调用、认证与管理员权限、旧同步接口保持拒绝、事件作者归属及草稿/保存冲突。真实消息订阅、真实作者保存、本地连接既有数据库和实际公网版本分别记录；不得用构造事件或已有轮询记录冒充真实回调。
