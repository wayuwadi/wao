# ADR-057：长期行动计划独立保存真实打卡并通过飞书身份私聊提醒

- 状态：已接受
- 日期：2026-08-12

## 背景

任务和 PDCA 适合跟踪一件明确事项，但“未来一百天持续改善身体状态”一类长期目标还缺少周期行动、
按日打卡和个人提醒的连续入口。自动化域的无执行器任务仍含描述性模拟结果，不能把它当作真实提醒；
图片和短视频也不足以推导安全的训练、饮食或医疗方案。

## 决策

- 新增成员私有的行动计划，保存目标、日期范围、用户自行确认的周期行动、每日真实打卡与事实复盘。
- 行动规则按星期保存；调整计划时旧行动截止并新建当前版本，历史打卡不删除、不回写。
- 提醒只使用当前账号已经绑定的飞书 `open_id`，通过已配置的企业自建应用私聊发送。缺少绑定或应用配置时保存明确失败，
  最多重试六次，不回退到群 webhook，也不伪装成成功。
- `(plan_id, reminder_date)` 唯一；应用节点先占有投递记录再调用飞书，以适配双节点部署并避免重复提醒；
  节点在发送途中退出时，五分钟后可重新抢占停滞的投递。
- WAO 不根据外形图片自动生成医疗、饮食或训练处方；行动内容由用户填写，界面持续展示边界提醒。

## 结果

- 用户可以把长期愿景落成每天可打卡的动作，跨设备查看真实进度和复盘。
- 飞书私聊依赖成员绑定与自建应用配置；无条件时仍可使用页面内计划和打卡，但会明确显示提醒失败。
- 独立表便于以后增加周复盘和趋势统计；本轮不推断体重、体脂、热量或运动效果。
