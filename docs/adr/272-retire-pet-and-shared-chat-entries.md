# ADR-272：从 WAO 浏览器工作台移除宠物和共享聊天入口

状态：已采纳（2026-09-24）。来源：WAO 需求 #1183，用户确认“聊天”指成员共享聊天，不包括 ChatGPT 对话。

## 决定

- 登录后的工作台不再渲染右下角网页宠物；设置导航不再展示宠物设置。左下角快捷链接移除既有桌面宠物默认项，读取旧偏好时也隐藏该项。
- 顶栏、桌面侧栏和手机底栏不再展示成员共享聊天按钮；任务、文档、小记和文件的“分享到聊天”操作及可配置聊天快捷键一并移除，避免出现无法找到聊天入口的操作。
- 保留 ChatGPT 对话、AI 会话、站内通知及其原有入口。共享聊天已有数据、服务端接口和历史链接保留；历史 `/chat` 地址、通知或已有复盘记录仍可按需打开原浮层，不主动展示入口。
- 这次只改变浏览器工作台的可见入口，不删除宠物素材、共享聊天记录或历史桌面客户端代码。

## 验收

登录后在宽屏和窄屏检查顶栏、侧栏、手机底栏、设置导航及主要分享菜单；上述宠物和共享聊天入口均不可见，ChatGPT 对话和 AI 会话仍可进入。用旧 `/chat` 地址核对兼容打开，且不影响站内通知。
