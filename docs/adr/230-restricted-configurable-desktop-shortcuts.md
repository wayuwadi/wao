# ADR-230：通过受限桥接同步成员级桌面快捷键

- 状态：已采纳
- 日期：2026-09-12

## 背景

WAO 网页已有窗口内快捷键，完整工作区客户端则把业务页面放在不具备 Tauri capability 的远程 WebView 中。
新需求要求成员自行配置功能与快捷键关系，并在客户端隐藏时仍能用系统级组合唤起小记。直接给远程 WebView
开放全局快捷键插件会扩大原生权限边界，也不符合 ADR-222 的隔离约束。

## 决策

成员配置继续由 Web 使用既有 `/api/preferences/keyboard-shortcuts-v1` 持久化。窗口内组合由 Web 的统一键盘处理器执行；
系统级组合通过同源保留路径传给 Rust 导航拦截器，拦截器只接受三个固定动作与受限的修饰键加单个字母／数字组合，
随后把净化后的映射发送给本地外壳。只有本地外壳持有 Tauri global-shortcut 权限，负责原子注销旧注册并登记当前配置。
触发后先恢复主窗口，再调用已有固定 `workspace_action`，不接受脚本、路由或任意命令。

网页浏览器只保存并执行窗口内组合，不声明系统级能力。桌面顶栏的页面名称和菜单标签同样只作为有长度上限的显示数据传递；
点击使用 0–49 的位置索引回到远程页面已有按钮，不把用户文本拼入执行脚本。

## 结果

- 成员可跨设备保存统一配置，客户端运行时获得真实窗口外快捷键。
- 远程业务页面仍没有插件调用权限；新增原生能力保持动作白名单、输入上限和同源校验。
- 操作系统拒绝被占用组合时，本地外壳显示失败原因，用户回到同一快捷键页面修改后即可重试。
