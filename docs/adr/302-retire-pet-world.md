# ADR-302：下线松风庭院

- 状态：已接受
- 日期：2026-10-02

用户决定停止维护松风庭院。移除 /pet-world 浏览器路由与功能介绍，前后端菜单注册表、历史个人布局、手机导航和页签统一过滤 pet-world。旧客户端提交带庭院的注册表时忽略这一项，保留其他菜单定制；不再自动补齐庭院入口。

庭院仅有浏览器本地存档，本次保留既有存档、历史场景源码和宠物资源，不删除用户位置数据。常规构建不再加载庭院的 Three.js 场景。该原型无独立业务 API、工作区 MCP 或 CLI 能力，无新增迁移或权限。

验收覆盖旧菜单保存与读取、导航与页签恢复、功能目录、旧路由恢复页，以及类型检查和生产构建。
