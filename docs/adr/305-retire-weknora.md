# ADR-305：下线 WeKnora 及派生内容同步

- 状态：已接受
- 日期：2026-10-02

用户要求不再保留 WeKnora。前后端外部应用注册表过滤稳定 id，旧版自动升级不再补入口；旧个人布局与历史页签不恢复应用。/apps/weknora 显示页面恢复入口，移除嵌入页同步面板和原生知识库的 WeKnora 状态轮询。WAO 知识库和文档仍正常保存与查看。

关闭内容同步的全部 HTTP 路由、自动化执行器和五秒后台推进器，历史定时任务不能恢复或手动运行。公共 UI、机器入库、独立健康和 /api/v1、/r/ 专属代理返回 410。带 file_path 的旧下载关闭，WAO 自身 /files 页面继续走主站。正常发布只停止 Compose 项目 wao-weknora 且工作目录位于 /opt/wao-weknora 的容器，禁用隧道与专属备份计时器；不删除数据库、索引、文件、API Key、同步记录或现有备份，不卸载通用模型工具。

无新增迁移。工作区 MCP 和 CLI 没有此专属同步权限，本次记录退役而不扩大令牌能力。验收覆盖注册表兼容、旧路由、同步接口拒绝、调度禁用、原生知识库回归、部署配置渲染和退役目标隔离。生产停用随正常发布执行，本次不远程停机或做发布后验收。
