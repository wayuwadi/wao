# ADR-101：今日节奏使用模板与每日实例建立可扩展日面板

## 状态

已接受（2026-08-23）。

## 决策

- 时间块和精力补给继续使用已有成员偏好，新增的时效清单使用关系型「模板 + 每日实例」。
- 每日实例保存名称、时间窗和通知快照；历史不随当前模板改名或删除而变化。
- 大小周不复制新配置，服务端读取日历的 `alternate-work-week`；当天覆盖单独落库。
- 每日文档使用成员与日期派生的稳定 id，并由 `workday_rhythm_day` 唯一绑定；只在首次真实输入时创建。
- 提醒由服务端按上海时区每分钟扫描，使用投递表唯一键处理 Linux/Windows 多节点并发。
- 日模块采用独立前端组件与已有领域 API；每日卦象只复用「天人一卦」的服务端权威结果，不在浏览器重新起卦。

## 后果

- 增加五张业务表和一个后台调度器，但换来可核对的历史、幂等文档和真实跨节点通知。
- 已有 `workday-rhythm-config-v1` 与 `workday-rhythm-day-*` 不迁移、不改写，新旧界面能滚动发布。
- 考勤完成仍是成员自我确认，不把提醒面板包装成公司考勤真实数据。
