# ADR-254：退役飞书聊天归档并降低任务收集调用量

已采纳，2026-09-21。修订 ADR-231。

## 决策

- 停止飞书聊天记录的每日知识库归档、手动同步、历史补录和依赖实时同步的飞书复盘；旧接口明确拒绝，不读取飞书或写入知识库。原生 WAO 聊天及其复盘继续使用，历史归档不删除。
- V159 暂停两个历史聊天同步自动化。后台拒绝恢复、重新授权及手动运行这些执行器，前端隐藏退役任务，单独保留“飞书任务收集配置”。共用凭据、群成员及 @机器人保存任务能力保留。
- 快速收集以事件回调为即时入口，轮询默认改为十分钟，读取本轮时间窗口并容纳最多两分钟调度延迟。仍使用消息幂等和双节点租约，不做历史归档。
- 普通失败冷却从十分钟递增至最长六小时，冷却存入共享数据库租约；月额度错误 99991403 冷却到上海时区次月一日。成功后清零连续失败次数。消息读取异常不清空机器人身份缓存；更换应用时才清除。
- 十分钟窗口外的消息编辑、撤回和稍后添加表情依赖事件订阅。额度超限期间缺失消息不自动补扫；前端明确展示即时回调与低频兜底的差别。
- Jenkins 自定义机器人 Webhook 不变。请求统计明确区分出站尝试与额度消耗，HTTP 4xx/5xx、认证接口和自定义机器人 Webhook 不计入月额度。

## 验收

覆盖旧同步入口无出站调用、任务回调收集、轮询身份缓存、跨节点失败冷却及月额度处理；验证任务收集配置不再展示归档与补录入口。已有历史记录保持可读。
