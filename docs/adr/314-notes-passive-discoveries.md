# ADR-314：小记以成员明确开启的顺手发现替代手动挖掘

状态：已接受。日期：2026-10-03。

用户已确认列表内一条可原地展开的具体发现；不新增路由、不凑洞察/提醒/文章三类、不生成图片。取代 ADR-288/293 的相关规则；保留所有历史产物、收藏和旧图片，来源权限不因收藏绕过。

复用旧挖掘物化表、本机 Codex 执行队列和成员偏好；新增持久变更、增量词项、成员租约、独立反馈与预算。扩展 ADR-306 的受控小记用途，不恢复 ADR-304 退役的 Runner，不更换供应商或硬编码开发模型。新成员和无新偏好的老成员默认关闭，开启需要设置内本人明确动作。

正文事务可靠记录变化；AI 派生修改只失效/更新索引，不能制造第二份证据。生成允许零条，必须准确来源和后续证据检查；独立审查不是真实性保证。使用数据库 CAS、冻结版本、开启代次、有限重试与用量记录。暂停后迟到结果不得发布。

实现与默认值见 [小记顺手发现](../specs/notes-passive-discoveries.md)。CLI/MCP 不增加工具或旧令牌权限，通用已授权文档保存仍在业务服务层记录变更。
