# ADR-238：润色等待反馈与后台查看

## 状态

已采纳，补充 ADR-237。

## 决策

真实采样的 Codex 润色后端耗时为 16.22 秒和 18.23 秒，执行阶段约 15 秒。当前协议只回传完整正文，没有逐字增量，不能用动画伪装流式输出，也不承诺固定完成时间。

编辑器和润色工作台显示服务端真实阶段及本次任务已等待秒数，刷新保留起始时间；超过 30 秒提示无需重复提交。计时表示等待时间，不代表模型进度。

编辑器在处理时关闭弹窗只收起视图，继续查询同一个任务。编辑器内保留入口，完成或失败后更新提示，点击后回到对照面板；不自动弹窗打断编辑。重复点击润色先回到现有任务。原文变更检查和明确确认替换保持有效。完成后选择保留原文才移除候选。

本次不改变模型、推理配置、授权或 Runner 协议，不宣称降低模型生成耗时。真正增量输出需后续验证协议支持与安全边界。
