# ADR-062：首页每日建议复用本地 Codex 与真实任务上下文

## 状态

已暂停。历史决策保留；2026-08-20 起首页入口与生产自动预热关闭，服务端接口及既有缓存暂不删除。

## 背景

首页已有面向 WAO 系统自身的改进建议，但没有面向成员当下生活和工作的建议。早期 `/suggestions` 属于只读
内容展示域，数据库规格也明确真实 AI 建议生成需单独立项；把“入职新公司”等固定文案写进前端或 seed 会把
一次需求伪装成长期智能能力，也无法随成员后续任务变化。

WAO 当前已经具备可用条件：成员级登录身份、真实 Task / Project 数据、在线本地 Codex Runner、只读沙箱和
成员偏好键值存储。无需新增模型凭据或另一套建议表。

## 决策

- 首页新增“给此刻的你”，首次打开时读取当前成员当天缓存；没有缓存且本地 Codex 在线时自动生成。
- 生成上下文只含当前成员作为负责人的未完成 Task 及其所属 Project，按临近截止日期优先、最多 12 条；不读取
  密钥库、系统设置、其他成员私人会话或未分配给当前成员的任务。
- 服务端提示要求从真实上下文识别最临近的处境；涉及入职、返工或新团队时覆盖心态、融入团队、发挥优势和
  一个当天行动。上下文没有相关事实时只能给通用建议，不得补造经历或角色。
- 生成继续走现有 `ai_assistant_run` 短期队列和 `read-only` Runner 沙箱，但不创建私人聊天会话；完成后提示词
  按既有流程清除。结果以 `daily-guidance` 成员偏好按自然日保存，跨设备恢复且每天最多自动生成一次。
- 同一成员的生成请求按服务实例串行化，并在进入队列前再次读取当天缓存；多个页面或设备同时打开时不会在同一
  节点重复生成。跨节点同时请求仍由内部只读队列的成员键拒绝重复活动运行。
- 用户可以主动“换一组”，该操作明确触发重新生成并覆盖当天缓存。页面覆盖读取中、生成中、成功、节点离线、
  失败重试；离线时不展示预置建议冒充 AI 结果。
- `/api/daily-guidance` 只访问共享数据库并走双 Gateway；云 Nginx 为生成请求保留 330 秒读取窗口，且禁止在
  超时后自动重放 POST，避免一次点击生成两份结果。
- 自然日和任务临近度统一以 `Asia/Shanghai` 计算。

## 后果

- 用户打开 WAO 就能获得与当前真实任务相关的建议，而不是静态鸡汤；入职任务会自然触发团队融入和优势发挥建议。
- 复用成员偏好避免新增 migration 和重复模型消耗；该缓存不是长期知识档案，若未来需要反馈、收藏或历史对比，
  再引入独立实体和保留策略。
- 建议生成仍依赖至少一台在线且上报 Codex 能力的 Runner；不可用时页面诚实展示原因并允许重试。
