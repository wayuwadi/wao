# ADR-073：以可退役适配器接入 OpenAI 视频生成

## 状态

已采纳。

## 上下文

WAO 自媒体 Agent 已有选题、文案、素材和发布链路，但没有真实视频生成。OpenAI 当前提供
Videos API，可异步生成并下载 MP4；与此同时，官方已公告该 API 与 Sora 2 模型将在
2026-09-24 停用。WAO 的 Codex 账号是供 CLI 使用的订阅式 OAuth，不是 Videos API 所需的
平台 API Key，不能越权复用。

Agent 媒体目前保存在节点本地卷，公网 API 又会在 Linux/Windows 两个 Gateway 间分流。如果任意节点
创建、另一节点播放，完成文件会偶发不可见；Windows 节点也没有已验证的 OpenAI VPN 出口。

## 决策

- 在 `agent-server` 内建立边界清晰的 OpenAI Videos API 适配器和持久化异步状态机，不引入演示引擎。
- API Key 仅使用私有环境变量 `AGENT_VIDEO_API_KEY`；未配置时能力明确不可用。
- Nginx 把 `/api/agent/videos/**` 固定路由到 Linux 主节点，生成文件写入该节点现有 Agent 媒体卷，
  播放仍需 WAO Session 和工作区鉴权。
- 创建请求使用本地任务 ID 与尝试次数组成幂等键；服务重启后继续查询和下载，失败任务可人工重试。
- 2026-09-24 起自动禁止新生成；历史任务和已下载视频继续可读。未来供应商或替代 API 必须通过新的
  适配器与 ADR 接入，不能悄悄把模型名指向协议不兼容的服务。

## 后果

- 当前有真实 API Key 时可完成生成、持久化和预览；没有 Key 时不会产生费用或伪造效果。
- Linux 主节点是该能力的显式单点，主节点故障时视频生成和播放不可用，但 WAO 其他双节点 API 不受影响。
- 临近停用的依赖不会渗入发布任务模型；到期后的拆除范围限于视频客户端、生成任务和页面入口。
- 视频仍占用主节点本地磁盘，后续若要跨节点处理、长期归档或大量生成，应先引入 S3 兼容对象存储。
