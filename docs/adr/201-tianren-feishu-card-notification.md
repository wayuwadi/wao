# ADR-201：卦象解读按成员群配置主动发送卡片

状态：已接受（2026-09-04）。

## 决策

- 用户提供的 JSON 2.0 卡片作为展示样式，保留紫色标题、卦象图标与横幅图片；固定谦卦示例替换为服务端真实卦象及已保存 AI 解读，不另一次调用 AI。
- 在 `workday-rhythm-config-v1.energyNotification` 增加 `notifyTianren`，旧配置默认关闭。目标复用该成员已有 CHAT / WEBHOOK 选择，不回退到别人的群或全局默认群。
- 开启时明确告知：当天解读及公开结果链接会发到所选群。仅首次成功解读发送，每人每卦一条；重新解读不刷屏。开启后也会处理当天已有解读，不补发历史。
- 服务端每 15 秒检查当天有会话的卦象，以键集分页避免未配置成员饿死后续成员。投递快照持久化、数据库条件更新抢占；刷新或关闭页面不影响处理。
- 通知受统一群提醒总开关、提醒开关、沉默时段及成员开关约束；被策略阻止时记录跳过，不在沉默结束后集中补发。
- 网络结果不确定、进程中断后的发送中记录标记 UNKNOWN，不自动重发。应用通道请求携带稳定 uuid；Webhook 没有可靠去重回执，手动重试前必须确认群里没收到。禁止宣称端到端 exactly-once。
- 冻结目标及卡片快照，重试不偷换收件群；已发送不允许再次发送。发送失败不影响原卦象或 AI 存档。

## 验收

验证配置迁移、真实数据组卡、成员隔离、无解读不发送、跨节点抢占、沉默跳过、失败与未知状态重试、已发送幂等、页面刷新恢复和真实飞书图片显示。未验证真实群收到前不能宣称对接完成。
