# ADR-072：周期人生回顾使用成员真实记录与条件性趋势假设

## 状态

已采纳。复用 ADR-019、ADR-045、ADR-064 的飞书归档、成员私有 AI 对话与只读 Codex 队列。

## 背景

成员希望每周、每月、每年回看过去做过什么、聊过哪些对人生有意义的话题，并观察长期轨迹。WAO 已经保存已完成任务、
成员私有 AI 对话和按天同步的飞书群聊；如果仍要求成员重新手输材料，会漏掉真实上下文。另一方面，大模型不能从有限记录
可靠预测寿命、健康、财富、关系或具体未来事件，也不能用固定示例把缺失资料伪装成个人洞察。

## 决策

- 新增成员私有“人生回顾”模块，按上海时区提供自然周、自然月、自然年和“最早记录至今”四种范围。
- 事实来源只包含：当前成员作为负责人的已完成任务、当前成员自己的 `ai_assistant_conversation` 消息，以及系统已真实同步的
  飞书群聊文档。密码本、系统设置、凭据和其他成员私有 AI 会话不进入上下文。
- 每次最多向 Codex 提供最近 36 条来源和 30,000 字上下文；来源正文是不可信资料，使用 JSON 字符串封装并明确禁止执行其中指令。
- 报告固定返回“过去做了什么、有意义的话题、轨迹趋势假设、下次回顾问题”四段。前三段必须引用实际存在的 `[S编号]`；
  服务端拒绝缺失引用、越界引用、缺字段和额外字段，不用静态文案兜底。
- “轨迹”只允许表达“如果当前模式持续，可能……”一类条件性假设，并必须指出会改变趋势的变量；禁止确定性命运、寿命、
  疾病、财富、关系结果和具体未来事件预测。页面持续显示“证据优先，不算命”。
- 生成结果连同来源标题、日期和内部链接按成员、周期保存；不重复保存任务或聊天正文。相同周期手动刷新使用 upsert，保留最新版本。
- Linux 主节点每六小时检查一次，为每位成员补齐最近一个已经结束且尚无存档的自然周、月、年；无真实资料时跳过。
  长任务使用独立单线程，不阻塞其他调度器、不在双节点重复生成。“至今回顾”仅由成员主动触发。
- 生成 POST 使用 330 秒代理读取窗口且禁止自动重放；资料预览与历史读取仍是普通共享数据库请求。

## 后果

- 周、月、年回顾可在周期结束后自动形成，成员也能浏览其他周期并主动刷新；每条关键结论都能回到任务或飞书文档核对。
- 飞书归档是群级上下文，不能证明当前成员亲自参与某句话；报告只把它视为期间群聊话题，不擅自归因。
- 当前只保留生成时的来源元数据，不复制原始正文；源任务或文档后来删除时，旧报告仍能说明当时引用了什么，但内部链接可能失效。
- 有限记录只能形成假设而非人生预测；若未来引入健康、财务等高风险数据，必须另立数据授权和专业审核 ADR。
