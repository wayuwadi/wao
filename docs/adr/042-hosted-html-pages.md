# ADR-042：文件与图床提供隔离的单文件 HTML 托管

## 状态

已采纳。

## 上下文

WAO 已能把通用文件存进 MySQL，但公开文件链接必须经过人机校验并以附件下载，不能直接作为网页打开。用户希望把 AI 生成的单文件 HTML 快速发布到现有公网域名，并可修改链接后缀、浏览器标题和 icon。

直接把任意 HTML 当作 WAO 同源页面执行会让其中的脚本接触站内接口，也可能借表单发起带会话的请求，因此不能复用普通下载出口。

## 决策

- 新增 `hosted_page`，HTML 正文、可选 icon 和元数据均存主节点 MySQL；列表查询不加载二进制正文。
- 站内通过 `/api/hosted-pages` 新建、修改、删除；公开地址为 `/api/pages/{slug}`，后缀全局唯一，只允许小写字母、数字和中划线。
- 只接受 UTF-8 的 `.html` / `.htm` 单文件，最大 10MB；icon 必须是 1MB 以内的图片。更新时可以只改标题或后缀，不重复上传正文和 icon。
- 服务端移除上传文档原有的 `title` 与 favicon，再注入用户配置，保证配置立即生效。
- 公开响应设置 `Content-Security-Policy: sandbox`，允许页面脚本、弹窗和弹出窗口，但不授予 `allow-same-origin` 或 `allow-forms`。页面因此不能读取 WAO 登录态、调用受保护的同源接口或通过表单修改站内数据。
- 公开 HTML 不缓存；favicon 可协商缓存。删除记录后公开链接立即失效。

## 后果

- 这是单文件托管，不解包 zip，也不自动托管 HTML 引用的相对 CSS、JS 或图片；页面应内联资源或引用公网绝对地址。
- 依赖同源身份、表单提交或顶层导航的 HTML 会受 sandbox 限制。这是公开运行不受信任脚本必须接受的安全边界。
- 页面正文进入 MySQL，会增加备份体积；当前个人/小团队规模可接受，体量增长后可保持 URL 不变迁移到对象存储。
