# ADR-315：小记保存信号与成员自动整理设置

状态：接受；日期：2026-10-03。

保存正文与可靠的保存信号同事务，三阶段由后端已有本机 AI 队列推进。浏览器只展示状态并发起明确单项操作，标签推荐保持原能力。无可靠来源的历史待执行任务停止写回并提示明确重试，不盲目续跑。

沿用成员偏好键，聚合配置通过指纹 CAS 保存。关闭阶段递增不可逆取消代次；重新开启不复活旧任务，运行进程终态前仍占用名额。成员锁串行化分配，来源轮次、阶段 attempt 和文档版本保护迟到写回。

取消没有业务依据的短标题/正文下限；整篇长文显式提示选段处理。手动标题、已有可核实总览图与用户图片保留。通用 MCP 写令牌不因此获得 AI 执行权限。

这是自动整理交付，不宣称现有可覆盖对照表能永久保留原稿；原稿保护由后续独立 PR 完成。见 [规格](../specs/notes-save-ai-settings.md)。

并行交付期间 main 已先合入 V178/V179，本机 V176/V177 已执行且不得改写。允许 Flyway 以 out-of-order 模式应用低于当前最大版本但尚未执行的新增迁移；仍启用默认校验和校验。此次 V176 仅增建独立小记信号/阶段表，V177 依赖已存在的 doc/member 及本功能，不依赖待办表顺序。合并前核对版本唯一性、依赖及真实 MySQL 执行，禁止借此改写任何已执行文件。
