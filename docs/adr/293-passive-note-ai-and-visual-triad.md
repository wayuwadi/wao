# ADR-293：小记后台自动整理与三视角启发图

状态：实施中（2026-09-28）。本决策扩展 ADR-288，不改变小记原文的事实源地位。

## 背景

小记标题、润色和总览图已有持久 AI 队列，但完成后的写回主要由浏览器本地任务驱动；小记挖掘需手动启动，且只返回文字候选。两位成员的实际使用摩擦和结果取舍尚待分别核实，因此本次先保留现有触发方式。

## 决策

- 新建小记沿用当前成员独立保存的标题、润色和总览图设置，以及现行默认开启策略；不恢复逐篇开关。正文保存优先，AI 失败不得冒充正文保存失败。已启用任务在服务端持久化、续跑：标题完成后先入队文字润色，再等待配图槽位；配图结束后以最终正文保存润色阅读版本。正文或标题变化时旧结果停止写回，只有标签等元信息变化时沿用新版本继续；原文与润色版分离。
- 挖掘沿用现有手动启动，只使用当前成员本人、未删除未归档的非自动小记。至少两篇有正文才可启动；没有有根据的新结论时不生成图。
- 一次合格挖掘可以产生三张视觉候选，分别呈现积累、换角度和可尝试的下一步。每张记录一句判断、理由、所引小记版本和独立图片任务状态；图像是象征性表达，不在画面中伪造人物、数字或经历。
- 三张图逐张进入现有文章图片队列，避免同一成员图片互斥冲突。生成失败可单张重试；已完成的图不重复生成。图片候选只在本人首页与小记挖掘区显示，不自动写入原小记、不公开分享、不创建提醒或任务。
- 视频不属于本次交付。ADR-074 的供应商与凭据边界继续有效。

## 验收

1. 关闭浏览器后，已保存的小记仍能完成自动整理；旧版本、人工标题和已有图片不会被迟到结果覆盖。
2. 两名成员的来源、图、任务与反馈相互隔离；同一来源快照重复调度不重复计费。
3. 三图的方向、文字依据和来源可分别核对；没有可靠线索时零图，失败时保留已成功的图并可重试。
4. 首页只展示新的可看产物及真实进度，不以任务数量或额度消耗代替采用价值。

此能力只供浏览器本人会话使用。现有工作区 MCP 令牌没有本人私有图片和反馈授权；本次不新增 CLI 命令。若以后需要终端批量导出，先设计专用读取范围与审计。
