# ADR-327：临时公网运行环境单独启动飞书收集调度

已采纳，2026-10-07。补充 ADR-326 的运行边界。

现有临时公网后端沿用 `local-cloud`，其 `wao.scheduling.enabled=false` 关闭全部 `@Scheduled` 注册。仅打开数据库中的群聊收集开关，无法启动消息轮询及持久收件处理。

部署节点可在私有启动参数显式设置 `wao.feishu.collection-scheduling-enabled=true`。全局调度关闭时，独立调度器只注册飞书群消息轮询、收件处理和已完成收件清理，沿用原服务及周期；本地默认不启用。全局调度已开启时不再注册独立任务，避免双重执行。

不为了一个功能开启所有后台任务，不改变数据库、API、CLI/MCP 权限及发布通道。运行验收需要实际调度读取证据和队列处理结果，不能只依赖配置返回成功。
