# ADR-324：手机使用浏览器小记与主屏幕 Web 应用

状态：接受；日期：2026-10-04。

用户以“手机快速使用 WAO”为目标，确认 Safari 登录后添加到主屏幕的方案，以免维护、签名和升级独立手机应用。本决策取代 ADR-323 的持续 iOS 开发与自动构建例外，恢复 ADR-264 的浏览器维护范围；历史原生源码、分享扩展和制品保留，不卸载既有应用。移动工作流移除 main push 自动触发，保留人工恢复入口，只有用户明确恢复原生开发时才执行。

复用 Vue Web 的真实 API、登录、权限和成员隔离草稿，以及已有内容优先手机壳。Web 应用保持 manifest id `/`，启动地址改为 `/notes`；浏览器直接访问首页和项目仍保持其明确地址。手机主屏幕 Web 应用与桌面浏览器使用同一版本，不新增自动刷新或另一套数据缓存。

宽度不超过 760px 使用底部导航和按需完整菜单；小记采用单列与适合触控的编辑字号。软键盘导致可见视口收缩时隐藏底部导航和悬浮新建，专心编辑；全屏编辑跟随 VisualViewport 的高度与顶部偏移，并保留安全区。缩放手势不当作键盘，不禁止用户缩放。

不以此次 Web 布局交付宣称实现 iOS 系统分享接收、无操作读取剪贴板或录音转写。它们有独立的平台能力与服务要求。截图中的桌面布局须依据当前版本和设备视口核验，不凭截图断言根因；窄屏浏览器验收与实体 iPhone/Safari 验收分别记录。
