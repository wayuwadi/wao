# ADR-193：Skill 安全扫描使用可审计的作者 Pass

## 状态

已接受（2026-09-02）。修订 [ADR-094](094-skill-market-versioned-packages.md) 的上传安全流程，不改变包不执行、
版本不可变和管理员人工审核边界。

## 上下文

Skill 发布预检原本只返回命中文件，不返回行号，并在任何规则命中后隐藏发布表单。发布者即使确认命中属于可公开配置，
也只能重新选择同一文件夹，而服务端仍会无条件拒绝草稿，无法继续发布。单纯在前端隐藏警告会丢失安全依据；单纯允许
绕过又会让管理员不知道作者放行了什么。

## 决策

- 每类扫描规则在每个文本文件中返回首个命中的文件路径和行号，不回传可能包含凭据的原文。
- 浏览器在预检后保留本次选择的 `File`；作者点击 `Pass` 后直接进入元数据表单，正式创建时复用这些文件，不要求再次
  选择文件夹或 ZIP。
- 服务端正式创建时仍重新扫描。只有请求显式携带 `scanOverrideConfirmed=true` 才允许保存带命中的草稿，并把原始命中
  和确认状态一起固化到 `skill_version`。
- 作者提交和管理员审核都继续展示拦截点。管理员可在人工复核后通过或驳回；没有确认状态的带命中版本仍不能提交或通过。
- AI Run 自动生成的候选不能自动 Pass，必须保持失败关闭。

## 后果

- 发布者能定位误报并用一次明确操作继续，上传选择不会被清空。
- 放行不是删除告警：不可变版本保留作者决定，最终公开仍需管理员人工审核。
- 扫描结果不展示匹配原文，避免诊断界面反向泄露真实凭据。
