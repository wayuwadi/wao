# ADR-261：文章总览配图复用 Linux Codex 登录态与安全任务队列

状态：已采纳。

## 背景

小记和文档分享出去只有文字。用户希望一键生成概括全文的开篇图，并按成员定制提示词。现有服务有图床、成员偏好和两台已登录 ChatGPT/Codex 的 Linux Runner，但没有单独图像 API Key。

## 决策

- 复用 assistant-v2 的持久安全队列，新增 `ARTICLE_IMAGE` 用途。仅当前脚本哈希的 Linux Codex Runner 领取；与文字任务共用领取令牌、超时和失败收口。
- Runner 仅调用内置 `image_gen`。图片必须来自本次隔离 `CODEX_HOME/generated_images`，不能按模型回答读取任意路径。图像上传使用领取令牌与 Runner 令牌双重校验，服务端验证 PNG 后存入现有图床，成功完成时核对已登记的图床 URL。
- 正文只作为一次生成任务的有界输入，完成或超时即从队列清除；图片地址写入正文后沿用小记/文档的保存流程。成员提示词存现有 `preferences`，默认文案由前端统一提供，不增加数据库表或全局配置。

## 影响

两台 Linux 节点无需新增服务凭据。用户能在原编辑器中生成、恢复并插入总览图。图像质量与额度由当前登录态的内置工具决定；工具不可用时任务明确失败，且不能改用可写开发任务或未经授权的外部图像 API。
