# ADR-094：Skill 市场使用共享库保存不可变审核包

- 状态：接受
- 日期：2026-08-21

## 决策

Skill 与版本分开建模。每次提交产生不可变的 `skill_version`，审核通过后由 `skill.published_version_id` 指向对外版本。包与元数据一起保存在共享 MySQL，不依赖任一 Linux / Windows 节点的本地目录。

## 原因

审核的实物、用户下载的实物和 SHA-256 必须始终是同一份。不可变版本也使新版驳回时能继续服务旧版。一期以 10 MiB 上限控制数据库增长；规模扩大后可在不改变领域模型的前提下把 `package_content` 迁入对象存储。
