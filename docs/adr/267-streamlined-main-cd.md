# ADR-267：主线 Jenkins 精简为打包和发布

- 状态：已采纳
- 日期：2026-09-24
- 来源：用户要求参考公司流水线，缩短主线工作流，并使用中文阶段名

## 决策

`wao-main-cd` 保留一分钟提交合并、单并发、变更范围判断、不可变 Git SHA 制品、Linux1 → Linux2 → 云入口滚动发布、失败停止、生产健康验收、提交状态和飞书通知。流水线阶段只展示「拉取代码」「确定发布范围」「打包构建」「部署并验收」，Jenkins 或备份运维文件变化时再展示「同步运维配置」。

主线不再运行 Maven、Vitest、AI Runner、CLI 和部署脚本的完整测试集。开发者在合并 PR 前执行与改动相称的本地测试；生产 CD 只做快速输入与脚本语法检查、编译和打包。Docker 构建跳过测试编译。纯文档和仅测试代码变更不发布。浏览器快路径仍跳过后端镜像与服务重启。

Jenkins 和备份运维配置仅在相关版本化文件变化且生产发布验收通过后核对并同步；没有实际差异则不重启控制器，避免每次后端发布都触发安全重启。

## 影响与边界

发布速度不再受完整集成测试影响；代码缺陷会在本地验证或生产构建、滚动发布和健康验收中暴露。生产发布的数据库迁移版本冲突预检、节点摘流、版本一致性和公网健康检查仍是硬门槛，不因团队人数少而放宽。
