# ADR-274：云端公网网关解析不采用本机隧道地址

- 状态：已由 ADR-275 取代
- 日期：2026-09-24
- 来源：构建 #504 首台就绪后出现公共 API 502/504；云端 Nginx 错误日志显示回源超时与 no live upstreams
- 调整：ADR-271、ADR-273 的公网路由与健康检查

## 决策

云端 `/etc/hosts` 为 SSH 隧道将 `linux1.wayuwa.cn` 映射到 `127.0.0.1`。这个地址不能用于公网 Nginx 回源。渲染公网 Nginx 时，先选非回环 IPv4；若本机解析只得到回环地址，改向公共 DNS 查询 A 记录。解析失败则拒绝生成新配置，保留现有 Nginx 配置。云端健康检查使用同一个解析器得到的地址，不再通过本机隧道冒充公网回源健康。

Jenkins 生成的初始配置、云端摘流重渲染和每分钟 DDNS 更新统一使用这一解析器；测试覆盖回环映射被公共 DNS 地址替换的情况。
