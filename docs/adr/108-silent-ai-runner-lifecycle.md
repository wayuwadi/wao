# ADR-108：AI Runner 在线状态变化不再发送群通知

## 状态

已采纳。

## 背景

ADR-029 要求 Runner 超过 2 分钟没有心跳时发送离线群通知，恢复心跳后再发送上线通知。VPN 定时断开、电脑休眠、网络短暂波动和发布重启都会触发这类状态变化，但它们并不是需要群成员立即处理的事件，反复通知会掩盖真正的任务和发布结果。

## 决策

- 保留每分钟扫描和超过 2 分钟判定离线的机制，保证 WAO 页面、任务派工和 Wake-on-LAN 仍使用真实心跳状态。
- 自动离线和后续心跳恢复只更新 `ai_runner_node.online_state`，不再发送飞书群通知。本决策取代 ADR-029 中的上线/离线通知要求。
- 管理员主动解除执行电脑接入仍发送一次通知；这是人工发起的凭据作废操作，与日常网络状态变化不同。
- AI 任务成功、失败和生产发布结果通知不受影响。

## 后果

- VPN 定时断开或恢复、计划任务重启 Runner 及短暂网络波动不再打扰群聊。
- 管理员需要在 WAO 的“执行电脑”页查看实时在线状态和最后心跳时间。
