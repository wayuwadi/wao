# ADR-297：下线决策管理

- 状态：已接受
- 日期：2026-10-02

用户要求下线决策管理。移除浏览器路由、功能探索介绍、默认与历史导航入口、手机导航和持久页签；服务端菜单注册表忽略旧配置中的 decisions，功能健康统计不再列出或累计该功能。移除 /api/decisions 控制器，旧客户端不能继续读写。

保留共享的 memory_document / memory_revision 数据和项目工程记忆能力，不新增删表或删除历史决策的迁移。既有本机草稿保持原样。恢复需要另行决定并恢复路由与专属接口，个人布局不会自动复活入口。

CLI / 工作区 MCP 没有决策管理专属命令或工具，本次不新增能力或扩大令牌权限。

验收：导航、功能探索、旧页签和旧地址不再打开决策；项目、知识库和共享记忆保持可用；旧专属 API 返回 404。
