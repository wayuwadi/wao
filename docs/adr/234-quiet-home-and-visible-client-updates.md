# ADR-234：首页弱化 AI Run，并恢复成功交付反馈

- 日期：2026-09-19
- 状态：已采纳
- 来源：任务 `t17897276079220` 和用户补充的 Mac 更新入口问题。

日常开发改由本地电脑承担，首页 AI Run 降为默认折叠的实验入口，保留已有运行、草稿与直达链接。补充旧客户端网页顶栏去重；新版单层桥接沿用 ADR-230。网页安装图标使用独立安全边距资源，页面品牌资产保持原样。

客户端更新入口必须在没有新版本、检查中和检查失败时也可找到。顶栏常驻入口先打开版本页，再由用户决定下载和安装；不以后台探测成功作为入口出现的前提。原生应用的交付依赖独立安装包，不冒充主站热更新。

按本次用户明确要求，取代 [ADR-152：成功静默通知](152-silent-success-delivery-notifications.md) 第 3、4 条中 Jenkins 成功静默的决定，每个成功批次发送一张短卡；AI Run 的通知决策不随之改变。生产成功卡必须以三节点与最终检查状态为证据，影子构建和无需部署不得称作已上线。成功门禁只使用群通知总开关和沉默时段，失败开关继续只控制失败。成功门禁不可读时保持静默，失败仍保留 fail-open 告警兜底。

详细范围、验收及旧版本限制见 `docs/specs/home-desktop-quiet-2026-09-19.md`。
