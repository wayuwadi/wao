# ADR-211：只读基础设施总览与历史资源采集

已采纳。Linux2 以独立 Python 标准库服务每 60 秒采集 Linux1、Linux2、云入口：CPU、内存可用量、交换分区、物理磁盘、负载、运行时间、Docker 容器与 systemd 服务。使用既有严格验证主机密钥的部署 SSH 通道，HTTP 请求不能传入命令或目的主机。网页服务不持有 SSH 私钥。

仅监听 Linux2 与云端 loopback 18782，云 Nginx 每次读取向 WAO 验证管理员会话。SQLite 保存 7 天资源趋势，接口按 1 小时、24 小时、7 天聚合到最多约 240 个点；服务清单保留最后成功快照。单机失败不阻断其他主机，旧值标记时间、失败原因与过期，缺少权限的资源显示未知。

WAO 增加原生基础设施菜单与页面，支持节点切换、磁盘容量、按应用分组的服务表、运行状态筛选、搜索与历史图。可见时每分钟读取，离开页签暂停。页面不具备启停、终端或配置修改能力。容器和 systemd 统计可能重叠，不相加冒充主机资源。
