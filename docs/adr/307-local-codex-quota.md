# ADR-307：独立读取本机 Codex 额度

- 状态：已接受
- 日期：2026-10-03

用户要求首页读取本机 Codex 账号的额度、重置时间及重置卡，并能在 Linux2 使用相同账号时复用。ADR-304 的 Runner 退役继续有效；旧心跳停止后，首页不能再依赖 Runner 刷新快照。

新增显式启用的只读采集器，通过本机 Codex app-server stdio 调用 `account/read` 与 `account/rateLimits/read`。不创建模型会话、不执行任务、不消耗重置卡、不复制登录凭据。子进程只继承登录目录、系统路径与代理等必要环境，数据库凭据与 API Key 不传入；采集最长 8 秒，退出时回收进程。默认关闭，避免无意共享主机账号信息。

允许的展示字段存入已有 `system_setting`，键为 `codex-local-quota-v1:<source>`。不同机器使用唯一来源名，同账号按规范化邮箱取最新采样内容，不累加额度或重置卡；共用数据库的未登录节点也可读取快照。不同数据库之间不自动同步。数据沿用既有账号额度接口的登录成员可见范围。

启用调度时每分钟采样；查询可补采且一分钟内节流，并发查询不等待已有采样锁。失败保留旧值、标记历史；超过 15 分钟或明显来自未来的时间不算新鲜。无历史时返回明确的不可用信息。不保存原始协议、认证文件、访问令牌或错误原文。

首页保持四等分：卦象、Codex 周剩余、周重置、官方重置卡。重置时间取通用周窗口的 `resetsAt`，与会员到期日区分；详情保留其他额度窗口和采集来源。重置卡 `availableCount` 为权威值，缺失显示未同步，零值显示 0 张。手工记录保留在详情折叠项，不参与官方统计。

不增加数据库迁移、Runner 路由、MCP 工具或 CLI 权限。配置与验收见 [本机额度采集](../runbooks/local-codex-quota.md)。
