# ADR-330：数字成员图库及小记配图身份

- 状态：已接受
- 日期：2026-10-07

用户确认以数字成员图库管理本人、家人及宠物，小记只增加一个轻量设置图标，后续扩展文章、视频等能力。此前小记只把正文和画面偏好交给模型，账号没有已确认性别或形象资产，因而可能生成与本人不符的人物。

采用私有 Subject→ReferenceAsset→Look/不可变版本→GenerationUse 分层。性别来自账号明确确认信息，并与本人绑定成员一致，不用名称或照片推断；候选形象人工确认，默认本人按账号唯一绑定。私有原照片与候选形象不进入公共图床，小记生成后的配图沿用已有分享行为。

先接通已有本机 Codex 图片出口，参考照片真实作为输入，身份和资产哈希在入队时冻结。新增独立图片生成目的保存私有候选；旧正文/画面字段兼容，增加可选 identitySelection。本机参考图功能默认关闭，具体主机完成实际验证后开启，不静默转入额外付费 API。

采用拥有者行锁与 CAS 版本避免覆盖草稿。追加不可变形象版本并记录生成使用，保证后来换默认不改变旧文章。归档与引用保护优先于破坏性清理。头像相似度仍是人工确认，照片不足不声称已复刻真实人物。

视频、语音、动作、3D 和供应商模型绑定由后续独立 Capability/ProviderBinding 扩展，当前不以占位 UI 声称可用。此次不增加 workspace MCP 或 CLI 权限，须单独私有资产 scope 才能开放脚本操作。规格：[数字成员图库](../specs/digital-member-library.md)。
