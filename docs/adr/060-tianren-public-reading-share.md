# ADR-060：“天人一卦”使用不可猜测凭据分享只读卦象投影

- 状态：已接受
- 日期：2026-08-13

> 2026-08-14 的 [ADR-067](067-tianren-share-latest-ai-reflection.md) 已在不改变凭据机制的前提下，
> 将公开内容扩展为卦象及当前最新一条 AI 自照。本 ADR 中“AI 对话都不进入 DTO”的原始决策以 ADR-067 为准。

## 背景

成员希望在起卦后复制一个公网 HTML 链接，让别人直接看到结果。已有每日卦象是真实服务端存档，已有
`/api/share/**` 和 Vue 公开路由可以提供免登录页面；但卦象记录属于成员私有数据，并关联包含关注点和 AI 回答的
私有会话，不能把整个内部 DTO 公开，也不能用可枚举的记录 id 充当访问凭据。

## 决策

- 分享由登录成员主动点击触发，不因起卦自动公开。服务端只允许当前成员为自己拥有的卦象生成链接。
- `tianren_daily_reading.share_token` 保存 128 位安全随机十六进制凭据并加唯一索引；同一卦重复或并发分享复用一个凭据。
- 公网页面使用 `/s/tianren/{token}`，读取免登录接口 `GET /api/share/tianren/{token}`。
- 公开 DTO 只包含日期、六爻、变爻、本卦、之卦和起卦时间；成员 id、记录 id、关注点、`conversationId` 与 AI
  对话都不进入 DTO。分享页明确说明链接公开性和文化反思边界。
- 第一版链接长期有效且没有公开的撤销入口；以后如需失效时间、撤销或分享私有 AI 解读，必须单独立项并重新评估
  隐私边界，不能静默扩大现有公开内容。

## 结果

- 收到链接的人无需登录或重新起卦，即可在公网 HTML 页面看到同一份服务端校验结果。
- 随机凭据降低枚举成员历史的风险，专用公开投影从类型层阻止私有字段误传。
- 链接即访问凭据；成员应只发给愿意公开结果的对象，WAO 不在页面展示分享者身份。
