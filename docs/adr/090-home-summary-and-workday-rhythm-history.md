# ADR-090：首页额度收口与今日节奏历史复用成员每日存档

## 状态

已采纳。首页展示部分修订 ADR-065；今日节奏历史补充 ADR-079、ADR-084。

## 背景

首页同时在理念区、独立 Codex 大卡片和自主进化区展示额度与运行说明，占用首屏且信息重复；自主目标只保存在
Vue 组件内，离开首页后组件销毁会丢失尚未派发的输入。

今日节奏已经把每日目标与精力补给次数按成员、日期真实保存为
`workday-rhythm-day-YYYY-MM-DD`，但没有历史入口。另建一套只记录新数据的统计表会让已有记录无法回顾，扫描所有
成员偏好又会破坏成员隔离并形成无界查询。

## 决策

- 首页移除独立 Codex 使用大卡片和重复额度文案，只在理念 hero 内展示真实七天窗口的周剩余额度，并保留动态执行槽位和 AI 详情入口；额度未知、
  同步失败或只有失效快照时不显示占位数字。`sessionQuotas` API 保持兼容，设置页和其他消费者不受影响。
- 理念区只保留必要口号，把运行数、AI 工具在线状态、槽位占用和仪表盘入口压缩成带无障碍名称及悬停说明的小图标。
- 首页自主目标按成员保存在浏览器本机草稿中，输入变化即时写入，离开再回来恢复；只有服务端成功创建运行后清理，
  派发失败继续保留并显示草稿状态。
- 新增 `/api/workday-rhythm/history`，只按当前会话成员查询明确的 ISO 日期键范围，单次最多 366 天并按日期倒序返回。
  服务端不接受成员 id，也不扫描其他偏好键。
- 历史直接读取已经落库的每日记录，不为没有存档的日期生成零值。损坏记录不伪装成空记录，响应返回跳过数量供页面提示。
- 每次保存每日记录时同步保存当时各精力项目的名称与点击机制快照。旧记录优先使用已有快照，其次使用当前成员配置；
  已删除且无法恢复名称的项目明确标为“已移除项目”，次数仍来自原始记录。

## 后果

- 首页首屏信息密度降低，额度只保留理念 hero 内一个真实总览位置，未派发目标切换页面也不会丢失。
- 既有今日节奏历史上线即可读取，无需迁移或复制用户记录；查询受成员和日期范围双重约束。
- 成员偏好仍适合当前低数据量的按月回顾。若后续需要跨年趋势、聚合图表或通知流水关联，再迁移到独立历史表，
  不在当前读取链路中伪造统计数据。
