# ADR-321：统一设置面板与天人独立模型配置

日期：2026-10-04

状态：已接受

## 背景

小记设置的窄长表单使模型选择与提示词编辑拥挤；卦象缺少本页模型和深度配置。用户确认统一 UI，并授权其它适合的设置入口一起采用此风格。

## 决策

使用现有 Vue 技术栈提取共享弹窗、分项设置布局和模型目录字段。小记三个入口与卦象共用视觉组件，配置仍独立；项目及文件设置采用相同标题、底栏和短表单布局。规范唯一入口为 `docs/design/settings-ui-pattern.md`，AGENTS 只引用该入口。

天人设置扩展已有成员偏好 JSON 的 model 与 reasoningEffort，不新增数据库结构。历史默认 Astra/medium；旧客户端省略字段时保留当前值。新任务在文字入队时固定完整设置快照，自动图沿用，手动重画使用当前配置。天人不再从小记读取执行深度。真实目录校验不支持组合，并保留不可用的旧选值供用户处理。

草稿恢复保持原 CAS 版本，跨设备更新必须显式对比处理；界面不会通过刷新自动覆盖远端设置。现有私有图片、解读版本、幂等和授权边界保持。

## 影响

增加共享 UI 与成员独立的运行配置，减少设置入口之间漂移。不恢复 Runner 或扩大 MCP/CLI 权限。方案与接口见 `docs/specs/unified-ai-settings.md` 和 `docs/api/tianren-visuals.md`。
