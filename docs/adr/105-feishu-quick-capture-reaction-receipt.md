# ADR-105：飞书快速收集使用原消息表情回执

## 状态

已接受（2026-08-24）。

## 背景

ADR-102 为个人快速收集增加了详细群卡片。真实使用中，每条记录后都再发一张卡片会切断群聊节奏；应用发送失败时回落全局 Webhook，还可能把回执发到非原始群。

## 决策

1. 快速收集成功后，使用飞书消息表情接口给原 `message_id` 添加 `DONE`。
2. 可识别的收集请求未能创建任务时添加 `ERROR`，保留最小可感知失败状态。
3. 该链路不再依赖 `FeishuWebhookNotifier`，不发群卡片，不做 Webhook 回落；
   `TaskService.createFromChat` 同时跳过通用“新建任务” Webhook。
4. 表情是任务创建后的次要回执；添加失败只记日志，不回滚真实任务。

## 后果

群聊只增加一个贴在原消息上的表情，不再产生卡片噪音，也不会把私人收集结果发到 Webhook 指向的其他群。代价是表情本身不再提供任务详情链接，需要时在 WAO 的“稍后”列表查看。
