# ADR-035：定时飞书通知使用自建应用卡片回调

## 状态

已采纳。

## 决策

自定义的「飞书群提醒 / 公告」自动化使用已在「飞书群聊同步」配置的自建应用向目标群发送消息卡片，而非全局 webhook。卡片回传 `card.action.trigger` 到既有事件地址，服务端以飞书提供的操作者 open_id 持久化「做到了 / 没做到」。通知事件与反馈分表保存，保证重启后仍能接收已发卡片的反馈；未点击不产生反馈记录。

报表只统计真实回调，支持日、周、月、总范围及明细。

## 后果

管理员须在飞书开放平台订阅 `card.action.trigger`，并授予应用机器人及以应用身份发送群消息权限。未完成该配置时任务明确失败，不能降级为无法识别点击人的 webhook 通知。
