# ADR-276：123 云盘改存可直接阅读的 WAO 内容副本

## 状态

已采纳；取代 ADR-188 中“每天上传完整加密数据库快照到 123 云盘”的云端日常任务，不改变 Linux1/Linux2 间的恢复快照。

## 背景

先前云端每天上传约 2.5 GiB 的完整加密恢复归档。用户希望在 123 云盘中直接打开有意义的知识和任务文件，后续仅上传变化的内容，而非每天保存一份不可浏览的完整数据库归档。

## 决策

- 每天从 WAO MySQL 导出所有成员当前未删除的知识库文档、小记和任务为 UTF-8 文本文件；实际引用且仍存在的图片、附件保留原格式。个人记忆和其他业务库不在本次可读副本范围。
- 使用独立的 `WAO-可读文件/` 目录与 SHA-256 清单。每次从源数据计算文件内容，只上传新增或变化的文件；原有文件不重传。云端手工修改的托管文件不被覆盖，异常的大量删除被阻止。
- 新云端目录与旧的 `WAO-backups/` 加密快照隔离；新程序不清理旧快照。原本的云端恢复口令和隔离恢复工具继续保留。
- Linux1/Linux2 间每天的加密数据库恢复快照和五分钟 binlog 归档继续运行，承担完整服务恢复。可读副本只负责用户内容浏览，不能替代数据库恢复。
- 123 云盘授权目录只给予 WAO WebDAV 应用访问，应用密码仍保存在 root-only 配置中。文本明文可被云盘账号与持有其访问权的人阅读，因此授权范围只按用户要求覆盖上述内容。

## 后果与回退

云端首次同步要上传现有文本和媒体；后续改动量决定日常上传量。数据库仍需读取并计算内容与媒体哈希，但不会每天向云端传输整份恢复归档。云端删除或编辑托管文件、WebDAV 不可用及来源数据异常会使同步明确失败。

如需恢复每日完整加密云端快照，可把定时服务重新指向 `upload-peer-offsite.sh`，前提是已有云端恢复口令仍可用。旧加密恢复点不因本决策自动删除。
