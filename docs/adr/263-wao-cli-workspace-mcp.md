# ADR-263：WAO CLI 复用工作区 MCP

状态：已采纳。

## 背景

WAO 已有面向外部 AI 的工作区 MCP，用户还需要可供人、脚本和本机 AI 直接使用的 `wao` 命令，并希望后续服务与 API 开发时持续维护命令能力。

## 决策

- 首版 CLI 使用现有工作区 MCP 令牌和实时工具目录，不再为相同项目、任务、知识库操作引入第二套后端鉴权与 API。
- 常用的 19 个工具配以资源式子命令；通用 `tools call` 可调用服务端之后新增且当前令牌可见的工具。新增 API 仍需逐项确认权限与 CLI 价值，不能自动扩大旧令牌权限。
- Mac 令牌存系统钥匙串，环境变量适用于脚本；不在仓库、命令参数或明文配置保存令牌。命令运行结果支持 JSON，写入失败不自动重试。
- 项目级 skill 和 `AGENTS.md` 提醒开发者同步检查 MCP、CLI、规格与测试；此决策不授权自动开放删除、通知或其他敏感操作。

## 结果

人和 AI 都可用统一命令操作获授权的 WAO 工作区，命令权限随服务端工具目录变化。新增业务能力有明确的 CLI 覆盖检查与台账入口。
