# ADR-295：下线未继续使用的独立功能

状态：实施中（2026-09-29）。来源：产品所有者明确要求全站移除入口、接口、数据和代码；“AI 会话”和“记忆”只指独立功能，项目 AI 执行及其必要记录继续保留。

## 决定

下线我的准则、爬虫能力、账号资源库、基础设施清单、账务本、英语训练、单词本、饮食管理、周报生成、终端设备、游戏厅、数据中心、ChatGPT 对话独立页面、形象管理、独立记忆中心、AI 会话独立页面、更新日记、行动计划、链接空间、CalDAV 接入和微信登录。浏览器路由、导航注册、搜索目录、历史页签、专属 API、服务、部署入口和专属数据同步退役。旧 Flyway migration 保持不可变；新 migration 删除专属表和配置。

项目 AI Run、Runner 配对与执行进度、自动化、AI 用量、项目工程记忆及其候选和读写引用保留。项目记忆候选的发布、驳回迁入项目页专属接口；个人决策仍以统一版本表存储，改由 `/api/decisions` 专属接口访问。人生回顾、参考图库、工作日节奏仍使用的共享 AI 助手服务与会话记录保留，但独立 ChatGPT 对话页下线。运行健康监控、证书同步与项目工作区 MCP 保留；基础设施清单采集器另行停用和删除。

新迁移只删除独立记忆数据：个人记忆原表、设备 MCP 授权、机器/应用记忆和 Codex 会话归档；`memory_document` 中项目范围及个人 `decision` 分类保留。产品所有者已明确要求直接删除历史微信绑定，因此同时清理 `account_identity` 中的微信身份和 `account_login_event` 中的微信登录事件；账号、成员及其他登录方式不删除。仅有微信身份的账号在迁移后无法再用原方式登录，需通过剩余登录方式或管理员协助恢复访问。

浏览器启动时清理这些独立功能的历史本地草稿键；新决策草稿与项目 AI 执行数据不在清理范围。周报生成和数据中心没有专属业务表，删除对应服务及入口即可。

WeKnora 内容同步保留项目工程记忆来源；读取旧配置时自动忽略已下线模块，及时同步检查和完整同步会分批清理退役来源的远端派生文档，即使原配置关闭了普通来源删除。停用同步的环境需要单独启动一次完整同步并核对远端清理结果。

## 数据与发布边界

`V172__retire_unused_standalone_features.sql` 含不可逆 DDL/DML，部署前须核对 Linux2 数据库备份与恢复点，以及迁移版本号是否仍唯一。不得修改已经执行的 migration。基础设施清单退役脚本只处理该采集器的 systemd 服务、源码安装目录、配置和资源历史；发布健康监控及证书同步不受影响。

PR 合并说明须分别列出本地验证、迁移静态核对、真实数据库验收缺项和是否已上线。按照 ADR-232，合并不是上线，线上验收由产品所有者负责。

## 验收

老菜单注册、个人导航布局、全局搜索和本机持久页签均不再显示下线功能；直接访问旧路由不加载功能页，旧专属 API 不再存在。项目 AI Run 可创建、查看结果和记忆引用，项目候选能在项目页审核；决策管理仍能保存、冲突核对和归档。登录页只提供飞书与邮箱；CalDAV 不再出现在日历和设置中。新迁移后无保留代码查询被删除的表。

本 ADR 取代 ADR-272 中“保留 ChatGPT 对话、AI 会话及其原有入口”的决定。各功能的历史规格与 ADR 只作为当时设计记录，不代表现行能力。
