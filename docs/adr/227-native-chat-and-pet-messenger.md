# ADR-227：WAO 原生聊天与宠物传话入口

- 状态：实施中，待真实链路验收。
- 日期：2026-09-10
- 来源：共享任务 `t1789013082654` 及用户补充的桌面宠物聊天需求。

## 决策

本次以任务的六项子任务为交付边界：WAO 内部通知、全局聊天入口、任务分享到聊天、退休飞书双向桥接、Enter 发送和未读提示。全面复刻飞书属于后续产品方向。

共享聊天的发送、引用、表情和已读均由 WAO 数据库负责，移除飞书桥接、轮询和同步管理接口。旧飞书导入消息退出当前消息流；保留历史数据库记录和已有复盘引用，不执行破坏性生产清库。飞书登录与独立知识采集不属于聊天桥接，继续保留。

任务、评论、运行结果与定时提醒等系统群通知改为持久化站内通知，沿用通知中心和成员已读状态。个人日历提醒按成员过滤；主动外部卡片分享、验证码转发、登录和知识采集维持各自独立功能。聊天入口 Teleport 到应用全局浮层，在任务抽屉上可用；收起聊天和 Escape 不关闭正在编辑的任务。Enter 发送、Shift+Enter 换行，中文输入法确认候选词不触发发送。任务分享带入标题和范围正确的链接，追加到现有聊天草稿，成员自行发送。

## 宠物交互

宠物是传话伙伴：新消息气泡展示真实发送者和预览；点击气泡打开快速回复，点聊天按钮展开完整聊天。AI 对话保留独立入口，避免把同事消息误认为 AI 回答。连续消息合并为未读数，已读以成员实际打开阅读为准；发送失败保留草稿并支持重试。

网页宠物受浏览器窗口限制。桌面客户端用独立透明、置顶窗口显示宠物，复用同源登录和聊天 API；不复制账号凭据，不给远程页面通用文件、进程或更新权限。桌面原生能力需单独构建、签名发布和实机验收，Web 发布不能替代客户端升级。

## 验收

- 无飞书配置也能发送文字、图片、引用和表情；重试不重复发送。
- Task 打开时能展开与收起聊天，任务草稿保持；分享正确反映任务或子任务范围。
- Enter、Shift+Enter、输入法和发送失败均符合草稿保护要求。
- 聊天隐藏时不标记已读，入口和宠物显示真实未读；打开阅读后清除提示。
- 自动群通知留在 WAO 通知中心，不再向飞书群发送。
- 桌面宠物在主窗口隐藏后仍可接收气泡和回复；断网、退出登录和失败不丢草稿。
