# ADR-067：“天人一卦”公开分享展示最新 AI 自照

- 状态：已接受
- 日期：2026-08-14

## 背景

[ADR-060](060-tianren-public-reading-share.md) 第一版为了收紧隐私面，公开页只投影卦象，明确排除整个 AI 会话。
实际使用时，成员要分享的是页面上已经看到的完整结果：卦象及其下方的“AI 自照”。只分享上半部会丢失四时、
起居、情志和当日小行动的生活分析，与“分享结果”的用户预期不符。

直接公开会话详情仍然不可接受：其中包含用户关注点、追问、会话标识和其他不必要的元数据。因此需要一个比“全部私有”更实用、
又比“整个会话公开”更小的投影边界。

## 决策

- 继续使用 ADR-060 的不可猜测、持久化分享凭据，不新增可枚举路径，也不公开成员或存档标识。
- 公开 DTO 新增可空字段 `interpretation`，仅读取卦象存档绑定会话中当前最新的一条 `assistant` 消息。
- 读取前同时校验会话归属与卦象成员一致。会话缺失、归属不符或尚无成功 AI 回复时返回 null，不降级为用户消息或静态演示文案。
- 不返回 `user` 消息、关注点原文、会话 id、消息 id、标题或完整历史。AI 回复可能基于成员主动提供的生活上下文，页面在分享操作旁明确告知。
- 分享链接继续是实时投影；成员在该卦会话中继续得到 AI 回复后，同一链接展示新的最新自照。私有页和分享页都以“最新一条”为准。
- 前端复用 `renderMarkdown` 的 DOMPurify 白名单渲染 AI 内容，不把服务端 Markdown 直接作为未净化 HTML 执行。

## 结果

- 收到链接的人可以看到与分享者当前页面一致的卦象和最新 AI 自照，生活分析不再丢失。
- 公开数据面扩展到一条 AI 输出，但仍通过归属校验和专用 DTO 排除用户输入、完整对话及身份信息。
- 链接持有者会看到后续更新的最新自照；如果以后需要快照、撤销或按消息挑选分享，必须单独设计持久化和授权语义。
