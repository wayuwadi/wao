# ADR-182：个人决策管理复用统一记忆的确认决策

- 状态：已接受
- 日期：2026-08-31

## 背景

用户会从一次具体经历中得到“下次遇到相似情境应该怎么选”的结论。例如夜间火车与傍晚高铁都能到达武汉，
但等待与跨夜行程会额外消耗精力。普通任务适合跟踪要做的事，普通笔记能保存原始经历，却都不能让这类已经
确认的选择原则形成易找、易改且能被个人 AI 上下文召回的长期记录。

统一记忆已经按账号隔离个人 `decision` 分类，支持版本、冲突检查、废止、检索和 MCP 召回。另建决策表会让同一
结论在决策页与记忆中心形成两个权威来源，也会要求额外同步生命周期。

## 决策

- 新增“决策管理”个人导航与专用页面，底层只读写统一记忆中当前账号的 `personal / decision` 数据，不新增重复表。
- 录入按“决策标题、适用情境、具体决定、原因”组织；正文保存为带中文标题的普通 Markdown，使记忆中心和 MCP
  无需专用解析也能直接阅读。历史自由正文在决策页按“具体决定”兼容展示。
- 新增和编辑继续使用统一记忆的立即发布与 `baseRevisionId` 并发检查；409 或网络失败时保留页面输入和本机草稿。
- “废止”沿用统一记忆的归档语义：历史版本保留，但默认列表和 AI 检索不再返回。
- 本轮不根据一段经历自动生成或替用户确认决策。没有可靠规则能证明模型推断符合本人意图，决策内容必须由用户填写。

## 后果

- 用户可从“个人 → 决策管理”直接维护选择原则，并在记忆中心核对完整版本历史。
- 决策仍受现有个人账号隔离、版本审计与 MCP 权限保护，不增加数据迁移和双写故障面。
- 结构化 Markdown 是可逆的展示约定；未来若需要提醒、复盘或失效条件，可基于真实使用再扩展独立字段。
