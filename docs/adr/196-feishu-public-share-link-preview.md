# ADR-196：飞书链接预览复用公开分享投影与统一事件回调

- 状态：已接受
- 日期：2026-09-03

## 背景

WAO 已为任务、子任务、文档、小记和“天人一卦”提供公开只读分享链接，但链接粘贴到飞书后只显示 URL。
飞书的链接预览能力不是网页 Open Graph 抓取：正式发布的飞书应用需要注册 URL 规则，并把
`url.preview.get` 回调发送给业务服务，业务服务须在 3 秒内返回内联标题和可选卡片。

为预览另建一份内容模型会让分享页与飞书卡片出现字段、权限和实时状态漂移；从私有业务接口拼预览还会扩大回调的
数据权限。WAO 已有的公开分享投影正好定义了链接持有者可以看到的内容边界。

## 决策

- 继续复用公开的 `/api/feishu/events` 作为 `url.preview.get` 回调入口，沿用同一套 Verification Token /
  Encrypt Key 校验，不新增回调密钥或免登录端点。
- 只识别当前请求站点下的 `/s/t/**`、`/s/d/**`、`/s/tianren/**` 及其任务/文档 Markdown 直读地址；
  外域、非 HTTP(S)、带用户信息、端口不一致和其他路径一律返回空对象，不读取业务数据。
- 任务、子任务、文档、小记和卦象预览只调用现有公开投影服务。卡片不出现负责人、成员、评论、活动、关注点、
  私有会话或完整 AI 历史，权限边界与原分享链接完全一致。
- 响应同时提供带内容类型的内联标题与 `raw` 只读卡片。卡片展示少量关键事实和经过纯文本化、限长的摘要，
  唯一操作是打开触发预览的原链接；不提供会改变 WAO 数据的按钮。
- 不存在、已撤销或不受支持的链接降级为空对象；不得把错误消息、内部 id 或堆栈变成公开预览，也不得阻断
  既有群消息、卡片回传和表情事件处理。
- 飞书开放平台使用两条范围规则 `wao.wayuwa.cn/s/**` 与 `wao.wayuwa.cn/api/share/**`，订阅
  `url.preview.get` 到既有回调地址并发布正式应用。该平台配置是能力生效的必要部署步骤。

## 后果

- 飞书成员无需打开链接即可识别分享类型、标题和关键摘要，并能从卡片直接进入同一公开链接。
- 预览是实时投影；任务状态、文档正文或最新公开自照变化后，再次触发预览会读取新内容，不提供快照语义。
- 热点链接会把读取流量带到现有公开服务。当前实现不调用模型或外部 API，并对文本严格限长；若规模接近飞书建议的
  并发阈值，再单独增加短时缓存与限流，不能用过期演示数据兜底。
