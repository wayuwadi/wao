# ADR-331：WAO 自主建设协调器与关键节点工作台

- 状态：已接受
- 日期：2026-10-07
- 依据：用户小记「我想自动化」及当前会话确认「自主闭环：小改动自动交付，大事飞书确认」「关键节点工作台」，追加要求连接首页、看板与小人。

按功能持续审视真实问题，三种方案首项推荐；没有证据就收口为无改动，不制造优化任务。服务端持久化成员隔离的策略、运行、Agent、决定与交付证据，专用 Windows Codex 执行器使用独立仓库和任务 worktree。审视只读，实现按冻结文件范围拆分独立 Agent，依赖排序、重叠范围串行。数据库租约限制跨实例并行，过期执行器不能回写；离线保留队列，副作用中断后先核对已有工作与 PR、发布证据。

这项新的显式开发协调能力替代此前“不新增自主代码派工”的产品限制；不恢复退役 Runner / AI Run 接口，其 410、业务只读 Codex、原 MCP 令牌权限及浏览器单客户端范围继续有效。只允许显式配置的 WAO 仓库、成员及本机现有 ChatGPT 登录，不向业务服务或旧 token 下发 shell 和凭据。

小改动按推荐方案实现、验证、一个需求一个 PR、既有授权通道合并与发布。产品方向、权限、数据删除、凭据、技术栈、迁移、部署配置和宽泛目录范围等大事先保存决定，释放执行槽。飞书用既有加密应用配置投递本人卡片，应用、消息、本人身份、运行、方案版本、期限必须匹配；明确按钮或回复具体消息“确认/确认继续”才续跑，“退回：理由”暂停；含糊同意不批准。决定与续跑在同一事务内，重复事件不重复执行。

验证与发布分开，提交冻结；无法完成真实浏览器/既有数据库验收时不合并。公网终态独立核对 PR 合并 SHA、前后端版本覆盖、静态入口和就绪。发布或进程失败保留工作区与证据，不以模型声称成功替代真实发布。任务最终验收仍属于用户。

首页采用轻量入口，看板采用真实状态汇总，小人的当前任务链接进入同一个关键节点工作台。数字头像仅呈现身份；头像绑定不能授予代码执行权限。原型模拟任务不得进入业务列表。

规格：[自主建设](../specs/autonomous-development.md)。
