# 六个休息世界与伙伴游戏本地验收

需求开始于 2026-10-02，验收完成于 2026-10-03。同步基线 `f6444221`，独立工作区与分支 `codex/breathe-play-worlds`，未覆盖其他任务改动。

## 实现

- 顶部六种风格自由切换，保留呼吸、静坐、登录和工作区入口；原有五个 SVG 角色恢复鲜明颜色，并进入各自场景。
- 六种玩法分别是动作记忆、物理摆放、箭头路线、五角色平台冒险、手账创作、光影拼图；共用按访客/成员隔离的本机进度。
- 进入游戏暂停呼吸；切换风格保留计时器；游戏在后台和认证弹窗开启时暂停。存档支持自动保存、失败重试、损坏保护、跨标签页冲突选择。
- 手账支持贴纸、绘线、文字和独立 SVG 导出；导出文字经过 XML 转义，图片内嵌。浏览器未自动下载时有可重试链接。
- 修复原登录弹窗 `:global` 选择器误将深色背景应用到整页的问题，恢复浅色场景对比度。
- 不新增依赖、不改变 API、MCP、CLI、数据库和部署流程。

## 自动化

- 11 个相关测试文件、58 项通过：`relaxWorlds`、`relaxProgress`、`relaxGames`、`relaxLoop`、`LoginView`、`HomeBreathingStage`、`PublicBreathing`、`breathingSession`、`breathingAuth`、`breathingCallback`、`breathingRoutes`。包含手账写满绘线后的完整存档恢复。
- 平台冒险组件使用真实组件按键事件及逐帧物理推进，依次使用五种技能、收集五枚贴纸并抵达终点。不是直接写入通关状态。
- 验证动作接力暂停、重放、错误重试及正确顺序过关；存档失败、损坏、换号和跨标签页不覆盖；动画后台取消与恢复不补跑。
- 导出 SVG 的 XML 可解析，文字正确转义，包含独立图片与下载链接。
- `vue-tsc --build`、修改文件 ESLint、Vite 生产构建通过。构建仍有项目原有的大于 500 kB 分块提示；未运行无关全量测试。
- 工程一致性检查无错误；保留基线已有的 5 个 ADR 重号警告。本次没有新增 ADR 或迁移文件。

## 浏览器操作

本地 `127.0.0.1:5258/breathe` 与隔离访客存储的 `localhost:5258/breathe`，通过项目既有验收代理连接 `127.0.0.1:18080` 真实业务服务，无模拟业务响应。复用当前已有服务和数据库，不新建或修改数据库；现有环境记录说明它与 Windows 临时公网实例共用数据库，不将本轮描述为原 Linux2 生产库复验。

- 既有会话显示真实工作区入口；访客显示登录入口，真实登录弹窗可打开及关闭。未重新完成真实账号登录、跨账号登录或 OAuth 成功往返；这些原有流程由本轮相关单元回归覆盖，不能替代真实往返验收。
- 记忆接力：观察页面实际动作顺序并点击回应，出现“接力成功”，最佳记录更新。
- 物理摆放：拖动伙伴、旋转与重力落下；提供键盘选择和挪动。
- 环游小队：逐格旋转首关路线、发射，真实页面显示到家及下一关。
- 平台冒险：浏览器验证角色切换、照明、跳跃和冲刺；全路线通关由上述组件物理测试覆盖，未将其写成真人浏览器全程通关。
- 手账：添加与旋转贴纸、键盘挪动、输入文字、切换风格和刷新恢复。实际下载的 SVG 文件包含该文字和内嵌角色图片，PowerShell XML 解析通过。浏览器工具的下载事件等待超时，但本机文件实际已生成，使用实际文件验收。
- 光影拼图：调节首关灯光与角色角度，显示“影子重合了”和作品完成。
- 呼吸：启动一分钟练习，换风格仍为运行状态；进入游戏再返回显示“已暂停”与“继续呼吸”，进度保留。
- 360×780 下逐一检查六种休息场景及六款游戏，无横向内容溢出；完成后恢复默认视口。未使用实体手机验收。
- 最终访客页面未捕获控制台错误。

所有游戏进度仅在当前浏览器保存，不提供云端或跨设备同步。合并即结束本轮交付，不等待 Jenkins，不宣称已上线。
