# 首页十五秒活动验收

本地真实链路：`http://127.0.0.1:5255/`，正常登录既有开发账号，经既有 Windows1 后端读取真实数据；本次无需创建业务验收记录。

- 首页两个常驻入口及三个思考、记录菜单项已移除，旧草稿数据不清理。
- 四人抛球、芭蕾、街舞、接龙、伸展、转圈可从伙伴菜单启动；芭蕾实测超过 15 秒归位，其他活动共用同一截止逻辑。
- Enter、Shift+F10 打开菜单，Esc 收起活动；活动切换不叠加。
- 390px 窄屏菜单和角色可达，无横向溢出；恢复桌面尺寸后沿用主线并排布局。
- 修复聚焦底部角色引发隐藏容器滚动的截断：可点击区域始终限制于可见画布，活动时跟随实际位置。
- 10 个相关测试文件共 42 项通过；生产构建及类型检查通过。工程一致性检查无新增错误，5 个已有 ADR 重号告警保持原状。
- 物理触屏、低性能设备帧率未覆盖。同步主线时的 Vite 临时重载日志不作为运行期错误，刷新后继续完成验收。

复验：运行规格中的 Vitest 命令和 `npm run build`，再在正常登录的首页点击任一伙伴，依次启动活动；等待 15 秒检查归位，尝试 Esc、拖动和窗口缩窄。角色没有肢体，芭蕾与街舞采用旋转、踮跳、压拍的风格化动作。
