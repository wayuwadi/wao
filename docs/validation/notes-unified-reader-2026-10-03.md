## 真实浏览器步骤

沿用现有本机业务服务与独立开发库，通过 `wao-web/scripts/acceptance/serve.mjs` 代理进入本地前端；未创建数据库、未执行迁移、未调用 AI、未恢复旧 Runner。浏览器使用本机开发账号，读取既有验收小记及其他作者的小记，不修改其正文。

1. 桌面默认卡片的预览组透明度为 0；悬浮或键盘聚焦后变为 1。点击预览进入只读侧栏，点击方式菜单可直接进入另一布局。
2. 工具栏“阅读模式”延续选中的文章及布局。筛选为一条记录时目录仅一篇，首末篇翻页按钮不可用。
3. 新建区域输入本轮专用草稿，打开、切换和关闭阅读器后正文保持；关闭后焦点回到预览按钮。验收后清空本轮专用草稿，未保存新业务数据。
4. 他人小记为 `contenteditable=false`，图片在原文位置显示；放大图片后 Esc 只关闭图片，阅读器仍保留且焦点回到关闭按钮。
5. 390 像素宽度下长文滚动至 554 像素，翻到下一篇再返回，恢复为 554；切换布局保留当前段落。
6. 320、390 与 1440 像素宽度检查：无横向溢出，长标题换行、按钮可见；手机目录可展开及 Esc 收起，放大到桌面后正文可操作。
7. 保留单击全文展开和双击原地编辑，不由预览触发保存请求。

窄屏菜单曾因页面滚动提前关闭，已改为按钮锚点随滚动重定位，并在真实浏览器复验通过。图片 Esc 与焦点返回同时验证。

私有证据位于本机 `wao-evidence/notes-ai-20261003/unified-reader/`，截图与精确记录 ID 不提交 Git。组件测试使用明确的合成数据，不替代上述真实链路。

未验证：真实触摸硬件、屏幕阅读器。触摸入口由媒体查询保证可见，桌面浏览器窄屏验收不等同于触摸硬件验收。发布状态记录在共享发布协调记录及本机 handoff 中，合并不等同于上线。
