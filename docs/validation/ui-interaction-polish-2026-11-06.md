# 手机阅读与常用操作验收

本轮以维护仓库 `wayuwadi/wao` 的 `9a6b8605` 为基线。优化针对实际路由中的知识库工作区、资源库、日历、待办、功能目录、习惯和倒数日；退役的项目页和旧知识库首页不计入交付。

## 行为与真实链路

- 资源库按文件、图片、网页分别搜索，匹配展示名、原名、来源和关联项目；用户输入重置分页，切换账号恢复搜索时保留该账号页码。真实文件改名成功后显示已保存，焦点回到改名入口；等待时移向其他输入框不会被迟到回执抢回。
- 图床第二页开始搜索回到匹配结果；图片按钮可用 Enter 打开预览，Escape 关闭后返回原入口。手机分页保留当前页、前后翻页和跳页，320／390px 无页面横向溢出。
- 托管 HTML 使用固定底栏的公共弹窗。真实 API 拒绝无效链接后，名称和所选 HTML 保留；修正链接重试成功，页面出现在托管列表。320×480 的底栏保持可见。
- 知识库手机首页正文全宽，清单和目录按需打开；文档目录与大纲默认收起。父子抽屉互斥，选择与 Escape 关闭恢复入口焦点；隐藏页签和切换账号清理临时面板。桌面偏好独立保存，正文编辑器保持挂载。
- 对单个本地验收文档注入有期限的保存失败：输入正文、打开与关闭目录及清单后草稿仍在；解除故障后原位重试，刷新并通过 API 重新读取，确认正文已持久化。故障配置已清除。正文工具栏提供可读名称与按下状态，实际加粗操作与状态一致。
- 日历有明确的新建入口，沿当前所选日期创建；手机工具栏三行排列，日期和“今天”不折行，日视图不再横向撑宽。创建类型弹窗可用 Escape 返回新建入口。
- 待办真实快速创建成功后清空输入并恢复焦点；从带 `date` 的每日回顾转到“所有”，地址变为 `scope=all`，刷新不回跳。输入法、失败后改标题重试、同任务 ID、异步焦点与账号切换由组件及真实 router 回归覆盖。
- 功能目录搜索跨分类时明确显示范围；打开日历再返回保留关键词，清空后回到此前分类。习惯实际新增成功；全局每周起始日改为周日后，月历按周日排列。习惯和倒数日筛选无结果均可清除恢复。
- 设置搜索补齐每周起始日、布局和控件风格；中文 Escape 不清除关键词，清除操作恢复输入焦点。

浏览器验收连接本机隔离 MySQL 与 Spring Boot，使用独立验收账号和真实 HTTP 保存；未操作生产用户任务。截图和包含会话信息的本机运行资料留在仓库外。

## 自动化验证边界

整合相关测试及公共弹窗调用方共 71 个文件、936 项：918 项通过，18 项失败与未修改基线逐项相同，新增／修改测试均通过。失败涉及既有旧项目页、Notes 等断言；本轮不宣称全仓测试全部通过，也未为通过检查而修改这些旧断言。

此前更广检查为 392 个文件、2578 项，49 项失败中 45 项在未修改基线精确复现，其余 4 项已通过修正或独立重跑消除。该历史扫描用于定位问题，不代替最终相关测试。

代码冻结后，对全部新增／修改测试文件重跑：21 个文件、406 项全部通过，包含最新的功能目录读取失败后页码恢复回归。稳定性专项 6 个文件、49 项通过；编辑器 150 项通过；更新说明生成与绑定 13 项通过。Windows 发布输入检查通过。

UI 增量规范使用实际维护基线 `delivery/main`；本机 `origin` 是历史仓库，不作为发布基线。设置 `WAO_CHANGE_BASE=delivery/main` 后执行 `npm run build`，类型检查、UI 规范和生产构建均通过；保留既有大资源块体积提示。必需 CI 与线上实际版本另在 PR 和交付记录核对，本文件不以合并状态代替发布验证。
