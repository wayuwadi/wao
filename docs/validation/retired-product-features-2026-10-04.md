# 本批次功能下线本地验收

范围与存续边界见 [ADR-319](../adr/319-retire-reviews-reports-and-obsolete-settings.md)。

- 前端 10 个相关测试文件、81 项测试通过：导航与旧路由、个人布局、历史页签恢复、全局搜索、通知中心、设置草稿与失败重试、组织成员、更新介绍及每日提醒。
- 后端 111 项相关测试通过：退役 HTTP 方法与未知子路径、历史通知开关失效、断网窗口不再限制调度、菜单注册、AI 助手与自动任务、通知中心及 Flyway migration 一致性。
- `npm run build` 与 TypeScript 检查通过；构建保留现有大包体提示。
- 本地服务以 `local-cloud` 连接既有数据库；不执行 Flyway、不注册服务发现、不启用共享调度。浏览器通知设置读到既有每日提醒与项目配置，四项 AI Run 开关与三项退役设置入口不再显示。
- 本地真实服务复验五类退役 API 的 GET、POST、PUT、DELETE 共 20 个请求，全部返回 HTTP 410；未知旧点子子路径同样拒绝，不再返回路由匹配异常。
- 浏览器点击离开未保存通知草稿后出现确认框；浏览器工具被此确认框阻塞，未完成取消后的路由切换复验与真实保存。未修改真实通知开关、发送通知或删除数据；草稿保护、保存失败与重试已有前端回归覆盖。
- 工程一致性检查通过，没有新增 ADR/Flyway 冲突；保留基线已有五组 ADR 重号警告（23、152、172、187、278）。`git diff --check` 通过。

合并即本次交付；不将合并表述为上线，发布后的验收由用户负责。
