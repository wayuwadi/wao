# 休息旅程视觉打磨验收

## 构建

- `cd wao-web && npm run build`：通过，包含 `vue-tsc --build` 和 Vite production build。

## 浏览器画面

- 本地生产预览 1280×720：休息选择、标题、伙伴及底部操作都在当前视口内；页面宽度没有横向溢出。
- 本地生产预览 320×740：两个休息选项、伙伴、顶部导航和底部操作均完整可见；文档宽度等于视口宽度。
- 选择「留下来，呼吸一会儿」后：呼吸 / 静坐、时长和主动开始按钮可见；用户需点击开始才进入计时，验收期间未启动练习。
- 头像、草地与水色地面、按钮图标的层次在生产预览中可见；微风装饰减少动态效果时按媒体偏好停止。

## 范围

仅更新浏览器端视觉和发布介绍，无后端、接口、数据库或部署配置变更。
