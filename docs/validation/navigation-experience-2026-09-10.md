- 前端全量：整合主分支客户端修复后，167 个测试文件、960 项全部通过。
- 生产构建与类型检查：`npm run build` 通过；改动文件 ESLint 通过。
- 未登录接口检查：本地 `/api/navigation/layout` 返回 HTTP 401，未回退其他成员。
- 后端：NavigationLayoutServiceTest（8 项通过） 覆盖成员隔离、首次保存保留字段、并发及首次插入竞争、损坏布局、非法分组／位置、响应丢失后的幂等重试，以及通用偏好接口禁止绕过版本校验。
- 新增目录测试：搜索展开匹配文件夹，定位当前文档，非拖拽移动仍使用原排序接口，文档编辑内容保持。
