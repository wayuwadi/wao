## 已实现

- `/breathe` 公共入口与 `/login` 兼容路由，已登录同样可停留；单一登录弹窗与工作区“休息一下”。
- 静默、呼吸、静坐；1/5/15/30 分钟与自定义；绝对时间计时、暂停/继续、切换确认、主动/自然结束、结束后留在空间或进入工作区。
- 登录打开即暂停；邮箱失败保留草稿；飞书离站快照以 OAuth state 绑定、10 分钟有效、一次性消费并恢复为暂停。访客偏好与成员旧键隔离，恢复练习不写回个人偏好。
- 公开认证不再自动读取成员目录。工作区显式加载目录，公开页只使用会话识别与公开备案接口。
- 全站主题、静音、减少动态效果、设置收纳、轻量伙伴及真实备案。横屏采用左右布局，原生登录弹窗按 visualViewport 定位并可滚动。

## 亲自操作浏览器的证据

开发入口 `http://127.0.0.1:5246/breathe`；无热更新的生产构建预览 `http://localhost:5247/breathe`。两者代理本机既有 `18080` 业务服务，不是静态 Demo 或模拟业务响应。

- 未登录完整一分钟呼吸自然结束；未登录一分钟静坐自然结束，静坐不展示吸呼指令。
- 暂停后等待及登录失败、关闭重开均保持 `00:59`，由用户主动继续；主题切换不重置练习。
- 运行中切换模式显示确认，取消后保持暂停；主动结束及自然结束均显示两个后续选择。
- 登录失败来自真实后端错误“邮箱或密码不正确”；测试使用不存在的输入，没有修改现有账号或密码。关闭重开保留本页输入，焦点返回登录按钮。
- 既有登录会话可以进入工作区，再从“休息一下”回到公开空间。
- 桌面 1280×720、手机 390×844/320×568、横屏 844×390 检查。横屏问题经修正后页面高度为 390，主按钮下缘为 238；320 窄屏主操作可见，页尾可滚动查看，无横向内容溢出。
- 390×340 受限视口模拟软键盘占用：登录 dialog 顶部 12、底部 328、可见高度 314，内容高度 564；可滚动且键盘能到达提交及切换按钮。未在实体手机上弹出系统软键盘。
- 仅记录方法与路径的本地代理证据：访客静坐及既有登录用户公开停留时，只有 `/api/auth/session` 和 `/api/public/site-info`；打开认证后增加 `/api/auth/feishu/authorize`。未记录 Cookie、密码、请求体或查询参数；没有成员、任务、AI Run、额度请求。
- 减少动态效果、音频不可用、卸载清理与跨账号偏好使用单元测试验证；真实跨账号登录和真实 OAuth 往返未通过验收，不能以测试模拟替代。
