## 边界

验证范围是测试工具和既有服务的只读调用。没有修改业务逻辑、数据库结构、部署配置，也没有进行 HTTP 压测、生产容量评估或发布后验收。首轮开发过程中曾因 MyBatis 独立配置缺少 `DbConfig` 失败，补全后两轮真实采样通过；不把失败轮次纳入基准。
