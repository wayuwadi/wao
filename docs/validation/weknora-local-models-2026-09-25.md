# WeKnora 本地模型与薇娜拉验收（2026-09-25）

## 实机结果

- Mac M5 Pro、64 GB 内存运行 Ollama；Qwen3 4B Instruct 用于中文问答，BGE-M3 用于 1024 维向量。Ollama 监听本机回环地址，经 SSH 反向隧道和 Linux2 的 Docker 网关转发供 WeKnora 使用。
- WAO 可同步的 869 篇文档全部有成功映射，覆盖「小记」111 篇及其他知识库文档；对应的 2065 个 WeKnora 分段文档均有 1024 维向量，解析失败数为 0。完整库另外有 66 个早期非文档模块副本不在本次文档重解析范围内。
- 「薇娜拉 · 知识库与小记」派生库包含 128 个非 Codex 工作记录的原始文档副本，128 个均有 1024 维向量。重复运行镜像检查结果为新增 0、更新 0、跳过 128、移除 0。
- 薇娜拉选定派生库、禁用联网搜索。WeKnora 实际问答分别对小记的四步流程和 English 知识库第一天安排返回中文答案，并引用各自原始文档的派生副本；副本正文保留 WAO 原文链接。
- 本机模型管理页 HTTP 返回 200，能显示 Ollama、隧道和模型状态；每小时维护 LaunchAgent 的实机启动结果为退出码 0，日志记录失败嵌入重试 0 及派生库跳过 128。

## 边界

- WeKnora 的 Wiki 和摘要后台任务仍可能显示 `finalizing`；上述验收核对的是已入库向量和带引用的实际问答，不把传输成功等同于 Wiki 完成。
- Mac 关机、休眠或断网时无法提供本地模型。维护任务仅验证过在线无变化路径；离线后失败任务的实际恢复留待故障场景观察。
- 已验证本机管理页及 WeKnora API 问答；WAO 嵌入页面的浏览器手动点击链路此次未完成验收。
