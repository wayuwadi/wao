# 侧边入口数量验收

2026-10-14，本地隔离应用仅监听 127.0.0.1，关闭迁移和本地后台调度，直接连接既有数据库；使用专属临时成员。与同机并行验收分开端口及浏览器域名，不修改其他成员的状态。

- 三个受影响测试文件 28 项通过；类型、UI 增量规范、静态构建通过。读取中／错误不报零、重试零状态、迟到响应、日期隔离、数量更新不展开和全部记录统计由回归测试覆盖。
- 日常规则通过真实 API 创建五项：早晚合计三项 OPEN、一项 DONE、一项 SKIPPED，收起入口显示剩余 3。浏览器完成一项后 2、跳过另一项后 1、分别恢复后 3；使用保存确认后读取的数据。
- 临时成员持久化四条当天与一条明天小记作为数量夹具（SQL 写入仅限本次临时成员，不触发夹具 AI）；前三条预览与全部条数区分。浏览器真实保存另一条小记后，当天入口从 4 更新为 5；切到明天显示 1，回到今天恢复 5，侧边仍默认收起。
- 保存前关闭临时成员的自动标题／润色／配图／思考图；自动标签继续沿用已有保存流程，记录其关联任务终态后再清理，不宣称完全禁用模型调用。
- 桌面明亮／深色和 390px 窄屏视觉通过，窄屏文档宽度与滚动宽度均为 390px。入口可用 Enter 打开、Esc 收起，数量提示可读。界面与 `/design` 演示同步复用主题 token。
- 工程一致性无新增错误；原有五组 ADR 重号警告保留，没有新增或修改数据库 migration。

公网版本与资源合并后单独核对；实体设备最终体验由用户验收。
