# 阶段 A 设计预览验收：A2

日期：2026-10-03（北京时间）。本报告只证明设计预览可操作，不是任何一款正式游戏的玩法、存档或发布验收。

## 交付边界

- 本机地址 `http://127.0.0.1:5268/`，`wao-game/demos/serve.mjs` 只绑定回环地址，只提供本次预览，不代理业务接口。
- 新增纯呼吸首页，七个游戏依次红橙黄绿青蓝紫；六种旧风格在游戏页构图菜单保留，静坐放在次级入口，不放进纯呼吸首页。
- 七种美术构图、游戏内面板、首发范围、触屏控件位置、暂停/沉浸/返回、示例记忆文件流程可交互。
- Canvas 场景为原创示意，HUD均标示例，没有正式物理/战斗/驾驶循环；触屏按钮明确标为布局预览。
- Demo 使用 `wao:design-preview:a1` 独立命名空间，A2 保留 v1 示例选择兼容；没有读取、删除或迁移旧游戏档。真实游戏记忆方案另见规格，尚未实现。

## 实际浏览器操作

在 Codex 浏览器中完成以下步骤，截图和观察文件见 `assets/seven-games-design-a2/`。A1阶段的保存验证原始证据保留在 `assets/seven-games-design-a1/`，不可误作当前A2外观。

1. A2 首页默认只有呼吸内容与轻量导航；点击开始显示“吸气”，暂停显示“已暂停”；切游戏后隐藏呼吸，返回首页保留可继续入口。
2. 七游戏逐项切换，核对游戏名称、颜色文本、实际页面CSS主色和背景色；结果 `rainbow-checks.json`。不只核对入口圆点。
3. 游戏页切换到涂鸦手账构图，恐龙主色仍为红色 `#f8a79b`，没有误切到蓝色游戏。
4. 桌面七画面逐项截图；390px容器中七个视图的可见按钮、select、标题均未超出容器，核心触屏布局按钮高度均为44px，结果 `mobile-layout.json`。检查呼吸首页的窄屏布局。
5. 操作沉浸→暂停→继续→退出→返回呼吸；场景面板始终在页面内，不导航到其他站点。该测试覆盖设计流程，不证明正式游戏停止了尚未实现的循环。
6. A1实测：选择恐龙里程挑战→启用本机保存→刷新→面板仍选择里程挑战。切仅本次不删除已有本机档。
7. A1实测导出全部生成 `C:/Users/wage/Downloads/wao-demo-all.json`（549字节，7个游戏示例选择）。浏览器下载事件等待超时，但实际文件存在，读取内容并用上传控件重新导入验证，没有把超时当作成功证据。
8. 在 `localhost:5268` 独立来源存储环境导入该真实文件，先显示7游戏/时间/选项，再“备份并恢复”；恐龙从默认无尽变成里程挑战。恢复覆盖前备份后重新变回无尽。这里恢复的是Demo选择，不是游戏续玩。
9. 导入3份真实错误文件：JSON损坏、formatVersion=99、choice=900；均停留在导入界面报错，未改变原选择，结果 `assets/seven-games-design-a1/invalid-imports.json`。A2进一步回归同一个正常v1文件，导入预览正确，点击取消返回记忆中心而不覆盖。
10. 同源第二标签页修改已持久化选择，原页提示“另一页已有修改”，记忆中心出现“读取另一页记忆”，没有静默刷新本页选择。截图 `assets/seven-games-design-a1/cross-tab-conflict.png`。
11. A2 浏览器工具捕获的控制台 error 列表为空。

## 未验证与未实现

- 七款正式核心玩法、胜败成长、真实游戏存档、跨设备续玩、规则迁移、并发原子事务、配额失败恢复均尚未实现，不能沿用Demo的通过结果。
- 本轮窄屏是390px响应式容器。浏览器viewport覆盖调用未改变实际1280px视口时已读取宽度识别，未写成390px真实浏览器视口或实体手机验收；正式开发需补真实360px视口与触屏设备链路。
- 尚未注入真实存储配额失败或同时事务竞态；Demo的localStorage通知不是正式IndexedDB原子存档方案。
- 尚未测量主站拆分前后构建时间、发布耗时、初始加载体积；第一款工程拆分实施时采集同基线数据，不提前宣称提速。
- 当前发布器尚不支持游戏catalog独立原子激活；发布通道适配与回滚测试是第一款正式上线前的明确门槛。
