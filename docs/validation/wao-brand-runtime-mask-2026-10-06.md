# WAO 单色标识发布路径验收

- 公网首次品牌发布核对发现 CSS mask 被改写为 `/releases/<SHA>/brand/`，该路径未在静态版本目录开放，呼吸页图形及背景纹样不可见。运行时主站路径修复避免扩大 Nginx 公开范围。
- 修改文件 ESLint、18 项呼吸页/公开呼吸/旅程回归测试及类型检查、生产构建通过；保留既有分包体积警告。
- 使用精确 `WAO_GIT_SHA` 构建检查：生成 CSS 不含版本目录的品牌资源引用，运行时 JS 保留主站 `/brand/` 地址。
- `127.0.0.1:5281/breathe` 从生产 dist 验收，版本目录仅提供 assets，品牌资源只在根 `/brand/` 提供：左上角单色标识、固定字标和右下背景柔环均实际可见，计算样式指向主站资源，1280×720 无横向溢出。
- 公网修复版继续在发布后独立核对精确版本、品牌文件摘要、服务就绪、首页和呼吸页截图；不以此前未显示图形的发布作为完成证明。
