# 待办视图与收集箱验收

最终基线为主分支 `935ca9fa`，包含「今天」父子任务层级修复、任务搜索和当前清单已完成筛选。本次四项需求在 `codex/todo-view-preferences` 分支实现，本文记录本地验收，不代表已发布。

## 已验证行为

- 列表、看板、横向时间线复用同一授权数据，保留四象限。看板能将任务拖入常用状态列，保存后重新读取一致。
- 时间线分别展示执行区间和截止标记；无日期任务仍可见，可切换日期范围。多日任务不会把午夜结束算入下一天。
- 分组与排序独立配置，优先级支持两个方向；「今天」继续按日期组保留父子层级、折叠、上下文和真实计数。
- 显示已完成、显示详细、任务时间／倒数日、侧边栏／弹窗均影响实际页面。详情中的收集箱入口可以返回收集箱。
- 首次偏好读取未完成或失败时，视图设置不能用默认值覆盖账号选择；重试读取或恢复未同步选择的保存成功后可继续操作。列表、看板与时间线保留搜索和当前范围已完成筛选。
- 两个独立浏览器会话登录同一个测试账号：同步开启时读取相同视图；关闭后，新选择只留在对应浏览器，刷新后恢复，账号原视图未被改写。
- 汇总快速添加、全局新建未指定清单时，服务器保存为空项目、当前成员负责，刷新后出现在收集箱。清单内快速添加保存到该清单。
- `POST /api/tasks` 可省略清单；个人收集箱不派发项目任务活动通知。失效的显式清单保留选择与草稿，不静默改投。
