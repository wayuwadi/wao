## 真实浏览器

复用既有 `local-cloud` 业务服务 `127.0.0.1:18080` 与实际小记，没有创建数据库或执行迁移。

1. 从四张图片的真实小记全屏阅读双击进入编辑，默认正文只有四个图号，右侧为四张图片。切换嵌入后四张原图在正文出现，切回引用后正文不显示图片。
2. 引用与图片双向定位、原图全屏、Esc 关闭并返回入口焦点通过；普通卡片编辑的图号右键保留尺寸、排版与复制菜单。
3. 嵌入模式刷新后自动恢复，再切换回引用。窄屏正文最大 650px，宽屏最大 1100px。
4. 在本轮新建的临时编辑草稿中粘贴一个既有图片引用，图片与图号立即从四个变为五个，两种模式切换保留五张图片和临时文字。
5. 对该单篇的 PATCH 请求启用本地验收故障，返回 503，未向后端写入测试修改；错误与重试入口可见，文字及图片继续保留。刷新重新打开后第五张图片仍恢复，证明草稿未丢失。
6. 通过不保存退出清理本轮临时草稿，原文恢复四张图片且没有临时标记；关闭本地故障模拟，重新进入显示已保存。
7. 390×844 与 390×420 检查无横向溢出、图片栏上下排列，保存按钮分别位于 831px / 407px，均在可见视口内。最后一次复验基于同步后的手机主干，不将窗口缩放称为真实手机软键盘验收。
