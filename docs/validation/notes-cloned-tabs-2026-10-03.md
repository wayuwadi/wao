# 复制页签草稿验收

开发基线 `50988b6dd8140bbefe7c4acb4c50d54bc964fcce`，独立修复复制 sessionStorage 导致草稿身份碰撞。

- 修复前克隆会话后分别输入，两边读取到后一份输入，新增回归失败；修复后保持各自正文。
- 4 个前端测试文件共 88 项通过，包含小记、新建弹窗、AI 草稿守卫与存储边界。覆盖复制前草稿继承、新建区草稿继承、刷新身份稳定、原页签清理不影响复制页签、存储失败不修改来源、不因刷新迁移而复活已保存草稿。
- 本地真实应用连接既有 Windows 临时数据库，使用专用合成小记。通过辅助入口点击打开复制窗口，分别输入 A2/B2，两个窗口刷新各自保留；原页签保存 A3，复制页签刷新仍保留未保存 B3；随后保存 B3，刷新读取一致。
- 显式连续保存采用用户已确认的最新输入更新规则，两次保存成功符合规格，不把它误报为冲突缺陷。
- 截图、精确标识、修复前后日志及清理结果存放本机证据目录，不提交业务 ID 或私有数据。

自动命令及人工浏览器步骤见 `docs/runbooks/notes-regression.md` 的“复制会话专项”。原生复制菜单、崩溃恢复、旧版与新版页面混用未实测，不扩展通过声明。
