# 小记自动已有标签本地验收

- 独立工作区基于 main；不混入其他工作区未提交的顺手发现改动。无数据库迁移、无新 CLI/MCP 权限。
- 前端小记、自动整理、顶栏与快速记录四文件 89 项通过；服务端持久整理、原稿、润色任务、设置、旧工作流、并发与 Flyway 七组 106 项通过。类型检查、生产构建通过。工程一致性零错误，五项历史 ADR 编号警告保持。
- 真实会话浏览器在本地前后端连接既有 MySQL；只登记一篇合成小记，并对这篇请求关闭标题、正文、图片，成员设置未改。保存信号与工作流投影使用连接内隔离表；模型任务及阶段尝试持久化到真实表。不启动其他小记的工作流。
- 浏览器保存后关闭页面，实际本机模型完成 NOTE_TAGS，服务端阶段 DONE/APPLIED。再次打开，读回相关已有标签及原手选标签；正文逐字一致，标签字典前后完全一致。成功阶段默认收起，检查其真实状态与重新打开后的标签，不能把隐藏的成功图标当作失败。
- 实际模型阶段完成后，本轮精确登记的合成小记移入可恢复回收站，未清空回收站；成员偏好未修改。测试覆盖模型返回未知/重复/已删除标签的过滤以及无字典、无相关标签跳过。
- 本地验收不代表线上发布验收。合并后线上体验由用户确认。
