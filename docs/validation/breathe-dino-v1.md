# 恐龙荒野首发验收记录

日期：2026-10-03。工作分支 `codex/seven-games-design`。依据已确认 A2、用户取消逐款 Demo 等待的最新指示及 `docs/specs/breathe-dino-runner.md`。本文件记录真实结果，不把模拟当作手操，不代表已合并或上线。

## 真实浏览器玩法与页面

- 六步练习：跳过三类仙人掌及低飞鸟，下蹲过中飞鸟，保持站立通过高飞鸟；实际6/6、283米、17.5秒。
- 1000米挑战：实际24障碍、41.8秒完成，包含394米、854米处暂停继续。使用原生鼠标持续按压长跳、页面蹲/起身控件和可见路况提示；未注入游戏状态。`sprint-browser-actions.json` 是界面操作记录；`sprint-browser-win.png/.txt` 是结算证据。
- 真实碰撞失败57米，另有166/168米仙人掌群失败；快速重开、换旅程、返回、音效开关均可操作。
- 呼吸/游戏切换销毁iframe；呼吸计时切走暂停，静坐次级入口可用。六种布局切换保持同一个游戏实例且失焦暂停。
- 沉浸退出原生点击复测：滚动144→144，页脚先恢复再滚回；记忆面板外导航、布局和游戏控件 inert，关闭返回控件。见 `immersion-scroll.json`、`immersion-restored.png`。
- 五款旧游戏分别操作技能、旋转/发射、枕头布局、影子滑杆、贴纸旋转；贴纸文字切换后保留，旧存档没有迁移或清空。见 `legacy-five-production.json`。
- 同源360px验收容器中真实视口clientWidth/scrollWidth均360，跳/蹲按钮162×56；通过练习前两障碍并暂停。实际窄视口，不是缩放截图；未用真实手机硬件。
- 生产构建预览控制台 error/warn为空。实际千米连续交互、暂停和触控有响应；未采集专用GPU/低端手机FPS，不把体积或构建速度当FPS。

## 真实记忆链路

- 自动保存最高分/局数/千米通关、刷新恢复。1000米通关后4局/1次，导出真实文件482字节；在 localhost 独立于127.0.0.1的浏览器存储域中预览、导入，再真正跑一局递增到5局，最高分/通关保留。
- 仅本次游玩局数3，刷新恢复本机局数2；主动导出可用。单款/全部入口都输出可再次导入的规则v1文件，目前正式注册只有恐龙。
- 覆盖预览取消保持原档，确认备份后可恢复；损坏JSON、规则99、负分与超过10MiB均拒绝，原局数不变。
- 两页冲突：本页2局草稿保留，另一页1局；读取预览取消不丢草稿，确认先事务备份2局再读取1局，随后从备份恢复2局。
- 存储配额/拒绝通过明确标注的开发故障注入入口验证，使用独立数据库：失败保留2/3局草稿，可导出、重试；解除注入后重试写入成功。这不是耗尽真实磁盘或修改浏览器权限。
