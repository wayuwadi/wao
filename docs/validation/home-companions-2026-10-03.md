# 首页四个伙伴验收

用户确认 Demo 的 A 底边布局后，独立接入实际首页。保留原有信息卡、天气、文案与导航，没有业务数据写入。

## 自动验证

- `companionScene.spec.ts`、`homeCompanions.spec.ts`、`HomeView.spec.ts`、`HomeOverviewCard.spec.ts`：4 文件、18 项通过。
- 覆盖窄屏横向边界、越界限制、高速释放后的弹簧收敛、后台时间跳跃、加载期间卸载、安静模式单帧、系统减少动态效果、KeepAlive 停用、观察器/帧/上下文释放、上下文丢失、静态降级和新画布重试。
- `npm.cmd run build`：类型和构建通过。场景独立延迟加载制品约 540 kB、gzip 137 kB；沿用已有 Three.js，不新增依赖。
- 工程一致性检查无新增错误；5 组历史 ADR 重号警告保留。无新 migration、ADR 编号或对外业务能力。

## 真实本地浏览器链路

- 使用既有正常登录、本机验收前端 5255 与既有后端 18080。首页读取真实卦象、Codex 信息和天气；没有替换成 Demo 数据。
- Enter 操作蓝色伙伴得到回应；拖动后显示「接住啦。」并回到原位置。
- 开启「安静陪伴」后按钮状态为开启，绿色伙伴仍可通过键盘回应，再唤醒恢复动作。
- 原有卦象预览成功打开并关闭；原有休息入口到达 `/breathe`，浏览器返回后四个角色恢复显示。
- 390 像素真实首页：四等分信息卡按原样换为 2×2，角色按钮宽约 82、高约 95 像素，四个角色均在视口内，保留原有底部导航。
- 桌面、窄屏截图存于忽略目录 `.local/core-acceptance/home-companions-*`，避免把实际账户信息放进版本库。

## 限制

没有实体手机触控/GPU 验收，未作跨设备帧率承诺。后台/上下文丢失通过回归验证，未在真实浏览器强制制造 GPU 故障。参考站的轮廓与毛绒效果被独立重建，不宣称逐像素复刻。

体验：首页底边轻点或拖动任一伙伴；悬浮/键盘聚焦伙伴区域后可切换安静模式，触屏入口始终可见。没有新增 AI 对话或后台智能体能力。
