# 首页日期轻提醒验收

本次范围为首页日期渠道、日历明确分类与渠道设置。原留白、四伙伴、天气、休息/写作入口和其他通知渠道保留。没有使用真实生日推测或修改个人重要日数据。

## 本地证据

- Vue 类型检查、改动文件 ESLint 和生产构建通过。
- 前端相关回归覆盖日期展示、未显示释放、确认失败重试、后台/编辑让位、上海跨日、真实来源定位、成员草稿恢复和设置冲突。
- 服务测试覆盖公历/农历、二十四节气、提前日与当天、来源关闭、过期租约、上海跨日、成员隔离、并发争取和设置条件保存；日历 HTTP 持久化与 Flyway 编号校验同时通过。
- 正常既有账号登录本地服务，连接既有 MySQL。日历、成员偏好和通知配置使用同一连接的临时表副本，测试生日与回执不进入持久表，关闭验收连接后自然释放；后台通知关闭。没有执行生产清理或改写已有 migration。
- MySQL 实际 HTTP 链路：未登录拒绝、关闭渠道后无候选、旧版本设置返回冲突、仅首页渠道的三天提前提醒、备注不泄露、八个并发请求仅一个获租约、错误 token 拒绝、展示和确认幂等、旧客户端修改保留生日配置。
- 浏览器实际创建本人生日并回到首页，出现局部祝福和小蛋糕；「看看日历」打开该事项及发生日，确认退场。设置开关通过实际 API 保存。320px 页面开关、保存操作及生日提示完整可见，文档没有横向溢出。

## 发布边界

V187 仅增加三个有兼容默认值的日历字段。公网发布需先核对唯一协调者、现有迁移校验与待执行集合，再通过既有通道发布后端和静态制品，并核对实际前后端版本、资源校验、就绪接口及首页/日历/设置。未在真实生日当天伪造公网提醒来代替验收。

实体手机、系统级减少动态效果及真实重要日长期使用由用户继续体验。模拟减少动画、并发和跨日测试不等同于实体设备验收。
