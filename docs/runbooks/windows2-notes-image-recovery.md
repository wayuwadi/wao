# Windows2 小记本人形象配图恢复

依据 ADR-306 和 [数字成员图库规格](../specs/digital-member-library.md)。Windows2 沿用服务账号已有的 ChatGPT 登录，通过本机 Codex 执行小记；旧 Runner 继续退役，不新增 API Key 或付费回退。

## 如何区分登录和参考图开关

`codex login status` 成功只说明 CLI 找到了登录。小记使用“本人默认”或已确认形象时，还需要主机显式开启 `wao.ai.local-notes.reference-images-enabled`。该开关默认关闭；缺失时页面提示“本机参考图生成尚未核验启用”，请求在实际生图前被拒绝。不要因此反复登录、清除认证缓存或删除用户图库。

先定位实际 Java 服务、附加配置文件、`CODEX_HOME` 与 Codex 版本指针，不能用 SSH 登录账号的默认目录代替服务运行环境。检查只输出启用状态、CLI 版本和登录方式；凭据、私有照片、提示词及完整环境不进入日志或 Git。

## 恢复步骤

1. 使用现有授权 SSH 通道。核对主机、服务进程归属、实际配置和版本指针；以服务账号的环境执行 `codex login status`。登录失效时通过官方登录流程恢复，不复制其他账号的缓存。
2. 按产品执行封装做真实合成文字调用，再做合成参考图调用：同一 CLI 和模型、只读沙箱、忽略用户配置和规则、禁用 shell、子代理及搜索，仅生图开启 `image_generation`。输入图片来自本次明确标识的合成材料。
3. 从 `thread.started` 对应的 `CODEX_HOME/generated_images/<threadId>` 核对本次 PNG 的签名、尺寸、大小和归属，并目视检查参考特征。模型说“生成成功”、CLI 返回 0 或开关存在均不能代替图片验收。
4. 通过后，在既有私有服务配置的 `wao.ai.local-notes` 下增加 `reference-images-enabled: true`，保留其他字段。比较修改前文件摘要，保留具有相同 ACL 的备份，原子替换；私有配置与备份不提交 Git。
5. 等待本机小记任务空闲，核对服务进程 ID、启动时间及活动制品摘要后，仅让所属后端重新加载配置。复用现有运行监督器，不重启 MySQL、网关、前端或 Codex 桌面会话，不新增计划任务。核对后端健康与公网 `/api/edge/ready`。
6. 浏览器刷新，配图形象设置应显示“本机参考图生成已启用”。用明确标识的验收小记验证本人默认形象的实际配图、正文保留、图片持久化和刷新恢复；结束后仅将该验收小记移入可恢复回收站。

原有失败阶段不会因配置恢复自动重做。对需要恢复的具体小记使用对应阶段的重试入口，不批量改写历史标题、正文、形象绑定或任务状态。

## 回退与后续发布

配置或调用失败时，通过同一授权通道恢复本次备份并让所属后端重新加载；保留原文、图库、任务和生成证据。不要删除目录锁绕过仍在运行的服务。

Windows2 的主机配置独立于 Git 制品。Jenkins 合并后发布仍沿用该配置；部署到新主机时必须重新验证参考图能力，再显式启用，不能仅因旧主机成功而将默认值改为 true。

## 2026-10-10 实测

- Windows2 使用受管理 CLI `0.162.0-alpha.2`，ChatGPT 登录状态成功；同一执行限制下真实文字调用完成。
- 合成几何参考生成真实 PNG，1254 × 1254，1,433,689 字节；目视确认蓝色矩形主体、黄色圆形和红色天线特征。
- 原配置缺少参考图开关；保留私有备份后启用，所属后端重载，公网就绪返回 `code=0`、`protocol=1`，浏览器显示参考图能力已启用。
- 公网浏览器保存明确标识的合成验收小记，沿用已选择的本人默认形象，生成的总览图成功写入并可放大；刷新后仍显示 1 张图，126 字正文完整保留。结束后仅将验收小记移入可恢复回收站。此验收不代表真人相似度或实体手机验收。
