# 小记本机 Codex 真实验收

用于没有服务端 AI 账号时，复用已登录的本机 Codex CLI，检查浏览器 → 小记保存 → 持久工作流 → 真实 AI → 条件回写 → 浏览器恢复。

这是独立的 **test classpath 验收入口**，不是生产 AI 路由。生产仍遵循 ADR-304，Runner 的端点、节点、凭据和安装器保持下线；不新增 API Key，不把 ChatGPT 登录信息复制进 WAO。入口固定使用 `gpt-6-astra`、ChatGPT 登录、只读沙箱，禁用 shell、子代理和网页搜索。仅使用明确标注的合成材料。

## 启动

1. 使用既有 `local-cloud` 数据连接，加载 `MYSQL_HOST`、`MYSQL_PORT`、`DB_NAME`、`DB_USER`、`DB_PASS`；不要将凭据放入下面的 JSON 或 Git。先执行 `codex login status`，确认使用 ChatGPT 登录。
2. 在 Git 忽略目录保存配置（UTF-8，无 BOM）：

```json
{
  "port": 18082,
  "memberId": "专用验收成员的真实ID",
  "titlePrefix": "WAO-CODEX-ACCEPTANCE-本轮唯一标识",
  "codex": "已安装codex可执行文件的绝对路径",
  "evidenceDir": "本机私有证据目录的绝对路径",
  "docIds": [],
  "mode": "hold",
  "timeoutSeconds": 180,
  "delaySeconds": 0
}
```

3. Windows PowerShell 运行：

```powershell
./deploy/scripts/notes-local-codex.ps1 -ConfigPath <配置的绝对路径>
```

入口监听 `127.0.0.1`，禁用 Flyway、服务发现和共享定时任务。主资源目录先于测试资源，防止 H2 测试配置覆盖真实连接。另起本机 Vite，将 `/api` 代理到本入口；不要更换公网运行制品或代理。

4. 在浏览器以对应成员登录。记录原来的小记 AI 偏好；本轮只启用正文润色，关闭标题和配图。若该成员存在历史在途工作，不清除别人的任务，应选择空闲的专用验收成员或在授权范围内临时调整该成员的并发数量并在结束时恢复。
5. 浏览器创建合成小记，正文至少 40 字。编辑标题为完整 `titlePrefix` 加场景名（默认自动截断的标题可能不足以匹配前缀）。从页面的 `data-note-id` 登记精确 ID 后放入 `docIds`；改为 `mode: normal` 才会推进。只有作者、标题前缀和 ID 同时匹配的未删除小记会执行。

## 验收步骤

这些步骤需要真实浏览器操作，不能用脚本退出码替代。

| 场景 | 操作与通过证据 |
| --- | --- |
| 成功与持久化 | 保存后等待润色完成；刷新并再次编辑，确认只有一份最新正文；核对样本事实与数字。 |
| 迟到结果与未保存输入 | `delaySeconds: 20`，任务执行中继续输入并记录焦点与光标；等待后台完成和页面自动轮询，确认输入、焦点与光标保留；保存再打开。 |
| 来源已经改变 | 延迟期间保存新正文，确认旧任务成果不覆盖新正文；新任务依据新的正文生成。 |
| 失败与重试 | `mode: fail` 只在验收执行出口抛错；页面应显示失败、保留原文及重试入口。改回 `normal`，从页面重试并确认完成。 |
| 超时 | `mode: timeout` 以极短超时启动实际 CLI 并结束本次进程；确认错误与原文保留。它是执行器超时注入，不能宣称验证了真实运营商断网。 |
| 本机进程中断 | 只结束本入口及其拥有的 CLI 子进程。重启后先使用 `hold`；确认旧进程确已停止后设为 `recover`，将登记小记的遗留运行收口为失败，再切回 `normal` 从页面重试。该人工恢复入口不代表生产具备自动恢复。 |

`hold` 暂停发起新工作，不能取消已经开始的模型调用。`recover` 不发起模型请求。不会自动重复模型请求，不使用额度重置。同一证据目录通过文件锁限制为一个验收进程；不要用不同配置重复登记同一文档。

## 证据与清理

- `evidenceDir/runs.jsonl`：精确文档 / 运行 ID、模型、模式、时间、耗时与结果。
- `evidenceDir/<runId>/result.txt` 和 `events.log`：真实 CLI 输出与日志，保留在私有目录，不提交 Git。
- 浏览器截图与操作记录另存到同一目录；执行状态成功不能单独证明页面、草稿或光标验收通过。
- 完成后将 `mode` 改为 `hold`，恢复临时偏好，并只通过浏览器软删除本轮精确登记的小记。保留证据，不清空回收站。
- 本地验证、PR 合并和生产部署分别报告。此入口没有接通生产 Provider API，也不覆盖标题、标签和配图的真实 AI 验收；这些缺项应保留。

实现复用正文提示词、TextPolishJobService、NoteAiWorkflowService、真实 MySQL 和 Provider 完成态 CAS。测试适配器只替换正文入队出口：等待态隔离于生产 Provider 消费查询，条件领取后沿用 Provider 完成状态。不提供 CLI/MCP 业务命令，因为这是只在测试类路径存在的本机验收资产，无对外服务能力或令牌扩权。
