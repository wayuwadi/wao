## 实机和交付边界

本次会话原生应用 UI 自动化不可用，浏览器控制也发生超时。自动检查、二进制架构和代码签名校验不能替代真实登录后的 UI 操作。以下需 Mac 用户确认或后续可用的原生 UI 验收：

- 邮箱/飞书登录及重启后会话保留；文件上传、下载、外链和新窗口。
- 原生标题栏、业务 WebView 的缩放与布局；编辑快捷键。
- 未保存草稿切换更新中心、关闭与 Dock 恢复后保留。
- 实际应用内下载、签名验证、确认安装和重新打开。
- Apple Silicon 实机启动和业务使用（Universal 架构检查不能代替此项）。

当前没有 Apple Developer ID 证书和公证；应用使用 ad-hoc 代码签名，公开下载页如实说明。Tauri 更新签名独立校验，私钥仅在 CI Secret 中使用。

## 2026-09-24 窗口顶部快捷操作修复的本地验收

- Apple Silicon Mac（macOS 26.5.1）已通过 `npm ci` 初始化前端依赖，并用本机 Node 24、Rust 1.98、Xcode Command Line Tools 构建独立的“WAO 开发宿主.app”；不替换已安装的正式客户端。完整 Xcode 与 `rustup` 未安装，本机未尝试 Universal DMG；正式双端包仍由 Jenkins 的 Windows 构建器与 Mac 节点生成。
- 开发宿主在真实 macOS 窗口启动。原生窗口无障碍树包含关闭、最小化、全屏按钮；顶部操作区包含后退、前进、刷新、页面菜单及快捷操作。界面截图中，远程登录页从顶部操作区下方开始。点击右侧“版本与更新”打开本地更新页，再点击“返回工作区”，恢复同一个远程登录页。
- 该开发宿主使用独立应用标识与会话。用户在开发宿主完成邮箱登录后，真实首页和业务数据正常显示。标题栏“新建任务”打开真实任务面板，空标题时创建按钮禁用；“新建小记”进入空白编辑器；主题切换可在明暗之间往返；快捷键面板、聊天、通知中心均能打开并关闭；折叠侧栏可恢复；后退、前进可在页面间导航。验收时没有创建任务、小记或发送消息。
- 回归对照：第一版覆盖式标题栏构建进入两个已有项目后，侧栏与页签正常、无障碍树也包含任务表，但主内容区域白屏；同一会话、同一项目在改动前的独立基线构建可正常显示。补上 macOS 主窗口的透明配置后，最终构建的项目标题、筛选栏与任务表均在截图中正常显示；使用父视图边界计算业务 WebView 高度，标题栏下方也没有多余空带。
- 最终构建从项目页打开“版本与更新”后，原生红黄绿按钮和更新面板均正常显示；返回工作区后，原项目任务表继续显示。前端测试 25 项通过、1 项原有跳过；Rust 测试 13 项通过；前端生产构建、应用签名校验、工程一致性检查与 `git diff --check` 通过。一致性检查仅报告基线已有的 4 处 ADR 重号。
