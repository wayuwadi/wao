## 真实用户链路

使用既有本地验收入口和正常登录，不清库、不创建模拟业务账号。登记专用小记标题、精确 ID、时间、验证结果到本机私有记录，不将真实内容和标识提交 Git。

1. 首页点底部空白或「和伙伴玩 → 抛个小球」；检查八秒收起、Esc 收起、再次投掷仍只有一球。点安静、切页、切换系统减少动态效果后应停止。
2. 轻按伙伴观察压缩，拖到边缘松手观察归位；鼠标划过毛绒观察局部变化。上方文字和卡片不移动，页面没有新增常驻面板。
3. 把选中文字拖到蓝色伙伴；看到轮廓和预览。键盘用伙伴 Shift+F10 或「和伙伴玩 → 递一段文字给小画家」完成等价粘贴。
4. 先在纸条正文输入专用旧草稿，再在接物预览输入中文、多行和 `<img ...>` 原文。关闭并刷新，检查两份输入仍在；追加后原稿保留，HTML 不成为图片，最后主动保存。
5. 到小记列表刷新，用专用标识搜索确认持久化内容，不只看成功提示。其他位置草稿保持不变。
6. 390px 窄屏检查伙伴和菜单可见、预览无横向溢出；长文本可滚动，关闭、追加和保存按钮可达。系统中文输入法和真实触屏设备另作人工确认。
