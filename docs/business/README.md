# 业务架构资料

本目录用于沉淀 WAO 的业务架构、模块边界、角色、核心流程和领域规则。业务实现以这里的可评审规格为输入。

建议小伙伴首个 PR 提供：

1. `business-architecture.md`：业务目标、角色、模块边界和核心流程。
2. `business-architecture.mmd` 或其他可编辑源文件。
3. `business-architecture.svg` 或 PNG 导出图。
4. 各模块待确认事项和 Phase 1 范围。

ER 图放在 `docs/database/`，并同步字段字典、索引、约束及 Flyway migration 规划。
