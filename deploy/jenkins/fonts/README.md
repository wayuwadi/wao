# WAO Release Sans

`WAO-Release-Sans.ttf` 是 [Google Fonts Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc) 的子集，保留 ASCII、常用标点、全角字符与 GB2312 中文字符，用于 Jenkins 发布图。原字体遵循同目录 `OFL.txt`。为遵守授权中的保留名称条款，子集字体已改名为「WAO Release Sans」。发布图需要显示子集外字符时，渲染器会失败并让飞书通知退回原文字卡，避免显示方框字。

源文件：`https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf`。字体不在 Jenkins 运行时联网下载。
