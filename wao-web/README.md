## 小记保存与恢复

活动草稿按成员、编辑入口及页签隔离。服务器保存完成后，清理活动草稿前保留该页签最后一次提交的完整输入；备份写入失败时保留原草稿。恢复副本不会自动作为未保存内容重新出现，空白新建区的“找回上次内容”可将最近副本恢复为新的草稿 ID，不自动提交、不覆盖已有小记。明确放弃输入不会替换保存恢复副本。

保存完成时同时比较正文、富文本结构、标签、标题及形象选择；提交期间的后续变化继续保留。浏览器存储失败且仍有修改，或请求仍在提交时，刷新/关闭页面触发浏览器离开提醒。恢复副本仅在当前浏览器的网站存储中，清除网站数据、浏览器损坏或更换设备无法依靠它恢复；它不替代服务器备份。

回归检查：`npm run test:unit -- --run src/__tests__/QuickNotePopover.spec.ts src/__tests__/noteDraftStorage.spec.ts src/__tests__/NotesView.spec.ts`。
